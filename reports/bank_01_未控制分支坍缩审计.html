是否需要降低同质化？

可以保留
  • Input 文本无精确重复。
  • 长度、轮数和开场角色存在一定变化。
  • 已有成功样本可作为自由生成基线。
必须新增
  • 从 Output Schema 的 enum 确定性抽样软目标。
  • 让模型只修正 Requirements 中不可达或冲突的最少字段。
  • 保存 sampled enum 与最终值的偏差，监控实际分支覆盖。
  • 重跑剩余编号时优先覆盖缺失 Step，而不是继续自由选择。

enum 软目标方案

递归收集 enum
step / rule / name / nested items
→
按编号确定性抽样
001、002…可复现
→
模型检查可达性
只改冲突最少字段

这是一种软约束：Schema 的独立 enum 组合并不保证语义可达，因此 Requirements 具有最终优先级。记录抽样值与最终值，可以区分“目标不可达”与“模型无视覆盖提示”。
