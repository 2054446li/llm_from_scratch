## 🔥 技术深度题（20 题）

### 1. Transformer 核心问题

**Q1: 解释 Attention 机制，为什么用 softmax？**

*预期答案框架*：
- 背景：处理序列位置间的依赖
- 核心：计算相似度权重，加权求和
- Softmax 的理由：归一化为概率、梯度流、指数强化高值
- 缩放的必要性：稳定方差

**Q2: 为什么需要多头注意力？**

*答案框架*：
- 单头的限制：只有一种关注模式
- 多头的优势：多角度特征提取
- 参数量不变的原因
- 并行计算的效率

**Q3: RoPE 如何编码相对位置？**

*答案框架*：
- 旋转矩阵的性质
- 点积只依赖相对距离的数学证明
- 与绝对位置编码的区别
- 长文本泛化能力

### 2. 预训练相关问题

**Q4: 为什么预训练有效？**

*答案框架*：
- 无需标注，利用大规模数据
- 学习通用表示
- 迁移学习的理论基础
- 实验证明（缩放律）

**Q5: 缩放律对模型设计有什么启示？**

*答案框架*：
- 模型和数据都重要
- N:D ≈ 1:20 的计算最优设置
- 资源分配的指导
- 为什么继续扩大规模有效

**Q6: GPT-3 和 GPT-2 最根本的区别？**

*答案框架*：
- 参数：1.5B vs 175B（100 倍）
- 数据：40GB vs 300B tokens
- 能力：有无 Few-shot 学习
- 背后：规模的量变到质变

---

### 3. 微调和对齐问题

**Q7: LoRA 为什么有效？**

*答案框架*：
- 核心假设：权重更新的秩较低
- 数学表达：W' = W + BA
- 参数量对比：减少 90% 以上
- 实践验证：保持性能同时减少成本

**Q8: DPO 相比 RLHF 的优势？**

*答案框架*：
- RLHF 的复杂性：3 个阶段，多个模型
- DPO 的简化：直接从偏好学习
- 去掉奖励模型的可能性
- 实验结果的对比

**Q9: 如何评估模型对齐的质量？**

*答案框架*：
- 自动指标的局限
- 人工评估的标准
- 多维度评估（有用、安全、真实）
- 基准数据集的选择

### 4. 强化学习问题

**Q10: 策略梯度方法中为什么需要基线？**

*答案框架*：
- 方差问题：每个样本的梯度方差大
- 基线的作用：减少方差不改变期望
- 最优基线的形式：状态价值函数
- 实践中的替代方案

**Q11: PPO 如何防止策略过度更新？**

*答案框架*：
- 信任区域的思想
- 剪裁目标函数的设计
- 与 TRPO 的关系
- 超参数 ε 的影响

**Q12: RLHF 中为什么需要 KL 约束？**

*答案框架*：
- 问题：模型偏离预训练模型
- 解决：KL 散度正则化
- β 的选择与权衡
- 模式退化的诊断

### 5. Agent 和推理问题

**Q13: ReAct 框架如何改进推理？**

*答案框架*：
- 传统：思考 → 输出
- ReAct：思考 → 行动 → 观察 → 再思考
- 优势：可以利用工具和反馈
- 应用场景

**Q14: 如何设计一个高效的 Agent 系统？**

*答案框架*：
- 工具的定义和接口
- 路由和选择机制
- 记忆管理
- 推理成本控制

**Q15: Chain-of-Thought 为什么有效？**

*答案框架*：
- 中间步骤的显式化
- 从一步到多步的转变
- 推理复杂度的权衡
- 与系统 1/系统 2 的类比

## 🎯 系统设计题（15 题）

### 1. 基础推理系统

**Q16: 如何设计一个 100B 模型的推理系统？**

*答案框架*：

**架构**：
- 单 GPU（A100）不够，需要多卡
- 张量并行：分割权重跨 GPU
- 流水线并行：分层跨 GPU
- 通信开销的权衡

**推理流程**：
```
输入 prompt
→ 编码（处理所有 token）
→ 生成（逐 token 自回归）
→ 输出
```

**优化**：
- KV 缓存：保存历史
- 批处理：多个请求
- 量化：减少内存
- 基于模型的剪枝

**Q17: 如何处理变长序列的推理？**

*答案框架*：
- 填充的浪费
- 动态批处理
- 页式注意力
- 流式处理

## 📋 答题技巧

### 回答框架

1. **理解问题**（30 秒）
   - 确认理解了问题
   - 澄清任何歧义

2. **高层视角**（1 分钟）
   - 简短的核心答案
   - 主要要点

3. **深度展开**（2-3 分钟）
   - 原理、例子、对比
   - 数据或公式支撑

4. **考虑权衡**（1 分钟）
   - 不同方案的优劣
   - 选择标准

5. **预期追问**（30 秒）
   - "你可能想问..."
   - 主动展示深度思考

### 常见失误

❌ 直接冲进细节，忘记背景
❌ 说了太多废话，没有核心点
❌ 只有理论，没有实践考虑
❌ 不承认自己不知道
❌ 没有考虑权衡和假设
