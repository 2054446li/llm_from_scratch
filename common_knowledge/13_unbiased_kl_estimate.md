# 无偏 KL 散度估计（Unbiased KL Estimate）

> 后训练 RL 稳定性核心。脉络分两层：先是 Schulman (2020) 的 k1/k2/k3 三个**蒙特卡洛 KL 估计器**（解决「KL 无法精确算、只能采样估计」的值层面问题），再是 DeepSeek-V3.2 的**离策略梯度修正**（把 k3 从 on-policy 推广到 off-policy）。前置：理解 [[9_grpo]] 中的 KL 正则项与重要性采样。

## 概述

在 GRPO/PPO 这类 RL 目标里，通常会加一个 KL 正则项 $\beta \cdot \mathbb{D}_{KL}(\pi_\theta \| \pi_{ref})$，把当前策略 $\pi_\theta$ 拴在参考策略 $\pi_{ref}$ 附近，防止训练跑偏。问题在于：**KL 散度本身无法精确计算**——按定义要对整个词表逐 token 求和：

$$\mathbb{D}_{KL}(q \| p) = \sum_x q(x) \log\frac{q(x)}{p(x)} = \mathbb{E}_{x \sim q}\!\left[\log\frac{q(x)}{p(x)}\right]$$

现实中我们只有从 $q$ 采样出的少量样本，只能用它们**估计** KL。一个好的估计器要同时满足两点：**无偏**（期望等于真实 KL）和**低方差**（单样本估计就不至于抖得太厉害）。Schulman 的三个估计器就是围绕这两个目标展开的。

## 一、Schulman 的三个 KL 估计器（值层面）

记单个样本 $x \sim q$，定义概率比 $r = \dfrac{p(x)}{q(x)}$。注意 KL 的定义里是 $\log\dfrac{q}{p} = -\log r$。

### k1：朴素估计（无偏，高方差）

直接照搬定义，用单样本的 $-\log r$ 作为估计：

$$k_1 = -\log r = \log\frac{q(x)}{p(x)}$$

- **无偏**：$\mathbb{E}_{x\sim q}[-\log r] = \mathbb{D}_{KL}(q\|p)$，就是定义本身。
- **高方差**：$-\log r$ 可正可负（当 $p(x) > q(x)$ 时为负），而真实 KL 恒非负。用一个能取负值的量去估一个恒正的量，单样本方差极大。

### k2：平方对数（低方差，有偏）

$$k_2 = \frac{1}{2}\left(\log r\right)^2$$

- **低方差**：恒非负，且形式上更"集中"，经验方差远小于 k1。
- **有偏**：它估的其实不是 KL，而是一个 **f-散度**。当 $p$、$q$ 接近时，所有 f-散度在二阶上都趋于 $\frac{1}{2}\chi^2$，彼此近似相等，所以 $q\to p$ 时 k2 的偏差是高阶小量、可以忽略；但 $p$、$q$ 差得远时偏差不可忽略。

### k3：控制变量修正（无偏，低方差）★

理想估计器应当**既无偏、又低方差、还恒非负**。做法是给 k1 加一个**期望为零的控制变量（control variate）**——注意 $\mathbb{E}_{x\sim q}[r] = \sum_x q(x)\frac{p(x)}{q(x)} = 1$，所以 $r-1$ 的期望恒为 0。于是对任意 $\lambda$：

$$-\log r + \lambda\,(r - 1)$$

都是 KL 的无偏估计。要让方差最小、且保证非负，取 $\lambda = 1$：

$$k_3 = (r - 1) - \log r$$

- **无偏**：因为 $r-1$ 是零期望控制变量，加上它不改变期望。
- **恒非负**：由不等式 $\log x \le x - 1$，可知 $(r-1) - \log r \ge 0$ 对所有 $r>0$ 成立。它其实是以 $-\log$ 为凸函数生成的 **Bregman 散度**，几何上恒为正。
- **低方差**：$r$ 与 $-\log r$ 的波动方向相反，相加后相互抵消，方差显著低于 k1，与 k2 相当。

**经验对比**（$p=\mathcal{N}(0,1)$，$q=\mathcal{N}(0.1,1)$，真实 KL$=0.005$）：

| 估计器 | 形式 | 偏差 | 标准差/真值 | 恒非负 |
|---|---|---|---|---|
| k1 | $-\log r$ | 0（无偏） | ≈20（极高） | 否 |
| k2 | $\frac{1}{2}(\log r)^2$ | ≈0.002（有偏） | ≈1.42 | 是 |
| k3 | $(r-1)-\log r$ | 0（无偏） | ≈1.42 | 是 |

k3 拿到了 k2 的低方差，又保住了 k1 的无偏——所以 GRPO/PPO 默认用 k3 做 KL 正则项的估计。

> **推广**：反方向 $\mathbb{D}_{KL}(p\|q)$ 的无偏低方差估计为 $r\log r - (r-1)$；一般 f-散度 $\mathbb{E}_q[f(r)]$ 的对应估计为 $f(r) - f'(1)(r-1)$，减去的正是零期望控制变量项。k3 是 $f=-\log$ 的特例。


## 实践要点

- **不同领域用不同 KL 强度**：DeepSeek-V3.2 发现对**可验证奖励**的领域（如数学），施加**较弱的 KL 惩罚、甚至完全省略**反而能提升性能。原因：这类领域有明确正确信号，不需要靠 KL 拴住参考策略，放开后探索更充分。
- 该修正与 [[9_grpo]] 的「离策略序列掩码」「保持路由」「保持采样掩码」共同构成 DeepSeek-V3.2 扩展 RL 算力的稳定性配方，核心主题都是处理 **训练-推理 / 新旧策略不一致** 带来的离策略问题。

## 与后训练的关联

大规模 on-policy RL 为了效率，必然把一大批 rollout 切成多个 mini-batch 多步更新（引入离策略），且 rollout 用高度优化的推理框架生成、训练用另一套框架（训练-推理不一致）。这两点都让「名义 on-policy、实际 off-policy」成为常态。无偏 KL 估计是在这种现实下，保证 KL 正则项不引入系统偏差、从而支撑长程稳定 RL 的关键一环。
