# YaRN（Yet another RoPE extensioN，RoPE 上下文窗口扩展）

> 长上下文扩展的主流方法，源自 Peng et al. (2023)。DeepSeek-V2、LLaMA 等用它把窗口从几 K 扩到 128K。前置：理解 RoPE（旋转位置编码）。
> 后训练关联：长上下文是长 CoT、长文档 RLHF / 多轮对齐的前提；YaRN 几乎免训练，是低成本撑大窗口的标准手段。

## 一句话直觉（先回答常见疑问）

**"是不是某个维度转不到一圈时才插值？"——对，基本就是这个意思。**

RoPE 把每一对维度想象成一个**以不同速度旋转的时钟**：高频维度转得飞快、低频维度转得极慢。判断"这个维度要不要插值"的标准，就是看它**在整个上下文长度 $L$ 内转了几圈**：

- 转了**很多圈**（高频、快时钟）→ 模型在训练时已经反复见过它的各种角度 → **不插值**，原样保留。
- **转不到一圈**（低频、慢时钟）→ 推理到长位置时，它的角度会落到训练时从没见过的区域 → **完全插值**（把角度压回训练范围）。
- 介于两者之间 → **斜坡平滑过渡**。

YaRN 的全部精巧之处，就是"**按圈数分维度、区别对待**"加上一个"**注意力锐化（温度）修正**"。

## 概述

YaRN 是一种**免训练或仅需极少量微调**就能把基于 RoPE 的模型上下文窗口**外推数十倍**的技术。它是「位置插值（PI）→ NTK-aware → YaRN」这条演进链的集大成者，核心是两个创新：

1. **NTK-by-parts 分段插值**：不再"一刀切"地压缩所有维度，而是按上面说的"圈数"区别对待。
2. **注意力温度缩放**：序列变长后注意力会"变散"，用一个温度因子把它重新"锐化"回来。

一句话：**对 RoPE 的不同频率维度采取不同的插值强度，并对注意力做温度校正，从而在不破坏局部位置精度的前提下大幅外推上下文长度。**

## 背景：RoPE 为什么外推会崩（动机）

### RoPE 的频率结构

RoPE 把 query/key 向量两两分组，对第 $i$ 对维度施加一个旋转，旋转角速度（频率）为：

$$\theta_i = b^{-2i/d}, \quad i = 0, 1, \dots, d/2-1$$

其中 $b$ 是 base（常取 10000），$d$ 是每头维度。位置为 $m$ 的 token，第 $i$ 对维度被旋转的角度是 $m\theta_i$。

- **低维（$i$ 小）→ $\theta_i$ 大 → 频率高 → 旋转快 → 波长短 $\lambda_i = 2\pi/\theta_i$**，编码"局部/相邻"位置差异。
- **高维（$i$ 大）→ $\theta_i$ 小 → 频率低 → 旋转慢 → 波长长**，编码"全局/远距离"位置差异。

把"波长"$\lambda_i$ 理解成"这个时钟转一整圈需要走多少个 token"会很直观：高频维度可能每隔几个 token 就转一圈，低频维度可能要几万个 token 才转一圈。

### 崩坏的根源：位置分布外（OOD）

训练时模型只见过位置 $0 \sim L_{\text{train}}$（如 4K）。也就是说，对每个维度，模型只见过角度 $m\theta_i$ 在 $[0,\, L_{\text{train}}\theta_i]$ 这个范围内的取值。

推理到位置 100K 时：
- **高频维度**：它本来转得就快，在 4K 内已经转了成百上千圈，$[0, L_{\text{train}}\theta_i]$ 早就覆盖了整个 $[0, 2\pi]$ 圆周很多遍。位置变到 100K 只是"多转几圈"，角度仍然落在见过的圆周上 → **没问题**。
- **低频维度**：它转得极慢，在 4K 内可能连一圈都没转完，模型只见过这个时钟"前小半圈"的样子。位置变到 100K，角度 $m\theta_i$ 一下子冲到训练从没见过的"后半圈" → **彻底 OOD**，注意力 logits 出现异常大/异常的值，性能崩坏。

**这就是为什么"圈数"是关键判据**：转得多的维度天生抗外推，转不满一圈的维度才是外推时真正"没见过新角度"的受害者，需要被插值救回来。

## 三代方法演进（每一代在解决上一代的什么问题）

| 方法 | 做法 | 为什么这么做 / 缺陷 |
|------|------|------|
| **直接外推** | 啥都不改，直接喂长序列 | 低频维度 OOD，崩坏 |
| **位置插值 PI**（Chen et al.） | 把所有位置 $m \to m/s$（$s=L_{\text{target}}/L_{\text{train}}$），等价于所有频率统一压扁 $s$ 倍 | 思路：把长位置"压回"训练范围内。**但一刀切**——高频维度本来不需要压，被强行压扁后相邻 token 的角度差变得极小，**局部分辨率被压垮**，丢失精细位置区分 |
| **NTK-aware** | 不改位置而改 base：$b \to b \cdot s^{d/(d-2)}$，效果是高频几乎不动、低频压得多 | 思路：意识到"不该一刀切"，让高频少受影响。**但仍是按一个全局公式连续分配**，没有显式判断每个维度到底转没转满一圈，边界处理偏经验 |
| **YaRN** | NTK-by-parts 分段 + 注意力温度缩放 | 把"按圈数区别对待"显式化、精确化，再补一个注意力锐化修正。当前主流 |

**关键演进逻辑**：PI 发现"压缩能解决 OOD"，但代价是压垮高频；NTK-aware 发现"高频不该压"；YaRN 把这个洞察做到极致——用"圈数 $r_i$"精确划线，并额外修正了一个 PI/NTK 都忽略的副作用（注意力变散）。

## 核心原理与公式

### 1. NTK-by-parts（分段插值）—— 核心创新一

**目标**：精确判断每个维度"转了几圈"，据此决定插值强度。

定义每个维度在原训练窗口内转过的圈数（用波长换算）：

$$r_i = \frac{L_{\text{train}}}{\lambda_i} = \frac{L_{\text{train}}\,\theta_i}{2\pi}$$

$r_i$ 就是"第 $i$ 个时钟在训练长度内转了几圈"。按它把维度分三类：

- **高频维度（$r_i > \beta$，转了很多圈）**：**完全不插值**。
  *为什么*：它在训练时已见过整个圆周无数遍，外推不会 OOD；而它负责局部分辨率，一旦插值就被压垮。所以原样保留。
- **低频维度（$r_i < \alpha$，转不到一圈/很少圈）**：**完全插值**，行为同 PI（频率压 $s$ 倍）。
  *为什么*：它正是 OOD 的受害者，必须把角度压回训练范围；而它负责的是粗粒度全局位置，压扁一点对分辨率影响小。
- **中间维度（$\alpha \le r_i \le \beta$）**：用**斜坡函数 ramp $\gamma(r_i)$** 平滑过渡，避免在边界突变：

$$\gamma(r_i) = \begin{cases} 0, & r_i < \alpha \\[2pt] 1, & r_i > \beta \\[2pt] \dfrac{r_i - \alpha}{\beta - \alpha}, & \text{otherwise} \end{cases}$$

最终每个维度用的频率，是"原频率 $\theta_i$（不插值）"与"PI 压扁频率 $\theta_i/s$（完全插值）"按 $\gamma$ 的插值混合：

$$\theta_i^{\text{new}} = \gamma(r_i)\cdot\theta_i + \bigl(1-\gamma(r_i)\bigr)\cdot\frac{\theta_i}{s}$$

> **$\gamma=1$（高频）→ 用原频率，不动；$\gamma=0$（低频）→ 用 PI 频率，全压。** 这正好对应你的疑问：转得满的不插值，转不满的才插值。
> **$\alpha$、$\beta$ 的含义**：$\alpha$ 是"开始保留"的圈数下界，$\beta$ 是"完全保留"的圈数上界。DeepSeek-V2 取 $\alpha=1,\beta=32$——直觉上 $\alpha=1$ 恰好就是"**转满一圈**"这条线，转不满一圈的维度完全插值，印证了你的理解。

### 2. 注意力温度缩放 —— 核心创新二

**现象**：序列从 4K 拉到 128K 后，每个 query 要 attend 的 key 多了几十倍。即使 logits 分布形状不变，softmax 在更多项上归一化会让**注意力熵升高**（概率被摊薄、变得过于分散、"看哪都差不多"），削弱了模型聚焦关键 token 的能力，长序列困惑度上升。

**做法**：在 softmax 前给 logits 整体放大（除以一个 $t<1$ 的温度，等价于乘以 $1/t>1$），把分布重新**锐化**：

$$\text{softmax}\!\left(\frac{q^\top k}{t \cdot \sqrt{d}}\right)$$

*为什么有效*：放大 logits 会拉开最大值与其它值的差距，softmax 后概率更集中，把被长序列摊薄的熵拉回正常水平。

**工程实现**：等价于把 $q$、$k$ 各预先乘以 $1/\sqrt{t}$，**完全不改注意力主体代码**，只在生成 q/k 时加一个标量缩放。缩放强度随外推倍数 $s$ 增大而增大，原版 YaRN 的推荐式为：

$$\sqrt{\frac{1}{t}} = 0.1 \cdot \ln(s) + 1 \quad\Longleftrightarrow\quad \frac{1}{t} = \bigl(0.1\ln s + 1\bigr)^2$$

> $s$ 越大（外推越狠）→ 序列越长 → 熵升得越多 → 需要的锐化（$1/t$）越强，所以缩放因子随 $\ln s$ 单调增。$s=1$ 时因子为 1，退化回不缩放。

## DeepSeek-V2 中的具体应用

| 项目 | 设置 / 说明 |
|------|------------|
| 窗口扩展 | 4K → 128K（目标最大长度设 160K） |
| 超参 | $s=40$，$\alpha=1$，$\beta=32$ |
| 温度因子 | 改为 $\sqrt{1/t} = 0.0707 \cdot \ln(s) + 1$（因 MLA 注意力机制不同，系数从 0.1 重调到 0.0707 以最小化困惑度） |
| 作用对象 | **仅作用于解耦的共享 key $k^R$**——MLA 中只有它承载 RoPE，压缩潜在向量 $c^{KV}$ 不带位置信息 |
| 微调成本 | 仅在 **32K 序列**上额外训 **1000 步**（batch 576），即可在 128K"大海捞针"（NIAH）测试中表现良好 |

> **MLA 的特殊便利**：标准 RoPE 作用于全部 K，而 MLA 把位置信息**解耦**到单独的一路 $k^R$。所以 YaRN 只需调这一路，其余压缩的 KV 潜在向量完全不受影响。这是 MLA「解耦 RoPE」设计与 YaRN 的天然契合——也解释了为什么 DeepSeek 能用极小的微调代价完成扩展。

## 优势

- **几乎免训练**：少量微调（甚至零样本）即可外推，远比从头训长上下文便宜。
- **保局部精度**：分段插值不牺牲高频维度，相邻 token 区分能力不受损。
- **困惑度低**：温度缩放校正注意力熵，长序列质量优于 PI / NTK-aware。
- **实现简单**：只改频率和一个温度标量，不动注意力主体结构。

## 与相关方法对比

| 方法 | 是否需训练 | 高频精度 | 注意力熵校正 | 外推能力 |
|------|-----------|---------|------------|---------|
| 直接外推 | 否 | — | 无 | 极差（OOD 崩坏） |
| 位置插值 PI | 需微调 | 差（被压垮） | 无 | 中 |
| NTK-aware | 可免训练 | 较好 | 无 | 中上 |
| **YaRN** | 极少微调 | **好（分段保留）** | **有** | **强** |
