# 预训练、SFT、RL 三阶段学习率对比

## 概述

大语言模型训练通常分为三个阶段：预训练（Pre-training）、监督微调（SFT）、强化学习对齐（RLHF/DPO）。三个阶段的学习率逐步递减，反映了不同阶段优化目标和约束条件的本质差异。

## 典型学习率对比

| 阶段 | 学习率范围 | 典型值（以67B为例） | 数据规模 | 优化目标 |
|------|-----------|-------------------|---------|---------|
| Pre-training | 1e-4 ~ 5e-4 | 3.2e-4 | 万亿级 token | 学习通用语言表示 |
| SFT | 5e-6 ~ 2e-5 | 5e-6 ~ 1e-5 | 百万级样本 | 学习指令遵循格式 |
| RLHF/DPO | 1e-6 ~ 5e-6 | 5e-6 | 十万级偏好对 | 微调偏好与安全性 |

## 各阶段学习率设置的原因

### Pre-training：大学习率（1e-4 ~ 5e-4）

**为什么大：**

1. **起点远离最优**：模型从随机初始化开始，参数空间中距离任何有意义的解都很远，需要大步长快速移动
2. **数据量充足**：万亿级 token 提供了强的梯度信号，单步的错误可以被后续数据纠正
3. **优化景观宽阔**：预训练的 loss landscape 相对平滑，存在较大的低损失盆地，大学习率不容易跳出
4. **效率需求**：预训练耗时数月，学习率太小会导致收敛过慢，无法在合理时间内完成

**调度策略：**
- 通常有 warmup 阶段（如 2000 步线性升温）
- 之后按余弦或多步衰减逐步降低
- DeepSeek LLM 使用多步衰减：80% tokens 后降至 31.6%，90% 后降至 10%

### SFT：中等学习率（5e-6 ~ 2e-5）

**为什么要比预训练小 10-50 倍：**

1. **保护预训练知识**：预训练已经学到了丰富的语言知识和世界知识，大学习率会破坏这些表示（灾难性遗忘）
2. **数据量有限**：SFT 数据通常只有百万级，大学习率 + 少量数据 = 过拟合
3. **目标是"格式调整"而非"知识注入"**：SFT 主要教模型如何以对话形式输出已有知识，不需要大幅修改权重
4. **分布偏移风险**：SFT 数据分布与预训练数据不同，大学习率可能让模型过度适配 SFT 分布

**实践观察（来自 DeepSeek LLM）：**
- 67B 模型比 7B 需要更小的学习率（5e-6 vs 1e-5）
- 67B 只需 2 epoch，7B 需 4 epoch
- 更大模型对过拟合更敏感

### RLHF/DPO：最小学习率（1e-6 ~ 5e-6）

**为什么要最小：**

1. **对齐税（Alignment Tax）**：RL 阶段很容易降低模型的基础能力，极小学习率限制了每步的权重变化幅度
2. **奖励信号噪声大**：奖励模型本身不完美，大学习率会放大奖励信号中的噪声和偏差
3. **Reward Hacking 风险**：大学习率可能让模型快速找到"欺骗"奖励模型的捷径，而非真正改善质量
4. **目标极其精细**：从"能回答"到"回答得更好/更安全"是非常微小的行为调整
5. **稳定性要求高**：RL 训练本身不稳定（策略梯度方差大），小学习率是基本的稳定措施

**DPO 特殊考虑：**
- DPO 虽然去除了 RL 的不稳定性，但仍需要小学习率
- 原因：偏好数据中的"好/坏"区分往往很微妙，大步长容易矫枉过正

## 直觉类比

```
预训练 = 开车从家到目的地城市    → 油门到底，高速行驶
SFT    = 在城市里找到目标街区    → 减速，遵守路标
RL     = 在街区里精确停到车位中   → 缓慢移动，反复微调方向
```

## 影响学习率选择的其他因素

| 因素 | 影响 |
|------|------|
| 模型规模越大 | 学习率应越小（loss landscape 更尖锐） |
| 数据质量越高 | 可以适当增大（梯度信号更纯净） |
| Batch size 越大 | 学习率可适当增大（梯度估计更准） |
| 训练步数越多 | 初始学习率可以更大（有更多衰减空间） |

## 缩放定律视角

DeepSeek LLM 的研究发现，最优学习率与计算预算之间存在幂律关系：

$$\eta_{opt} = 0.3118 \cdot C^{-0.1250}$$

即计算预算（≈模型规模×数据量）越大，最优学习率越小。这从理论上统一解释了为什么更大的模型、更后期的阶段需要更小的学习率。
