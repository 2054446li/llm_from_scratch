# ch05 — 训练系统与优化器

> AdamW / 混合精度 / DeepSpeed-ZeRO 是后训练工程师的基础设施知识，面试必考。

---

## Q1 ⭐ AdamW 的原理？为什么比 Adam 好？
**Adam**：自适应学习率，维护一阶矩 m（梯度均值）和二阶矩 v（梯度方差）：
```
m = β₁·m + (1-β₁)·g
v = β₂·v + (1-β₂)·g²
θ = θ - lr · m̂ / (√v̂ + ε)
```
**Adam 的 L2 正则问题**：Adam 中 L2 正则（`loss += λ·‖θ‖²`）等价于在梯度上加 `λθ`，但这个梯度也会被自适应缩放，导致正则效果被削弱（参数更新大的方向正则也被缩小）。

**AdamW**：把权重衰减从梯度中分离，直接作用在参数上：
```
θ = θ - lr · m̂/(√v̂+ε) - lr·λ·θ
```
权重衰减不经过自适应缩放，正则效果更稳定。**现代 LLM 训练标配**。

**追问：β₁/β₂/ε 典型值？** β₁=0.9，β₂=0.95（LLM 常用，比 0.999 更快适应），ε=1e-8。

## Q2 ⭐ 学习率调度：Warmup + Cosine Decay 的原因？
- **Warmup**：训练初期参数随机，梯度方差大，直接用大 LR 会不稳定。Warmup 从小 LR 线性增大，让二阶矩 v 先积累稳定的统计量。
- **Cosine Decay**：训练后期用余弦曲线平滑降低 LR，避免在最优点附近震荡，让模型收敛到更好的局部最优。
- **WSD（Warmup-Stable-Decay）**🔥：DeepSeek 等采用，先 warmup，中间长期稳定 LR，最后快速 decay。好处是可以在 stable 阶段随时保存 checkpoint 并 decay，灵活控制训练终止点。

## Q3 ⭐ 混合精度训练（BF16/FP16 + FP32）的原理？
**动机**：FP32 训练显存占用大、计算慢；FP16/BF16 快但精度低。

**混合精度**：
- **前向/反向**：用 FP16 或 BF16 计算（快、省显存）
- **参数更新**：保留 FP32 主权重（master weights），更新后再转回低精度
- **为什么用 BF16 而非 FP16**：BF16 与 FP32 指数位相同（8位），动态范围一致，不需要 loss scaling；FP16 动态范围小，容易溢出，需要 loss scaling。**LLM 主流用 BF16**。

## Q4 ⭐ DeepSpeed ZeRO 的三个阶段？
**背景**：大模型训练时，每个 GPU 存完整模型状态（参数 + 梯度 + 优化器状态）显存不够。ZeRO 把这些状态**分片**到多个 GPU。

| 阶段 | 分片内容 | 显存节省 | 通信开销 |
|------|---------|---------|---------|
| **ZeRO-1** | 优化器状态 | ~4x | 低 |
| **ZeRO-2** | 优化器状态 + 梯度 | ~8x | 中 |
| **ZeRO-3** | 优化器状态 + 梯度 + 参数 | ~N倍(N=GPU数) | 高 |

- ZeRO-1/2 常用于训练，ZeRO-3 显存最省但通信最多。
- **ZeRO-Offload**：把优化器状态/梯度 offload 到 CPU，进一步省 GPU 显存（速度换显存）。

## Q5 3D 并行的三个维度？
- **数据并行（DP）**：每个 GPU 有完整模型，数据分片，梯度 AllReduce 同步。
- **张量并行（TP）**：把单层（如 FFN、注意力头）的权重矩阵切分到多个 GPU，层内并行。通信频繁（每层都需要 AllReduce），适合单机多卡。
- **流水线并行（PP）**：把模型按层切分到不同 GPU，形成流水线。通信少但有 bubble（等待）。

**实际使用**：通常 TP 在机内（NVLink 快），PP 在机间（IB 慢但通信少），DP 在最外层。

---

## Q6 梯度裁剪（Gradient Clipping）的作用？
防止梯度爆炸。把梯度的全局 L2 范数裁剪到阈值（通常 1.0）：若 `‖g‖ > clip_norm`，则 `g = g · clip_norm / ‖g‖`。LLM 训练标配，尤其在 RL 阶段（奖励信号方差大，梯度更容易爆炸）。

---

## 一句话速记
- AdamW：权重衰减从梯度分离，正则效果不被自适应缩放削弱。
- BF16：动态范围与 FP32 一致，无需 loss scaling，LLM 主流。
- ZeRO：分片优化器/梯度/参数，ZeRO-3 省显存最多但通信最重。
- 3D 并行：TP 机内、PP 机间、DP 最外层。
