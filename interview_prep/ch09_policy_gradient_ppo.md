# ch09 — 策略梯度与 PPO

> PPO 是 RLHF 的核心算法，四模型架构是后训练工程师必须能画出来的。

---

## Q1 ⭐ 策略梯度（REINFORCE）的基本思想？
**目标**：最大化期望奖励 `J(θ) = E_{y~π_θ}[R(y)]`。

**梯度**（策略梯度定理）：
```
∇J(θ) = E[R(y) · ∇log π_θ(y|x)]
```
**直觉**：奖励高的轨迹，增大其概率；奖励低的轨迹，减小其概率。

**问题**：① 高方差（单次采样奖励波动大）；② 样本效率低（on-policy，每次更新后数据作废）。

**基线（Baseline）**：减去基线 b（通常是奖励均值）降低方差：`∇J = E[(R-b) · ∇log π]`，不影响期望，只降方差。

---

## Q2 ⭐ TRPO 解决了什么问题？PPO 如何简化它？
**TRPO 问题**：策略梯度更新步长难以控制，步子太大会破坏策略。TRPO 用 KL 散度约束每次更新：`max J s.t. KL(π_old||π_new) ≤ δ`，但需要二阶优化（共轭梯度），计算复杂。

**PPO（Proximal Policy Optimization）**：用 clip 替代 KL 约束，一阶优化即可：
```
L_CLIP = E[min(r_t·A_t, clip(r_t, 1-ε, 1+ε)·A_t)]
```
其中 `r_t = π_θ(a|s) / π_old(a|s)` 是重要性采样比，ε 通常为 0.2。

**直觉**：当新策略偏离旧策略太多（r_t 超出 [1-ε, 1+ε]），梯度被截断，防止过大更新。

---

## Q3 ⭐ GAE（广义优势估计）是什么？
**优势函数**：`A(s,a) = Q(s,a) - V(s)`，衡量动作 a 比平均水平好多少。

**TD 误差**：`δ_t = r_t + γV(s_{t+1}) - V(s_t)`

**GAE**：用 λ 加权的多步 TD 误差：
```
A_t^GAE = Σ_{l=0}^∞ (γλ)^l · δ_{t+l}
```
- λ=0：纯 TD（低方差高偏差）
- λ=1：纯 MC（高方差低偏差）
- λ∈(0.9, 0.95)：平衡，实践中常用

## Q4 ⭐ RLHF 中 PPO 的四模型架构？
```
Actor (π_θ)      ← 被优化的策略，从 SFT 初始化
Critic (V_φ)     ← 估计状态价值，从 SFT 或 RM 初始化
Reference (π_ref)← 冻结的 SFT 模型，用于计算 KL
Reward Model (r) ← 冻结的 RM，提供奖励信号
```

**训练流程**：
1. Actor 生成回复 y
2. RM 打分得到 r(x,y)
3. 计算 KL：`KL_t = log π_θ(y_t|...) - log π_ref(y_t|...)`
4. 总奖励：`R_t = r(x,y)·1[t=T] - β·KL_t`（只在最后 token 加 RM 分，每步减 KL）
5. Critic 估计优势，PPO clip 更新 Actor
6. Critic 用 TD 误差更新

**显存挑战**：四个模型同时在 GPU 上，显存压力极大。实践中 Reference 和 RM 可以 offload 或量化。

---

## Q5 PPO 在 LLM 中的特殊性？和游戏 RL 有什么不同？
- **动作空间**：词表大小（32K-150K），远大于游戏。
- **序列奖励**：奖励通常只在序列末尾给出（稀疏），中间 token 无直接奖励。
- **KL 惩罚**：LLM 的 PPO 必须加 KL 约束，否则模型会快速崩溃（reward hacking）。
- **样本效率**：LLM 生成成本高，通常每个 prompt 只采样 1-4 个回复（游戏可以采样数千步）。

---

## 一句话速记
- REINFORCE：高方差，基线降方差。
- PPO：clip 替代 KL 约束，一阶优化，ε=0.2。
- GAE：λ 加权多步 TD，平衡偏差-方差。
- 四模型：Actor/Critic/Reference/RM，Reference 和 RM 冻结。
