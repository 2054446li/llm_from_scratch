# ch12 — DPO 系列

> DPO 是离线对齐路线的奠基，推导必须能逐行讲清，变体对比是高频题。

---

## Q1 ⭐ DPO 的核心思想？它绕开了什么？
**DPO（Direct Preference Optimization）**：把 RLHF 的"RM 训练 + PPO"两步合并成**一个对偏好数据的分类损失**，**绕开了显式 RM 和在线采样（rollout）**。

**核心洞察**：RLHF 的 KL 正则最优解有闭式形式，可以反解出奖励，代入 Bradley-Terry 后奖励项消掉，得到只依赖策略的损失。

---

## Q2 ⭐ DPO 损失的推导过程？（必须能讲）
**第一步**：RLHF 目标（KL 正则的奖励最大化）的最优解：
```
π*(y|x) = (1/Z(x)) · π_ref(y|x) · exp(r(x,y)/β)
```
**第二步**：反解出奖励：
```
r(x,y) = β·log(π*(y|x)/π_ref(y|x)) + β·log Z(x)
```
**第三步**：代入 Bradley-Terry 模型 `P(y_w>y_l) = σ(r(y_w)-r(y_l))`，**配分函数 Z(x) 在差值中抵消**：
```
L_DPO = -E[log σ(β·(log(π_θ(y_w)/π_ref(y_w)) - log(π_θ(y_l)/π_ref(y_l))))]
```
**直觉**：拉高 chosen 的相对对数概率，压低 rejected 的，β 控制偏离 π_ref 的强度。

---

## Q3 ⭐ DPO vs PPO：根本区别是什么？
| 维度 | DPO | PPO |
|------|-----|-----|
| on/off-policy | **off-policy**（离线，固定偏好数据） | on-policy（在线采样） |
| RM | 无（隐式奖励） | 需要显式 RM |
| 采样 | 无需 rollout | 需要在线 rollout |
| 资源 | 省（无 RM、无采样） | 重（四模型） |
| 探索 | 无法探索数据外的回答 | 能探索新回答 |

**根本区别（on/off-policy）**：DPO 只能从固定的偏好数据学习，无法探索数据分布外的回答；PPO 在线采样，能发现新的高奖励回答。这是 DPO 与 GRPO/PPO 的根本分野。

---

## Q4 ⭐ DPO 的隐式奖励是什么？β 的作用？
- **隐式奖励**：`r(x,y) = β·log(π_θ(y|x)/π_ref(y|x))`，DPO 训练的策略本身就隐含了一个奖励模型（"Your Language Model is Secretly a Reward Model"）。
- **β**：控制隐式 KL 约束强度。β 大 → 更贴近 π_ref（保守）；β 小 → 允许更大偏离（激进，但可能过拟合）。

---

## Q5 ⭐ DPO 的失效点/局限？
1. **分布偏移**：当 π_ref 与偏好数据分布不匹配时，DPO 效果差（偏好数据最好来自 π_ref 采样）。
2. **likelihood 双降**：训练中 chosen 和 rejected 的概率**可能同时下降**（只要相对差距拉大即可满足损失），导致模型整体概率质量流失。
3. **长度偏置**：DPO 倾向于偏好更长的回复（与 SimPO 要解决的问题）。
4. **对噪声敏感**：偏好数据的标注噪声会直接影响，无 RM 的平滑作用。

---

## Q6 ⭐ DPO 变体对比（核心三问：要不要 ref 模型、要不要成对数据、如何处理长度偏置）
| 变体 | 改了什么 | 解决的问题 | 需 ref? | 需成对? |
|------|---------|-----------|---------|---------|
| **DPO** | 基线 | — | 是 | 是 |
| **IPO** | 加正则项 | 防对确定性偏好过拟合 | 是 | 是 |
| **KTO** | 用前景理论，二元标签 | 只需"好/坏"标签，数据更易得 | 是 | **否** |
| **ORPO** | SFT+对齐合一，odds-ratio 惩罚 | **无需 ref 模型**，一步到位 | **否** | 是 |
| **SimPO** | 长度归一化平均对数概率 + margin | **去 ref 模型 + 解决长度偏置** | **否** | 是 |

**一句话串**：DPO 变体主要在动三样——ref 模型、成对数据、长度偏置。

---

## 一句话速记
- DPO 推导：RLHF 最优解 → 反解奖励 → 代入 BT → Z(x) 抵消 → 分类损失。
- 隐式奖励：β·log(π_θ/π_ref)，β 控制 KL 强度。
- DPO 是 off-policy，不能探索；likelihood 双降是典型失效。
- 变体三问：ref? 成对? 长度偏置? SimPO 三者全改。
