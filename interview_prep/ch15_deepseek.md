# ch15 — DeepSeek 架构与后训练串讲

> DeepSeek 是国内后训练岗最常被问的模型。面试常让你"讲讲 R1 是怎么训的"或"MLA 解决什么问题"。本章串起架构创新 + 后训练配方。

---

## Q1 ⭐ DeepSeek 系列的演进主线？
- **V1（2024.01）**：稠密 67B，追赶 Llama2，验证基座能力。
- **V2（2024.05）**：里程碑——**MLA + DeepSeekMoE**，236B/激活21B，KV Cache 降 93%，训练成本降 42.5%。
- **V3（2024.12）**：极致效率 MoE，671B/激活37B，FP8 训练 + 无辅助损失负载均衡 + MTP。
- **R1（2025.01）**：纯 RL 激发推理（GRPO + RLVR），R1-Zero 证明无 SFT 也能涌现推理。
- **V3.2（2025.12）**：DSA 稀疏注意力 + 可扩展 RL 稳定性配方。
- **V4（2026）**：1M 上下文，分域 RL + OPD 统一后训练范式。

---

## Q2 ⭐🔥 MLA（Multi-head Latent Attention）解决什么问题？原理？
**问题**：MHA 的 KV Cache 随序列线性增长，长上下文/大 batch 推理时显存爆炸——直接限制 RL rollout 吞吐。

**原理**：把 K/V **联合低秩压缩**成一个低维 latent 向量 c_KV，推理时只缓存 c_KV（而非完整 K/V），用时再上投影还原。
```
c_KV = W_DKV · h        # 下投影到低维 latent（缓存这个）
k = W_UK · c_KV         # 用时上投影还原 K
v = W_UV · c_KV         # 用时上投影还原 V
```
- **KV Cache 降 93%**：只存低维 c_KV 而非完整多头 K/V。
- **质量不降甚至更好**：低秩压缩类似隐式正则。
- **解耦 RoPE**：RoPE 需要位置相关的旋转，无法直接压缩，所以 MLA 把 K 拆成"压缩部分 + 独立的 RoPE 部分"（decoupled RoPE），单独保留一小块携带位置信息。

**后训练关联**🔥：MLA 让 KV Cache 极小 → RL rollout 时同显存能跑更大 batch/更长序列 → RL 采样吞吐更高，这是 DeepSeek 能做大规模 reasoning RL 的基础设施前提。

## Q3 ⭐🔥 DeepSeekMoE 的两个创新？
1. **细粒度专家**：把每个专家拆更小，增加路由组合灵活性（同等激活参数下能组合更多知识）。
2. **共享专家（Shared Expert）**：部分专家对所有 token 恒激活，处理通用知识，让路由专家专注领域知识，减少冗余。

**V3 的负载均衡创新**：用**无辅助损失（auxiliary-loss-free）**的动态偏置调整路由，替代传统负载均衡辅助损失——避免辅助损失干扰主任务 loss。

## Q4 ⭐🔥 DeepSeek-R1 完整训练流程？（高频必背）
四段式：
1. **冷启动 SFT**：少量高质量长 CoT 数据微调，建立推理格式（解决 R1-Zero 可读性差、语言混杂问题）。
2. **推理 RL（GRPO + RLVR）**：数学/代码用规则奖励（答案校验、编译器、单测）做大规模 RL，激发推理。加语言一致性奖励防中英混杂。
3. **拒绝采样 + SFT**：用 RL 模型生成大量回复，规则/RM 筛选高质量样本，再 SFT 扩展到通用领域（写作、QA）。
4. **全场景 RL**：结合规则奖励（推理）+ RM（通用对齐帮助性/安全性）做最终对齐。

**R1-Zero**：跳过所有 SFT，从 base 直接 GRPO+RLVR。证明**纯 RL 可涌现推理能力**（自发出现反思、验证、长 CoT），但可读性差、语言混杂——所以正式 R1 加冷启动。

---

## Q5 🔥 R1 带来的关键认知？
- **纯 RL 可涌现推理**：不需要海量 CoT 标注，规则奖励 + GRPO 就能让模型学会长链推理（"aha moment"自发反思）。
- **蒸馏 > 小模型直接 RL**：R1 的推理能力蒸馏到小模型（Qwen/Llama）效果，比小模型自己做 RL 更好——说明**大模型 RL 出的能力可高效迁移**，小模型 RL 探索能力有限。
- **RLVR 是关键**：可验证奖励绕开 RM 的 reward hacking 和标注成本，是纯 RL 可行的前提。

---

## Q6 🔥 DeepSeek-V3.2 的可扩展 RL 稳定性配方？
- **DSA（DeepSeek Sparse Attention）**：可训练稀疏注意力，进一步降长序列成本。
- **离策略修正**：长 rollout + 异步更新导致 off-policy，用重要性采样 + KL 修正保证正确性（连接 k1/k2/k3 估计器）。
- **训练-推理一致性**：保证 RL 训练时的策略分布与推理引擎（如 vLLM/SGLang）一致，避免数值差异导致的 off-policy 偏差。

---

## 一句话速记
- MLA：K/V 低秩压缩，KV Cache 降 93%，解耦 RoPE，是大规模 RL rollout 的基础设施前提。
- DeepSeekMoE：细粒度专家 + 共享专家，V3 用无辅助损失负载均衡。
- R1 四段式：冷启动 SFT → 推理 RL(GRPO+RLVR) → 拒绝采样 SFT → 全场景 RL。
- R1-Zero：纯 RL 涌现推理，但可读性差需冷启动。
- 大模型 RL 能力可蒸馏到小模型，优于小模型直接 RL。
