- **流水线并行 (PP)**：分层分配到不同 GPU
- **序列并行 (SP)**：长序列处理

### 5. 训练稳定性
- **梯度裁剪**：防止梯度爆炸
- **损失尖刺的诊断与解决**

## 关键知识点

### 优化器对比表

| 优化器 | 优点 | 缺点 | 适用 |
|-----|-----|-----|------|
| SGD | 简单、高效 | 收敛慢 | 小数据集 |
| Adam | 自适应学习率 | 可能过度正则化 | 通用 |
| AdamW | 解耦权重衰减 | 略显复杂 | 推荐 |
| Lion | 内存高效 | 较新 | 大模型 |
| Sophia | 二阶信息 | 计算开销 | 研究 |

### 学习率调度公式

**Cosine Annealing**：
$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\pi t/T))$$

**Linear Warmup + Cosine Decay**：
- 前 10% epoch：线性预热到目标学习率
- 后 90% epoch：余弦衰减到最小值

### 并行策略选择

```
数据规模  |  模型大小  |  推荐策略
---------|----------|----------
小       |  小      |  单 GPU
小       |  中/大   |  TP + PP
大       |  小      |  DDP
大       |  中      |  DDP + TP
大       |  大      |  DDP + TP + PP
```

## 面试准备

### 常见问题

1. **为什么 AdamW 比 Adam 更好？**
   - Adam 中权重衰减被正则化替代，导致过度正则化
   - AdamW 解耦权重衰减和梯度更新

2. **如何诊断梯度爆炸？**
   - 监控梯度范数
   - 观察损失值变化
   - 检查是否出现 NaN/Inf

3. **流水线并行的通信开销？**
   - GPU 间的激活和梯度传输
   - 不同配置的优化

4. **混合精度训练何时必要？**
   - 参数量超过 10B 时
   - 内存受限情况
   - 推理环节

- 遇到过训练不稳定的情况吗，怎么解决的？
- 如何优化通信开销？
