## 二、核心方法（终端纯文本公式）

### 整体框架
针对每个 query `q_t`，用更紧凑的表示型 KV 替换原始 KV：
```
o*_t = Σ_{c∈C} [ gᶜ_t · Attn(q_t, K̃ᶜ_t, Ṽᶜ_t) ],   C = {cmp, slc, win}
```
`gᶜ_t ∈ [0,1]` 是门控得分（MLP + sigmoid）。通过 N_t ≪ t 维持高稀疏率。

### 三个分支
1. **Token 压缩 (cmp)**：把连续块（块长 l、步幅 d，通常 d<l 有重叠）经带块内位置编码的可学习 MLP `φ` 压成单个代表 token → 捕捉粗粒度全局语义。
2. **Token 选择 (slc)**：
   - 分块选择（连续块），动机=GPU 对连续访问吞吐高 + 注意力分数本身空间连续。
   - 重要性分数**复用压缩分支的注意力中间结果**算出（公式 8/9），几乎零额外开销。
   - **GQA/MQA 组内跨头共享选择**（公式 10）：同组所有头选同一批块，才能真正减少解码 KV 加载。
   - top-n 块选择（公式 11/12）。
3. **滑动窗口 (win)**：专门分支处理局部上下文，防止局部模式"抄近路"主导学习；三分支各用独立 KV，避免梯度干扰。

### 硬件 kernel 三原则（Triton）
- 以组为中心加载：一次把同 GQA 组所有头的 query + 共享稀疏块索引载入 SRAM。
- 共享 KV 获取：内层循环顺序加载连续 KV 块。
- 网格外层循环：各 query 块内层循环长度≈恒定（∝n），负载在 SM 间均衡。

## 三、对后训练工程师的参考价值（重点）

> 本论文虽属架构论文，但有以下几处对 post-training 直接相关，特此标注。

### 1. ⭐ R1 蒸馏 + 长 CoT SFT 的可复用 recipe（4.3 节 + Table 3）
- **工程判断**：作者明确指出"RL 在较小规模模型上效果有限"，故对小模型用**从 DeepSeek-R1 的知识蒸馏**而非直接 RL 来激发推理能力。
- **SFT 配置**：10B token、32k 长度数学推理轨迹做监督微调。
- **评测协议**：AIME 24，temperature=0.7 / top-p=0.95 / **每题采样 16 取平均 (avg@16)**；设 8k & 16k 两种生成长度上限验证推理深度影响。
- **结果**：NSA-R vs Full-Attn-R = 0.121 vs 0.046 (8k)、0.146 vs 0.092 (16k)。→ 稀疏注意力不损伤、反而增强推理后训练。

### 2. ⭐ "原生可训练"对后训练范式的意义
- 2.2 节把**长上下文微调 + 强化学习**列为需要训练期稀疏支持的核心动机。
- 4.2 节关键局限说明：CoT 评测只能和 Full Attention 比，**因为 H2O/Quest/InfLLM 等仅推理稀疏方法不支持训练**。→ NSA 的价值正是让稀疏注意力能进入 SFT/RL 流水线，并保证训练-推理用同一套稀疏模式（on-policy RL 正确性前提）。

### 3. ⭐ RL rollout 吞吐的直接收益（第 5 节）
- 解码是内存带宽受限；NSA 解码 64k 达 11.6× 加速（Table 4）。RL 长 CoT rollout 正是大量长序列解码 → 直接提升采样吞吐。
- 训练期 64k 前向 9.0×、反向 6.0× → 长上下文 SFT/RL 训练本身也更快。

### 4. MoE + 稀疏注意力训练系统坑（6.1 节）
- 放弃 ClusterKV 的原因之一：聚类负载不均会与 **MoE 专家并行(EP)组执行时间倾斜**叠加，造成持续负载不均。→ MoE 后训练系统优化时需注意此交互效应。

## 四、与 MLA 的关系（讨论记录）

- **是否可结合**：原理正交可叠加——MLA 压"每个 token 的 KV 大小"（低秩 latent），NSA 压"参与注意力的 token 数量"（块稀疏）。最优方案很可能是二者叠加，而非二选一。截至本文，无公开的 NSA+MLA 联合实现。
- **协同点**：MLA 的 KV 是所有头共享的一份 latent，天然满足 NSA "组内一致选择" 的诉求，比 GQA 更契合。
- **摩擦点**：① NSA 选择分支需显式算 q-k 分数，与 MLA 解码期"矩阵吸收"优化冲突；② 两套 RoPE 处理（MLA 解耦 RoPE vs NSA 块内位置编码）需调和；③ 两者各有定制 kernel，合并需重写。
- **谁更快**：分阶段看。超长序列(64k+)解码 NSA 加速天花板更高（优势随长度放大；MLA 是固定倍数压缩）；MLA 砍带宽不砍 FLOPs，NSA 两者都砍。但 NSA 加速比是 vs Full Attention 测的，不能直接等同于 vs MLA。

## 五、关键洞察与可借鉴点

1. **稀疏要"原生"才有意义**：事后(post-hoc)施加稀疏会让模型偏离预训练轨迹、损伤检索头（top 20% 注意力只覆盖 70% 分数）。
2. **理论稀疏 ≠ 实际加速**："高效推理的假象"——很多方法阶段受限（只优化 prefill 或只优化 decode）或与 GQA 不兼容（各头选各的 → KV 访问退化为并集）。
3. **分块是硬件友好与分数分布的双重选择**：注意力分数空间连续（Fig 8 可视化呈块状聚集），分块既贴合 GPU 连续访问又贴合分数分布。
4. **三分支独立 KV + 门控**：防止局部模式主导，对长 CoT（既要局部连贯又要长程检索）尤为重要。
5. **评测推理模型**：avg@16 + 多生成长度上限，是验证推理深度的标准做法。
