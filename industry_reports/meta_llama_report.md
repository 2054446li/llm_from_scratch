# Meta Llama 系列技术分析

> Llama 1 和 Llama 2 的架构设计、训练方法和开源影响。

---

## Llama 1 (2023 年 2 月)

### 核心创新

**为什么重要**：
- 证明了开源大模型的可行性
- 打破了 OpenAI 的垄断
- 激发了开源 LLM 社区

### 架构特点

| 组件 | 选择 |
|-----|------|
| 参数 | 7B, 13B, 33B, 65B |
| 上下文 | 2K |
| 位置编码 | RoPE |
| Attention | MHA (Multi-Head Attention) |
| 激活 | SwiGLU |
| 归一化 | RMSNorm |

### 训练数据

- **规模**：1.4T tokens
- **来源**：
  - 公开网页爬取
  - 学术论文
  - 代码仓库
  - 维基百科
  - 书籍

### 性能

- 7B：与 GPT-3.5 在某些任务相当
- 13B：接近 GPT-3（175B）的水平
- 开源社区非常活跃的微调版本（Alpaca、Vicuna 等）

---

## Llama 2 (2023 年 7 月)

### 主要改进

1. **上下文长度**：2K → 4K
2. **SFT + DPO 对齐**（而不是 RLHF）
3. **Chat 版本**：专门的对话优化
4. **更好的推理**
5. **安全性加强**

### 关键技术

#### 位置编码改进

- 从绝对 RoPE 到 GQA 的引入
- 长序列处理更好

#### GQA (Grouped-Query Attention)

```
Llama 1: 
- Query: 32 heads, head_dim=128
- Key:   32 heads, head_dim=128  
- Value: 32 heads, head_dim=128
KV 缓存：32 * 128 * seq_len

Llama 2:
- Query: 32 heads
- Key:   8 heads (共享)
- Value: 8 heads (共享)
KV 缓存：8 * 128 * seq_len （减少 4 倍）
```

**影响**：
- 推理速度提升
- 内存需求减少
- 性能基本保持

#### 对齐方法

**从 RLHF 改为 DPO**：
- 更简单的训练流程
- 移除奖励模型
- 直接用偏好数据优化

**质量**：
- Chat Llama 2 质量明显好于 Llama 1
- 可用性大幅提升

### 安全性设计

1. **数据过滤**
   - 移除不安全内容
   - 红队测试数据
   
2. **System Prompts**
   - 安全指导
   - 拒绝不当请求

3. **持续改进**
   - 用户反馈循环

## 架构对标

### Llama 1 vs Llama 2

| 特性 | Llama 1 | Llama 2 |
|-----|--------|--------|
| 上下文 | 2K | 4K |
| Attention | MHA | GQA |
| 对齐 | 无 | DPO |
| Chat 版 | 无 | 有 |
| 推理速度 | 标准 | 快 |

### Llama 2 vs GPT-3.5

- 通用能力：70-80% GPT-3.5 水平
- 中文能力：相对较弱（训练数据中中文较少）
- 代码能力：可以接受
- 成本：开源，可免费使用

---

## 生态与影响

### 开源生态

**微调方案**：
- Alpaca：最初的指令微调
- Vicuna：多轮对话优化
- Chinese-LLaMA：中文适配
- OpenLLaMA：完全开源复现

**推理框架**：
- llama.cpp：CPU 推理
- vLLM：高吞吐推理
- ollama：简化部署

### 学术贡献

1. 证明了 70B 规模的开源模型质量可接受
2. DPO 对齐方法的应用
3. 开源模型的可行性

### 商业影响

- Meta 从闭源回到开源
- 激励其他公司开源（Qwen、DeepSeek 等）
- 降低了 LLM 应用的门槛

---

## 关键学习点

1. **开源的力量**：社区的改进速度超过商业预期

2. **GQA 的有效性**：平衡性能和推理效率的好方案

3. **对齐的多种方式**：DPO 可以替代 RLHF

4. **安全性需要系统设计**：不是事后思考

5. **模型大小的递减收益**：7B vs 70B 的质量差异不如想象大

---

## 对比总结

**为什么 Llama 重要**：
- ✅ 开源性：激励开源社区
- ✅ 质量：足够好用
- ✅ 效率：推理优化
- ✓ 缺陷：中文能力一般
