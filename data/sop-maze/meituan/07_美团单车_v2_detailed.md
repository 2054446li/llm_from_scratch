## Objective

本SOP旨在规范美团单车共享出行服务的运营流程，确保：

1. **用车便捷**：扫码即用，快速开锁，提升出行效率
2. **计费透明**：清晰的价格体系，实时费用展示
3. **规范运营**：引导用户规范停车，维护城市秩序
4. **服务保障**：完善的故障报修、押金管理、客服支持体系

## Standard Operating Procedures

### 1. 扫码开锁

#### 1.1 开锁方式

##### 1.1.1 开锁方式对比

| 方式 | 操作步骤 | 适用场景 | 成功率 |
|------|----------|----------|--------|
| 扫码开锁 | 美团APP/微信扫码 → 车辆检查 → 确认开锁 | 标准流程 | >98% |
| 输入编码 | 手动输入车身编码 → 车辆检查 → 确认开锁 | 二维码损坏时 | >95% |
| NFC开锁 | 手机NFC靠近车锁 → 自动识别 → 开锁 | 支持NFC功能手机 | >99% |
| 蓝牙开锁 | APP蓝牙连接 → 自动识别附近车辆 → 开锁 | 信号不佳区域 | >97% |

##### 1.1.2 开锁前检查流程

```
用户扫码 ──▶ 车辆状态检查 ──▶ 信用分核验 ──▶ 服务区核验 ──▶ 开锁成功
    │              │              │              │
    ▼              ▼              ▼              ▼
  启动扫码       检查项目：      信用要求：      位置判断：
  识别车辆       - 二维码完好    - 信用分 ≥ 550   - 在运营区内
                 - 车胎有气      - 无欠费记录     - 不在禁停区
                 - 刹车正常      - 无违规记录     
                 - 车座完好
                 - 链条正常
```

**【KCP】开锁前检查关键控制点**：
- 车辆必须在运营区内（GPS定位校验）
- 用户信用分≥550分且无欠费记录
- 车辆状态正常（非故障、低电量电单车）

#### 1.2 开锁失败处理

##### 1.2.1 失败原因与解决方案

| 失败原因 | 提示信息 | 解决方案 | 系统处理 |
|----------|----------|----------|----------|
| 车辆故障 | "该车辆暂时无法使用" | 换一辆车，或报修 | 标记车辆待维修 |
| 信号问题 | "网络异常，请重试" | 检查网络，稍后重试 | 记录失败日志 |
| 信用不足 | "信用分不足，无法用车" | 充值押金或提升信用 | 引导信用提升 |
| 欠费未缴 | "您有未支付订单" | 结清欠费后使用 | 跳转支付页面 |
| 运营区外 | "该车辆不在运营区内" | 前往运营区内用车 | 显示最近运营区 |
| 车辆被预约 | "该车辆已被预约" | 选择其他车辆 | 显示附近可用车 |

**【话术】开锁失败引导话术**：

```
系统："该车辆暂时无法使用，可能原因：车辆故障、电量不足或正在维修"
用户："那怎么办"
系统："已为您推荐附近3辆可用车辆，距离您分别为50米、80米、120米，是否需要导航前往？"
```

### 3. 关锁结账

#### 3.1 关锁流程

##### 3.1.1 标准关锁流程

```
到达目的地 ──▶ 寻找停车点 ──▶ 规范停放 ──▶ 手动关锁 ──▶ 听到提示音 ──▶ APP确认
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
  查看APP        显示附近P点     车头朝向一致    拉下车锁       显示结算页
  停车点地图     导航前往        不阻碍通行      听到提示音     费用明细
```

##### 3.1.2 停车规范要求

| 要求 | 说明 | 违规后果 |
|------|------|----------|
| 指定停车点（P点） | 必须在APP显示的P点停车 | 收取调度费10-20元 |
| 整齐摆放 | 车头朝向一致，不阻碍通行 | 信用分扣减 |
| 禁止区域 | 小区内部、楼道、地下等禁止停车 | 收取管理费+信用扣减 |
| 禁停区 | 明确标识的禁停区域 | 高额调度费20-50元 |

**【话术】停车引导话术**：

```
系统："您当前位置不在指定停车点，附近最近的P点距离您50米，是否需要导航前往？"
用户："我就停这儿吧"
系统："非P点停车将产生10元调度费，且可能影响您的信用分。建议您前往P点停车，可避免额外费用"
```

#### 3.2 关锁确认

##### 3.2.1 关锁确认步骤

| 步骤 | 操作 | 确认方式 | 异常处理 |
|------|------|----------|----------|
| 1 | 手动拉下车锁 | 听到"关锁成功"提示音 | 无提示音时重试 |
| 2 | 查看APP状态 | 显示"骑行结束" | 显示未结束时联系客服 |
| 3 | 确认费用 | 查看结算金额 | 费用异常时申诉 |
| 4 | 支付费用 | 自动扣款或手动支付 | 余额不足时充值 |

##### 3.2.2 关锁异常处理

| 异常情况 | 处理方式 | 客服介入条件 |
|----------|----------|--------------|
| 关锁无提示音 | 等待10秒后重试，或联系客服 | 重试3次无效 |
| APP显示未关锁 | 检查车锁是否完全闭合，拍照留证 | 5分钟后仍显示未关锁 |
| 费用异常 | 在APP内申诉，或联系客服 | 费用差异>5元 |
| 重复扣费 | 提交申诉，提供支付凭证 | 确认重复扣费后24小时内退款 |

### 5. 违规停车处理
