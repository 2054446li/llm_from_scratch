## Objective

本SOP旨在规范美团众包骑手的运营流程，确保：

1. **准入合规**：建立标准化的骑手准入审核机制，保障配送服务质量
2. **配送安全**：强化安全培训和规范，降低配送风险
3. **收入保障**：建立透明的收入结算和等级激励体系
4. **权益保护**：提供申诉渠道，保障骑手合法权益
5. **服务品质**：确保骑手-商家-用户三方协同，提升配送体验

## Standard Operating Procedures

### 1. 注册认证

#### 1.1 注册申请

##### 1.1.1 准入条件

| 条件项 | 要求 | 说明 |
|--------|------|------|
| 年龄 | 18-55周岁 | 身体健康，能胜任配送工作 |
| 身份证 | 有效二代身份证 | 实名认证，人证一致 |
| 健康证 | 有效期内健康证 | 餐饮配送必备，1年有效 |
| 手机 | 智能手机 | 能安装众包APP，网络畅通 |
| 交通工具 | 电动车/摩托车/自行车 | 符合当地交通法规 |
| 装备 | 保温箱、头盔等 | 平台可租赁或自购 |

##### 1.1.2 注册流程

```
下载众包APP ──▶ 手机号注册 ──▶ 实名认证 ──▶ 上传证件 ──▶ 人脸识别 ──▶ 提交审核
      │            │              │              │              │              │
      ▼            ▼              ▼              ▼              ▼              ▼
   iOS/Android   短信验证       身份证正      身份证/      活体检测       等待1-3
   应用商店                       反面拍照      健康证等                      工作日
```

**【KCP】注册认证关键控制点**：
- 身份证必须在有效期内，且为本人持有
- 人脸识别必须通过活体检测，确保人证一致
- 健康证必须在有效期内，且为正规医疗机构出具
- 有犯罪记录或交通严重违法记录者不予通过

**【话术】注册咨询标准话术**：
```
用户："我想当美团骑手，需要什么条件？"
客服："您好，成为众包骑手需要：1）18-55周岁，身体健康；2）有效身份证；3）健康证（可在入职后补办）；4）智能手机；5）电动车或自行车。注册审核通常1-3个工作日完成。"
```

#### 1.2 资质审核

##### 1.2.1 审核流程

```
资料提交 ──▶ 系统自动初审 ──▶ 人工复核 ──▶ 背景核查 ──▶ 审核结果通知 ──▶ 开通账号
    │              │              │            │              │              │
    ▼              ▼              ▼            ▼              ▼              ▼
骑手上传      OCR识别+      审核员核查      公安接口     短信+APP       可接单
证件照片      规则校验      信息真实性      验证背景       推送通知       开始配送
```

##### 1.2.2 审核标准

| 审核项 | 通过标准 | 常见驳回原因 |
|--------|----------|--------------|
| 身份证 | 有效期内，人证一致 | 过期、非本人、照片模糊 |
| 健康证 | 有效期内，正规机构 | 过期、伪造、机构不认可 |
| 人脸识别 | 活体通过，人证匹配 | 非本人、光线不足、动作不符 |
| 背景核查 | 无犯罪/严重交通违法记录 | 有犯罪记录、醉驾记录等 |

**【Rule】资质拦截规则**：
- **黑名单拦截**：在平台黑名单或有严重违规记录，系统自动拒绝"该身份信息存在违规记录，暂不支持注册"
- **年龄拦截**：未满18周岁或超过55周岁，提示"年龄不符合要求"
- **健康证拦截**：健康证过期或无效，提示"请上传有效期内的健康证"
- **背景拦截**：有犯罪记录或严重交通违法，提示"背景审核未通过"

### 3. 接单配送

#### 3.1 接单流程

##### 3.1.1 接单模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 系统派单 | 系统自动分配订单 | 新手期、专送骑手 |
| 抢单模式 | 骑手主动抢单 | 众包骑手主要模式 |
| 预约单 | 用户预约时间配送 | 提前规划路线 |
| 帮送单 | 非餐品配送 | 文件、物品等 |

##### 3.1.2 标准配送流程

```
上线接单 ──▶ 收到派单/抢单 ──▶ 确认接单 ──▶ 前往商家 ──▶ 到店取餐 ──▶ 核对商品 ──▶ 配送用户 ──▶ 送达确认
    │              │              │            │            │            │            │            │
    ▼              ▼              ▼            ▼            ▼            ▼            ▼            ▼
 设置工作      系统推送/      倒计时       导航前往      扫码/报号      核对数量      导航前往      用户确认
 状态在线      大厅抢单       确认接单      商家位置      确认取餐      检查包装      用户地址      订单完成
```

**【KCP】接单关键控制点**：
- 接单后必须在规定时间内到店取餐
- 取餐时必须核对商品与订单一致
- 配送途中必须保证餐品安全和温度
- 送达时必须确认用户身份或按用户要求放置

##### 3.1.3 时效标准

| 环节 | 时效要求 | 超时处理 |
|------|----------|----------|
| 接单确认 | 派单后30秒内 | 自动转派 |
| 到店时间 | 接单后规定时间 | 超时扣款/扣分 |
| 取餐等待 | 商家出餐时间 | 超时可申诉 |
| 配送时间 | 按距离计算 | 超时扣款/扣分 |
| 送达确认 | 送达后即时 | 影响收入结算 |

**【话术】配送环节标准话术**：
```
到店取餐："美团配送，来取123456号订单" 商家："好的，稍等... 餐齐了，请核对"
联系用户："您好，美团外卖，您的订单已送达，请出来取一下"
无法联系："您好，美团外卖，您的订单已送达指定地点，请及时取餐"
```

#### 3.2 配送异常处理

##### 3.2.1 异常类型与处理

| 异常类型 | 处理方式 | 责任判定 | 申诉可能 |
|----------|----------|----------|----------|
| 商家出餐慢 | 等待/报备/取消 | 商家责任 | 可申诉免责 |
| 用户地址错误 | 联系用户/按新地址配送 | 用户责任 | 可申诉加钱 |
| 用户不接电话 | 等待5分钟/报备/放置 | 用户责任 | 可申诉免责 |
| 餐品洒漏 | 拍照报备/协商处理 | 视情况 | 可申诉 |
| 交通事故 | 报备/转单/取消 | 骑手责任 | 视情况 |
| 恶劣天气 | 系统调整时效 | 不可抗力 | 自动免责 |

**【Rule】配送拦截规则**：
- **疲劳拦截**：连续接单超过4小时，系统提示休息"您已连续配送4小时，建议休息15分钟"
- **超时预警**：配送即将超时，系统提示"订单即将超时，请加快配送"
- **异常订单拦截**：用户投诉或差评过多，该用户订单提示"该用户近期有异常记录，请谨慎接单"
- **区域限制**：未开通区域无法接单"该区域暂未开通众包服务"

### 4. 收入结算

#### 4.1 收入构成

##### 4.1.1 收入类型

| 收入类型 | 计算方式 | 说明 |
|----------|----------|------|
| 基础配送费 | 按距离/时段计算 | 基础收入，每单3-15元不等 |
| 距离补贴 | 超距离加价 | 远距离订单额外补贴 |
| 时段补贴 | 高峰/深夜加价 | 午晚高峰、深夜时段额外补贴 |
| 重量补贴 | 超重加价 | 超重订单额外补贴 |
| 天气补贴 | 恶劣天气加价 | 雨雪天气额外补贴 |
| 奖励活动 | 完成活动任务 | 冲单奖、时段奖等 |
| 差评扣款 | 按差评数量扣减 | 服务质量扣款 |
| 超时扣款 | 按超时程度扣减 | 配送时效扣款 |

##### 4.1.2 收入计算示例

```
订单收入构成：
├── 基础配送费：¥6.00（3公里内）
├── 高峰时段补贴：¥2.00（12:00-13:30）
├── 距离补贴：¥1.50（超出3公里）
├── 重量补贴：¥0（未超重）
├── 奖励活动：¥0（未参与活动）
├── 扣款项：
│   ├── 超时扣款：-¥1.00（超时5分钟）
│   └── 其他扣款：¥0
└── 本单实际收入：¥8.50
```

#### 4.2 结算提现

##### 4.2.1 结算周期

| 结算类型 | 周期 | 到账方式 | 说明 |
|----------|------|----------|------|
| 日结算 | 当日收入次日可提 | 手动提现 | 众包标准模式 |
| 周结算 | 每周固定日期 | 自动/手动 | 部分城市支持 |
| 实时提现 | 即时到账 | 手动提现 | 需手续费 |

##### 4.2.2 提现流程

```
查看收入 ──▶ 申请提现 ──▶ 选择到账方式 ──▶ 确认提现 ──▶ 到账通知
    │            │              │              │              │
    ▼            ▼              ▼              ▼              ▼
 收入明细      输入金额       银行卡/       验证身份      短信/APP
 查看确认      确认申请        支付宝        确认提现       通知到账
```

**【KCP】结算关键控制点**：
- 提现前必须完成实名认证和银行卡绑定
- 提现金额必须大于最低提现门槛（通常10-100元）
- 有违规处罚或争议订单时，相应金额可能冻结
- 提现到账时间根据银行不同有差异

**【话术】收入咨询话术**：
```
骑手："昨天的钱什么时候能提现？"
系统提示："您昨日收入¥256.50，已计入可提现余额。当前可提现金额¥512.30，最小提现金额¥10元。"
```

### 6. 申诉处理

#### 6.1 申诉类型

##### 6.1.1 可申诉场景

| 申诉类型 | 适用场景 | 举证要求 | 处理时效 |
|----------|----------|----------|----------|

##### 6.1.2 申诉流程

```
发现问题 ──▶ 收集证据 ──▶ 提交申诉 ──▶ 平台审核 ──▶ 结果通知 ──▶ 执行处理
    │            │            │            │            │            │
    ▼            ▼            ▼            ▼            ▼            ▼
 订单异常      截图/录音     APP内提交    人工审核     通过/驳回    退款/撤销
 或处罚通知    订单信息      申诉材料     调查核实     通知骑手      处罚
```

**【KCP】申诉关键控制点**：
- 申诉必须在规定时间内提交（通常7天内）
- 必须提供充分证据支持申诉理由
- 同一问题只能申诉一次，结果不可更改
- 恶意申诉会影响骑手信誉

#### 6.2 申诉处理

##### 6.2.1 处理标准

| 申诉结果 | 处理方式 | 时效 |
|----------|----------|------|
| 申诉通过 | 撤销处罚/返还扣款/删除差评 | 即时生效 |
| 申诉驳回 | 维持原判，说明原因 | 通知骑手 |
| 部分通过 | 减轻处罚/部分返还 | 即时生效 |

**【话术】申诉处理话术**：
```
系统通知："您的申诉【差评申诉-订单#123456】已审核通过。经核实，该差评因用户原因造成，已为您删除差评记录，恢复相应积分。感谢您的耐心配合！"
```
