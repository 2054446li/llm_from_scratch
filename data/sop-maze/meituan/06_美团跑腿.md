## Objective

本SOP旨在规范美团跑腿同城即时配送服务的运营流程，确保：

1. **响应速度**：用户下单后快速匹配骑手，缩短等待时间
2. **服务品质**：保障物品安全、准时送达
3. **服务多样**：支持帮买、帮送、帮取、代办等多种服务场景
4. **风险管控**：完善物品损坏/丢失处理、安全保障机制

## Standard Operating Procedures

### 1. 下单发单

#### 1.1 服务类型

| 服务类型 | 说明 | 典型场景 |
|----------|------|----------|
| 帮买 | 骑手代用户购买商品 | 代购餐饮、超市商品、药品等 |
| 帮送 | 骑手将物品从A地送至B地 | 文件传递、礼品配送、商务急件 |
| 帮取 | 骑手代为取回物品 | 取快递、取钥匙、取证件 |
| 代办 | 骑手代为办理简单事务 | 排队、缴费、简单手续 [需内部资料确认] |

#### 1.2 下单流程

```
选择服务类型 ──▶ 填写取/送地址 ──▶ 描述物品/需求 ──▶ 选择配送时效 ──▶ 确认支付
```

#### 1.3 订单信息填写规范

| 字段 | 必填性 | 说明 |
|------|--------|------|
| 取货地址 | 必填 | 精确到门牌号，含联系人及电话 |
| 送货地址 | 必填 | 精确到门牌号，含联系人及电话 |
| 物品信息 | 必填 | 类型、数量、预估重量/体积 |
| 物品价值 | 建议填写 | 用于保价和理赔参考 |
| 备注说明 | 选填 | 特殊要求、取货码、外观要求等 |
| 期望时效 | 必填 | 普通/加急/专人直送 [需内部资料确认] |

#### 1.4 费用构成 [需内部资料确认]

| 费用项目 | 说明 |
|----------|------|
| 基础配送费 | 根据距离、重量、时段计算 |
| 重量附加费 | 超重部分按阶梯计费 |
| 时段加价 | 高峰期、恶劣天气加价 |
| 加急服务费 | 优先配送、专人直送 |
| 保价费 | 按声明价值比例收取 |

### 2. 骑手接单

#### 2.1 接单模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 系统派单 | 算法根据位置、负载自动分配 | 标准订单 |
| 骑手抢单 | 骑手主动选择订单 | 众包模式 |
| 指派骑手 | 平台指定优质骑手 | 高价值/特殊订单 |

#### 2.2 接单时效要求 [需内部资料确认]

| 服务类型 | 接单响应时限 | 到店/取货时限 |
|----------|--------------|---------------|
| 普通帮买 | 5分钟内 | 接单后30分钟内 |
| 普通帮送 | 5分钟内 | 接单后20分钟内 |
| 加急服务 | 3分钟内 | 接单后15分钟内 |
| 专人直送 | 即时响应 | 立即取货 |

#### 2.3 骑手资质要求 [需内部资料确认]

- 实名认证
- 健康证明（餐饮配送）
- 无犯罪记录
- 培训考核合格
- 装备要求（保温箱、头盔等）

### 3. 物品取送

#### 3.1 取货流程

```
到达取货点 ──▶ 联系发货人 ──▶ 核验物品 ──▶ 拍照留证 ──▶ 确认取货
```

#### 3.2 物品核验标准

| 检查项 | 操作要求 |
|--------|----------|
| 外观检查 | 包装完好、无破损、无渗漏 |
| 数量核对 | 与订单描述一致 |
| 禁限品检查 | 拒绝承接违禁品 [需内部资料确认] |
| 特殊要求确认 | 温度要求、易碎标识等 |

#### 3.3 配送途中规范

| 环节 | 要求 |
|------|------|
| 路线规划 | 按系统推荐路线，特殊情况可调整 |
| 时效监控 | 实时更新配送进度 |
| 异常上报 | 交通堵塞、车辆故障等及时上报 |
| 物品保管 | 妥善放置，防止损坏、丢失 |

#### 3.4 送达流程

```
到达送货点 ──▶ 联系收货人 ──▶ 核验身份 ──▶ 交付物品 ──▶ 确认签收 ──▶ 拍照完成
```

### 4. 帮买帮送

#### 4.1 帮买服务流程

| 步骤 | 骑手操作 | 用户配合 |
|------|----------|----------|
| 1 | 接单后联系用户确认需求 | 保持电话畅通 |
| 2 | 前往指定商家购买 | 可指定商家或让骑手推荐 |
| 3 | 购买时拍照确认商品/价格 | 及时确认或调整 |
| 4 | 垫付或用户预付 | 确认支付方式 |
| 5 | 配送至收货地址 | 准备接收 |

#### 4.2 帮买费用处理 [需内部资料确认]

- **商品费用**：骑手垫付后凭小票报销，或用户提前预付
- **价格差异**：实际价格与预估差异±10%内正常结算，超出需确认
- **小票要求**：必须提供正规购物小票

#### 4.3 帮送服务要点

| 场景 | 特殊要求 |
|------|----------|
| 文件急送 | 优先配送，确保准时 |
| 餐饮配送 | 保温/保冷，注意时效 |
| 生鲜配送 | 冷链运输，优先处理 |
| 贵重物品 | 保价配送，当面签收 |

### 5. 物品损坏/丢失处理

#### 5.1 损坏/丢失场景

| 场景 | 责任判定 | 处理原则 |
|------|----------|----------|
| 取货时已损坏 | 发货方责任 | 拍照留证，联系发货人确认 |
| 配送途中损坏 | 骑手/平台责任 | 按保价或实际价值赔偿 |
| 配送途中丢失 | 骑手/平台责任 | 全额赔偿 |
| 收货后发现问题 | 需举证区分责任 | 根据证据判定 |

#### 5.2 理赔流程

```
用户申请理赔 ──▶ 提交证据（照片、视频、价值证明）──▶ 平台审核 ──▶ 责任判定 ──▶ 赔付/拒赔
```

#### 5.3 赔付标准 [需内部资料确认]

| 情况 | 赔付标准 |
|------|----------|
| 已保价物品 | 按保价金额赔付，最高不超过声明价值 |
| 未保价物品 | 按实际损失赔付，有上限 [需内部资料确认] |
| 部分损坏 | 按损坏比例赔付或协商修复费用 |
| 完全丢失 | 全额赔付（受保价/赔付上限限制） |

#### 5.4 免责情形 [需内部资料确认]

- 不可抗力（自然灾害、政府行为等）
- 物品本身质量问题
- 用户提供的地址/联系方式错误
- 用户指定的特殊配送方式导致

### 6. 加急服务

#### 6.1 加急服务类型 [需内部资料确认]

| 类型 | 时效承诺 | 服务特点 |
|------|----------|----------|
| 普通加急 | 比标准时效快30% | 优先派单、优先配送 |
| 极速达 | 1小时内送达 | 专人专送，不拼单 |
| 专人直送 | 取货后直接送达，不绕路 | 一对一服务，价格较高 |

#### 6.2 加急服务保障

- **时效承诺**：超时赔付或免单 [需内部资料确认]
- **专属客服**：加急订单专属客服通道
- **实时追踪**：更频繁的配送进度更新

|----------|------|
| 订单确认 | 订单号、骑手信息（姓名、电话）、预计送达时间、实时追踪链接 |
