## Objective

本SOP旨在规范美团丽人（美容美发美甲等本地生活服务）业务的全流程运营，确保：

1. **入驻合规**：建立标准化的丽人行业商户准入审核机制，保障平台服务品质
2. **服务透明**：确保团购套餐内容真实、价格透明、使用规则清晰
3. **预约顺畅**：提供便捷的在线预约系统，减少用户等待时间
4. **核销高效**：简化到店核销流程，提升用户消费体验
5. **售后完善**：建立完善的退款、投诉、评价管理体系，保障用户权益
6. **经营赋能**：帮助丽人商户提升线上运营能力，实现客流增长

## Standard Operating Procedures

### 1. 商户入驻

#### 1.1 入驻申请

##### 1.1.1 入驻类型选择

| 入驻类型 | 适用对象 | 资质要求 | 费用标准 |
|----------|----------|----------|----------|
| 美容护肤 | 美容院、皮肤管理中心 | 营业执照+卫生许可证 | 抽佣8-15% |
| 美发造型 | 理发店、造型工作室 | 营业执照+卫生许可证 | 抽佣8-12% |
| 美甲美睫 | 美甲店、美睫工作室 | 营业执照+卫生许可证 | 抽佣10-15% |
| 按摩SPA | 按摩店、SPA会所 | 营业执照+卫生许可证+特种行业许可 | 抽佣10-18% |
| 纹绣纹身 | 纹绣工作室、纹身店 | 营业执照+卫生许可证+医疗美容资质（如涉及） | 抽佣12-18% |

##### 1.1.2 入驻申请流程

```
下载开店宝APP ──▶ 注册账号 ──▶ 选择经营类目 ──▶ 填写店铺信息 ──▶ 上传资质证照 ──▶ 提交审核
       │            │              │                │                │              │
       ▼            ▼              ▼                ▼                ▼              ▼
  iOS/Android    手机号验证    美容/美发/       店名/地址/       营业执照/       等待1-3
  应用商店                      美甲等分类       联系人/营业      卫生许可证/      工作日
                                                 时间/简介        环境照片
```

**【KCP】入驻申请关键控制点**：
- 营业执照必须在有效期内，经营范围需包含美容美发美甲等相关内容
- 卫生许可证必须与实际经营项目一致，且在有效期内
- 店铺地址必须与证照地址一致（或提供合法租赁证明）
- 店铺环境照片需真实反映经营场所，包括门头、大厅、操作间等
- 如涉及医疗美容项目（如注射、激光等），需提供医疗机构执业许可证

**【多方对话】入驻咨询场景**：
```
商户："我想在美团丽人开店，需要什么条件？"
平台客服："您好，丽人行业开店需要准备以下材料：
          1）营业执照原件照片；
          2）卫生许可证；
          3）法人身份证正反面；
          4）店铺门头照、大厅环境照、操作间照片；
          5）从业人员健康证（至少1人）。
          审核通常需要1-3个工作日。"

商户："我的店是美甲美睫工作室，在居民楼里可以吗？"
平台客服："居民楼内开店需要提供合法的商用或商住两用房产证明，
          且需符合当地对居民楼内经营的相关规定。建议您先确认房屋性质是否符合要求。"
```

#### 1.2 资质审核

##### 1.2.1 审核流程

```
资料提交 ──▶ 系统自动初审 ──▶ 人工复核 ──▶ 资质核验 ──▶ 审核结果通知 ──▶ 签约入驻
    │              │              │            │              │              │
    ▼              ▼              ▼            ▼              ▼              ▼
商户上传      OCR识别+      审核员核查      第三方接口     短信+APP       电子合同
资质照片      规则校验      信息一致性      验证真伪       推送通知       在线签署
```

##### 1.2.2 审核标准

| 审核项 | 通过标准 | 常见驳回原因 |
|--------|----------|--------------|
| 营业执照 | 有效期内，经营范围匹配 | 过期、经营范围不符、伪造 |
| 卫生许可证 | 有效期内，许可项目匹配 | 过期、许可项目缺失、地址不符 |
| 法人身份证 | 清晰可辨，与营业执照一致 | 模糊、过期、信息不一致 |
| 店铺照片 | 真实环境，与证照地址一致 | 网图、与地址不符、环境不达标 |
| 健康证 | 从业人员健康证在有效期内 | 过期、人数不足、信息模糊 |

**【多方对话】审核结果通知场景**：
```

             请更新证件后重新提交。"

平台（短信）："【美团丽人】您的入驻申请需要补充材料，请上传店内消毒设备照片和
             从业人员健康证照片。"
```

**【KCP】服务发布关键控制点**：
- 服务图片必须为真实案例或环境实拍，禁止使用网图或过度PS的效果图
- 服务内容描述必须真实准确，不得虚假宣传或夸大效果
- 价格设置必须合理，门市价应为实际参考价，禁止虚高
- 使用规则必须清晰完整，包括预约要求、适用人群、注意事项等
- 涉及特殊功效（如医疗效果）需有相关资质证明

### 3. 预约管理

#### 3.1 在线预约流程

##### 3.1.1 用户预约操作

| 步骤 | 操作内容 | 系统处理 |
|------|----------|----------|
| 1 | 选择服务，点击「立即预约」 | 显示可预约日期和时段 |
| 2 | 选择日期、时间 | 实时查询技师和房间库存 |
| 3 | 选择技师（可选） | 显示技师排班和可约状态 |
| 4 | 填写联系人信息 | 验证手机号 |
| 5 | 确认预约信息 | 显示预约详情和注意事项 |
| 6 | 提交预约 | 发送预约请求给商户 |

##### 3.1.2 预约状态流转

```
用户提交预约
      ↓
商户收到预约通知（短信+APP推送）
      ↓
┌─────────────────────────────────────────┐
│  商户确认 → 预约成功，通知用户          │
│  商户拒绝 → 说明原因，推荐其他时段      │
│  超时未响应（30分钟）→ 系统自动取消     │
└─────────────────────────────────────────┘
```

**【KCP】预约管理关键控制点**：
- 商户必须在30分钟内响应预约请求，超时自动取消
- 预约时段设置需考虑服务时长和技师排班，避免重叠
- 高峰期（周末/节假日）建议开启提前预约限制
- 用户取消预约需提前规定时间（通常2-4小时），否则可能产生违约金

**【多方对话】预约确认场景**：
```
平台（短信）："【美团丽人】您预约了花漾美甲的日式美甲服务，时间：8月5日14:00，
             地址：朝阳区XX路XX号。请准时到店，如需取消请提前2小时联系。"

商户（致电用户）："您好，我是花漾美甲的客服，确认一下您明天下午2点的预约。
                  请问您有偏好的颜色或款式吗？我们可以提前准备色板。"
用户："我想做裸色的，简单一点的款式"
商户："好的，我们为您准备了最新的裸色系色板。明天见！"
```

### 4. 到店服务

#### 4.1 接待流程

##### 4.1.1 用户到店

| 步骤 | 操作内容 |
|------|----------|
| 1 | 用户到店，前台核对预约信息 |
| 2 | 确认服务项目和团购券状态 |
| 3 | 引导用户到休息区或操作间 |
| 4 | 技师进行需求沟通和服务确认 |
| 5 | 开始服务 |

##### 4.1.2 服务中沟通

```
服务前沟通：
├── 了解用户需求和期望
├── 说明服务流程和预计时长
├── 确认使用的产品和工具
└── 告知注意事项和可能的不适感

服务中沟通：
├── 询问舒适度，调整力度/温度
├── 介绍当前步骤和功效
└── 解答用户疑问

服务后沟通：
├── 展示服务效果
├── 告知护理注意事项
├── 推荐后续护理方案
└── 引导用户评价
```

**【多方对话】到店接待场景**：
```
前台："您好，欢迎光临花漾美甲。请问有预约吗？"
用户："有，我预约了下午2点的美甲"
前台："好的，请问您贵姓？我查一下... 是张小姐对吗？预约的是日式美甲128元套餐。"
用户："对的"
前台："好的，请先坐一下，我帮您确认团购券。李老师马上过来为您服务。"

技师："张小姐您好，我是李老师。您今天想做什么款式？"
用户："我想做裸色的，简单一点的"
技师："好的，我们这里有最新的裸色系，我给您看一下色板。
      您的指甲状态很好，建议可以做建构让甲型更饱满。"
```

##### 4.2.2 升单建议

### 5. 团购核销

#### 5.1 核销流程

##### 5.1.1 用户出示券码

| 步骤 | 操作内容 |
|------|----------|
| 1 | 服务完成后，前台告知用户可以核销团购券 |
| 2 | 用户打开美团APP，进入「我的」-「订单」 |
| 3 | 找到对应团购券，点击「出示券码」 |
| 4 | 向商户展示二维码或券号 |
| 5 | 商户扫码或输入密码完成核销 |

##### 5.1.2 商户核销操作

```
商户端核销流程：
1. 登录开店宝APP
2. 进入「验券」功能
3. 扫描用户出示的二维码
   或
   手动输入12位券码
4. 确认券信息（服务项目、有效期、使用限制）
5. 如有多张券，选择本次使用的数量
6. 点击「确认核销」
7. 打印小票或电子确认
```

**【KCP】团购核销关键控制点**：
- 核销前必须确认服务项目与券面一致
- 检查团购券是否在有效期内
- 确认是否满足使用条件（如新客专享、节假日限制等）
- 多张券核销时需与用户确认使用顺序
- 核销后不可撤销，请谨慎操作

**【多方对话】核销场景**：
```
前台："张小姐，服务完成了，您满意吗？"

前台："谢谢！那我来帮您核销团购券。请打开美团APP出示一下券码。"
用户：（出示券码）
前台：（扫码）"确认一下，核销的是花漾美甲128元日式美甲套餐一张，对吗？"
用户："对的"
前台：（点击确认）"好了，已核销成功。这是您的小票，欢迎下次光临！"
```

#### 5.2 核销异常处理

##### 5.2.1 常见异常及处理

| 异常情况 | 处理方式 |
|----------|----------|
| 券码无法识别 | 检查网络 → 手动输入券号 → 联系美团客服 |
| 券已过期 | 查看有效期 → 协商延期使用或引导重新购买 |
| 券已使用 | 查询核销记录 → 核实是否重复核销 |
| 服务内容与券不符 | 与用户协商补差价或更换服务项目 |
| 用户未购买团购 | 引导现场购买或按门市价结算 |
