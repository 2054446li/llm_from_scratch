## 业务概述

美团酒店旅游业务为用户提供酒店预订、民宿短租、景点门票、旅游套餐等服务，覆盖国内及海外目的地，满足用户商务出行、休闲旅游等住宿需求。

### 核心参与方

```
+-----------+      搜索/预订     +-----------+      确认/接待     +-----------+
|  消费者   | -----------------> |  美团平台  | -----------------> |  酒店/民宿  |
+-----------+                    +-----------+                    +-----------+
     ^                               |                                |
     |      入住完成/评价            |      结算                       | 提供服务
     |                               v                                v
     +-----------------------  交易系统  <------------------------  确认入住
```

## Objective

1. **预订体验目标**：提供便捷的搜索、比价、预订体验
2. **价格竞争力目标**：确保价格优势，提供最优价格保证
3. **入住顺畅目标**：减少到店无房、订单差错等问题
4. **服务保障目标**：7×24小时客服支持，及时解决预订问题

## Standard Operating Procedures

### 一、酒店搜索预订流程

#### 1.1 用户端操作流程

| 步骤 | 操作内容 | 注意事项 |
|------|----------|----------|
| 1 | 打开美团APP，进入「酒店/民宿」频道 | 自动定位或手动输入目的地 |
| 2 | 设置入住日期、离店日期、房间数、入住人数 | 注意节假日价格可能上涨 |
| 3 | 筛选条件（价格、星级、评分、设施等） | 可使用地图模式查看位置 |
| 4 | 浏览酒店列表，查看详情 | 查看真实用户评价、实拍图片 |
| 5 | 选择房型，查看退改政策 | 注意不同价格对应不同取消规则 |
| 6 | 填写入住人信息，提交订单 | 确保姓名与身份证一致 |
| 7 | 在线支付，完成预订 | 支持预付/到店付（视酒店政策） |

#### 1.2 预订确认流程

```
用户支付成功
      ↓
系统向酒店发送预订请求
      ↓
┌─────────────────────────────────────────┐
│  酒店确认有房 → 预订成功，发送确认短信  │
│  酒店满房/拒单 → 推荐替代酒店或全额退款 │
│  超时未确认 → 系统自动处理 `[需内部资料确认：超时时间]` │
└─────────────────────────────────────────┘
```

#### 1.3 预订类型 `[需内部资料确认：具体预订模式]`

| 预订类型 | 说明 | 特点 |
|----------|------|------|
| 预付订单 | 在线支付房费 | 价格优惠，保证有房 |
| 到店付订单 | 到店后支付 | 灵活取消，价格可能较高 |
| 担保订单 | 信用卡担保，到店付 | 部分高端酒店要求 |
| 会员专享价 | 美团会员专属价格 | 需登录会员账号 |
| 企业协议价 | 合作企业专属价格 | 需企业认证 |

### 二、入住流程

#### 2.1 到店入住

| 步骤 | 操作内容 | 所需材料 |
|------|----------|----------|
| 1 | 到达酒店前台 | 携带预订人身份证 |
| 2 | 出示预订信息 | 报预订人姓名/手机号，或出示美团订单 |
| 3 | 前台核实订单 | 酒店系统在美团商家版核实 |
| 4 | 身份登记 | 所有入住人身份证登记（公安要求） |
| 5 | 缴纳押金（如需） | 现金或刷卡预授权 |
| 6 | 领取房卡，入住 | 确认房间号、早餐时间、WiFi密码等 |

#### 2.2 入住异常处理

| 异常情况 | 处理流程 |
|----------|----------|
| 到店无房 | 联系美团客服 → 协调酒店解决 → 无法解决则升级房型或安排附近同等级酒店 |
| 房型不符 | 拍照留证 → 联系客服 → 要求按订单房型入住或退还差价 |
| 酒店拒接 | 核实拒接原因 → 全额退款 → 补偿用户损失 |
| 订单查询不到 | 提供订单号 → 客服核实 → 手工确认或重新下单 |

---

### 三、退房流程

#### 3.1 正常退房

```
1. 整理行李，检查房间
2. 到前台办理退房
3. 退还房卡
4. 前台查房（部分酒店免查房）
5. 退还押金
6. 开具发票（如需）
7. 离店
```

#### 3.2 延迟退房

| 场景 | 处理方式 |
|------|----------|
| 会员权益延迟 | 美团会员可享受免费延迟退房 `[需内部资料确认：具体权益]` |
| 付费延迟 | 与酒店协商，按小时或半天付费 |
| 未协商超时 | 可能产生额外房费 |

### 四、订单变更

#### 4.1 修改订单 `[需内部资料确认：修改规则]`

| 修改类型 | 操作方式 | 限制条件 |
|----------|----------|----------|
| 修改入住日期 | 申请改期，补/退差价 | 需酒店确认有房 |
| 修改房型 | 取消原订单，重新预订 | 视取消政策 |
| 修改入住人 | 联系客服修改 | 部分酒店不允许 |
| 增加房间数 | 追加预订 | 视酒店库存 |

#### 4.2 变更流程

```
用户申请变更
      ↓
系统检查变更可行性
      ↓
┌─────────────────────────────────────────┐
│  可直接变更 → 确认差价，完成修改        │
│  需酒店确认 → 发送变更请求，等待确认    │
│  不可变更 → 建议取消后重新预订          │
└─────────────────────────────────────────┘
```

### 五、取消与退款

#### 5.1 取消政策类型 `[需内部资料确认：具体取消规则]`

| 政策类型 | 说明 | 适用场景 |
|----------|------|----------|
| 免费取消 | 入住前可免费取消，全额退款 | 标准价格 |
| 限时免费取消 | 入住前X小时/天可免费取消 | 促销价格 |
| 不可取消 | 一旦预订，不可退款 | 特价房、预付价 |
| 有条件取消 | 取消收取首晚房费或一定比例 | 优惠价格 |

#### 5.2 取消流程

```
用户申请取消
      ↓
系统判断取消政策
      ↓
┌─────────────────────────────────────────┐
│  免费取消 → 立即取消，全额退款          │
│  扣款取消 → 显示扣款金额，确认后取消    │
│  不可取消 → 提示无法退款，特殊情况申诉  │
└─────────────────────────────────────────┘
      ↓
退款到账（1-15个工作日，视支付方式）
```

#### 5.3 退款时效

| 支付方式 | 退款时效 |
|----------|----------|
| 美团余额 | 即时到账 |
| 微信/支付宝 | 1-3个工作日 |
| 银行卡 | 3-15个工作日 |
| 信用卡 | 3-15个工作日 |

### 六、行程冲突处理

#### 6.1 用户行程变更

```
用户因行程变更无法入住
      ↓
┌─────────────────────────────────────────┐
│  方案1：申请改期（酒店同意情况下）      │
│  方案2：申请取消（按取消政策退款）      │
│  方案3：转让订单（部分情况允许）        │
│  方案4：特殊申诉（不可抗力证明）        │
└─────────────────────────────────────────┘
```

#### 6.2 不可抗力处理

| 场景 | 处理方式 |
|------|----------|
| 航班取消/延误 | 提供证明，申请免费取消/改期 |
| 自然灾害 | 启动应急机制，统一免费退改 |
| 疫情等突发情况 | 按政府政策执行退改方案 |

---

### 七、特价房规则

#### 7.1 特价房类型 `[需内部资料确认：具体产品定义]`

| 类型 | 特点 | 限制 |
|------|------|------|
| 今夜特价 | 当天剩余库存低价出售 | 仅限当天入住，不可取消 |
| 提前购 | 提前X天预订享优惠 | 不可取消或改期 |
| 连住优惠 | 连续入住多晚享折扣 | 提前离店不退差价 |
| 会员专享 | 会员专属特价 | 需会员身份 |
| 尾房清仓 | 当天剩余房间低价处理 | 房型随机，不可指定 |

#### 7.2 特价房注意事项

- 通常标注「不可取消」或「限时取消」
- 部分特价房不享受会员权益
- 发票可能按实际支付金额开具
- 早餐等附加服务可能不包含
