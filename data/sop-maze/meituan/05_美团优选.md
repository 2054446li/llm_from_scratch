## Objective

本SOP旨在规范美团优选社区团购业务的运营流程，确保：

1. **用户体验**：提供便捷、高效的社区团购购物体验
2. **履约质量**：保障"次日达"配送时效和商品品质
3. **团长服务**：建立标准化的团长管理和服务体系
4. **售后保障**：完善缺货、质量问题等售后处理机制

## Standard Operating Procedures

### 1. 下单流程

#### 1.1 用户端操作

| 步骤 | 操作内容 | 关键要点 |
|------|----------|----------|
| 1 | 打开美团APP/美团优选小程序 | 定位到所在社区 |
| 2 | 选择自提点（团长） | 查看距离、评分、营业状态 |
| 3 | 浏览商品并加入购物车 | 注意截单时间（通常22:00） |
| 4 | 确认订单并支付 | 支持多种支付方式 |
| 5 | 等待次日配送通知 | 接收取货提醒 |

#### 1.2 系统处理流程

```
用户下单 ──▶ 订单聚合 ──▶ 供应商接单 ──▶ 商品备货 ──▶ 物流揽收
```

**关键时效要求** [需内部资料确认]：
- 截单时间：每日22:00（部分区域可能不同）
- 订单确认：实时确认
- 支付时限：下单后30分钟内

### 2. 次日达配送

#### 2.1 配送流程

| 环节 | 时间节点 | 操作内容 |
|------|----------|----------|
| 供应商发货 | 00:00-06:00 | 商品打包、贴标 |
| 中心仓收货 | 06:00-08:00 | 质检、分拣 |
| 网格仓配送 | 08:00-14:00 | 按线路配送至各团长点 |
| 团长签收 | 14:00-16:00 | 清点、入库、通知用户 |

#### 2.2 配送时效标准 [需内部资料确认]

- **标准时效**：当日22:00前下单，次日16:00前送达
- **特殊商品**：生鲜类优先配送，确保新鲜度
- **延迟处理**：超时配送自动触发补偿机制

### 3. 自提点提货

#### 3.1 提货流程

```
用户收到通知 ──▶ 前往自提点 ──▶ 出示取货码 ──▶ 团长核验 ──▶ 取货完成
```

#### 3.2 取货方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 取货码取货 | 4-6位数字验证码 | 标准流程 |
| 扫码取货 | 扫描订单二维码 | 手机操作便捷 |
| 团长代查 | 提供手机号后四位 | 忘带手机时 |

#### 3.3 提货时效

- **标准提货时间**：到货后48小时内
- **生鲜商品**：建议当天提取
- **超期处理**：超期未提商品由团长按售后流程处理

### 4. 团长管理

#### 4.1 团长招募标准 [需内部资料确认]

| 维度 | 基本要求 |
|------|----------|
| 场地要求 | 有固定经营场所，具备冷藏/冷冻条件 |
| 位置要求 | 位于社区内或出入口，便于用户到达 |
| 时间要求 | 能够保证每日16:00-20:00营业 |
| 设备要求 | 智能手机、网络环境、货架/存储空间 |

#### 4.2 团长职责

1. **收货管理**
   - 按时接收配送商品
   - 清点数量、检查品质
   - 分类存放（常温/冷藏/冷冻）

2. **用户服务**
   - 通知用户取货
   - 核验身份、交付商品
   - 处理简单咨询

3. **售后协助**
   - 接收退货商品
   - 记录售后问题
   - 配合平台处理纠纷

#### 4.3 团长激励与考核 [需内部资料确认]

| 考核维度 | 说明 |
|----------|------|
| 订单量 | 月度销售件数 |
| 履约率 | 按时收货、通知用户率 |
| 投诉率 | 用户投诉次数 |
| 售后率 | 退货退款比例 |

### 5. 售后处理

#### 5.1 售后类型

| 类型 | 说明 | 处理时限 |
|------|------|----------|
| 商品质量问题 | 破损、变质、过期等 | 24小时内 |
| 缺货/少货 | 订单商品未送达或数量不足 | 24小时内 |
| 错发商品 | 收到非订单内商品 | 24小时内 |
| 无理由退货 | 用户主观原因 [需内部资料确认] | 按平台规则 |

#### 5.2 售后流程

```
用户申请 ──▶ 团长/平台审核 ──▶ 确认问题 ──▶ 退款/补货/补偿 ──▶ 完结
    │              │              │
    ▼              ▼              ▼
 拍照举证    核实情况      系统操作
```

#### 5.3 退款标准 [需内部资料确认]

- **全额退款**：商品严重质量问题、完全未送达
- **部分退款**：商品轻微瑕疵、重量不足
- **优惠券补偿**：小额问题、用户满意度维护

### 6. 缺货补差

#### 6.1 缺货场景

| 场景 | 处理方式 |
|------|----------|
| 下单后缺货 | 系统自动退款+通知用户 |
| 配送中损耗 | 全额退款或次日补送 |
| 规格替换 | 经用户同意后更换等值商品 |

#### 6.2 补差规则

- **价格差异**：多退少不补（替换商品更贵不额外收费）
- **品质差异**：降级替换需经用户确认
- **时效承诺**：缺货商品24小时内处理完毕

| 输出类型 | 要求 |
