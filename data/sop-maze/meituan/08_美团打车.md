## Objective

本SOP旨在规范美团打车网约车服务的运营流程，确保：

1. **叫车便捷**：快速响应，智能匹配，缩短用户等待时间
2. **服务品质**：司机专业、车辆整洁、行程安全
3. **价格透明**：预估准确、计费清晰、无隐形消费
4. **安全保障**：全程安全监控、紧急求助、行程异常处理

## Standard Operating Procedures

### 1. 叫车下单

#### 1.1 车型选择

| 车型 | 说明 | 适用场景 |
|------|------|----------|
| 快车 | 经济型，日常出行 | 普通通勤、短途出行 |
| 优享 | 品质型，车况较好 | 商务出行、追求舒适 |
| 专车 | 高端型，服务标准化 | 重要场合、接待客户 |
| 出租车 | 传统出租车 | 习惯出租车服务的用户 |
| 拼车 | 共享出行，价格优惠 | 不赶时间、预算有限 |

#### 1.2 下单流程

```
打开美团APP ──▶ 选择打车 ──▶ 确认上车点 ──▶ 输入目的地 ──▶ 选择车型 ──▶ 确认叫车
```

#### 1.3 订单信息

| 字段 | 必填性 | 说明 |
|------|--------|------|
| 上车点 | 必填 | 自动定位，可手动调整 |
| 目的地 | 必填 | 输入地址或选择常用地点 |
| 车型 | 必填 | 单选或多选（叫车时可多选） |
| 乘车人 | 选填 | 代人叫车时填写 |
| 备注 | 选填 | 特殊需求说明 |

#### 1.4 预估价格 [需内部资料确认]

| 费用项目 | 说明 |
|----------|------|
| 起步价 | 含基础里程和时长 |
| 里程费 | 超出起步里程后按公里计费 |
| 时长费 | 低速或等待时按时间计费 |
| 远途费 | 长距离行程附加费 |
| 夜间费 | 夜间时段（通常23:00-5:00）加价 |
| 动态调价 | 高峰期供需调节 [需内部资料确认] |

### 2. 司机接单

#### 2.1 派单机制

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 系统派单 | 算法根据距离、方向、评分匹配 | 标准派单 |
| 司机抢单 | 司机主动选择订单 | 预约单、特殊订单 |
| 指派专车 | 高价值订单指派优质司机 | 专车服务 |

#### 2.2 接单时效 [需内部资料确认]

| 阶段 | 时效要求 |
|------|----------|
| 系统派单 | 实时推送 |
| 司机接单响应 | 通常10-15秒内 |
| 司机到达上车点 | 根据距离，通常3-10分钟 |

#### 2.3 司机信息展示

| 信息项 | 说明 |
|--------|------|
| 车牌号 | 车辆识别 |
| 车型颜色 | 便于用户寻找 |
| 司机姓名 | 称呼使用 |
| 司机评分 | 服务质量参考 |
| 接单数 | 经验参考 |
| 实时位置 | 地图显示车辆位置 |

#### 2.4 取消规则 [需内部资料确认]

| 取消方 | 取消时机 | 费用/处罚 |
|--------|----------|-----------|
| 用户 | 司机接单后3分钟内 | 免费取消 |
| 用户 | 司机接单3分钟后 | 可能产生取消费 |
| 用户 | 司机已到达后 | 产生取消费 [需内部资料确认] |
| 司机 | 无正当理由取消 | 平台处罚 |

### 3. 行程服务

#### 3.1 上车流程

```
司机到达 ──▶ 电话联系 ──▶ 核对信息（车牌、手机尾号）──▶ 上车 ──▶ 确认开始行程
```

#### 3.2 行程中服务规范

| 环节 | 标准要求 |
|------|----------|
| 路线选择 | 按导航或用户指定路线行驶 |
| 驾驶规范 | 安全驾驶，遵守交通规则 |
| 服务态度 | 礼貌用语，不打扰乘客（除非乘客主动交流） |
| 车内环境 | 整洁无异味，温度适宜 |
| 特殊需求 | 协助放置行李，调节空调/音乐等 |

#### 3.3 行程监控

| 监控项 | 说明 |
|--------|------|
| GPS轨迹 | 实时记录行驶路线 |
| 时长监控 | 记录行驶时长、等待时长 |
| 异常检测 | 偏离路线、长时间停留等异常预警 |
| 录音保护 | 行程录音（加密存储，用于纠纷处理） [需内部资料确认] |

#### 3.4 到达流程

```
到达目的地 ──▶ 结束行程 ──▶ 系统计算费用 ──▶ 展示账单 ──▶ 支付
```

### 4. 支付结算

#### 4.1 支付方式

| 方式 | 说明 |
|------|------|
| 在线支付 | 微信支付、支付宝、银行卡等 |
| 余额支付 | 美团钱包余额 |
| 月付/先乘后付 | 信用支付，次月还款 [需内部资料确认] |
| 现金支付 | 出租车支持（部分城市） |

#### 4.2 费用组成

```
最终费用 = 起步价 + 里程费 + 时长费 + 远途费 + 夜间费 + 其他附加费 - 优惠券抵扣
```

#### 4.3 发票开具

| 项目 | 说明 |
|------|------|
| 开票类型 | 电子发票 |
| 开票内容 | 运输服务/客运服务 |
| 开票时效 | 行程结束后申请 [需内部资料确认] |
| 开票周期 | 通常即时或1-3个工作日内 |

### 5. 行程异常

#### 5.1 异常类型

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 司机迟到 | 超过预计到达时间 | 联系司机或取消重叫，可能获得补偿 |
| 司机未到达 | 司机标记到达但实际未到 | 投诉，核实后处理 |
| 路线偏离 | 未按合理路线行驶 | 系统预警，用户可反馈 |
| 车辆不符 | 实际车辆与平台显示不符 | 拒绝乘坐，立即投诉 |
| 司机态度问题 | 服务态度恶劣 | 投诉，平台核实处罚 |
| 物品遗失 | 物品遗落在车上 | 联系客服协助寻找 |

#### 5.2 异常处理流程

```
发现异常 ──▶ 联系司机/客服 ──▶ 描述问题 ──▶ 平台核实 ──▶ 处理结果 ──▶ 补偿（如适用）
```

#### 5.3 费用争议处理 [需内部资料确认]

| 争议类型 | 处理方式 |
|----------|----------|
| 费用过高 | 核对路线和计费明细 |
| 未乘车扣费 | 核实后退款 |
| 重复扣费 | 核实后退还多扣部分 |
| 优惠券未使用 | 核实后补发或退款 |

### 6. 安全服务

#### 6.1 安全功能

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| 紧急求助 | 一键报警，发送位置和行程信息 | 遇到危险时 |
| 行程分享 | 将行程信息分享给亲友 | 独自乘车时 |
| 号码保护 | 虚拟号码，保护双方隐私 | 全程 |
| 实时位置 | 亲友可查看实时位置 | 行程分享后 |
| 安全中心 | 安全知识、应急指南 | 随时查看 |

#### 6.2 紧急求助流程

```
点击紧急求助 ──▶ 确认求助 ──▶ 系统自动报警并通知紧急联系人 ──▶ 客服介入
```

#### 6.3 司机安全审核 [需内部资料确认]

| 审核项 | 要求 |
|--------|------|
| 身份认证 | 实名认证，人脸识别 |
| 驾驶证 | 有效驾驶证，驾龄要求（通常3年以上） |
| 行驶证 | 车辆合法登记 |
| 无犯罪记录 | 背景审查 |
| 车辆年检 | 定期安全检测 |
| 培训考核 | 安全服务培训合格 |

#### 6.4 行程中安全监控

| 监控项 | 说明 |
|--------|------|
| 偏航预警 | 偏离常规路线自动提醒 |
| 长时间停留 | 异常停留触发预警 |
| 紧急刹车/加速 | 危险驾驶行为检测 |
| 录音监控 | 异常情况可追溯 [需内部资料确认] |
