## Objective

本SOP旨在规范美团打车网约车服务的运营流程，确保：

1. **叫车便捷**：快速响应，智能匹配，缩短用户等待时间
2. **服务品质**：司机专业、车辆整洁、行程安全
3. **价格透明**：预估准确、计费清晰、无隐形消费
4. **安全保障**：全程安全监控、紧急求助、行程异常处理

**多方对话系统**：
- **用户** ↔ **平台系统**（下单、派单、计费、支付）
- **用户** ↔ **司机**（电话沟通、行程确认）
- **平台** ↔ **司机**（派单、导航、监控）
- **用户/司机** ↔ **客服**（异常处理、投诉、协助）

## Standard Operating Procedures

### 1. 叫车下单

#### 1.1 车型选择

##### 1.1.1 车型类型对比

| 车型 | 定位 | 适用场景 | 预估价格区间 | 车辆要求 |
|------|------|----------|--------------|----------|
| 快车 | 经济型，日常出行 | 普通通勤、短途出行 | 基础价 | 符合网约车标准的普通车辆 |
| 优享 | 品质型，车况较好 | 商务出行、追求舒适 | 快车的1.2-1.5倍 | 车龄<3年，B级及以上车型 |
| 专车 | 高端型，服务标准化 | 重要场合、接待客户 | 快车的2-3倍 | 豪华品牌，司机持证上岗 |
| 出租车 | 传统出租车 | 习惯出租车服务的用户 | 打表计费 | 正规出租车 |
| 拼车 | 共享出行，价格优惠 | 不赶时间、预算有限 | 快车的6-8折 | 与快车相同 |

##### 1.1.2 下单流程

```
打开美团APP ──▶ 选择打车 ──▶ 确认上车点 ──▶ 输入目的地 ──▶ 选择车型 ──▶ 确认叫车
      │            │              │              │              │
      ▼            ▼              ▼              ▼              ▼
   进入首页      自动定位       可地图选点      多车型对比      等待接单
   点击打车      可手动调整      常用地址       预估价展示      实时派单
```

**【话术】下单引导话术**：

```
用户："选快车吧"
系统："好的，正在为您呼叫快车，预计2分钟内接单"
```

#### 1.2 订单信息填写

##### 1.2.1 必填字段说明

| 字段 | 必填性 | 填写要求 | 系统辅助 |
|------|--------|----------|----------|
| 上车点 | 必填 | 自动定位，可手动调整至具体门牌号 | GPS定位+地图选点 |
| 目的地 | 必填 | 输入地址或选择常用地点 | 地址联想+历史记录 |
| 车型 | 必填 | 单选或多选（叫车时可多选） | 智能推荐 |
| 乘车人 | 选填 | 代人叫车时填写姓名电话 | 通讯录导入 |
| 备注 | 选填 | 特殊需求说明（如：带宠物、需要后备箱） | 常用标签选择 |

##### 1.2.2 预估价格说明

| 费用项目 | 计算方式 | 说明 |
|----------|----------|------|
| 起步价 | 含基础里程（通常3公里）和时长（通常8分钟） | 各城市标准不同 |
| 里程费 | 超出起步里程后按公里计费 | 普通时段/高峰时段费率不同 |
| 时长费 | 低速或等待时按时间计费 | 通常<12km/h时开始计时 |
| 远途费 | 长距离行程附加费 | 通常超过12或15公里后收取 |
| 夜间费 | 夜间时段（通常23:00-5:00）加价 | 在里程费基础上加收 |
| 动态调价 | 高峰期供需调节 | 倍数显示，用户可选择等待 |

**【KCP】价格透明关键控制点**：
- 叫车前必须展示预估价格区间
- 动态调价时必须明确显示倍数（如1.5倍）
- 预估价格与实际价格差异>20%时必须说明原因

### 2. 司机接单

#### 2.1 派单机制

##### 2.1.1 派单模式对比

| 模式 | 说明 | 适用场景 | 响应时效 |
|------|------|----------|----------|
| 系统派单 | 算法根据距离、方向、评分自动匹配最优司机 | 标准订单 | 即时推送 |
| 司机抢单 | 司机端显示附近订单，司机主动选择接单 | 预约单、机场订单 | 5分钟内 |
| 指派专车 | 高价值订单指定优质司机服务 | 专车服务 | 即时响应 |

##### 2.1.2 派单算法逻辑

```
订单生成 ──▶ 筛选可用司机 ──▶ 计算匹配分数 ──▶ 推送订单 ──▶ 司机响应 ──▶ 确认接单
    │            │               │              │            │
    ▼            ▼               ▼              ▼            ▼
  订单属性     距离<3km       距离权重30%    推送Top3     15秒响应
  位置/车型    同方向         评分权重25%    司机列表     超时重派
  时效要求     在线状态       服务权重25%                 拒绝记录
                              实时权重20%
```

#### 2.2 接单时效标准

##### 2.2.1 各阶段时效要求

| 阶段 | 时效要求 | 超时处理 |
|------|----------|----------|
| 系统派单 | 实时推送 | - |
| 司机接单响应 | 15秒内 | 自动转派下一司机 |
| 司机到达上车点 | 根据距离预估（通常3-10分钟） | 超时可取消重叫 |
| 用户等待 | 司机接单后开始计时 | 超过预估时间可投诉 |

**【多方对话】派单成功对话**：

```
【系统推送】
系统："已为您安排司机王师傅，车牌号京A·12345，白色丰田凯美瑞，司机评分4.9分。预计5分钟后到达"

【司机联系】
司机："您好，我是美团打车司机王师傅，我已经接单了，正在前往您定位的上车点，预计5分钟到达"
用户："好的，我在XX大厦门口等你"
司机："好的，到了我给您打电话"
```

#### 2.3 司机信息展示

##### 2.3.1 展示信息清单

| 信息项 | 展示内容 | 用途 |
|--------|----------|------|
| 车牌号 | 完整车牌（如：京A·12345） | 车辆识别 |
| 车型颜色 | 如：白色丰田凯美瑞 | 便于用户寻找 |
| 司机姓名 | 王师傅 | 称呼使用 |
| 司机评分 | 4.9分（5分制） | 服务质量参考 |
| 接单数 | 已完成3280单 | 经验参考 |
| 实时位置 | 地图显示车辆位置及移动轨迹 | 掌握接驾进度 |
| 预计到达 | "预计5分钟后到达" | 时间预期管理 |

#### 2.4 取消规则

##### 2.4.1 取消费用规则

| 取消方 | 取消时机 | 费用/处罚 | 说明 |
|--------|----------|-----------|------|
| 用户 | 司机接单后3分钟内 | 免费取消 | - |
| 用户 | 司机接单3分钟后，未到达前 | 可能产生3-5元取消费 | 补偿司机空驶 |
| 用户 | 司机已到达后 | 产生10-15元取消费 | 全额补偿司机 |
| 司机 | 无正当理由取消 | 平台处罚（扣分/罚款） | 影响司机接单权限 |
| 司机 | 超过3分钟未到达上车点 | 用户可免费取消 | 系统标记司机违规 |

**【Rule】取消拦截规则**：
- **频繁取消拦截**：用户当日取消>3次，系统提示"您今日取消次数较多，继续取消可能影响您的叫车优先级"
- **司机到达后取消拦截**：司机点击"已到达"后，用户取消需支付取消费，系统弹窗确认"司机已到达，取消将收取10元费用，是否确认？"

### 5. 行程异常处理

#### 5.1 异常类型与处理

##### 5.1.1 异常场景矩阵

| 异常类型 | 判定标准 | 处理方式 | 用户补偿 |
|----------|----------|----------|----------|
| 司机迟到 | 超过预估到达时间5分钟以上 | 联系司机/取消重叫 | 迟到补偿券 |
| 司机未到达 | 司机标记到达但实际未到 | 投诉核实后处理 | 全额退款+补偿 |
| 路线偏离 | 偏离导航路线>500米 | 系统预警，用户可反馈 | 差价退还 |
| 车辆不符 | 实际车辆与平台显示不符 | 拒绝乘坐，立即投诉 | 全额退款+补偿 |
| 司机态度问题 | 服务态度恶劣/言语冲突 | 投诉，平台核实处罚 | 视情况补偿 |
| 物品遗失 | 物品遗落在车上 | 联系客服协助寻找 | 协助找回 |
| 费用争议 | 实际费用远超预估 | 核实路线和计费明细 | 差价退还 |

#### 5.2 异常处理流程

##### 5.2.1 标准处理流程

```
发现异常 ──▶ 联系司机/客服 ──▶ 描述问题 ──▶ 平台核实 ──▶ 处理结果 ──▶ 补偿发放
    │            │              │            │            │
    ▼            ▼              ▼            ▼            ▼
  保留证据     APP一键反馈      上传照片/     系统+人工    优惠券/
  拍照截图     或拨打客服       录音证据      联合核实      现金补偿
```

**【多方对话】费用争议处理**：

#### 6.3 司机安全审核

##### 6.3.1 准入审核标准

| 审核项 | 要求 | 验证方式 | 审核周期 |
|--------|------|----------|----------|
| 身份认证 | 实名认证，人脸识别 | 身份证OCR+活体检测 | 即时 |
| 驾驶证 | 有效驾驶证，驾龄≥3年 | 证件上传审核 | 1-3工作日 |
| 行驶证 | 车辆合法登记，车龄<8年 | 证件上传审核 | 1-3工作日 |
| 无犯罪记录 | 背景审查通过 | 第三方背调 | 3-5工作日 |
| 车辆年检 | 定期安全检测合格 | 年检标上传 | 1工作日 |
| 培训考核 | 安全服务培训≥90分 | 线上考试 | 即时 |

**【Rule】司机资质拦截规则**：
- **准入拦截**：未通过全部安全审核的司机无法上线接单
- **评分拦截**：司机评分<4.5分且连续3日，暂停派单，需参加培训
- **投诉拦截**：收到安全类投诉，立即暂停服务，调查期间禁止接单
- **疲劳驾驶拦截**：连续在线>10小时或夜间连续接单>4小时，强制下线休息

#### 6.4 行程中安全监控

##### 6.4.1 自动预警机制

| 监控项 | 预警条件 | 系统响应 |
|--------|----------|----------|
| 偏航预警 | 偏离常规路线>1公里 | APP推送提醒用户 |
| 长时间停留 | 非拥堵情况下停留>10分钟 | 短信+电话确认安全 |
| 紧急刹车/加速 | 检测到危险驾驶行为 | 记录并纳入司机考核 |
| 夜间异常 | 夜间(0-5点)行程异常 | 加强监控+客服关注 |
| 订单取消异常 | 司机频繁取消订单 | 风控标记+人工审核 |
