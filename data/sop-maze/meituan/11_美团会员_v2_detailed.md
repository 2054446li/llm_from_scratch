## Objective

本文档旨在规范美团会员体系（含美团会员、神会员）的标准操作流程，确保用户能够清晰了解会员权益、便捷完成开通/续费，并合理使用各项会员特权。适用于所有美团会员相关服务场景。

**核心目标：**
- 提供清晰的会员权益说明
- 简化会员开通与续费流程
- 规范权益领取与使用规则
- 建立透明的退款与退订机制
- 提升会员用户体验与满意度

### 2. 权益领取

#### 2.1 无门槛红包权益
##### 2.1.1 红包发放规则
| 权益项目 | 美团会员 | 神会员 | 领取方式 |
|---------|---------|--------|---------|
| 通用红包 | 6张×¥5 | 6张×¥5 | 自动发放至账户 |
| 外卖红包 | 6张×¥5 | 8张×¥5 | 每月1日发放 |
| 到店红包 | 2张×¥10 | 4张×¥10 | 需手动领取 |
| 酒店红包 | 1张×¥20 | 2张×¥20 | 季度发放 |

##### 2.1.2 红包使用规则
| 规则项 | 说明 |
|-------|------|
| 使用门槛 | 无门槛，订单金额≥红包面额即可 |
| 叠加限制 | 每单限用1张会员红包 |
| 有效期 | 发放后30天内有效 |
| 退款处理 | 订单退款后红包退回（在有效期内）|

#### 2.2 神券膨胀权益（神会员专属）
##### 2.2.1 膨胀规则
```
普通红包 ──▶ 选择膨胀 ──▶ 满足条件 ──▶ 金额提升
  ¥5    ──▶  点击膨胀  ──▶ 满30可用 ──▶  ¥8-¥15
```

##### 2.2.2 膨胀档位
| 膨胀前 | 膨胀后 | 使用门槛 | 适用场景 |
|-------|-------|---------|---------|
| ¥5 | ¥8-¥10 | 满25可用 | 普通外卖订单 |
| ¥5 | ¥10-¥15 | 满35可用 | 大额外卖订单 |
| ¥5 | ¥12-¥20 | 满50可用 | 多人聚餐订单 |

##### 2.2.3 膨胀限制
- 每月膨胀次数有限制
- 膨胀后红包有效期缩短（通常7天）
- 膨胀操作不可逆

#### 2.3 权益领取流程
```
开通成功 ──▶ 权益到账 ──▶ 手动/自动领取 ──▶ 红包卡券包 ──▶ 下单使用
```

#### 2.4 权益有效期
| 权益类型 | 有效期 | 说明 |
|---------|--------|------|
| 月度红包 | 自发放起30天 | 当月有效 |
| 膨胀神券 | 膨胀后7天 | 需及时使用 |
| 生日特权 | 生日当月 | 一次性权益 |
| 年度权益 | 会员期内有效 | 随会员到期失效 |

### 3. 会员续费

#### 3.1 续费方式
| 续费方式 | 说明 | 扣费时间 |
|---------|------|---------|
| 自动续费 | 到期自动扣费续期 | 到期前1天 |
| 手动续费 | 用户主动操作续费 | 任意时间 |
| 提前续费 | 在有效期内续费 | 立即生效 |

#### 3.2 自动续费规则
##### 3.2.1 续费流程
```
到期前提醒 ──▶ 到期前1天扣费 ──▶ 扣费成功 ──▶ 续期成功
    │              │              │
    ▼              ▼              ▼
消息推送      余额/绑卡扣费    发送确认通知
短信提醒      扣费失败重试    新周期权益发放
```

##### 3.2.2 扣费失败处理
| 失败次数 | 处理动作 |
|---------|---------|
| 第1次 | 立即重试，发送提醒 |
| 第2次 | 24小时后重试 |
| 第3次 | 会员到期，停止自动续费 |

#### 3.3 提前续费处理
- 提前续费：当前会员期延长
- 权益叠加：未使用权益可累计
- 价格保护：续费按当前价格执行

#### 3.4 续费优惠
| 优惠类型 | 优惠内容 | 适用条件 |
|---------|---------|---------|
| 连续包月优惠 | 月费8折 | 保持自动续费 |
| 年卡优惠 | 相当于7折 | 购买年卡 |
| 老用户回馈 | 额外红包 | 续费满X个月 |
| 活动期续费 | 限时特价 | 活动期间 |

### 4. 退款规则

#### 4.1 退款条件
| 退款场景 | 退款条件 | 退款金额 |
|---------|---------|---------|
| 未使用权益 | 开通后7天内，未使用任何权益 | 全额退款 |
| 部分使用 | 已使用部分权益 | 按比例扣除后退还 |
| 服务异常 | 平台原因导致权益无法使用 | 协商退款 |
| 误购退款 | 24小时内申请 | 全额退款 |

#### 4.2 退款计算公式
```
可退金额 = 实付金额 - 已使用权益价值 - 已享受优惠价值

示例：
实付金额：¥15
已使用红包：2张×¥5 = ¥10
可退金额：¥15 - ¥10 = ¥5
```

#### 4.3 退款流程
```
申请退款 ──▶ 权益核查 ──▶ 金额计算 ──▶ 审核确认 ──▶ 原路退回
```

#### 4.4 退款时效
| 支付方式 | 退款时效 | 到账路径 |
|---------|---------|---------|
| 余额支付 | 即时 | 美团余额 |
| 微信支付 | 1-3工作日 | 微信零钱/银行卡 |
| 支付宝 | 1-3工作日 | 支付宝余额/银行卡 |
| 银行卡 | 3-7工作日 | 原支付银行卡 |

### 5. 权益使用限制

#### 5.1 红包使用限制
| 限制类型 | 具体规则 |
|---------|---------|
| 门槛限制 | 无门槛红包：订单金额≥红包面额即可使用 |
| 品类限制 | 部分红包仅限指定品类（外卖/到店/酒店）|
| 商家限制 | 部分商家不参与红包活动 |
| 叠加限制 | 每单限用1张会员红包 |
| 地域限制 | 部分红包限指定城市使用 |

#### 5.2 神券膨胀规则
| 膨胀前 | 膨胀后 | 使用门槛 | 适用场景 |
|-------|-------|---------|---------|
| ¥5 | ¥8-¥10 | 满25可用 | 普通外卖订单 |
| ¥5 | ¥10-¥15 | 满35可用 | 大额外卖订单 |
| ¥5 | ¥12-¥20 | 满50可用 | 多人聚餐订单 |

#### 5.3 权益冻结情形
- 账号异常（疑似盗号/违规）
- 存在未处理的投诉/纠纷
- 违反平台规则被处罚期间
- 会员退款处理中

#### 5.4 权益转让限制
- 会员身份不可转让
- 红包仅限本人使用
- 部分权益可赠送（需满足条件）

| 拦截条件 | 拦截动作 | 提示话术 |

| 拦截条件 | 拦截动作 | 提示话术 |
