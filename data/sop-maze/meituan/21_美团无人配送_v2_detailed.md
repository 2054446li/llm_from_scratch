## Objective

本SOP旨在规范美团无人配送业务的运营流程，确保：

1. **安全可靠**：建立多重安全防护机制，确保无人设备运行安全
2. **高效履约**：保障无人机/无人车配送时效，实现快速送达
3. **人机协作**：建立完善的远程监控与人工介入机制
4. **合规运营**：满足空域管理、道路测试等监管要求
5. **用户体验**：提供便捷、透明的无人配送服务体验

## Standard Operating Procedures

### 1. 订单接入与调度

#### 1.1 订单接入流程

##### 1.1.1 订单来源与分配

| 订单来源 | 分配策略 | 适用场景 |
|----------|----------|----------|
| 外卖订单 | 距离+时效优先 | 3公里内，时效要求高 |
| 买药订单 | 最高优先级 | 紧急药品配送 |
| 商超订单 | 载重匹配 | 中小件商品 |
| 测试订单 | 指定区域 | 新区域试运营 |

##### 1.1.2 智能调度系统

```
订单接入 ──▶ 地址解析 ──▶ 设备匹配 ──▶ 路径计算 ──▶ 任务派发
    │           │           │           │           │
    ▼           ▼           ▼           ▼           ▼
  订单信息    经纬度/    无人机/      最优路径     下发至
  提取        空域编码   无人车选择    计算         设备
```

**【KCP】调度关键控制点**：
- 必须确认起降点/停靠点可用状态
- 无人机配送需确认空域开放时段
- 无人车配送需确认道路测试许可区域
- 载重不得超过设备额定载重（无人机≤3kg，无人车≤100kg）

#### 1.2 设备状态管理

##### 1.2.1 设备状态监控

| 状态 | 说明 | 可接单状态 |
|------|------|------------|
| 待机中 | 设备空闲，位于停靠点 | 可接单 |
| 充电中 | 电量低于阈值，正在充电 | 不可接单 |
| 配送中 | 正在执行配送任务 | 不可接单 |
| 维护中 | 定期保养或故障维修 | 不可接单 |
| 返航中 | 任务完成或异常返航 | 不可接单 |

##### 1.2.2 设备健康检查

```
任务分配前 ──▶ 电量检查（>30%）──▶ GPS信号检查 ──▶ 通信链路检查 ──▶ 载荷检查
                    │                  │                │              │
                    ▼                  ▼                ▼              ▼
                低于阈值            信号强度>3格      延迟<200ms      重量合规
                拒绝派单            否则等待          否则切换备用    否则拒单
```

**【Rule】设备状态拦截规则**：
- **电量拦截**：无人机电量<30%、无人车电量<20%时，系统禁止派单并提示"设备电量不足，正在充电中"
- **天气拦截**：风速>10m/s、降雨量>5mm/h、能见度<500m时，无人机暂停服务
- **空域拦截**：空域管制时段（如民航航班高峰期），无人机无法起飞
- **载重拦截**：订单商品重量超过设备额定载重时，自动转人工配送

### 2. 自动装载流程

| 检查项 | 检查内容 | 合格标准 |

##### 2.1.2 装载流程

```

       │              │            │            │            │            │
       ▼              ▼            ▼            ▼            ▼            ▼
   通知商家       核对订单      按规范放置    晃动测试     自动上锁     开始配送
   准备商品       商品清单      重心居中      确认稳固     拍照留证     任务激活
```

**【话术】装载环节标准话术**（系统自动播报）：
- 到达取货点："美团无人配送已到达，请准备装载商品"
- 装载完成："商品装载完成，舱门已关闭，即将开始配送"
- 异常提醒："检测到舱门未完全关闭，请重新检查"

#### 2.2 装载异常处理

| 异常类型 | 判定标准 | 处理流程 | 通知方式 |
|----------|----------|----------|----------|

| 超重 | 实际重量>额定载重 | 拒载并建议分批配送 | APP推送 |
| 包装破损 | 外包装明显破损 | 拒载并要求更换包装 | APP推送+电话 |
| 装载超时 | 超过5分钟未完成 | 自动上报运维人员介入 | 运维系统告警 |

### 3. 路径规划与导航

#### 3.1 无人机路径规划

##### 3.1.1 空域分层管理

| 空域层级 | 高度范围 | 用途 | 管制要求 |
|----------|----------|------|----------|
| 低空空域 | 0-120m | 无人机配送主通道 | 需申请飞行许可 |
| 过渡空域 | 120-300m | 紧急避让使用 | 管制时段禁用 |
| 禁飞空域 | 全高度 | 机场、军事区等 | 永久禁飞 |

##### 3.1.2 航路规划原则

```
起点（商家/起降点）
        │
        ▼
  ┌─────────────┐
  │  航点规划    │──▶ 避开禁飞区
  │  - 最优路径  │──▶ 避开人口密集区
  │  - 备用路径  │──▶ 考虑电量续航
  │  - 紧急返航  │──▶ 设置紧急降落点
  └─────────────┘
        │
        ▼
终点（用户/起降点）
```

**【KCP】航路规划关键控制点**：
- 航线必须避开禁飞区、限飞区、人口密集区
- 单程飞行距离不超过设备续航能力的70%
- 设置至少1个备用降落点和1个紧急降落点
- 飞行高度保持在30-100米之间

#### 3.2 无人车路径规划

##### 3.2.1 道路分级管理

| 道路类型 | 允许通行 | 速度限制 | 特殊要求 |
|----------|----------|----------|----------|
| 封闭园区道路 | 允许 | ≤20km/h | 优先使用 |
| 非机动车道 | 允许 | ≤15km/h | 避让行人 |
| 人行道 | 条件允许时 | ≤5km/h | 人工确认 |
| 机动车道 | 禁止 | - | 仅在过街时短暂通行 |

##### 3.2.2 导航策略

```
起点（商家/停靠点）
        │
        ▼
  ┌─────────────┐
  │  路径计算    │──▶ 优先非机动车道
  │  - 主路径    │──▶ 避开施工路段
  │  - 备选路径  │──▶ 考虑红绿灯等待
  │  - 过街点    │──▶ 选择斑马线/天桥
  └─────────────┘
        │
        ▼
终点（用户/停靠点）
```

### 4. 配送执行与监控

#### 4.1 配送过程监控

##### 4.1.1 实时监控指标

| 监控维度 | 监控指标 | 告警阈值 | 响应时间 |
|----------|----------|----------|----------|
| 位置监控 | GPS坐标 | 偏离航线>10m | 实时 |
| 电量监控 | 剩余电量 | <20% | 实时 |
| 通信监控 | 信号强度 | <2格 | 实时 |
| 速度监控 | 飞行/行驶速度 | 超限速20% | 实时 |
| 环境监控 | 风速/障碍物 | 风速>8m/s | 实时 |

##### 4.1.2 监控中心响应流程

```
告警触发 ──▶ 分级评估 ──▶ 响应决策 ──▶ 执行处理 ──▶ 结果记录
    │           │           │           │           │
    ▼           ▼           ▼           ▼           ▼
  系统自动    P1/P2/P3    自动/人工    远程控制    日志归档
  检测异常    分级        决策        现场处置    复盘分析
```

**【话术】监控告警话术**（系统自动）：
- 电量告警："注意，设备电量低于20%，建议尽快完成配送或返航"
- 偏离航线："检测到偏离规划航线，正在自动修正"
- 通信中断："通信信号弱，尝试切换备用链路"

#### 4.2 安全监控机制

##### 4.2.1 多层安全防护

| 层级 | 防护机制 | 触发条件 | 处置动作 |
|------|----------|----------|----------|
| 感知层 | 激光雷达+摄像头 | 检测到障碍物 | 减速/绕行/悬停 |
| 决策层 | AI避障算法 | 碰撞风险>阈值 | 紧急制动/避让 |
| 控制层 | 飞控/车控系统 | 姿态异常 | 自动稳定/迫降 |
| 监管层 | 远程监控员 | 系统告警 | 人工接管/指令 |

##### 4.2.2 紧急处置流程

```
紧急情况 ──▶ 自动响应 ──▶ 人工介入 ──▶ 现场处置 ──▶ 事后复盘
    │           │           │           │           │
    ▼           ▼           ▼           ▼           ▼
  系统检测    紧急制动    监控员接管   运维到场    原因分析
  异常状态    悬停/停靠   远程控制     现场处理    改进措施
```

**【Rule】安全拦截规则**：
- **距离拦截**：无人机与障碍物距离<5m时，强制悬停并上报
- **高度拦截**：无人机飞行高度<10m或>120m时，强制调整高度
- **速度拦截**：无人车速度超过限速20%时，强制减速
- **人员接近拦截**：检测到人员靠近无人车<1m时，停车并语音提示
