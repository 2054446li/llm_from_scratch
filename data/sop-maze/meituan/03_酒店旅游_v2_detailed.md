# 美团酒店旅游 SOP 详细版（v2_detailed）

> **文档版本**: v2.0 详细版  
> **适用场景**: 酒店预订全流程客服/运营处理  
> **更新日期**: 2026年8月

---

## Objective

1. **预订体验目标**: 提供便捷的搜索、比价、预订体验，预订成功率 ≥ 98%
2. **价格竞争力目标**: 确保价格优势，提供最优价格保证
3. **入住顺畅目标**: 减少到店无房、订单差错等问题，到店无房率 ≤ 0.5%
4. **服务保障目标**: 7×24小时客服支持，紧急问题15分钟内响应

---

## Standard Operating Procedures

### 一、酒店搜索预订流程

#### 1.1 用户端操作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     酒店预订操作流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │1.搜索酒店│ -> │2.选择房型│ -> │3.确认政策│ -> │4.在线支付│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 取消政策确认、入住人信息准确性、价格明细确认               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 打开美团APP，进入「酒店/民宿」频道 | 自动定位或手动输入目的地 | 定位失败需手动选择城市 |
| 2 | 设置入住日期、离店日期、房间数、入住人数 | 注意节假日价格可能上涨 | 入住日期必须晚于当前时间 |
| 3 | 筛选条件（价格、星级、评分、设施等） | 可使用地图模式查看位置 | 筛选条件可组合使用 |
| 4 | 浏览酒店列表，查看详情 | 查看真实用户评价、实拍图片 | **KCP**: 必须展示真实用户评价 |
| 5 | 选择房型，查看退改政策 | 注意不同价格对应不同取消规则 | 取消政策必须显著标注 |
| 6 | 填写入住人信息，提交订单 | 确保姓名与身份证一致 | **KCP**: 入住人姓名必填 |
| 7 | 在线支付，完成预订 | 支持预付/到店付（视酒店政策） | 支付超时15分钟释放库存 |

### 二、入住流程

#### 2.1 到店入住

| 步骤 | 操作内容 | 所需材料 | KCP标记 |
|------|----------|----------|---------|
| 1 | 到达酒店前台 | 携带预订人身份证 | 到店时间记录 |
| 2 | 出示预订信息 | 报预订人姓名/手机号，或出示美团订单 | 订单信息核对 |
| 3 | 前台核实订单 | 酒店系统在美团商家版核实 | **KCP**: 订单有效性验证 |
| 4 | 身份登记 | 所有入住人身份证登记（公安要求） | 身份证信息录入 |
| 5 | 缴纳押金（如需） | 现金或刷卡预授权 | 押金金额确认 |
| 6 | 领取房卡，入住 | 确认房间号、早餐时间、WiFi密码等 | 房卡发放记录 |

#### 2.2 入住异常处理

| 异常情况 | 处理流程 | Rule层约束 | 话术 |
|----------|----------|------------|------|
| 到店无房 | 联系美团客服 → 协调酒店解决 → 无法解决则升级房型或安排附近同等级酒店 | **Rule**: 到店无房15分钟内解决 | "非常抱歉，立即为您协调，如无法安排将为您升级房型或安排同等级酒店" |
| 房型不符 | 拍照留证 → 联系客服 → 要求按订单房型入住或退还差价 | 房型不符必须按订单执行或补偿 | "为您核实，如确实房型不符将要求酒店按订单执行或退还差价" |
| 酒店拒接 | 核实拒接原因 → 全额退款 → 补偿用户损失 | 酒店拒接属严重违约 | "酒店拒接属违约行为，为您全额退款并安排其他酒店" |
| 订单查询不到 | 提供订单号 → 客服核实 → 手工确认或重新下单 | 10分钟内必须解决 | "正在为您核实订单，请稍等" |

#### 3.2 延迟退房

| 场景 | 处理方式 | Rule层约束 |
|------|----------|------------|
| 会员权益延迟 | 美团会员可享受免费延迟退房 | 黄金会员延迟至14:00，铂金会员延迟至15:00 |
| 付费延迟 | 与酒店协商，按小时或半天付费 | 需酒店确认可用 |
| 未协商超时 | 可能产生额外房费 | 超时房费按酒店规定收取 |

### 四、订单变更

#### 4.1 修改订单

| 修改类型 | 操作方式 | 限制条件 | Rule层约束 |
|----------|----------|----------|------------|
| 修改入住日期 | 申请改期，补/退差价 | 需酒店确认有房 | 改期需在入住前24小时申请 |

| 增加房间数 | 追加预订 | 视酒店库存 | 需酒店确认有房 |


### 五、取消与退款

#### 5.1 取消政策类型

| 政策类型 | 说明 | 适用场景 | Rule层约束 |
|----------|------|----------|------------|
| 免费取消 | 入住前可免费取消，全额退款 | 标准价格 | 需在取消时限前 |
| 限时免费取消 | 入住前X小时/天可免费取消 | 促销价格 | 超时不可免费取消 |
| 不可取消 | 一旦预订，不可退款 | 特价房、预付价 | 预订页必须显著标注 |
| 有条件取消 | 取消收取首晚房费或一定比例 | 优惠价格 | 扣款标准必须明确 |

#### 5.2 取消流程

```
用户申请取消
    │
    ▼
系统判断取消政策
    │
    ▼
┌─────────────────────────────────────────┐
│ Rule: 取消政策拦截                      │
│                                         │
│ 免费取消 → 立即取消，全额退款           │
│ 限时取消 → 检查是否在时限内             │
│ 不可取消 → 提示无法退款，特殊情况申诉   │
│ 有条件取消 → 显示扣款金额，确认后取消   │
└─────────────────────────────────────────┘
    │
    ▼
退款到账（1-15个工作日，视支付方式）
```

#### 5.3 退款时效

| 支付方式 | 退款时效 | 备注 |
|----------|----------|------|
| 美团余额 | 即时到账 | 推荐用户使用 |
| 微信/支付宝 | 1-3个工作日 | 原路退回 |
| 银行卡 | 3-15个工作日 | 视银行处理速度 |
| 信用卡 | 3-15个工作日 | 视银行处理速度 |

### 七、特价房规则

#### 7.1 特价房类型

| 类型 | 特点 | 限制 | Rule层约束 |
|------|------|------|------------|
| 今夜特价 | 当天剩余库存低价出售 | 仅限当天入住，不可取消 | 当天18:00后开放预订 |
| 提前购 | 提前X天预订享优惠 | 不可取消或改期 | 需提前3-7天预订 |
| 连住优惠 | 连续入住多晚享折扣 | 提前离店不退差价 | 连住需一次性预订 |
| 会员专享 | 会员专属特价 | 需会员身份 | 需登录会员账号 |
| 尾房清仓 | 当天剩余房间低价处理 | 房型随机，不可指定 | 18:00后开放，随机分配 |

#### 7.2 特价房注意事项

```
┌─────────────────────────────────────────────────────────────────┐
│                    特价房注意事项                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Rule 1: 通常标注「不可取消」或「限时取消」                     │
│          - 预订页必须显著标注取消政策                           │
│          - 用户确认后方可预订                                   │
│                                                                 │
│  Rule 2: 部分特价房不享受会员权益                               │
│          - 延迟退房权益可能不适用                               │
│          - 积分累计可能按实际支付金额                           │
│                                                                 │
│  Rule 3: 发票可能按实际支付金额开具                             │
│          - 不可按原价开具发票                                   │
│                                                                 │
│  Rule 4: 早餐等附加服务可能不包含                               │
│          - 需单独确认是否含早                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Rule 层约束汇总

| 规则类别 | 规则名称 | 规则内容 | 触发时机 |
|----------|----------|----------|----------|
| 取消政策 | 取消政策拦截 | 不同价格对应不同取消规则 | 预订/取消时 |
| 取消政策 | 取消时限拦截 | 限时取消需在时限前申请 | 取消申请时 |
| 超售处理 | 超售处理 | 到店无房15分钟内解决 | 到店无房时 |
| 超售处理 | 替代酒店安排 | 无法协调时安排同等级酒店 | 超售处理时 |
| 退款 | 退款时效 | 不同支付方式不同退款时效 | 退款处理时 |
| 不可抗力 | 不可抗力处理 | 提供证明可免费退改 | 特殊申诉时 |
