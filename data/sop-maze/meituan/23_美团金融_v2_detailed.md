## Objective

本SOP旨在规范美团金融业务的运营流程，确保：

1. **合规安全**：严格遵守金融监管要求，保障用户资金安全
2. **用户体验**：简化金融操作流程，提升用户使用便捷性
3. **风险可控**：建立完善的风控体系，防范欺诈和信用风险
4. **服务高效**：快速响应用户金融需求，提升服务满意度
5. **信息透明**：确保费率、规则清晰透明，保护用户知情权

**多方对话系统**：
- **用户** ↔ **平台系统**（账户开通、实名认证、借款申请、还款操作）
- **用户** ↔ **客服**（业务咨询、问题处理、争议申诉）
- **平台** ↔ **银行/征信**（绑卡验证、征信查询、资金划拨）
- **商家** ↔ **平台**（生意贷申请、资质审核、放款还款）

- 同一身份证最多绑定5个美团支付账户

#### 1.2 实名认证

##### 1.2.1 认证等级

| 认证等级 | 认证方式 | 功能权限 | 限额标准 |
|----------|----------|----------|----------|
| 未认证 | 仅绑定手机号 | 仅可小额支付 | 单笔500元，累计1000元 |
| 一级认证 | 身份证信息 | 基础支付功能 | 单笔1万元，累计5万元 |
| 二级认证 | 身份证+人脸识别 | 全部支付功能 | 单笔5万元，累计20万元 |
| 三级认证 | 补充银行卡验证 | 大额支付/贷款 | 单笔20万元，累计100万元 |


**【话术】认证引导话术**：

```
系统："为了保障您的账户安全和提升支付额度，建议您完成实名认证"
用户："认证有什么好处？"
系统："认证后可享受：1.单笔支付额度提升至5万元；2.可使用生活费等金融服务；3.账户更安全，支持密码找回"
用户："怎么认证？"
系统："请准备身份证，按提示拍摄身份证正反面，然后进行人脸识别，全程约2分钟"
```

**【Rule】实名认证拦截规则**：
- **黑名单拦截**：身份证在反洗钱黑名单中，禁止认证
- **重复认证拦截**：同一身份证已认证其他账户，需先解绑
- **信息不符拦截**：姓名与身份证号不匹配，提示重新输入
- **年龄限制拦截**：未满18周岁用户，限制部分金融功能

**【话术】认证结果通知话术**：
- 认证通过："实名认证已通过，您现在可以享受完整的支付服务"
- 认证失败："实名认证未通过，原因：身份证信息有误。请核对后重新输入"
- 人脸识别失败："人脸识别未通过，请确保光线充足、面部无遮挡后重试"

- **解冻规则**：还清逾期款项后，系统评估解冻

```
    ├── 利息费用
    │      ├── 日利率：0.02%-0.05%
    │      ├── 年化利率：7.2%-18%

    └── 其他费用

```

**【话术】借款引导话术**：


**【KCP】借款关键控制点**：
