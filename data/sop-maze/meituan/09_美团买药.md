## Objective

本文档旨在规范美团买药即时送药服务的标准操作流程，确保用户能够安全、便捷地购买药品，同时保障处方审核的合规性和用户隐私安全。适用于美团买药平台的所有药品购买场景，包括 OTC 非处方药和处方药。

**核心目标：**
- 提供便捷的药品搜索与比价服务
- 确保处方药购买的合规性与安全性
- 实现快速、准时的药品配送
- 保护用户购药隐私
- 提供专业的用药咨询与售后服务

## Standard Operating Procedures

### 1. 药品搜索

#### 1.1 搜索入口
| 入口类型 | 说明 | 操作路径 |
|---------|------|---------|
| 首页搜索 | 直接输入药品名称/症状 | 美团App首页搜索框 |
| 分类浏览 | 按疾病/科室/药品类型筛选 | 买药频道 > 分类 |
| 扫码找药 | 扫描药品条形码 | 搜索框 > 扫码图标 |
| 附近药店 | 基于LBS的周边药店 | 买药首页 > 附近药店 |

#### 1.2 搜索流程
```
用户输入 → 智能联想 → 结果展示 → 筛选排序 → 商品详情
```

#### 1.3 筛选维度
- **药品类型**：处方药 / 非处方药 / 医疗器械 / 保健品
- **价格区间**：自定义价格范围
- **配送时效**：30分钟达 / 1小时达 / 当日达
- **药店距离**：1km内 / 3km内 / 全城
- **品牌筛选**：指定药品品牌
- **规格剂型**：片剂/胶囊/颗粒/口服液等

#### 1.4 商品信息展示 [需内部资料确认]
- 药品名称、通用名、商品名
- 批准文号（国药准字）
- 生产厂家、生产日期、有效期
- 规格、用法用量
- 价格、促销信息
- 库存状态
- 药店资质信息

### 2. 处方审核

#### 2.1 处方药购买流程
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择处方药  │────▶│  提交处方   │────▶│  处方审核   │────▶│  审核通过   │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                    │
                              ┌─────────────────────────────────────┘
                              ▼
                       ┌─────────────┐
                       │  进入下单   │
                       └─────────────┘
```

#### 2.2 处方来源类型
| 处方类型 | 说明 | 有效期 |
|---------|------|--------|
| 平台在线问诊 | 美团互联网医院医生开具 | 3天 |
| 上传实体处方 | 用户拍照上传医院处方 | 原处方有效期内 |
| 历史处方复用 | 平台内历史有效处方 | 原处方剩余有效期 |
| 复诊续方 | 基于历史购药记录的续方 | 新开具起3天 |

#### 2.3 处方审核标准 [需内部资料确认]
- **合法性审核**：处方来源是否合法、医师资质是否有效
- **规范性审核**：处方要素是否齐全（患者信息、药品、用量、医师签章）
- **合理性审核**：用药与诊断是否匹配、剂量是否合理
- **有效期审核**：处方是否在有效期内

#### 2.4 实名认证要求
- 购买处方药需完成实名认证
- 处方信息与购买人信息需一致
- 部分特殊药品需额外身份验证

### 3. 下单配送

#### 3.1 下单流程
```
确认药品 ──▶ 选择数量 ──▶ 填写收货地址 ──▶ 选择配送时间 ──▶ 支付订单
```

#### 3.2 配送方式
| 配送类型 | 时效承诺 | 适用场景 | 费用 |
|---------|---------|---------|------|
| 即时配送 | 平均30分钟 | 急需用药 | 根据距离计算 |
| 预约配送 | 指定时间段 | 计划用药 | 根据距离计算 |
| 快递配送 | 1-3天 | 非急需/囤货 | 满额免邮 |

#### 3.3 配送包装规范 [需内部资料确认]
- **隐私包装**：外包装不显示药品信息
- **温控包装**：冷链药品使用保温箱+冰袋
- **防震包装**：易碎药品增加缓冲材料
- **密封包装**：确保药品包装完整无损

#### 3.4 配送跟踪
- 实时查看骑手位置
- 配送状态推送通知
- 预计送达时间动态更新
- 异常配送自动预警

### 4. 用药咨询

#### 4.1 咨询渠道
| 渠道 | 服务时间 | 响应时效 | 服务内容 |
|-----|---------|---------|---------|
| 在线药师 | 7×24小时 | 平均2分钟 | 用药指导、禁忌提醒 |
| 电话药师 | 7×24小时 | 即时 | 紧急用药咨询 |
| 智能客服 | 全天候 | 即时 | 常见问题解答 |
| 订单咨询 | 订单关联 | 工作时段 | 订单相关问题 |

#### 4.2 咨询服务范围
- 药品用法用量指导
- 药物相互作用提醒
- 特殊人群用药建议（孕妇/儿童/老人）
- 不良反应处理建议
- 药品储存条件说明

#### 4.3 咨询记录管理 [需内部资料确认]
- 咨询内容加密存储
- 历史咨询可追溯
- 敏感信息脱敏处理

### 5. 药品售后

#### 5.1 售后政策
| 售后类型 | 适用条件 | 处理方式 | 时效要求 |
|---------|---------|---------|---------|
| 质量问题 | 药品破损/变质/过期 | 全额退款/换货 | 签收后7天内 |
| 错发漏发 | 商品与订单不符 | 补发/退款 | 签收后24小时内反馈 |
| 订单取消 | 配送前取消 | 全额退款 | 骑手取货前 |
| 拒收退货 | 配送中拒收 | 协商处理 | 配送时 |

#### 5.2 售后流程
```
用户申请 ──▶ 原因核实 ──▶ 凭证审核 ──▶ 处理方案 ──▶ 退款/补发 ──▶ 完结
```

#### 5.3 特殊药品售后限制
- 处方药：一经售出，非质量问题不退换
- 冷链药品：签收后非质量问题不退换
- 拆封药品：非质量问题不退换

### 6. 隐私保护

#### 6.1 隐私保护措施
| 保护环节 | 具体措施 |
|---------|---------|
| 数据传输 | 全链路HTTPS加密 |
| 数据存储 | 敏感字段加密存储 |
| 订单信息 | 脱敏展示（骑手/客服可见范围受限）|
| 包装隐私 | 外包装无药品名称/病症信息 |
| 访问控制 | 最小权限原则，操作留痕 |

#### 6.2 购药记录保护 [需内部资料确认]
- 购药记录仅用户本人可见
- 不向第三方共享购药数据
- 不用于精准广告推送（药品相关）
- 合规情况下配合监管部门查询

#### 6.3 用户隐私权利
- 查看个人购药记录
- 删除历史搜索记录
- 导出个人数据
- 注销账户（按法规保留必要记录）

### 合规要求

1. **处方药销售**：严格执行"先方后药"原则，无处方不得销售处方药
2. **信息展示**：药品广告需符合《广告法》和《药品管理法》规定
3. **数据安全**：用户健康数据按敏感个人信息保护
4. **药师资质**：提供用药咨询的药师需持有执业药师资格证
5. **冷链管理**：冷链药品配送全程温度监控并记录
