## Objective

本SOP旨在规范美团电影演出（猫眼）业务的运营流程，确保：

1. **购票体验**：提供便捷、高效的影片/演出选座购票服务，购票转化率 ≥ 15%
2. **出票顺畅**：保障电子票务出票的准确性和时效性，出票成功率 ≥ 99%
3. **退改保障**：建立灵活的退改签机制，保障用户权益，退改满意度 ≥ 92%
4. **会员服务**：完善会员权益体系，提升用户粘性，会员复购率 ≥ 40%
5. **多方协同**：协调观众、平台、影院/场馆三方高效协作，客诉率 ≤ 0.3%

## Standard Operating Procedures

### 一、影片/演出浏览流程

#### 1.1 用户端操作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     影片/演出浏览操作流程                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │1.选择入口│ -> │2.浏览筛选│ -> │3.查看详情│ -> │4.选择场次│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 实时排片数据、评分真实性、库存准确性                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 打开美团APP/猫眼APP/小程序 | 可按位置、类型、价格筛选 | 定位失败需手动选择城市 |
| 2 | 浏览热映/即将上映影片或演出 | 查看评分、票房、排片信息 | **KCP**: 必须展示实时排片数据 |
| 3 | 设置筛选条件（类型/价格/距离） | 注意区分影片版本（2D/3D/IMAX） | 下映影片自动下架 |
| 4 | 查看影片/演出详情 | 查看预告片、剧情简介、用户评价 | 评分低于6.0分需提示"评分较低" |
| 5 | 选择目标场次 | 确认影院、时间、版本、语言 | 开场前15分钟关闭线上购票 |

#### 1.2 入口选择

| 入口 | 操作路径 | 适用场景 |
|------|----------|----------|
| 美团APP | 首页 → 电影演出 | 已安装美团APP用户 |
| 猫眼APP | 独立APP入口 | 电影重度用户 |
| 微信小程序 | 搜索"猫眼电影" | 快速访问，无需下载 |
| 支付宝小程序 | 搜索"猫眼电影" | 支付宝生态用户 |
| 影院官方合作 | 影院官网跳转 | 官方渠道引流 |

#### 1.3 筛选与排序

| 筛选维度 | 选项示例 | 关键要点 |
|----------|----------|----------|
| 影片类型 | 动作、喜剧、爱情、科幻 | 类型分类清晰 |
| 价格区间 | 0-30元、30-50元、50元以上 | 显示优惠后价格 |
| 距离范围 | 3km内、5km内、全城 | 基于用户位置 |
| 特色标签 | IMAX、杜比、巨幕、4DX | 特效厅标识 |
| 时间筛选 | 上午、下午、晚上、深夜 | 时段选择 |
| 演出类型 | 演唱会、话剧、音乐剧、体育赛事 | 演出分类 |

**【KCP】影片浏览关键控制点**：
- 必须显示影片实时评分和票房数据
- 排片信息必须为实时数据（含/不含优惠）
- 影片评分低于6.0分的需提示"评分较低"
- 演出场次必须显示剩余库存

| 步骤 | 操作内容 | 系统处理 | KCP标记 |

#### 2.2 座位图展示

| 座位状态 | 颜色标识 | 说明 |
|----------|----------|------|
| 可选座位 | 白色/灰色 | 可点击选择 |
| 已售座位 | 红色 | 已被购买 |
| 选中座位 | 绿色/蓝色 | 用户已选 |
| 情侣座 | 特殊标识 | 双人连座 |
| 特殊座位 | 标识说明 | 无障碍座位等 |

**【KCP】选座关键控制点**：
- 座位图必须实时同步，防止超卖
- 选中座位锁定时效为15分钟
- 情侣座、VIP座等特殊座位需明确标识

#### 2.3 座位锁定机制

| 锁定阶段 | 时效 | 说明 | Rule层约束 |
|----------|------|------|------------|
| 选座锁定 | 15分钟 | 选中座位后15分钟内需完成支付 | 超时自动释放座位 |
| 订单锁定 | 15分钟 | 提交订单后15分钟内需完成支付 | 超时订单自动取消 |
| 超时释放 | 即时 | 超时后座位自动释放回库存 | 释放后其他用户可选 |

| 短信取票码 | 短信发送的验证码 | 备用取票方式 |
| NFC/蓝牙 | 手机靠近取票 | 支持NFC的设备 |

#### 4.2 取票流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     取票入场操作流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │1.到达影院│ -> │2.自助取票│ -> │3.检票入场│ -> │4.按号入座│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 取票码有效性、取票机同步、检票准确性                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | KCP标记 |
|------|----------|---------|
| 1 | 到达影院，建议提前30分钟 | 到店时间记录 |
| 2 | 找到自助取票机 | 取票机状态监控 |
| 3 | 扫码/输入取票码 | **KCP**: 取票码唯一性校验 |
| 4 | 打印纸质票 | 纸质票信息准确性 |
| 5 | 检票入场 | 检票时效记录 |

**【KCP】取票关键控制点**：
- 取票码必须唯一且加密
- 取票机必须实时同步出票状态
- 同一取票码禁止重复打印（可重打1-2次）

#### 4.3 取票异常处理

| 异常情况 | 处理流程 | Rule层约束 | 话术 |

### 五、退改签处理流程

#### 5.1 退改签政策

| 政策类型 | 说明 | 适用场景 | Rule层约束 |
|----------|------|----------|------------|
| 随时退 | 开场前可随时退 | 部分影院/演出 | 自动审核通过 |
| 条件退 | 开场前N小时可退 | 大部分影院 | 按政策计算退款金额 |
| 不可退 | 一经售出不可退 | 特价票/特殊场次 | 购买前强制确认 |
| 改签 | 可改同影院其他场次 | 支持改签的影院 | 多退少补+改签费 |

#### 5.2 退改签时效规则

| 退改场景 | 退款比例 | 手续费 | 处理时效 | KCP标记 |
|----------|----------|--------|----------|---------|

| 开场前2小时退 | 100% | 5元/张 | 即时到账 | 自动退款 |
| 开场前1小时退 | 80% | - | 1-3个工作日 | 人工审核 |
| 开场后退票 | 0% | - | 不可退 | 系统拦截 |

## Rule 层（系统约束与拦截规则）

### R1. 座位库存拦截

| 规则ID | 规则名称 | 触发条件 | 拦截动作 | 提示信息 |
|--------|----------|----------|----------|----------|
| R1.1 | 座位被占拦截 | 支付时座位已被他人购买 | 支付失败，释放座位 | "座位已被抢占，请重新选座" |
| R1.2 | 满座拦截 | 场次座位售罄 | 关闭该场次选座入口 | "该场次已满座，请选择其他场次" |
| R1.3 | 锁座超时拦截 | 选座后超过15分钟未支付 | 自动释放座位 | "选座已超时，请重新选座" |
| R1.4 | 超卖拦截 | 系统库存与影院库存不一致 | 以影院系统为准 | "座位库存已更新，请刷新后重试" |

### R2. 时间拦截

| 规则ID | 规则名称 | 触发条件 | 拦截动作 | 提示信息 |
|--------|----------|----------|----------|----------|
| R2.1 | 开场前拦截 | 开场前15分钟内 | 关闭线上购票 | "该场次即将开场，请至影院前台购票" |
| R2.2 | 已开场拦截 | 影片已开场 | 关闭购票入口 | "该场次已开场，不可购票" |
| R2.3 | 预售拦截 | 影片未开售预售 | 日期不可选 | "该影片暂未开售，请关注开售通知" |
| R2.4 | 停售拦截 | 影院停止线上售票 | 关闭购票入口 | "该影院已停止线上售票" |

### R3. 退改拦截
