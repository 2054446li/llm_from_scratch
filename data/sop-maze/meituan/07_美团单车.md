## Objective

本SOP旨在规范美团单车共享出行服务的运营流程，确保：

1. **用车便捷**：扫码即用，快速开锁，提升出行效率
2. **计费透明**：清晰的价格体系，实时费用展示
3. **规范运营**：引导用户规范停车，维护城市秩序
4. **服务保障**：完善的故障报修、押金管理、客服支持体系

## Standard Operating Procedures

### 1. 扫码开锁

#### 1.1 开锁方式

| 方式 | 操作步骤 | 适用场景 |
|------|----------|----------|
| 扫码开锁 | 美团APP/微信扫码 → 车辆检查 → 确认开锁 | 标准流程 |
| 输入编码 | 手动输入车身编码 → 车辆检查 → 确认开锁 | 二维码损坏时 |
| NFC开锁 | 手机NFC靠近车锁 → 自动识别 → 开锁 | 支持NFC功能手机 |

#### 1.2 开锁前检查

```
用户扫码 ──▶ 车辆状态检查 ──▶ 信用分核验 ──▶ 开锁成功
                │                  │
                ▼                  ▼
           检查项目：          信用要求：
           - 二维码完好       - 信用分 ≥ 550 [需内部资料确认]
           - 车胎有气         - 无欠费记录
           - 刹车正常         - 无违规记录
           - 车座完好
           - 链条正常
```

#### 1.3 开锁失败处理

| 失败原因 | 提示信息 | 解决方案 |
|----------|----------|----------|
| 车辆故障 | "该车辆暂时无法使用" | 换一辆车，或报修 |
| 信号问题 | "网络异常，请重试" | 检查网络，稍后重试 |
| 信用不足 | "信用分不足，无法用车" | 充值押金或提升信用 |
| 欠费未缴 | "您有未支付订单" | 结清欠费后使用 |
| 运营区外 | "该车辆不在运营区内" | 前往运营区内用车 |

### 2. 骑行计费

#### 2.1 计费规则 [需内部资料确认]

| 项目 | 标准（参考） | 说明 |
|------|--------------|------|
| 起步价 | 1.5元/30分钟 | 含30分钟骑行时长 |
| 时长费 | 1.0元/30分钟 | 超出起步时长后 |
| 调度费 | 10-30元 | 超区停车、禁停区停车 |
| 车辆管理费 | 5-20元 | 违规停车（非指定停车点） |

#### 2.2 计费流程

```
开锁成功 ──▶ 开始计时 ──▶ 实时计费 ──▶ 关锁结算 ──▶ 费用确认 ──▶ 支付
                │            │            │
                ▼            ▼            ▼
            计时开始      费用显示      优惠券抵扣
            骑行状态      在APP中       会员减免
```

#### 2.3 费用展示

| 展示时机 | 展示内容 |
|----------|----------|
| 开锁前 | 预估费用、计费规则说明 |
| 骑行中 | 已骑行时长、当前费用（实时更新） |
| 关锁后 | 最终费用明细、优惠券抵扣、实付金额 |

### 3. 关锁结账

#### 3.1 关锁流程

```
到达目的地 ──▶ 寻找停车点 ──▶ 规范停放 ──▶ 手动关锁 ──▶ 听到提示音 ──▶ APP确认
```

#### 3.2 停车规范

| 要求 | 说明 | 违规后果 |
|------|------|----------|
| 指定停车点 | 必须在APP显示的P点停车 | 收取调度费 |
| 整齐摆放 | 车头朝向一致，不阻碍通行 | 信用分扣减 |
| 禁止区域 | 小区内部、楼道、地下等禁止停车 | 收取管理费+信用扣减 |
| 禁停区 | 明确标识的禁停区域 | 高额调度费 |

#### 3.3 关锁确认

| 步骤 | 操作 | 确认方式 |
|------|------|----------|
| 1 | 手动拉下车锁 | 听到"关锁成功"提示音 |
| 2 | 查看APP状态 | 显示"骑行结束" |
| 3 | 确认费用 | 查看结算金额 |
| 4 | 支付费用 | 自动扣款或手动支付 |

#### 3.4 关锁异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 关锁无提示音 | 等待10秒后重试，或联系客服 |
| APP显示未关锁 | 检查车锁是否完全闭合，拍照留证 |
| 费用异常 | 在APP内申诉，或联系客服 |

### 4. 故障报修

#### 4.1 故障类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 机械故障 | 车辆机械部件损坏 | 车胎没气、刹车失灵、链条脱落 |
| 电子故障 | 智能设备故障 | 无法开锁、无法关锁、定位异常 |
| 外观损坏 | 车辆外观破损 | 车座损坏、脚踏缺失、二维码损坏 |
| 其他问题 | 其他影响使用的问题 | 车辆脏污、被私锁 |

#### 4.2 报修流程

```
发现故障 ──▶ 拍照留证 ──▶ APP报修 ──▶ 选择故障类型 ──▶ 提交描述 ──▶ 完成报修
                                              │
                                              ▼
                                         系统记录故障
                                         调度运维处理
```

#### 4.3 报修入口

| 入口 | 路径 |
|------|------|
| 扫码页 | 扫码后显示"该车有故障"选项 |
| 骑行页 | 骑行中点击"报修"按钮 |
| 订单页 | 历史订单中选择对应订单报修 |
| 客服页 | 通过客服入口反馈 |

#### 4.4 报修奖励 [需内部资料确认]

- 有效报修可获得优惠券奖励
- 恶意报修将扣减信用分
- 多次有效报修提升用户信用等级

### 5. 违规停车

#### 5.1 违规类型

| 类型 | 定义 | 处罚措施 [需内部资料确认] |
|------|------|---------------------------|
| 非P点停车 | 未在指定停车点关锁 | 调度费10-20元 |
| 禁停区停车 | 在明确禁停区域停车 | 调度费20-30元 |
| 小区内部停车 | 将车辆骑入小区并停放 | 管理费10元+信用扣减 |
| 妨碍通行 | 车辆停放阻碍行人/车辆通行 | 信用扣减+可能的调度费 |

#### 5.2 违规处理流程

```
系统检测违规 ──▶ 推送违规通知 ──▶ 用户申诉（可选）──▶ 费用扣除 ──▶ 信用记录
      │                              │
      ▼                              ▼
  GPS定位判断                    申诉审核
  用户拍照验证                   维持/撤销处罚
```

#### 5.3 信用体系 [需内部资料确认]

| 信用分区间 | 等级 | 权益影响 |
|------------|------|----------|
| 750-850 | 优秀 | 免押金、优先客服 |
| 650-749 | 良好 | 正常用车 |
| 550-649 | 一般 | 需缴纳押金 |
| <550 | 较差 | 限制用车 |

### 6. 押金/充值管理

#### 6.1 押金政策 [需内部资料确认]

| 用户类型 | 押金要求 | 说明 |
|----------|----------|------|
| 信用良好用户 | 免押金 | 信用分≥650可免押 [需内部资料确认] |
| 普通用户 | 199元 | 可退还 |
| 信用不足用户 | 199元 | 信用提升后可申请免押 |

#### 6.2 押金操作流程

| 操作 | 流程 | 时效 |
|------|------|------|
| 缴纳押金 | 钱包 → 押金 → 支付 | 实时到账 |
| 退还押金 | 钱包 → 押金 → 申请退款 | 1-7个工作日 [需内部资料确认] |
| 押金状态查询 | 钱包 → 押金 → 查看状态 | 实时 |

#### 6.3 充值管理

| 项目 | 说明 |
|------|------|
| 骑行卡 | 次卡、周卡、月卡、季卡 [需内部资料确认] |
| 余额充值 | 预充值，用于支付骑行费用 |
| 自动续费 | 骑行卡到期自动续费（可选） |
| 退款规则 | 未使用的骑行卡可申请退款 [需内部资料确认] |

#### 6.4 骑行卡类型 [需内部资料确认]

| 卡类型 | 适用范围 | 有效期 |
|--------|----------|--------|
| 次卡 | 固定次数，每次抵扣 | 购买后30天 |
| 周卡 | 7天内不限次数 | 激活后7天 |
| 月卡 | 30天内不限次数 | 激活后30天 |
| 季卡 | 90天内不限次数 | 激活后90天 |
