## Objective

1. **时效目标**: 订单30分钟送达率 ≥ 95%，平均配送时长 ≤ 35分钟
2. **体验目标**: 用户下单转化率 ≥ 25%，复购率 ≥ 55%
3. **服务目标**: 客服响应时效 ≤ 2分钟，售后问题30分钟内处理完成
4. **质量目标**: 客诉率 ≤ 1.5%，商品完好率 ≥ 98%
5. **平台目标**: 提升即时零售市场份额，建立"万物到家"用户心智

## Standard Operating Procedures

### 一、用户注册与登录流程

#### 1.1 注册流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     用户注册流程图                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │ 打开APP  │ -> │ 选择登录 │ -> │ 验证身份 │ -> │ 完善信息 │  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  登录方式:                                                      │
│  - 手机号+验证码（推荐）                                        │
│  - 手机号+密码                                                  │
│  - 微信授权登录                                                 │
│  - 支付宝授权登录                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 下载美团APP或打开小程序 | 支持iOS/Android/微信小程序 | 需最新版本以获得完整功能 |
| 2 | 点击「我的」-「登录/注册」 | 新用户自动进入注册流程 | 已登录用户跳过此步骤 |
| 3 | 输入手机号，获取验证码 | 验证码60秒内有效 | **Rule**: 同一手机号1分钟内只能获取1次验证码 |
| 4 | 输入验证码完成验证 | 验证码错误3次需重新获取 | **Rule**: 验证码错误5次锁定15分钟 |
| 5 | 设置登录密码（可选） | 支持后续密码登录 | 密码强度需符合安全要求 |
| 6 | 完善个人信息（昵称、头像） | 可跳过，后续在设置中完善 | 首次注册送新人礼包 |

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|

| 7 | 确认订单金额 | 核对商品金额、配送费、优惠 | 金额异常提示 |
| 8 | 选择支付方式 | 微信支付、支付宝、美团支付等 | **KCP**: 支付安全校验 |
| 9 | 完成支付 | 支付成功生成订单 | 支付超时15分钟自动取消 |

## Rule 层约束汇总

| 规则类别 | 规则名称 | 规则内容 | 触发时机 |
|----------|----------|----------|----------|
| 账号安全 | 验证码频率限制 | 同一手机号1分钟内只能获取1次验证码 | 获取验证码时 |
| 账号安全 | 验证码错误锁定 | 验证码错误5次锁定15分钟 | 验证时 |
| 配送范围 | 配送范围拦截 | 超出商家配送范围无法下单 | 下单时 |
| 订单时效 | 支付超时取消 | 15分钟未支付自动取消订单 | 下单后 |
| 订单时效 | 自动确认收货 | 送达后24小时自动确认收货 | 送达后 |
| 售后时效 | 普通商品售后 | 签收后7天内可申请售后 | 售后申请时 |
| 售后时效 | 生鲜商品售后 | 签收后24小时内可申请售后 | 售后申请时 |
| 售后凭证 | 凭证要求拦截 | 必须提供照片凭证 | 售后申请时 |
| 配送补偿 | 超时自动补偿 | 超时10分钟自动发放补偿红包 | 配送超时 |
| 退款 | 极速退款条件 | 信用良好用户审核通过后即时退款 | 退款时 |

## Evaluation（5+）

### 评估维度1：配送时效
| 指标 | 目标值 | 评估方法 |
|------|--------|----------|
| 平均配送时长 | ≤ 35分钟 | 下单到送达时间 |
| 30分钟送达率 | ≥ 95% | 30分钟内送达订单/总订单 |
| 准时率 | ≥ 95% | 准时送达/总订单 |
| 超时补偿覆盖率 | 100% | 超时订单自动补偿比例 |

### 评估维度2：用户体验
| 指标 | 目标值 | 评估方法 |
|------|--------|----------|
| 下单转化率 | ≥ 25% | 下单用户数/浏览商品用户数 |
| 复购率 | ≥ 55% | 30天内再次下单用户占比 |
| 订单评分 | ≥ 4.7/5 | 用户评价平均分 |
| 客诉率 | ≤ 1.5% | 投诉订单/总订单 |

### 评估维度3：售后服务
| 指标 | 目标值 | 评估方法 |
|------|--------|----------|
| 售后响应时效 | ≤ 30分钟 | 申请到首次响应时间 |
| 退款处理时效 | ≤ 24小时 | 申请到退款完成时间 |
| 售后满意度 | ≥ 95% | 售后评价满意占比 |
| 极速退款覆盖率 | ≥ 90% | 极速退款/总退款 |

### 评估维度4：商品质量
| 指标 | 目标值 | 评估方法 |
|------|--------|----------|
| 商品完好率 | ≥ 98% | 完好送达商品/总商品 |
| 缺货率 | ≤ 3% | 缺货商品/总商品 |
| 错发率 | ≤ 0.5% | 错发订单/总订单 |
| 漏发率 | ≤ 0.5% | 漏发订单/总订单 |

### 评估维度5：客服服务
| 指标 | 目标值 | 评估方法 |
|------|--------|----------|
| 客服响应时效 | ≤ 2分钟 | 用户接入到客服响应时间 |
| 问题解决率 | ≥ 90% | 一次性解决问题占比 |
| 客服满意度 | ≥ 95% | 客服评价满意占比 |
| 投诉升级率 | ≤ 2% | 需升级处理投诉/总投诉 |
