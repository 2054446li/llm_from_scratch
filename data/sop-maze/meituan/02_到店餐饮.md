## 业务概述

美团到店餐饮业务（原「美团点评」）是连接消费者与线下餐饮商家的服务平台，提供团购套餐、代金券、预订订座、买单优惠等服务，帮助用户发现优质餐厅，享受优惠价格。

### 核心参与方

```
+-----------+      浏览/购买     +-----------+      入驻/核销     +-----------+
|  消费者   | ----------------> |  美团平台  | ----------------> |   商家    |
+-----------+                   +-----------+                   +-----------+
     ^                              |                               |
     |      消费完成/评价           |      结算                      | 提供服务
     |                              v                               v
     +----------------------  交易系统  <-----------------------  确认核销
```

## Objective

1. **用户体验目标**：帮助用户便捷发现、购买、使用到店服务
2. **商家引流目标**：为线下商家带来精准客流，提升翻台率
3. **平台交易目标**：提高团购转化率，降低退款率
4. **服务质量目标**：确保团购信息真实准确，杜绝虚假宣传

## Standard Operating Procedures

### 一、团购购买流程

#### 1.1 用户端操作流程

| 步骤 | 操作内容 | 注意事项 |
|------|----------|----------|
| 1 | 打开美团APP，进入「美食」频道 | 可按位置、菜系、价格筛选 |
| 2 | 浏览商家及团购套餐 | 查看套餐详情、使用规则、用户评价 |
| 3 | 选择套餐规格（如有） | 注意区分：工作日/周末、午餐/晚餐等 |
| 4 | 确认购买数量 | 部分套餐限购，注意查看 |
| 5 | 选择支付方式，完成支付 | 支持多种支付方式 |
| 6 | 获取团购券码 | 券码发送至APP「我的订单」和短信 |

#### 1.2 团购券类型

```
团购产品类型：
├── 套餐团购
│   ├── 固定套餐：菜品组合固定，不可更换
│   └── 可选套餐：在指定范围内选择菜品
├── 代金券
│   ├── 全场通用券：除酒水外全场通用
│   ├── 菜品券：仅限指定菜品使用
│   └── 满减券：满X元可用，可叠加/不可叠加
├── 预订套餐
│   ├── 需提前预约，保留座位
│   └── 节假日可能不可用
└── 限时秒杀
    ├── 特定时段低价抢购
    └── 通常不可退款
```

#### 1.3 购买限制说明 `[需内部资料确认：具体限制规则]`

| 限制类型 | 说明 |
|----------|------|
| 购买数量限制 | 每人限购X份，每桌限用X张 |
| 使用时间限制 | 工作日/周末、午餐/晚餐时段 |
| 使用日期限制 | 节假日不可用/仅限特定日期 |
| 叠加使用限制 | 是否可与其他优惠同享 |
| 预约要求 | 是否需要提前电话预约 |

### 二、预约订座流程

#### 2.1 在线预订

| 步骤 | 操作内容 | 系统处理 |
|------|----------|----------|
| 1 | 选择商家，点击「订座」 | 显示可预订时段和桌型 |
| 2 | 选择日期、时间、人数 | 实时查询座位库存 |
| 3 | 填写联系人信息 | 验证手机号 |
| 4 | 提交预订 | 发送预订请求给商家 |
| 5 | 等待确认 | 商家确认后通知用户 `[需内部资料确认：确认时效]` |

#### 2.2 预订状态流转

```
用户提交预订
      ↓
商家收到预订通知
      ↓
┌─────────────────────────────────────────┐
│  商家确认 → 预订成功，通知用户          │
│  商家拒绝 → 说明原因，推荐其他时段      │
│  超时未响应 → 系统自动取消              │
└─────────────────────────────────────────┘
```

#### 2.3 电话预约（传统方式）

- 用户拨打商家电话进行预约
- 商家在系统中标记预订信息
- 到店后报手机号或姓名确认

---

### 三、到店核销流程

#### 3.1 用户到店

| 步骤 | 操作内容 |
|------|----------|
| 1 | 到店后向服务员说明有美团团购 |
| 2 | 打开美团APP，进入「我的」-「订单」 |
| 3 | 找到对应团购券，点击「出示券码」 |
| 4 | 向服务员展示二维码或券号 |
| 5 | 等待商家扫码/输入密码核销 |
| 6 | 核销成功后享用服务 |

#### 3.2 商家核销操作

```
商家端核销流程：
1. 登录美团商家版APP
2. 进入「验券」功能
3. 扫描用户出示的二维码
   或
   手动输入12位券码
4. 确认券信息（套餐内容、有效期）
5. 点击「确认核销」
6. 打印小票或电子确认
```

#### 3.3 核销异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 券码无法识别 | 检查网络 → 手动输入券号 → 联系客服 |
| 券已过期 | 查看有效期 → 协商延期使用或退款 |
| 券已使用 | 查询核销记录 → 核实是否重复核销 |
| 商家无法核销 | 拍照留证 → 联系美团客服处理 |

---

### 四、套餐变更处理

#### 4.1 用户主动变更

```
用户想更换套餐
      ↓
┌─────────────────────────────────────────┐
│  未消费：申请退款后重新购买新套餐       │
│  已部分消费：与商家协商补差价           │
│  商家同意：现场调整，平台记录变更       │
└─────────────────────────────────────────┘
```

#### 4.2 商家原因变更

| 场景 | 处理方式 |
|------|----------|
| 菜品临时售罄 | 协商更换等价菜品，或退还差价 |
| 套餐内容调整 | 提前通知已购用户，提供补偿方案 |
| 商家停业装修 | 主动联系用户退款，提供替代推荐 |

### 五、退款规则

#### 5.1 退款类型 `[需内部资料确认：具体退款政策]`

| 退款场景 | 退款条件 | 退款金额 |
|----------|----------|----------|
| 未消费随时退 | 券未核销，在有效期内 | 全额退款 |
| 过期自动退 | 券过期未使用 | 全额原路退回 `[需内部资料确认：是否自动退]` |
| 商家原因 | 商家停业/无法提供服务 | 全额退款 + 补偿 |
| 用户原因 | 个人原因不想去了 | 按退款规则扣除手续费/不可退 |
| 部分使用 | 套餐内部分菜品未使用 | 协商退还差价 |

#### 5.2 退款流程

```
用户申请退款
      ↓
选择退款原因 → 提交申请
      ↓
系统审核/商家审核
      ↓
┌─────────────────────────────────────────┐
│  符合条件 → 自动退款（1-7个工作日）     │
│  需核实 → 客服介入处理                  │
│  不符合 → 拒绝并说明原因                │
└─────────────────────────────────────────┘
```

#### 5.3 不可退款情形

- 明确标注「不可退」的特价秒杀商品
- 已核销使用的团购券
- 超过退款时限的申请 `[需内部资料确认：具体时限]`
- 用户恶意退款（系统判定）

---

### 六、商家爽约处理

#### 6.1 爽约定义

商家爽约包括但不限于：
- 预订成功后商家拒绝接待
- 商家临时停业未提前通知
- 到店后无法提供团购套餐内容
- 要求用户额外支付不合理费用

#### 6.2 处理流程

```
用户投诉商家爽约
      ↓
平台核实情况（联系商家、查看记录）
      ↓
┌─────────────────────────────────────────┐
│  情况属实：                             │
│  - 为用户全额退款                       │
│  - 提供补偿（优惠券/现金）              │
│  - 记录商家违约行为                     │
│  - 严重情况下架商家/处罚                │
└─────────────────────────────────────────┘
```

#### 6.3 商家处罚措施 `[需内部资料确认：具体处罚标准]`

| 爽约次数 | 处罚措施 |
|----------|----------|
| 首次 | 警告，要求整改 |
| 多次 | 降低搜索排名，限制参加活动 |
| 严重/恶意 | 下架处理，终止合作 |

5. **投诉响应**：商家爽约投诉24小时内处理 `[需内部资料确认：时效标准]`
