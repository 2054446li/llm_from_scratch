## Objective

1. **用户体验目标**: 提供沉浸式直播购物体验，直播间转化率 ≥ 8%，用户停留时长 ≥ 5分钟
2. **商家运营目标**: 帮助本地商家通过直播引流获客，单场直播GMV提升 ≥ 30%
3. **平台生态目标**: 构建本地生活直播生态，直播订单占比 ≥ 15%
4. **服务质量目标**: 直播商品信息真实准确，虚假宣传率 ≤ 0.1%，用户满意度 ≥ 4.6/5

| 步骤 | 操作内容 | 系统处理 | Rule层约束 |

### 二、优惠券领取流程

#### 2.1 直播专享优惠券类型

| 优惠券类型 | 使用规则 | 领取限制 | Rule层约束 |
|------------|----------|----------|------------|
| 直播间专享券 | 仅限当前直播间商品使用 | 每人限领1张 | 需观看直播满3分钟可领 |
| 满减券 | 满X元减Y元 | 每人限领2张 | 不可与直播价叠加 |
| 无门槛券 | 直接抵扣，无最低消费 | 限量发放 | 先到先得 |
| 分享裂变券 | 分享给好友后解锁 | 分享3人可领 | 好友需为新用户 |
| 整点秒杀券 | 特定时段发放 | 整点限量100张 | 需提前预约提醒 |

#### 2.2 优惠券领取流程

```
用户发现优惠券
```

### 三、团购下单流程

#### 3.1 直播间下单流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     直播间下单操作流程                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │1.选择商品│ -> │2.确认规格│ -> │3.选择优惠│ -> │4.完成支付│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 直播价确认、库存实时校验、优惠券自动匹配                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 系统处理 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 点击商品卡片进入详情 | 展示商品详情、直播专享价、库存状态 | **KCP**: 直播价需显著标注 |
| 2 | 选择商品规格（如适用） | 实时校验库存 | 库存不足时标记「已售罄」 |
| 3 | 确认购买数量 | 检查限购数量 | 超出限购数量系统拦截 |
| 4 | 系统自动匹配最优优惠券 | 计算券后价格 | 用户可手动更换优惠券 |
| 5 | 选择支付方式完成支付 | 支付处理 | 支付超时15分钟释放库存 |
| 6 | 获取团购券码 | 券码发送至卡包 | 支持即时核销或预约使用 |

| 脚本审核不通过 | "您的直播脚本未通过审核，原因：【具体原因】，请修改后重新提交" |
| 数据反馈 | "本场直播数据：观看人数XXX，转化率X%，GMV XXX元" |

## Rule 层约束汇总

| 规则类别 | 规则名称 | 规则内容 | 触发时机 |
|----------|----------|----------|----------|
| 直播时效 | 直播时效拦截 | 直播结束后一定时间内可购买，超时恢复原价 | 下单时 |
| 库存管理 | 库存实时拦截 | 实时校验商品库存，避免超卖 | 下单时 |
| 限购管理 | 限购数量拦截 | 校验用户已购买数量，防止恶意抢购 | 下单时 |
| 优惠券 | 优惠券匹配拦截 | 自动匹配最优优惠券，校验使用条件 | 下单时 |
| 预约时效 | 商家确认时限 | 商家需在30分钟内确认预约 | 预约提交后 |
| 预约时效 | 时段可用性拦截 | 检查所选时段是否有空位 | 预约时 |
| 退款 | 退款时效拦截 | 不同类型商品不同退款规则 | 退款申请时 |
| 内容合规 | 直播内容审核 | 直播内容需符合平台规范 | 直播前/中 |
| 售后 | 举证要求拦截 | 描述不符等需提供举证材料 | 售后申请时 |
