## Objective

本SOP旨在规范美团民宿（含榛果民宿）业务的运营流程，确保：

1. **房客体验**：提供安全、舒适、便捷的民宿预订和入住体验
2. **房东服务**：建立标准化的房东管理和服务体系，提升房源质量
3. **交易安全**：保障预订、支付、退改等环节的资金安全和权益保障
4. **纠纷处理**：完善入住纠纷、设施问题等售后处理机制

## Standard Operating Procedures

### 1. 房源搜索

#### 1.1 用户端操作

##### 1.1.1 入口选择

| 入口 | 操作路径 | 适用场景 |
|------|----------|----------|
| 美团APP | 首页 → 酒店民宿 → 民宿 | 已安装美团APP用户 |
| 榛果民宿APP | 独立APP入口 | 民宿重度用户 |
| 微信小程序 | 搜索"美团民宿" | 快速访问，无需下载 |
| 房东分享链接 | 点击房东分享的房源链接 | 老用户推荐 |

##### 1.1.2 目的地选择流程

```
用户输入目的地/选择当前位置 ──▶ 系统展示房源列表 ──▶ 筛选条件设置 ──▶ 查看房源详情 ──▶ 加入心愿单/立即预订
         │                          │                     │                  │
         ▼                          ▼                     ▼                  ▼
    城市/商圈/景点              地图/列表双模式        价格/房型/设施       图片/评价/位置
```

**【KCP】房源搜索关键控制点**：
- 必须显示房源真实位置（精确到小区/街道级别）
- 房源照片必须为实拍，禁止过度美化
- 房东响应率低于80%的房源需提示"房东回复较慢"

##### 1.1.3 筛选与排序

| 筛选维度 | 选项示例 | 关键要点 |
|----------|----------|----------|
| 价格区间 | 100-300元/晚、300-500元/晚 | 显示均价，不含清洁费/服务费 |
| 房型 | 整套出租、独立房间、合住房间 | 明确私密性等级 |
| 床型 | 大床、双床、多床 | 显示可住人数 |
| 设施 | WiFi、空调、洗衣机、厨房 | 勾选必有设施 |
| 特色 | 海景房、Loft、近地铁 | 标签化筛选 |

**【Rule】房源展示拦截规则**：
- **资质拦截**：未通过实名认证的房东房源不展示
- **评分拦截**：综合评分低于3.0分的房源降权展示
- **违规拦截**：近期有投诉记录的房源暂停展示

##### 1.1.4 房源详情查看

```
进入房源详情 ──▶ 浏览图片/视频 ──▶ 查看设施清单 ──▶ 阅读评价 ──▶ 查看位置 ──▶ 咨询房东
      │              │                  │              │            │
      ▼              ▼                  ▼              ▼            ▼
  基础信息展示    实拍图/VR看房      便利设施图标    真实住客评价   地图导航
```

**【话术】房源咨询标准话术**：
- 用户咨询房源："您好，我对您的房源很感兴趣，想确认一下入住时间是否可订？"
- 房东回复："您好，感谢您的关注！您选的日期可以预订，房间已为您保留24小时，请尽快下单确认。"

#### 1.2 系统处理流程

##### 1.2.1 房源排序机制

| 排序方式 | 算法逻辑 | 适用场景 |
|----------|----------|----------|
| 智能推荐 | 综合评分、销量、价格、距离 | 默认排序 |
| 价格从低到高 | 按每晚单价升序 | 预算敏感用户 |
| 好评优先 | 按评分从高到低 | 品质优先用户 |
| 距离优先 | 按与目的地距离排序 | 位置敏感用户 |

##### 1.2.2 房源质量评分

| 评分维度 | 权重 | 数据来源 |
|----------|------|----------|
| 住客评价 | 40% | 历史订单评价 |
| 房东服务 | 25% | 响应速度、确认率 |
| 房源设施 | 20% | 设施完整度、维护状态 |
| 位置交通 | 15% | 交通便利性、周边配套 |

### 2. 房东沟通

#### 2.1 沟通流程

##### 2.1.1 标准沟通流程

```
房客发起咨询 ──▶ 房东接收消息 ──▶ 房东回复 ──▶ 房客确认 ──▶ 达成意向 ──▶ 房客下单
      │              │              │            │            │
      ▼              ▼              ▼            ▼            ▼
  询问可订性/    APP推送通知    确认可订/    确认预订    进入预订
  特殊需求       +短信提醒       解答疑问     意向        流程
```

**【KCP】房东沟通关键控制点**：
- 房东必须在15分钟内响应咨询（工作时间）
- 房东响应率低于80%将触发预警
- 房东48小时未响应，系统自动关闭对话并推荐其他房源

##### 2.1.2 沟通内容规范

| 沟通场景 | 房客常见问题 | 房东标准回复 |
|----------|--------------|--------------|
| 可订性确认 | "8月10日-12日可以住吗？" | "可以预订，已为您保留24小时" |
| 入住人数 | "可以住4个人吗？" | "房源最多可住3人，超过人数需额外收费" |
| 特殊需求 | "可以带宠物吗？" | "抱歉，本房源不接受宠物入住" |
| 设施确认 | "有停车位吗？" | "小区内有收费停车位，10元/天" |
| 入住时间 | "可以提前入住吗？" | "正常入住时间14:00，如需提前请提前沟通" |

**【话术】房东沟通标准话术**：

**房客咨询房源**：
```
房客："您好，我想预订8月10日-12日的房间，请问还有房吗？"
房东："您好，感谢您的关注！您选的日期可以预订，目前房源充足。房间可容纳2人，配备独立卫浴和空调。请问您有什么特殊需求吗？"
```

**确认预订意向**：
```
房客："好的，我确定要订"
房东："好的，已为您保留24小时，请尽快在APP内完成预订。预订成功后我会发送入住指南给您。"
```

#### 2.2 多方对话机制

##### 2.2.1 对话参与方

| 参与方 | 角色职责 | 消息可见性 |
|--------|----------|------------|
| 房客 | 提出需求、确认细节 | 房客-房东对话双方可见 |
| 房东 | 回复咨询、确认预订 | 房客-房东对话双方可见 |
| 平台客服 | 介入纠纷、提供支持 | 仅在投诉/纠纷时介入 |

##### 2.2.2 消息类型

| 消息类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| 咨询消息 | 房客主动发起 | 房东15分钟内响应 |
| 系统通知 | 订单状态变更 | 自动推送 |
| 入住指南 | 预订成功后 | 房东发送/系统自动 |
| 紧急联系 | 入住遇到问题 | 平台客服介入 |

### 3. 预订确认

#### 3.1 预订流程

##### 3.1.1 标准预订流程

```
选择入住/退房日期 ──▶ 选择入住人数 ──▶ 确认订单信息 ──▶ 选择优惠券 ──▶ 提交订单 ──▶ 支付定金/全款
         │                  │                  │              │              │
         ▼                  ▼                  ▼              ▼              ▼
    日历选择器          成人/儿童数量      房源/价格/规则    可用优惠券列表   支付方式选择
```

**【话术】预订确认标准话术**：
- 预订前："订单提交后，房东有15分钟确认时间，超时未确认将自动退款"
- 预订成功："预订成功！房东将在15分钟内确认订单，请留意通知"
- 房东确认："房东已确认您的订单，入住指南已发送至您的手机"

##### 3.1.2 订单确认机制

| 确认方式 | 流程说明 | 时效要求 |
|----------|----------|----------|
| 自动确认 | 房东设置自动接单，订单即时确认 | 即时 |
| 手动确认 | 房东收到订单后手动确认 | 15分钟内 |
| 超时处理 | 房东超时未确认 | 自动取消并全额退款 |

**【Rule】预订拦截规则**：
- **超订拦截**：同一日期已被预订的房源，系统自动关闭该日期预订入口
- **房东资质拦截**：未完成实名认证/房源认证的房东，无法接受预订
- **信用拦截**：房客信用分低于400分，需支付全额押金

#### 3.2 价格与费用

##### 3.2.1 费用构成

| 费用项目 | 计算方式 | 说明 |
|----------|----------|------|
| 房费 | 每晚单价 × 入住天数 | 基础费用 |
| 清洁费 | 固定金额/次 | 退房后清洁费用 |
| 服务费 | 房费 × 服务费率（通常10%） | 平台服务费 |
| 押金 | 固定金额/按房费比例 | 可退，退房后返还 |

##### 3.2.2 价格展示规范

```
房源详情页 ──▶ 显示每晚单价 ──▶ 选择日期后 ──▶ 显示总价明细 ──▶ 确认支付
      │                           │                  │
      ▼                           ▼                  ▼
  "￥288/晚"                房费+清洁费+服务费    各项费用明细
```

### 4. 入住登记

#### 4.1 入住流程

##### 4.1.1 标准入住流程

```
房客到达房源 ──▶ 身份核验 ──▶ 签署入住协议 ──▶ 领取钥匙/密码 ──▶ 检查房间设施 ──▶ 确认入住
      │              │              │                │              │
      ▼              ▼              ▼                ▼              ▼
  按入住指南导航    身份证+人脸识别   电子协议签署     智能门锁密码   拍照记录初始状态
```

**【KCP】入住登记关键控制点**：
- 必须完成实名认证（身份证+人脸识别）
- 住客信息与预订人信息必须一致
- 入住协议必须电子签署并存档

##### 4.1.2 入住方式

| 入住方式 | 操作说明 | 适用场景 |
|----------|----------|----------|
| 自助入住 | 智能门锁密码/钥匙盒 | 房东不在本地 |
| 房东接待 | 房东现场交接 | 需要讲解设施使用 |
| 管家服务 | 专职管家接待 | 高端民宿 |

**【话术】入住接待标准话术**：

**自助入住**：
```
系统消息："您的入住密码为123456，有效期为入住期间。房源地址：XX小区X栋X单元XXX室，门禁密码：8888"
```

**房东接待**：
```
房东："您好，欢迎入住！我是房东张三，这是您的房间。WiFi密码在路由器上，空调遥控器在这里，有什么需要随时联系我。"
房客："好的，谢谢"
房东："祝您入住愉快！"
```

#### 4.2 身份核验

##### 4.2.1 核验流程

| 核验环节 | 核验内容 | 核验方式 |
|----------|----------|----------|
| 身份认证 | 身份证真实性 | OCR识别+公安库比对 |
| 人脸识别 | 人证一致性 | 活体检测+人脸比对 |
| 信息登记 | 住客信息存档 | 系统自动记录 |

**【Rule】身份核验拦截规则**：
- **人证不符拦截**：人脸识别与身份证照片不一致，禁止入住
- **黑名单拦截**：命中公安黑名单，自动报警并拒绝入住
- **未成年人拦截**：未满18周岁单独入住，需监护人陪同

### 6. 退房结算

#### 6.1 退房流程

##### 6.1.1 标准退房流程

```
房客整理物品 ──▶ 检查房间设施 ──▶ 归还钥匙 ──▶ 房东/系统验收 ──▶ 押金退还 ──▶ 订单完结
      │              │                  │              │            │
      ▼              ▼                  ▼              ▼            ▼
  清理垃圾/      拍照留存/        密码失效/      检查损坏/    原路退回/
  关闭电器       恢复入住状态      钥匙归还       清洁状况     余额退款
```

**【KCP】退房结算关键控制点**：
- 退房时间必须遵守约定（通常12:00前）
- 房间设施损坏必须有照片证据
- 押金退还必须在退房后24小时内完成

##### 6.1.2 退房方式

| 退房方式 | 操作说明 | 适用场景 |
|----------|----------|----------|
| 自助退房 | 房客自行离开，密码自动失效 | 智能门锁房源 |
| 房东验收 | 房东现场检查，确认无误后退房 | 需要当面交接 |
| 延迟退房 | 提前申请，支付额外费用 | 需要延迟离开 |

**【话术】退房标准话术**：

**自助退房**：
```
系统消息："退房成功！房间密码已失效。押金将在24小时内原路退回，请注意查收。期待您的再次入住！"
```

**房东验收**：
```
房东："您好，我来验收一下房间... 房间状况良好，没有损坏。押金将全额退还，感谢您的入住！"
房客："谢谢，房间住得很舒服"
房东："欢迎下次再来，祝您一路平安！"
```

#### 6.2 押金处理

##### 6.2.1 押金退还规则

| 情况 | 处理方式 | 时效 |
|------|----------|------|
| 无损坏/清洁正常 | 全额退还 | 24小时内 |
| 轻微损坏 | 协商赔偿金额，剩余退还 | 48小时内 |
| 严重损坏 | 扣除押金，不足部分追偿 | 7天内处理 |
| 物品丢失 | 按价赔偿 | 7天内处理 |

### 7. 评价反馈

#### 7.1 评价流程

##### 7.1.1 评价机制

```
订单完结 ──▶ 系统推送评价邀请 ──▶ 房客提交评价 ──▶ 房东回复评价 ──▶ 评价展示
    │              │                  │              │
    ▼              ▼                  ▼              ▼
 退房后24小时    APP推送+短信      评分+文字+      房东可回复
                                  图片/视频       解释说明
```

**【KCP】评价关键控制点**：
- 评价必须基于真实入住体验
- 双方互评后才公开显示
- 恶意评价可申请平台审核

##### 7.1.2 评价维度

| 评价维度 | 权重 | 评分标准 |
|----------|------|----------|
| 描述相符 | 25% | 房源与描述一致性 |
| 清洁卫生 | 25% | 房间清洁程度 |
| 房东服务 | 20% | 房东响应和服务态度 |
| 位置交通 | 15% | 交通便利性 |
| 性价比 | 15% | 价格合理性 |

#### 7.2 评价管理

##### 7.2.1 好评激励

| 评价等级 | 标准 | 房东激励 |
|----------|------|----------|
| 超赞房东 | 综合评分≥4.8，响应率≥90% | 流量加权、专属标识 |

| 新晋房东 | 首次接待完成且好评 | 新手流量扶持 |

### 8. 纠纷处理

#### 8.1 纠纷类型与判定

##### 8.1.1 纠纷类型定义

| 类型 | 定义 | 举证要求 | 处理时限 |
|------|------|----------|----------|
| 房源不符 | 实际房源与描述严重不符 | 照片/视频对比 | 24小时内 |
| 设施故障 | 关键设施无法正常使用 | 故障照片/视频 | 24小时内 |
| 卫生问题 | 房间清洁度不达标 | 照片/视频 | 24小时内 |
| 安全问题 | 安全隐患/骚扰等 | 照片/报警记录 | 2小时内 |
| 费用争议 | 额外收费/押金争议 | 聊天记录/订单 | 48小时内 |

**【Rule】纠纷处理拦截规则**：
- **虚假房源拦截**：核实房源虚假，永久下架并处罚房东
- **安全投诉拦截**：涉及人身安全的投诉，立即冻结房源并介入处理
- **恶意投诉拦截**：核实为恶意投诉，记录用户信用并限制投诉权限

##### 8.1.2 纠纷处理流程

```
房客发起投诉 ──▶ 平台接收审核 ──▶ 双方举证 ──▶ 平台判定 ──▶ 执行处理 ──▶ 完结归档
      │              │              │            │            │
      ▼              ▼              ▼            ▼            ▼
  APP内投诉/    初步判定类型    上传证据/      根据规则      退款/赔偿/
  客服电话                       陈述情况       做出判定      处罚房东
```

#### 8.2 处理标准

##### 8.2.1 退款标准

| 情况 | 退款标准 | 额外补偿 |
|------|----------|----------|
| 房源严重不符 | 全额退款+重新安排住宿 | 100元优惠券 |
| 设施无法使用 | 按影响程度部分退款 | 50元优惠券 |
| 卫生问题严重 | 全额退款或换房 | 清洁费退还 |
| 安全问题 | 全额退款+紧急安置 | 200元补偿 |

**【话术】纠纷处理标准话术**：

**房源不符投诉**：
```
房客："实际房源和图片完全不一样，卫生间很脏"
客服："非常抱歉给您带来不好的体验。请您上传一下实际房源的照片，我们立即为您处理。经核实属实，我们将为您全额退款并补偿100元优惠券。"
```
