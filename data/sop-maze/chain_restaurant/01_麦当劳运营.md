## 3. Objective

### 3.1 业务目标

| 目标维度 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| 服务质量 | 提供一致的顾客体验 | 顾客满意度 ≥ 90% |
| 运营效率 | 快速准确的服务 | 平均服务时间 ≤ 3分钟 |
| 食品安全 | 零食品安全事故 | 食品安全合规率 100% |
| 清洁卫生 | 维持高标准的清洁环境 | 清洁检查评分 ≥ 95分 |
| 员工培训 | 确保所有员工按标准操作 | 员工培训合格率 100% |

### 3.2 QSC&V 原则

麦当劳运营的核心原则：**QSC&V**
- **Q**uality（品质）：食品质量与制作标准
- **S**ervice（服务）：快速、友好、准确的服务
- **C**leanliness（清洁）：门店环境与个人卫生
- **V**alue（价值）：物超所值的顾客体验

## 4. Standard Operating Procedures

### 4.1 顾客接待流程

#### 4.1.1 迎宾服务

**Level 1: 顾客进店识别**
- 员工需在顾客进门后 3 秒内给予关注
- 保持微笑，目光接触

**Level 2: 问候语标准**
- 标准问候语："欢迎光临麦当劳！"
- 高峰时段可简化为点头微笑示意
- 特殊时段问候：
  - 早餐时段："早上好，欢迎光临！"
  - 节假日："节日快乐，欢迎光临！"

**Level 3: 引导服务**
- 询问："请问您是在这里用餐还是外带？"
- 引导顾客至自助点餐机或柜台
- 特殊顾客协助（老人、儿童、残障人士）

**Level 4: 排队管理**
- 当排队超过 5 人时，启动分流引导
- 主动推荐自助点餐："您可以使用自助点餐机，更加快捷"
- 提供菜单预览

**对话示例：**
```
顾客：[走进门店]
员工："欢迎光临麦当劳！请问您是在这里用餐还是外带？"
顾客："在这里吃。"
员工："好的，您可以选择自助点餐机或到柜台点餐。自助点餐现在有优惠哦！"
顾客："我去自助点餐吧。"
员工："好的，请往这边走，如有需要随时叫我。"
```

### 4.2 点餐服务流程

#### 4.2.1 柜台点餐

**Level 1: 接单确认**
- 员工："您好，请问要点什么？"
- 保持目光接触，身体前倾表示专注

**Level 2: 产品推荐**
- 根据时段推荐套餐
- 询问是否需要升级（大份/超值升级）
- 标准话术："我们的XX套餐今天有优惠，需要了解一下吗？"

**Level 3: 订单确认**
- 复述订单："您点的是XX套餐，饮料要可乐可以吗？"
- 确认特殊要求："汉堡要不要加酱？"
- 确认过敏原信息（如顾客询问）

**Level 4: 支付引导**
- 告知金额："一共XX元"
- 提供支付方式选择："现金、刷卡还是移动支付？"
- 打印小票并指引取餐位置

**对话示例：**
```
员工："您好，请问要点什么？"
顾客："我要一个巨无霸套餐。"
员工："好的，巨无霸套餐。饮料需要换成大杯吗？只需加2元。"
顾客："不用了，中杯就行。"
员工："好的，中杯可乐。需要加购派吗？今天苹果派第二个半价。"
顾客："加一个苹果派吧。"
员工："好的，您点的是：巨无霸套餐（中杯可乐）+ 苹果派，一共35元。现金还是扫码？"
顾客："扫码。"
员工："请扫这里。支付成功后请拿好小票，到那边取餐口等候，会叫您的号码。"
```

#### 4.2.2 自助点餐机辅助

**Level 1: 主动询问**
- 观察顾客在机器前犹豫时主动上前
- "您好，需要我帮您操作吗？"

**Level 2: 操作指导**
- 引导选择用餐方式（堂食/外带）
- 介绍分类导航
- 协助定制产品（去酱、加料等）

**Level 3: 支付协助**
- 指导选择支付方式
- 协助处理支付故障

**Level 4: 取餐指引**
- 告知取餐号码
- 指引取餐区域

### 4.3 出餐配餐流程

#### 4.3.1 厨房制作

**Level 1: 订单接收**
- 系统自动分配至相应工作站
- 屏幕显示订单详情和制作要求

**Level 2: 产品制作**
- 按标准配方和时间制作
- 关键控制点：
  - 汉堡组装顺序
  - 薯条炸制时间（3分钟）
  - 饮料配比标准

**Level 3: 质量检查**
- 外观检查：包装完整、标识正确
- 温度检查：热食温度 ≥ 60°C
- 特殊要求核对（去酱、加料等）

**Level 4: 传递至配餐区**
- 按订单号摆放
- 系统标记制作完成

#### 4.3.2 配餐叫号

**Level 1: 订单核对**
- 核对屏幕订单与小票
- 确认产品完整性

**Level 2: 产品组装**
- 按标准摆放：主食→配餐→饮料
- 配餐顺序：汉堡→薯条→饮料

**Level 3: 叫号服务**
- 清晰叫号："XX号，您的餐好了！"
- 重复叫号 2 次（间隔 10 秒）

**Level 4: 交付确认**
- 核对小票："您好，这是您点的XX套餐，请确认一下。"
- 提供必要餐具和调料
- 祝语："祝您用餐愉快！"

**对话示例：**
```
配餐员："125号，您的餐好了！"
顾客：[上前]
配餐员："您好，这是您点的巨无霸套餐和苹果派，请确认一下。"
顾客："对的。"
配餐员："这是您的餐具和番茄酱。巨无霸比较厚，建议这样拿[示范]。祝您用餐愉快！"
```

### 4.4 收银结账流程

#### 4.4.1 现金收银

**Level 1: 金额确认**
- 清晰报出应收金额
- 等待顾客付款

**Level 2: 收款验钞**
- 当面点清现金
- 使用验钞机验证大额纸币

**Level 3: 找零计算**
- 计算找零金额
- 按标准方式递送（纸币+硬币组合）

**Level 4: 小票交付**
- 打印并双手递送小票
- 指引取餐："请拿好小票到那边取餐，会叫您的号码。"

#### 4.4.2 电子支付

**Level 1: 支付方式确认**
- 询问："微信、支付宝还是刷卡？"
- 指引扫码或刷卡位置

**Level 2: 支付引导**
- 扫码支付："请扫屏幕上的二维码"
- 刷卡支付："请插卡/刷卡，按提示操作"

**Level 3: 支付确认**
- 等待系统确认支付成功
- 确认金额无误

**Level 4: 凭证交付**
- 打印小票（如顾客需要）
- 指引取餐

#### 4.4.3 退款/换货处理

**Level 1: 原因确认**
- 询问："请问是什么原因需要退款/换货呢？"
- 倾听并记录

**Level 2: 权限判断**
- 小额退款（<50元）：员工可直接处理
- 大额退款：需值班经理授权

**Level 3: 处理执行**
- 按系统流程操作退款
- 或重新制作产品

**Level 4: 道歉与补偿**
- 标准道歉语："非常抱歉给您带来不好的体验"
- 必要时提供优惠券或小食补偿

**对话示例：**
```
顾客："我点错了，想要退款。"
员工："非常抱歉给您带来不便。请问是哪一单呢？"
顾客：[出示小票]
员工："好的，我看到您点的是XX套餐。请问是什么原因需要退款呢？"
顾客："点多了，吃不完。"
员工："理解。这个退款需要经理授权，请稍等，我马上叫经理过来。"
[呼叫经理]
经理："您好，听说您需要退款？"
顾客："是的。"
经理："好的，我帮您处理。款项会在3-5个工作日内退回您的账户。这是您的小食券，下次来可以免费领一份薯条，感谢您的理解。"
```

### 4.5 顾客投诉处理

#### 4.5.1 投诉接收

**Level 1: 倾听与记录**
- 立即停下手中工作，专注倾听
- 保持眼神接触，适当点头
- 标准语："非常抱歉，请您详细说一下情况"

**Level 2: 情绪安抚**
- 表达同理心："我理解您的感受"
- 避免辩解，先处理情绪

**Level 3: 信息确认**
- 复述投诉内容确认理解正确
- 询问关键信息（订单号、时间、产品等）

**Level 4: 升级判断**
- 一般投诉：现场员工处理
- 严重投诉：立即升级至值班经理
- 食品安全投诉：立即升级至店长

#### 4.5.2 投诉处理

**Level 1: 方案提供**
- 根据投诉类型提供解决方案：
  - 产品质量问题：重新制作/退款
  - 服务问题：道歉+补偿
  - 等待时间过长：道歉+小食补偿

**Level 2: 权限内处理**
- 员工权限：小额补偿（优惠券、小食）
- 经理权限：全额退款、大额补偿

**Level 3: 执行解决**
- 立即执行承诺的解决方案
- 告知处理时间

**Level 4: 跟进确认**
- 解决后询问："请问这样处理您满意吗？"
- 记录投诉详情至系统

#### 4.5.3 投诉闭环

**Level 1: 感谢反馈**
- "感谢您告诉我们，这帮助我们改进"

**Level 2: 送别顾客**
- "期待您下次光临，我们会做得更好"

**Level 3: 内部通报**
- 填写投诉记录表
- 交接班时通报

**Level 4: 改进跟踪**
- 周会回顾投诉案例
- 制定改进措施

**对话示例：**
```
顾客："我等了20分钟了，餐还没好！"
员工："非常抱歉让您久等了！我马上帮您查一下。请问您的订单号是多少？"
顾客："128号！"
员工：[查看系统] "非常抱歉，您的订单因为系统故障被延迟了。这是我们的失误。我现在立即让厨房优先制作，2分钟内一定给您。另外送您一份薯条表示歉意，您看可以吗？"
顾客："好吧，快点。"
员工："一定！我这就去催。请您稍坐，好了我给您送过来。"
[2分钟后]
员工："让您久等了！这是您的套餐和赠送的薯条。再次抱歉，希望您用餐愉快。"
```

### 4.6 门店清洁标准

#### 4.6.1 用餐区清洁

**Level 1: 日常维护（每15分钟）**
- 巡视餐桌，清理空盘和垃圾
- 擦拭桌面污渍
- 补充调味品和纸巾

**Level 2: 餐位清洁（顾客离店后）**
- 清理桌面所有物品
- 喷洒清洁剂，擦拭桌面
- 检查并清洁座椅
- 清扫地面

**Level 3: 深度清洁（每2小时）**
- 清洁所有餐桌椅
- 清洁门窗玻璃
- 清洁自助点餐机屏幕
- 清洁垃圾桶及周边

**Level 4: 闭店清洁**
- 全面清洁所有区域
- 地面拖洗
- 消毒处理
- 检查并补充所有物料

#### 4.6.2 厨房清洁

**Level 1: 操作台清洁（每30分钟）**
- 清理操作台残渣
- 擦拭台面
- 清洁工具归位

**Level 2: 设备清洁（每班次）**
- 炸炉滤油/清洁
- 煎炉清洁
- 饮料机清洁
- 微波炉清洁

**Level 3: 器具清洁（每次使用后）**
- 餐具清洗消毒
- 工具清洗归位
- 抹布分类清洗

**Level 4: 深度清洁（每日闭店）**
- 全面清洁所有设备
- 地面清洁消毒
- 冷藏设备清洁
- 灭虫检查

#### 4.6.3 洗手间清洁

**Level 1: 定时检查（每30分钟）**
- 检查并补充洗手液、纸巾
- 清理垃圾
- 检查设施完好

**Level 2: 日常清洁（每2小时）**
- 清洁洗手台
- 清洁镜面
- 清洁马桶/便池
- 拖地

**Level 3: 消毒处理（每4小时）**
- 门把手消毒
- 水龙头消毒
- 马桶消毒

**Level 4: 深度清洁（每日）**
- 全面清洁消毒
- 检查并维修设施
- 补充所有耗材

#### 4.6.4 员工卫生

**Level 1: 个人卫生**
- 每日洗澡、刷牙
- 头发整洁（戴工作帽）
- 指甲修剪清洁
- 禁止佩戴首饰

**Level 2: 着装规范**
- 穿着干净制服
- 佩戴名牌
- 穿防滑工作鞋

**Level 3: 手部卫生**
- 上岗前洗手消毒
- 接触生食后洗手
- 如厕后洗手
- 每小时洗手消毒

**Level 4: 健康监测**
- 每日健康自查
- 患病及时报告
- 伤口包扎处理
- 定期健康体检
