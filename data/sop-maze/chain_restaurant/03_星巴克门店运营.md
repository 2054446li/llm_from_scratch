## 3. Objective

### 业务目标

| 目标维度 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| **顾客体验** | 打造"第三空间"体验，让每位顾客感受到归属感和连接 | 顾客满意度评分 >= 4.5/5 |
| **咖啡品质** | 确保每一杯咖啡符合星巴克全球统一品质标准 | 品质一致性评分 >= 95% |
| **服务效率** | 高峰期单杯饮品制作时间控制在标准范围内 | 平均出品时间 <= 3分钟 |
| **会员增长** | 提升星享卡会员活跃度和星礼卡销售 | 会员消费占比 >= 60% |
| **客诉管理** | 及时有效解决顾客投诉，挽回顾客信任 | 客诉解决率 >= 98% |
| **运营标准** | 维持门店清洁、安全、舒适的运营环境 | 运营检查评分 >= 90分 |

### 核心理念

- **第三空间 (Third Place)**：介于家庭和工作场所之间的社交空间，提供舒适、放松的环境
- **咖啡文化 (Coffee Culture)**：传承咖啡制作工艺，分享咖啡知识
- **连接 (Connection)**：与顾客建立真诚的人际连接
- **卓越运营 (Operational Excellence)**：标准化流程确保品质一致性

## 4. Standard Operating Procedures

### 4.1 顾客接待与点单 (Connect & Order)

#### 4.1.1 顾客进店问候
- **4.1.1.1** 顾客进店后3秒内主动问候
  - 使用标准问候语："您好，欢迎光临星巴克！"
  - 保持微笑，眼神接触
  - 身体姿态：站立端正，双手自然放置或轻握于身前
- **4.1.1.2** 识别熟客并个性化问候
  - 记住常客的姓名和常点饮品
  - 使用顾客姓氏称呼："张先生，早上好！今天还是大杯拿铁吗？"
- **4.1.1.3** 高峰期排队管理
  - 引导顾客有序排队
  - 提供菜单预览建议
  - 预估等待时间告知

#### 4.1.2 点单服务
- **4.1.2.1** 主动询问需求
  - "请问今天想喝点什么？"
  - 推荐当季新品或特色饮品
  - 询问杯型偏好（中杯/大杯/超大杯）
- **4.1.2.2** 饮品定制确认
  - 温度选择：热饮/去冰/少冰/正常冰
  - 浓缩咖啡份数确认
  - 糖浆口味和泵数确认
  - 牛奶类型：全脂/脱脂/豆奶/燕麦奶/杏仁奶
  - 特殊要求：加奶油、焦糖淋酱、可可粉等
- **4.1.2.3** 复述订单确认
  - 完整复述："大杯去冰焦糖玛奇朵，换燕麦奶，加一份浓缩，对吗？"
  - 确认后在杯身上准确标记
  - 告知预计等待时间

#### 4.1.3 收银结账
- **4.1.3.1** 确认支付方式
  - 询问："请问怎么支付？"
  - 支持方式：现金、银行卡、移动支付、星礼卡、星享卡积分
- **4.1.3.2** 会员识别与积分
  - 主动询问："有星享卡吗？可以积分哦"
  - 协助顾客出示会员码
  - 确认积分到账
- **4.1.3.3** 找零与票据
  - 双手递送找零和发票
  - 感谢语："收您XX元，找您XX元，谢谢！"

### 4.2 咖啡制作流程 (Brew & Craft)

#### 4.2.1 咖啡豆研磨与萃取
- **4.2.1.1** 咖啡豆新鲜度检查
  - 开封后咖啡豆使用期限：7天内
  - 研磨后咖啡粉使用期限：30分钟内
  - 过期咖啡豆/粉立即废弃
- **4.2.1.2** 研磨标准
  - 根据饮品类型选择研磨度
  - 意式浓缩：细研磨
  - 滴滤咖啡：中研磨
  - 法压壶：粗研磨
- **4.2.1.3** 意式浓缩萃取标准
  - 单份浓缩：7-9克咖啡粉，萃取时间18-23秒，出品量约30ml
  - 双份浓缩：14-18克咖啡粉，萃取时间18-23秒，出品量约60ml
  - 萃取状态：流速稳定，油脂(Crema)呈金黄色

#### 4.2.2 牛奶蒸煮与打发
- **4.2.2.1** 牛奶温度标准
  - 热饮牛奶温度：60-70°C（手感微烫但可短暂触碰）
  - 使用温度计或手感经验判断
- **4.2.2.2** 打发技术
  - 蒸汽棒角度：与牛奶液面呈45度角
  - 进气阶段：发出"嘶嘶"声，持续3-5秒
  - 打绵阶段：蒸汽棒深入液面下，形成漩涡
  - 奶泡质地：细腻光滑，无大气泡
- **4.2.2.3** 牛奶类型处理
  - 全脂奶：标准打发，奶泡丰富
  - 脱脂奶：打发更快，奶泡较轻盈
  - 豆奶/燕麦奶：降低蒸汽压力，避免蛋白质变性

#### 4.2.3 饮品调制与拉花
- **4.2.3.1** 饮品配方标准
  - 严格按配方比例调制
  - 使用标准量杯和计量工具
  - 糖浆泵数：中杯3泵/大杯4泵/超大杯5泵
- **4.2.3.2** 拉花标准
  - 基础图案：心形、叶子、郁金香
  - 拉花要求：图案居中，线条清晰
  - 无法拉花时：使用勺子控制奶泡，保持表面平整
- **4.2.3.3** 出品前检查
  - 杯口清洁，无奶渍
  - 杯盖匹配正确（热盖/冷盖）
  - 配件齐全（搅拌棒、糖包、纸巾等）

### 4.3 出品与交付 (Deliver & Delight)

#### 4.3.1 吧台叫号
- **4.3.1.1** 饮品完成后叫号
  - 清晰报出："大杯拿铁好了！"
  - 高峰期使用顺序号："23号订单好了！"
- **4.3.1.2** 饮品确认
  - 顾客取餐时再次确认饮品
  - "这是您的大杯去冰焦糖玛奇朵，请慢用！"
- **4.3.1.3** 双手递送
  - 双手将饮品递给顾客
  - 热饮提醒："小心烫！"

#### 4.3.2 顾客关怀
- **4.3.2.1** 自助区引导
  - 指引糖包、奶精、搅拌棒位置
  - 主动询问是否需要额外配料
- **4.3.2.2** 堂食服务
  - 询问："请问在这里享用吗？"
  - 提供陶瓷杯使用
  - 主动提供温水或柠檬水
- **4.3.2.3** 离店致谢
  - 顾客离店时主动道别："谢谢光临，请慢走！"
  - 邀请再次光临："期待下次见到您！"

### 4.4 会员与星礼卡服务 (Rewards & Cards)

#### 4.4.1 星享卡会员服务
- **4.4.1.1** 会员注册引导
  - 介绍会员权益：积分累积、生日赠饮、专属优惠
  - 协助下载APP并注册
  - 首次注册赠送优惠券
- **4.4.1.2** 积分累积与查询
  - 每笔消费前主动扫码积分
  - 告知当前积分余额
  - 提醒积分兑换选项
- **4.4.1.3** 会员等级维护
  - 玉星、金星等级权益说明
  - 提醒等级到期时间
  - 保级建议

#### 4.4.2 星礼卡销售与管理
- **4.4.2.1** 星礼卡推荐
  - 介绍卡面设计（节日限定、常规款）
  - 说明使用范围：全国通用、线上线下通用
  - 推荐充值金额：100/200/500元
- **4.4.2.2** 星礼卡激活与充值
  - 现场激活并绑定APP
  - 充值后确认余额
  - 提供礼品包装服务（如需要）
- **4.4.2.3** 星礼卡售后
  - 遗失卡处理：凭购买凭证和绑定信息挂失
  - 余额查询服务
  - 过期卡延期处理

### 4.5 客诉处理 (Recover & Resolve)

#### 4.5.1 LATTE处理法则
- **4.5.1.1** L - Listen（倾听）
  - 停下手中工作，专注倾听
  - 保持眼神接触，点头示意
  - 不打断顾客陈述
- **4.5.1.2** A - Acknowledge（致歉）
  - 真诚道歉："非常抱歉给您带来不好的体验"
  - 表达理解："我理解您的感受"
  - 不辩解、不推卸责任
- **4.5.1.3** T - Take Action（行动）
  - 立即采取行动解决问题
  - 询问顾客期望的解决方案
  - 权限范围内快速决策
- **4.5.1.4** T - Thank（感谢）
  - 感谢顾客反馈："感谢您告诉我们"
  - 邀请再次光临
- **4.5.1.5** E - Encourage（鼓励）
  - 鼓励顾客继续提出意见
  - 告知改进措施

#### 4.5.2 常见问题处理
- **4.5.2.1** 饮品质量问题
  - 立即重新制作
  - 询问具体不满意之处
  - 提供额外补偿（优惠券、升杯等）
- **4.5.2.2** 服务投诉
  - 向值班经理汇报
  - 由经理出面道歉
  - 记录事件详情
- **4.5.2.3** 等待时间过长
  - 主动告知预计等待时间
  - 提供等候饮品（温水/试饮）
  - 适当补偿（升杯、优惠券）
- **4.5.2.4** 商品/食品问题
  - 立即更换或退款
  - 检查库存商品质量
  - 记录批次信息

#### 4.5.3 升级处理
- **4.5.3.1** 当班经理介入
  - 员工无法处理时立即呼叫经理
  - 经理拥有更高赔偿权限
- **4.5.3.2** 顾客服务热线
  - 提供400客服电话
  - 协助顾客记录投诉编号
- **4.5.3.3** 书面投诉处理
  - 记录顾客联系方式
  - 24小时内回访
  - 书面回复处理结果

### 4.6 门店运营与清洁 (Maintain & Clean)

#### 4.6.1 设备维护
- **4.6.1.1** 意式咖啡机
  - 每日开店：预热15分钟，检查水压、蒸汽压力
  - 每2小时：反冲洗清洁冲煮头
  - 每日闭店：深度清洁，包括冲煮头、蒸汽棒、滴水盘
  - 每周：更换滤水器，检查磨豆机刀片
- **4.6.1.2** 磨豆机
  - 每日清洁豆仓和出粉口
  - 定期校准研磨度
  - 检查刀片磨损情况
- **4.6.1.3** 制冰机与冰箱
  - 每日检查温度：冷藏2-4°C，冷冻-18°C以下
  - 每周清洁内部
  - 每月除霜和深度消毒

#### 4.6.2 环境卫生
- **4.6.2.1** 吧台区域
  - 随时保持整洁，无积水、无咖啡渍
  - 物料摆放整齐，标签朝外
  - 每30分钟擦拭一次台面
- **4.6.2.2** 顾客区域
  - 每15分钟巡场，清理桌面垃圾
  - 及时补充糖包、奶精、纸巾
  - 座椅归位，地面清洁
- **4.6.2.3** 洗手间
  - 每30分钟检查清洁
  - 补充洗手液、纸巾
  - 保持无异味、地面干燥
- **4.6.2.4** 外场区域
  - 户外座椅清洁
  - 遮阳伞和绿植维护
  - 地面无烟头、无垃圾

#### 4.6.3 库存管理
- **4.6.3.1** 原料盘点
  - 每日闭店盘点：牛奶、咖啡豆、糖浆等
  - 记录使用量，预测次日需求
  - 临期物料优先使用（FIFO原则）
- **4.6.3.2** 订货管理
  - 根据销售数据和销售预测订货
  - 安全库存：确保3天用量
  - 紧急补货流程
- **4.6.3.3** 物料储存
  - 咖啡豆：密封避光，室温保存
  - 牛奶：冷藏，先进先出
  - 糖浆：常温避光，开封后标注日期

## 5. Rule层（系统约束）

### 5.1 品质规则

| 规则编号 | 规则名称 | 规则描述 | 违规后果 |
|---------|---------|---------|---------|
| Q-001 | 新鲜度规则 | 开封咖啡豆7天内使用，研磨咖啡粉30分钟内使用 | 过期物料废弃，记录损耗 |
| Q-002 | 温度规则 | 热饮牛奶温度60-70°C，饮品出品温度不低于55°C | 重新制作 |
| Q-003 | 萃取规则 | 意式浓缩萃取时间18-23秒，Crema呈金黄色 | 调整研磨度，不合格废弃 |
| Q-004 | 配方规则 | 严格按标准配方制作，不得擅自更改 | 重新培训，多次违规警告 |
| Q-005 | 清洁规则 | 蒸汽棒每次使用后立即擦拭，防止奶垢积累 | 立即清洁，设备维护 |

### 5.2 服务规则

## 8. Evaluation

### 8.1 评估维度与指标

| 评估维度 | 权重 | 关键指标 | 目标值 | 测量方式 |
|---------|-----|---------|-------|---------|
| **顾客满意度** | 25% | NPS评分 | >= 50 | 月度调研 |
| | | 顾客满意度评分 | >= 4.5/5 | 实时评价 |
| **咖啡品质** | 25% | 神秘顾客评分 | >= 90/100 | 季度审核 |
| | | 饮品一致性 | >= 95% | 抽检 |
| **服务效率** | 20% | 平均出品时间 | <= 3分钟 | 系统统计 |
| | | 高峰期等待时间 | <= 5分钟 | 系统统计 |
| **会员运营** | 15% | 会员消费占比 | >= 60% | 销售数据 |
| | | 星礼卡销售额 | 环比增长5% | 销售数据 |
| **运营标准** | 15% | 运营检查评分 | >= 90分 | 月度检查 |
| | | 客诉解决率 | >= 98% | 客诉系统 |

### 8.2 评估方法

#### 8.2.1 神秘顾客 (Mystery Shopper)
- 频率：每月1-2次
- 评估内容：
  - 问候及时性
  - 点单流程规范性
  - 饮品品质
  - 服务礼仪
  - 离店送别
- 评分标准：100分制，90分以上优秀，80-90分良好，70-80分需改进，70分以下不合格

#### 8.2.2 实时监控
- 视频监控抽查
- 服务流程合规性检查
- 顾客反馈实时收集

#### 8.2.3 数据分析
- 销售数据分析
- 客诉数据分析
- 会员活跃度分析

### 8.3 改进机制

| 评估结果 | 改进措施 |
|---------|---------|
| 优秀 (>=90分) | 表彰奖励，经验分享 |
| 良好 (80-89分) | 针对性培训，持续观察 |
| 需改进 (70-79分) | 强制培训，经理辅导 |
| 不合格 (<70分) | 重新培训，绩效面谈 |

### 8.4 持续优化

- **月度回顾**：每月运营数据分析，识别改进点
- **季度培训**：根据评估结果更新培训内容
- **年度审计**：全面运营审计，更新SOP标准
- **顾客反馈循环**：建立顾客反馈收集-分析-改进闭环
