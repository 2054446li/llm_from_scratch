## Objective

1. **响应速度目标**：客服热线接通率 ≥ 95%，平均等待时间 ≤ 30秒；在线客服首次响应时间 ≤ 60秒
2. **问题解决目标**：首次解决率 ≥ 85%，顾客满意度 ≥ 4.5分（5分制）
3. **投诉处理目标**：一般投诉24小时内解决，紧急投诉4小时内响应，重大投诉1小时内升级
4. **服务一致性目标**：全渠道服务标准统一，确保顾客在任何触点获得一致体验
5. **效率优化目标**：通过标准化流程和知识库建设，提升客服人均处理效率 ≥ 20%
6. **品牌保护目标**：投诉升级率 ≤ 5%，负面舆情及时处置率 100%

## Standard Operating Procedures

### 一、顾客咨询处理

#### 1.1 咨询分类与响应标准

```
咨询类型结构：
├── 产品咨询
│   ├── 菜单信息（新品、价格、营养成分）
│   ├── 供应时间（早餐、正餐、夜宵时段）
│   └── 过敏原信息
├── 门店咨询
│   ├── 营业时间
│   ├── 地址导航
│   ├── 停车信息
│   └── 服务设施（WiFi、插座、儿童区）
├── 活动咨询
│   ├── 优惠活动
│   ├── 优惠券使用
│   └── 联名活动
├── 支付咨询
│   ├── 支付方式
│   ├── 发票开具
│   └── 退款进度
└── 会员咨询
    ├── 会员权益
    ├── 积分规则
    └── 等级升级
```

#### 1.2 咨询处理流程

| 步骤 | 操作内容 | 时效要求 | 质量标准 |
|------|----------|----------|----------|
| 1 | 热情问候，确认顾客身份 | 5秒内 | 使用标准问候语 |
| 2 | 倾听需求，准确理解问题 | - | 不打断顾客，适时确认 |
| 3 | 查询知识库/系统，获取信息 | 30秒内 | 信息准确、完整 |
| 4 | 清晰解答，提供解决方案 | - | 语言简洁，避免术语 |
| 5 | 确认顾客理解，询问是否还有其他问题 | - | 确保无遗漏 |
| 6 | 礼貌结束，邀请评价 | - | 标准结束语 |

#### 1.3 常见咨询应答模板

**新品咨询**
```
顾客：你们最近有什么新品？
客服：您好！我们最近推出了[新品名称]，主要特色是[特点描述]，
      售价[价格]元。目前[供应状态]。您可以在[渠道]购买，
      需要我为您详细介绍吗？
```

**营业时间咨询**
```
顾客：你们几点开门？
客服：您好！肯德基[具体门店]的营业时间是[时间]，
      早餐供应时间为[早餐时段]，正餐从[时间]开始。
      建议您通过肯德基APP查看附近门店的实时营业状态。
```

### 二、投诉处理流程

#### 2.1 投诉分级标准

| 级别 | 定义 | 响应时效 | 解决时效 | 升级条件 |
|------|------|----------|----------|----------|
| **一般投诉** | 轻微服务瑕疵、小额退款诉求 | 30分钟内 | 24小时 | 顾客要求升级 |
| **紧急投诉** | 食品安全疑虑、服务态度恶劣 | 15分钟内 | 4小时 | 涉及媒体/监管 |
| **重大投诉** | 群体性事件、严重食安事故、媒体曝光 | 5分钟内 | 1小时 | 自动升级高管 |

#### 2.2 投诉处理步骤

##### 第一层：投诉接收与记录

| 步骤 | 操作要点 | 话术示例 |
|------|----------|----------|
| 1. 情绪安抚 | 表达同理心，承认顾客感受 | "非常理解您的心情，遇到这样的情况确实让人不愉快" |
| 2. 信息记录 | 5W2H原则（何时、何地、何人、何事、为何、如何、多少） | 完整记录，复述确认 |
| 3. 初步判断 | 评估严重程度和紧急性 | 根据描述判断分级 |
| 4. 承诺跟进 | 明确告知处理时效和方式 | "我会在[时间]前给您回复，我的工号是[XXX]" |

##### 第二层：调查与方案制定

```
调查流程：
┌─────────────────────────────────────────────────────────┐
│ 1. 核实订单/消费记录                                    │
│ 2. 联系涉事门店/人员了解情况                            │
│ 3. 调取监控（如涉及）                                   │
│ 4. 分析责任归属                                         │
│ 5. 制定补偿方案（参考补偿标准）                         │
│ 6. 内部审批（重大投诉需主管批准）                       │
└─────────────────────────────────────────────────────────┘
```

##### 第三层：方案执行与闭环

| 步骤 | 操作内容 | 注意事项 |
|------|----------|----------|
| 1 | 联系顾客，说明调查结果 | 客观陈述，不推诿责任 |
| 2 | 提出解决方案，征询意见 | 提供选项，尊重顾客选择 |
| 3 | 执行补偿/整改措施 | 即时执行，不拖延 |
| 4 | 确认顾客满意，结案 | 明确告知已结案 |
| 5 | 24-48小时内回访 | 确认无后续问题 |

#### 2.3 补偿标准参考 `[需内部资料确认]`

| 投诉类型 | 补偿方案 | 审批权限 |
|----------|----------|----------|
|  minor服务瑕疵 | 优惠券/小食赠送 | 客服专员 |
| 餐品质量问题 | 退款+等额优惠券 | 客服主管 |
| 服务态度投诉 | 退款+补偿券+道歉 | 客服主管 |
| 食品安全疑虑 | 全额退款+医疗检查费+补偿 | 区域经理 |
| 严重食安事故 | 依法赔偿+公关处理 | 总部法务/公关 |

#### 4.2 食品安全事件处理

##### 4.2.1 异物投诉处理

| 步骤 | 操作内容 | 关键要点 |
|------|----------|----------|
| 1 | 立即表达重视和歉意 | "食品安全是我们最重视的问题" |
| 2 | 详细记录异物描述、购买信息 | 请顾客拍照留存 |
| 3 | 通知涉事门店封存同批次产品 | 防止问题扩大 |
| 4 | 启动内部调查（供应链→门店） | 追溯问题源头 |
| 5 | 与顾客协商解决方案 | 退款+补偿+必要时医疗检查 |
| 6 | 48小时内反馈调查结果 | 无论结果如何，及时沟通 |

##### 4.2.2 食后不适处理

```
紧急处理流程：
┌─────────────────────────────────────────────────────────┐
│ 1. 立即表达关切，询问当前身体状况                       │
│ 2. 建议就医并保留诊断证明（如需要）                     │
│ 3. 记录：食用产品、食用时间、症状出现时间、症状描述     │
│ 4. 1小时内上报食品安全部门                              │
│ 5. 主动承担合理医疗费用（凭票据）                       │
│ 6. 配合监管部门调查                                     │
│ 7. 48小时内回访顾客健康状况                             │
└─────────────────────────────────────────────────────────┘
```

**注意**：所有食品安全投诉必须立即上报，不得隐瞒或拖延。

### 六、紧急事件处理

#### 6.1 紧急事件分类

| 级别 | 事件类型 | 示例 |
|------|----------|------|
| **A级-危机事件** | 重大食品安全事故、群体性中毒、媒体曝光负面 | 多人食后不适、产品含危险异物 |
| **B级-紧急事件** | 门店安全事故、严重服务冲突、网络舆情 | 门店火灾、顾客与员工冲突、热搜负面 |
| **C级-突发事件** | 系统故障、供应链中断、恶劣天气影响 | POS系统瘫痪、配送大面积延误 |

#### 6.2 紧急事件响应流程

##### A级危机事件

```
响应时间线：
0-5分钟：   接到报告 → 立即上报客服总监+公关部+法务部
5-15分钟：  成立危机小组 → 收集事件信息 → 初步评估影响
15-30分钟： 制定初步应对策略 → 准备对外话术 → 上报总部
30-60分钟： 对外发声（如需要）→ 持续监控舆情 → 多部门协同处置
持续：      每2小时更新进展 → 事件复盘 → 改进措施
```

##### B级紧急事件

| 时间节点 | 处理动作 | 责任人 |
|----------|----------|--------|
| 即时 | 记录并上报主管 | 一线客服 |
| 15分钟内 | 主管评估并制定方案 | 客服主管 |
| 1小时内 | 联系顾客/门店，执行方案 | 指定专员 |
| 4小时内 | 问题解决，内部通报 | 客服主管 |
| 24小时内 | 事件复盘 | 客服经理 |

##### C级突发事件

```
系统故障处理示例：
```

1. **响应时效保障**：热线平均等待≤30秒，在线客服首次响应≤60秒，投诉处理按分级时效执行

6. **升级机制**：明确升级条件和路径，重大事件不隐瞒、不拖延
7. **持续改进**：定期分析投诉数据，识别服务改进点，推动产品和流程优化
8. **合规安全**：严格遵守消费者权益保护法规和信息安全要求
