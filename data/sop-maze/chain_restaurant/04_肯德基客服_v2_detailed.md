## Objective

本文档旨在规范肯德基客服服务体系的标准操作流程，确保顾客问题能够得到及时、专业、有效的解决，同时建立完善的投诉处理和危机应对机制。适用于所有肯德基客服相关服务场景。

**核心目标：**
- 提供多渠道、便捷的客户服务入口
- 快速准确识别和分类顾客问题
- 智能与人工服务高效协同
- 建立公平的投诉处理和补偿机制
- 确保食品安全事件得到及时有效处置
- 持续优化服务质量，提升顾客满意度和品牌忠诚度

**行业基准数据参考：**

| 指标类别 | 行业基准 | 肯德基目标 | 数据来源 |

| 首次解决率 | ≥75% | ≥85% | 客服行业报告 |
| 顾客满意度 | ≥4.0/5 | ≥4.5/5 | 百胜中国财报 |

## Standard Operating Procedures

### 1. 问题分类

#### 1.1 一级分类

##### 1.1.1 分类说明

| 分类代码 | 分类名称 | 占比估算 | 处理时效 |
|---------|---------|---------|---------|
| A | 产品咨询 | 25% | 即时 |
| B | 订单问题 | 30% | 即时-24h |
| C | 投诉处理 | 15% | 24h-72h |
| D | 会员服务 | 18% | 即时-48h |
| E | 食品安全 | 8% | 即时-4h |
| F | 紧急事件 | 4% | 即时-1h |

##### 1.1.2 分类路由规则

```
顾客输入 → 意图识别 → 一级分类 → 二级分类 → 技能组匹配 → 客服分配
```

#### 1.2 二级分类（订单问题示例）

| 二级分类 | 具体问题 | 处理优先级 |
|---------|---------|-----------|
| B1-配送问题 | 超时未送达、配送地址错误、骑手联系不上 | P0-紧急 |
| B2-餐品问题 | 餐品缺失、错送、质量问题、温度不足 | P0-紧急 |
| B3-订单修改 | 地址修改、商品增减、取消订单 | P1-高 |
| B4-门店服务 | 等餐过长、服务态度、门店拒单 | P1-高 |
| B5-支付问题 | 支付失败、重复扣款、发票开具 | P2-中 |

#### 1.3 问题分级标准

| 优先级 | 定义 | 响应时效 | 处理时效 | 升级条件 |
|-------|------|---------|---------|---------|
| P0-紧急 | 食品安全/食后不适/重大财产损失 | 5分钟 | 1-4小时 | 自动升级 |
| P1-高 | 配送超时/餐品质量问题/服务态度 | 15分钟 | 24小时 | 超时升级 |
| P2-中 | 一般订单问题/会员服务 | 30分钟 | 48小时 | 投诉升级 |
| P3-低 | 产品咨询/活动咨询 | 即时 | 即时 | 不自动升级 |

### 2. 智能客服

#### 2.1 智能客服能力

| 能力类型 | 功能说明 | 覆盖场景 |
|---------|---------|---------|
| 意图识别 | 理解顾客问题类型 | 全场景 |
| 知识问答 | 基于知识库回答问题 | 菜单/活动/门店咨询 |
| 订单查询 | 关联顾客订单信息 | 订单相关问题 |
| 自助办理 | 引导顾客自助操作 | 优惠券使用/积分查询 |
| 智能推荐 | 推荐解决方案 | 常见问题处理 |

#### 2.2 智能客服流程

```
顾客输入 ──▶ 意图识别 ──▶ 知识匹配 ──▶ 方案输出
                │              │
                ▼              ▼
           置信度低        无匹配知识
                │              │
                └──────┬───────┘
                       ▼
                  转人工客服
```

#### 2.3 智能客服转人工条件

| 转人工场景 | 触发条件 |
|-----------|---------|
| 意图不明 | 连续3次无法识别顾客意图 |
| 知识缺失 | 问题不在知识库范围内 |
| 顾客要求 | 顾客明确要求人工服务 |
| 情绪识别 | 检测到顾客负面情绪（愤怒/不满） |
| 复杂问题 | 涉及多部门协调/投诉升级 |
| 食品安全 | 涉及食品安全/食后不适 |

#### 3.1 人工客服渠道

| 渠道 | 服务时间 | 平均等待 | 适用场景 |
|-----|---------|---------|---------|
| 在线客服 | 7×24小时 | 1-3分钟 | 一般问题咨询 |
| 电话客服 | 7×24小时 | ≤30秒 | 紧急/复杂问题 |
| 微信公众号 | 7:00-23:00 | 2-5分钟 | 会员服务/活动咨询 |
| APP内客服 | 7×24小时 | 1-3分钟 | 订单相关问题 |
| 门店现场 | 营业时间 | 即时 | 到店问题处理 |

#### 3.2 人工接入流程

```
顾客请求 ──▶ 排队等待 ──▶ 客服分配 ──▶ 问题沟通 ──▶ 方案处理 ──▶ 服务结束
                │            │            │            │
                ▼            ▼            ▼            ▼
            队列状态      技能匹配      知识推荐      满意度评价
            预计等待      历史关联      权限判断      工单归档
```

#### 3.3 客服分配策略

| 分配维度 | 策略说明 |
|---------|---------|
| 技能匹配 | 根据问题类型分配对应技能组（订单/投诉/会员） |
| 负载均衡 | 优先分配给当前负载低的客服 |
| 历史关联 | 优先分配给服务过该顾客的客服 |
| 语言匹配 | 匹配顾客使用的语言/方言 |
| 优先级 | 会员等级高的顾客优先接入 |

#### 3.4 客服处理规范

| 环节 | 规范要求 | 话术示例 |
|-----|---------|---------|
| 开场白 | 问候语+工号+询问需求 | "您好，肯德基客服中心，工号9527为您服务，请问有什么可以帮您？" |
| 问题确认 | 复述问题+确认理解 | "了解到您的问题是【配送超时】，订单号【XXXXXX】，对吗？" |
| 方案提供 | 清晰说明+操作指引 | "为您查询到订单状态...解决方案有..." |
| 处理执行 | 即时处理/建单跟进 | "我现在就为您处理..." |
| 结束语 | 确认解决+满意度引导 | "问题已为您解决，请对本次服务评价，感谢您的来电！" |

### 4. 投诉处理

#### 4.1 投诉类型

| 投诉类型 | 定义 | 处理部门 |
|---------|------|---------|
| 服务投诉 | 对客服/门店服务不满 | 客服质检/门店管理 |
| 产品投诉 | 对餐品质量/口味不满 | 品控部门 |
| 配送投诉 | 对配送服务不满 | 配送管理 |
| 食安投诉 | 食品安全相关问题 | 食品安全部门 |
| 会员投诉 | 对会员权益/积分不满 | 会员运营 |

#### 4.2 投诉处理流程

```
投诉受理 ──▶ 分级定责 ──▶ 调查核实 ──▶ 方案制定 ──▶ 沟通确认 ──▶ 执行闭环
    │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼
  即时响应    责任判定    证据收集    补偿方案    顾客确认
  情绪安抚    系统标记    多方核实    审批流程    结果反馈
```

#### 4.3 投诉分级处理

| 投诉级别 | 判定标准 | 处理时效 | 审批层级 |
|---------|---------|---------|---------|
| 一般投诉 | 普通顾客首次投诉 | 24小时 | 客服主管 |
| 重要投诉 | 会员顾客/多次投诉 | 12小时 | 客服经理 |
| 重大投诉 | 媒体关注/监管部门转办 | 4小时 | 区域总监 |
| 危机投诉 | 群体性食安事件/严重事故 | 1小时 | 危机小组 |

#### 4.4 投诉补偿标准

| 投诉类型 | 轻微 | 一般 | 严重 |
|---------|------|------|------|
| 配送延迟 | 小食券¥5-10 | 套餐券¥20-30 | 全额退款+等额券 |
| 餐品问题 | 小食券¥10 | 退款+券¥20 | 退款+券¥50+道歉 |
| 服务态度 | 券¥10 | 券¥20+道歉 | 券¥50+书面道歉 |
| 食品安全 | 退款+券¥50 | 退款+券¥100+检查费 | 依法赔偿+公关处理 |

### 5. 食品安全事件处理

#### 5.1 食安事件分类

| 级别 | 事件类型 | 示例 |
|------|----------|------|
| **A级-危机事件** | 重大食品安全事故、群体性中毒 | 多人食后不适、产品含危险异物 |
| **B级-紧急事件** | 个体食后不适、异物投诉 | 顾客投诉腹泻、发现异物 |
| **C级-一般事件** | 品质瑕疵、温度问题 | 餐品凉了、口感异常 |

#### 5.2 食安事件响应流程

##### A级危机事件

```
响应时间线：
0-5分钟：   接到报告 → 立即上报客服总监+食品安全部+公关部
5-15分钟：  成立危机小组 → 收集事件信息 → 初步评估影响
15-30分钟： 制定初步应对策略 → 准备对外话术 → 上报总部
30-60分钟： 对外发声（如需要）→ 持续监控舆情 → 多部门协同处置
持续：      每2小时更新进展 → 事件复盘 → 改进措施
```

##### B级紧急事件

| 时间节点 | 处理动作 | 责任人 |
|----------|----------|--------|
| 即时 | 记录并上报主管 | 一线客服 |
| 15分钟内 | 主管评估并制定方案 | 客服主管 |
| 1小时内 | 联系顾客/门店，执行方案 | 指定专员 |
| 4小时内 | 问题解决，内部通报 | 客服主管 |
| 24小时内 | 事件复盘 | 客服经理 |

##### 异物投诉处理流程

| 步骤 | 操作内容 | 关键要点 | 【KCP】标记 |
|------|----------|----------|------------|
| 1 | 立即表达重视和歉意 | "食品安全是我们最重视的问题" | 【KCP-1】首次响应 |
| 2 | 详细记录异物描述、购买信息 | 请顾客拍照留存 | 【KCP-2】证据保全 |
| 3 | 通知涉事门店封存同批次产品 | 防止问题扩大 | 【KCP-3】风险控制 |
| 4 | 启动内部调查（供应链→门店） | 追溯问题源头 | 【KCP-4】调查启动 |
| 5 | 与顾客协商解决方案 | 退款+补偿+必要时医疗检查 | 【KCP-5】方案执行 |
| 6 | 48小时内反馈调查结果 | 无论结果如何，及时沟通 | 【KCP-6】闭环反馈 |

## Rule 层（拦截与约束）

### Rule 1: 恶意投诉拦截

| 拦截条件 | 拦截动作 | 提示话术 |
|---------|---------|---------|
| 同一问题24小时内投诉>3次 | 合并处理 | "您的问题已在处理中，请勿重复提交" |
| 虚假证据/恶意索赔 | 标记警告 | "检测到异常投诉行为，请如实描述问题" |
| 辱骂/威胁客服 | 限制服务 | "检测到不当言论，客服服务将受限" |
| 职业投诉人识别 | 特殊处理 | "您的问题将转交专人处理" |

### Rule 2: 重复投诉合并

| 拦截条件 | 拦截动作 | 提示话术 |
|---------|---------|---------|
| 同一订单重复投诉 | 合并工单 | "该订单已有投诉在处理中，我们将合并处理" |
| 相似问题7天内重复 | 关联历史 | "检测到历史相似问题，为您关联处理" |
| 已解决再次投诉 | 核实原因 | "该问题已标记解决，请说明再次反馈的原因" |

### Rule 3: 敏感词拦截

| 拦截条件 | 拦截动作 | 提示话术 |
|---------|---------|---------|
| 涉及政治敏感词 | 屏蔽并警告 | "发言包含不当内容，请文明沟通" |
| 涉及个人隐私 | 脱敏处理 | "为保护隐私，相关信息已脱敏" |
| 涉及违法犯罪 | 转交风控 | "检测到敏感信息，将转交相关部门" |
| 媒体/曝光关键词 | 自动升级 | "您的问题已升级至主管处理" |

### Rule 4: 升级规则拦截

| 拦截条件 | 拦截动作 | 提示话术 |

| 食品安全关键词 | 强制升级 | "食品安全问题已立即上报处理" |

## 标准话术库

### 场景1：开场白

**标准话术：**
"您好，肯德基客服中心，很高兴为您服务！我是客服专员[工号]，请问有什么可以帮您？"

**会员顾客：**
"您好，尊敬的[会员等级]会员，肯德基客服中心为您服务！我是专属客服[工号]，请问有什么可以帮您？"

### 场景2：问题确认

**话术：**
"好的，我了解一下。您遇到的问题是[复述问题]，订单号是[XXXX]，对吗？"

**【KCP】确认要点：**
- 订单号/门店信息
- 问题发生时间
- 涉及产品
- 顾客诉求

### 场景3：情绪安抚

**配送超时安抚：**
"非常抱歉让您久等了！我完全理解您现在的心情，等待外卖确实让人着急。请您放心，我会立即为您查询订单状态并优先处理。"

**投诉安抚：**
"非常抱歉给您带来不好的体验！我代表肯德基向您诚挚道歉。请您放心，我会认真对待您的问题，一定给您一个满意的答复。"

**食安问题安抚：**
"食品安全是我们最重视的问题，听到您遇到这样的情况我非常重视。我代表肯德基向您诚挚道歉，我会立即为您处理并彻查原因。"
