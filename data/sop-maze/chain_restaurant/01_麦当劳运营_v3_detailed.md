## SOP: 麦当劳门店运营标准流程v3

麦当劳门店员工（含柜台服务员、配餐员、清洁员）日常运营SOP，覆盖点餐服务、配餐标准、清洁规范、投诉处理四大核心场景，基于QSC&V（品质Quality、服务Service、清洁Cleanliness、价值Value）原则构建。

【Rule 1 — 60秒服务标准】⚠️ 柜台服务核心指标

【Rule 2 — 食品安全红线】⚠️ 绝对禁止
├─ 以下行为严禁发生:
│   ├─ 使用过期食材/原料
│   ├─ 不洗手直接接触即食食品
│   ├─ 生熟交叉污染
│   ├─ 炸油超过报废标准继续使用
│   ├─ 温度敏感食品在危险温度区(5°C-60°C)放置超4小时
│   └─ 篡改产品保质期标签
└─ 触发处理: 立即停止操作→报告经理→废弃问题产品→重新培训

【Rule 3 — 顾客过敏应对】⚠️ 生命安全优先
├─ 顾客声明食物过敏
│   └─ 立即执行:
│       ├─ 停止当前所有操作，洗手消毒
│       ├─ 查阅过敏原手册确认成分
│       ├─ 如无法100%确认安全，告知顾客"不建议食用"
│       ├─ 使用独立清洁器具制作(如顾客坚持)
│       └─ 在订单上标注"过敏"提醒所有环节
└─ 严禁: 对过敏原信息不确定时仍承诺安全

【Rule 4 — 现金安全规则】
├─ 收银规范:
│   ├─ 收款时唱收唱付"收您XX元"
│   ├─ 找零时唱付"找您XX元"
│   ├─ 大钞(100元)必须使用验钞机
│   └─ 抽屉现金不得超过限额(通常500元)
├─ 差异处理:
│   ├─ 短款: 立即报告，差额补齐
│   └─ 长款: 报告经理，不得私留
└─ 交接: 每班清点，双人确认签字

【Rule 5 — 产品废弃标准】
├─ 时间废弃(保质期到期必须废弃):
│   ├─ 薯条: 炸制后7分钟
│   ├─ 汉堡肉饼: 组装后15分钟(保温柜)
│   ├─ 炸鸡类: 炸制后30分钟
│   ├─ 咖啡: 冲泡后30分钟
│   └─ 生菜/洋葱等配料: 开袋后4小时
├─ 品质废弃(出现以下情况立即废弃):
│   ├─ 外观异常(变色/变形/异味)
│   ├─ 温度异常(冷食变热/热食变冷)
│   └─ 受到污染(掉落/接触不洁物)
└─ 废弃程序: 丢入废弃桶→记录废弃原因→不得食用或带走

### Objective

**角色**: 麦当劳门店一线员工(柜台服务员/配餐员/清洁员)

**场景**: 麦当劳门店日常运营，包括柜台点餐(堂食/外带/得来速)、配餐制作、清洁维护、投诉处理

**目标**: 按照QSC&V标准执行各项操作，确保顾客获得一致性的高品质体验

**关键要求**:
- 严格遵守60秒服务标准(柜台)/90秒(得来速)
- 食品安全红线绝对不可触碰
- 所有产品必须按标准配方制作
- 清洁消毒程序必须按时按质完成
- 顾客投诉使用LEARN法则处理(Listen倾听、Empathize共情、Apologize道歉、React解决、Notify告知)

### Standard Operating Procedures

#### Step 0: 开场/岗位准备
- **Step 0.1**: 仪容检查
  - 制服整洁，佩戴工牌
  - 头发完全收进帽子，无外露
  - 手部清洁，指甲修剪整齐
  - 摘除首饰(婚戒除外)
- **Step 0.2**: 岗位检查
  - 检查设备运行状态
  - 确认原料库存充足
  - 查看交接班记录
  - 确认清洁用品到位
- **Step 0.3**: 进入岗位
  - 站位准备，保持标准站姿
  - 准备收银/配餐器具
  - 确认60秒计时器可用

#### Step 1: 柜台点餐服务
- **Step 1.0**: 顾客接近识别
  - 顾客进入3米范围内，目光接触
  - 顾客到达柜台，立即问候
- **Step 1.1**: 3秒微笑问候(60秒计时开始)
  - 话术: "喜欢您来！您好，请问要点什么？"
  - 保持眼神接触，微笑服务
- **Step 1.2**: 点餐录入与确认
  - **Step 1.2.1**: 堂食订单
    - 确认用餐人数(影响配餐速度)
    - 录入系统，确认屏幕显示正确
  - **Step 1.2.2**: 外带订单
    - 确认包装需求
    - 标注"外带"标签
  - **Step 1.2.3**: 特殊需求
    - 记录过敏原信息
    - 记录定制要求(去酱/加料等)
- **Step 1.3**: 推荐与建议销售
  - 话术: "我们现在有XX套餐很划算，需要了解一下吗？"
  - 接受推荐 → 加购 → 返回Step 1.2
  - 拒绝推荐 → 继续Step 1.2
- **Step 1.4**: 配餐交付与感谢(60秒计时结束)
  - 按单核对所有产品
  - 话术: "您的餐齐了，请慢用，喜欢您再来！"

#### Step 2: 配餐制作标准
- **Step 2.1**: 汉堡组装
  - **Step 2.1.1**: 面包准备(烘烤11秒，切面朝上)
  - **Step 2.1.2**: 酱料涂抹(按产品标准枪数/圈数)
  - **Step 2.1.3**: 配料添加(顺序: 生菜→洋葱→酸黄瓜→芝士→肉饼)
  - **Step 2.1.4**: 肉饼放置与包装(12秒内完成)
- **Step 2.2**: 薯条制作
  - **Step 2.2.1**: FIFO检查，先使用旧批次
  - **Step 2.2.2**: 炸制(3分15秒，168°C)
  - **Step 2.2.3**: 沥油30秒，撒盐(小份2.8g/中份4.2g/大份5.6g)
  - 保质期: 7分钟，超时废弃
- **Step 2.3**: 饮料配制
  - **Step 2.3.1**: 杯型选择与检查
  - **Step 2.3.2**: 冰块添加(杯型对应标准冰量)
  - **Step 2.3.3**: 糖浆与碳酸水配比(1:5)
  - **Step 2.3.4**: 杯盖安装，液面距杯口1cm
- **Step 2.4**: 炸鸡/鸡块

- **Rule 7**: 语言与行为规范 - 标准服务用语、禁止用语、仪容仪表要求
- **Rule 8**: 得来速特殊规则 - 双窗口分工、总时长目标、安全注意事项
