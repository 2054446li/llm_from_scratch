# 海底捞服务SOP 详细版（v2_detailed）

> **文档版本**: v2.0 详细版  
> **适用场景**: 海底捞全部门店前厅服务全流程  
> **更新日期**: 2026年8月

---

## Objective

### 1.1 业务目标

| 目标维度 | 具体指标 | 目标值 | 行业基准 |
|---------|---------|--------|----------|
| 顾客满意度 | 顾客满意度评分 | >= 4.8/5.0 | 餐饮行业平均 4.2/5.0 |
| 服务效率 | 顾客等位时间 | <= 30分钟(高峰期) | 火锅行业平均 45分钟 |
| 服务响应 | 顾客呼叫响应时间 | <= 15秒 | 餐饮行业平均 60秒 |
| 投诉处理 | 投诉解决满意度 | >= 95% | 餐饮行业平均 75% |
| 会员转化 | 新客会员注册率 | >= 60% | 餐饮行业平均 25% |
| 复购率 | 会员月复购率 | >= 35% | 火锅行业平均 18% |
| 翻台率 | 日均翻台次数 | >= 4.5次/桌 | 火锅行业平均 3.2次/桌 |

### 1.2 服务理念

> "服务至上，顾客至上" —— 通过超预期服务创造顾客惊喜，建立情感连接，打造"家文化"就餐体验。

## Standard Operating Procedures

### 一、顾客接待与等位服务

#### 1.1 迎宾接待流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     迎宾接待操作流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │1.到店识别│ -> │2.需求确认│ -> │3.引导安排│ -> │4.等位服务│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 3米微笑原则、特殊需求识别、等位进度告知                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 服务话术 | 注意事项 | Rule层约束 |
|------|----------|----------|----------|------------|
| 1 | 距顾客3米内主动微笑致意 | "您好，欢迎光临海底捞！" | **KCP**: 3秒内必须有问候 | 未问候扣绩效2分 |
| 2 | 观察顾客人数及特殊需求 | "请问您几位用餐？有预约吗？" | 识别老人/儿童/孕妇/残障人士 | 特殊需求必须记录 |
| 3 | 核对预约信息或安排等位 | "请出示预约信息，我为您核对" | 有预约优先安排预留座位 | 预约保留15分钟 |
| 4 | 发放等位号，引导至等位区 | "前面还有X桌，预计等位X分钟" | **KCP**: 每10分钟主动告知进度 | 超时未告知扣绩效1分 |

#### 1.2 等位关怀服务

| 服务项目 | 服务时机 | 服务话术 | KCP标记 |
|----------|----------|----------|---------|
| 提供饮品小食 | 入座等位区时 | "这边有免费的小食和饮料，请随意取用" | 等位5分钟内必须提供 |
| 擦鞋服务 | 等位超过10分钟 | "我们提供免费擦鞋服务，需要体验一下吗？" | 主动询问，不强制 |
| 美甲服务 | 等位超过15分钟 | "等位还有一段时间，可以免费做美甲" | 女士优先推荐 |
| 儿童游乐 | 带儿童家庭等位 | "小朋友可以去游乐区玩，有专人照看" | **KCP**: 儿童安全确认 |
| 等位补偿 | 等位超过30分钟 | "让您久等了，送您一份菜品/小礼品" | 自动触发，无需顾客提醒 |

        "我们还有儿童游乐区，小朋友可以去玩。"

| 步骤 | 操作内容 | 服务话术 | KCP标记 |

| 3 | 告知上菜时间 | "首份菜品15分钟内上桌" | **KCP**: 首份15分钟承诺 |

### 五、投诉与意见处理

#### 5.1 投诉接收与情绪安抚

| 步骤 | 操作标准 | 服务话术 | KCP标记 |
|------|----------|----------|---------|
| 1 | 立即停下工作，专注倾听 | [点头示意，眼神接触] | **KCP**: 顾客说话时不得打断 |

## Evaluation（6个评估案例）

### 评估案例1：迎宾接待评估

| 评估维度 | 评估标准 | 优秀案例 | 待改进案例 |
|----------|----------|----------|------------|
| 问候时效 | 3秒内主动问候 | 顾客进门即听到"您好，欢迎光临" | 顾客站了10秒才有人招呼 |
| 微笑服务 | 面带微笑，眼神接触 | 真诚微笑，眼神温暖 | 面无表情，低头看单 |
| 需求识别 | 主动询问人数、预约、特殊需求 | "5位有预约吗？有小朋友需要婴儿椅吗？" | 只问"几位"，无其他询问 |
| 等位关怀 | 主动告知进度，提供增值服务 | 每10分钟告知，主动提供擦鞋美甲 | 顾客问了才说，无增值服务 |

**评分标准**：
- 4项全优：10分
- 3项优1项良：8分
- 2项优2项良：6分
- 1项优或以下：4分以下
