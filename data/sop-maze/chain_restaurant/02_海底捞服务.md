## 3. Objective

### 3.1 业务目标

| 目标维度 | 具体指标 | 目标值 |
|---------|---------|--------|
| 顾客满意度 | 顾客满意度评分 | >= 4.8/5.0 |
| 服务效率 | 顾客等位时间 | <= 30分钟(高峰期) |
| 服务响应 | 顾客呼叫响应时间 | <= 15秒 |
| 投诉处理 | 投诉解决满意度 | >= 95% |
| 会员转化 | 新客会员注册率 | >= 60% |
| 复购率 | 会员月复购率 | >= 35% |

### 3.2 服务理念

> "服务至上，顾客至上" —— 通过超预期服务创造顾客惊喜，建立情感连接，打造"家文化"就餐体验。

## 4. Standard Operating Procedures

### 4.1 顾客接待与等位服务

#### 4.1.1 迎宾接待

**一级：到店识别**
- 门迎岗服务员距顾客3米内主动微笑致意
- 标准问候语："您好，欢迎光临海底捞！"
- 观察顾客人数、特殊需求(老人/儿童/孕妇/残障人士)

**二级：需求确认**
- 询问："请问您几位用餐？"
- 询问："有预约吗？"
- 询问："是否有特殊需求？(如婴儿椅、无障碍通道)"

**三级：引导安排**
- 有预约：核对预约信息 → 引导至预留座位
- 无预约有空位：引导至合适座位
- 无预约需等位：启动等位服务流程

**四级：等位服务**
- 发放等位号，告知预计等位时间
- 引导至等位区，提供饮品和小食
- 提供增值服务：擦鞋、美甲、棋牌、儿童游乐
- 每10分钟主动告知等位进度
- 等位超过30分钟赠送菜品或小礼品

**对话示例：**
```
顾客："我们要等多久？"
服务员："您好，前面还有8桌，预计等位25分钟。这边有免费的小食和饮料，
        您还可以体验我们的免费擦鞋/美甲服务。这是您的等位号，
        到号我会第一时间叫您，请留意广播。"
```

#### 4.1.2 入座服务

**一级：引导入座**
- 走在顾客前方1.5米处引导
- 协助拉椅让座(女士/老人优先)
- 协助放置衣物和包袋(提供衣罩/椅套)

**二级：初访关怀**
- 提供热毛巾擦手(冬季)/冰毛巾(夏季)
- 提供围裙、袖套、手机袋
- 介绍调料区位置和自助饮品

**三级：需求记录**
- 询问锅底偏好(辣度选择)
- 询问是否有食物过敏
- 询问是否为特殊场合(生日/纪念日/商务)

---

### 4.2 点餐与推荐服务

#### 4.2.1 菜单介绍

**一级：菜品介绍**
- 递上菜单，介绍当日特色菜品
- 说明菜品份量(半份/整份可选)
- 介绍招牌菜品和新品推荐

**二级：智能推荐**
- 根据人数推荐合理菜品数量
- 根据口味偏好推荐搭配
- 提醒避免过量点餐

**三级：营养搭配建议**
- 荤素搭配建议(推荐比例3:7或4:6)
- 特殊人群推荐(老人/儿童/孕妇)
- 锅底与菜品搭配建议

**对话示例：**
```
服务员："您好，我们4个人，您看这些够吗？"
顾客："帮我看看"
服务员："您点了6个荤菜3个素菜，建议再加1-2个素菜平衡一下。
        另外我们的招牌虾滑和毛肚很受欢迎，需要尝尝吗？
        锅底推荐鸳鸯锅，辣度可以选微辣，适合大家口味。"
```

#### 4.2.2 点餐确认

**一级：复述确认**
- 完整复述顾客所点菜品
- 确认锅底、调料、饮品
- 确认特殊要求(如免葱免蒜)

**二级：下单流程**
- 手持设备或纸质单录入系统
- 告知顾客预计上菜时间
- 首份菜品上桌时间承诺(15分钟内)

**三级：后厨协同**
```
服务员 → 后厨："3号桌订单，鸳鸯锅(微辣+菌汤)，
              招牌菜：虾滑、毛肚、黄喉，
              注意：一份虾滑不要蒜蓉"
后厨 → 服务员："收到，预计10分钟出首份"
```

### 4.3 就餐过程服务

#### 4.3.1 上菜服务

**一级：上菜规范**
- 报菜名："您好，这是您点的XXX"
- 介绍特色吃法(如毛肚"七上八下")
- 确认菜品无误后摆放整齐

**二级：分菜服务**
- 主动提供分菜服务
- 协助下菜、煮菜、捞菜
- 及时更换骨碟(满1/3即换)

**三级：巡台服务**
- 每5分钟巡台一次
- 主动添加汤底、茶水
- 及时清理桌面杂物
- 观察顾客需求，主动服务

#### 4.3.2 席间关怀

**一级：主动服务**
- 看到顾客擦汗 → 调低空调/递上纸巾
- 看到顾客看手机 → 提供手机支架
- 看到顾客长发 → 提供发圈
- 看到戴眼镜顾客 → 提供眼镜布

**二级：需求预判**
- 顾客频繁看表 → 询问是否赶时间，加快服务
- 顾客剩菜较多 → 询问是否不合口味，主动处理
- 顾客拍照 → 主动协助调整菜品摆盘

**三级：互动服务**
- 拉面表演(如顾客感兴趣)
- 生日祝福(详见4.4.1)
- 游戏互动(等位或用餐时)

**对话示例：**
```
[场景：顾客频繁看表]
服务员："您好，看您比较赶时间，需要我帮您加快上菜速度吗？
        或者我可以帮您把剩下的菜品打包，您可以先吃。"
顾客："确实有点急"
服务员："好的，我马上跟后厨催一下，先把煮好的菜给您打包。"
```

### 4.4 特殊服务

#### 4.4.1 生日服务

**一级：信息获取**
- 预订时或入座时确认是否生日
- 记录寿星姓名、年龄(可选)

**二级：惊喜准备**
- 通知后厨准备长寿面(免费)
- 准备生日蛋糕/果盘(根据会员等级)
- 安排员工排练生日歌

**三级：仪式执行**
- 关灯/调暗灯光
- 员工举牌、唱生日歌
- 赠送生日礼物(小礼品/优惠券)
- 拍照留念，协助分享至社交媒体

**四级：后续关怀**
- 赠送生日专属优惠券
- 登记生日信息至会员系统

**对话示例：**
```
服务员："今天是您生日对吗？我们为您准备了长寿面，一会儿还有小惊喜！"
[生日仪式开始]
服务员(带领团队)："祝XX先生/女士生日快乐！"
服务员："这是我们送您的生日礼物，祝您天天开心！"
```

#### 4.4.2 老人服务

**一级：优先安排**
- 优先安排靠窗、安静、方便出入的座位
- 提供软垫座椅
- 协助搀扶入座

**二级：专属关怀**
- 提供易咀嚼、易消化的菜品推荐
- 菜品煮得更软烂
- 提供放大镜(如需要看菜单)

**三级：安全关注**
- 提醒地面湿滑
- 协助取餐、倒茶(避免烫伤)
- 离店时协助起身、送至门口

#### 4.4.3 儿童服务

**一级：设施提供**
- 提供婴儿椅、儿童餐具
- 提供儿童围兜、湿巾
- 提供儿童游乐区(等位时)

**二级：安全关怀**
- 提醒家长注意热锅、热水安全
- 提供防撞角(桌角防护)
- 协助照看(短暂离开时)

**三级：互动服务**
- 赠送小玩具/贴纸
- 提供蒸蛋、面条等儿童餐(免费)
- 与儿童友好互动

**四级：家长支持**
- 协助加热奶瓶/辅食
- 提供母婴室(如有)
- 协助处理突发状况(如哭闹)

#### 4.4.4 其他特殊场景

| 场景 | 服务要点 |
|-----|---------|
| 孕妇 | 优先安排通风位置、提供靠垫、推荐清淡菜品、协助取餐 |
| 残障人士 | 无障碍通道、宽敞座位、主动协助、耐心服务 |
| 商务宴请 | 安静包间、隐私保护、专业高效服务、酒水推荐 |
| 情侣约会 | 浪漫氛围、玫瑰花/巧克力赠送、拍照服务 |
| 大型聚餐 | 提前沟通菜单、分桌安排、统一上菜节奏、团购优惠 |

### 4.5 投诉与意见处理

#### 4.5.1 投诉接收

**一级：倾听记录**
- 立即停下手中工作，专注倾听
- 保持眼神接触，点头示意
- 不打断顾客陈述
- 记录投诉要点

**二级：情绪安抚**
- 标准话术："非常抱歉给您带来不好的体验"
- 表达同理心："我理解您的感受"
- 避免辩解，先处理情绪

#### 4.5.2 投诉处理

**一级：现场解决**
- 服务员权限内：立即处理(如换菜、免单菜品)
- 超出权限：立即请示领班/经理
- 处理时限：简单问题5分钟内，复杂问题15分钟内

**二级：补偿措施**
| 投诉类型 | 补偿标准 |
|---------|---------|
| 菜品质量问题 | 退换菜品 + 赠送菜品/优惠券 |
| 服务态度问题 | 道歉 + 经理亲自服务 + 折扣/免单 |
| 等待时间过长 | 赠送菜品/小吃 + 折扣 |
| 异物/食品安全 | 免单 + 体检费用 + 郑重道歉 |
| 其他不满意 | 根据情况赠送优惠券或小礼品 |

**三级：升级处理**
- 重大投诉立即上报店长
- 24小时内电话回访
- 书面记录投诉详情

**对话示例：**
```
顾客："这个菜里有头发！"
服务员："非常抱歉，这确实是我们的疏忽，我代表餐厅向您道歉。
        我马上为您更换一份新的，这份菜品免单。
        另外我请经理过来，给您一个满意的处理方案。"
[呼叫经理]
服务员："经理，3号桌菜品中发现异物，顾客很不满。"
经理："您好，我是本店经理，非常抱歉发生这样的事情。
     今天这桌我们免单，另外赠送您一张200元无门槛优惠券，
     您看可以吗？我们一定会加强后厨管理。"
```

#### 4.5.3 意见收集

**一级：主动询问**
- 用餐中："菜品口味还满意吗？"
- 结账时："今天服务还满意吗？"
- 离店时："欢迎提出宝贵意见"

**二级：反馈渠道**
- 店内意见卡
- 扫码评价
- 会员APP反馈
- 客服热线

**三级：闭环管理**
- 每日汇总顾客意见
- 周会分析改进
- 重要意见48小时内回复顾客

### 4.6 会员服务

#### 4.6.1 会员注册

**一级：注册引导**
- 介绍会员权益(积分、生日礼、专属折扣)
- 协助扫码注册
- 赠送注册礼(如20元优惠券)

**二级：信息完善**
- 引导完善生日、口味偏好等信息
- 说明积分规则(消费1元=1积分)

#### 4.6.2 会员权益

| 会员等级 | 成长值要求 | 主要权益 |
|---------|-----------|---------|
| 红海会员 | 注册即得 | 积分累计、生日礼、会员日折扣 |
| 银海会员 | 2000成长值 | 9.5折、优先等位、专属客服 |
| 金海会员 | 10000成长值 | 9折、免排队、专属礼品 |
| 黑海会员 | 邀请制 | 8.8折、专属经理、极致服务 |

#### 4.6.3 会员维护

**一级：日常维护**
- 识别会员身份，称呼姓氏(如"张先生您好")
- 根据消费记录推荐偏好菜品
- 主动告知积分情况和可用优惠

**二级：主动营销**
- 会员日提醒
- 优惠券到期提醒
- 新品试吃邀请
- 生日专属祝福

**三级：流失挽回**
- 识别30天未消费会员
- 推送专属回归礼
- 电话回访了解原因

## 5. Rule层

### 5.1 系统约束

| 约束类别 | 具体规则 | 违规处理 |
|---------|---------|---------|
| **服务时效** | 顾客进店3秒内必须有问候 | 口头警告 |
| **服务时效** | 等位顾客每10分钟主动告知进度 | 绩效扣分 |
| **服务时效** | 顾客呼叫15秒内必须响应 | 绩效扣分 |
| **服务时效** | 首份菜品15分钟内上桌 | 菜品免单 |
| **仪容仪表** | 统一着装、佩戴工牌、头发束起 | 立即整改 |
| **仪容仪表** | 不得佩戴夸张首饰、不得涂指甲油 | 立即整改 |
| **服务用语** | 必须使用"您好"、"请"、"谢谢"、"对不起" | 培训再教育 |
| **服务禁忌** | 不得与顾客争辩 | 严重警告 |
| **服务禁忌** | 不得在顾客面前议论其他顾客 | 严重警告 |
| **服务禁忌** | 不得接受顾客小费 | 退还+警告 |
| **食品安全** | 严格执行"先进先出"原则 | 开除处理 |
| **食品安全** | 发现异物立即停售并上报 | 隐瞒者开除 |
| **投诉处理** | 重大投诉必须10分钟内上报店长 | 记过处分 |
| **信息保密** | 不得泄露顾客个人信息 | 开除+追责 |

### 5.2 权限矩阵

| 服务场景 | 服务员 | 领班 | 经理 | 店长 |
|---------|-------|-----|-----|-----|
| 菜品退换 | <=50元 | <=200元 | 全单 | 全单 |
| 折扣优惠 | 9.8折 | 9折 | 8.5折 | 全免 |
| 赠送菜品 | 小吃类 | <=50元 | <=100元 | 无限制 |
| 投诉处理 | 初步安抚 | 一般投诉 | 重大投诉 | 危机公关 |
| 会员升级 | 无 | 推荐 | 银/金海 | 黑海 |

## 7. Output Requirement

### 7.1 服务输出规范

| 输出项 | 规范要求 |
|-------|---------|
| **服务态度** | 热情、主动、真诚、耐心 |
| **服务语言** | 普通话，使用敬语，音量适中 |
| **服务动作** | 标准、优雅、不打扰顾客用餐 |
| **服务效率** | 响应及时，不拖沓 |
| **服务结果** | 顾客满意，问题闭环 |

### 7.2 记录输出

- 每单服务完成后填写服务日志
- 特殊事件(投诉、表扬)详细记录
- 会员消费记录实时更新
- 每日服务数据汇总上报

### 7.3 质量检查输出

- 神秘顾客评分 >= 90分
- 顾客满意度调查 >= 4.8分
- 投诉率 <= 0.5%
- 服务差错率 <= 1%

## 8. Evaluation

### 8.1 评估维度

| 维度 | 权重 | 评估指标 | 评估方式 |
|-----|-----|---------|---------|
| **服务态度** | 25% | 微笑服务率、主动服务次数 | 现场检查+录像抽查 |
| **服务技能** | 20% | 业务知识掌握、操作规范 | 理论考试+实操考核 |
| **服务效率** | 20% | 响应时间、上菜速度 | 系统数据+神秘顾客 |
| **顾客满意度** | 25% | 好评率、投诉率、回头客率 | 评价系统+回访 |
| **团队协作** | 10% | 传帮带效果、补位意识 | 同事互评+上级评价 |

### 8.2 考核标准

| 等级 | 分数区间 | 绩效系数 | 说明 |
|-----|---------|---------|-----|
| 优秀 | >= 95分 | 1.2 | 服务标杆，可参与晋升 |
| 良好 | 85-94分 | 1.0 | 合格，继续保持 |
| 合格 | 70-84分 | 0.8 | 需改进，加强培训 |
| 不合格 | < 70分 | 0.6 | 待岗培训，再不合格劝退 |
