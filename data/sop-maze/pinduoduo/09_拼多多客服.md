## Objective

本文档旨在规范拼多多客服服务体系的标准操作流程，确保用户问题能够得到及时、专业、有效的解决，同时建立完善的投诉处理和纠纷仲裁机制。适用于所有拼多多客服相关服务场景。

**核心目标：**
- 提供多渠道、便捷的客户服务入口
- 快速准确识别和分类用户问题
- 智能与人工服务高效协同
- 建立公平的投诉处理和纠纷仲裁机制
- 持续优化服务质量，提升用户满意度

### 2. 标准流程

#### 2.1 订单查询流程

```
用户发起查询 ──▶ 身份验证 ──▶ 订单检索 ──▶ 信息展示 ──▶ 问题确认
                    │            │            │
                    ▼            ▼            ▼
                登录状态     按条件筛选    订单详情
                权限校验     关联订单      物流信息
```

| 查询类型 | 查询条件 | 展示信息 | 处理时效 |
|---------|---------|---------|---------|
| 按订单号 | 订单编号 | 订单详情、支付状态、物流信息 | 即时 |
| 按时间 | 时间范围 | 订单列表、交易汇总 | 即时 |
| 按商品 | 商品名称/店铺 | 相关订单、售后状态 | 即时 |
| 按状态 | 待付款/待发货/待收货 | 分类订单列表 | 即时 |

#### 2.2 退款退货流程

```
退款申请 ──▶ 条件审核 ──▶ 商家确认 ──▶ 退货指引 ──▶ 物流跟踪 ──▶ 退款执行
    │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼
 用户发起   时效检查   商家审核   地址提供   退货确认   资金退回
 原因选择   商品核实   同意/拒绝  包装要求   验收核实   到账通知
```

| 退款类型 | 适用场景 | 退款时效 | 审核要求 |
|---------|---------|---------|---------|
| 仅退款 | 未发货/虚拟商品 | 即时-24小时 | 系统/商家审核 |
| 退货退款 | 已收货商品问题 | 3-7个工作日 | 商家收货确认 |
| 极速退款 | 信用良好用户 | 即时到账 | 系统自动 |
| 平台介入 | 商家拒绝/超时 | 1-3个工作日 | 平台仲裁 |

#### 2.3 物流跟踪流程

```
物流查询 ──▶ 运单识别 ──▶ 状态同步 ──▶ 异常检测 ──▶ 问题处理
    │          │          │          │
    ▼          ▼          ▼          ▼
 订单关联   快递公司   实时轨迹   超时/滞留
 单号提取   接口查询   节点推送   自动预警
```

| 物流状态 | 处理措施 | 用户通知 | 异常处理 |
|---------|---------|---------|---------|
| 已发货 | 推送物流信息 | 短信/App推送 | - |
| 运输中 | 实时更新轨迹 | 节点到达通知 | 超时预警 |
| 派送中 | 派送员信息 | 预计送达提醒 | 联系不上 |
| 已签收 | 签收确认 | 签收通知 | 未收到核实 |
| 异常件 | 标记异常 | 异常原因通知 | 主动介入 |

## Rule层

### 系统约束

| 规则类别 | 规则名称 | 规则说明 | 约束强度 |
|---------|---------|---------|---------|
| 时效约束 | 首响时效 | 用户接入后首次响应时间 | 必须≤30秒 |
| 时效约束 | 处理时效 | 不同优先级问题的处理时限 | P0:2h/P1:24h/P2:48h |
| 权限约束 | 退款权限 | 单笔退款金额上限 | 普通客服≤¥500 |
| 权限约束 | 补偿权限 | 单笔补偿金额上限 | 普通客服≤¥100 |
| 合规约束 | 信息保密 | 用户信息保护要求 | 严禁泄露 |
| 合规约束 | 录音留存 | 电话客服录音要求 | 必须录音并保存90天 |
| 流程约束 | 升级条件 | 必须升级的场景 | 强制升级 |
| 流程约束 | 闭环要求 | 问题必须关闭 | 未解决不得关闭 |

3. **录音留存**：电话客服需告知用户并录音留存
4. **投诉权利**：保障用户投诉权利，不得打击报复
5. **仲裁公正**：纠纷仲裁保持中立，依据规则和证据判定
6. **数据安全**：客服系统数据加密存储，访问留痕
7. **假货处理**：假货投诉优先处理，假一赔十严格执行
8. **消费者权益**：7天无理由退货权益保障
