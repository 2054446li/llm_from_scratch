## 4. 详细操作流程 (Detailed Procedures)

### 4.1 一级：加入淘宝联盟

#### 4.1.1 二级：账号要求确认

**Rule层约束：**
- RULE-001: 一个身份证只能认证一个联盟账号
- RULE-002: 账号需满18周岁
- RULE-003: 部分高风险类目需要额外资质审核
- RULE-004: 账号状态正常，无严重违规记录

**4.1.1.1 三级：身份类型判断**

**4.1.1.1.1 四级：个人推广者**
- 条件：持有中国大陆身份证
- 所需材料：身份证正反面照片、手持身份证照片
- 审核时效：1-3个工作日

**4.1.1.1.2 四级：企业推广者**
- 条件：持有有效营业执照
- 所需材料：营业执照、法人身份证、对公账户
- 审核时效：3-5个工作日

**多方对话示例：**

       2. 完成实名认证（个人需身份证，企业需营业执照）
       3. 绑定有效的支付宝账号用于收佣金
       4. 年满18周岁
       请问您是个人推广还是企业推广呢？"

### 4.2 一级：推广链接生成

#### 4.2.1 二级：创建推广位 [KCP:PID]

**Rule层约束：**
- RULE-005: 每个推广位对应唯一PID
- RULE-006: 推广位类型需与实际推广渠道匹配
- RULE-007: PID是佣金归属的唯一标识

**4.2.1.1 三级：推广位类型选择**

**4.2.1.1.1 四级：网站推广位**
- 适用：拥有独立网站的推广者
- 需填写：网站域名、备案信息
- PID格式：mm_123456_123456_123456

**4.2.1.1.2 四级：APP推广位**
- 适用：拥有独立APP的推广者
- 需填写：APP名称、下载链接
- 需通过应用商店审核

**4.2.1.1.3 四级：导购推广位**
- 适用：社群、朋友圈、微博等社交渠道
- 无需额外资质
- 最常用的推广位类型

**4.2.1.1.4 四级：软件推广位**
- 适用：浏览器插件、工具软件等
- 需提交软件说明和截图
- 审核较严格

**多方对话示例：**
```
[用户] "PID是什么？怎么创建？"
[客服] "【KCP:PID】PID是推广位ID，是识别您推广来源和计算佣金的唯一标识。
       创建步骤：
       1. 登录联盟后台 → 推广管理 → 推广位管理
       2. 点击'新建推广位'
       3. 选择推广位类型（网站/APP/导购/软件）
       4. 填写相关信息提交
       5. 获取PID：格式为 mm_账号ID_推广组ID_推广位ID"

[用户] "我主要在微信群推广，选什么类型？"
[客服] "建议选择'导购推广位'，这是最适合社群推广的类型，
       无需额外资质，创建后即可使用。"
```

### 4.3 一级：佣金计算与结算

#### 4.3.1 二级：佣金计算公式

**Rule层约束：**
- RULE-008: 技术服务费统一收取佣金的10%
- RULE-009: 退款订单佣金为0或按比例扣减
- RULE-010: 维权成功订单扣除对应佣金

**4.3.1.1 三级：基础公式**

```
实际佣金 = 商品实际成交金额 × 佣金比例 × (1 - 技术服务费率10%)
```

**4.3.1.2 三级：关键要素说明**

| 要素 | 说明 | 备注 |
|------|------|------|
| 实际成交金额 | 订单实付金额（不含运费） | 使用优惠券按券后价计算 |
| 佣金比例 | 商家设置的推广比例 | 不同类目比例不同 |
| 技术服务费 | 平台收取10% | 从佣金中自动扣除 |
| 税率 | 个人所得税/增值税 | 根据收入类型计算 |

**多方对话示例：**
```
[用户] "佣金是怎么算的？为什么实际到账比预估少？"
[客服] "佣金计算公式：实际佣金 = 成交金额 × 佣金比例 × 90%
       
       例如：商品100元，佣金比例10%
       - 预估佣金：100 × 10% = 10元
       - 技术服务费：10 × 10% = 1元
       - 实际佣金：10 - 1 = 9元
       
       此外还可能扣除：
       - 个人所得税（按劳务报酬计算）
       - 退款订单佣金扣回
       
       您可以在'效果报表'中查看每笔订单的详细扣费明细。"
```

- RULE-012: 无最低提现金额限制
- RULE-013: 企业账号需开票后才能提现

**4.3.2.1.1 四级：个人推广者提现**
- 到账账户：绑定的支付宝账号

**4.3.2.1.2 四级：企业推广者提现**
- 需开具增值税专用发票

### 4.4 一级：违规处理 [KCP:违规]

#### 4.4.1 二级：违规行为分类

**Rule层约束：**
- RULE-014: 一般违规扣2-12分/次
- RULE-015: 严重违规扣12-48分/次
- RULE-016: 特别严重扣48分，永久封号

**4.4.1.1 三级：违规类型表**

| 违规类型 | 具体表现 | 处罚措施 |
|---------|---------|---------|
| 虚假推广 | 自买自卖、刷单、虚假流量 | 扣分+冻结佣金+封号 |
| 违规引流 | 诱导点击、欺骗用户 | 扣分+限制推广权限 |
| 侵权推广 | 冒用他人品牌、盗用素材 | 扣分+下架链接+赔偿 |
| 违规内容 | 发布违禁品、虚假宣传 | 扣分+删除内容 |
| 技术违规 | 爬虫、API滥用、破解 | 永久封号+法律追责 |

**4.4.1.2 三级：处罚等级**

**4.4.1.2.1 四级：警告**
- 适用：首次轻微违规
- 处理：系统警告，不扣分
- 要求：立即整改

**4.4.1.2.2 四级：限制推广**
- 适用：一般违规累计
- 处理：部分功能受限
- 期限：根据违规程度

**4.4.1.2.3 四级：冻结佣金**
- 适用：违规订单佣金
- 处理：违规订单佣金冻结
- 解冻：申诉成功或处罚期满

**4.4.1.2.4 四级：扣除佣金**
- 适用：确认违规
- 处理：扣除已结算的违规佣金
- 不可恢复

**4.4.1.2.5 四级：封号**
- 适用：特别严重违规
- 处理：永久关闭联盟账号
- 不可申诉恢复
