## 4. 详细操作流程 (Detailed Procedures)

### 4.1 一级：商家入驻 [KCP:实名认证]

#### 4.1.1 二级：账号注册

**4.1.1.1 三级：注册方式**

**4.1.1.1.1 四级：淘宝账号注册**
1. 访问淘宝官网或下载淘宝APP
2. 点击"免费注册"
3. 填写手机号/邮箱
4. 设置登录密码
5. 完成手机验证

**4.1.1.1.2 四级：千牛账号关联**
- 千牛使用淘宝账号登录
- 无需单独注册千牛账号
- 一个淘宝账号对应一个千牛工作台

---

#### 4.1.2 二级：实名认证 [KCP:实名认证]

**Rule层约束：**
- RULE-QN-001: [KCP:实名认证] 个人店铺需身份证认证
- RULE-QN-002: 企业店铺需营业执照认证
- RULE-QN-003: 认证审核时间：个人1-3个工作日，企业3-5个工作日
- RULE-QN-004: 认证信息必须真实有效

**4.1.2.1 三级：个人店铺认证**

**4.1.2.1.1 四级：所需材料**
- 身份证正反面照片
- 手持身份证照片
- 本人银行卡（用于结算）

**4.1.2.1.2 四级：认证流程**
1. 登录千牛 → 卖家中心 → 店铺管理 → 店铺认证
2. 选择"个人认证"
3. 上传身份证照片
4. 完成人脸识别
5. 绑定银行卡
6. 等待审核

**4.1.2.2 三级：企业店铺认证**

**4.1.2.2.1 四级：所需材料**
- 营业执照（彩色扫描件）
- 法人身份证正反面
- 对公账户信息
- 企业支付宝账号

**4.1.2.2.2 四级：认证流程**
1. 登录千牛 → 卖家中心 → 店铺管理 → 店铺认证
2. 选择"企业认证"
3. 上传营业执照和法人身份证
4. 填写对公账户信息
5. 绑定企业支付宝
6. 等待审核

**多方对话示例：**
```
[商家] "怎么开通淘宝店铺？需要什么条件？"
[客服] "您好！开通淘宝店铺需要完成以下流程：

【入驻流程】
1. 账号注册：注册淘宝账号
2. 【KCP:实名认证】实名认证：
   • 个人店铺：身份证+人脸识别
   • 企业店铺：营业执照+法人身份证
3. 开店认证：填写店铺信息
4. 【KCP:保证金缴纳】缴纳保证金

【认证时效】
• 【Rule-QN-003】个人认证：1-3个工作日
• 【Rule-QN-003】企业认证：3-5个工作日

【个人vs企业对比】
┌──────────┬──────────────┬──────────────┐
│   项目   │   个人店铺   │   企业店铺   │
├──────────┼──────────────┼──────────────┤
```

#### 4.1.3 二级：开店认证

**4.1.3.1 三级：店铺信息设置**

**4.1.3.1.1 四级：基本信息**
- 店铺名称：2-10个汉字，不可与已有店铺重复
- 店铺类目：选择主营类目
- 店铺介绍：简要描述店铺特色

**4.1.3.1.2 四级：协议签署**
- 阅读并同意《淘宝服务协议》
- 阅读并同意《消费者保障服务协议》
- 确认开店承诺

---

#### 4.1.4 二级：保证金缴纳 [KCP:保证金缴纳]

**Rule层约束：**
- RULE-QN-005: [KCP:保证金缴纳] 必须缴纳保证金才能正常经营
- RULE-QN-006: 一般类目1000元起，特殊类目金额更高
- RULE-QN-007: 支持现金缴纳或保险替代
- RULE-QN-008: 关店后符合条件可申请退还

**4.1.4.1 三级：保证金标准**

| 类目类型 | 保证金金额 | 说明 |
|---------|-----------|------|
| 一般类目 | 1000元 | 服装、家居等 |
| 食品类目 | 3000元 | 需食品经营许可证 |
| 保健品 | 5000元 | 需相关资质 |
| 数码家电 | 2000-10000元 | 根据品牌而定 |
| 虚拟商品 | 1000-5000元 | 根据类型而定 |

**4.1.4.2 三级：缴纳方式**

**4.1.4.2.1 四级：现金缴纳**
- 支付宝余额支付
- 银行卡支付
- 直接冻结在支付宝账户

**4.1.4.2.2 四级：保险替代**
- 购买保证金保险
- 年费约30元（以1000元保证金为例）
- 无需冻结大额资金

**话术模板：**
| 场景 | 话术 |
|------|------|
| 保证金说明 | "【KCP:保证金缴纳】开店需要缴纳保证金，一般类目1000元起，用于保障消费者权益" |
| 保险替代 | "您可以选择购买保证金保险，每年约30元，无需冻结大额资金" |
| 退还说明 | "关店后30天内无纠纷可申请退还保证金" |

#### 4.2.2 二级：物流设置

### 4.3 一级：商品发布

#### 4.3.1 二级：类目选择 [重要]

**Rule层约束：**
- RULE-QN-009: 类目错放会导致商品下架或降权
- RULE-QN-010: 必须使用正确类目
- RULE-QN-011: 部分类目需要特殊资质

**4.3.1.1 三级：类目选择方法**

**4.3.1.1.1 四级：搜索选择**
1. 发布商品时输入商品关键词
2. 系统推荐相关类目
3. 选择最匹配的类目

**4.3.1.1.2 四级：逐级选择**
1. 选择一级类目
2. 选择二级类目
3. 选择三级类目
4. 确认最终类目

**多方对话示例：**
```
[商家] "商品被下架了怎么办？"
[客服] "【KCP:违规类型判断】商品下架通常有以下原因：

【常见下架原因】
1. 【Rule-QN-009】类目错放：商品放在错误类目下
2. 标题违规：使用违禁词或虚假宣传
3. 图片违规：盗用他人图片或违规内容
4. 价格异常：价格明显偏离市场价
5. 资质缺失：特殊类目缺少必要资质

【处理步骤】
1. 千牛 → 卖家中心 → 体检中心 → 查看违规记录
2. 确认具体违规原因
3. 针对性整改：
   • 类目错放：重新选择正确类目
   • 标题违规：修改标题，删除违禁词
   • 图片违规：更换为原创图片
4. 整改后重新提交审核

【申诉】
如认为判定有误，可在3天内提交申诉。

请提供商品ID，我帮您查询具体下架原因。"
```

#### 4.3.2 二级：商品信息填写

**4.3.2.1 三级：标题规范**

**Rule层约束：**
- RULE-QN-012: 标题30个汉字以内
- RULE-QN-013: 必须包含核心关键词
- RULE-QN-014: 不得使用违禁词

**4.3.2.1.1 四级：标题结构**
```
[品牌] + [核心关键词] + [属性词] + [卖点]
示例：【耐克】男鞋跑步鞋夏季透气网面运动鞋轻便减震
```

**4.3.2.2 三级：商品属性**
- 完整填写品牌、型号、规格
- 准确填写材质、尺寸、重量
- 属性越完整，搜索曝光越高

**4.3.2.3 三级：价格设置**
- 售价：实际销售价格
- 原价：划线价（需有真实销售记录）
- 成本价：用于利润分析（不展示）

---

#### 4.3.3 二级：商品图片

**Rule层约束：**
- RULE-QN-015: 主图800×800像素以上
- RULE-QN-016: 图片需清晰，无水印
- RULE-QN-017: 不得含有违规内容

**4.3.3.1 三级：图片要求**

| 图片类型 | 尺寸要求 | 内容要求 |
|---------|---------|---------|
| 主图 | 800×800px以上 | 白底或场景图，无水印 |
| 详情图 | 宽度750px | 展示细节、功能、使用场景 |
| SKU图 | 800×800px | 展示不同规格/颜色 |

### 4.5 一级：售后与违规处理 [KCP:违规类型判断]

#### 4.5.1 二级：违规类型判断 [KCP]

**Rule层约束：**
- RULE-QN-021: [KCP:违规类型判断] 需先判断违规类型再处理
- RULE-QN-022: 一般违规：警告、扣分、商品下架
- RULE-QN-023: 严重违规：店铺屏蔽、限制功能
- RULE-QN-024: 售假违规：商品删除、封店

**4.5.1.1 三级：违规类型表**

| 违规类型 | 常见情形 | 处罚措施 |
|---------|---------|---------|
| 一般违规 | 类目错放、标题违规、描述不符 | 警告、扣分、商品下架 |
| 严重违规 | 虚假交易、恶意骚扰、泄露信息 | 店铺屏蔽、限制功能 |
| 售假违规 | 销售假冒商品、盗版侵权 | 商品删除、扣分、封店 |
| 违禁商品 | 销售禁限售商品 | 立即下架、严重处罚 |

**4.5.1.2 三级：违规通知查看**
- 千牛消息中心接收违规通知
- 卖家中心 → 体检中心查看违规记录
- 查看违规详情和处罚依据
