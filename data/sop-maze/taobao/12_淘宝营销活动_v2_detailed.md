### 4.2 一级：优惠叠加计算 [KCP:优惠叠加规则]

#### 4.2.1 二级：优惠类型梳理

**Rule层约束：**
- RULE-MK-004: [KCP:优惠叠加规则] 需明确各层级优惠的叠加关系
- RULE-MK-005: 跨店满减 vs 官方立减：二选一，系统自动取最优
- RULE-MK-006: 店铺券 vs 商品券：一般不可叠加，取面额大的

**4.2.1.1 三级：优惠层级表**

| 优惠层级 | 优惠类型 | 叠加规则 |
|---------|---------|---------|
| 第一层 | 单品优惠（限时折扣、秒杀价） | 与所有优惠叠加 |
| 第二层 | 店铺优惠（店铺券、商品券） | 一般不可叠加，取最优 |
| 第三层 | 跨店满减/官方立减 | 与店铺券叠加，与立减互斥 |
| 第四层 | 红包/淘金币/积分 | 可与上述叠加 |
| 第五层 | 88VIP折扣/支付优惠 | 最后计算 |

**4.2.1.2 三级：互斥规则说明**

**4.2.1.2.1 四级：不可叠加情况**
- 跨店满减 vs 官方立减：二选一
- 店铺券 vs 商品券：一般取面额大的
- 部分特殊券标注"不可叠加"

**4.2.1.2.2 四级：可叠加情况**
- 单品优惠 + 店铺券 + 跨店满减 + 红包 + 88VIP
- 理论上最多可叠加5层优惠

#### 4.2.2 二级：计算示例

**4.2.2.1 三级：标准计算流程**

```
场景：双11购买商品，原价500元

计算流程：
1. 单品优惠：限时9折 → 500 × 0.9 = 450元
2. 店铺优惠券：满400减50 → 450 - 50 = 400元
3. 跨店满减：每满300减50 → 400 - 50 = 350元
4. 红包抵扣：超级红包10元 → 350 - 10 = 340元
5. 88VIP折扣：95折 → 340 × 0.95 = 323元

最终实付：323元
优惠总额：500 - 323 = 177元（省35.4%）
```

### 4.3 一级：抢购问题处理

#### 4.3.1 二级：预售问题

**Rule层约束：**
- RULE-MK-007: 定金正常情况不退，付尾款后可全额退
- RULE-MK-008: 未付尾款定金不退
- RULE-MK-009: 尾款支持叠加优惠券和满减

**4.3.1.1 三级：预售规则表**

| 问题 | 处理方式 |
|-----|---------|
| 定金能否退还 | 正常情况不退，付尾款后可全额退；未付尾款定金不退 |
| 忘记付尾款 | 提醒尾款时间，过期定金不退，可协商特殊处理 |
| 尾款能否用券 | 可以，尾款支持叠加优惠券和满减 |
| 预售商品改地址 | 付尾款前可改，付尾款后按普通订单规则 |

**多方对话示例：**

### 4.4 一级：活动价保 [KCP:价保资格判定]

#### 4.4.1 二级：价保规则说明

**Rule层约束：**
- RULE-MK-010: [KCP:价保资格判定] 需先判定是否符合价保条件
- RULE-MK-011: 双11/618一般15天价保，部分商品30天
- RULE-MK-012: 百亿补贴、秒杀、限时特惠商品不支持价保

**4.4.1.1 三级：价保条件表**

| 项目 | 规则说明 |
|-----|---------|
| 价保期限 | 双11/618一般15天，部分商品30天，以页面标注为准 |
| 价保范围 | 同一商品、同一规格、同一销售链接 |
| 差价计算 | 活动实付价 - 当前活动价（需扣除已享受优惠） |
| 不适用情况 | 百亿补贴、秒杀、限时特惠、使用特殊优惠券等 |

**4.4.1.2 三级：价保申请流程**

```
1. 用户发起申请
   └── 路径：我的淘宝 → 我的订单 → 价保中心 → 一键价保
   
2. 系统自动审核
   └── 检测订单是否符合价保条件
   └── 计算差价金额
   
3. 审核结果处理
   ├── 符合价保 → 自动退差价到原支付渠道
   └── 不符合 → 说明具体原因
   
4. 人工复核（如有争议）
   └── 核实商品链接、价格变动截图
   └── 特殊情况人工审批
```

**多方对话示例：**
```
[用户] "我上周买的手机现在降价200元，申请价保说我不符合，为什么？"
[客服] "【KCP:价保资格判定】价保失败可能有以下原因：

【可能原因分析】

1. 【Rule-MK-011】超过价保期限
   • 检查订单签收时间
   • 一般价保期为15天（部分30天）
   • 从签收之日起算
```

### 4.5 一级：活动售后 [KCP:退款优惠扣回]

#### 4.5.1 二级：退货退款规则

**Rule层约束：**
- RULE-MK-013: [KCP:退款优惠扣回] 部分退货可能导致满减失效
- RULE-MK-014: 活动商品退货退款金额按实付金额退
- RULE-MK-015: 退货后优惠券一般不退回

**4.5.1.1 三级：退货规则表**

| 场景 | 处理方式 |
|-----|---------|
| 活动商品退货 | 支持7天无理由，退款金额按实付金额退 |
| 退货后优惠失效 | 部分退货可能导致满减失效，需按比例扣除 |
| 定金退款 | 付尾款后申请全额退款，定金+尾款一起退 |
| 赠品处理 | 退货需一并退回赠品，否则扣除赠品价值 |

**4.5.1.2 三级：优惠扣回计算**

```
案例：原订单商品A 200元 + 商品B 200元 = 400元
满减优惠：每满300减50，实付350元

如退商品A（200元）：
- 剩余商品B 200元，不满足满300门槛
- 需扣除满减50元中的部分金额（约25元）
- 商品A退款：200 - 25 = 175元
```
