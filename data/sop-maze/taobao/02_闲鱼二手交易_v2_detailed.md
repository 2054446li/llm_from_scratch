### Objective

**角色**: 闲鱼客服/运营人员

**场景**: 
- 二手交易全流程咨询
- 交易纠纷仲裁处理
- 违规行为识别与处罚
- 用户权益保护

**目标**: 
- 保障C2C二手交易安全
- 维护买卖双方合法权益
- 降低平台交易纠纷率
- 提升用户交易体验

### Standard Operating Procedures

#### Step 1: 发布审核

##### 1.1 商品发布规范
- 标题: 清晰描述商品品牌+型号+成色
- 图片: 实拍图不少于3张，禁止使用网图
- 描述: 如实描述瑕疵、使用痕迹
- 定价: 参考同类商品市场价

##### 1.2 禁售品识别

| 类别 | 具体商品 | 处理方式 |
|------|----------|----------|
| 违禁品 | 枪支弹药、毒品、管制刀具 | 立即下架+封号 |
| 假冒商品 | 高仿奢侈品、盗版软件 | 下架+扣分 |
| 虚拟商品 | 账号、游戏币、优惠券 | 限制发布 |
| 医疗器械 | 处方药、隐形眼镜 | 需资质证明 |
| 食品 | 自制食品、保健品 | 需许可证 |

**Rule层约束**：
| 规则项 | 约束内容 | 违规后果 |
|--------|----------|----------|
| 禁售品发布 | 严禁发布违禁品 | 立即下架+封号 |
| 图片规范 | 必须实拍，禁止网图 | 商品下架+警告 |
| 描述真实性 | 如实描述瑕疵 | 虚假宣传扣分 |

##### 1.3 审核流程
```
用户发布 ──▶ AI初筛(秒级) ──▶ 人工复核(可疑) ──▶ 上架/驳回
                │
                ▼
            敏感词过滤
            图片识别
            价格异常检测
```

**KCP 1: 商品发布审核**
- 时效：AI初筛秒级，人工复核24小时内
- 检查点：是否涉及禁售品、图片是否实拍、描述是否合规
- 违规处理：立即下架，视情节扣分/封号

#### Step 2: 交易咨询

##### 2.1 买家咨询处理
- 商品详情确认
- 成色/瑕疵说明
- 议价处理（允许合理议价）
- 发货时间确认
- 运费承担方式（到付/包邮）

**多方对话示例**：
```
买家：这个iPhone还能便宜吗？
卖家：亲，已经是闲置最低价了，成色95新，原价8999，现在4500出，可以包邮
买家：4000行吗？
卖家：抱歉呢，4500已经是底价了。手机无拆无修，电池健康90%，还送手机壳和钢化膜
买家：那包邮吧，什么时候能发货？
卖家：今天下单，明天发货，发顺丰
```

**客服介入话术**：
```
用户：卖家不回复我消息怎么办？
客服：建议您耐心等待2-4小时。如超过24小时未回复，您可以：
      1. 查看卖家最近上线时间
      2. 如卖家长期不在线，建议考虑其他同类商品
      3. 不要脱离平台交易，谨防诈骗
```

##### 2.2 议价话术模板
```
【买家议价】"能便宜点吗？"
【回复模板】"亲，已经是闲置最低价了，成色XX，原价XX，现在XX出，
           可以包邮/送小礼物"

【买家要求包邮】"包邮吗？"
【回复模板】"亲，XX地区可以包邮，其他地区需要补XX元运费"
```

##### 2.3 风险提示
- 禁止引导站外交易（微信/支付宝直接转账）
- 禁止发送第三方链接
- 高价值商品建议使用验货宝

**Rule层约束**：
| 规则项 | 约束内容 | 违规后果 |
|--------|----------|----------|
| 站外交易 | 禁止引导脱离平台交易 | 警告+限制功能 |
| 诈骗行为 | 诱导提前确认收货 | 封号处理 |
| 虚假链接 | 发送钓鱼链接 | 永久封号 |

---

#### Step 3: 发货确认

##### 3.1 发货前检查清单
- [ ] 商品与描述一致
- [ ] 配件齐全
- [ ] 包装完好
- [ ] 拍照留证（商品状态+快递单号）

##### 3.2 发货规范

| 商品类型 | 建议物流 | 保价建议 |
|----------|----------|----------|
| 普通物品 | 菜鸟裹裹/三通一达 | 100元以上建议保价 |
| 贵重物品 | 顺丰 | 必须保价 |
| 易碎品 | 顺丰+木架包装 | 必须保价 |
| 大件物品 | 德邦/安能 | 必须保价 |

##### 3.3 发货时效
- 普通商品: 72小时内发货
- 预售商品: 约定时间内发货
- 超时处理: 买家可申请退款，卖家需赔付

**KCP 2: 发货时效监控**
- 时效：72小时内必须发货
- 检查点：是否超时、是否虚假发货
- 超时处理：买家可申请退款+投诉

**话术示例**：
```
用户：卖家3天了还没发货
客服：根据闲鱼规则，卖家应在72小时内发货。现已超时，您可以：
      1. 申请退款（立即到账）
      2. 投诉卖家「未按约定时间发货」
      时效说明：申请退款后，卖家48小时内不处理则自动退款
```

#### Step 4: 收货纠纷

##### 4.1 自动确认收货规则
```
发货后 ──▶ 10天(普通快递) ──▶ 自动确认收货
       ──▶ 15天(平邮) ──▶ 自动确认收货
       ──▶ 30天(海外购) ──▶ 自动确认收货
```

##### 4.2 常见纠纷类型及处理

| 纠纷类型 | 买家举证 | 卖家举证 | 处理建议 |
|----------|----------|----------|----------|
| 商品不符 | 开箱视频、对比图 | 发货前照片 | 支持退货退款 |
| 未收到货 | 物流信息 | 签收底单 | 联系物流核实 |
| 质量问题 | 故障视频/照片 | 发货前测试视频 | 协商部分退款 |
| 假货争议 | 品牌方鉴定 | 购买凭证 | 支持退货+处罚卖家 |

**多方对话示例（商品不符）**：
```
买家：收到的手机和描述不符，说是95新结果边框好多划痕
客服：您好，我来帮您处理。请问您有拍摄开箱视频吗？
买家：有，我发给你
客服：好的，请您上传开箱视频和商品照片。同时请问卖家商品描述是怎么写的？
买家：描述说"几乎全新，无明显划痕"
客服：了解了。经对比，商品确实存在描述不符的情况。您可以申请退货退款，
      运费由卖家承担。如卖家拒绝，可申请平台介入。
```

##### 4.3 闲鱼小法庭流程
```
申请介入 ──▶ 双方举证(48小时) ──▶ 系统随机抽17人评审 ──▶ 投票裁决
                                              │
                                              ▼
                                         先获9票者胜
                                         (通常24小时内出结果)
```

**KCP 3: 纠纷举证**
- 时效：申请介入后48小时内完成举证
- 检查点：开箱视频、聊天记录、物流凭证
- 关键证据：开箱视频必须包含快递单号+包裹完整+商品全貌

##### 4.4 举证要求
- **开箱视频**: 必须包含快递单号+包裹完整+商品全貌
- **聊天记录**: 完整对话，不得删减
- **物流凭证**: 签收底单/物流轨迹截图
- **鉴定报告**: 品牌官方或权威机构出具

---

#### Step 5: 违规处理

##### 5.1 违规类型分级

| 等级 | 违规行为 | 处罚措施 |
|------|----------|----------|
| 轻微 | 描述不清、图片模糊 | 商品下架，警告 |
| 一般 | 售假、虚假宣传 | 删除商品，扣12分 |
| 严重 | 诈骗、多次售假 | 限制发布，扣48分 |
| 特别严重 | 团伙诈骗、违禁品 | 永久封号，移送司法 |

##### 5.2 售假识别要点
- 价格明显低于市场价
- 无法提供购买凭证
- 商品细节与正品有差异
- 买家投诉率异常

##### 5.3 诈骗识别要点
- 引导站外交易
- 要求提前确认收货
- 虚假发货（单号无效）
- 诱导点击钓鱼链接

**话术示例（诈骗预警）**：
```
用户：卖家说加微信详聊，给我便宜50块，能加吗？
客服：⚠️ 高风险警告！这是典型的诈骗套路
      
      处理建议：
      1. 坚决拒绝：所有沟通必须在闲鱼平台内完成
      2. 举报卖家：点击"举报"-"引导站外交易"
      3. 安全提醒：
         - 站外交易无平台保障
         - 转账后卖家可能消失
         - 无法申请退款
      4. 正确做法：
         - 议价在闲鱼消息中进行
         - 付款通过闲鱼担保交易
         - 绝不脱离平台
```

##### 5.4 申诉流程
```
收到处罚 ──▶ 查看处罚详情 ──▶ 准备申诉材料 ──▶ 提交申诉(72小时内)
                                              │
                                              ▼
                                         平台复核 ──▶ 维持/撤销处罚
```

**Rule层约束**：
| 规则项 | 约束内容 | 申诉时效 |
|--------|----------|----------|
| 处罚申诉 | 72小时内提交 | 超期无法申诉 |
| 申诉次数 | 有且仅有一次 | 恶意申诉加重处罚 |
| 材料要求 | 真实有效 | 虚假材料封号 |
