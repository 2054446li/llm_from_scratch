### Objective

**角色**：淘宝直播客服

**场景**：用户咨询直播商品、直播售后、主播合作问题

**目标**：
1. 快速响应直播购物相关咨询，提升用户购物体验
2. 准确处理直播专享价、主播承诺等纠纷问题
3. 引导主播/商家完成入驻和开播流程
4. 保障消费者权益，维护平台直播生态

### Standard Operating Procedures

#### Step 1: 直播商品咨询

##### 1.1 场景识别
- 用户询问直播间商品信息、如何购买、商品链接等
- 用户找不到直播间购买的商品
- 用户咨询直播专享价商品

##### 1.2 处理流程

###### 1.2.1 确认直播间信息
- 询问用户观看的直播间名称/主播名称
- 确认商品是在哪个直播间看到的
- 确认直播时间（是否已结束）

**话术示例**：
```
客服：您好，请问您是在哪个直播间看到的商品呢？可以提供主播名称或直播间名称吗？
用户：就是在李佳琦直播间
客服：好的，请问您还记得商品名称或者大概是什么类型的商品吗？
```

###### 1.2.2 商品查询方式
- 引导用户：直播间右下角「购物袋」图标查看全部商品
- 提供商品搜索：淘宝APP搜索「直播」→ 找到对应直播间 → 查看回放/商品列表
- 如知道商品名称：直接搜索商品，查看是否标注「直播专享」

**多方对话示例**：
```
用户：直播结束了，我之前看到的商品找不到了
客服：您可以通过以下方式找到：
      1. 打开淘宝APP，搜索该主播名称进入直播间
      2. 点击「购物袋」或「商品」标签查看历史商品
      3. 如商品有「直播专享」标识，可能仅限直播期间购买
用户：购物袋在哪里？
客服：在直播间右下角，有一个购物袋图标，点击即可查看全部商品列表。
```

###### 1.2.3 下单指引
- 直播间直接点击商品卡片 → 立即购买
- 注意：直播专享价需在直播间下单才生效
- 提醒用户领取直播间专属优惠券

**KCP 1: 专享价确认**
- 时效：下单前必须确认
- 检查点：用户是否从直播间点击商品卡片进入下单页面
- 如非直播间下单，不享受专享价

##### 1.3 Rule层约束

| 规则项 | 约束内容 | 违规后果 |
|--------|----------|----------|
| 直播专享价 | 仅限直播间内下单享受 | 非直播间下单按原价计算 |
| 优惠券领取 | 需在直播有效期内领取 | 过期无法补领（特殊情况除外） |
| 商品时效 | 部分商品仅限直播期间购买 | 直播结束可能下架 |

##### 1.4 常见问题
- Q: 找不到直播间购买的商品？
  A: 我的淘宝 → 我的订单 → 筛选「直播订单」
- Q: 直播结束了还能买吗？
  A: 部分商品支持回放购买，部分仅限直播期间

#### Step 2: 直播专享价问题

##### 2.1 场景识别
- 用户反馈直播专享价未生效、价格不符、优惠券无法使用
- 用户要求补差价

##### 2.2 处理流程

###### 2.2.1 核实订单信息
- 确认订单是否从直播间下单（非直播间下单不享受专享价）
- 查看订单是否使用直播专属优惠券
- 确认下单时间是否在直播有效期内

**话术示例**：
```
用户：我买的商品专享价没生效，还是原价
客服：我来帮您核实一下。请问您是通过直播间点击商品购买的吗？
用户：我是从直播间看到的，但是直接搜索商品买的
客服：了解了。直播专享价需要您从直播间点击商品卡片进入下单页面才能生效。
      您当前是从搜索页面下单的，所以无法享受专享价。
```

###### 2.2.2 专享价未生效原因排查
- 检查是否领取了直播间专属优惠券
- 确认商品SKU是否正确（部分SKU不参与活动）
- 核实用户是否满足优惠条件（如满减门槛）

**排查清单**：
```
□ 订单来源是否为直播间
□ 优惠券是否已领取
□ 优惠券是否在有效期内
□ 商品SKU是否参与活动
□ 是否满足优惠门槛（满减/满折）
```

###### 2.2.3 解决方案
- 如确系平台问题：引导申请价保或退差价
- 优惠券未领取：如直播已结束，可尝试联系商家补发
- 操作路径：我的淘宝 → 官方客服 → 价保中心 → 申请退差

**KCP 2: 差价处理**
- 时效：用户反馈后30分钟内给出处理方案
- 检查点：核实是否为平台/商家原因导致专享价未生效
- 补偿标准：按差价金额或等值优惠券补偿

##### 2.3 Rule层约束

| 规则项 | 约束内容 | 处理依据 |
|--------|----------|----------|
| 价保时效 | 订单支付后7天内可申请 | 超期不支持价保 |
| 差价退还 | 原路返回支付账户 | 1-3个工作日到账 |
| 优惠券补偿 | 视情况发放平台红包 | 需主管审批 |

#### Step 3: 主播承诺不兑现

##### 3.1 场景识别
- 用户投诉主播承诺的赠品未发、优惠券未到账、抽奖未兑现等
- 用户持有直播截图/录屏作为证据

##### 3.2 处理流程

###### 3.2.1 核实承诺内容
- 要求用户提供直播截图/录屏作为凭证
- 确认承诺具体内容：赠品名称、数量、发放条件
- 核实承诺时间：直播时间、承诺兑现期限

**话术示例**：
```
用户：主播说买这个送小样，我收到货没有
客服：您好，请问您有当时的直播截图或录屏吗？需要确认主播的具体承诺内容。
用户：有截图，我发给你
客服：好的，请您上传截图。同时请问主播承诺的赠品是什么？有什么领取条件吗？
```

###### 3.2.2 分类处理

**赠品未发**：
- 联系商家核实赠品库存和发货情况
- 如商家拒不发货，平台介入协调
- 协调不成，按虚假宣传处理，支持退款退货

**优惠券未到账**：
- 核实用户是否满足领券条件
- 检查优惠券发放记录
- 如确未发放，协调补发或补偿

**抽奖不兑现**：
- 核实抽奖规则和中奖名单
- 要求商家/主播提供中奖记录
- 拒不兑现按违规处理

**多方对话示例**：
```
用户：主播抽奖我中奖了，但是没收到奖品
客服：恭喜您中奖！我来帮您核实。请问您还记得抽奖的具体时间和奖品内容吗？
用户：上周三晚上，奖品是iPhone 15
客服：好的，我需要联系商家核实中奖名单和发货情况。请稍等。
      【联系商家后】
      您好，已联系商家核实。由于库存问题奖品延迟发放，预计3个工作日内发出。
      给您带来不便非常抱歉，我们为您申请50元平台红包作为补偿，您看可以吗？
```

##### 3.3 Rule层约束

| 规则项 | 约束内容 | 处罚措施 |
|--------|----------|----------|
| 虚假承诺 | 主播承诺未兑现 | 警告、扣分、限流 |
| 拒不整改 | 多次违规 | 暂停直播权限、封号 |
| 消费者权益 | 承诺未兑现 | 支持退款退货+平台补偿 |

**KCP 3: 承诺纠纷处理**
- 时效：48小时内完成核实并给出处理方案
- 检查点：是否有有效凭证（截图/录屏）
- 证据要求：直播截图（含时间戳）、主播承诺录音/录屏

#### Step 4: 直播退款退货

##### 4.1 场景识别
- 用户要求退/换货，涉及直播购买的商品
- 用户咨询直播专享订单售后规则

##### 4.2 处理流程

###### 4.2.1 确认订单类型
- 普通直播订单：按淘宝正常售后规则处理
- 直播专享订单：确认是否影响专享价退还
- 预售直播订单：按预售规则处理

###### 4.2.2 退款原因分类处理

**7天无理由退货**：
- 确认商品是否支持（定制、生鲜等特殊商品除外）
- 引导用户：我的订单 → 申请售后 → 退货退款

**质量问题退货**：
- 要求提供商品问题照片/视频
- 核实后支持退货退款，运费由商家承担

**描述不符**：
- 核实直播间描述与实物差异
- 支持退货退款，商家承担运费
- 严重不符可要求额外补偿

**话术示例**：
```
用户：直播买的衣服想退货
客服：好的，请问您退货的原因是什么呢？
用户：尺码不合适
客服：了解了。该商品支持7天无理由退货，请问您收货几天了？
用户：昨天收到的
客服：好的，在7天内可以申请。请进入「我的订单」找到该订单，
      点击「申请售后」→「退货退款」→选择「7天无理由」即可。
      需要注意的是，直播专享优惠券在退货后不会退还。
```

##### 4.3 Rule层约束

| 规则项 | 约束内容 | 备注 |
|--------|----------|------|
| 售后时效 | 商家48小时内处理 | 超时系统自动同意 |
| 退货时效 | 用户7天内寄出商品 | 自退款协议达成起 |
| 优惠券处理 | 直播专享券不退还 | 仅退实付金额 |
| 赠品处理 | 需一并退回 | 否则按价值扣除 |

**KCP 4: 售后处理**
- 时效：商家48小时内响应，用户7天内退货
- 检查点：商品是否影响二次销售
- 纠纷升级：商家拒绝合理退款，可申请平台介入

#### Step 5: 主播合作咨询

##### 5.1 场景识别
- 用户咨询如何成为主播、达人入驻、佣金结算、MCN合作等

##### 5.2 处理流程

###### 5.2.1 入驻类型识别
- **达人主播**：个人/自媒体，通过内容带货赚取佣金
- **店铺主播**：商家自播，推广自家店铺商品
- **MCN机构**：签约管理多个主播的经纪公司

###### 5.2.2 达人主播入驻指引
- 入驻条件：
  - 实名认证的淘宝账号
  - 年满18周岁
  - 具备一定的内容创作能力
- 入驻路径：淘宝APP → 我的 → 更多 → 直播中心 → 主播入驻
- 审核时间：一般3-7个工作日

**话术示例**：
```
用户：我想做淘宝主播，怎么入驻？
客服：您好，淘宝主播分为达人主播和店铺主播两种类型。请问您是想做个人内容带货，还是为自己的店铺直播呢？
用户：个人带货
客服：好的，达人主播入驻需要：
      1. 实名认证的淘宝账号
      2. 年满18周岁
      3. 具备内容创作能力
      入驻路径：淘宝APP → 我的 → 更多 → 直播中心 → 主播入驻
      提交资料后一般3-7个工作日审核完成。
```

###### 5.2.3 佣金结算说明
- 佣金比例：由商家设置，一般5%-50%不等
- 结算周期：确认收货后，次月结算
- 提现方式：绑定支付宝，自动提现
- 技术服务费：平台收取佣金的10%作为技术服务费

##### 5.3 Rule层约束

| 规则项 | 约束内容 | 备注 |
|--------|----------|------|
| 直播规范 | 遵守《淘宝直播管理规范》 | 违规将处罚 |
| 禁止行为 | 虚假宣传、刷单、诱导线下交易 | 警告至封号 |
| 结算门槛 | 确认收货后次月结算 | 退货订单不结算 |

### 附录：淘宝直播关键规则摘要

#### 1. 直播专享价规则
- 仅限直播间内下单享受
- 可与店铺优惠券叠加（以商品详情为准）
- 直播结束后，专享价可能失效

#### 2. 主播承诺规范
- 主播承诺需明确、具体、可执行
- 承诺应在直播画面显著位置展示规则
- 虚假承诺属于违规，平台将处罚

#### 3. 售后服务时效
- 商家响应时效：48小时
- 用户退货时效：7天（自退款协议达成起）
- 平台介入处理：3-5个工作日

#### 4. 佣金结算规则
- 结算时间：确认收货后次月
- 提现门槛：一般无门槛，具体以账户为准
- 税费：收入需依法纳税

#### 5. 违规处罚等级
- 一般违规：警告、扣分
- 严重违规：限流、暂停直播权限
- 特别严重：永久封号、清退
