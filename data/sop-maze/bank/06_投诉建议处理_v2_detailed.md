## Objective

**角色**：银行客户投诉处理专员/客服代表/投诉主管

**场景**：处理客户通过各渠道（电话、网点、信函、网络、监管转办）提交的投诉与建议

**目标**：依法依规、高效专业地处理客户投诉，确保15日内办结，维护客户权益和银行声誉

**多方对话系统**：
- **客户** ↔ **客服**（投诉受理、进度告知、结果反馈）
- **客服** ↔ **主管**（重大投诉升级、处理方案审批）
- **客服** ↔ **业务部门**（事实调查、责任认定、协调处理）
- **客服** ↔ **合规部门**（监管投诉、恶意投诉、法律风险）

## Standard Operating Procedures

### Step 0: 开场/受理

客户通过各渠道发起投诉或建议。

#### 0.1 投诉渠道矩阵

| 渠道 | 接入方式 | 响应时效 | 处理特点 |
|------|----------|----------|----------|
| 客服热线（955XX） | 电话接入 | 即时 | 主要渠道，需先安抚情绪 |
| 营业网点现场 | 大堂经理接待 | 即时 | 易引发围观，需快速隔离处理 |
| 官方网站/手机银行 | 在线客服/留言 | 即时/24小时内 | 需文字回复，留存完整 |
| 信函/电子邮件 | 邮件接收 | 收到后24小时内 | 正式渠道，需书面回复 |
| 监管转办（12378等） | 监管系统转办 | 2小时内 | 最高优先级，全程留痕 |
| 社交媒体/舆情 | 监测发现 | 发现后1小时内 | 传播快，需公关协同 |

#### 0.2 客户情绪识别与应对

| 情绪等级 | 表现特征 | 应对策略 | 话术要点 |
|----------|----------|----------|----------|
| 平和 | 理性陈述问题 | 正常受理流程 | 标准服务用语 |
| 不满 | 语气急躁、抱怨 | 积极倾听、表达理解 | "理解您的心情" |
| 愤怒 | 大声指责、威胁 | 先安抚情绪、再处理问题 | "非常抱歉让您生气" |
| 激动 | 哭闹、拍桌子 | 立即隔离、主管介入 | "请您冷静，我们一定解决" |
| 危险 | 扬言自杀、暴力 | 启动应急预案、报警 | "您的安全最重要" |

**【话术】开场安抚话术（情绪激动的客户）**：

```
客服："您好，我是投诉处理专员小王，请问怎么称呼您？"
客户："你们银行太不像话了！我要投诉！"
客服："非常理解您的心情，遇到这样的事情确实让人生气。请您先消消气，
      您的问题我一定会认真处理。我是专门负责投诉处理的，
      请您放心，给我几分钟时间了解情况，好吗？"
客户："...好吧"
客服："谢谢您的理解。请问您遇到了什么问题？我会详细记录并帮您解决。"
```

**【KCP】情绪安抚关键控制点**：
- 客户情绪激动时，必须先安抚再询问，不可直接进入询问流程
- 客户大声抱怨时，客服音量应降低20%，语速放慢30%
- 客户使用侮辱性语言时，保持专业态度，不反驳、不对抗
- 客户威胁升级（媒体、监管）时，立即标记紧急并上报

#### 0.3 身份核实流程

```
客户来电/来访 ──▶ 问候并自报身份 ──▶ 询问客户姓名 ──▶ 核实身份信息 ──▶ 确认身份通过

      ▼                ▼                  ▼              ▼

                   投诉专员XXX"                      （卡号/身份证/手机号）

**【话术】身份核实话术**：

```
客服："您好，我是XX银行客户服务中心投诉处理专员小李，工号1234。
      请问您贵姓？"
客户："我姓张"
客服："张先生您好，为了核实您的身份并保护您的账户安全，
      请问您能提供一下银行卡号后四位和开户时预留的手机号吗？"
客户："卡号后四位是6688，手机号138xxxx1234"
客服："好的，已核实您的身份。张先生，请问有什么可以帮您？"
```

### Step 1: 投诉登记

详细记录客户投诉信息，建立投诉工单。

#### 1.1 登记要素清单

| 要素类别 | 具体内容 | 必填性 | 备注 |
|----------|----------|--------|------|
| 客户信息 | 姓名、联系方式、证件号码 | 必填 | 用于身份核实和回访 |
| 账户信息 | 账号/卡号、开户行 | 选填 | 涉及资金交易时必填 |
| 投诉类型 | 服务/收费/产品/系统/人员 | 必填 | 影响处理部门分配 |
| 投诉事项 | 时间、地点、经过、涉及人员 | 必填 | 事实调查基础 |
| 客户诉求 | 退款、道歉、解释、赔偿、其他 | 必填 | 处理目标导向 |
| 证据材料 | 凭证、录音、截图、合同等 | 选填 | 支持投诉主张 |
| 特殊标记 | 监管投诉、媒体关注、群体事件 | 必填 | 影响处理优先级 |

#### 1.2 投诉类型速查表

| 投诉类型 | 常见情形 | 处理要点 | 责任部门 |
|----------|----------|----------|----------|
| 服务投诉 | 态度差、排队久、业务不熟 | 核实监控、道歉整改 | 网点/客服 |
| 收费投诉 | 不明扣费、收费标准争议 | 核查收费依据、协商退费 | 运营/财务 |
| 产品投诉 | 理财亏损、保险误导 | 核查销售合规性、协商补偿 | 零售/合规 |
| 系统投诉 | 系统故障、交易失败 | 技术排查、损失评估 | 科技/运营 |
| 信贷投诉 | 贷款被拒、利率争议 | 核查审批流程、解释政策 | 信贷/风险 |
| 信用卡投诉 | 年费争议、盗刷、催收 | 核查交易记录、协商方案 | 卡中心 |
| 信息投诉 | 信息泄露、骚扰电话 | 核查信息使用、整改措施 | 合规/科技 |

**【话术】信息登记话术**：

```
客服："张先生，为了准确记录您的问题，我需要询问几个细节，请您配合。
      首先，请问这个问题是什么时候发生的？"
客户："昨天我去你们网点办业务的时候"
客服："好的，是哪家网点呢？"
客户："XX路支行"
客服："明白了。请问具体是什么事情让您不满意？"
客户："我排队排了一个小时，结果那个柜员态度特别差！"
客服："非常抱歉给您带来不好的体验。请问您记得那位柜员的工号或姓名吗？"
客户："不记得了，是个女的"
客服："好的，我们会通过监控核实。请问您希望银行怎么处理这件事？"
客户："我要她跟我道歉！"
客服："明白，您的诉求我已记录。除了道歉，还有其他要求吗？
      比如对处理结果的反馈方式？"
```

#### 1.3 特殊情形识别

**【KCP】重复投诉识别关键控制点**：
- 系统自动识别：同一客户+同一事项+30天内
- 人工识别标志：客户提及"上次投诉""还没解决""又发生了"
- 处理方式：查询历史工单，询问是否有新情况

**【话术】重复投诉处理话术**：

```
客服："张先生，我查到您上个月就同一事项已经提交过投诉，
      当时我们已为您办理了退款并电话告知了处理结果。
      请问这次是有什么新的情况吗？"
客户："没有新情况，我就是觉得你们处理得太慢了！"
客服："理解您的心情。根据记录，您的投诉我们在5个工作日内就处理完毕了，
      没有超期。如果您对处理结果不满意，可以申请复议，
      我帮您转接复议专员，可以吗？"
```

**【KCP】恶意投诉识别关键控制点**：
- 识别标准（满足多项）：要求明显不合理赔偿、提供虚假证据、以投诉要挟、被认定为职业投诉人
- 处理方式：正常登记并按流程处理、标记恶意投诉标签、留存证据、不上当不妥协原则

### Step 2: 投诉分级

根据投诉性质、影响程度进行三级分类。

#### 2.1 分级标准矩阵

| 级别 | 判定标准 | 处理时限 | 审批权限 | 响应要求 |
|------|----------|----------|----------|----------|
| 一般投诉 | 普通服务纠纷、收费争议、单笔小额（<5万） | 5-10日办结 | 客服主管 | 正常流程 |
| 重大投诉 | 涉及资金安全、系统故障、批量客户、较大金额（5-50万） | 10-15日办结 | 部门负责人 | 主管介入 |
| 紧急投诉 | 群体性事件、监管转办、媒体关注、重大资金损失（>50万）、人身安全 | 即时响应，15日办结 | 分管行长 | 应急预案 |

#### 2.2 升级条件清单

**【KCP】投诉升级关键控制点**：

满足以下任一条件，投诉需升级处理：
- [ ] 客户明确要求升级
- [ ] 涉及金额5万元以上
- [ ] 涉及批量客户（3户以上）
- [ ] 可能引发媒体关注或群体性事件
- [ ] 监管转办或督办
- [ ] 处理人员与投诉事项有利害关系需回避
- [ ] 客户威胁自杀、暴力等极端行为
- [ ] 3次以上重复投诉

**【话术】升级告知话术**：

```
客服："张先生，您反映的问题涉及金额较大（/情况比较复杂），
      为了给您更专业的处理，我将为您升级至我们部门负责人亲自处理。
      负责人会在2小时内与您联系，您看可以吗？"
客户："你们不会是想推诿吧？"
客服："绝对不是推诿。这是我们对重要投诉的特别处理机制，
      由更高级别的人员介入，能够调动更多资源来解决问题。
      这是我的直线电话，如果负责人没有及时联系您，
      您可以直接打给我，我会督办到底。"
```

### Step 3A: 一般投诉调查流程

针对一般性投诉开展标准调查。

#### 3A.1 调查内容清单

| 调查项目 | 调查方式 | 责任部门 | 完成时限 |
|----------|----------|----------|----------|
| 业务记录核查 | 调阅系统交易流水、业务凭证 | 运营部门 | 1-2日 |
| 经办人员说明 | 听取涉事员工陈述 | 网点/部门 | 1-2日 |
| 客户证据核实 | 核对客户提供的凭证、录音等 | 客服部门 | 1日 |
| 监控录像调取 | 调取营业网点监控 | 安保部门 | 2-3日 |
| 事实经过确认 | 综合分析形成调查报告 | 客服部门 | 2-3日 |

**【话术】内部协调调查话术（客服→业务部门）**：

```
客服："张经理，有个投诉需要你们部门配合调查。
      客户投诉昨天在XX网点办理转账业务时，柜员操作失误导致转账失败，
      客户因此损失了利息。"
业务部张经理："把客户信息发我，我查一下。"
客服："客户姓名：李明，账号：6222xxxxxxxx1234，业务时间：昨天14:30左右。"
业务部张经理："查到了，确实有这笔业务记录。当时系统有点卡，
               柜员操作了两次才成功。"
客服："客户说因为转账延迟，他的一笔理财没买上，损失了预期收益。"
业务部张经理："这个情况我们需要核实一下。柜员操作是否有违规？"
客服："从记录看没有违规，但客户体验确实受影响。"
业务部张经理："明白了，我们查一下当时的监控，确认柜员操作是否规范。
               明天上午给你回复。"
客服："好的，这个投诉客户比较着急，请尽快处理。"
```

- 处理过程全程留痕
- 答复内容需经合规审核
- 按时向监管报送进展和结果

### Step 4: 调查核实

全面调查投诉事项，收集证据材料。

#### 4.1 调查要点清单

| 要点 | 具体要求 | 注意事项 |
|------|----------|----------|
| 客观公正 | 不偏听偏信，全面收集证据 | 既要听客户陈述，也要听员工说明 |
| 证据完整 | 书面材料、电子记录、录音录像 | 确保证据链完整 |
| 时效把控 | 调查应在规定时限内完成 | 复杂情况及时申请延期 |
| 书面报告 | 形成书面调查报告 | 报告需经审核 |

#### 4.2 调查流程

```
接收投诉 ──▶ 初步分析 ──▶ 证据收集 ──▶ 事实认定 ──▶ 责任判定 ──▶ 方案拟定
    │            │            │            │            │
    ▼            ▼            ▼            ▼            ▼
  了解概况     确定方向     多方取证     综合判断     提出建议
```

**【话术】调查进展反馈话术**：

```
客服："张先生，关于您反映的问题，我已经完成了初步调查。
      经查，您提到的扣费确实是系统误扣，我们深表歉意。
      目前我正在拟定处理方案，预计明天上午可以给您正式答复。
      您看可以吗？"
客户："那我的钱什么时候能退回来？"
客服："处理方案确定后，退款会在3个工作日内到账。
      我会全程跟进，确保及时到账。"
```

### Step 5: 处理决策

根据调查结果制定处理方案。

#### 5.1 决策类型对比

| 决策类型 | 适用情形 | 处理动作 | 审批要求 |
|----------|----------|----------|----------|
| 直接处理 | 简单纠纷、责任明确 | 直接答复、办理退款/调整 | 客服主管审批 |
| 协商解决 | 需要与客户沟通协商 | 联系客户协商解决方案 | 部门负责人审批 |
| 升级上报 | 复杂疑难、监管关注、重大赔偿 | 上报高级管理层审批 | 分管行长审批 |

#### 5.2 处理方案要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 事实认定 | 对投诉事项的事实判断 | "经调查，该笔扣费系系统误扣" |
| 责任认定 | 对责任归属的判定 | "属于我行系统故障导致的误扣" |
| 处理依据 | 依据的规章制度 | "根据《XX银行服务收费管理办法》第X条" |
| 处理决定 | 具体的处理措施 | "退还误扣款项50元，补偿同期存款利息" |
| 整改措施 | 预防类似问题的措施 | "已修复系统漏洞，加强日常监控" |

**【话术】处理结果告知话术（直接处理）**：

```
客服："张先生，关于您反映的扣费问题，我已经调查清楚了。
      经核实，这笔50元的扣费确实是系统误扣，属于我行的责任。
      我们深表歉意，并为您制定了以下处理方案：
      第一，误扣的50元将在3个工作日内退还到您的账户；
      第二，补偿您同期存款利息0.5元；
      第三，已修复系统漏洞，避免再次发生。
      您对这个处理结果满意吗？"
客户："嗯，还行吧"
客服："感谢您的理解。稍后我会把书面处理结果发送到您手机。
      还有其他可以帮您的吗？"
```

**【话术】协商解决方案话术**：

```
客服："张先生，关于您反映的理财亏损问题，我已经调查清楚了。
      经核实，当时客户经理在销售过程中确实存在风险提示不充分的问题。
      考虑到您的情况，我们提出以下协商方案：
      银行承担部分责任，补偿您2万元，您看可以接受吗？"
客户："2万太少了，我亏了8万呢！"
客服："理解您的心情。这个补偿金额是根据责任划分确定的。
      如果您不满意，我可以帮您申请复议，或者您也可以向
      银行业调解中心申请第三方调解，这是免费的。您看哪种方式更合适？"
客户："那再给我加1万"
客服："这个金额我需要向领导申请。请您稍等，我请示一下。"

### Step 6: 客户反馈

将处理结果告知客户，确认满意度。

#### 6.1 反馈要求清单

| 要求 | 具体内容 | 注意事项 |
|------|----------|----------|
| 书面或电话告知 | 以书面或电话形式告知处理结果 | 监管投诉需书面回复 |
| 说明事实认定 | 清晰说明调查认定的事实 | 客观准确 |
| 说明处理依据 | 说明依据的规章制度 | 引用具体条款 |
| 说明处理决定 | 明确告知处理决定 | 具体可执行 |
| 告知申诉权利 | 告知客户申诉/复议权利 | 尊重客户权利 |
| 记录客户意见 | 记录客户对处理结果的意见 | 无论满意与否 |

#### 6.2 客户反馈处理分支

```
告知处理结果 ──▶ 客户接受 ──▶ 进入结案归档
      │
      ├──▶ 客户不接受 ──▶ 再次解释 ──▶ 客户接受 ──▶ 结案归档
      │                      │
      │                      └──▶ 客户仍不接受 ──▶ 记录后结案
      │
      ├──▶ 客户要求复议 ──▶ 启动复议流程 ──▶ 重新调查/上级复核
      │
      └──▶ 客户表示将向监管投诉 ──▶ 告知已处理完毕
                                   尊重客户权利 ──▶ 记录后结案
```

**【话术】客户不接受处理结果话术**：

      您希望选择哪种方式？"

      如果您不信任复议，也可以直接申请第三方调解。

| 监管转办 | 部门存档 | 向监管报送结案报告 |

**【KCP】结案归档关键控制点**：
- 投诉资料仅限处理相关人员查阅
- 禁止将投诉信息用于非工作目的
- 电子资料加密存储，纸质资料专柜保管
- 投诉处理完毕资料保存不少于3年
