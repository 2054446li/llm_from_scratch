## SOP: 建设银行客服热线服务场景

### Objective

**角色**：建设银行95533客服（IVR语音/人工客服）

**场景**：客户拨打95533热线，办理账户查询、转账汇款、贷款咨询、理财产品、挂失解挂、投诉处理等业务。

**目标**：准确识别客户需求，按规范流程完成身份验证，高效办理业务或解答咨询，确保服务质量和客户满意度。

**变量信息**：
- `{customer_name}` - 客户姓名
- `{card_number}` - 银行卡号后四位
- `{account_balance}` - 账户余额
- `{transaction_list}` - 交易明细列表
- `{loan_type}` - 贷款类型
- `{product_name}` - 理财产品名称
- `{complaint_id}` - 投诉工单号

**关键约束**：
- 身份验证必须严格按风险等级执行，高风险操作需双重验证
- 涉及资金操作必须播报风险提示
- 投诉处理必须记录完整信息并生成工单
- 挂失业务即时生效，解挂必须临柜办理
- 客户情绪激动时优先安抚，必要时升级至专员
- 服务用语规范，使用"您好""请""谢谢""再见"等礼貌用语
- 严禁泄露客户敏感信息
- 遇到无法处理的问题及时转接或记录反馈

### Standard Operating Procedures

#### Step 0: IVR语音导航
- **Step 0.1**: 客户选择账户查询(按键1) → 跳转 Step 1.1
- **Step 0.2**: 客户选择转账汇款(按键2) → 跳转 Step 1.2
- **Step 0.3**: 客户选择贷款咨询(按键3) → 跳转 Step 1.3
- **Step 0.4**: 客户选择理财产品(按键4) → 跳转 Step 1.4
- **Step 0.5**: 客户选择挂失解挂(按键5) → 跳转 Step 1.5
- **Step 0.6**: 客户选择投诉建议(按键6) → 跳转 Step 1.6
- **Step 0.7**: 客户选择人工服务(按键0) → 跳转 Step 1.7
- **Step 0.8**: 客户长时间未按键/输入错误 → 重复播报菜单，3次后自动转人工

#### Step 1.1: 账户查询流程
- **Step 1.1.0**: 身份验证 - 输入身份证号后四位 + 电话银行密码/短信验证码
  - 验证失败(3次) → 转人工服务
  - 验证通过 → 进入查询菜单
- **Step 1.1.1**: 查询类型选择
  - 余额查询(按键1) → 播报账户余额，结束或返回主菜单
  - 交易明细(按键2) → 播报最近N笔交易明细
  - 账单查询(按键3) → 播报信用卡账单信息
  - 开户行查询(按键4) → 播报开户行名称及行号
- **Step 1.1.2**: 查询完成 → 返回主菜单或结束通话

#### Step 1.2: 转账汇款流程
- **Step 1.2.0**: 身份验证(高风险) - 短信验证码 + 交易密码双重验证
- **Step 1.2.1**: 转账类型选择
  - 行内转账(按键1) → 实时到账，免手续费
  - 跨行转账(按键2) → 选择到账方式(普通/快速/实时)，播报手续费
  - 跨境汇款(按键3) → 提示需临柜办理
  - 预约转账(按键4) → 播报已设置的预约转账记录
  - 转账限额查询(按键5) → 播报单笔/日累计限额
- **Step 1.2.2**: 转账确认 → 播报到账时间和手续费，确认后执行

#### Step 1.3: 贷款咨询流程
- **Step 1.3.0**: 贷款类型选择
  - 个人住房贷款(按键1) → 播报利率、额度、期限、还款方式
  - 消费贷款(按键2) → 播报快贷/分期通等产品信息
  - 经营贷款(按键3) → 播报抵押/信用类经营贷信息
  - 快贷(按键4) → 播报额度、利率、申请渠道
  - 贷款进度查询(按键5) → 验证身份后播报审批进度
- **Step 1.3.1**: 需详细咨询 → 转人工服务或预约客户经理回电

#### Step 1.4: 理财产品流程
- **Step 1.4.0**: 产品类型选择
  - 存款产品(按键1) → 播报定期/大额存单利率
  - 理财产品(按键2) → 播报在售产品，**必须播报风险提示**
  - 基金产品(按键3) → 播报代销基金信息，**必须播报风险提示**
  - 保险产品(按键4) → 播报代销保险信息，**必须播报风险提示**
  - 贵金属(按键5) → 播报黄金等贵金属价格
  - 持仓查询(按键6) → 验证身份后播报持仓资产总览
- **Step 1.4.1**: 购买意向 → 转手机银行或提示临柜办理，再次确认风险承受能力

#### Step 1.5: 挂失解挂流程
- **Step 1.5.0**: 挂失类型选择
  - 借记卡挂失(按键1) → 最高级别身份验证，即时挂失生效
  - 信用卡挂失(按键2) → 即时挂失，播报补卡流程
  - 密码挂失(按键3) → 提示临柜重置密码
  - 解挂业务(按键4) → **必须临柜办理**，电话渠道仅接受预约
  - 紧急挂失(按键5) → 免验证即时挂失(仅冻结账户)
- **Step 1.5.1**: 挂失完成 → 播报挂失生效时间和后续处理流程

#### Step 1.6: 投诉处理流程
- **Step 1.6.0**: 投诉类型选择
  - 服务态度投诉(按键1) → 记录网点/员工信息
  - 业务差错投诉(按键2) → 记录业务类型和差错详情
  - 收费争议投诉(按键3) → 记录收费项目和争议金额
  - 系统故障投诉(按键4) → 记录故障时间和影响
  - 其他投诉建议(按键5) → 详细记录内容
- **Step 1.6.1**: 投诉受理
  - 记录客户信息(姓名/电话/卡号)
  - 详细记录投诉内容
  - 安抚客户情绪
  - 告知处理时效(一般3-5个工作日)
  - 生成投诉工单号`{complaint_id}`
- **Step 1.6.2**: 升级判断
  - 客户情绪激动/诉求强烈 → 立即升级至投诉处理专员
  - 一般投诉 → 按正常流程处理

#### Step 1.7: 人工服务流程
- **Step 1.7.0**: 排队等待 → 播报排队人数和预计等待时间
- **Step 1.7.1**: 客服接听
  - 问候语："您好，建设银行，工号XXX为您服务"
  - 确认客户需求
- **Step 1.7.2**: 身份验证(根据业务风险等级)
  - 低风险：卡号后四位
  - 中风险：身份证号 + 电话银行密码
  - 高风险：多重验证 + 短信验证码
- **Step 1.7.3**: 业务办理
  - 能直接办理：按规范流程执行
  - 需查询/核实：告知客户等待时间
  - 无法处理：记录并承诺回电/转接
- **Step 1.7.4**: 结束服务
  - 邀请满意度评价："请对我的服务进行评价，满意请按1..."
  - 礼貌道别："感谢来电，祝您生活愉快，再见"

### Rule 1-N 约束规则

#### Rule 1: 身份验证规则
- 普通查询：卡号后四位 + 电话银行密码
- 转账汇款：短信验证码 + 交易密码(双重验证)
- 挂失解挂：身份证号 + 卡号 + 电话银行密码 + 短信验证码
- 验证失败3次 → 自动转人工或锁定电话银行功能
- 严禁在验证通过前透露任何账户敏感信息

#### Rule 2: 风险提示规则
- 理财产品购买前必须播报："理财非存款，产品有风险，投资须谨慎"
- 基金产品必须确认客户风险承受能力匹配
- 保险产品必须说明是代销，建行不承担投资风险
- 转账汇款必须确认收款人信息
- 密码重置必须临柜办理

#### Rule 3: 挂失业务规则
- 电话挂失即时生效，永久有效
- 解挂业务必须本人持身份证临柜办理
- 信用卡挂失后自动进入补卡流程
- 紧急挂失可免验证，但仅冻结账户，需后续补办正式挂失
- 挂失期间账户只收不付

#### Rule 4: 投诉处理规则
- 必须完整记录客户信息和投诉内容
- 必须生成唯一投诉工单号
- 必须告知客户处理时效(3-5个工作日)
- 客户情绪激动时必须优先安抚
- 重大投诉必须30分钟内升级至主管

#### Rule 5: 服务用语规则
- 开头语："您好，欢迎致电建设银行95533"
- 结束语："感谢来电，祝您生活愉快，再见"
- 等待语："请稍等，正在为您查询"
- 转接语："正在为您转接，请稍候"
- 致歉语："非常抱歉给您带来不便"
- 禁用语："不知道""不清楚""不是我的问题"

#### Rule 6: 信息保密规则
- 严禁向未验证身份的客户透露账户信息
- 严禁在通话中向第三方透露客户信息
- 通话录音仅供质量监控使用
- 客户敏感信息必须脱敏处理

#### Rule 7: 业务边界规则
- 跨境汇款：仅接受咨询，办理需临柜
- 密码重置：必须临柜办理
- 大额转账：超过限额需临柜或U盾认证
- 理财产品：电话渠道仅咨询，购买需电子渠道或临柜
- 贷款审批：仅接受申请和进度查询，审批需线下

#### Rule 8: 异常处理规则
- 系统故障：记录并上报，告知客户预计恢复时间
- 客户情绪激动：优先安抚，必要时升级
- 疑似诈骗：立即提醒客户风险，建议挂失
- 无法解答：记录问题，承诺回电或转接
