## Objective

本SOP旨在规范银行信贷客服的贷款咨询与申请服务流程，确保：

1. **专业合规**：严格遵守监管要求，保护客户信息安全，防范金融诈骗
2. **精准匹配**：根据客户需求和资质，推荐最合适的贷款产品
3. **透明清晰**：利率、费用、条件说明清晰，不误导客户
4. **高效服务**：快速响应客户需求，缩短咨询到申请的时间

**多方对话系统**：
- **客户** ↔ **客服**（电话咨询、需求沟通、方案讲解）
- **客服** ↔ **信贷系统**（资质查询、额度测算、信息记录）
- **客服** ↔ **风控部门**（疑难案例、特殊审批、风险预警）
- **客户** ↔ **网点/客户经理**（面签、资料提交、后续跟进）

## Standard Operating Procedures

### 1. 开场接待

#### 1.1 欢迎问候

##### 1.1.1 标准问候流程

```
电话接入 ──▶ 系统弹屏 ──▶ 身份确认 ──▶ 欢迎语 ──▶ 询问需求
    │            │            │            │            │
    ▼            ▼            ▼            ▼            ▼
  来电显示     客户信息      核实称呼      标准话术      引导说明
  号码识别     历史记录      确认身份      热情专业      明确意图
```

**【话术】开场问候话术**

```
客服："您好，欢迎致电XX银行信贷服务中心，我是客服专员小李，工号1234。请问有什么可以帮您？"
客户："我想咨询一下贷款"
客服："好的，很高兴为您服务。请问您贵姓？"
客户："我姓张"
客服："张先生您好，请问您是想咨询房贷、消费贷还是经营贷呢？"
```

**【话术】老客户识别话术**

```
客服："张先生您好，系统显示您是我行老客户，之前咨询过消费贷。请问这次是想了解贷款进度还是有新的贷款需求？"
客户："我想再咨询一下房贷"
客服："好的，我为您转接房贷专员，请稍等"
```

#### 1.2 需求识别

##### 1.2.1 需求类型判定

| 客户表述 | 需求类型 | 判定依据 | 跳转步骤 |
|----------|----------|----------|----------|
| "买房/按揭/二手房/公积金" | 房贷 | 明确购房需求 | Step 3.1 |
| "装修/旅游/教育/医疗/买车/日常消费" | 消费贷 | 个人消费需求 | Step 3.2 |
| "开店/进货/周转/扩大经营/企业用" | 经营贷 | 经营周转需求 | Step 3.3 |
| "想贷款/借钱/利率多少" | 未明确 | 需进一步挖掘 | Step 2 |
| "随便问问/了解一下" | 低意向 | 需引导明确 | Step 2 |

**【KCP】需求识别关键控制点**：
- 必须在30秒内明确客户贷款类型意向
- 对于需求不明确客户，使用开放式问题引导
- 记录客户来源渠道（广告/转介绍/老客户）

#### 1.3 骚扰/无关来电处理

##### 1.3.1 识别标准与处理

| 类型 | 识别特征 | 处理方式 | 话术 |
|------|----------|----------|------|
| 推销电话 | 推销其他产品/服务 | 礼貌拒绝，结束通话 | "抱歉，这里是贷款咨询热线，如需贷款服务欢迎来电，再见" |
| 骚扰电话 | 无意义对话/恶意骚扰 | 警告后结束 | "您的来电已记录，如需贷款服务请正常咨询，再见" |
| 误拨电话 | 明显打错/非贷款需求 | 礼貌告知，结束通话 | "您可能打错了，这里是XX银行信贷中心，再见" |
| 竞品调研 | 询问内部数据/策略 | 拒绝透露，礼貌结束 | "抱歉，这些信息不便透露，感谢来电，再见" |

#### 1.4 敏感信息处理

##### 1.4.1 敏感话题识别与处理

| 敏感类型 | 识别特征 | 处理方式 | 升级路径 |
|----------|----------|----------|----------|
| 涉政话题 | 涉及政治敏感内容 | 立即制止，转移话题 | 无效则结束 |
| 涉黄/暴力 | 不当内容 | 严肃警告，结束通话 | 记录并上报 |
| 威胁恐吓 | 言语威胁 | 保持冷静，记录信息 | 立即上报主管 |
| 投诉升级 | 强烈不满/要求投诉 | 安抚情绪，转接专员 | 转投诉处理组 |
| 诈骗嫌疑 | 明显诈骗话术 | 提醒客户，结束通话 | 标记风险号码 |

**【话术】敏感话题处理话术**

```
客户：（涉及敏感话题）
客服："张先生，我们专注于贷款咨询服务，这个话题不在服务范围内。请问您有贷款方面的需求吗？"
客户：（继续敏感话题）
客服："抱歉，如果您没有贷款咨询需求，我将结束通话。如有需要欢迎再次来电，再见"
```

### 2. 需求挖掘

#### 2.1 房贷需求挖掘

##### 2.1.1 房贷需求要素

| 要素 | 询问目的 | 标准话术 |
|------|----------|----------|
| 房屋类型 | 确定首付比例 | "请问您购买的是首套房还是二套房？" |
| 房屋总价 | 测算贷款额度 | "请问您看中的房子总价大概是多少？" |
| 首付能力 | 评估首付准备 | "您目前准备了多少首付款？" |
| 购房区域 | 了解当地政策 | "房子是在哪个城市/区域？" |
| 购房进度 | 确定紧急程度 | "您已经签约了吗？还是正在看房？" |

**【话术】房贷需求挖掘话术**

```
客服："张先生，请问您购买的是首套房还是二套房？"
客户："首套房，刚需"
客服："好的，首套房政策比较优惠。请问房子总价大概多少？您准备了多少首付？"
客户："房子200万，准备了40万"
客服："明白了，首付40万，需要贷款160万。请问您月收入大概多少？这关系到还款能力评估"
客户："我月薪1万5，我爱人8千"
客服："您家庭月收入2.3万，还款能力充足。我为您详细介绍房贷产品"
```

#### 2.2 消费贷需求挖掘

##### 2.2.1 消费贷需求要素

| 要素 | 询问目的 | 标准话术 |
|------|----------|----------|
| 消费用途 | 确认合规用途 | "请问贷款具体用于什么消费？" |
| 资金缺口 | 确定贷款金额 | "您的总预算是多少？还差多少资金？" |
| 用款时间 | 确定紧急程度 | "您大概什么时候需要这笔资金？" |
| 还款来源 | 评估还款能力 | "您计划用什么收入来还款？" |
| 现有负债 | 评估负债率 | "您目前还有其他贷款或信用卡欠款吗？" |

**【话术】消费贷需求挖掘话术**

```
客服："请问您贷款具体用于什么消费呢？"
客户："想装修房子"
客服："装修是个大额支出。请问您的装修预算是多少？目前资金缺口多大？"

客服："了解了。请问您计划什么时候开工？大概什么时候需要这笔钱？"
客户："下个月开工，希望这个月能到位"
客服："时间比较紧。请问您月收入大概多少？我帮您评估一下能贷多少"
```

### 3. 产品介绍

#### 3.1 房贷产品介绍

##### 3.1.1 房贷产品要素

| 项目 | 首套房 | 二套房 | 说明 |
|------|--------|--------|------|
| 首付比例 | 最低15% | 最低25% | 以当地政策为准 |
| 贷款利率 | LPR-20BP起（约3.3%） | LPR+20BP起（约3.7%） | 以实际审批为准 |
| 贷款期限 | 最长30年 | 最长30年 | 年龄+期限≤70 |
| 最高额度 | 房屋总价85% | 房屋总价75% | 受还款能力限制 |
| 还款方式 | 等额本息/等额本金 | 等额本息/等额本金 | 可自主选择 |

**【话术】房贷产品介绍话术**

```
客服："张先生，我为您介绍我行房贷产品。首套房利率LPR-20BP起，当前约3.3%，首付比例最低15%，期限最长30年。支持等额本息和等额本金两种还款方式。以您的情况，贷款160万，期限30年，等额本息月供约7000元，在您家庭收入承受范围内"
客户："利率还能再低吗？"
客服："具体利率根据您的征信、收入等综合评估，优质客户可享受更优惠利率。以实际审批结果为准"
```

**【话术】利率说明话术（必含合规提示）**

```
客服："我行房贷利率执行LPR浮动利率机制。首套房利率为LPR-20个基点起，当前LPR为3.5%，所以最低约3.3%。但具体利率要根据您的征信情况、收入水平等综合评估确定，最终以审批结果为准"
```

##### 3.1.2 还款方式对比

| 对比项 | 等额本息 | 等额本金 |
|--------|----------|----------|
| 月供特点 | 每月相同 | 逐月递减 |
| 前期压力 | 较小 | 较大 |
| 总利息 | 较多 | 较少 |
| 适合人群 | 收入稳定者 | 前期资金充裕者 |
| 计算公式 | 月供=[本金×月利率×(1+月利率)^n]÷[(1+月利率)^n-1] | 首月=(本金÷n)+(本金×月利率)，每月递减 |

**【话术】还款方式推荐话术**

```
客服："两种还款方式，我帮您对比一下。等额本息每月还款固定约7000元，适合收入稳定的您；等额本金首月还9000多，之后逐月减少，总利息能省不少。您看哪种更适合？"
客户："我想总利息少点"
客服："那推荐等额本金。不过前期月供较高，您确认能承受吗？"
```

#### 3.2 消费贷产品介绍

##### 3.2.1 消费贷产品要素

| 项目 | 内容 |
|------|------|
| 适用对象 | 有消费需求的个人客户 |
| 贷款额度 | 最高50万元 |
| 贷款利率 | 年利率3.5%起，根据信用评分浮动 |
| 贷款期限 | 最长5年 |
| 还款方式 | 等额本息、先息后本、随借随还 |
| 申请条件 | 年满22周岁，有稳定收入，征信良好 |
| 放款时间 | 线上最快当天，线下1-3个工作日 |

**【话术】消费贷产品介绍话术**

```
客服："我行消费贷年利率3.5%起，额度最高50万，期限最长5年，无需抵押，凭信用申请。可用于装修、教育、旅游等合规消费场景。以您15万的需求，期限3年，年利率4%的话，等额本息月供约4400元"
客户："不需要抵押是吧？"
客服："是的，纯信用贷款。但额度会根据您的收入、征信等综合评估，以审批结果为准"
```

##### 3.2.2 消费贷还款方式

| 还款方式 | 特点 | 适用场景 |
|----------|------|----------|
| 等额本息 | 每月还款固定 | 收入稳定，规划明确 |
| 先息后本 | 前期只还利息，到期还本金 | 短期周转，预期有大额收入 |
| 随借随还 | 按日计息，灵活还款 | 资金需求不确定 |

#### 3.3 经营贷产品介绍

##### 3.3.1 经营贷产品要素

| 项目 | 信用类 | 抵押类 |
|------|--------|--------|
| 最高额度 | 100万元 | 1000万元 |
| 贷款利率 | 年利率3.5%起 | 年利率3.2%起 |
| 贷款期限 | 最长3年 | 最长10年 |
| 申请条件 | 营业执照满1年，有实际经营 | 有符合条件的抵押物 |
| 放款方式 | 自主支付（50万以下） | 受托支付（50万以上） |

**【话术】经营贷产品介绍话术**

```
客服："我行经营贷分信用类和抵押类。信用类无需抵押，最高100万，年利率3.5%起；抵押类需房产抵押，最高1000万，年利率3.2%起。您有房产可以抵押吗？"
客户："有，但还在还按揭"
客服："按揭房也可以申请二抵，或先结清再抵押。具体方案需要根据房产估值和剩余按揭计算"
```

##### 3.3.2 抵押物要求

| 抵押物类型 | 抵押率 | 要求 |
