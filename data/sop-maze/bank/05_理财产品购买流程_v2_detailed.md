## Objective

本SOP旨在规范银行理财产品销售全流程，确保：

1. **合规销售**：严格执行监管要求，落实适当性管理、双录、冷静期等制度
2. **风险揭示**：充分揭示产品风险，禁止承诺保本保收益
3. **客户权益保护**：确保客户在充分知情的前提下自主决策
4. **服务质量**：提供专业、规范的理财顾问服务

**多方对话系统**：
- **客户** ↔ **理财经理**（需求沟通、产品介绍、风险揭示）
- **客户** ↔ **系统**（风险评估、电子签约、交易确认）
- **理财经理** ↔ **系统**（产品查询、适当性匹配、双录留痕）
- **客户/理财经理** ↔ **合规审核**（大额交易、复杂产品审核）

## Standard Operating Procedures

### Step 1: 开场问候与需求了解

#### 1.1 客户分流判断

| 客户类型 | 判断标准 | 处理方式 | 跳转步骤 |
|----------|----------|----------|----------|
| 有明确购买意向 | 主动询问理财产品、表示想购买 | 进入风险评估流程 | Step2 |
| 无购买意向 | 只是看看、随便咨询、暂无需求 | 礼貌结束或提供资料 | Step9 |
| 咨询其他业务 | 询问存款/贷款/信用卡等非理财业务 | 转接对应业务线 | Step8 |
| 投诉/异议 | 对既往购买产品不满、要求赎回 | 转接客诉处理流程 | 客诉流程 |

**【话术】开场问候话术**：

```
理财经理："您好，欢迎光临XX银行。我是理财经理小李，请问有什么可以帮您？"
客户："我想了解一下理财产品"
理财经理："好的，请问您之前在我行购买过理财产品吗？今天是想咨询还是准备购买呢？"
```

#### 1.2 需求了解要点

| 了解维度 | 询问内容 | 目的 |
|----------|----------|------|
| 投资经验 | 是否购买过理财/基金/股票 | 判断客户投资成熟度 |
| 资金规模 | 计划投资金额（大致区间） | 匹配产品起购金额 |
| 投资期限 | 短期（<1年）/中期（1-3年）/长期（>3年） | 匹配产品期限 |
| 流动性需求 | 是否需要随时支取 | 选择开放/封闭式产品 |
| 收益预期 | 期望收益率区间 | 管理收益预期 |

**【话术】需求了解话术**：

```
理财经理："为了更好地为您推荐合适的产品，我想了解几个问题：
1. 您之前购买过理财产品吗？大概有多少投资经验？
2. 您这次计划投资多少资金？
3. 这笔钱大概多久不会用到？
4. 您对收益有什么期望吗？"
```

### Step 2: 风险评估

#### 2.1 评估状态查询

| 评估状态 | 判定标准 | 处理方式 |
|----------|----------|----------|
| 首次评估 | 无历史评估记录 | 引导填写风险评估问卷 |
| 评估有效 | 评估日期≤1年 | 直接查询风险等级，进入适当性匹配 |
| 评估过期 | 评估日期>1年 | 提示过期，重新进行评估 |
| 评估失效 | 客户财务状况发生重大变化 | 建议重新评估 |

**【KCP】风险评估关键控制点**：
- **KCP-2.1** 必须确认客户身份，禁止代客测评
- **KCP-2.2** 评估问卷必须由客户本人独立填写
- **KCP-2.3** 高龄客户（≥65岁）需额外风险提示
- **KCP-2.4** 评估结果必须告知客户并确认理解

#### 2.2 风险评估问卷

| 评估维度 | 问题示例 | 选项设置 |
|----------|----------|----------|
| 投资经验 | 您有多少年投资经验？ | 无/1年以下/1-3年/3-5年/5年以上 |
| 投资期限 | 您计划的投资期限是？ | 1年以内/1-3年/3-5年/5年以上 |
| 投资目标 | 您的投资目标是？ | 保本保值/稳健增值/平衡配置/追求高收益 |
| 风险承受意愿 | 您能接受的最高亏损比例？ | 不能亏损/5%以内/10%以内/20%以内/30%以上 |
| 收入稳定性 | 您的收入稳定性如何？ | 非常稳定/比较稳定/一般/不太稳定/很不稳定 |
| 资产状况 | 投资资金占您总资产的比例？ | 10%以下/10-30%/30-50%/50-80%/80%以上 |
| 投资知识 | 您对投资理财的了解程度？ | 完全不了解/了解较少/一般/比较了解/非常了解 |

**【话术】风险评估引导话术**：

```
理财经理："根据监管要求，购买理财产品前需要进行风险评估。这个评估将帮助我们了解您的风险承受能力，为您推荐合适的产品。评估结果有效期一年，请问您之前做过吗？"
客户："没有，第一次买"
理财经理："好的，我现在为您进行风险评估，大概需要3-5分钟。请您根据实际情况如实填写，这将直接影响我们能为您推荐的产品范围。"
```

#### 2.3 风险等级生成

| 客户风险等级 | 对应分数区间 | 等级描述 | 可购买产品等级 |
|--------------|--------------|----------|----------------|
| C1（保守型） | 0-20分 | 风险承受能力极低，追求本金安全 | R1 |
| C2（稳健型） | 21-40分 | 风险承受能力较低，追求稳健收益 | R1-R2 |
| C3（平衡型） | 41-60分 | 风险承受能力中等，可接受小幅波动 | R1-R3 |
| C4（成长型） | 61-80分 | 风险承受能力较高，追求较高收益 | R1-R4 |
| C5（进取型） | 81-100分 | 风险承受能力很高，可接受大幅波动 | R1-R5 |

**【话术】评估结果告知话术**：

```
理财经理："根据您的评估结果，您的风险等级为C3（平衡型）。这意味着您可以购买R1、R2、R3风险等级的理财产品。R1为低风险，R2为中低风险，R3为中等风险。请问您对这个结果有疑问吗？"
```

### Step 3: 适当性匹配

#### 3.1 匹配原则

| 客户等级 | 可购买产品等级 | 禁止购买 |
|----------|----------------|----------|
| C1（保守型） | R1 | R2-R5 |
| C2（稳健型） | R1、R2 | R3-R5 |
| C3（平衡型） | R1、R2、R3 | R4、R5 |
| C4（成长型） | R1、R2、R3、R4 | R5 |
| C5（进取型） | R1、R2、R3、R4、R5 | 无 |

**【KCP】适当性匹配关键控制点**：
- **KCP-3.1** 严禁向客户销售风险等级高于其承受能力的产品
- **KCP-3.2** 必须留存匹配记录，证明已履行适当性义务
- **KCP-3.3** 客户要求超风险购买时必须拒绝并解释原因

#### 3.2 产品筛选维度

| 筛选维度 | 客户偏好 | 匹配逻辑 |
|----------|----------|----------|
| 风险等级 | 根据客户C等级 | 只能选择≤客户等级的产品 |
| 投资期限 | 短期/中期/长期 | 匹配产品期限 |
| 起购金额 | 客户计划投资金额 | 客户资金≥产品起购金额 |
| 产品类型 | 固收类/混合类/权益类 | 根据风险等级限制 |
| 收益类型 | 保本浮动/非保本浮动 | C1客户优先保本型 |
| 开放类型 | 开放式/封闭式 | 根据流动性需求 |

**【话术】产品推荐话术**：

```
理财经理："根据您的C3（平衡型）评级，我为您筛选了几款合适的产品：
1. '稳健增利'理财，R2等级，期限6个月，业绩比较基准3.5%-4.0%
2. '平衡优选'理财，R3等级，期限1年，业绩比较基准4.0%-4.5%
请问您对哪款产品感兴趣？或者您有什么具体要求，我可以再帮您筛选。"
```

### Step 4: 产品详细介绍与风险提示

#### 4.1 产品介绍要素

| 介绍要素 | 说明内容 | 合规要求 |
|----------|----------|----------|
| 产品名称及代码 | 完整产品名称、登记编码 | 必须准确完整 |
| 产品类型 | 固定收益类/混合类/权益类/商品及金融衍生品类 | 明确告知 |
| 风险等级 | R1-R5风险等级 | 必须与客户等级匹配 |
| 投资范围 | 资金投向、资产配置比例 | 详细说明 |
| 产品期限 | 起息日、到期日、存续期限 | 明确告知 |
| 业绩比较基准 | 参考收益区间 | **必须强调非承诺收益** |
| 费用结构 | 认购费、管理费、托管费、赎回费、销售服务费 | 逐一说明 |
| 赎回规则 | 是否可提前赎回、赎回限制、到账时间 | 详细说明 |
| 收益分配 | 分配方式、分配频率 | 明确告知 |

**【KCP】风险揭示关键控制点**：
- **KCP-4.1** 必须完整朗读"理财非存款、产品有风险、投资须谨慎"
- **KCP-4.2** 必须明确告知业绩比较基准不代表实际收益
- **KCP-4.3** 必须说明产品费用及可能产生的亏损
- **KCP-4.4** 必须说明提前赎回限制及流动性风险
- **KCP-4.5** 复杂产品需提供产品适合度评估

#### 4.2 风险揭示语句（必须完整朗读）

**【话术】标准风险揭示话术**：

```
理财经理："在向您介绍产品之前，我需要向您揭示以下重要风险，请您认真听取：

1. 【理财非存款】理财产品与存款有本质区别，不具有保本保收益特征。
2. 【产品有风险】本产品存在市场风险、信用风险、流动性风险等各类风险。
3. 【投资须谨慎】请您根据自身的风险承受能力审慎决策。
4. 【业绩比较基准】本产品的业绩比较基准为X%-Y%，这仅是管理人设定的投资目标，**不代表实际收益，不构成收益承诺**。实际收益可能高于、等于或低于该区间，甚至可能产生本金亏损。
5. 【费用说明】本产品收取管理费X%/年、托管费Y%/年，这些费用将从产品资产中扣除，影响实际收益。
6. 【赎回限制】本产品为封闭式产品，存续期内不可提前赎回，请您确认投资期限内不会用到这笔资金。

请问以上内容您是否清楚理解？"
```

#### 4.3 高龄客户特别风险提示

**【KCP】高龄客户（≥65岁）特别风险控制点**：
- **KCP-4.6** 必须评估客户认知能力
- **KCP-4.7** 建议家属陪同，需确认客户独立决策能力
- **KCP-4.8** 禁止向高龄客户推荐R4及以上风险等级产品
- **KCP-4.9** 延长冷静期至48小时（建议）

**【话术】高龄客户风险提示话术**：

```
理财经理："考虑到您的年龄，我需要额外提醒您：
1. 建议您与家人商量后再做决定；
2. 请确认您完全理解产品的风险特征；
3. 我们为您延长冷静期至48小时，期间可随时无条件撤销。
请问您是否需要与家人沟通后再决定？"
```

### Step 5: 双录确认（录音录像）

#### 5.1 双录触发条件

| 场景 | 是否必须双录 | 备注 |
|------|--------------|------|
| 营业网点面签购买 | **必须** | 监管强制要求 |
| 手机银行自助购买 | 不需要 | 系统已留痕 |
| 网上银行购买 | 不需要 | 系统已留痕 |
| 电话银行购买 | 录音留痕 | 替代双录 |
| 大额交易（≥100万） | **必须** | 额外合规要求 |
| 复杂产品结构 | **必须** | 衍生品、结构化产品等 |

**【KCP】双录关键控制点**：
- **KCP-5.1** 双录必须在签约前完成，禁止先签约后补录
- **KCP-5.2** 双录画面必须清晰显示客户和理财经理面部
- **KCP-5.3** 双录音质清晰，风险揭示语句完整
- **KCP-5.4** 客户必须亲口确认"理解风险、自愿购买"
- **KCP-5.5** 双录文件保存期限≥产品终止后6个月

#### 5.2 双录必备要素

| 要素类别 | 具体内容 | 合规要求 |
|----------|----------|----------|
| 时间信息 | 录制日期时间 | 系统时间戳 |
| 人员信息 | 理财经理姓名、工号、客户姓名 | 口头声明 |
| 产品信息 | 产品全称、代码、风险等级 | 展示产品说明书 |
| 风险揭示 | 完整朗读标准风险揭示语句 | 逐条朗读 |
| 客户确认 | 客户亲口确认理解并自愿购买 | 客户亲口表述 |
| 文件签署 | 客户签署风险揭示书过程 | 录制签署过程 |

**【话术】双录开场话术**：

```
理财经理："现在开始录音录像。今天是2024年X月X日，我是XX银行理财经理XXX，工号XXXX。请问您是XXX先生/女士吗？"
客户："是的"
理财经理："现在为您办理'XXX'理财产品的购买手续。请确认您已年满18周岁，具有完全民事行为能力。"
客户："确认"
```

**【话术】双录风险揭示话术**：

```
理财经理："请听我完整朗读风险揭示语句：

'理财非存款、产品有风险、投资须谨慎。本产品为R2风险等级理财产品，业绩比较基准3.5%-4.0%不代表实际收益，不构成收益承诺。产品存续期内不可提前赎回，可能面临流动性风险。产品收取管理费、托管费，实际收益将扣除相关费用。'

请问您是否清楚理解上述风险？"
客户："清楚理解"
理财经理："请问您是否自愿购买本产品，无人强迫？"
客户："自愿购买"
```

#### 5.3 双录异常处理

| 异常情况 | 处理方式 | 跳转 |
|----------|----------|------|

### 约束条件

- 必须确认客户风险等级与产品风险等级匹配
- 必须包含风险揭示语句"理财非存款、产品有风险、投资须谨慎"
- 必须说明业绩比较基准不等于实际收益
- 双录场景必须确认客户自愿购买
- 必须告知冷静期权利
- 禁止承诺保本保收益
- 始终保持专业合规
