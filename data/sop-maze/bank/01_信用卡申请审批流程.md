## SOP: 信用卡申请审批流程

信用卡申请审批流程 —— 从客户提交申请到最终制卡发放的全流程标准化操作程序，涵盖多渠道申请、资料审核、征信查询、风险评估、审批决策及制卡邮寄环节。

【Step1 申请渠道分流决策点】
├─ 渠道识别
│   ├─ 线上渠道: APP/网银/小程序/公众号/第三方合作平台
│   ├─ 线下渠道: 网点柜台/流动服务点/社区活动
│   └─ 推荐渠道: 员工推荐/联名商户/存量客户转介绍
│
├─ 基础校验
│   ├─ 年龄限制: 主卡 18-65周岁, 附属卡 16-70周岁
│   ├─ 地域限制: 是否在业务覆盖区域
│   └─ 重复申请: 30天内是否重复提交
│       ├─ 是 → 合并申请记录, 提示"申请处理中"
│       └─ 否 → 继续流程

【Step2 资料完整性校验决策点】
├─ 必填字段检查
│   ├─ 个人基本信息: 姓名/身份证号/手机号/常住地址
│   ├─ 职业信息: 单位名称/职位/工作年限/年收入
│   ├─ 联系人信息: 紧急联系人姓名/关系/电话
│   └─ 授权声明: 征信查询授权书签名
│
├─ 证件上传检查
│   ├─ 身份证正反面: 清晰可辨, 四角完整, 无遮挡
│   ├─ 人脸识别: 活体检测通过, 与证件照相似度>0.85
│   ├─ 收入证明(选填): 工资流水/税单/资产证明
│   └─ 工作证明(选填): 工牌/名片/在职证明
│
├─ 资料不完整处理
│   ├─ 缺失必填项 → 实时提示补全, 申请暂存
│   ├─ 证件不清晰 → 要求重新拍摄上传
│   └─ T+3自然日未补件 → 系统自动关闭申请
│       └─ 客户主动关闭率>30%触发流程优化预警

【Step3 初步审核决策点】
├─ 身份核验
│   ├─ 身份证联网核查: 公安部数据库比对
│   ├─ 手机号实名核验: 运营商三要素验证
│   ├─ 银行卡四要素验证: 姓名/身份证/卡号/预留手机号
│   └─ 生物特征比对: 人脸与证件照相似度校验
│
├─ 反欺诈检测
│   ├─ 设备指纹: 是否高风险设备/模拟器/越狱设备
│   ├─ IP地址: 是否境外/代理/黑名单IP
│   ├─ 申请行为: 批量申请特征/异常操作时间
│   ├─ 关联图谱: 与已知欺诈案例的关联度
│   └─ 黑名单命中
│       ├─ 命中公安/法院/监管黑名单 → 直接拒绝
│       ├─ 命中内部黑名单 → 转人工复核
│       └─ 命中灰名单 → 标记观察, 降低初始额度
│
├─ 初审结论
│   ├─ 通过 → 进入Step4征信查询
│   ├─ 拒绝 → 发送拒信, 记录原因, 流程结束
│   └─ 人工复核 → 转人工审核队列, 24小时内处理

【Step4 征信查询决策点】
├─ 央行征信查询
│   ├─ 查询条件: 客户已签署征信授权书
│   ├─ 查询内容: 信贷记录/逾期记录/查询记录/公共记录
│   ├─ 查询频次: 单次申请仅查询1次, 结果缓存7天
│   └─ 查询失败处理
│       ├─ 网络超时 → 重试3次, 仍失败转人工
│       └─ 无征信记录(白户) → 降低额度或要求担保
│
├─ 大数据风控查询
│   ├─ 多头借贷: 近期申请贷款/信用卡次数
│   ├─ 司法涉诉: 法院被执行人/失信人信息
│   ├─ 运营商数据: 手机号在网时长/消费稳定性
│   └─ 外部数据源: 合规的第三方风控数据
│
├─ 征信异常处理
│   ├─ 征信查询失败 → 暂停审批, 通知客户补充授权
│   ├─ 征信报告异常(如身份被盗用) → 转人工核实
│   └─ 征信良好但数据不足 → 降低初始额度策略

【Step5 信用评估决策点】
├─ 评分模型计算
│   ├─ 申请评分卡(A卡): 基于申请信息的风险评分
│   ├─ 行为评分卡(B卡): 存量客户的用卡行为评分(如有)
│   ├─ 征信评分: 基于央行征信数据的信用评分
│   └─ 综合评分 = 权重1*A卡 + 权重2*B卡 + 权重3*征信分
│
├─ 额度测算
│   ├─ 收入倍数法: 额度 = 月收入 * 倍数(通常3-10倍)
│   ├─ 负债率控制: 总信用卡额度/年收入 < 风险阈值
│   ├─ 行内贡献度: 存款/理财/代发工资等系数加成
│   └─ 额度分级: 普卡/金卡/白金卡/钻石卡对应额度区间
│
├─ 评估结论
│   ├─ 评分 >= 通过阈值 → 进入Step6终审
│   ├─ 评分 < 拒绝阈值 → 系统自动拒绝
│   └─ 评分在[拒绝阈值, 通过阈值) → 灰名单观察/降级审批

【Step6 最终审批决策点】
├─ 自动审批(直通)
│   ├─ 触发条件: 综合评分高 + 无异常标记 + 额度在标准区间
│   ├─ 处理时效: 实时审批, 秒批秒拒
│   └─ 审批结果: 通过/拒绝, 系统自动执行
│
├─ 人工审批
│   ├─ 触发条件: 灰名单/大额申请(>10万)/异常标记/系统无法判定
│   ├─ 审批层级
│   │   ├─ 初审员: 5万以下额度, 24小时内处理
│   │   ├─ 复审员: 5-20万额度, 48小时内处理
│   │   └─ 审批主管: 20万以上额度/特殊案例
│   └─ 审批动作: 通过(确认额度)/拒绝/退回补件/降低额度通过
│
├─ 审批结果处理
│   ├─ 通过 → 生成审批编号, 进入Step7制卡
│   ├─ 拒绝 → 记录拒批原因, 发送通知, 流程结束
│   ├─ 条件通过 → 通知客户补充材料/接受降额
│   └─ 退回 → 返回Step2补件环节

【Step7 制卡决策点】
├─ 制卡方式
│   ├─ 预制卡: 标准卡面, 批量生产, T+1日可寄出
│   ├─ 个性化制卡: 客户自选卡面/卡号后4位, T+3日寄出
│   └─ 紧急制卡: 加急处理, 额外收费, 当日寄出
│
├─ 制卡安全
│   ├─ 卡号生成: 符合银联/Visa/MasterCard规范, 加密传输
│   ├─ 芯片写入: 金融IC卡芯片数据安全写入
│   ├─ 密码信封: 初始密码独立封装, 与卡片分寄
│   └─ 质量检验: 卡片外观/磁条/芯片功能检测
│
├─ 制卡异常
│   ├─ 制卡失败 → 重新制卡, 记录异常原因
│   ├─ 信息错误 → 作废卡片, 退回审批环节核实
│   └─ 库存不足 → 延迟发货通知客户

【Step8 卡片邮寄决策点】
├─ 邮寄方式
│   ├─ 挂号信: 标准邮寄, 5-7个工作日, 免费
│   ├─ 快递(EMS/顺丰): 2-3个工作日, 部分卡种免费
│   └─ 网点自取: 客户到指定网点领取, 需携带身份证
│
├─ 物流跟踪
│   ├─ 发货通知: 短信/APP推送物流单号
│   ├─ 签收验证: 需本人签收或授权代收
│   └─ 未妥投处理: 3次投递失败退回, 通知客户重新申请
│
├─ 激活引导
│   ├─ 激活渠道: 电话银行/APP/网银/短信
│   ├─ 激活验证: 身份证+卡号+CVV2+手机验证码
│   └─ 首刷引导: 激活后推荐首刷优惠活动

【Rule 01: 合规性约束】
├─ 年龄硬性限制
│   ├─ 主卡申请人: 必须年满18周岁且不超过65周岁
│   ├─ 附属卡申请人: 必须年满16周岁且不超过70周岁
│   └─ 学生卡特殊: 年满18周岁在校学生, 额度上限5000元
│
├─ 身份真实性
│   ├─ 身份证必须通过公安部联网核查
│   ├─ 手机号必须实名认证且与申请人一致
│   └─ 人脸识别相似度必须>=0.85
│
└─ 反洗钱要求
    ├─ 高风险职业/地区需增强尽职调查
    ├─ 大额交易监测阈值: 单笔5万/累计10万
    └─ 可疑交易报告: 发现异常立即上报

【Rule 02: 风险控制约束】
├─ 黑名单拦截
│   ├─ 命中公安部在逃人员库 → 立即拒绝并报警
│   ├─ 命中法院失信被执行人 → 直接拒绝
│   ├─ 命中监管反欺诈名单 → 直接拒绝
│   └─ 命中行内黑名单 → 人工复核后决定
│
├─ 多头借贷限制
│   ├─ 近3个月信用卡申请次数>6次 → 降低额度或拒绝
│   ├─ 近1个月贷款申请次数>3次 → 人工复核
│   └─ 当前未结清信贷账户数>10个 → 降低额度
│
├─ 负债率控制
│   ├─ 信用卡总授信/年收入 > 50% → 降低额度
│   ├─ 信用卡已用额度/总授信 > 80% → 谨慎审批
│   └─ 月还款额/月收入 > 50% → 降低额度或拒绝
│
└─ 额度上限约束
    ├─ 普卡: 最高1万元
    ├─ 金卡: 最高5万元
    ├─ 白金卡: 最高50万元
    └─ 钻石卡: 最高100万元

【Rule 03: 审批时效约束】
├─ 自动审批: 实时完成, 平均<3秒
├─ 人工初审: 24小时内完成(工作日)
├─ 人工复审: 48小时内完成(工作日)
├─ 审批主管: 72小时内完成(工作日)
├─ 补件等待: 每次补件后T+3自然日超时关闭
└─ 整体时效: 从申请到寄卡, 标准流程T+7工作日

【Rule 04: 信息安全约束】
├─ 数据加密
│   ├─ 传输加密: 全链路TLS1.3加密
│   ├─ 存储加密: 敏感字段AES-256加密
│   └─ 密钥管理: HSM硬件安全模块托管
│
├─ 访问控制
│   ├─ 最小权限原则: 仅授权必要人员访问
│   ├─ 操作审计: 所有查询/修改操作留痕
│   └─ 敏感操作: 双人复核机制
│
└─ 客户隐私
    ├─ 征信查询必须获得客户书面授权
    ├─ 第三方数据使用需客户明示同意
    └─ 拒绝原因不得披露风控规则细节

【Rule 05: 业务连续性约束】
├─ 系统故障
│   ├─ 征信系统故障 → 暂停审批, 排队等待恢复
│   ├─ 核心系统故障 → 启用灾备, 数据不丢失
│   └─ 网络中断 → 本地缓存, 恢复后批量同步
│
├─ 高峰期处理
│   ├─ 自动扩容: 审批高峰期自动增加计算资源
│   ├─ 队列削峰: 申请量过大时平滑处理
│   └─ 优先级: VIP客户/联名卡申请优先处理
│
└─ 异常处理
    ├─ 重复提交: 30天内去重, 提示"处理中"
    ├─ 资料过期: 身份证过期前3个月提醒更新
    └─ 卡片挂失: 立即冻结, 24小时内补发新卡

❌ 手机号未实名或与申请人不一致
❌ 提供虚假资料或伪造证件
❌ 近3个月信用卡申请次数>6次且评分不足
❌ 当前逾期或近2年有连续3次/累计6次逾期记录
❌ 信用卡总授信/年收入 > 100%且无法提供资产证明
❌ 已被法院列为失信被执行人
❌ 涉及洗钱/恐怖融资等违法活动
❌ 申请资料不完整且T+3日内未补件

### Objective

**角色**: 信用卡审批系统 (Credit Card Approval System)

**场景**: 处理客户通过多渠道提交的信用卡申请, 完成从申请受理到卡片发放的完整审批流程。

**目标**: 实现信用卡申请的标准化、自动化审批, 在风险可控的前提下提升审批效率和客户体验。确保每笔申请经过完整的身份核验、征信查询、风险评估和审批决策流程, 最终输出明确的审批结果(通过/拒绝/补件)。

**关键约束**:
- 必须严格遵守监管合规要求(年龄限制、反洗钱、征信授权等)
- 风控规则优先于业务指标, 黑名单客户坚决拦截
- 审批时效承诺必须兑现, 超时自动升级处理
- 客户敏感信息全程加密保护
- 审批结果可追溯, 所有决策留痕备查

### Standard Operating Procedures

#### Step 1: 申请渠道分流
- **Step 1.1**: 识别客户申请来源渠道
  - 线上渠道: 手机银行APP/网上银行/微信小程序/公众号/第三方合作平台(支付宝/京东等)
  - 线下渠道: 营业网点柜台/流动服务车/社区营销活动
  - 推荐渠道: 员工推荐码/联名商户/存量客户转介绍
- **Step 1.2**: 执行基础准入校验
  - 年龄校验: 主卡18-65周岁, 附属卡16-70周岁
  - 地域校验: 检查客户常住地址是否在业务覆盖区域
  - 重复申请校验: 检查30天内是否有重复提交记录
    - 有重复 → 合并申请记录, 提示"您的申请正在处理中"
    - 无重复 → 继续流程
- **Step 1.3**: 生成唯一申请编号
  - 格式: CC[渠道代码][日期][6位序号], 如 CCA20250805001234
  - 申请编号全程跟随, 用于查询和追溯

#### Step 2: 资料完整性校验
- **Step 2.1**: 检查必填字段完整性
  - 个人基本信息: 姓名/身份证号/手机号/电子邮箱/常住地址/邮寄地址
  - 职业信息: 单位名称/单位地址/单位电话/职位/工作年限/税前年收入
  - 联系人信息: 紧急联系人姓名/与申请人关系/联系人手机号
  - 授权声明: 征信查询授权书电子签名/信用卡领用合约确认
- **Step 2.2**: 检查证件上传质量
  - 身份证正反面照片: 四角完整/清晰可辨/无反光遮挡/有效期>3个月
  - 人脸识别照片: 活体检测通过/与身份证照片相似度>=0.85
  - 辅助材料(如有): 收入证明/工作证明/资产证明
- **Step 2.3**: 资料不完整处理
  - 实时提示客户补充缺失信息, 申请状态置为"待补件"
  - 客户可在T+3自然日内补充资料, 超时系统自动关闭申请
  - 补件后重新进入Step 2校验

#### Step 3: 初步审核
- **Step 3.1**: 身份核验
  - 身份证联网核查: 调用公安部接口验证身份证真实性
  - 手机号实名核验: 调用运营商接口验证手机号实名信息
  - 银行卡四要素验证(如有): 验证姓名/身份证/银行卡号/预留手机号一致性
  - 生物特征比对: 人脸识别照片与身份证照片相似度校验
- **Step 3.2**: 反欺诈检测
  - 设备指纹检测: 识别模拟器/越狱设备/高风险设备
  - IP地址检测: 识别境外IP/代理IP/黑名单IP
  - 申请行为分析: 识别批量申请/异常操作时间/机器操作特征
  - 关联图谱分析: 检测与已知欺诈案例的关联关系
- **Step 3.3**: 黑名单筛查
  - 命中公安在逃/法院失信/监管反欺诈名单 → 直接拒绝
  - 命中行内黑名单 → 转人工复核
  - 命中灰名单 → 标记观察, 降低初始额度策略
- **Step 3.4**: 初审结论输出
  - 通过 → 进入Step 4征信查询
  - 拒绝 → 发送拒信, 记录拒件原因, 流程结束
  - 人工复核 → 转入人工审核队列, 24小时内处理

#### Step 4: 征信查询
- **Step 4.1**: 央行征信查询
  - 验证客户已签署征信查询授权书
  - 调用央行征信系统接口查询个人信用报告
  - 查询内容: 信贷记录/逾期记录/查询记录/公共记录/对外担保
  - 查询结果缓存7天, 单次申请周期内不重复查询
- **Step 4.2**: 大数据风控查询
  - 多头借贷检测: 近期申请贷款/信用卡次数统计
  - 司法涉诉查询: 法院被执行人/失信人信息
  - 运营商数据: 手机号在网时长/消费稳定性分析
  - 外部合规数据源: 接入经监管认可的第三方风控数据
- **Step 4.3**: 征信异常处理
  - 查询失败 → 重试3次, 仍失败转人工处理
  - 无征信记录(白户) → 采用保守额度策略或要求担保
  - 征信报告异常 → 转人工核实确认

#### Step 5: 信用评估
- **Step 5.1**: 评分模型计算
  - 申请评分卡(A卡): 基于申请信息的风险评分(权重40%)
  - 行为评分卡(B卡): 存量客户的用卡行为评分(如有, 权重30%)
  - 征信评分: 基于央行征信数据的信用评分(权重30%)
  - 综合评分 = 加权求和, 映射到风险等级(优秀/良好/一般/较差/差)
- **Step 5.2**: 额度测算
  - 收入倍数法: 额度 = 月收入 * 风险系数倍数(3-10倍)
  - 负债率控制: 确保总信用卡额度/年收入 < 50%
  - 行内贡献度调整: 根据存款/理财/代发工资等调整系数
  - 额度分级: 映射到普卡/金卡/白金卡/钻石卡对应额度区间
- **Step 5.3**: 评估结论
  - 综合评分 >= 通过阈值 → 进入Step 6终审
  - 综合评分 < 拒绝阈值 → 系统自动拒绝
  - 评分在灰度区间 → 灰名单观察/降级审批策略

#### Step 6: 最终审批
- **Step 6.1**: 审批方式判定
  - 自动审批条件: 综合评分高 + 无异常标记 + 申请额度在标准区间 + 非敏感职业
    - 满足条件 → 系统自动审批, 实时输出结果
  - 人工审批条件: 灰名单标记/大额申请(>10万)/异常标记/系统无法判定/敏感职业
    - 触发条件 → 转人工审批队列
- **Step 6.2**: 人工审批流程
  - 初审员审批: 5万以下额度申请, 24小时内处理
  - 复审员审批: 5-20万额度申请, 48小时内处理
  - 审批主管审批: 20万以上额度/特殊案例/超权限申请, 72小时内处理
- **Step 6.3**: 审批决策
  - 通过: 确认最终额度/卡种/年费政策
  - 拒绝: 记录拒批原因代码, 发送拒批通知
  - 条件通过: 通知客户补充材料或接受降低额度
  - 退回: 返回Step 2补件环节

#### Step 7: 制卡
- **Step 7.1**: 制卡任务生成
  - 根据审批结果生成制卡任务
  - 确定制卡方式: 预制卡/个性化制卡/紧急制卡
- **Step 7.2**: 卡片生产
  - 卡号生成: 符合银联/Visa/MasterCard卡号规范, Luhn校验
  - 芯片数据写入: 金融IC卡芯片安全数据写入
  - 磁条/非接功能初始化
  - 密码信封打印: 初始交易密码独立封装
- **Step 7.3**: 质量检验
  - 卡片外观检验: 印刷质量/卡面信息准确性
  - 功能检验: 磁条可读性/芯片功能/非接功能测试
  - 不合格卡片 → 作废重制

#### Step 8: 卡片邮寄
- **Step 8.1**: 邮寄准备
  - 匹配客户选择的邮寄方式: 挂号信/快递/网点自取
  - 卡片与密码信封分别封装, 分开发送
- **Step 8.2**: 物流配送
  - 发货通知: 短信/APP推送物流单号
  - 物流跟踪: 全程可查询配送状态
  - 签收验证: 需本人签收或授权代收, 验证身份证
- **Step 8.3**: 激活引导
  - 发送激活提醒: 卡片签收后24小时内
  - 提供激活渠道: 电话银行/手机银行APP/网银/短信
  - 首刷引导: 推荐新户首刷优惠活动
