# 查勘定损流程 SOP

## 1. SOP简介

本SOP规范保险公司查勘员接到车险报案后，前往事故现场进行查勘、拍照取证、损失评估、定损核价的全流程操作标准，确保查勘服务质量与定损准确性。

## 3. Objective

### 3.1 流程目标

| 目标维度 | 具体目标 | 衡量标准 |
|---------|---------|---------|
| 时效目标 | 快速响应、及时到场 | 城区30分钟/郊区60分钟到达率≥95% |
| 质量目标 | 查勘全面、取证完整 | 照片合规率≥98%、证据链完整率≥99% |
| 准确目标 | 定损准确、核价合理 | 定损准确率≥95%、核价偏差≤5% |
| 服务目标 | 专业规范、客户满意 | 客户满意度≥90%、投诉率≤1% |
| 合规目标 | 操作合规、风险可控 | 合规操作率100%、欺诈识别率≥80% |

对话流程说明：

① 客户 ↔ 查勘员 (现场交互)
   - 查勘员："您好，我是XX保险公司查勘员XXX，工号XXX，前来处理您的报案。"
   - 客户：配合出示证件、陈述事故经过
   - 查勘员：说明查勘流程、告知预计定损时间

② 查勘员 ↔ 理赔系统 (数据交互)
   - 接收：案件信息、历史出险记录、保单信息
   - 提交：查勘报告、定损清单、照片档案、责任建议

③ 查勘员 ↔ 维修厂 (定损交互)
   - 询价：配件价格、工时费用、维修周期
   - 确认：维修方案、替代配件品质、残值处理

④ 客户 ↔ 理赔系统 (服务交互)
   - 查询：理赔进度、赔付金额、到账时间
   - 反馈：服务评价、投诉建议

⑤ 理赔系统 ↔ 维修厂 (结算交互)
   - 直赔：维修费直接结算给维修厂
   - 授权：客户授权下的维修费支付
```

### 4.2 拍照规范

#### 4.2.1 拍摄要求总览

| 拍摄类型 | 数量要求 | 技术要求 | 内容要求 |
|---------|---------|---------|---------|
| 全景照片 | ≥2张 | 广角/标准镜头、水平拍摄 | 事故全貌、道路环境、参照物 |
| 碰撞部位 | ≥4张 | 45度角拍摄、光线充足 | 接触点、变形程度、痕迹特征 |
| 车辆信息 | ≥3张 | 微距/标准镜头、对焦清晰 | 车架号、车牌、里程表 |
| 证件照片 | 全套 | 正面拍摄、四角完整、无反光 | 驾驶证、行驶证、身份证、保单 |
| 细节特写 | 按需 | 微距镜头、补光充足 | 重要痕迹、散落物、油液泄漏 |

### 4.3 现场话术

#### 4.3.1 到达现场话术

| 安抚客户 | "请您不要着急，我会帮您妥善处理这次事故。首先确认一下，现场是否安全？有人受伤吗？" | 体现关怀、确认安全优先 |

#### 4.3.2 询问事故经过话术

```
标准询问流程 (5W2H)：

When (时间):
  "请问事故发生的具体时间是什么时候？" 
  → 核对与报案时间是否一致

Where (地点):
  "事故发生的具体位置是这里吗？是否有移动过车辆？"
  → 确认第一现场

Who (当事人):
  "当时是谁驾驶这辆车？车上还有其他人吗？"
  → 核实驾驶员身份、确认是否有乘员受伤

What (经过):
  "请您描述一下事故发生的具体经过，包括您的行驶方向、车速、当时的路况。"
  → 了解事故全貌、判断责任

Why (原因):
  "您认为造成这次事故的主要原因是什么？是否有避让不及或其他特殊情况？"
  → 分析事故原因

How (如何):
  "事故发生后您采取了什么措施？是否报警？是否有目击证人？"
  → 了解后续处理情况

How much (损失):
  "除了车辆损失，还有其他损失吗？比如人员受伤、第三方财产损失？"
  → 全面评估损失
```

### 4.5 定损核价方法

#### 4.5.1 配件价格体系

| 价格类型 | 定义 | 适用场景 | 价格水平 |
|---------|------|---------|---------|
| 4S店价 | 品牌授权经销商原厂配件价格 | 新车/在质保期车辆/客户要求 | 最高 |
| 市场价 | 正规配件市场原厂配件价格 | 一般车辆/客户自选维修厂 | 中等 |
| 协议价 | 与配件商/维修厂签订的优惠价格 | 合作维修厂定损 | 较低 |
| 拆车件价 | 拆解车辆可用配件价格 | 老旧车型/特殊配件/客户同意 | 最低 |

#### 4.5.2 定损核价流程

```
定损核价步骤：

Step 1: 确定损失项目
  ├─ 区分更换件 vs 修复件
  ├─ 区分原厂件 vs 副厂件
  └─ 列出配件清单 (名称/编码/数量)

Step 2: 查询配件价格
  ├─ 使用定损系统查询标准价格
  ├─ 向维修厂/配件商询价
  ├─ 核对配件编码与车型匹配
  └─ 确认配件供应情况

Step 3: 评估工时费用
  ├─ 确定维修项目 (拆装/钣金/喷漆/机电)
  ├─ 查询工时定额 (行业标准/合作厂协议)
  ├─ 计算工时费用 = 工时数 × 工时单价
  └─ 确认辅料费用

Step 4: 计算残值扣除
  ├─ 识别有残值的更换配件
  ├─ 评估残值金额 (市场价/回收价)
  ├─ 确定扣除方式 (协商扣除/回收处理)
  └─ 计算净残值

Step 5: 汇总定损金额
  ├─ 材料费 = 配件费 + 辅料费
  ├─ 工时费 = 各项目工时费之和
  ├─ 残值扣除
  └─ 定损总金额 = 材料费 + 工时费 - 残值

Step 6: 审核与确认
  ├─ 自查：项目完整、价格合理、计算准确
  ├─ 超权限上报核损岗审核
  └─ 与客户确认签字
```

### 5.1 查勘规则总览

|---------|---------|---------|---------|
| R1 | 时效要求 | 城区30分钟/郊区60分钟到达现场 | 超时需说明原因并上报 |
| R2 | 拍照规范 | 按标准拍摄≥15张照片，照片清晰完整 | 照片不合规需补拍 |
| R3 | 定损标准 | 配件价格按系统标准，工时按行业标准 | 价格偏差需说明理由 |
| R4 | 客户签字 | 定损单必须客户签字确认 | 无签字定损无效 |

### 5.2 规则详细说明

#### R1: 时效要求规则

```
时效标准：
├─ 城区案件 (五环内/市中心)：≤30分钟
├─ 郊区案件 (五环外/县城)：≤60分钟  
├─ 偏远地区 (乡镇/山区)：≤90分钟
└─ 特殊天气/路况：可适当延长，需记录原因

时效计算：
├─ 起点：调度派工时间
├─ 终点：查勘员到达现场的GPS定位时间
└─ 扣除：客户要求改期/客户延迟到场的时间

超时处理：
├─ 超时10分钟内：系统记录，月度统计
├─ 超时10-30分钟：需填写超时说明
└─ 超时30分钟以上：需主管审批并说明原因
```

#### R2: 拍照规范规则

```
照片质量要求：
├─ 清晰度：能清楚识别车牌号、VIN码、损伤细节
├─ 完整性：照片四角完整，无遮挡
├─ 关联性：照片能反映事故全貌和细节关系
├─ 时效性：照片GPS时间戳与查勘时间一致
└─ 规范性：按标准顺序拍摄，命名规范

必拍项目 (缺一不可)：
├─ 全景照片 ≥2张
├─ 双方车辆车架号
├─ 双方车辆车牌
├─ 碰撞部位照片 ≥4张
├─ 驾驶证、行驶证
└─ 查勘员与车辆合影

禁止行为：
├─ 使用非本次事故的照片
├─ 照片经过PS修改
├─ 照片时间戳与查勘时间不符
└─ 照片模糊不清无法识别
```

#### R3: 定损标准规则

```
配件定价规则：
├─ 必须使用定损系统标准价格
├─ 系统无价格的，按询价流程确定
├─ 同一配件只能使用一种价格类型
├─ 更换配件必须是本次事故造成的损坏
└─ 能修复的配件不得更换

工时定价规则：
├─ 工时单价按当地行业标准或合作厂协议
├─ 工时数参照《机动车维修工时定额》
├─ 同一维修项目不得重复计算工时
└─ 辅料费按实际发生或定额标准

残值处理规则：
├─ 有回收价值的配件必须扣除残值
├─ 残值金额按市场价或协议价确定
├─ 残值扣除方式需与客户协商一致
└─ 残值配件回收需有交接记录
```

#### R4: 客户签字规则

```
必须签字的文件：
├─ 查勘记录单 (确认事故经过和查勘结果)
├─ 定损确认单 (确认定损项目和金额)
├─ 维修厂选择确认书 (确认维修厂选择)
└─ 权益转让书 (涉及代位求偿时)

签字要求：
├─ 必须是当事人本人签字
├─ 签字必须与身份证件姓名一致
├─ 签字需清晰可辨认
├─ 修改处需当事人按手印确认
└─ 代签需有授权委托书

特殊情况：
├─ 客户拒绝签字：记录原因，见证人签字
├─ 客户不在现场：事后补签或电子签名
└─ 客户对定损有异议：注明异议内容，先签无异议部分
```

#### R5: 争议处理规则

```
争议类型：
├─ 责任争议：事故责任划分存在分歧
├─ 损失争议：对损失项目或金额有异议
├─ 保险责任争议：是否属于保险责任范围
└─ 欺诈嫌疑：怀疑存在骗保行为

处理流程：
├─ 第一步：现场沟通解释，争取协商解决
├─ 第二步：24小时内上报核损岗/主管
├─ 第三步：收集补充证据，申请复核
├─ 第四步：复杂争议提交理赔委员会讨论
└─ 第五步：必要时引入第三方鉴定

上报要求：
├─ 填写《争议案件上报表》
├─ 附相关证据材料
├─ 说明争议焦点和查勘员意见
└─ 记录客户联系方式和诉求
```

```
【案件信息】
报案号：BX202408050001
报案时间：2024-08-05 09:30
出险时间：2024-08-05 09:15
出险地点：XX市XX区XX路XX号附近

车型：大众帕萨特 2022款
险种：车损险+三者险+不计免赔

【事故经过】
客户陈述：早晨上班途中，因避让突然窜出的行人，

3. 评估护栏损失 (第三方财产损失)
4. 检查车辆损失范围 (左前灯、保险杠、翼子板、轮胎)

【客户对话示例】
客户："我当时是为了躲人才撞的，这能赔吧？"
查勘员："根据您购买的保险，车辆损失可以通过车损险赔付。
关于避让行人的情况，我们会核实现场痕迹。
另外，护栏的损失需要通过交强险和三者险赔付，
请问您报警了吗？"

【定损重点】
- 左前大灯：更换
- 前保险杠：修复+喷漆
- 左前翼子板：修复+喷漆
- 左前轮胎：检查是否需更换

### 6.2 场景B：双方事故

```
【案件信息】

报案时间：2024-08-05 14:20
出险时间：2024-08-05 14:10
出险地点：XX市XX路口
被保险人：李四 (标的车主)
对方车主：王五 (三者车主)
标的车型：丰田凯美瑞
三者车型：本田雅阁

【事故经过】
标的车主陈述：在路口直行时，对方车辆从左侧转弯，
两车发生碰撞，标的车右前侧受损，三者车左前侧受损。

【查勘要点】
1. 核实交警责任认定 (拍照留存认定书)
2. 分别查勘两车损失
3. 确认两车碰撞痕迹匹配
4. 询问双方事故经过是否一致

【客户对话示例】
标的车主："交警已经认定他全责了，我应该怎么走保险？"
查勘员："因为交警认定对方全责，您有两种选择：
1. 向对方保险公司索赔；
2. 如果您着急修车，可以先向我们公司申请代位求偿，
   我们赔付后向对方追偿。
请问您希望哪种方式？"

【定损重点】
- 两车分别定损
- 标的车损失：右前大灯、前保险杠、右前翼子板
- 三者车损失：左前大灯、前保险杠、左前翼子板、左前轮
- 确认损失与碰撞部位逻辑一致
```

### 6.3 场景C：人伤事故

```
【案件信息】
报案号：BX202408050003
报案时间：2024-08-05 16:45
出险时间：2024-08-05 16:30
出险地点：XX市XX路
被保险人：赵六
事故类型：标的车与电动车碰撞
伤亡情况：电动车驾驶员受伤，已送医院

【事故经过】
客户陈述：行驶中与横穿马路的电动车发生碰撞，
电动车驾驶员倒地受伤，已拨打120送医，已报警。

【查勘要点】
1. 确认人员受伤情况 (伤情严重程度)
2. 核实事故真实性 (现场痕迹、刹车痕迹)
3. 收集伤者信息 (姓名、联系方式、就诊医院)
4. 确认是否垫付医疗费
5. 告知人伤理赔流程

【客户对话示例】
客户："对方去医院了，我需要垫付医药费吗？"
查勘员："关于医疗费垫付，我们有以下建议：
1. 交强险可以垫付1.8万元医疗费，需要医院出具抢救费用清单；
2. 您可以先垫付部分费用，保留好所有票据；
3. 也可以让对方先自行支付，后续凭票据理赔。
请问伤者现在在哪家医院？伤情如何？"

【处理重点】
- 现场查勘后，人伤部分移交人伤岗跟进
- 记录伤者就诊医院、初步诊断
- 告知客户人伤理赔所需材料
- 提醒客户不要私下承诺赔偿金额
```

### 6.5 场景E：现场破坏/车辆已移动

```
【案件信息】
报案号：BX202408050005
报案时间：2024-08-05 11:20
到达现场：2024-08-05 11:45
现场情况：车辆已移至路边，原始现场已被破坏

【处理流程】
1. 核实移动原因
   查勘员："请问车辆为什么移动了？原始现场在哪里？"
   客户："当时为了不影响交通，交警让移到路边的。"

2. 确认原始现场位置
   - 请客户指认原始碰撞位置
   - 拍摄原始现场环境照片
   - 寻找地面痕迹 (刹车痕、散落物、油渍)

3. 痕迹比对验证
   - 车辆碰撞痕迹与地面痕迹是否匹配
   - 车辆损伤与描述的事故经过是否一致
   - 散落物分布是否符合碰撞逻辑

4. 补充证据收集
   - 联系交警获取事故认定书
   - 询问是否有目击证人
   - 查看周边监控摄像头

5. 风险提示与记录
   查勘员："由于现场已经移动，部分证据可能无法获取，
   如果后续对事故真实性有疑问，可能会影响理赔。
   请您在《现场移动确认书》上签字。"

【定损注意事项】
- 更加仔细地核对损失与事故描述的匹配性
- 对存疑的损失项目要求提供更多证据
- 必要时申请复勘或第三方鉴定
```

### 6.6 场景F：争议事故

```
【案件信息】
报案号：BX202408050006
报案时间：2024-08-05 15:00
出险地点：XX市XX路
争议类型：客户对定损金额有异议

【争议情况】
客户认为左前门应该更换，查勘员认为可以修复。
客户要求去4S店维修，查勘员初步定损为普通维修厂价格。

【处理流程】
1. 倾听客户诉求
   查勘员："我理解您的想法，能否告诉我您坚持更换的原因？"
   客户："这门变形这么严重，修了也不结实，而且我这是新车！"

2. 解释定损依据
   查勘员："关于左前门的损伤，我的判断依据是：
   - 变形程度在可修复范围内，没有伤及结构
   - 修复后强度可以达到安全标准
   - 按照保险补偿原则，能修复的不更换
   但如果您坚持更换，我可以申请核损复核。"

3. 提供解决方案
   查勘员："关于维修厂选择，我们有以下方案：
   A. 如果您选择合作4S店，我们可以按4S店价格定损
   B. 如果您选择其他4S店，可能需要先垫付后理赔
   C. 如果您对定损结果有异议，可以申请第三方评估
   您希望选择哪种？"

4. 上报争议案件
   - 填写《争议案件上报表》
   - 说明争议焦点：更换vs修复
   - 附上现场照片和定损清单
   - 提交核损岗审核

5. 后续跟进
   - 24小时内反馈核损意见
   - 与客户沟通最终方案
   - 记录争议处理全过程
```

| 评估维度 | 指标名称 | 计算公式 | 目标值 | 权重 |
|---------|---------|---------|-------|------|

| 质量指标 | 查勘质量合格率 | 质量合格案件数/总案件数×100% | ≥98% | 25% |

| 合规指标 | 合规操作率 | 合规操作案件数/总案件数×100% | 100% | 10% |

### 8.2 详细评估标准

#### 8.2.1 到场时效评估

| 等级 | 标准 | 得分 |
|-----|------|------|
| 优秀 | 按时到场率≥98% | 100分 |
| 良好 | 按时到场率95%-98% | 90分 |
| 合格 | 按时到场率90%-95% | 80分 |
| 待改进 | 按时到场率<90% | 60分 |

#### 8.2.2 查勘质量评估

```
查勘质量评分表：

一、照片质量 (40分)
  ├─ 数量达标 (10分)：≥15张满分，每少1张扣2分
  ├─ 清晰度 (10分)：照片清晰可辨
  ├─ 完整性 (10分)：必拍项目齐全
  └─ 规范性 (10分)：拍摄角度规范

二、信息完整 (30分)
  ├─ 事故信息 (10分)：时间/地点/经过完整
  ├─ 当事人信息 (10分)：证件信息齐全
  └─ 损失信息 (10分)：损失描述详细

三、流程合规 (30分)
  ├─ 身份核实 (10分)：证件核实记录
  ├─ 签字确认 (10分)：必要文件签字
  └─ 系统录入 (10分)：信息录入及时准确
```

#### 8.2.3 定损准确率评估
