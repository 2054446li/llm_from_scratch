## Objective

### 3.1 流程目标

| 目标维度 | 具体描述 | 量化指标 |
|---------|---------|---------|
| **欺诈识别** | 建立多维度欺诈识别体系，覆盖事前/事中/事后全流程 | 预警准确率 ≥ 85% |
| **调查取证** | 确保证据链完整、合法有效，支撑后续处置决策 | 证据合规率 100% |
| **风险处置** | 根据案件性质采取差异化处置策略，最大化减损 | 减损率 ≥ 30% |
| **合规运营** | 严格遵守法律法规，保护客户合法权益 | 合规投诉率 ≤ 1% |
| **知识沉淀** | 形成案例库和规则库，持续优化风控能力 | 月度案例入库 ≥ 10件 |
| **行业协作** | 建立同业信息共享机制，提升行业反欺诈能力 | 季度信息共享 ≥ 5次 |

## Standard Operating Procedures

### Step 1: 欺诈线索识别与案件立案

#### 1.1 线索来源识别

##### 1.1.1 系统预警（规则引擎触发）

**【KCP1-1】线索来源真实性核验 - 关键控制点**
- 核验触发规则的准确性
- 排除系统误报可能
- 确认预警信息与客户实际情况的匹配度

**触发条件配置（20+识别指标）：**

| 指标类别 | 指标名称 | 触发条件 | 风险权重 | 适用险种 |
|---------|---------|---------|---------|---------|
| **时间异常** | 短期出险 | 投保后T+30天内出险（重疾险T+90天） | 高 | 全险种 |
| | 集中出险 | 特定时间段内密集出险（30天内≥2次） | 高 | 意外险、医疗险 |
| | 等待期边缘 | 等待期结束后T+7天内出险 | 中 | 健康险 |
| | 续保后即时出险 | 续保生效后T+3天内出险 | 中 | 全险种 |
| **频率异常** | 理赔频率 | 同一被保险人12个月内理赔次数≥3次 | 高 | 意外险、医疗险 |
| | 高频小额 | 6个月内小额理赔≥5次 | 中 | 意外险 |
| | 循环出险 | 相似原因反复理赔（3次以上） | 高 | 意外险 |
| | 升级出险 | 理赔金额逐次递增超过50% | 中 | 全险种 |
| **金额异常** | 高额理赔 | 单案理赔金额超保单保额80% | 高 | 全险种 |
| | 保额收入比 | 保额超过年收入20倍 | 高 | 寿险、重疾险 |
| | 损失夸大 | 维修/医疗费用明显高于市场均价 | 中 | 车险、医疗险 |
| | 零整比异常 | 配件价格与车辆实际价值不匹配 | 中 | 车险 |
| **就医异常** | 非定点医院 | 非定点医院就诊无合理说明 | 中 | 健康险 |
| | 异地就医 | 异地就医无转诊手续或合理理由 | 中 | 医疗险 |
| | 医院等级异常 | 小病大治、基层医院无法处理的疾病 | 中 | 医疗险 |
| | 频繁转院 | 无明确医学指征的频繁转院 | 高 | 医疗险 |
| **关系异常** | 关联预警 | 同一医院/医生高频出险 | 高 | 健康险 |
| | 修理厂关联 | 同一修理厂高频定损 | 高 | 车险 |
| | 受益人异常 | 受益人与被保险人关系异常 | 高 | 寿险 |
| | 代理人关联 | 同一代理人经办多起异常案件 | 高 | 全险种 |
| **职业风险** | 高风险职业 | 投保职业与实际职业不符 | 高 | 意外险、寿险 |
| | 职业变更未告知 | 职业变更后出险未补告知 | 中 | 意外险 |
| | 特殊行业 | 汽修、医疗、保险从业人员投保 | 中 | 全险种 |
| **行为异常** | 延迟报案 | 出险后超过48小时报案无正当理由 | 中 | 车险 |
| | 资料瑕疵 | 理赔资料存在涂改、拼接痕迹 | 高 | 全险种 |
| | 回避调查 | 客户拒绝配合调查或提供虚假联系方式 | 高 | 全险种 |
| | 异常委托 | 非受益人本人办理理赔且无法合理解释 | 中 | 全险种 |

**预警分级：**

| 等级 | 触发条件 | 响应时效 | 处理人 | 升级条件 |
|-----|---------|---------|-------|---------|
| **红色** | 疑似故意制造事故、伪造医疗票据、团伙作案特征 | 2小时内 | 风控主管 | 自动升级 |
| **橙色** | 短期内多次理赔、就医行为异常、金额明显异常 | 24小时内 | 风控专员 | 发现新疑点 |
| **黄色** | 理赔资料存疑、客户行为异常、单一指标异常 | 3个工作日内 | 风控专员 | 调查中发现异常 |
| **蓝色** | 关注类指标触发、同业信息共享提示 | 5个工作日内 | 理赔人员 | 系统定期复核 |

##### 1.1.2 人工举报（内部/外部渠道）

**内部举报渠道：**
- 理赔人员发现异常
- 客服人员接到可疑报案
- 代理人/经纪人发现客户异常行为
- 核保人员发现投保异常
- 内部审计发现违规线索

**外部举报渠道：**
- 同业公司协查通报
- 医疗机构举报
- 修理厂/4S店举报
- 知情人士实名/匿名举报
- 媒体曝光线索

**举报受理流程：**
1. **记录登记**
   - 记录举报人信息（可选择匿名，但需保留联系方式以便核实）
   - 登记举报时间、渠道、方式
   - 生成分配编号

2. **内容核实**
   - 详细记录举报内容（时间、地点、涉事人员、可疑点）
   - 要求提供相关证据或线索来源
   - 初步判断举报信息的真实性和可查性

3. **初步调查**
   - 通过公开渠道核实举报信息
   - 查询内部系统验证相关线索
   - 评估是否达到立案标准

4. **反馈保护**
   - 对实名举报人反馈受理情况
   - 严格保护举报人信息安全
   - 建立举报人保护机制

##### 1.1.3 数据异常（大数据分析发现）

**分析维度：**
- **理赔数据与投保数据交叉比对**
  - 投保前就诊记录与出险疾病关联
  - 投保动机与保额合理性分析
  - 告知内容与实际情况比对

- **历史案件模式匹配**
  - 与已知欺诈案例特征比对
  - 同类案件聚类分析
  - 新型欺诈模式识别

- **关联关系网络异常检测**
  - 关系图谱分析
  - 资金往来追踪
  - 行为模式异常识别

##### 1.1.4 同业通报（行业黑名单共享）

**信息共享平台：**
- 保险行业协会欺诈信息共享平台
- 同业公司案件协查通报
- 黑名单客户交叉验证
- 行业风险预警信息

**信息使用规范：**
- 严格限定使用范围
- 保护客户隐私信息
- 及时反馈核查结果
- 定期更新共享信息

##### 1.1.5 舆情监测（媒体/社交媒体）

**监测渠道：**
- 新闻媒体曝光
- 社交媒体讨论
- 网络投诉平台
- 行业论坛信息

**监测内容：**
- 涉及本司的负面信息
- 行业欺诈案例报道
- 新型欺诈手法曝光
- 客户异常行为线索

#### 1.2 立案标准与流程

**立案条件（满足任一）：**
1. 系统预警等级为红色或橙色
2. 人工举报内容具体、可查，且初步核实有疑点
3. 数据异常且有初步证据支撑
4. 同业通报涉及本司保单
5. 舆情监测发现重大可疑线索

**立案操作：**
1. 在反欺诈系统创建案件
2. 生成立案编号（格式：FYYYYMMDD-NNNN）
3. 录入基本信息：
   - 保单号、被保险人姓名、身份证号
   - 出险时间、报案时间、可疑点描述
   - 线索来源、预警等级
4. 分配调查责任人
5. 主管审批立案（红色预警需即时审批）

### Step 4: 调查取证实施

#### 4.1 资料核实

##### 4.1.1 医疗资料核实

**【KCP4-1】医疗资料核实要点**

**核实方式：**
1. 医院病案室调取原始病历
2. 核对诊断证明、出院小结、费用清单
3. 走访主治医生了解治疗情况
4. 医保系统核实报销记录
5. 检验检查科室核实报告真实性

**核实要点：**

| 资料类型 | 核实要点 | 常见造假点 | 核实方法 |
|---------|---------|-----------|---------|
| 门诊病历 | 就诊时间、诊断内容、医生签字 | 事后补写、篡改日期、伪造签字 | 医院系统查询、笔迹鉴定 |
| 住院病历 | 入院记录、病程记录、护理记录 | 挂床住院、虚构病情、冒名住院 | 病房走访、监控调取 |
| 医疗费发票 | 发票真伪、金额一致性、印章 | 假发票、虚开金额、伪造印章 | 税务系统验证、医院核实 |
| 诊断证明 | 医院公章、医生签字、诊断内容 | 伪造公章、冒名签字、夸大病情 | 医院核实、专家评估 |
| 检查报告 | 检查时间、影像资料、报告编号 | 套用他人报告、伪造报告、篡改结果 | 检查科室核实、影像比对 |
| 处方笺 | 药品名称、剂量、医生签字 | 虚构药品、夸大剂量、伪造签字 | 药房核实、系统查询 |
| 手术记录 | 手术时间、手术方式、术者签字 | 虚构手术、夸大手术范围 | 手术室核实、麻醉记录比对 |

##### 4.1.2 事故资料核实

**车险事故：**
- 交警部门事故认定书核实
- 现场照片与事故描述比对
- 维修清单与损失部位核对
- 旧件回收与更换件核实
- 事故认定书真伪鉴别

**意外险事故：**
- 事故证明出具单位核实
- 目击证人证言收集
- 现场痕迹勘查
- 出险时间与投保时间比对
- 事故原因与保险责任匹配

##### 4.1.3 身份关系核实

- 身份证件真伪鉴别
- 亲属关系证明核实
- 受益人身份确认
- 工作单位、居住地址实地核查
- 婚姻状况、家庭关系核实

#### 4.2 走访调查

##### 4.2.1 医院走访

**【KCP4-2】医院走访规范**

**走访对象：**
- 主治医生
- 责任护士
- 病案室人员
- 同病房患者
- 科室主任

**走访内容：**
- 核实患者就诊情况
- 了解治疗方案和实际住院天数
- 询问是否有挂床、冒名住院情况
- 收集医生对病情的专业意见
- 核实医疗费用的合理性

**走访技巧：**
- 提前预约，说明来意
- 携带必要证件和授权文件
- 注意保护患者隐私
- 做好走访记录，争取签字确认
- 必要时录音（征得同意）

**走访话术：**
```
开场白：
"您好，我是XX保险公司风控专员，正在对一起理赔案件进行核实。这是我们的介绍信和工作证。希望能占用您几分钟时间，了解一些情况。"

核心问题：
1. "请问您还记得患者XXX的就诊情况吗？大概是什么时间入院的？"
2. "患者当时的病情如何？主要诊断是什么？"
3. "患者实际住院了多少天？期间是否一直在病房？"
4. "患者的治疗方案是怎样的？效果如何？"
5. "您看这些医疗票据和病历记录，是否与您了解的情况一致？"

结束语：
"非常感谢您的配合，这对我们核实案件情况非常重要。如果后续还有问题，可能还需要向您请教。"
```

##### 4.2.2 现场复勘

**复勘时机：** 事故发生后尽快进行

**复勘内容：**
- 事故现场痕迹拍照固定
- 测量刹车痕迹、碰撞位置
- 走访周边商户、居民
- 调取监控录像
- 绘制现场示意图

**注意事项：**
- 携带测量工具、照相设备
- 记录天气、光线等环境因素
- 注意人身安全
- 必要时邀请第三方见证

##### 4.2.3 社会关系调查

**调查内容：**
- 被保险人/受益人邻里关系
- 经济状况、债务情况
- 近期重大生活变故
- 人际关系网络
- 不良嗜好或特殊习惯

**调查方式：**
- 社区/村委会走访
- 工作单位了解
- 知情人访谈
- 公开信息收集
- 社交媒体监测

#### 4.3 监控调取

##### 4.3.1 视频监控

**【KCP4-3】监控调取规范**

**调取范围：**
- 事故现场周边监控
- 医院出入口监控
- 银行取款监控（涉及保险金支取）
- 交通卡口监控
- 小区/商场监控

**调取流程：**
1. 确定监控归属单位
2. 出具调取证明（介绍信、工作证、立案证明）
3. 明确调取时间段
4. 现场拷贝或录制
5. 标注监控来源、时间、地点
6. 制作监控资料清单

**注意事项：**
- 及时调取，防止覆盖
- 保存原始载体
- 制作文字说明
- 计算完整性校验值

##### 4.3.2 电子数据

- 通话记录分析（出险前后通话对象、频率）
- 手机定位信息
- 社交媒体动态
- 网络购物记录
- 出行记录（机票、火车票、酒店）

#### 4.4 专家鉴定

##### 4.4.1 鉴定类型

| 鉴定类型 | 适用场景 | 鉴定机构 | 鉴定周期 | 费用预算 |
|---------|---------|---------|---------|---------|
| 伤残鉴定 | 伤残等级争议 | 司法鉴定机构 | 15-30天 | 1000-3000元 |
| 痕迹鉴定 | 事故成因分析 | 交通事故鉴定中心 | 10-20天 | 2000-5000元 |
| 笔迹鉴定 | 签名真伪争议 | 文检鉴定机构 | 10-15天 | 1500-3000元 |
| 车损鉴定 | 维修费用争议 | 价格评估机构 | 7-15天 | 1000-2000元 |
| 医疗鉴定 | 疾病因果关系 | 医学会 | 30-60天 | 3000-8000元 |

##### 4.4.2 鉴定委托

- 选择具有资质的鉴定机构
- 明确鉴定事项和要求
- 提供完整鉴定材料
- 约定鉴定时限和费用
- 跟进鉴定进度
- 验收鉴定报告

#### 4.5 询问话术体系

##### 4.5.1 开放式提问

**目的：** 获取全面信息，了解事件全貌，建立沟通氛围

**话术示例：**

| 场景 | 开放式提问话术 | 预期获取信息 |
|-----|---------------|-------------|
| 事故经过 | "请您详细描述一下当时的情况，从事故发生前您在做什么开始说起。" | 完整时间线、行为细节 |
| 伤情描述 | "受伤后您有什么感觉？是怎么处理的？" | 伤情真实性、就医过程 |
| 关系说明 | "您和被保险人是什么关系？平时来往多吗？" | 关系真实性、利益关联 |
| 病史情况 | "您平时身体状况怎么样？有没有定期体检？" | 既往病史、投保前健康状况 |
| 经济状况 | "这次事故对您的工作和生活有什么影响？" | 索赔动机、损失真实性 |

**提问技巧：**
- 使用"什么"、"怎么"、"为什么"开头
- 避免引导性提问
- 给予充分时间回答
- 适时追问细节
- 记录关键信息

##### 4.5.2 压力测试

**目的：** 观察被询问人反应，发现矛盾点，突破心理防线

**话术示例：**

| 压力类型 | 话术示例 | 观察要点 |
|---------|---------|---------|
| 信息压力 | "我们了解到的情况和您说的有些出入，您能解释一下吗？" | 表情变化、语言迟疑 |
| 证据压力 | "医院的记录显示您当时并不在场，这是怎么回事？" | 是否承认、如何解释 |
| 关联压力 | "有人反映看到您在事故发生前就在现场附近，您怎么解释？" | 是否否认、解释合理性 |
| 时间压力 | "从您家到现场正常需要30分钟，但您说只用了10分钟？" | 时间逻辑漏洞 |
| 逻辑压力 | "您说当时是一个人，但通话记录显示您在和人通话？" | 矛盾点识别 |

**注意事项：**
- 压力测试需基于一定证据
- 避免威胁、恐吓
- 观察非语言信号
- 记录反应细节
- 适时调整策略

##### 4.5.3 矛盾点追问

**目的：** 针对发现的疑点深入追问，揭示真相

**话术示例：**

| 矛盾类型 | 追问话术 | 应对策略 |
|---------|---------|---------|
| 时间矛盾 | "您刚才说当时在现场，但监控显示您半小时后才到，怎么解释？" | 要求解释时间差 |
| 地点矛盾 | "病历显示您住院10天，但护士说您只住了3天，是怎么回事？" | 核实实际住院天数 |
| 金额矛盾 | "发票金额和费用清单对不上，您能说明一下吗？" | 要求提供原始票据 |
| 人员矛盾 | "您说当时是一个人，但目击证人说有两个人？" | 核实在场人员 |
| 伤情矛盾 | "医生说您的伤需要休养一个月，但您一周后就上班了？" | 核实伤情严重程度 |

**追问技巧：**
- 指出具体矛盾点
- 要求立即解释
- 不给准备时间
- 观察反应
- 记录解释内容

##### 4.5.4 询问记录规范

**记录要求：**
- 制作询问笔录，记录问答内容
- 被询问人确认无误后签字
- 记录询问时间、地点、询问人
- 全程录音录像（征得同意）
- 被询问人拒签的，注明原因

**笔录格式：**
```
询问笔录

询问人：________ 记录人：________
被询问人：________ 性别：____ 年龄：____ 身份证号：________________
工作单位/住址：________________________ 联系电话：________________

问：我们是XX保险公司工作人员，现就XXX案件向您了解情况，请您如实回答。您是否同意录音录像？

问：________________
答：________________

......

以上笔录我已看过，与我说的相符。
被询问人签名：________ 日期：________
```

#### 4.6 证据固定规范

**【KCP4】证据链完整性与合法性 - 关键控制点**

##### 4.6.1 书证

- 原件优先，复印件需与原件核对
- 注明来源、获取时间、获取人
- 重要书证拍照或扫描备份
- 制作书证清单

##### 4.6.2 物证

- 妥善保管，防止损坏、灭失
- 制作物证清单，标注特征
- 必要时封存
- 拍照固定

##### 4.6.3 视听资料

- 注明制作时间、地点、制作人
- 保存原始载体
- 制作文字说明
- 计算完整性校验值

##### 4.6.4 电子数据

- 提取过程录像
- 计算完整性校验值（MD5/SHA）
- 制作提取固定清单
- 保存原始存储介质

##### 4.6.5 证人证言

- 个别询问
- 告知如实作证义务
- 制作询问笔录
- 证人签字确认

### Step 5: 证据分析与案件定性

#### 5.1 证据审查

**【KCP5】证据三性审查与定性准确性 - 关键控制点**

##### 5.1.1 证据三性审查

| 审查维度 | 审查内容 | 审查标准 | 排除情形 |
|---------|---------|---------|---------|
| **真实性** | 证据来源、形成过程、内容真伪 | 排除伪造、变造可能 | 伪造票据、虚假陈述 |
| **合法性** | 取证程序、取证主体、证据形式 | 符合法律规定 | 非法取证、程序瑕疵 |
| **关联性** | 证据与待证事实的关系 | 能够证明案件事实 | 无关证据、间接证据 |

##### 5.1.2 证据链完整性

- **时间链：** 事件发展时间线是否完整
- **空间链：** 地点转换是否合理
- **人物链：** 涉及人员关系是否清晰
- **因果链：** 行为与结果之间因果关系是否成立
- **证据链闭合：** 各证据之间能否相互印证

#### 5.2 案件定性

##### 5.2.1 证据确凿（确认欺诈）

**认定标准：** 证据充分、确实，能够排除合理怀疑

**典型情形：**
- 伪造医疗票据被医院证实
- 事故现场监控显示故意制造事故
- 被保险人承认欺诈行为
- 鉴定结论确认欺诈事实
- 公安机关已刑事立案

**处置方向：** 拒赔、解除合同、追究法律责任

##### 5.2.2 证据不足（补充调查）

**认定标准：** 有疑点但证据不足以认定欺诈

**处置方向：**
- 扩大调查范围，补充收集证据
- 延长调查时限
- 必要时委托第三方深入调查
- 调整调查策略

##### 5.2.3 疑似欺诈（持续监控）

**认定标准：** 存在异常但无法证实欺诈

**处置方向：**
- 本次案件正常理赔
- 纳入重点关注名单
- 后续案件重点审查
- 建立监控档案

##### 5.2.4 正常案件（正常理赔）

**认定标准：** 调查未发现异常，符合保险责任

**处置方向：** 正常赔付，案件结案

#### 5.3 定性报告编制

**报告内容：**
1. **案件基本情况**：保单信息、出险经过、理赔申请
2. **调查过程**：调查方法、调查范围、调查时间
3. **证据清单**：收集的证据材料列表
4. **证据分析**：各项证据的分析意见
5. **定性结论**：案件性质认定及理由
6. **处置建议**：建议采取的处置措施
7. **风险提示**：类似案件风险提示
8. **附件**：证据材料复印件

**报告审批：**
```
调查员起草 → 风控专员审核 → 法务合规审核 → 风控主管审批
```

### Step 6: 处置决策与执行

#### 6.1 拒赔处理

**【KCP6】处置决策合法合规性 - 关键控制点**

##### 6.1.1 适用情形

- 投保人故意不履行如实告知义务
- 被保险人故意制造保险事故
- 编造虚假事故原因或夸大损失程度
- 保险事故属于责任免除范围
- 保险欺诈行为已证实

##### 6.1.2 拒赔流程

1. 法务合规审核拒赔依据
2. 制作拒赔通知书
3. 送达被保险人/受益人（书面送达并留存回执）
4. 说明拒赔理由和法律依据
5. 告知申诉途径和期限
6. 留存送达证据

##### 6.1.3 协谈与拒赔话术

| 场景 | 话术策略 | 示例话术 |
|-----|---------|---------|
| **委婉开场** | 表达理解，降低对抗 | "我们理解您现在的心情，这次调查也是为了保护所有投保人的利益。我们在核实过程中发现了一些情况，需要和您沟通。" |
| **证据展示** | 客观陈述，避免指责 | "我们在调查中发现了一些情况，想和您核实一下。根据医院的记录..." |
| **法律后果** | 明确告知，适度警示 | "根据《保险法》第十六条的规定，投保人故意不履行如实告知义务的，保险人对于合同解除前发生的保险事故，不承担赔偿或者给付保险金的责任，并不退还保险费。" |
| **协商减损** | 给出选择，促成和解 | "考虑到具体情况，如果您愿意协商，我们可以按XX比例赔付，这样也能避免诉讼带来的时间和精力成本。" |
| **坚定立场** | 明确态度，避免纠缠 | "基于以上事实和法律规定，我们公司决定对该案件予以拒赔。如果您对此决定有异议，可以通过以下途径申诉..." |

#### 6.2 协谈减损

##### 6.2.1 适用情形

- 证据存在一定瑕疵，诉讼结果不确定
- 客户有协商意愿，愿意降低索赔金额
- 快速结案有利于控制成本和声誉风险
- 部分欺诈但全额拒赔证据不足

##### 6.2.2 协谈策略

| 阶段 | 策略 | 话术要点 |
|-----|------|---------|
| **摸底阶段** | 了解客户真实诉求和底线 | "您希望通过协商达到什么样的结果？" |
| **施压阶段** | 展示证据，说明诉讼风险 | "根据我们掌握的证据，如果走诉讼程序，结果可能对您不利。" |
| **让步阶段** | 在授权范围内逐步让步 | "考虑到您的实际情况，我们可以适当让步，但希望您也能理解我们的立场。" |
| **成交阶段** | 达成一致，签署协议 | "那我们就按这个方案达成一致，请您在协议上签字确认。" |

##### 6.2.3 协谈协议

- 明确赔付金额和支付方式
- 约定一次性了结，放弃其他索赔
- 保密条款（视情况）
- 双方签字盖章
- 法律效力确认

#### 6.3 司法追偿

##### 6.3.1 刑事报案

**适用情形：** 涉嫌保险诈骗罪，证据确凿

**报案材料：**
- 报案书
- 保险合同及相关资料
- 欺诈证据材料
- 损失金额计算
- 嫌疑人身份信息
- 证据清单

**报案流程：**
1. 向公安机关经侦部门报案
2. 配合公安机关调查
3. 跟进案件进展
4. 刑事判决后申请民事赔偿

**【KCP6-1】刑事报案标准**
- 个人诈骗金额≥1万元
- 单位诈骗金额≥5万元
- 证据确实充分
- 符合刑事立案标准

##### 6.3.2 民事诉讼

**适用情形：** 不构成刑事犯罪但存在违约行为

**诉讼请求：**
- 解除合同
- 返还已赔付金额
- 赔偿损失
- 承担诉讼费用

##### 6.4.1 流程优化

## Rule层

### R1: 保密原则

**内容：** 反欺诈调查全过程严格保密，知情范围最小化

**要求：**
- 调查人员签署保密协议
- 案件信息不得外泄
- 涉及内部员工的，调查过程保密
- 对外沟通需经审批
- 敏感信息加密存储和传输
- 调查资料专人保管

**违规后果：** 泄密造成损失的，追究法律责任；内部员工给予纪律处分

### R2: 依法调查

**内容：** 调查取证必须遵守法律法规，不得侵犯他人合法权益

**要求：**
- 不得采用非法手段获取证据
- 不得限制他人人身自由
- 不得侵入他人住宅
- 不得威胁、恐吓被调查人
- 不得侵犯个人隐私
- 不得泄露商业秘密

**违规后果：** 非法证据予以排除，严重者追究法律责任

### R3: 证据链完整

**内容：** 证据收集必须形成完整链条，能够相互印证

**要求：**
- 单一证据不得定案
- 证据之间逻辑一致
- 排除合理怀疑
- 证据固定符合规范
- 证据来源可追溯
- 证据保管有记录

**违规后果：** 证据不足不得定性为欺诈

### R4: 时效要求

**内容：** 调查工作必须在规定时限内完成

**要求：**

| 案件类型 | 调查时限 | 延期审批 | 预警提醒 |
|---------|---------|---------|---------|
| 简易案件 | 5个工作日 | 主管审批 | 到期前2天 |
| 一般案件 | 15个工作日 | 部门经理审批 | 到期前5天 |
| 复杂案件 | 30个工作日 | 分管领导审批 | 到期前7天 |
| 重大案件 | 60个工作日 | 总经理审批 | 到期前15天 |

**违规后果：** 超期未结案件纳入考核，连续超期追究责任

### R5: 客户权益保护

**内容：** 调查过程中保护客户合法权益，避免不当侵害

**要求：**
- 不得影响客户正常生活
- 不得泄露客户隐私
- 及时告知调查进展
- 保障客户申诉权利
- 调查时间合理
- 调查方式文明

**违规后果：** 客户投诉成立的，追究相关人员责任

### R6: 司法协作

**内容：** 涉嫌犯罪的案件，及时移送司法机关

**要求：**
- 达到刑事立案标准的，10个工作日内移送
- 配合公安机关调查
- 提供完整证据材料
- 跟进案件进展
- 保护受害人权益
- 维护公司合法权益

**违规后果：** 该移不移的，追究相关人员责任

### R7: 回避制度

**内容：** 调查人员与案件有利害关系的，应当回避

**要求：**
- 主动申报利害关系
- 不得参与本人亲属案件调查
- 不得参与存在利益冲突的案件
- 回避决定由主管作出

**违规后果：** 未回避造成不公的，追究责任

### R8: 双人调查

**内容：** 外部调查应当两人以上进行

**要求：**
- 调查人员不少于2人
- 互相监督配合
- 共同签署调查记录
- 特殊情况需审批

**违规后果：** 单人调查取得的证据效力受限

### R9: 权限管理

**内容：** 严格控制系统访问权限

**要求：**
- 分级授权
- 最小权限原则
- 操作日志记录
- 定期权限审查
- 离职即销户

**违规后果：** 越权操作追究责任

### R10: 数据安全

**内容：** 保护调查数据安全

**要求：**
- 敏感数据加密
- 传输通道安全
- 存储介质安全
- 定期备份
- 销毁有记录

**违规后果：** 数据泄露追究责任

### R11: 利益冲突

**内容：** 防范利益冲突

**要求：**
- 不得收受被调查人财物
- 不得与第三方机构有不正当利益往来
- 不得泄露信息谋取私利
- 定期申报利益关系

**违规后果：** 利益冲突行为严肃处理，涉嫌犯罪的移送司法

### R12: 培训要求

**内容：** 调查人员应当具备相应资质

**要求：**
- 岗前培训合格
- 年度继续教育
- 专业技能考核
- 法律知识培训
- 职业道德教育

**违规后果：** 未经培训不得独立开展调查

### R13: 质量控制

**内容：** 建立调查质量管控机制

**要求：**
- 案件抽查制度
- 质量评估标准
- 问题案件复盘
- 持续改进机制
- 质量与绩效挂钩

**违规后果：** 质量问题纳入绩效考核

### R14: 档案管理

**内容：** 规范调查档案管理

**要求：**
- 一案一档
- 分类编号
- 专人保管
- 借阅登记
- 定期整理
- 到期鉴定

**违规后果：** 档案管理不善追究责任

### R15: 费用控制

**内容：** 合理控制调查费用

**要求：**
- 预算审批
- 费用标准
- 据实报销
- 超支审批
- 费用效益分析

**违规后果：** 费用超支需说明原因

### R16: 报告制度

**内容：** 建立案件报告制度

**要求：**
- 重大案件即时报告
- 月度统计报告
- 季度分析报告
- 年度总结报告
- 专项报告

**违规后果：** 瞒报漏报追究责任

### R17: 协作配合

**内容：** 加强部门协作

**要求：**
- 信息共享
- 协同调查
- 联合行动
- 定期会商
- 明确责任

**违规后果：** 协作不力影响案件的，追究责任

### R18: 外部合作

**内容：** 规范外部合作

**要求：**
- 资质审查
- 合同约束
- 过程监督
- 结果验收
- 费用结算

**违规后果：** 合作不当造成损失的，追究责任

### R19: 应急处置

**内容：** 建立应急处置机制

**要求：**
- 应急预案
- 快速响应
- 舆情管控
- 危机公关
- 事后复盘

**违规后果：** 处置不当扩大损失的，追究责任

### R20: 持续改进

**内容：** 持续优化反欺诈工作

**要求：**
- 定期评估
- 问题改进
- 经验总结
- 制度更新
- 技术升级

**违规后果：** 改进不力纳入考核

## Evaluation（6维度评估）

### 评估指标体系

| 指标类别 | 指标名称 | 计算公式 | 目标值 | 权重 | 评估周期 |
|---------|---------|---------|-------|-----|---------|
| **识别效能** | 欺诈识别率 | 识别欺诈案件数 / 实际欺诈案件总数 × 100% | ≥ 85% | 20% | 月度 |
| **调查质量** | 调查成功率 | 成功定性案件数 / 立案调查案件数 × 100% | ≥ 70% | 20% | 月度 |
| **经济效益** | 减损金额 | 年度累计减损金额 | ≥ 保费收入的 1% | 25% | 月度 |
| **效率指标** | 调查时效达标率 | 按时完成案件数 / 总案件数 × 100% | ≥ 90% | 15% | 周度 |
| **合规指标** | 合规率 | 合规案件数 / 总案件数 × 100% | 100% | 10% | 月度 |
| **服务指标** | 客户投诉率 | 投诉案件数 / 总案件数 × 100% | ≤ 1% | 10% | 月度 |

### 指标详细说明

#### 1. 欺诈识别率

**定义：** 系统或人工成功识别出的欺诈案件占所有实际欺诈案件的比例

**计算方式：**
```
欺诈识别率 = (系统预警准确数 + 人工发现数) / 实际欺诈案件总数 × 100%
```

**评估标准：**
| 等级 | 识别率范围 | 评价 |
|-----|-----------|-----|
| 优秀 | ≥90% | 识别能力突出 |
| 良好 | 85%-89% | 识别能力达标 |
| 一般 | 80%-84% | 识别能力待提升 |
| 较差 | <80% | 识别能力不足 |

**提升措施：**
- 优化风控规则模型
- 加强理赔人员培训
- 完善同业信息共享
- 引入AI识别技术

#### 2. 调查成功率

**定义：** 成功完成定性（确认欺诈或排除嫌疑）的案件占立案调查案件的比例

**计算方式：**
```
调查成功率 = (确认欺诈数 + 排除嫌疑数) / 立案调查总数 × 100%
```

**评估标准：**
| 等级 | 成功率范围 | 评价 |
|-----|-----------|-----|
| 优秀 | ≥80% | 调查能力突出 |
| 良好 | 70%-79% | 调查能力达标 |
| 一般 | 60%-69% | 调查能力待提升 |
| 较差 | <60% | 调查能力不足 |

**提升措施：**
- 提升调查人员专业能力
- 完善调查取证手段
- 加强外部协作
- 优化调查流程

#### 3. 减损金额

**定义：** 通过反欺诈工作避免的赔付支出

**计算方式：**
```
减损金额 = 拒赔金额 + 协谈减损金额 + 追偿金额
```

**统计维度：**
- 按案件类型统计
- 按欺诈类型统计
- 按调查方式统计
- 按调查人员统计

**评估标准：**
| 等级 | 减损率范围 | 评价 |
|-----|-----------|-----|
| 优秀 | ≥2% | 经济效益突出 |
| 良好 | 1%-1.9% | 经济效益达标 |
| 一般 | 0.5%-0.9% | 经济效益一般 |
| 较差 | <0.5% | 经济效益不足 |

#### 4. 调查时效达标率

**定义：** 在规定时限内完成调查的案件占比

**计算方式：**
```
调查时效达标率 = 按时完成案件数 / 总案件数 × 100%
```

**评估标准：**
| 等级 | 达标率范围 | 评价 |
|-----|-----------|-----|
| 优秀 | ≥95% | 效率突出 |
| 良好 | 90%-94% | 效率达标 |
| 一般 | 85%-89% | 效率待提升 |
| 较差 | <85% | 效率不足 |

**监控方式：**
- 系统预警即将超期案件
- 周度/月度时效分析
- 超期案件专项督办
- 时效与绩效挂钩

#### 5. 合规率

**定义：** 调查过程符合法律法规和公司制度的案件占比

**考核要点：**
- 取证程序合规
- 客户权益保护
- 档案资料完整
- 审批流程规范

**评估标准：**
| 等级 | 合规率 | 评价 |
|-----|-------|-----|
| 优秀 | 100% | 完全合规 |
| 良好 | 99% | 基本合规 |
| 一般 | 95%-98% | 存在轻微违规 |
| 较差 | <95% | 存在严重违规 |

**监控方式：**
- 定期合规检查
- 案件质量抽查
- 客户投诉分析
- 内外部审计

#### 6. 客户投诉率

**定义：** 因反欺诈调查引发客户投诉的案件占比

**计算方式：**
```
客户投诉率 = 投诉案件数 / 总调查案件数 × 100%
```

**投诉分类：**
| 投诉类型 | 说明 | 处理要求 |
|---------|------|---------|
| 服务态度 | 调查人员态度问题 | 24小时内响应 |
| 程序不当 | 调查程序存在瑕疵 | 48小时内核实 |
| 结果异议 | 对调查结果不认可 | 5个工作日内复核 |
| 权益侵害 | 认为合法权益受损 | 立即上报处理 |

**评估标准：**
| 等级 | 投诉率范围 | 评价 |
|-----|-----------|-----|
| 优秀 | ≤0.5% | 服务质量优秀 |
| 良好 | 0.5%-1% | 服务质量达标 |
| 一般 | 1%-2% | 服务质量待提升 |
| 较差 | >2% | 服务质量不足 |

### 评估周期与报告

| 评估类型 | 周期 | 报告内容 | 报送对象 | 责任人 |
|---------|-----|---------|---------|--------|
| 日常监控 | 每日 | 案件进度、预警信息 | 风控专员 | 系统 |
| 周度分析 | 每周 | 本周案件统计、问题汇总 | 风控主管 | 风控专员 |
| 月度报告 | 每月 | 指标完成情况、典型案例 | 部门经理 | 风控主管 |
| 季度评估 | 每季 | 全面评估、改进建议 | 分管领导 | 部门经理 |
| 年度总结 | 每年 | 年度总结、下年计划 | 总经理室 | 分管领导 |

### 综合评分计算

```
综合评分 = Σ(单项指标得分 × 权重)

单项指标得分计算：
- 达到目标值：100分
- 达到良好值：80分
- 达到一般值：60分
- 未达到一般值：40分

等级评定：
- 优秀：≥90分
- 良好：80-89分
- 合格：60-79分
- 不合格：<60分
```

### 附录D：法规依据

#### D.1 法律法规

**《中华人民共和国保险法》相关条款：**

**第十六条（如实告知义务）：**
> 订立保险合同，保险人就保险标的或者被保险人的有关情况提出询问的，投保人应当如实告知。
> 投保人故意或者因重大过失未履行前款规定的如实告知义务，足以影响保险人决定是否同意承保或者提高保险费率的，保险人有权解除合同。
> 投保人故意不履行如实告知义务的，保险人对于合同解除前发生的保险事故，不承担赔偿或者给付保险金的责任，并不退还保险费。

**第二十七条（保险欺诈）：**
> 未发生保险事故，被保险人或者受益人谎称发生了保险事故，向保险人提出赔偿或者给付保险金请求的，保险人有权解除合同，并不退还保险费。
> 投保人、被保险人故意制造保险事故的，保险人有权解除合同，不承担赔偿或者给付保险金的责任；除本法第四十三条规定外，不退还保险费。

**《中华人民共和国刑法》相关条款：**

**第一百九十八条（保险诈骗罪）：**
> 有下列情形之一，进行保险诈骗活动，数额较大的，处五年以下有期徒刑或者拘役，并处一万元以上十万元以下罚金；数额巨大或者有其他严重情节的，处五年以上十年以下有期徒刑，并处二万元以上二十万元以下罚金；数额特别巨大或者有其他特别严重情节的，处十年以上有期徒刑，并处二万元以上二十万元以下罚金或者没收财产：
> （一）投保人故意虚构保险标的，骗取保险金的；
> （二）投保人、被保险人或者受益人对发生的保险事故编造虚假的原因或者夸大损失的程度，骗取保险金的；
> （三）投保人、被保险人或者受益人编造未曾发生的保险事故，骗取保险金的；
> （四）投保人、被保险人故意造成财产损失的保险事故，骗取保险金的；
> （五）投保人、受益人故意造成被保险人死亡、伤残或者疾病，骗取保险金的。

#### D.2 监管规定
