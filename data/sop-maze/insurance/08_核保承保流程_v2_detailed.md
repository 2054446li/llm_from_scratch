## Objective

本SOP旨在规范保险公司核保承保的全流程操作，确保：

1. **风险控制**：通过5维风险评估模型，准确识别和量化承保风险，赔付率控制在精算假设范围内
2. **合规经营**：严格遵守《保险法》规定的如实告知义务、保险利益原则、反洗钱要求
3. **客户体验**：提供专业、透明、有温度的核保服务，条件承保接受率≥80%
4. **业务效率**：标准案件处理时效≤2工作日，体检案件≤7工作日
5. **可追溯性**：所有核保决策留痕，支持审计和复议

**多方对话系统**：
- **客户** ↔ **核保系统**（提交投保申请、上传资料、查询进度）
- **客户** ↔ **核保员**（健康告知核实、核保结论说明、条件协商）
- **核保员** ↔ **代理人**（资料补充、客户沟通协助）
- **核保员** ↔ **体检机构**（体检预约、报告解读）
- **核保员** ↔ **调查公司**（生存调查委托、报告审核）
- **核保员** ↔ **再保公司**（高额保单分保协商）

## Standard Operating Procedures

### 1. 投保资料接收与初审

#### 1.1 资料完整性检查

##### 1.1.1 投保资料清单

**基础身份资料**：

| 资料类型 | 具体内容 | 审核要点 | 风险标识 | KCP |
|----------|----------|----------|----------|-----|
| 身份证明 | 身份证/护照/户口本 | 真实性、有效期、与投保人一致性 | 伪造证件、过期证件 | ✓ 必须联网核查 |
| 年龄证明 | 出生证明/户籍证明 | 投保年龄是否符合产品限制 | 年龄误告 | ✓ 投保年龄计算 |
| 关系证明 | 结婚证/亲属关系证明 | 投保人与被保险人关系、保险利益 | 无可保利益 | ✓ 保险利益核实 |

**健康告知资料**：

| 资料类型 | 具体内容 | 审核要点 | 风险标识 | KCP |
|----------|----------|----------|----------|-----|
| 健康告知书 | 投保书健康告知栏 | 完整性、勾选一致性 | 漏告、错告 | ✓ 逐题核对 |
| 既往病历 | 门诊/住院病历、检查报告 | 疾病严重程度、治疗情况 | 既往症风险 | ✓ 病历真实性 |
| 体检报告 | 近期体检报告 | 异常指标、趋势变化 | 健康异常 | ✓ 报告时效性 |

**财务证明资料**：

| 资料类型 | 具体内容 | 审核要点 | 风险标识 | KCP |
|----------|----------|----------|----------|-----|
| 收入证明 | 工资流水/纳税证明/营业执照 | 收入稳定性、保额收入比 | 保额过高 | ✓ 收入核实 |
| 资产证明 | 房产证/存款证明/投资证明 | 资产真实性、来源合法性 | 资金来源不明 | ✓ 反洗钱筛查 |
| 负债证明 | 贷款合同/信用卡账单 | 负债率评估 | 财务风险 | ✓ 净资产计算 |

**职业证明资料**：

| 资料类型 | 具体内容 | 审核要点 | 风险标识 | KCP |
|----------|----------|----------|----------|-----|
| 职业证明 | 工作证/劳动合同/单位证明 | 职业类别判定 | 高风险职业 | ✓ 职业类别核实 |
| 执业资格 | 特殊行业资质证书 | 执业合法性 | 无证执业 | ✓ 资质验证 |

##### 1.1.2 初审流程

```
接收投保 ──▶ 资料清点 ──▶ 完整性检查 ──▶ 规则初筛 ──▶ 系统录入 ──▶ 案件分配
    │            │            │              │            │            │
    ▼            ▼            ▼              ▼            ▼            ▼
 多渠道入口   资料清单核对   必备项检查    年龄/保额    信息录入    核保员分配
                                         职业初筛
```

**【KCP】初审关键控制点**：
- 资料完整性检查必须在接收后4小时内完成
- 投保年龄必须在产品允许范围内（一般18-60岁）
- 保险利益必须明确且合法
- 反洗钱初筛必须完成（识别大额交易）

#### 1.2 投保规则初筛

##### 1.2.1 初筛规则矩阵

| 规则项 | 通过标准 | 拦截动作 | 处理时效 |
|--------|----------|----------|----------|
| 年龄限制 | 在产品投保年龄范围内 | 超龄不予受理 | 实时 |
| 保额限制 | 符合产品最低/最高保额 | 调整保额或拒保 | 实时 |
| 职业限制 | 非拒保职业类别 | 职业不符拒保 | 实时 |
| 地域限制 | 非高风险地区 | 需额外审核 | 实时 |
| 既往拒保史 | 无近期拒保记录 | 转人工审核 | 实时 |

### 2. 风险信息收集

#### 2.1 健康告知核实

##### 2.1.1 疾病史询问标准话术

**【开场白】**

```
核保员："您好，我是XX保险公司核保员，工号UW001。
为了给您提供准确的核保评估，我需要详细了解您的健康状况。
请您如实回答，这关系到您未来的理赔权益。

根据《保险法》规定，投保人应当如实告知被保险人的健康状况。
如果未如实告知，可能导致保险合同解除或理赔拒付。"
```

**【既往疾病询问话术】**

```
核保员："请问您是否曾经患有或正在患有以下疾病？

一、心脑血管疾病：
   - 高血压（血压≥140/90mmHg）
   - 冠心病、心肌梗死
   - 脑卒中（脑出血、脑梗塞）
   - 心律失常、心力衰竭

二、代谢性疾病：
   - 糖尿病（1型或2型）
   - 甲状腺疾病（甲亢、甲减、甲状腺结节）
   - 高血脂症

三、肿瘤疾病：
   - 良性肿瘤（请说明部位和性质）
   - 恶性肿瘤（癌症）

四、肝肾疾病：
   - 肝炎（乙肝、丙肝等）
   - 肝硬化、肝功能异常
   - 肾炎、肾功能异常

五、精神神经疾病：
   - 癫痫
   - 精神疾病（抑郁症、焦虑症等）
   - 帕金森病、多发性硬化

六、其他慢性疾病：
   - 哮喘、慢性阻塞性肺病
   - 类风湿关节炎
   - 系统性红斑狼疮

请详细说明患病时间、诊断医院、治疗情况和目前状况。"
```

**【询问技巧话术】**

```
开放式问题：
"能详细描述一下当时的诊断和治疗情况吗？"

时间确认：
"具体是什么时候确诊的？治疗了多长时间？"

现状确认：
"目前病情如何？是否还在服药/治疗？"

复查情况：
"最近有复查吗？指标是否正常？最近一次检查是什么时候？"

就医确认：
"在哪些医院就诊过？有保留病历或检查报告吗？"
```

##### 2.1.2 住院/手术史核实话术

**【住院史询问话术】**

```

- 住院时间：具体入院和出院日期
- 住院医院：医院名称和等级

- 出院情况：治愈/好转/未愈？医嘱建议？
- 目前状况：是否有后遗症？是否需要继续治疗？"
```

**【手术史询问话术】**

```

```

   - 父亲/母亲是否有高血压、冠心病、脑卒中？

   - 血友病
   - 多囊肾

【记录要点】
- 患病亲属关系
- 发病年龄
- 目前状况（在世/去世，如去世记录死亡原因和年龄）
- 是否有多位亲属患同种疾病"
```

##### 2.3.2 保额与收入匹配度评估

| 险种 | 建议保额上限 | 计算依据 | 超额处理 |
|------|--------------|----------|----------|
| 重疾险 | 年收入的3-5倍 | 收入替代+康复费用 | 要求财务证明 |
| 寿险 | 年收入的10-20倍 | 家庭责任覆盖 | 财务调查+生调 |
| 意外险 | 年收入的10-20倍 | 意外风险保障 | 职业核实 |
| 医疗险 | 根据产品规定 | 医疗费用覆盖 | 按产品限额 |

**【KCP】财务审核关键控制点**：
- 保额收入比超过20倍必须提供详细财务证明
- 高额保单（保额>500万）必须做生存调查
- 反洗钱筛查必须完成（识别大额现金交易）

### 3. 风险评估与分级

#### 3.1 5维风险评估模型

##### 3.1.1 年龄风险评分

| 年龄段 | 风险分值 | 评分说明 |
|--------|----------|----------|
| 18-25岁 | 0分 | 年轻，疾病发生率低 |
| 26-35岁 | 3分 | 青年，风险较低 |
| 36-45岁 | 6分 | 中年，风险开始上升 |
| 46-55岁 | 10分 | 中老年，风险明显增加 |
| 56-60岁 | 15分 | 近老年，风险较高 |
| >60岁 | 20分 | 老年，风险高（多数产品拒保） |

**年龄风险权重：15%**

##### 3.1.2 性别风险评分

| 性别 | 风险分值 | 评分说明 |
|------|----------|----------|
| 女性 | 0分 | 平均寿命更长，部分疾病风险较低 |
| 男性 | 3分 | 平均寿命较短，心血管疾病风险较高 |

**性别风险权重：5%**

##### 3.1.3 BMI风险评分

| BMI范围 | 风险分值 | 健康状态 | 评分说明 |
|---------|----------|----------|----------|
| 18.5-24 | 0分 | 正常 | 健康体重 |
| 24-28 | 5分 | 超重 | 轻度肥胖风险 |
| <18.5 | 8分 | 偏瘦 | 营养不良风险 |
| 28-32 | 10分 | 肥胖 | 代谢疾病风险 |
| >32 | 15分 | 重度肥胖 | 多种疾病高风险 |

**BMI计算公式**：
```
BMI = 体重(kg) / 身高(m)²

示例：体重70kg，身高1.75m
BMI = 70 / (1.75)² = 70 / 3.0625 = 22.86（正常）
```

**BMI风险权重：10%**

##### 3.1.4 健康风险评分

**血压评分（权重15%）**：

| 血压范围 | 分级 | 风险分值 |
|----------|------|----------|
| <120/80 mmHg | 正常 | 0分 |
| 120-139/80-89 mmHg | 正常高值 | 5分 |
| 140-159/90-99 mmHg | 1级高血压 | 10分 |
| 160-179/100-109 mmHg | 2级高血压 | 15分 |
| ≥180/110 mmHg | 3级高血压 | 20分 |

**血糖评分（权重15%）**：

| 血糖状态 | 空腹血糖(mmol/L) | 风险分值 |
|----------|------------------|----------|
| 正常 | <6.1 | 0分 |
| 空腹血糖受损 | 6.1-6.9 | 7分 |
| 糖尿病（控制良好） | ≥7.0，HbA1c<7% | 12分 |
| 糖尿病（控制不佳） | ≥7.0，HbA1c≥7% | 15分 |

**既往病史评分（权重20%）**：

| 病史情况 | 风险分值 | 评分说明 |
|----------|----------|----------|
| 无重大病史 | 0分 | 健康体 |
| 已治愈疾病（>5年） | 5分 | 如阑尾炎手术 |
| 已治愈疾病（2-5年） | 8分 | 如甲状腺手术 |
| 慢性病控制良好 | 10-15分 | 如高血压控制良好 |
| 慢性病控制不佳 | 15-20分 | 如糖尿病控制不佳 |
| 严重病史 | 20分 | 如恶性肿瘤、心梗 |

##### 3.1.5 职业风险评分

| 职业类别 | 风险系数 | 风险分值 | 典型职业 |
|----------|----------|----------|----------|
| 1类 | 1.0 | 0分 | 办公室职员、教师、医生 |
| 2类 | 1.2 | 3分 | 销售人员、服务业人员 |
| 3类 | 1.5 | 6分 | 制造业工人、司机 |
| 4类 | 2.0 | 10分 | 建筑工人、机械操作员 |
| 5类 | 2.5 | 15分 | 高空作业、矿工、消防员 |
| 6类 | 3.0+ | 20分 | 爆破工、特技演员 |

**职业风险权重：10%**

#### 3.2 综合风险计算公式

```
风险总分 = (年龄得分 × 15%) + (性别得分 × 5%) + (BMI得分 × 10%) 
        + (健康得分 × 50%) + (职业得分 × 10%) + (财务得分 × 10%)

注：财务得分根据保额收入比计算
- 保额收入比 ≤10倍：0分
- 10-15倍：3分
- 15-20倍：6分
- >20倍：10分
```

**风险总分计算示例**：

```
客户画像：
- 年龄：45岁（得分6）
- 性别：男（得分3）
- BMI：26.5（得分5）
- 健康：1级高血压（得分10），无其他病史
  健康得分 = (10×15/50) + (0×15/50) + (0×20/50) = 3分
- 职业：企业高管1类（得分0）
- 财务：保额收入比8倍（得分0）

风险总分 = (6×0.15) + (3×0.05) + (5×0.10) + (3×0.50) + (0×0.10) + (0×0.10)
        = 0.9 + 0.15 + 0.5 + 1.5 + 0 + 0
        = 3.05分（标准体）
```

#### 3.3 风险等级映射

| 风险等级 | 风险总分区间 | 核保决策 | 费率调整 |
|----------|--------------|----------|----------|
| 标准体 | 0-40分 | 标准承保 | 标准费率 |
| 次标准体（轻度） | 40-55分 | 加费承保 | +10%-25% |
| 次标准体（中度） | 55-70分 | 加费/除外 | +25%-50% |
| 次标准体（重度） | 70-85分 | 加费+除外/限额 | +50%-100% |
| 延期体 | 不确定性风险 | 延期决定 | - |
| 拒保体 | ≥85分或绝对除外 | 拒保 | - |

**【KCP】风险评估关键控制点**：
- 风险评分必须由系统自动计算+人工复核
- 次标准体决策必须有明确的加费/除外依据
- 拒保决定必须经过主管审批
- 所有风险因子必须有书面记录

### 4. 核保决策

#### 4.1 标准体承保

**适用条件**：
- 风险总分 < 40分
- 无健康异常
- 无职业风险
- 保额收入比合理

**【话术】标准承保通知话术**：

```
系统："恭喜您！您的投保申请已通过核保审核。

核保结论：标准承保
保障范围：完整保障，无任何除外责任
保费费率：标准费率

您的保单将在首期保费到账后正式生效。
犹豫期为15天，在此期间您可无条件退保。

感谢您选择XX保险！"
```

#### 4.2 加费承保

**加费计算公式**：
```
加费比例 = 基础加费率 × 风险调整系数

基础加费率参考：
- 轻度风险（40-55分）：+10%-25%
- 中度风险（55-70分）：+25%-50%
- 重度风险（70-85分）：+50%-100%

调整后保费 = 标准保费 × (1 + 加费比例)
```

**【话术】加费承保说明话术**：

```

高于标准人群约30%，因此需要在标准费率基础上
增加风险保费。

加费比例：+25%
标准保费：25,000元/年
加费金额：6,250元/年
调整后保费：31,250元/年

保障范围：与标准承保一致，无任何除外责任

| R1.2 | 告知不完整拦截 | 健康告知未完整填写 | 要求补充告知 | "请完整填写健康告知书" |

| 规则ID | 规则名称 | 触发条件 | 拦截动作 | 提示信息 |
