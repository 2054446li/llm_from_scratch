# 保全服务流程SOP

## 1. SOP简介

本SOP规范保全专员处理客户保单相关服务申请的完整流程，涵盖保单贷款、红利领取、年金给付、保单复效等综合保全业务，确保服务合规高效、资金安全准确、客户体验优良。

## 3. Objective

### 3.1 流程目标

| 目标维度 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| **合规目标** | 确保所有保全业务符合监管要求与公司制度 | 合规率100%，零监管处罚 |
| **效率目标** | 在承诺时效内完成服务办理 | 贷款3工作日、红利1工作日、年金按时给付 |
| ** accuracy目标** | 确保金额计算准确、资金划拨无误 | 差错率<0.1%，资金零损失 |
| **服务目标** | 提供专业化、人性化的客户服务 | 客户满意度≥95%，投诉率<0.5% |
| **风控目标** | 防范欺诈风险与资金风险 | 反洗钱识别率100%，欺诈拦截率100% |

   - 专员：解释办理条件、核算金额、告知风险提示、确认办理意向

2. 保全专员 ↔ 核心业务系统
   - 录入保全申请、查询保单状态、计算现金价值/红利/年金
   - 获取系统校验结果（资格/额度/时效）

   - 大额交易自动报送
   - 可疑交易预警提示

5. 财务系统 ↔ 银行系统
   - 发起转账指令
   - 接收到账回执

6. 保全专员 ↔ 客户（结果反馈）
   - 通知办理结果
   - 发送电子凭证/到账提醒

## 4. Standard Operating Procedures

### Step 1: 服务申请受理与身份核验

#### 1.1 接收客户申请

| 受理渠道 | 受理方式 | 适用业务类型 | 注意事项 |
|---------|---------|-------------|---------|
| **柜面受理** | 客户亲临客服中心 | 全业务类型 | 原件核验、现场签字 |
| **电话受理** | 客服热线申请 | 咨询/简单查询 | 身份核验后预约柜面办理 |
| **线上受理** | APP/官网/小程序 | 红利查询/部分领取 | 人脸识别+电子签名 |
| **代理人代办** | 代理人持委托书 | 非资金类业务优先 | 双证核验+授权委托书 |

**受理话术模板：**
> "您好，欢迎办理保全服务。请问您需要办理什么业务？请提供您的身份证和保单号，我帮您查询保单状态。"

#### 1.2 身份核验流程

```
├─ 本人办理
│   ├─ 身份证原件核验（真伪/有效期）
│   ├─ 人证比对（人脸识别系统）
│   ├─ 保单权益人确认（系统核对投保人/被保险人）
│   └─ 联系方式验证（预留手机号短信验证）
│
└─ 委托代办
    ├─ 投保人身份证原件
    ├─ 代办人身份证原件
    ├─ 授权委托书（公证或公司标准格式）
    ├─ 关系证明（户口本/结婚证/亲属关系证明）
    └─ 代办人身份核验（同本人办理流程）
```

#### 1.3 保单归属权确认

- 查询保单号对应投保人信息
- 核对申请人与投保人身份一致性
- 确认保单无质押/冻结/司法查封等限制

### Step 2: 服务类型识别与分流

#### 2.1 服务类型判定矩阵

| 客户诉求 | 判定条件 | 对应服务类型 | 分流去向 |
|---------|---------|-------------|---------|
| 急需用钱，想借保单的钱 | 保单有现金价值 | **保单贷款** | 贷款分支 |
| 领取保单分红 | 分红险且已过犹豫期 | **红利领取** | 红利分支 |
| 到了领钱的年龄 | 年金险到达给付时点 | **年金给付** | 年金分支 |
| 保单失效想恢复 | 失效2年内 | **保单复效** | 复效分支 |
| 不想继续缴费 | 犹豫期外 | 退保/减额交清 | 其他分支 |
| 变更受益人/地址等 | 非资金类 | 保全变更 | 其他分支 |

#### 2.2 各服务类型办理条件

**A. 保单贷款办理条件**

| 条件项 | 具体要求 | 系统校验点 |
|-------|---------|-----------|
| 保单状态 | 有效且未处于理赔/质押状态 | 状态码 = 有效 |
| 缴费要求 | 缴满一定年限（通常2年） | 实缴期数 ≥ 最低要求 |
| 现金价值 | 当前现金价值 > 0 | 现金价值表查询 |
| 贷款额度 | 不超过现金价值的80% | 可贷额度 = 现金价值 × 80% |
| 贷款期限 | 通常6个月，可续贷 | 系统设置最大期限 |
| 特殊限制 | 投连险/万能险可能有特殊规定 | 产品规则校验 |

**B. 红利领取办理条件**

| 条件项 | 具体要求 | 系统校验点 |
|-------|---------|-----------|
| 产品类型 | 分红型保险 | 产品代码校验 |
| 分红年度 | 已过至少一个完整保单年度 | 生效日期+1年 |
| 领取方式 | 累积生息/现金领取/抵交保费 | 客户选择确认 |
| 累积红利 | 查询红利累积账户余额 | 红利系统查询 |

**C. 年金给付办理条件**

| 条件项 | 具体要求 | 系统校验点 |
|-------|---------|-----------|
| 产品类型 | 年金保险 | 产品代码校验 |
| 给付时点 | 到达约定给付年龄/日期 | 出生日期+给付年龄 |
| 给付条件 | 被保险人生存 | 生存状态确认 |
| 给付方式 | 年领/月领/一次性领取 | 客户选择确认 |

**D. 保单复效办理条件**

| 条件项 | 具体要求 | 系统校验点 |
|-------|---------|-----------|
| 失效时间 | 中止之日起2年内 | 失效日期+2年 ≥ 当前日期 |
| 健康告知 | 需重新健康告知/体检 | 健康问卷/体检报告 |
| 补交费用 | 欠缴保费+利息 | 财务核算 |
| 风险保额 | 可能需重新核保 | 核保系统流转 |

### Step 3: 资格与条件审核

#### 3.1 保单状态核查

```
保单状态流转图：

正常缴费 ──► 宽限期（60天）──► 保单失效 ──► 复效期（2年）──► 永久失效
    │                              ▲              │
    │                              └──────────────┘
    │                                    复效办理
    │
    ├─► 贷款中 ──► 贷款逾期 ──► 保单失效
    │
    ├─► 理赔中 ──► 理赔完成/拒赔
    │
    └─► 质押/冻结（司法/行政）──► 解除后恢复
```

**状态限制表：**

| 服务类型 | 正常 | 宽限期 | 贷款中 | 失效 | 理赔中 | 冻结 |
|---------|:--:|:--:|:--:|:--:|:--:|:--:|
| 保单贷款 | ✓ | ✓ | ✗ | ✗ | ✗ | ✗ |
| 红利领取 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 年金给付 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 保单复效 | ✗ | ✗ | ✗ | ✓ | ✗ | ✗ |
| 退保 | ✓ | ✓ | ✗ | ✓ | ✗ | ✗ |

#### 3.2 现金价值核算

**现金价值查询路径：**
1. 核心业务系统 → 保单查询 → 现金价值表
2. 输入保单年度/当前日期
3. 获取当前现金价值金额

**现金价值计算说明：**
- 现金价值 = 已缴保费 - 初始费用 - 保障成本 + 利息累积
- 早期退保/贷款现金价值较低（有初始费用扣除）
- 不同产品现金价值增长曲线不同

#### 3.3 贷款额度审核

```
贷款额度计算流程：

当前现金价值 = 查询现金价值表(保单号, 当前日期)
     │
     ▼
最高可贷额度 = 当前现金价值 × 贷款比例(通常80%)
     │
     ▼
实际贷款额度 = min(客户申请金额, 最高可贷额度, 产品单笔上限)
     │
     ▼
系统校验：实际贷款额度 ≤ 可用额度 ✓
```

#### 3.4 复效条件审核

| 审核项目 | 审核内容 | 审核标准 |
|---------|---------|---------|
| 时效审核 | 失效时间是否在2年内 | 失效日期 + 730天 ≥ 申请日期 |
| 健康审核 | 重新健康告知 | 无新增重大疾病/高风险职业 |
| 财务审核 | 补交保费能力确认 | 客户确认补交金额 |
| 核保审核 | 风险保额变化 | 可能需体检/加费/除外 |

#### 3.5 反洗钱与合规筛查

**大额交易识别：**
- 单笔交易 ≥ 人民币5万元（或等值外币1万美元）
- 当日累计交易 ≥ 人民币5万元

**可疑交易监测：**
- 频繁办理贷款/领取业务
- 资金快进快出
- 与投保人身份/收入明显不符的大额交易
- 非面对面交易且无法合理解释

### Step 4: 金额核算与确认

#### 4.1 保单贷款金额核算

**可贷额度计算：**

```
可贷额度 = min(申请金额, 现金价值 × 80%, 产品贷款上限)

示例：
- 保单现金价值：100,000元
- 客户申请贷款：70,000元
- 产品贷款上限：500,000元
- 计算：min(70000, 100000×80%=80000, 500000) = 70,000元 ✓
```

**贷款利息计算：**

```
利息计算公式：

日利息 = 贷款本金 × 年利率 / 365
累计利息 = Σ(每日本金余额 × 日利率)

示例：
- 贷款本金：50,000元
- 年利率：5.5%
- 贷款期限：180天

到期利息 = 50000 × 5.5% × 180 / 365 = 1,356.16元
到期应还 = 50000 + 1356.16 = 51,356.16元
```

**利率说明：**
- 贷款利率通常参照央行基准利率+上浮
- 不同产品、不同时期利率可能不同
- 利率变动时按合同约定执行（固定/浮动）

#### 4.2 红利金额核算

**累积红利计算：**

```
累积红利 = Σ(各保单年度分红金额)

其中：
- 年度分红 = 保单保额 × 分红率
- 分红率由保险公司根据经营状况确定
- 累积红利可选择累积生息或现金领取

利息红利（如选择累积生息）：
利息 = 累积红利 × 累积利率 × 持有天数 / 365
```

**红利领取方式：**

| 领取方式 | 处理方式 | 适用场景 |
|---------|---------|---------|
| 现金领取 | 一次性给付至银行账户 | 急需资金 |
| 累积生息 | 继续留存生息 | 长期增值 |
| 抵交保费 | 抵扣下期应缴保费 | 缴费压力 |
| 购买交清增额 | 增加保单保额 | 保障提升 |

#### 4.3 年金给付核算

**定期年金计算：**

```
年领金额 = 基本保额 × 年金给付比例
月领金额 = 年领金额 × 月领系数(通常8.5%)

示例：
- 基本保额：100,000元
- 年金给付比例：10%
- 年领金额 = 100000 × 10% = 10,000元/年
- 月领金额 = 10000 × 8.5% = 850元/月
```

**终身年金计算（精算公式）：**

```
终身年金现值 = 年领金额 × 年金现值系数

其中年金现值系数取决于：
- 被保险人当前年龄
- 生命表（死亡率）
- 预定利率

实务中由系统根据精算表自动计算
```

#### 4.4 复效费用核算

**补交保费计算：**

```
应补保费 = 欠缴保费 + 复效利息

欠缴保费 = Σ(各期应缴保费)

复效利息 = 欠缴保费 × 复效利率 × 欠费天数 / 365

示例：
- 月缴保费：1,000元
- 欠缴期数：6期
- 欠缴保费：6,000元
- 复效利率：6%
- 平均欠费天数：90天

复效利息 = 6000 × 6% × 90 / 365 = 88.77元
应补总额 = 6000 + 88.77 = 6,088.77元
```

### Step 6: 审批与资金处理

#### 6.1 内部审批流程

**审批权限矩阵：**

| 业务类型 | 金额范围 | 审批层级 | 审批时效 |
|---------|---------|---------|---------|
| 常规业务 | ≤5万 | 专员初审→主管复核 | 即时 |
| 大额业务 | 5-10万 | 专员初审→主管复核→部门经理 | 1工作日 |
| 超大额业务 | >10万 | 专员初审→主管复核→部门经理→分管总 | 2工作日 |
| 特殊业务 | 不限 | 专员初审→主管复核→风控合规→分管总 | 3工作日 |

**特殊业务定义：**
- 保单复效（需核保）
- 退保（犹豫期外）
- 异常保全（资料不全/信息存疑）
- 高风险客户业务

#### 6.2 资金划拨处理

**贷款发放流程：**

```
1. 审批通过后，系统自动生成付款指令
2. 财务系统接收指令，校验账户信息
3. 财务专员复核付款金额、账户
4. 提交银行转账（大额需双签）
5. 银行处理到账（通常实时/当日）
6. 系统接收银行回执，更新保单状态为"贷款中"
7. 发送到账通知短信/APP推送
```

**红利/年金给付流程：**

```
1. 审批通过后，系统生成代付清单
2. 财务系统汇总当日所有给付业务
3. 生成批量代付文件提交银行
4. 银行批量处理（通常T+1到账）
5. 接收银行回执，核对成功/失败清单
6. 成功：更新系统状态，发送到账通知
7. 失败：标记异常，人工跟进处理
```

**复效收费流程：**

```
1. 系统生成应补费用明细
2. 客户缴费（POS/转账/现金）
3. 财务确认到账
4. 系统更新保单状态为"有效"
5. 生成复效确认书
6. 发送复效成功通知
```

## 8. Evaluation

### 8.1 评估指标体系

| 评估维度 | 指标名称 | 计算公式 | 目标值 | 权重 |
|---------|---------|---------|-------|------|
| **时效指标** | 贷款办理时效 | 贷款业务平均处理时间 | ≤3工作日 | 20% |
| | 红利到账时效 | 红利业务平均处理时间 | ≤1工作日 | 15% |
| | 复效办理时效 | 复效业务平均处理时间 | ≤5工作日 | 10% |
| **质量指标** | 业务差错率 | 差错笔数/总笔数 | <0.1% | 20% |
| | 资金差错率 | 资金差错金额/总金额 | 0% | 15% |
| **服务指标** | 客户满意度 | 满意评价数/总评价数 | ≥95% | 10% |
| | 投诉率 | 投诉笔数/总笔数 | <0.5% | 5% |
| **效率指标** | 资金周转效率 | 贷款周转次数/年均 | ≥2次 | 5% |

### 8.2 评估标准

| 等级 | 综合得分 | 评价 |
|-----|---------|------|
| A（优秀） | ≥90分 | 流程执行优秀，可作为标杆 |
| B（良好） | 80-89分 | 流程执行良好，有小幅改进空间 |
| C（合格） | 70-79分 | 流程基本合格，需针对性改进 |
| D（待改进） | <70分 | 流程存在明显问题，需全面整改 |

### 8.3 持续改进机制

```
评估周期：月度评估 + 季度复盘 + 年度审计

改进流程：
1. 数据收集：系统自动采集时效/差错/满意度数据
2. 问题识别：分析不达标指标，定位问题环节
3. 根因分析：鱼骨图/5Why分析找出根本原因
4. 改进措施：制定针对性改进方案
5. 实施跟踪：执行改进措施，跟踪效果
6. 固化标准：有效措施纳入SOP更新
```

## 附录：风险提示话术库

### 保单贷款风险提示

> "温馨提示：保单贷款期间，您的保险保障继续有效。但请注意：
> 1. 贷款本金和利息需要在到期时归还；
> 2. 如果贷款本息累计超过保单现金价值，保单将会失效；
> 3. 贷款利息按日计算，提前还款可以节省利息；
> 4. 建议您在资金宽裕时尽早还款，以免影响保单效力。"

### 红利领取风险提示

> "温馨提示：
> 1. 红利金额根据公司经营状况确定，过往分红不代表未来；
> 2. 选择现金领取后，红利将不再累积生息；
> 3. 如果您选择累积生息，红利将继续享受利息收益；
> 4. 请确认您的银行账户信息准确，以免影响资金到账。"

### 年金给付风险提示

> "温馨提示：
> 1. 年金给付开始后，请确保您的银行账户状态正常；
> 2. 如选择月领方式，每月给付日请留意账户到账情况；
> 3. 如需变更领取账户，请提前办理变更手续；
> 4. 被保险人身故后，未领取的年金将按合同约定处理。"

### 保单复效风险提示

> "温馨提示：
> 1. 复效需要重新进行健康告知，如健康状况变化可能影响核保结论；
> 2. 复效需要补交欠缴保费及利息；
> 3. 复效后可能有等待期，等待期内发生保险事故可能无法理赔；
> 4. 请在复效前充分了解您的健康状况和复效条件。"

### 退保/部分领取风险提示

> "温馨提示：
> 1. 退保/部分领取后，保单保额或账户价值将相应减少；
> 2. 犹豫期后退保可能产生损失，退还金额可能低于已缴保费；
> 3. 部分领取后，保单收益可能受到影响；
> 4. 请充分考虑后再做决定，如有疑问请咨询客服。"
