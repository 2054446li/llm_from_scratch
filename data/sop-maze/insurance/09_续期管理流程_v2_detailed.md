### 2.2 详细时间轴图

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│                           续期管理完整时间轴 (T-45 至 T+60)                                │
└──────────────────────────────────────────────────────────────────────────────────────────┘

【到期前阶段 - 主动续期期】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

T-45天 (仅A级客户)
├─ 触达方式: 专属电话 (1对1专员)
├─ 话术策略: 身份确认 → 提前告知 → 需求了解 → 服务预约
├─ 关键动作: 确认联系方式有效性、了解服务需求、标记客户状态
├─ KCP: 高价值客户首次触达必须在T-45前完成
└─ 系统操作: 标记"A级首次触达完成"、更新客户画像

T-30天 (全部客户)
├─ 触达方式: 短信 + APP推送 + 微信 (多渠道)
├─ 话术策略: 标准提醒 → 金额告知 → 方式指引 → 热线提供
├─ 关键动作: 确保信息送达、引导自助服务
├─ KCP: 提醒覆盖率必须达到100%
└─ 系统操作: 发送记录存档、标记"T-30提醒完成"

T-21天 (B/C级客户电话跟进)
├─ 触达方式: 自动外呼 (B级) / 人工电话 (C级)
├─ 话术策略: 提醒确认 → 意向探测 → 疑问解答
├─ 关键动作: 识别响应状态、标记客户意向
└─ 系统操作: 更新客户意向标签

T-15天 (未响应客户)
├─ 触达方式: 人工电话外呼
├─ 话术策略: 截止日期强调 → 续保意向确认 → 疑问解答 → 缴费预约
├─ 关键动作: 确认客户收到提醒、了解未响应原因
├─ KCP: 未响应客户必须在T-15前完成电话触达
└─ 系统操作: 更新客户意向标签、记录未响应原因

T-7天 (仍未缴费)
├─ 触达方式: 电话 (升级话术)
├─ 话术策略: 宽限期概念说明 → 逾期影响强调 → 缴费协助提供 → 计划确认
├─ 关键动作: 明确告知宽限期规则、确认具体缴费计划
├─ KCP: 必须明确告知宽限期60天规则及失效后果
└─ 系统操作: 标记"紧急跟进"、设置T-0提醒

T-3天 (最后提醒)
├─ 触达方式: 电话 + 短信
├─ 话术策略: 最后提醒 → 宽限期即将开始 → 缴费通道开放
├─ 关键动作: 确保客户知晓到期日
└─ 系统操作: 标记"最后提醒完成"

T-0天 (到期日)
├─ 触达方式: 电话 (未缴费客户) + 短信 (全部客户)
├─ 话术策略: 到期提醒 → 宽限期开始计算 → 60天缓冲说明 → 失效后果警示
├─ 关键动作: 正式通知进入宽限期、明确时间节点
├─ KCP: 到期日必须完成未缴费客户的电话触达
└─ 系统操作: 标记"进入宽限期"、启动宽限期管理流程

【宽限期阶段 - 催缴回收期】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

T+1至T+15天 (宽限期早期)
├─ 触达方式: 短信 (每周2次) + 电话 (A级客户)
├─ 话术策略: 温和提醒 → 宽限期概念重申 → 缴费便利性强调
├─ 关键动作: 保持联系、了解延迟原因
└─ 系统操作: 每周更新跟进记录

T+16至T+30天 (宽限期中期)
├─ 触达方式: 电话 (每周1次) + 短信
├─ 话术策略: 时间进度提醒 → 失效风险预警 → 协助方案提供
├─ 关键动作: 加强紧迫感、提供缴费协助
├─ KCP: T+30时必须评估客户状态并调整策略
└─ 系统操作: 标记"宽限期中期"、升级跟进频率

T+31至T+45天 (宽限期后期)
├─ 触达方式: 电话 (每3天1次) + 短信 (每日)
├─ 话术策略: 紧急提醒 → 失效后果详细说明 → 即时缴费通道
├─ 关键动作: 高频触达、代理人协同介入
├─ KCP: T+45时必须启动代理人协同或上门拜访
└─ 系统操作: 标记"紧急催缴"、通知主管

T+46至T+58天 (失效前最后阶段)
├─ 触达方式: 电话 (每日) + 短信 (每日) + 代理人上门
├─ 话术策略: 最后通牒 → 失效严重后果 → 即时解决方案
├─ 关键动作: 最高优先级处理、主管介入
├─ KCP: T+58前必须完成最后挽留尝试
└─ 系统操作: 标记"最后预警"、升级至主管

T+59至T+60天 (失效前48小时)
├─ 触达方式: 电话 (最高优先级) + 短信 + 所有渠道
├─ 话术策略: 48小时预警 → 保障终止说明 → 复效困难预告
├─ 关键动作: 最后努力、记录所有尝试
├─ KCP: 失效前48小时必须完成最终触达并记录
└─ 系统操作: 标记"失效预警"、准备失效处理

【失效后阶段 - 复效挽回期】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

T+61天 (失效当日)
├─ 触达方式: 电话 + 正式通知函
├─ 话术策略: 正式通知失效 → 失效后果说明 → 复效权利告知
├─ 关键动作: 正式确认失效、启动复效流程
├─ KCP: 失效后24小时内必须完成正式通知
└─ 系统操作: 标记"已失效"、启动复效流程

T+61至T+90天 (复效黄金期)
├─ 触达方式: 电话 (每周1次) + 短信
├─ 话术策略: 复效引导 → 保障空窗风险 → 复效条件说明
├─ 关键动作: 积极挽回、协助复效申请
└─ 系统操作: 记录复效跟进、标记复效意向

T+90天至2年 (复效有效期)
├─ 触达方式: 定期关怀 (每月1次)
├─ 话术策略: 关系维护 → 复效提醒 → 新产品介绍
├─ 关键动作: 保持联系、等待复效时机
└─ 系统操作: 定期更新记录、标记长期跟进

2年后 (永久失效)
├─ 处理: 终止跟进、归档管理
└─ 系统操作: 标记"永久失效"、关闭续期流程
```

## Objective

| 服务目标 | 投诉率 | ≤0.8% | 月度 |

| 精准目标 | A级客户续保率 | ≥98% | 月度 |
| 精准目标 | C级客户挽回率 | ≥40% | 季度 |

### 3.3 角色职责矩阵

| 角色 | 核心职责 | 协作场景 | 响应时效 | 升级条件 |
|-----|---------|---------|---------|---------|
| **客户** | 接收提醒、确认续保意向、完成缴费 | 全流程参与 | - | 投诉/特殊需求 |
| **续期专员** | 数据筛选、提醒触达、异议处理、缴费协助、宽限期管理 | 主导续期流程 | 工作日8小时内 | 复杂异议/高价值客户 |
| **续期主管** | 团队管理、疑难处理、质量监控、决策审批 | 升级处理/审批 | 2小时内 | 重大投诉/政策例外 |

客户表态: "我在考虑" / "想对比下" / "再想想"
处理流程:
├── 1. 了解犹豫原因 (开放式提问)
│   话术: "理解您想慎重考虑。能分享一下您主要在对比哪些方面吗？"
├── 2. 分类处理
│   ├── 价格因素 → 转入异议处理-价格类
│   ├── 保障内容 → 转入异议处理-保障类
│   └── 竞品对比 → 转入场景7: 竞品对比
├── 3. 安排产品专家对接 (如需要)
│   话术: "我请我们的产品专家为您做一个详细分析，帮您做更明智的选择。"
├── 4. 提供产品对比资料
│   动作: 发送客观的产品对比表
├── 5. 保持适度跟进频率 (3天1次)
│   话术: "我3天后再联系您，这期间有任何问题随时找我。"
└── 系统操作: 标记"犹豫对比" + 记录具体原因

【场景3: 经济困难】

处理流程:
├── 1. 表达理解与共情
│   话术: "理解您现在的困难，经济压力确实不小。让我们看看有什么解决办法。"
├── 2. 提供解决方案 (按优先级排序)
│   ├── 方案A: 宽限期利用
│   │   话术: "您有60天宽限期，可以先缓一缓，这期间保障仍然有效。"
│   ├── 方案B: 保单贷款
│   │   话术: "您的保单有现金价值，可以申请贷款来缴费，利率比较优惠。"
│   ├── 方案C: 减额交清
│   │   话术: "可以用已缴保费折算，降低保额但保障继续，以后不用再缴费。"
│   ├── 方案D: 减保
│   │   话术: "降低保额，相应减少保费，保留核心保障。"
│   └── 方案E: 分期缴费
│       话术: "申请将年缴改为月缴或季缴，减轻每次缴费压力。"
├── 3. 制定缴费计划
│   话术: "根据您的情况，我建议...您看这样可以吗？"
└── 系统操作: 标记"经济困难" + 记录解决方案

【场景4: 信息变更】
客户表态: "我换电话了" / "搬家了" / "银行卡换了"
处理流程:
├── 1. 确认变更内容
│   话术: "好的，我帮您更新。新的信息是？"
├── 2. 分类处理
│   ├── 联系方式变更
│   │   ├── 收集新信息
│   │   ├── 验证有效性 (如发送验证码)
│   │   └── 系统更新
│   ├── 地址变更
│   │   ├── 收集新地址
│   │   └── 系统更新 + 保单寄送调整
│   └── 缴费账户变更
│       ├── 收集新账户信息
│       ├── 验证账户有效性
│       ├── 签署变更申请
│       └── 系统更新 + 代扣协议变更
├── 3. 确认更新完成
│   话术: "信息已更新，新的联系方式是XXX，对吗？"
└── 系统操作: 更新客户信息 + 记录变更历史

【场景5: 宽限期催缴】
客户状态: 已进入宽限期，尚未缴费
处理流程:
├── 1. 告知当前状态
│   话术: "您的保单已于X月X日到期，现在处于宽限期第X天，还有Y天宽限期。"
├── 2. 强调宽限期规则
│   话术: "宽限期共60天，期间保障仍然有效，但请务必在X月X日前缴费，否则保单失效。"

### 附录C: 续期率计算公式

#### C.1 基础续期率

```
整体续保率 = 续保成功保单数 / 应续保保单总数 × 100%

示例:
应续保保单总数 = 1,000份
续保成功保单数 = 930份
整体续保率 = 930 / 1,000 × 100% = 93%
```

#### C.2 分维度续期率

```
A级客户续保率 = A级续保成功数 / A级应续保数 × 100%
B级客户续保率 = B级续保成功数 / B级应续保数 × 100%
C级客户挽回率 = C级续保成功数 / C级应续保数 × 100%

提前续保率 = 到期日前续保数 / 续保成功总数 × 100%
宽限期回收率 = 宽限期内回收数 / 进入宽限期总数 × 100%
复效成功率 = 复效成功数 / 复效申请数 × 100%
```

#### C.3 综合续期率 (加权)

```
综合续期率 = A级续保率 × 40% + B级续保率 × 35% + C级续保率 × 25%

示例:
A级续保率 = 98%，权重40% → 39.2%
B级续保率 = 92%，权重35% → 32.2%
C级续保率 = 75%，权重25% → 18.75%

综合续期率 = 39.2% + 32.2% + 18.75% = 90.15%
```

#### C.4 价值续期率 (按保费)

```
价值续期率 = 续保保费总额 / 应续保保费总额 × 100%

示例:
应续保保费总额 = 10,000,000元
续保保费总额 = 9,500,000元
价值续期率 = 9,500,000 / 10,000,000 × 100% = 95%
```

#### C.5 13个月续期率 (行业标准)

```
13个月续期率 = 第13个月仍有效的保单数 / 首年承保保单数 × 100%

示例:
2023年首年承保保单数 = 500份
2024年第13个月仍有效 = 465份
13个月续期率 = 465 / 500 × 100% = 93%
```

#### C.6 25个月续期率

```
25个月续期率 = 第25个月仍有效的保单数 / 首年承保保单数 × 100%

示例:
2022年首年承保保单数 = 400份
2024年第25个月仍有效 = 360份
25个月续期率 = 360 / 400 × 100% = 90%
```
