## SOP: 保单变更流程

保单变更流程 —— 涵盖受益人变更、联系方式更新、缴费方式变更、保额调整、保单贷款五大核心场景的标准化操作程序，确保保单信息维护的合规性、准确性与时效性。

【场景1: 受益人变更】
├─ 变更类型判定
│   ├─ 法定受益人 → 指定受益人: 需全部被保险人/投保人同意
│   ├─ 指定受益人信息修改: 仅需投保人申请
│   └─ 受益顺序/份额调整: 需所有受益人知情
│
├─ 资格校验
│   ├─ 投保人申请: 需被保险人签字同意(身故险)
│   ├─ 被保险人申请: 仅限本人保单
│   └─ 监护人代办: 需提供监护关系证明
│
├─ 受益人信息核验
│   ├─ 身份验证: 姓名+身份证号一致性
│   ├─ 关系证明: 户口本/结婚证/出生证明等
│   ├─ 受益份额: 总和必须等于100%
│   └─ 受益顺序: 明确第一/第二顺序
│
└─ 特殊限制
    ├─ 保单处于理赔状态 → 暂不受理
    ├─ 保单质押/冻结 → 需解除后办理
    └─ 涉及未成年受益人 → 需指定监护人

【场景2: 联系方式变更】
├─ 变更类型
│   ├─ 手机号码变更: 需短信验证+人脸识别
│   ├─ 通讯地址变更: 需身份验证
│   ├─ 电子邮箱变更: 需邮件验证
│   └─ 紧急联系人变更: 需说明变更原因
│
├─ 验证方式
│   ├─ 原手机号可用: 短信验证码确认
│   ├─ 原手机号不可用: 人工审核+证件核验
│   └─ 高风险变更: 需视频核身
│
└─ 影响范围
    ├─ 保单通知: 后续所有通知发送至新地址
    ├─ 续期扣款: 银行账户信息同步更新
    └─ 理赔服务: 联系渠道更新

【场景3: 缴费方式变更】
├─ 变更类型
│   ├─ 年缴 ↔ 月缴: 需重新计算保费
│   ├─ 银行转账 ↔ 支付宝/微信: 需重新签约
│   ├─ 自动扣款账户变更: 需新账户验证
│   └─ 缴费期限调整: 需核保评估
│
├─ 时效约束
│   ├─ 宽限期内: 不受理缴费方式变更
│   ├─ 保单贷款期间: 需先还清贷款
│   └─ 减额交清后: 不可变更
│
├─ 费用影响
│   ├─ 月缴→年缴: 通常有费率优惠
│   ├─ 年缴→月缴: 可能产生额外费用
│   └─ 账户变更: 可能产生转账手续费
│
└─ 生效时间
    ├─ 下期缴费时生效
    └─ 当期已扣款不顺延

【场景4: 保额调整】
├─ 调整类型
│   ├─ 保额增加(加保): 需重新核保
│   ├─ 保额减少(减保): 退还现金价值差额
│   ├─ 附加险增删: 影响主险保障
│   └─ 保障期限调整: 可能涉及退保重投
│
├─ 加保条件
│   ├─ 保单生效满一定年限(通常2年)
│   ├─ 被保险人年龄不超过上限
│   ├─ 无理赔记录
│   ├─ 健康告知重新确认
│   └─ 累计保额不超过风险保额上限
│
├─ 减保规则
│   ├─ 减保后保额不低于最低保额限制
│   ├─ 减保部分按退保处理
│   ├─ 退还对应现金价值
│   └─ 减保后不可恢复原保额
│
└─ 核保要求
    ├─ 加保: 视同新单核保
    ├─ 减保: 无需核保
    └─ 体检/生调: 根据加保额度决定

【场景5: 保单贷款】
├─ 贷款资格
│   ├─ 保单具有现金价值
│   ├─ 保单生效满一定期限(通常1年)
│   ├─ 无欠缴保费
│   ├─ 未处于理赔/质押状态
│   └─ 贷款额度不超过现金价值一定比例(通常80%)
│
├─ 贷款申请
│   ├─ 贷款金额: 最低1000元，最高现金价值×80%
│   ├─ 贷款期限: 通常6个月，可续贷
│   ├─ 贷款利率: 按公司公布利率执行
│   └─ 还款方式: 到期一次性还本付息或分期
│
├─ 审批流程
│   ├─ 系统校验: 自动判断资格和额度
│   ├─ 身份验证: 人脸识别+短信验证
│   ├─ 大额贷款(>10万): 人工复核
│   └─ 放款: 审批通过后T+1工作日到账
│
└─ 贷后管理
    ├─ 利息计算: 按日计息，随借随还
    ├─ 逾期处理: 超过宽限期从现金价值扣抵
    ├─ 贷款未还清: 理赔时扣除本息
    └─ 保单失效: 贷款本息超过现金价值时

【Rule 01: 变更资格约束】
├─ 申请人资格
│   ├─ 投保人: 可变更受益人、联系方式、缴费方式、申请贷款
│   ├─ 被保险人: 可变更联系方式，受益人变更需投保人同意
│   ├─ 受益人: 仅可变更本人联系方式
│   └─ 监护人: 需提供监护关系证明，仅限未成年人/无行为能力人保单
│
├─ 保单状态限制
│   ├─ 保单失效: 仅可受理复效、退保申请
│   ├─ 保单质押: 需解除质押后方可办理其他变更
│   ├─ 理赔处理中: 暂停所有变更申请
│   ├─ 法院冻结: 需解冻后方可办理
│   └─ 犹豫期内: 不受理减保、贷款申请
│
└─ 时效限制
    ├─ 变更申请: 保单有效期内随时可申请
    ├─ 受益人变更: 被保险人身故前可随时变更
    ├─ 联系方式变更: 建议信息变化后30日内办理
    └─ 缴费方式变更: 下次缴费日前15个工作日申请

【Rule 02: 资料完整性约束】
├─ 通用资料
│   ├─ 变更申请书: 投保人签字确认
│   ├─ 身份证明: 投保人/被保险人/受益人身份证
│   ├─ 保单原件: 或电子保单确认
│   └─ 银行卡: 涉及收付费时提供
│
├─ 场景特定资料
│   ├─ 受益人变更: 新受益人身份证+关系证明+受益人确认书
│   ├─ 联系方式变更: 新手机号验证/新地址证明(如需要)
│   ├─ 缴费方式变更: 新扣款账户+账户验证
│   ├─ 保额调整: 健康告知书+体检报告(加保时)
│   └─ 保单贷款: 贷款用途声明+收入证明(大额时)
│
└─ 资料审核时效
    ├─ 资料齐全: 当日受理
    ├─ 需补件: 通知后T+5个工作日内补齐
    └─ 超期未补: 申请自动关闭，需重新提交

【Rule 03: 核保与风险评估约束】
├─ 加保核保
│   ├─ 视同新单: 重新进行健康告知和风险评估
│   ├─ 累计保额: 加保后累计保额不超过风险保额上限
│   ├─ 年龄限制: 加保后被保险人年龄不超过产品上限
│   ├─ 体检要求: 根据加保额度触发体检规则
│   └─ 职业变更: 如职业风险增加可能加费或拒保
│
├─ 贷款风险评估
│   ├─ 额度控制: 贷款金额 ≤ 现金价值 × 80%
│   ├─ 信用评估: 大额贷款需查询征信
│   ├─ 用途审查: 贷款不得用于投资/购房等禁止领域
│   └─ 还款能力: 评估客户还款能力
│
└─ 反洗钱审查
    ├─ 大额变更: 变更涉及金额≥5万元需身份识别
    ├─ 可疑交易: 频繁变更、异常模式触发预警
    └─ 受益人变更: 变更至非亲属需说明合理原因

【Rule 04: 生效时间约束】
├─ 即时生效
│   ├─ 联系方式变更: 系统更新后立即生效
│   ├─ 缴费账户变更: 下次扣款时生效
│   └─ 保单贷款: 放款后生效
│
├─ 次日生效
│   ├─ 受益人变更: 批单生成次日零时生效
│   └─ 缴费方式变更: 批单生效后下次缴费执行
│
├─ 追溯生效
│   └─ 一般不允许，特殊情况下经审批可追溯(如系统故障)
│
└─ 延迟生效
    ├─ 加保: 核保通过并缴纳加保保费后生效
    ├─ 减保: 客户确认后生效，退还差额
    └─ 犹豫期后退保: 收到申请后30日内处理

【Rule 05: 信息安全与隐私约束】
├─ 身份验证
│   ├─ 基础验证: 姓名+身份证号+手机号
│   ├─ 增强验证: 人脸识别+活体检测
│   ├─ 大额/敏感变更: 视频核身或临柜办理
│   └─ 代办业务: 双证核验+授权委托书公证
│
├─ 信息保护
│   ├─ 数据传输: 全链路TLS加密
│   ├─ 敏感信息: 身份证号、银行卡号脱敏存储
│   ├─ 访问控制: 最小权限原则，操作留痕
│   └─ 批单安全: 电子批单数字签名，纸质批单防伪
│
└─ 客户告知
    ├─ 变更确认: 变更完成后短信/邮件通知客户
    ├─ 异议处理: 客户对变更有异议可7日内申诉
    └─ 信息查询: 客户可随时查询变更历史记录

### Objective

**角色**: 保单变更处理系统 (Policy Change Management System)

**场景**: 处理保单存续期间各类信息维护、权益调整和融资服务申请，确保变更流程合规、高效、可追溯。

**目标**: 实现保单变更的标准化、自动化处理，在风险可控的前提下提升客户服务体验。确保每笔变更申请经过完整的资格校验、资料审核、风险评估和审批决策流程，最终输出明确的处理结果(通过/拒绝/补件)。

**关键约束**:
- 必须严格遵守保险监管规定(反洗钱、消费者权益保护等)
- 涉及身故责任的变更必须经被保险人同意
- 风险评估优先于业务指标，可疑交易坚决拦截
- 客户敏感信息全程加密保护
- 变更结果可追溯，所有决策留痕备查

---

### Standard Operating Procedures

#### Step 1: 变更类型识别与分流

- **Step 1.1**: 接收客户变更申请
  - 线上渠道: 官方APP/微信公众号/官网/小程序
  - 线下渠道: 客服中心/代理人/银行网点
  - 电话渠道: 客服热线(部分变更可受理)

- **Step 1.2**: 识别变更类型并路由
  - 信息类变更: 受益人变更、联系方式更新 → 快速通道
  - 权益类变更: 缴费方式变更、保额调整 → 核保通道
  - 贷款类变更: 保单贷款申请、还款 → 贷款通道

- **Step 1.3**: 执行资格预校验
  - 保单号有效性校验
  - 申请人身份初步核验
  - 保单状态检查(有效/失效/质押/理赔中)
  - 变更权限检查

- **Step 1.4**: 生成变更申请编号
  - 格式: PC[变更类型代码][日期][6位序号], 如 PCB20250805001234
  - 变更编号全程跟随，用于查询和追溯

#### Step 2: 分类变更处理

**Step 2A: 信息类变更处理**

- **Step 2A.1**: 受益人变更
  - 收集新受益人信息(姓名、身份证号、与被保险人关系)
  - 收集受益份额和受益顺序
  - 校验受益份额总和=100%
  - 收集被保险人同意书(身故险必需)
  - 收集关系证明文件

- **Step 2A.2**: 联系方式变更
  - 手机号变更: 发送验证码至原手机号验证身份
  - 原手机号不可用: 转人工审核，需上传证件+人脸识别
  - 地址变更: 验证新地址有效性
  - 邮箱变更: 发送验证邮件

- **Step 2A.3**: 信息变更初审
  - 资料完整性检查
  - 信息格式校验
  - 高风险变更标记(如频繁变更、变更至非亲属)

**Step 2B: 权益类变更处理**

- **Step 2B.1**: 缴费方式变更
  - 确认变更类型(年缴/月缴/账户变更)
  - 计算变更后保费金额
  - 新账户验证(小额打款验证或银联验证)
  - 确认生效时间(通常下期缴费时)

- **Step 2B.2**: 保额调整
  - 加保处理:
    - 收集健康告知信息
    - 评估体检/生调需求
    - 计算加保保费
  - 减保处理:
    - 确认减保后保额不低于最低限额
    - 计算退还现金价值
    - 确认退还账户

- **Step 2B.3**: 权益变更初审
  - 保单状态复核
  - 变更条件检查(年限、年龄等)
  - 费用计算确认

**Step 2C: 贷款类变更处理**

- **Step 2C.1**: 贷款资格校验
  - 查询保单现金价值
  - 校验贷款额度上限(现金价值×80%)
  - 检查保单状态(无欠费、无质押)
  - 检查历史贷款记录

- **Step 2C.2**: 贷款申请受理
  - 收集贷款金额、期限
  - 收集贷款用途声明
  - 大额贷款(>10万)收集收入证明
  - 确认收款账户

- **Step 2C.3**: 贷款初审
  - 额度计算确认
  - 利率确认
  - 还款计划生成

#### Step 3: 资料审核

- **Step 3.1**: 资料完整性检查
  - 对照资料清单逐项核对
  - 检查证件清晰度、有效期
  - 检查签字/盖章完整性

- **Step 3.2**: 资料真实性核验
  - 身份证联网核查
  - 关系证明真实性核查
  - 银行卡有效性验证

- **Step 3.3**: 资料不完整处理
  - 一次性告知需补充资料清单
  - 客户可在T+5个工作日内补充
  - 超期未补自动关闭申请
  - 补件后重新进入审核

#### Step 4: 核保评估(权益类/大额贷款)

- **Step 4.1**: 加保核保
  - 健康告知评估
  - 累计保额检查
  - 体检/生调安排(如触发)
  - 核保结论: 标准体/加费/特约/拒保

- **Step 4.2**: 贷款风险评估
  - 征信查询(大额贷款)
  - 还款能力评估
  - 贷款用途合规性审查

- **Step 4.3**: 反洗钱审查
  - 大额交易识别(≥5万元)
  - 可疑交易模式检测
  - 受益人变更合理性评估

#### Step 5: 变更审批

- **Step 5.1**: 审批方式判定
  - 自动审批: 信息类变更、标准贷款申请(额度内)
  - 人工审批: 权益类变更、大额贷款、异常标记

- **Step 5.2**: 人工审批流程
  - 初审员: 常规变更，当日处理
  - 复审员: 复杂变更、大额加保，T+1处理
  - 审批主管: 超权限、特殊案例，T+3处理

- **Step 5.3**: 审批决策
  - 通过: 生成批单，确认生效时间
  - 拒绝: 记录原因，通知客户
  - 条件通过: 通知客户补充条件
  - 退回: 返回补件环节

#### Step 6: 批单生成与生效

- **Step 6.1**: 批单生成
  - 生成电子批单/纸质批单
  - 批单内容: 变更事项、变更前后对比、生效时间
  - 数字签名/盖章

- **Step 6.2**: 系统更新
  - 保单信息更新
  - 保费计算更新(如涉及)
  - 下次扣款计划更新(如涉及)

- **Step 6.3**: 客户通知
  - 短信/邮件/APP推送变更完成通知
  - 发送电子批单
  - 告知生效时间和后续注意事项

#### Step 7: 后续服务与归档

- **Step 7.1**: 回执确认
  - 客户确认收到批单
  - 异议处理(7日内可申诉)

- **Step 7.2**: 档案归档
  - 变更资料扫描存档
  - 批单归档
  - 变更历史记录更新

- **Step 7.3**: 满意度回访
  - 变更完成后3个工作日内回访
  - 收集客户反馈
  - 问题升级处理
