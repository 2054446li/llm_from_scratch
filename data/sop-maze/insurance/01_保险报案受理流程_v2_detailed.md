## Objective

本SOP旨在规范保险公司报案受理全流程，确保：

1. **时效合规**：符合《保险法》规定的理赔时效要求，车险报案30分钟内响应
2. **服务专业**：统一服务标准，提升客户报案体验
3. **风险可控**：及时识别欺诈风险、道德风险，防范虚假报案
4. **信息完整**：确保报案信息采集完整，为后续理赔奠定基础
5. **紧急响应**：重大案件、人伤案件第一时间启动应急响应机制

**多方对话系统**：
- **客户** ↔ **报案坐席**（报案咨询、信息采集、进度查询）
- **报案坐席** ↔ **查勘调度**（案件派工、紧急协调）
- **报案坐席** ↔ **救援服务商**（救援调度、资源协调）
- **客户** ↔ **查勘员**（现场查勘、资料收集）
- **报案坐席** ↔ **核赔人员**（疑难案件会商、风险预警）

## Standard Operating Procedures

### Step 0: 报案接入

#### 0.1 报案渠道对比

| 渠道 | 定位 | 适用场景 | 响应时效 | 服务时间 |
|------|------|----------|----------|----------|
| 955XX电话 | 主渠道，人工服务 | 复杂案件、紧急报案 | 20秒内接通 | 7×24小时 |
| 官方APP | 自助渠道，便捷高效 | 小额案件、信息明确 | 即时 | 7×24小时 |
| 微信公众号 | 轻量渠道，年轻客群 | 简单咨询、进度查询 | 即时 | 7×24小时 |
| 代理人转报 | 服务延伸，存量客户 | 有专属代理人客户 | 30分钟内 | 工作时间 |
| 柜面报案 | 传统渠道，特殊需求 | 老年人、复杂案件 | 即时 | 工作时间 |
| 第三方平台 | 场景嵌入，生态合作 | 车险出险直连 | 即时 | 7×24小时 |

```

    │            │              │              │
    ▼            ▼              ▼              ▼

  微信入口    紧急程度      咨询/报案        紧急通道

**【话术】报案渠道引导话术**：

```
坐席："您好，XX保险客户服务中心，工号9527为您服务。请问有什么可以帮您？"
客户："我要报案"

坐席："好的，我来为您办理报案。请问您是通过什么渠道了解到我们的？
      如果您是车险出险，可以通过我们的APP一键报案，上传照片即可，更加便捷。
      请问您现在方便使用APP吗？"

客户："我在高速上，不方便用APP"
坐席："理解，高速上安全第一。我先为您记录报案信息，请您在安全位置停车后再补充材料。
      请问事故发生在哪条高速？大概位置是？"
```

**【KCP】渠道分流关键控制点**：
- 必须确认客户所处环境是否安全，特别是高速/危险路段
- 根据案件紧急程度动态调整渠道推荐策略
- 老年人/特殊群体优先引导至人工服务

### Step 1: 身份核验

#### 1.1 身份信息采集

| 核验项 | 采集内容 | 核验方式 | 不通过处理 |
|--------|----------|----------|------------|
| 保单号 | 保单号码或车牌号 | 系统查询 | 引导查找保单 |
| 身份证号 | 18位有效证件 | 公安库比对 | 转人工核实 |
| 手机号 | 报案人联系电话 | 短信验证 | 要求提供其他联系方式 |
| 人脸识别 | 活体检测 | APP人脸比对 | 转线下核实 |
| 关系证明 | 非本人报案时 | 授权委托书 | 要求补充授权 |

##### 1.1.1 非本人报案处理

| 报案人类型 | 所需证明 | 核验方式 | 备注 |
|------------|----------|----------|------|
| 被保险人本人 | 身份证+保单 | 系统核验 | 标准流程 |
| 投保人 | 身份证+保单 | 系统核验 | 需确认被保险人知情 |
| 驾驶员 | 驾驶证+行驶证 | 证件核验 | 车险案件 |
| 家属 | 关系证明+授权书 | 人工审核 | 医疗/寿险案件 |
| 单位经办人 | 工作证明+授权书 | 人工审核 | 团险/企财险 |

**【话术】身份核验话术**：
```
坐席："您好，为了保障您的权益，请先进行身份核验。
      请问您的保单号是多少？或者提供车牌号/身份证号也可以查询。"

客户："我不记得保单号了，车牌号是京A12345"
坐席："好的，我通过车牌号查询。请问是京A12345，车主姓名张三，对吗？"
客户："对的"
坐席："请问报案人是车主本人吗？如果不是，请说明与车主的关系。"
```

**【话术】非本人报案核验话术**：
```
坐席："请问您与被保险人是什么关系？"
客户："我是他儿子"
坐席："好的，请问您有被保险人签署的授权委托书吗？或者您能提供关系证明吗？
      如果是直系亲属，我们可以先受理，后续需要您补充相关材料。"
```

#### 1.2 保单有效性校验

| 校验项 | 校验内容 | 异常处理 | 系统提示 |
|--------|----------|----------|----------|
| 保单状态 | 有效/失效/终止 | 失效保单拒绝报案 | "保单已失效，无法受理" |
| 保险期间 | 出险时间是否在保障期内 | 超期拒绝报案 | "出险时间不在保险期间内" |
| 缴费状态 | 是否欠费/垫交 | 欠费保单特殊处理 | "保单存在欠费，请先补缴" |
| 责任范围 | 出险原因是否属保险责任 | 责任除外案件记录 | "该损失可能不属于保险责任" |
| 免赔额 | 是否达到免赔额标准 | 小额案件引导自助理赔 | "损失金额可能未达免赔额" |

**【KCP】身份核验关键控制点**：
- 必须确认报案人与被保险人的关系，防范冒名报案
- 保单状态异常需明确告知客户，避免后续纠纷
- 非本人报案需留存授权证明，确保理赔权益归属
- 身份证过期需提示客户更新，但不影响本次报案受理

### Step 2: 案件分类

#### 2.1 险种分类矩阵

| 险种类型 | 案件特征 | 处理时效 | 专业要求 |
|----------|----------|----------|----------|
| 机动车辆保险 | 车辆损失/第三者责任 | 30分钟响应 | 车险专业坐席 |
| 意外伤害保险 | 意外身故/伤残/医疗 | 即时响应 | 人伤专业坐席 |
| 健康医疗保险 | 疾病治疗/住院医疗 | 即时响应 | 医疗专业坐席 |
| 人寿保险 | 身故/全残/重疾 | 2小时响应 | 寿险专业坐席 |
| 财产保险 | 财产损失/营业中断 | 1小时响应 | 财产险专业坐席 |
| 责任保险 | 第三者索赔 | 1小时响应 | 责任险专业坐席 |

#### 2.2 案件紧急程度分级

| 等级 | 判定标准 | 响应时效 | 处理要求 |
|------|----------|----------|----------|
| 紧急 | 重大人伤/死亡、重大财产损失、高风险场景 | 5分钟内 | 立即派工，主管介入 |
| 高优先级 | 有人伤、高速/危险路段、老年人/儿童涉案 | 15分钟内 | 优先派工，电话跟进 |
| 标准 | 纯车损、小额财产损、普通医疗 | 30分钟内 | 正常流程处理 |
| 低优先级 | 咨询类、历史案件补充、非紧急报案 | 2小时内 | 批量处理 |

**【KCP】案件分级关键控制点**：
- 人伤案件必须第一时间确认伤情，启动医疗救援
- 高速/危险路段案件优先处理，确保客户安全
- VIP客户/高价值保单自动升级处理优先级

**【多方对话】紧急案件调度**：

```
【高速多车追尾，有人员受伤】
坐席："调度中心，这里是报案中心。京港澳高速K123处发生多车追尾，
      涉及3辆车，有2人受伤，已呼叫120。请立即派查勘员前往。"

调度："收到，事故位置京港澳高速K123，多车事故有人伤。
      最近查勘员小李距离15公里，预计20分钟到达。
      同时通知救援拖车待命。"

坐席："客户张先生，查勘员小李已出发，预计20分钟后到达，电话138XXXX。
      请您在安全位置等待，开启双闪，放置三角警示牌。
      如有人员受伤，请务必先拨打120。"

客户："好的，我已经叫了救护车"
坐席："好的，请您保持电话畅通，查勘员到达前如有紧急情况请拨打110或120。"

| 信息类别 | 采集项目 | 采集要点 | 必填性 |

| | 出险地点 | 详细地址/路段/方向 | 必填 |
| | 事故经过 | 各方行驶方向、碰撞部位 | 必填 |
| | 事故类型 | 追尾/刮擦/碰撞/翻车等 | 必填 |
| 车辆信息 | 车牌号 | 本车及三者车 | 必填 |
| | 车型 | 品牌型号 | 必填 |
| | 驾驶员 | 姓名/驾驶证号/联系方式 | 必填 |
| | 行驶状态 | 行驶中/停放中 | 必填 |
| 损失信息 | 本车损失 | 损失部位/程度/预估金额 | 必填 |
| | 三者损失 | 车辆/财产/人员损失 | 如有则填 |
| | 人员伤亡 | 伤情/就医医院 | 如有则填 |
| 责任信息 | 责任认定 | 全责/主责/同责/无责 | 尽量采集 |
| | 报警情况 | 交警到场/事故认定书 | 尽量采集 |

##### 3.1.1 事故责任预判指引

| 事故场景 | 常见责任划分 | 查勘要点 | 风险提示 |
|----------|--------------|----------|----------|
| 追尾事故 | 后车全责 | 刹车痕迹、碰撞位置 | 注意变道追尾 |
| 变道事故 | 变道方全责 | 车道线位置、车身角度 | 注意同时变道 |
| 路口事故 | 按信号灯/让行规则 | 信号灯状态、让行标志 | 注意无信号灯路口 |
| 倒车事故 | 倒车方全责 | 倒车轨迹、观察条件 | 注意盲区 |
| 停放受损 | 第三方责任 | 停放位置、监控情况 | 注意是否属于保险责任 |
