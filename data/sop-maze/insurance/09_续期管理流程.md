# 保险行业-续期管理流程SOP

## 1. SOP简介

本SOP规范续期专员在保单到期前联系客户、提醒缴费、处理续保、管理宽限期的完整流程，确保续保服务质量与续收效率。

### 3.1 流程目标

| 目标维度 | 具体目标 | 目标值 |
|---------|---------|--------|
| 续收目标 | 整体续保率 | ≥90% |

| 风险目标 | 宽限期回收率 | ≥70% |
| 服务目标 | 投诉率 | ≤1% |

### 3.3 角色职责

| 角色 | 核心职责 | 协作场景 |
|-----|---------|---------|
| **客户** | 接收提醒、确认续保意向、完成缴费 | 全流程参与 |
| **续期专员** | 数据筛选、提醒触达、异议处理、缴费协助、宽限期管理 | 主导续期流程 |
| **代理人** | 客户信息更新、上门协助、关系维护 | 高价值客户/失联客户 |
| **银行系统** | 代扣执行、转账处理、账户验证 | 缴费环节 |
| **核心系统** | 保单状态管理、缴费记录、数据同步 | 全系统支撑 |

## 4. Standard Operating Procedures

### 4.1 续期数据筛选与分级

#### 4.1.1 数据筛选流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         Step1: 续期数据筛选与分级                             │
└─────────────────────────────────────────────────────────────────────────────┘

4.1.1.1 数据提取
├── 输入: 核心系统续期清单
├── 筛选条件:
│   ├── 保单到期日: 未来30-60天内
│   ├── 保单状态: 有效/即将到期
│   └── 排除: 已退保/已理赔终止/已豁免
└── 输出: 原始续期客户清单

4.1.1.2 客户分级
├── A级-高价值客户 (优先级: 最高)
│   ├── 判定标准:
│   │   ├── 年缴保费 ≥ 50,000元
│   │   ├── 保单数量 ≥ 3张
│   │   ├── 家庭总保费 ≥ 100,000元
│   │   └── 历史续保记录: 连续3年准时
│   ├── 服务策略:
│   │   ├── 提前45天启动提醒
│   │   ├── 专属续期专员对接
│   │   ├── 代理人协同服务
│   │   └── 优先处理任何需求
│   └── 资源配置: 1对1专属服务
│
├── B级-普通客户 (优先级: 常规)
│   ├── 判定标准:
│   │   ├── 年缴保费 5,000-50,000元
│   │   ├── 保单数量 1-2张
│   │   └── 历史续保记录: 基本准时
│   ├── 服务策略:
│   │   ├── 提前30天启动提醒
│   │   ├── 标准续期流程
│   │   └── 短信+电话组合触达
│   └── 资源配置: 标准化批量处理
│
└── C级-风险客户 (优先级: 重点关注)
    ├── 判定标准:
    │   ├── 历史逾期记录 ≥ 2次
    │   ├── 上一年度宽限期内缴费
    │   ├── 曾有退保意向或投诉记录
    │   └── 联系方式变更频繁
    ├── 服务策略:
    │   ├── 提前60天启动提醒
    │   ├── 高频次触达 (每周1次)
    │   ├── 代理人深度介入
    │   └── 定制化挽留方案
    └── 资源配置: 重点跟踪+预警机制
```

#### 4.1.2 分级标签管理

| 标签类型 | 标签值 | 说明 |
|---------|-------|------|
| 价值标签 | HIGH_VALUE / NORMAL / RISK | 客户价值分级 |
| 渠道标签 | AGENT / DIRECT / BANK / ONLINE | 投保渠道 |
| 产品标签 | LIFE / HEALTH / SAVING / INVEST | 产品类型 |
| 行为标签 | EARLY_BIRD / REGULAR / DELAYER / RISKY | 缴费习惯 |
| 特殊标签 | VIP / SENIOR / OVERSEAS / SPECIAL_CARE | 特殊关怀 |

### 4.2 续保提醒触达

#### 4.2.1 提醒时间轴

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         Step2: 续保提醒触达                                   │
└─────────────────────────────────────────────────────────────────────────────┘

4.2.1.1 提醒时间规划

T-45天 (仅A级客户)
├── 触达方式: 电话 (专属专员)
├── 话术要点:
│   ├── 身份确认与关怀
│   ├── 提前告知续期时间
│   ├── 确认联系方式有效性
│   └── 了解是否有服务需求
└── 系统操作: 标记"首次触达完成"

T-30天 (全部客户)
├── 触达方式: 短信 + APP推送
├── 内容要素:
│   ├── 保单号后四位
│   ├── 到期日期
│   ├── 应缴金额
│   ├── 缴费方式链接
│   └── 客服热线
└── 系统操作: 发送记录存档

T-15天 (未响应客户)
├── 触达方式: 电话外呼
├── 话术要点:
│   ├── 提醒缴费截止日期
│   ├── 确认续保意向
│   ├── 解答初步疑问
│   └── 预约缴费时间
└── 系统操作: 更新客户意向标签

T-7天 (仍未缴费)
├── 触达方式: 电话 (升级话术)
├── 话术要点:
│   ├── 强调宽限期概念
│   ├── 说明逾期影响
│   ├── 提供缴费协助
│   └── 确认具体缴费计划
└── 系统操作: 标记"紧急跟进"

T-0天 (到期日)
├── 触达方式: 电话 + 短信
├── 话术要点:
│   ├── 最后提醒
│   ├── 宽限期开始计算
│   ├── 60天内可补缴
│   └── 失效后果说明
└── 系统操作: 转入宽限期管理流程
```

#### 4.2.2 触达渠道策略

| 客户类型 | 首选渠道 | 辅助渠道 | 备注 |
|---------|---------|---------|------|
| A级高价值 | 专属电话 | 微信/面谈 | 1对1专属服务 |
| B级普通 | 自动外呼 | 短信+APP | 标准化流程 |
| C级风险 | 人工电话 | 代理人上门 | 高频次跟进 |
| 年轻客户(≤35) | APP推送 | 微信/短信 | 数字化优先 |
| 老年客户(≥60) | 电话 | 代理人转达 | 耐心细致 |
| 海外客户 | 邮件 | 国际长途 | 时差考虑 |

### 4.3 客户响应处理

#### 4.3.1 响应分类处理

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         Step3: 客户响应处理                                   │
└─────────────────────────────────────────────────────────────────────────────┘

4.3.1.1 确认续保 (理想路径)
├── 客户表态: "我续保" / "继续缴费"
├── 处理流程:
│   ├── 感谢客户信任
│   ├── 确认缴费方式偏好
│   ├── 协助完成缴费 或 预约缴费时间
│   ├── 发送缴费指引
│   └── 预约保单检视服务
└── 系统操作: 标记"确认续保" → 进入Step4

4.3.1.2 犹豫对比 (需要引导)
├── 客户表态: "我在考虑" / "想对比下"
├── 处理流程:
│   ├── 了解犹豫原因
│   │   ├── 价格因素 → 转入4.4.1 价格异议处理
│   │   ├── 保障内容 → 转入4.4.2 保障异议处理
│   │   └── 竞品对比 → 转入4.4.4 竞品异议处理
│   ├── 安排产品专家对接 (如需要)
│   ├── 提供产品对比资料
│   ├── 预约深度沟通时间
│   └── 保持适度跟进频率 (3天1次)
└── 系统操作: 标记"犹豫对比" + 记录具体原因

4.3.1.3 拒绝续保 (挽留挑战)
├── 客户表态: "我不续了" / "退保吧"
├── 处理流程:
│   ├── 保持冷静与尊重
│   ├── 了解拒绝原因 (开放式提问)
│   │   ├── 经济困难 → 转入4.4.3 经济困难处理
│   │   ├── 不满意服务 → 服务补救
│   │   ├── 产品不合适 → 方案调整
│   │   └── 已购竞品 → 转入4.4.4 竞品异议处理
│   ├── 针对性挽留话术
│   ├── 提供替代方案 (如减额交清、保单贷款)
│   ├── 如坚持退保 → 告知退保损失
│   └── 保持长期关系 (定期关怀)
└── 系统操作: 标记"拒绝续保" + 记录原因 → 转入挽留流程

4.3.1.4 失联客户 (特殊处理)
├── 判定标准: 3次以上联系无响应
├── 处理流程:
│   ├── 多渠道尝试
│   │   ├── 原电话 (不同时段)
│   │   ├── 备用电话
│   │   ├── 短信/邮件
│   │   └── 微信/APP消息
│   ├── 代理人协助
│   │   ├── 提供客户最新信息
│   │   ├── 上门拜访 (如允许)
│   │   └── 转达续期提醒
│   ├── 紧急联系人
│   │   ├── 联系预留紧急联系人
│   │   └── 请其转达或提供新联系方式
│   └── 上门拜访 (高价值客户)
└── 系统操作: 标记"失联" → 启动失联客户专项流程
```

### 4.4 异议处理话术

#### 4.4.1 价格异议

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      异议处理: 价格贵                                         │
└─────────────────────────────────────────────────────────────────────────────┘

客户说: "保费太贵了，我不想交了"

应对流程:
├── 4.4.1.1 认同理解
│   └── "我理解您的考虑，保险确实是一项长期支出"
│
├── 4.4.1.2 价值重申
│   ├── 保障价值: "这份保单为您提供XX万保障，万一发生风险..."
│   ├── 已缴保费: "您已经缴费X年，退保会有较大损失..."
│   └── 成本对比: "如果重新投保，保费会因年龄增长而提高..."
│
├── 4.4.1.3 方案调整 (如需要)
│   ├── 减额交清: "可以用保单现金价值作为一次性保费，保额相应减少"
│   ├── 保单贷款: "可以贷款缴纳保费，缓解短期压力"
│   ├── 缓交申请: "某些情况下可以申请缓交，保障继续有效"
│   └── 减保: "降低保额，相应减少保费"
│
└── 4.4.1.4 促成决策
    └── "您看哪种方式更适合您现在的状况？"
```

#### 4.4.2 保障异议

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      异议处理: 保障够了                                       │
└─────────────────────────────────────────────────────────────────────────────┘

客户说: "我觉得保障已经够了，不需要再续保"

应对流程:
├── 4.4.2.1 保障检视
│   ├── "让我们回顾一下您目前的保障..."
│   ├── 分析现有保障缺口
│   └── 结合客户家庭变化 (新增成员、收入变化等)
│
├── 4.4.2.2 需求唤醒
│   ├── 风险案例分享 (适度)
│   ├── 医疗费用上涨趋势
│   └── 家庭责任变化
│
├── 4.4.2.3 保单升级
│   ├── 介绍可附加险种
│   ├── 推荐保障升级方案
│   └── 老客户专属优惠
│
└── 4.4.2.4 尊重决定
    └── 如客户坚持 → 记录原因 → 保持联系 → 定期回访
```

#### 4.4.3 经济困难

```
┌─────────────────────────────────────────────────────────────────────────────┐
```

## 5. Rule约束

### 5.1 续期规则体系

| 规则编号 | 规则名称 | 规则内容 | 违规后果 |
|---------|---------|---------|---------|
| **R1** | 提醒时效规则 | 必须在保单到期前至少提醒3次 (T-30/T-15/T-7) | 视为服务瑕疵 |
| **R2** | 宽限期计算规则 | 宽限期为60天，从到期日次日零时起算 | 计算错误导致客户损失需赔偿 |
| **R3** | 失效条件规则 | 宽限期结束未缴费即失效，保障终止 | 需准确告知客户 |
| **R4** | 复效期限规则 | 失效后2年内可申请复效，超期永久失效 | 错过复效期客户权益受损 |
| **R5** | 服务规范规则 | 禁止误导销售、禁止诋毁同业、禁止代签名 | 违规处罚/法律责任 |
| **R6** | 信息保密规则 | 客户信息严格保密，禁止泄露 | 泄密追责 |
| **R7** | 投诉处理规则 | 投诉必须24小时内响应，3个工作日内处理 | 超时升级处理 |
| **R8** | 代扣授权规则 | 银行代扣必须客户书面授权，禁止未经授权扣款 | 违规扣款需退还并赔偿 |

### 7.2 枚举值定义

```
renewal_result:
├── SUCCESS        - 续保成功
├── PENDING        - 处理中
├── GRACE_PERIOD   - 宽限期中
├── LAPSED         - 已失效
├── DECLINED       - 拒绝续保
├── SURRENDER      - 退保
└── LOST_CONTACT   - 失联

payment_method:
├── ONLINE_APP     - APP缴费
├── WECHAT         - 微信支付
├── ALIPAY         - 支付宝
├── BANK_TRANSFER  - 银行转账
├── CASH           - 现金
├── AUTO_DEBIT     - 银行代扣
└── AGENT_COLLECT  - 代理人代收

payment_status:
├── PENDING        - 待支付
├── PROCESSING     - 处理中
├── SUCCESS        - 支付成功
├── FAILED         - 支付失败
└── REFUNDED       - 已退款

lapse_reason:
├── ECONOMIC_DIFFICULTY  - 经济困难
├── PRODUCT_DISSATISFIED - 产品不满意
├── SERVICE_DISSATISFIED - 服务不满意
├── COMPETITOR_SWITCH    - 转投竞品
├── LOST_CONTACT         - 失联
├── FORGOT               - 遗忘
└── OTHER                - 其他
```

## 8. Evaluation

### 8.1 评估指标体系

| 指标类别 | 指标名称 | 计算公式 | 目标值 | 权重 |
|---------|---------|---------|--------|------|
| **续收指标** | 整体续保率 | 续保成功数 / 应续保总数 | ≥90% | 30% |
| | 提前续保率 | 到期日前续保数 / 续保成功数 | ≥60% | 15% |
| | 宽限期回收率 | 宽限期内回收数 / 进入宽限期数 | ≥70% | 15% |
| **效率指标** | 平均联系次数 | 总联系次数 / 续保成功数 | ≤3次 | 10% |
| | 平均处理时效 | 总处理天数 / 续保成功数 | ≤15天 | 10% |
| **质量指标** | 客户满意度 | 满意评价数 / 回访总数 | ≥4.5/5 | 10% |
| | 投诉率 | 投诉数 / 服务客户数 | ≤1% | 5% |
| **成本指标** | 单客服务成本 | 总成本 / 服务客户数 | 预算内 | 5% |

### 8.2 分级评估标准

| 评估等级 | 综合得分 | 等级描述 | 对应措施 |
|---------|---------|---------|---------|
| A级(优秀) | ≥90分 | 全面达标，表现优异 | 经验推广/奖励 |
| B级(良好) | 80-89分 | 基本达标，略有不足 | 保持并优化 |
| C级(合格) | 70-79分 | 部分达标，需要改进 | 专项培训 |
| D级(待改进) | <70分 | 多指标不达标 | 重点督导/整改 |
