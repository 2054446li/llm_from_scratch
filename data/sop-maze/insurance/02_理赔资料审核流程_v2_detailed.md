## Objective

本SOP旨在规范保险公司理赔资料审核的全流程操作，确保：

1. **合规性**：严格遵守《保险法》规定的理赔时效（30日内核定，10日内赔付）
2. **风控优先**：欺诈案件坚决拦截，涉嫌犯罪的移送公安机关
3. **客户体验**：资料审核一次性告知补件清单，避免客户反复补充
4. **数据安全**：客户隐私严格保密，理赔信息不得泄露
5. **可追溯性**：审核结果可追溯，所有决策留痕备查

**多方对话系统**：
- **客户** ↔ **理赔系统**（提交申请、上传资料、查询进度）
- **客户** ↔ **理赔审核员**（补件沟通、结果说明、申诉处理）
- **审核员** ↔ **医疗机构**（医疗记录核实、病历调取）
- **审核员** ↔ **调查部门**（高风险案件移交、查勘协作）
- **审核员** ↔ **财务部门**（赔付确认、支付执行）

## Standard Operating Procedures

### 1. 理赔受理

#### 1.1 案件登记

##### 1.1.1 受理渠道对比

| 渠道 | 适用场景 | 受理时效 | 资料要求 |
|------|----------|----------|----------|
| 官方APP | 个人客户，资料齐全 | 实时受理 | 电子影像上传 |
| 微信公众号 | 个人客户，便捷提交 | 实时受理 | 电子影像上传 |
| 客服热线 | 紧急报案，后续补资料 | 实时登记 | 口述信息记录 |
| 营业网点 | 复杂案件，需要指导 | 工作日受理 | 纸质资料+电子扫描 |
| 合作机构 | 团体客户，批量受理 | 1-2工作日 | 批量资料包 |

##### 1.1.2 案件登记流程

```
接收申请 ──▶ 身份验证 ──▶ 保单核实 ──▶ 生成案件号 ──▶ 初步分类
    │            │            │              │
    ▼            ▼            ▼              ▼
 多渠道入口   身份证OCR    保单系统查询   CL+险种+日期+序号
```

**【话术】报案受理话术**：

```
客服："您好，欢迎致电XX保险理赔服务热线。请问您是需要报案还是查询理赔进度？"
客户："我要报案，昨天住院了"
客服："好的，请您提供以下信息：1.您的姓名和身份证号；2.保单号；3.出险时间和经过；4.就诊医院名称。我现在为您登记。"
```

#### 1.2 案件分级

##### 1.2.1 案件分级标准

| 级别 | 金额标准 | 处理时效 | 审核权限 |
|------|----------|----------|----------|
| 简易案件 | <5000元 | 2个工作日 | 系统自动 |
| 标准案件 | 5000-10万元 | 5个工作日 | 初审员 |
| 重大案件 | 10-100万元 | 10个工作日 | 复审员 |
| 特大案件 | >100万元 | 30个工作日 | 核赔主管+专案组 |

**【KCP】案件分级关键控制点**：
- 案件分级必须在受理后30分钟内完成
- 重大/特大案件必须当日上报主管
- 案件分级错误导致超时效的，追究责任人

#### 1.3 险种分类

##### 1.3.1 险种类型对比

| 险种 | 核心审核点 | 必备资料 | 特殊要求 |
|------|------------|----------|----------|
| 医疗险 | 就诊真实性、费用合理性 | 病历、发票、清单 | 定点医院核实 |
| 意外险 | 事故真实性、伤残等级 | 事故证明、伤残鉴定 | 事故原因调查 |
| 重疾险 | 诊断符合性、投保前病史 | 病理报告、住院病历 | 投保时健康告知核实 |
| 寿险 | 身故真实性、受益人关系 | 死亡证明、关系证明 | 受益人身份核实 |
| 车险 | 事故责任、损失核定 | 事故认定书、定损单 | 现场查勘 |
| 财产险 | 损失清单、重置价值 | 损失照片、购置凭证 | 现场查勘 |

### 2. 资料完整性审核

#### 2.1 资料清单核对

##### 2.1.1 各险种必备资料清单

**医疗险必备资料**：
| 资料项 | 必填性 | 审核要点 | 常见驳回原因 |
|--------|--------|----------|--------------|
| 理赔申请书 | 必填 | 签字完整，信息准确 | 未签字、信息缺失 |
| 身份证明 | 必填 | 在有效期内，清晰可辨 | 过期、模糊 |
| 医疗费用发票 | 必填 | 财政监制章+医院章 | 印章不清、金额涂改 |
| 费用明细清单 | 必填 | 分项清晰，与发票一致 | 缺失、金额不符 |
| 诊断证明 | 必填 | 医院盖章，诊断明确 | 未盖章、诊断模糊 |
| 出院小结 | 必填（住院） | 医院盖章，出入院时间 | 未盖章、时间矛盾 |
| 银行卡信息 | 必填 | 被保险人/受益人本人账户 | 非本人账户 |
| 授权委托书 | 选填 | 签字+手印，授权明确 | 授权范围不清 |

**【话术】资料清单告知话术**：
```
系统："根据您申请的【医疗险】理赔，请准备以下资料：
1. 理赔申请书（可在线填写）
2. 被保险人身份证正反面
3. 医疗费用原始发票
4. 费用明细清单
5. 诊断证明书
6. 出院小结（如住院）
7. 银行卡信息

请确保所有资料影像清晰可辨，资料齐全后我们将在2个工作日内完成审核。"
```

#### 2.2 影像质量检查

##### 2.2.1 影像质量审核标准

| 检查项 | 合格标准 | 不合格处理 |
|--------|----------|------------|
| 清晰度 | 文字可辨识，无模糊 | 要求重新拍摄 |
| 完整性 | 资料完整，无裁剪 | 要求补充缺失部分 |
| 光线 | 光线均匀，无反光 | 要求调整光线重拍 |
| 角度 | 正面拍摄，无倾斜 | 要求重新拍摄 |
| 印章 | 印章清晰可辨 | 要求补充盖章或说明 |

**【KCP】影像质量关键控制点**：
- 发票必须清晰显示发票代码、发票号码、金额
- 身份证必须清晰显示姓名、身份证号、有效期
- 医院盖章必须完整，不得遮挡关键信息

#### 2.3 资料一致性校验

##### 2.3.1 一致性检查清单

| 检查项 | 检查内容 | 异常处理 |
|--------|----------|----------|
| 姓名一致性 | 申请书/身份证/病历/发票姓名一致 | 要求说明或更正 |
| 日期逻辑性 | 出险时间在保险期间内 | 超出保险期间则拒赔 |
| 金额一致性 | 发票金额=明细清单合计 | 要求说明差异 |
| 诊断一致性 | 病历诊断与申请诊断一致 | 要求医院说明 |
| 医院一致性 | 就诊医院在定点医院列表 | 非定点医院需核实 |

**【多方对话】资料补件沟通**：

```
【系统通知】
系统："您的理赔申请（案件号：CLM20250805001234）资料不完整，需要补充以下资料：
1. 意外事故证明（需工地安全部门或公安机关出具）
2. 完整医疗费用明细清单
补件期限：5个自然日"

【客户咨询】
客户："事故证明怎么开？"
客服："您好，事故证明需要由您出险时所在工地的安全管理部门出具，或由当地公安机关出具。证明内容需包含：事故时间、地点、原因、经过、伤情。如有疑问，可联系工地安全员或拨打110咨询。"

【客户补件后】
客户："事故证明已经开好了，我上传了"
客服："收到，我们正在审核您补充的资料..."
```

### 3. 医疗记录核实

#### 3.1 核实方式对比

| 核实方式 | 适用场景 | 时效 | 成本 |
|----------|----------|------|------|
| 系统直联 | 定点医院，有接口 | 实时 | 低 |
| 电话核实 | 一般案件，快速核实 | 1-2工作日 | 低 |
| 函件核实 | 需要书面回复 | 5-10工作日 | 中 |
| 实地核实 | 高风险案件，需详细病历 | 3-7工作日 | 高 |

#### 3.2 核实内容清单

| 核实项 | 核实目的 | 异常标记 |
|--------|----------|----------|
| 就诊真实性 | 确认真实就诊，非虚构 | 无就诊记录→欺诈嫌疑 |
| 就诊时间 | 确认与出险时间匹配 | 时间矛盾→欺诈嫌疑 |
| 诊断一致性 | 确认诊断与申请一致 | 诊断不符→要求说明 |
| 治疗合理性 | 确认治疗方案符合规范 | 过度医疗→费用剔除 |
| 费用合理性 | 确认收费与治疗匹配 | 费用异常→专项审核 |
| 既往病史 | 确认投保前是否患病 | 未如实告知→拒赔 |

**【话术】医疗核实话术**：
```
审核员："您好，我是XX保险公司理赔审核员，案件号CLM20250805001234。需要核实一位被保险人的就诊记录，请转病案室。"
医院："请提供患者信息"
审核员："患者姓名张三，身份证号110101199001011234，就诊时间2025年7月15日，就诊科室普外科。"
```

### 4. 事故查勘与损失评估

#### 4.1 查勘触发条件

| 触发条件 | 说明 | 查勘方式 |
|----------|------|----------|
| 重大案件 | 金额>10万元 | 现场查勘 |
| 事故原因不明 | 客户描述与资料不符 | 现场+走访 |
| 高风险评分 | 系统评分>60分 | 视情况定 |
| 短期多次出险 | 30天内多次出险 | 重点查勘 |
| 客户投诉 | 对理赔有异议 | 复核查勘 |

#### 4.2 损失评估方法

**医疗险损失评估**：
```
赔付金额 = (医保范围内费用 × 赔付比例) - 免赔额 + 住院津贴
```

| 评估项 | 计算方法 | 说明 |
|--------|----------|------|
| 医保范围内费用 | 按当地医保目录核定 | 剔除自费项目 |
| 赔付比例 | 按保单约定（80%/90%/100%） | 不同产品不同 |
| 免赔额 | 年度/次免赔额 | 按保单约定扣除 |
| 住院津贴 | 住院天数 × 日津贴标准 | 有上限限制 |

**【KCP】损失评估关键控制点**：
- 医保范围外费用必须有明确剔除依据
- 免赔额扣除必须符合保单约定
- 赔付金额不得超过保险金额

### 5. 欺诈识别与风险控制

#### 5.1 风险评分模型

| 评分维度 | 权重 | 评分因素 |
|----------|------|----------|
| 客户画像 | 20% | 年龄、职业、地域、历史理赔 |
| 出险特征 | 25% | 时间、地点、频次、金额 |
| 资料特征 | 25% | 发票真伪、印章一致性、笔迹 |
| 行为特征 | 15% | 申请时机、沟通态度、信息一致性 |
| 关联风险 | 15% | 与已知欺诈案件关联度 |

#### 5.2 风险等级划分

| 风险等级 | 分数区间 | 处理方式 | 审核权限 |
|----------|----------|----------|----------|
| 低风险 | 0-30分 | 自动通过 | 系统 |
| 中风险 | 31-60分 | 人工复核 | 初审员 |
| 高风险 | 61-80分 | 转调查部门 | 调查员 |
| 极高风险 | 81-100分 | 反欺诈调查 | 专案组 |

**【话术】欺诈调查话术**：
```
调查员："您好，我是XX保险公司调查员，需要就您的理赔案件进行核实。请问您2025年7月15日在协和医院的就诊是谁陪同的？当时的主治医生姓名您还记得吗？"
客户："是我爱人陪同的，医生姓李"
调查员："好的，我们会进一步核实。感谢您的配合。"
```

### 6. 核赔决策

| 核赔方式 | 适用条件 | 时效 | 权限 |
|----------|----------|------|------|
| 自动核赔 | 低风险+资料齐全+金额<5000元 | 实时 | 系统 |
| 初审 | 5万元以下 | 3工作日 | 初审员 |
| 复审 | 5-50万元 | 5工作日 | 复审员 |
| 主管审核 | 50万元以上 | 7工作日 | 核赔主管 |

#### 6.2 赔付决策类型

| 决策类型 | 适用条件 | 客户通知 | 时效要求 |
|----------|----------|----------|----------|
| 全额赔付 | 属于保险责任，资料齐全 | 赔付通知书 | 3日内支付 |
| 部分赔付 | 部分属于保险责任 | 部分赔付说明 | 客户确认后3日 |
| 协议赔付 | 责任边界模糊，协商一致 | 协议赔付方案 | 签署后3日 |
| 拒赔 | 不属于保险责任/欺诈证实 | 拒赔通知书 | 3日内发出 |

**【话术】赔付通知话术**：
```
系统："您的理赔申请已审核完成。赔付决策：全额赔付。核定赔付金额：25,800元。赔付明细：医疗费用23,300元，住院津贴2,500元。赔款将于3个工作日内转入您尾号1234的银行卡。"
```

**【话术】拒赔通知话术**：
```
系统："您的理赔申请已审核完成。赔付决策：拒赔。拒赔原因：投保时未如实告知重要事实（投保前已患甲状腺结节）。法律依据：《保险法》第十六条。如您有异议，可在30日内提出申诉，或在2年内向法院提起诉讼。"
```

## Rule 层（系统约束与拦截规则）

### R1. 合规性拦截规则

| 规则ID | 规则名称 | 触发条件 | 拦截动作 | 提示信息 |
|--------|----------|----------|----------|----------|
| R1.1 | 超时效拦截 | 收到完整理赔资料后>30日未核定 | 强制升级至主管 | "案件即将超法定时效，请立即处理" |

   - 投保时回答："否"
