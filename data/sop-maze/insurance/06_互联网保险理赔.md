# 互联网保险理赔 SOP 详细版

> **文档版本**: v1.0 详细版
> **适用场景**: 互联网保险理赔全流程处理
> **更新日期**: 2026年8月

---

## Objective

1. **用户体验目标**: 实现理赔全流程线上化，用户报案到获赔平均时效 ≤ 24小时（闪赔场景 ≤ 30分钟）
2. **风控目标**: 通过AI/OCR智能识别与反欺诈系统，欺诈案件识别率 ≥ 95%
3. **运营效率目标**: 智能审核覆盖率 ≥ 80%，人工审核工作量降低 60%
4. **合规目标**: 确保理赔流程符合《保险法》及银保监会相关规定

---

#### 1.1 用户端操作流程

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 打开保险公司APP/小程序，进入「理赔服务」 | 支持微信、支付宝、官方APP多渠道入口 | 未实名认证用户需先完成认证 |
| 2 | 选择对应险种（医疗/意外/车险/财产等） | 系统根据用户保单自动推荐可理赔险种 | **KCP**: 校验保单是否在有效期内 |

| 5 | 确认报案信息，电子签名提交 | 系统自动生成报案号 | 提交后发送短信/微信通知 |

#### 2.2 材料类型与识别规则

| 材料类型 | 识别内容 | 关键字段 | 真伪核验规则 |
|----------|----------|----------|--------------|
| 医疗发票 | 发票代码、号码、金额、日期、医院 | 发票代码10位/12位、发票号码8位、金额（大小写一致）、医院公章 | 对接税务局发票查验平台 |
| 费用明细清单 | 项目编码、项目名称、单价、数量、金额 | 医保编码合规性、项目与发票一致性 | 与发票总金额交叉核验 |
| 病历/诊断证明 | 就诊时间、主诉、诊断结果、医生签章 | 时间逻辑性、诊断与险种匹配度 | 医院HIS系统对接核验 |
| 出院小结 | 入院时间、出院时间、诊断、治疗经过 | 住院天数计算、诊断一致性 | 与发票日期交叉核验 |
| 事故证明 | 事故时间、地点、责任认定 | 交警/派出所公章、时间逻辑性 | 公安系统对接核验（试点） |
| 身份证明 | 姓名、身份证号、证件有效期 | 证件OCR识别、人脸识别比对 | 公安身份核验接口 |

#### 2.4 OCR识别异常处理

| 异常情况 | 处理流程 | Rule层约束 | 话术示例 |
|----------|----------|------------|----------|
| 图像模糊/不清晰 | 系统提示重新拍摄，提供拍摄指引 | 清晰度评分 < 0.6 必须重拍 | 「图像清晰度不足，请对准材料、光线充足处重新拍摄」 |
| 材料类型无法识别 | 转人工分类，或让用户手动选择 | 置信度 < 0.5 转人工 | 「无法自动识别材料类型，请手动选择或联系客服」 |
| 关键字段缺失 | 标记缺失字段，提示用户补充 | 必传字段缺失无法进入下一环节 | 「发票号码识别失败，请补充拍摄或手动输入」 |
| 发票真伪存疑 | 触发人工复核，暂停自动审核 | 发票查验返回「不一致」或「不存在」 | 「发票信息核验中，请耐心等待」 |
| 多页材料缺页 | 检测页码连续性，提示补传 | 病历/清单等需完整性校验 | 「检测到材料缺页（第3页/共5页），请补充上传」 |

#### 3.2 快赔通道规则

| 快赔条件 | 规则说明 | 时效承诺 |
|----------|----------|----------|
| 险种范围 | 医疗险（门诊/住院）、小额意外险（≤5000元） | - |
| 金额限制 | 单张发票金额 ≤ 10000元，年度累计 ≤ 50000元 | - |
| 材料要求 | 发票真伪核验通过 + 病历完整 + 无历史欺诈记录 | - |
| 出险频次 | 同一被保险人30天内报案次数 ≤ 3次 | - |
| 医院范围 | 二级及以上公立医院（白名单库） | - |
| 疾病范围 | 非慢性病、非既往症、非免责条款疾病 | - |

**快赔时效承诺**: 材料齐全后 **30分钟内** 完成审核并赔付到账

#### 3.4 反欺诈规则引擎

| 欺诈类型 | 识别规则 | 风险等级 | 处置方式 |
|----------|----------|----------|----------|
| 虚假发票 | 发票代码/号码格式异常；税务局查验不通过；PS痕迹检测 | 高 | 直接拒赔 + 记录黑名单 |
| 重复索赔 | 同一发票多次报案；同一出险拆分报案 | 高 | 合并案件 + 追回多赔款项 |
| 过度医疗 | 检查/用药与诊断不符；住院天数异常延长 | 中 | 剔除不合理费用后赔付 |
| 带病投保 | 出险时间与投保时间接近（<30天）；既往症未告知 | 中 | 调查核实后处理 |
| 串通骗保 | 同一医院/医生高频出险；关联人员集中报案 | 高 | 启动调查 + 法律手段 |
| 材料造假 | 病历/证明印章异常；医生签名异常 | 高 | 拒赔 + 报警处理 |

#### 3.5 审核结论类型

| 结论类型 | 适用场景 | 处理时效 | 用户通知 |
|----------|----------|----------|----------|
| 正常赔付 | 材料齐全、责任明确、金额无误 | 快赔30分钟/普通1-3日 | 短信+微信通知，附赔付明细 |
| 部分赔付 | 部分费用超出责任范围/存在不合理费用 | 1-3日 | 说明剔除费用及原因 |
| 协议赔付 | 存在争议但为提升体验协商赔付 | 3-5日 | 需用户签署协议确认 |
| 拒赔 | 不在责任范围/欺诈嫌疑/未如实告知 | 1-3日 | 详细说明拒赔理由及依据 |
| 延期处理 | 需补充材料/启动调查 | 视情况 | 说明原因及预计时效 |

## Rule 层约束汇总

| 规则类别 | 规则名称 | 规则内容 | 触发时机 |
|----------|----------|----------|----------|
| 报案时效 | 保单有效性拦截 | 校验保单是否存在、过期、退保 | 报案提交时 |
| 报案时效 | 出险时效拦截 | 校验出险时间是否在保单有效期内 | 报案提交时 |
| 报案时效 | 报案超期拦截 | 校验报案时间是否超过约定时限（48小时-10天） | 报案提交时 |
| 报案时效 | 重复报案拦截 | 校验是否重复报案 | 报案提交时 |
| 材料审核 | 材料完整性拦截 | 必传材料缺失无法进入审核 | 材料上传时 |
| 材料审核 | 清晰度拦截 | 图像清晰度不足需重拍 | OCR识别时 |
| 材料审核 | 发票真伪拦截 | 发票查验不通过触发人工复核 | OCR核验时 |
| 智能审核 | 反欺诈拦截 | 高风险案件转人工/调查 | 智能审核时 |
| 快赔通道 | 快赔资格拦截 | 不满足快赔条件进入普通队列 | 审核分流时 |
| 赔付执行 | 账户有效性拦截 | 账户异常暂停打款 | 赔付执行时 |
| 时效承诺 | 闪赔时效约束 | 快赔案件30分钟内完成 | 审核全流程 |
| 时效承诺 | 普通案件时效 | 普通案件3个工作日内完成 | 审核全流程 |
