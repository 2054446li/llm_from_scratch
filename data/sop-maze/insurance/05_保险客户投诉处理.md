【理赔纠纷分支】

  → 核定保险责任 → 计算赔付金额 → 作出理赔决定

【销售误导分支】
Step 2 → 识别为销售误导 → 进入销售回溯调查
  → 调取双录资料 → 核查销售话术合规性 → 认定误导事实
  → 评估客户损失 → 协商退保/补偿方案 → 追究销售人员责任

【服务质量分支】
Step 2 → 识别为服务质量问题 → 进入服务调查
  → 核查服务记录 → 访谈相关人员 → 认定服务瑕疵
  → 道歉整改 → 补偿安抚 → 内部问责

【保费争议分支】
Step 2 → 识别为保费争议 → 进入保费核查
  → 核查保费计算依据 → 核对费率表 → 审核收费记录
  → 认定争议性质 → 退费/补费处理 → 解释说明

【监管投诉分支】
Step 0 → 识别为监管转办（12378/信访/举报）→ 标记紧急
  → 2小时内联系客户确认受理 → 进入 Step 3C 监管流程
  → 10日内向监管报送进展 → 15日内办结并反馈监管

## Objective

**角色**：保险公司客户投诉处理专员/客服代表/投诉主管/理赔调查员

**场景**：处理客户通过各渠道（电话、网点、信函、网络、监管转办）提交的保险投诉

**目标**：依法依规、高效专业地处理客户投诉，确保15日内办结，维护客户权益和公司声誉

**多方对话系统**：
- **客户** ↔ **客服**（投诉受理、进度告知、结果反馈）
- **客服** ↔ **主管**（重大投诉升级、处理方案审批）
- **客服** ↔ **理赔部门**（理赔纠纷调查、责任认定）
- **客服** ↔ **销售部门**（销售误导核查、销售回溯）
- **客服** ↔ **合规部门**（监管投诉、恶意投诉、法律风险）

## Standard Operating Procedures

### Step 0: 开场/受理

客户通过各渠道发起投诉。

#### 0.1 投诉渠道矩阵

| 渠道 | 接入方式 | 响应时效 | 处理特点 |
|------|----------|----------|----------|
| 客服热线（955XX） | 电话接入 | 即时 | 主要渠道，需先安抚情绪 |
| 营业网点现场 | 柜面接待 | 即时 | 易引发围观，需快速隔离处理 |
| 官方网站/APP | 在线客服/留言 | 即时/24小时内 | 需文字回复，留存完整 |
| 信函/电子邮件 | 邮件接收 | 收到后24小时内 | 正式渠道，需书面回复 |
| 监管转办（12378等） | 监管系统转办 | 2小时内 | 最高优先级，全程留痕 |
| 社交媒体/舆情 | 监测发现 | 发现后1小时内 | 传播快，需公关协同 |

#### 0.2 保险投诉场景识别

| 投诉场景 | 典型表现 | 初步判断要点 | 关联部门 |
|----------|----------|--------------|----------|
| 理赔纠纷 | "保险公司拒赔""理赔太慢""赔得太少" | 询问保单号、出险时间、拒赔原因 | 理赔部 |
| 销售误导 | "当时说保本保息""没说清楚条款""被忽悠了" | 询问购买时间、销售人员、承诺内容 | 销售部/银保部 |
| 服务质量 | "客服态度差""没人理我""电话打不通" | 询问具体服务环节、涉及人员 | 客服部 |
| 保费争议 | "多收我保费""费率不对""自动扣费" | 询问保费金额、缴费方式、争议金额 | 财务部/运营部 |
| 监管投诉 | "我已经投诉到银保监会了" | 确认监管渠道、投诉编号 | 合规部 |

#### 0.3 客户情绪识别与应对

| 情绪等级 | 表现特征 | 应对策略 | 话术要点 |
|----------|----------|----------|----------|
| 平和 | 理性陈述问题 | 正常受理流程 | 标准服务用语 |
| 不满 | 语气急躁、抱怨 | 积极倾听、表达理解 | "理解您的心情" |
| 愤怒 | 大声指责、威胁 | 先安抚情绪、再处理问题 | "非常抱歉让您生气" |
| 激动 | 哭闹、拍桌子 | 立即隔离、主管介入 | "请您冷静，我们一定解决" |
| 危险 | 扬言自杀、暴力 | 启动应急预案、报警 | "您的安全最重要" |

**【话术】开场安抚话术（情绪激动的客户）**：

```
客服："您好，我是XX保险投诉处理专员小王，请问怎么称呼您？"
客户："你们保险公司太不像话了！我要投诉！"
客服："非常理解您的心情，遇到这样的事情确实让人生气。请您先消消气，
      您的问题我一定会认真处理。我是专门负责投诉处理的，
      请您放心，给我几分钟时间了解情况，好吗？"
客户："...好吧"
客服："谢谢您的理解。请问您遇到了什么问题？我会详细记录并帮您解决。"
```

**【KCP】情绪安抚关键控制点**：
- 客户情绪激动时，必须先安抚再询问，不可直接进入询问流程
- 客户大声抱怨时，客服音量应降低20%，语速放慢30%
- 客户使用侮辱性语言时，保持专业态度，不反驳、不对抗
- 客户威胁升级（媒体、监管）时，立即标记紧急并上报

```

      请问您贵姓？"

      请问您能提供一下保单号或身份证号码后四位吗？"

客服："好的，已核实您的身份。张先生，请问有什么可以帮您？"
```

### Step 1: 投诉登记

详细记录客户投诉信息，建立投诉工单。

#### 1.1 登记要素清单

| 要素类别 | 具体内容 | 必填性 | 备注 |
|----------|----------|--------|------|
| 客户信息 | 姓名、联系方式、证件号码 | 必填 | 用于身份核实和回访 |
| 保单信息 | 保单号、险种名称、投保时间 | 选填 | 涉及保单纠纷时必填 |
| 投诉类型 | 理赔/销售/服务/保费/其他 | 必填 | 影响处理部门分配 |
| 投诉事项 | 时间、地点、经过、涉及人员 | 必填 | 事实调查基础 |
| 客户诉求 | 理赔、退保、道歉、解释、赔偿 | 必填 | 处理目标导向 |
| 证据材料 | 保单、病历、发票、录音等 | 选填 | 支持投诉主张 |
| 特殊标记 | 监管投诉、媒体关注、群体事件 | 必填 | 影响处理优先级 |

#### 1.2 保险投诉类型速查表

| 投诉类型 | 常见情形 | 处理要点 | 责任部门 |
|----------|----------|----------|----------|
| 理赔纠纷 | 拒赔、少赔、理赔慢、理赔材料繁琐 | 核查保险责任、审核理赔材料 | 理赔部 |
| 销售误导 | 夸大收益、隐瞒条款、代签名、返佣 | 调取双录、核查销售合规性 | 销售部/合规部 |
| 服务质量 | 客服态度差、响应慢、网点服务差 | 核实服务记录、道歉整改 | 客服部 |
| 保费争议 | 多收保费、费率争议、自动扣费 | 核查保费计算依据、收费记录 | 财务部/运营部 |
| 退保纠纷 | 退保金额争议、退保流程繁琐 | 核算现金价值、解释退保规则 | 运营部 |
| 保全纠纷 | 变更信息困难、保全处理慢 | 核查保全申请记录、处理时效 | 运营部 |

**【话术】信息登记话术**：

```
客服："张先生，为了准确记录您的问题，我需要询问几个细节，请您配合。
      首先，请问您购买的是什么保险产品？"
客户："我去年买了一份重疾险"
客服："好的，请问保单号您方便提供吗？"
客户："保单号是P2023XXXXX"
客服："明白了。请问具体是什么事情让您不满意？"
客户："我前段时间住院了，申请理赔，你们却拒赔了！"
客服："非常抱歉给您带来困扰。请问拒赔的原因是什么？"
客户："说是什么既往症，但我买保险的时候根本不知道！"
客服："明白了。请问您希望保险公司怎么处理这件事？"
客户："我要你们全额理赔！"
客服："明白，您的诉求我已记录。除了理赔，还有其他要求吗？
      比如对处理结果的反馈方式？"
```

#### 1.3 特殊情形识别

**【KCP】重复投诉识别关键控制点**：
- 系统自动识别：同一客户+同一事项+30天内
- 人工识别标志：客户提及"上次投诉""还没解决""又发生了"
- 处理方式：查询历史工单，询问是否有新情况

**【话术】重复投诉处理话术**：

```
客服："张先生，我查到您上个月就同一理赔事项已经提交过投诉，
      当时我们已为您重新审核并作出了理赔决定。
      请问这次是有什么新的情况吗？"
客户："没有新情况，我就是觉得你们赔得太少了！"
客服："理解您的心情。根据记录，您的投诉我们在规定时限内处理完毕，
      核定赔付金额是依据保险合同条款计算的。
      如果您对处理结果不满意，可以申请复议，
      我帮您转接复议专员，可以吗？"
```

**【KCP】恶意投诉识别关键控制点**：
- 识别标准（满足多项）：要求明显不合理赔偿、提供虚假证据、以投诉要挟、被认定为职业投诉人
- 处理方式：正常登记并按流程处理、标记恶意投诉标签、留存证据、不上当不妥协原则

### Step 2: 投诉分级

根据投诉性质、影响程度进行三级分类。

#### 2.1 分级标准矩阵

| 级别 | 判定标准 | 处理时限 | 审批权限 | 响应要求 |
|------|----------|----------|----------|----------|
| 一般投诉 | 普通服务纠纷、小额理赔争议（<5万） | 15日办结 | 客服主管 | 正常流程 |
| 重大投诉 | 涉及大额理赔（5-50万）、销售误导、批量客户 | 15日办结 | 部门负责人 | 主管介入 |
| 紧急投诉 | 群体性事件、监管转办、媒体关注、重大资金损失（>50万） | 15日办结 | 分公司总经理 | 应急预案 |

#### 2.2 保险投诉场景分级标准

| 投诉场景 | 一般投诉 | 重大投诉 | 紧急投诉 |
|----------|----------|----------|----------|
| 理赔纠纷 | 小额理赔争议（<5万） | 大额理赔争议（5-50万） | 巨灾理赔、群体性理赔 |
| 销售误导 | 单一个案、小额退保 | 涉及多名客户、金额较大 | 群体性销售误导、媒体曝光 |
| 服务质量 | 一般服务态度问题 | 多次投诉同一人员 | 引发舆情、监管关注 |
| 保费争议 | 小额保费争议 | 大额保费争议 | 系统性收费问题 |

#### 2.3 升级条件清单

**【KCP】投诉升级关键控制点**：

满足以下任一条件，投诉需升级处理：
- [ ] 客户明确要求升级
- [ ] 涉及金额5万元以上
- [ ] 涉及批量客户（3户以上）
- [ ] 可能引发媒体关注或群体性事件
- [ ] 监管转办或督办
- [ ] 处理人员与投诉事项有利害关系需回避
- [ ] 客户威胁自杀、暴力等极端行为
- [ ] 3次以上重复投诉

**【话术】升级告知话术**：

```
客服："张先生，您反映的问题涉及金额较大（/情况比较复杂），
      为了给您更专业的处理，我将为您升级至我们部门负责人亲自处理。
      负责人会在2小时内与您联系，您看可以吗？"
客户："你们不会是想推诿吧？"
客服："绝对不是推诿。这是我们对重要投诉的特别处理机制，
      由更高级别的人员介入，能够调动更多资源来解决问题。
      这是我的直线电话，如果负责人没有及时联系您，
      您可以直接打给我，我会督办到底。"
```
