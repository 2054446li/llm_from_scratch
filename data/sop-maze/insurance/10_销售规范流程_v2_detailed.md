### 3.3 关键约束

- **适当性原则**：产品风险等级必须匹配客户风险承受能力
- **如实告知义务**：必须充分询问并记录客户健康、财务等告知事项
- **风险提示义务**：必须明确告知免责条款、退保损失等风险
- **双录要求**：销售过程必须全程录音录像
- **禁止行为**：严禁返佣、误导、代签名等违规行为

## Standard Operating Procedures

### Step 1: 客户接触与信任建立

#### 1.1 开场白设计

**【标准开场白话术】**

```
【电话销售场景】
代理人："您好，请问是{客户姓名}先生/女士吗？"
客户："是的，您是？"
代理人："您好，我是{保险公司名称}的保险顾问{代理人姓名}，工号{工号}。
        今天致电是因为我们注意到您之前关注过我们的保障计划，
        想占用您3-5分钟时间，了解一下您目前的保障需求，
        看看我们能否为您提供专业的建议。请问现在方便吗？"

【转介绍场景】
代理人："您好，{客户姓名}先生/女士吗？我是{保险公司名称}的{代理人姓名}。
        {介绍人姓名}是我的老客户，他说您最近正在考虑家庭保障规划，
        特意让我联系您。{介绍人姓名}一直是我们非常信任的客户，
        他推荐的朋友我们也一定会用心服务。"

【活动获客场景】
代理人："您好，{客户姓名}先生/女士，我是昨天在{活动名称}上
        为您讲解保障规划的{代理人姓名}。非常感谢您对我们产品的关注，
        根据您提到的{具体需求}，我特意为您准备了一份详细的方案，
        想找个时间和您详细沟通一下。"
```

**【KCP-1: 身份核实与开场合规】**
- 必须清晰表明保险公司名称、本人姓名、工号
- 必须说明致电目的
- 必须征得客户同意后才继续沟通
- 禁止冒用他人身份或隐瞒真实意图

#### 1.2 自我介绍与信任建立

**【信任建立四步法】**

| 步骤 | 内容 | 话术示例 | 目的 |
|------|------|---------|------|
| **专业背书** | 公司实力+个人资质 | "{保险公司}成立{XX}年，是世界500强企业，服务客户超过{XX}万。我个人从业{XX}年，服务过{XX}个家庭..." | 建立专业形象 |
| **客户见证** | 成功案例/客户评价 | "我上个月为一位和您情况类似的客户设计了方案，他特别满意，还给我介绍了3位朋友..." | 增强可信度 |
| **价值预告** | 沟通价值说明 | "今天和您沟通，我不会强行推销任何产品，主要是想了解您的实际情况，给您一些专业的建议..." | 降低防御心理 |
| **时间确认** | 确认沟通时长 | "大概需要15-20分钟，您看时间方便吗？如果不方便我们可以另约时间。" | 尊重客户时间 |

#### 1.3 关系破冰技巧

**【破冰话题库】**

```
【家庭话题】
"看您资料是{XX}年出生的，孩子应该正在上学吧？现在教育规划确实是个重要话题。"

【职业话题】
"您从事{行业}行业，这个行业这几年发展很不错啊，应该也是家庭的顶梁柱吧？"

【生活话题】
"{城市}最近天气变化挺大的，您和家人要注意身体。健康是家庭最大的财富。"

【共同话题】
"{介绍人}经常跟我提起您，说您特别{优点}，{介绍人}能有您这样的朋友真是幸运。"
```

### Step 2: 需求分析与挖掘

#### 2.1 SPIN提问法

**【SPIN提问框架】**

| 类型 | 定义 | 提问目的 | 示例问题 | 适用场景 |
|------|------|---------|---------|---------|
| **S-情境** | 了解客户现状 | 收集背景信息 | "您目前的家庭结构是怎样的？"<br>"您现在有哪些保障？" | 建立对话基础 |
| **P-问题** | 发现客户痛点 | 识别需求缺口 | "如果发生重大疾病，目前的储蓄够支撑多久？"<br>"孩子教育费用您是怎么规划的？" | 激发需求意识 |
| **I-暗示** | 扩大问题影响 | 强化需求紧迫性 | "如果收入中断，房贷谁来还？"<br>"如果父母生病需要照顾，工作怎么办？" | 推动需求明确 |
| **N-需求效益** | 确认解决方案价值 | 引导客户表达需求 | "如果有份保障能在关键时刻提供{XX}万，您觉得这个价值大吗？" | 锁定需求确认 |

**【SPIN提问话术示例】**

```
【健康保障需求挖掘】
S（情境）："您和家人的社保都有正常缴纳吧？"
P（问题）："如果哪天不幸患上重大疾病，比如癌症，治疗费用动辄几十万，
           社保报销后自付部分您有准备吗？"
I（暗示）："我遇到过客户，生病后不仅花光积蓄，还不得不卖房治病，
           一家人生活都受影响了。您觉得这种情况风险大吗？"
N（需求效益）："如果有份保险能在确诊时一次性赔付{XX}万，
              让您专心治病不用担心钱，您觉得这样的保障重要吗？"

【教育金需求挖掘】
S（情境）："您孩子现在多大了？在哪所学校读书？"
P（问题）："现在好的学校各种费用加起来一年得不少钱吧？
           您有专门为孩子准备教育基金吗？"
I（暗示）："我算过一笔账，从小学到大学，一个孩子的教育费用
           至少要准备{XX}万，如果还要出国留学就更多了。
           这笔钱您是打算怎么筹备的？"
N（需求效益）："如果有一种方式，能让您每年存一点，
              到孩子上大学时保证有{XX}万可用，而且万一您有意外
              这笔钱也能确保到位，您觉得怎么样？"
```

**【KCP-2: 需求识别与记录】**
- 必须全面收集客户家庭、健康、财务、已有保障信息
- 必须使用开放式问题引导客户表达真实需求
- 必须记录客户主要担忧和期望
- 禁止主观臆断客户需求

#### 2.2 家庭财务分析

**【家庭财务分析表】**

| 分析维度 | 收集内容 | 分析目的 |
|---------|---------|---------|
| **家庭结构** | 成员年龄、职业、健康状况 | 识别保障对象和优先级 |
| **收入来源** | 工资、投资、其他收入 | 评估保障额度需求 |
| **支出结构** | 固定支出、可变支出、大额支出 | 确定缴费能力 |
| **资产负债** | 房产、贷款、存款、投资 | 评估财务风险敞口 |
| **已有保障** | 社保、商保、企业福利 | 识别保障缺口 |

**【家庭财务分析话术】**

```
"为了更好地为您设计保障方案，我需要了解一下您的家庭财务情况。
这些信息仅用于方案设计，我们会严格保密。

首先，您家庭的主要收入来源是什么？年收入大概在什么范围？
（根据客户回答选择适当追问）

家里有没有房贷或其他贷款？每月还款大概多少？

除了社保，您和家人目前还有其他的商业保险吗？"
```

#### 2.3 保障缺口计算

**【保障缺口计算公式】**

```
重疾险缺口 = 年收入 × 3-5倍 - 已有重疾保额
寿险缺口 = 年支出 × 10-20倍 + 负债 - 已有寿险保额
意外险缺口 = 年收入 × 10-20倍 - 已有意外保额
医疗险缺口 = 大病医疗自付预估 - 已有医疗保障
教育金缺口 = 教育总费用 - 已准备教育基金
养老金缺口 = 退休后年支出 × 20年 - 社保养老金 - 已准备养老金
```

**【缺口计算演示话术】**

```
"根据您刚才提到的信息，我帮您粗略算一下保障缺口：

您年收入{XX}万，按照行业标准，重疾险保额应该覆盖3-5年收入，
也就是{XX}-{XX}万。您目前有{XX}万重疾保障，缺口大约是{XX}万。

寿险方面，您有房贷{XX}万，家庭年支出{XX}万，
按照10倍年支出计算，需要{XX}万寿险保障，目前缺口{XX}万。

也就是说，您的家庭保障缺口还有{XX}万左右，
这部分风险目前是敞口的。您觉得这些缺口需要补上吗？"
```

### Step 3: 产品方案设计

#### 3.1 方案类型选择

**【四类产品方案】**

| 方案类型 | 适用客户 | 核心卖点 | 产品组合示例 |
|---------|---------|---------|-------------|
| **保障型** | 预算有限、注重基础保障 | 高杠杆、低保费 | 定期寿险+消费型重疾险+医疗险+意外险 |
| **储蓄型** | 有储蓄需求、兼顾保障 | 保本增值、强制储蓄 | 终身寿险+储蓄型重疾险+年金险 |
| **投资型** | 有投资经验、追求收益 | 资产增值、灵活支取 | 分红险+万能险+投连险 |
| **组合型** | 需求多元、预算充足 | 全面保障+资产规划 | 保障型+储蓄型+投资型组合 |

#### 3.2 方案呈现结构

**【方案呈现五步法】**

```
第一步：需求回顾
"根据刚才的沟通，您的主要需求是：
1. 解决重疾保障缺口{XX}万
2. 为孩子准备教育金{XX}万
3. 补充养老金{XX}万

针对这些需求，我为您设计了以下方案："

第二步：方案概述
"这个方案是一个组合型方案，包含三个部分：
- 保障部分：解决您担心的疾病和意外风险
- 储蓄部分：为孩子准备确定的教育金
- 投资部分：让您的资金稳健增值

总保费{XX}元/年，平均每天{XX}元。"

第三步：逐项讲解
[使用FAB法则逐项讲解每个产品]

第四步：方案优势总结
"这个方案有三大优势：
1. 保障全面：重疾、意外、医疗全覆盖
2. 确定给付：教育金和养老金写进合同
3. 灵活可调：未来收入增加可以加保"

第五步：确认反馈
"您觉得这个方案能满足您的需求吗？有没有需要调整的地方？"
```

**【KCP-3: 方案匹配与适当性】**
- 方案必须基于客户需求分析结果设计
- 保费支出建议不超过家庭年收入10-20%
- 必须考虑客户缴费能力，避免过度销售
- 产品风险等级必须匹配客户风险承受能力

### Step 5: 异议处理与促成

#### 5.1 LSCPA异议处理模型

**【LSCPA模型应用】**

| 步骤 | 英文 | 中文 | 操作要点 | 示例话术 |
|------|------|------|---------|---------|
| **L** | Listen | 倾听 | 让客户充分表达，不打断 | "您说..." |
| **S** | Share | 分担 | 表示理解和认同 | "我理解您的顾虑..." |
| **C** | Clarify | 澄清 | 确认异议核心 | "您的意思是...对吗？" |
| **P** | Present | 陈述 | 提供解决方案 | "其实这个问题..." |
| **A** | Ask | 要求 | 请求行动 | "您看这个方案..." |

#### 5.2 常见异议处理话术

**【价格异议】**

```
L（倾听）："您觉得保费有点贵，对吗？"

S（分担）："完全理解，买保险确实是一笔不小的支出。
           我很多客户一开始也有这个顾虑。"

C（澄清）："您主要是觉得每年{XX}元的保费压力大，
           还是担心性价比不高呢？"

P（陈述）："如果是缴费压力，我们可以调整方案，
           比如把年缴改成月缴，每月只要{XX}元，
           相当于每天{XX}元，少喝两杯咖啡就省出来了。
           
           如果是性价比，您看这个对比：
           不买保险：万一患重疾，自付{XX}万，家庭财务崩溃
           买保险：每年{XX}元，确诊获赔{XX}万，杠杆{XX}倍
           这笔账怎么算都值啊。"

A（要求）："您是选择年缴还是月缴呢？"
```

**【需求异议】**

```
L（倾听）："您觉得现在还不需要保险，对吗？"

S（分担）："明白，您现在年轻身体好，感觉风险离自己很远。
           不过说实话，风险这东西，什么时候来谁也说不准。"

C（澄清）："您觉得自己还年轻，暂时不需要考虑保障，是吗？"

P（陈述）："其实保险最划算的就是在健康年轻时买。
           您看，同样的保障，30岁买每年{XX}元，
           40岁买就要{XX}元，贵了{XX}%。
           而且如果这期间身体出现小问题，
           可能还要加费甚至买不了。
           保险是卖给健康人的，等觉得需要时往往买不到了。"

A（要求）："趁现在健康状况好，先把基础保障建立起来，
           您看是按标准方案还是精简方案来？"
```

**【信任异议】**

```
L（倾听）："您对保险公司不太放心，是吗？"

S（分担）："理解您的顾虑，毕竟保险是长期承诺，
           谨慎点是应该的。"

C（澄清）："您主要是担心保险公司会不会倒闭，
           还是担心理赔会不会顺利呢？"

P（陈述）："关于公司安全性，保险公司受银保监会严格监管，
           注册资本最低{2}亿，还要交保证金、责任准备金。
           即使公司有问题，保单也会由其他公司接管，
           您的权益不受影响。
           
           关于理赔，我们的理赔率{97}%，
           平均{2}个工作日到账。
           只要投保时如实告知，符合条款都会顺利赔付。
           这是最近几位客户的理赔案例..."

A（要求）："您是还有什么顾虑，我们可以再聊聊？
           还是觉得方案没问题可以办理了？"
```

#### 5.3 促成技巧

**【六大促成法】**

| 促成方法 | 适用场景 | 话术示例 |
|---------|---------|---------|
| **假设成交法** | 客户已认可方案 | "这份保单的受益人您希望写谁？" |

- 必须确保客户充分理解后再促成
- 禁止代客户做决定或代签名

### Step 6: 投保办理与回访

#### 6.1 投保单填写规范

**【投保单填写要求】**

```
1. 客户信息准确完整
   - 姓名、证件号码与身份证完全一致
   - 联系方式确保可联系到本人
   - 地址详细到门牌号

2. 受益人指定明确
   - 法定或指定必须清晰
   - 指定受益人需写明姓名、关系、份额

3. 健康告知如实完整
   - 必须逐条询问并记录
   - 客户回答"是"的项目需详细记录
   - 不得诱导客户隐瞒或虚假告知

4. 签字确认规范
   - 投保人和被保险人必须本人签字
   - 日期填写实际签署日期
   - 不得代签名或诱导代签名
```

#### 6.2 健康告知询问规范

**【健康告知话术】**

```
"根据保险法规定，投保时需要如实告知健康状况。
我会逐条询问，请您如实回答，这关系到未来理赔是否顺利。

1. 过去两年内是否有过住院或手术？
   [如客户回答有，追问：是什么疾病？住了多久？目前恢复如何？]

2. 是否曾经被诊断患有以下疾病：
   高血压、糖尿病、心脏病、肝炎、肾病、肿瘤等？
   [逐类询问，记录客户回答]

3. 最近一年内是否有体检异常，被医生建议复查或治疗？
   [如有，追问：什么指标异常？复查结果如何？]

4. 目前是否正在服用药物或接受治疗？
   [如有，追问：什么药物？治疗什么疾病？]

以上信息您都如实告知了吗？
如果有遗漏，现在补充还来得及，隐瞒告知可能导致理赔被拒。"
```

**【KCP-6: 双录合规执行】**
- 必须全程录音录像，不得中断
- 必须清晰记录告知说明过程
- 必须确认客户理解并自愿购买
- 双录资料必须完整保存

#### 6.3 双录话术脚本

**【标准双录话术】**

```
"现在开始录音录像。

我是{保险公司}保险代理人{姓名}，工号{工号}。

{客户姓名}先生/女士，请问：
1. 您自愿购买这份保险吗？
2. 您确认已经了解这份保险产品的保障内容和免责条款了吗？
3. 您确认投保单上的健康告知都是如实填写的吗？
4. 您确认了解这份保险的犹豫期和退保可能产生的损失吗？

请您分别回答'是'或'确认'。"
```

#### 6.4 回访要求

**【新单回访规范】**

```
回访时效：保单承保后15天内
回访方式：电话回访（优先）或面访
回访内容：
1. 确认客户身份
2. 确认客户是否收到保险合同
3. 确认客户是否理解保险责任和免责条款
4. 确认投保单和健康告知是否客户本人填写
5. 确认客户是否了解犹豫期权利和退保损失
6. 确认销售过程中是否存在误导行为
7. 解答客户疑问

回访记录：
- 回访时间、方式、结果
- 客户反馈的问题及处理
- 回访人员签字
```

## Evaluation（6个评估维度）

### E1: 销售业绩维度

| 指标 | 计算方式 | 目标值 | 评估标准 |
|------|---------|--------|---------|
| **成交率** | 成交件数/接触客户数 | ≥30% | 优秀≥40%，良好30-40%，待提升<30% |
| **件均保费** | 总保费/成交件数 | 达成指标 | 优秀≥120%，良好100-120%，待提升<100% |
| **转介绍率** | 转介绍客户数/成交客户数 | ≥20% | 优秀≥30%，良好20-30%，待提升<20% |
| **客户增长率** | 新增客户数/期初客户数 | ≥15% | 优秀≥25%，良好15-25%，待提升<15% |

| 指标 | 计算方式 | 目标值 | 评估标准 |
