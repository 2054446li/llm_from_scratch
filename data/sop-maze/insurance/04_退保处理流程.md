## SOP: 保险退保处理流程

保险退保处理流程 —— 从客户提出退保申请到完成退款的全流程标准化操作程序，涵盖犹豫期退保、正常退保、现金价值计算、特殊退保及退款处理等核心场景。

【Step1 退保类型识别决策点】
├─ 犹豫期退保判定
│   ├─ 长期险犹豫期: 签收保单后15个自然日
│   ├─ 短期险犹豫期: 签收保单后3-5个自然日(视产品)
│   ├─ 起算时间: 以保单回执签收日期为准
│   └─ 判定标准: 当前日期 ≤ 签收日期 + 犹豫期天数
│       ├─ 是 → 进入犹豫期退保流程
│       └─ 否 → 进入正常退保流程
│
├─ 特殊退保判定
│   ├─ 触发条件1: 被保险人被确诊全残(1-3级伤残)
│   ├─ 触发条件2: 被保险人被确诊合同约定的重大疾病
│   ├─ 触发条件3: 投保人丧失缴费能力(需证明)
│   ├─ 触发条件4: 保单存在销售误导(需举证)
│   └─ 判定标准: 提供二级及以上医院诊断证明或有效举证材料
│       ├─ 是 → 进入特殊退保流程
│       └─ 否 → 按正常退保处理
│
├─ 退保渠道识别
│   ├─ 线上渠道: APP/官网/小程序/公众号
│   ├─ 线下渠道: 柜面/代理人/银行网点
│   └─ 电话渠道: 客服热线转人工

【Step2 保单状态校验决策点】
├─ 保单有效性检查
│   ├─ 保单状态: 有效/中止/终止/失效
│   │   ├─ 有效 → 继续流程
│   │   ├─ 中止 → 可申请复效或退保(按中止时价值)
│   │   └─ 终止/失效 → 不可退保,告知客户
│   │
│   ├─ 缴费状态检查
│   │   ├─ 正常缴费 → 继续流程
│   │   ├─ 宽限期内 → 继续流程(需补缴欠费)
│   │   └─ 停效超过2年 → 按失效处理
│   │
│   └─ 特殊状态检查
│       ├─ 已发生理赔 → 一般不可退保(除特定条款)
│       ├─ 保单质押中 → 需先解除质押
│       ├─ 被法院冻结 → 不可退保
│       └─ 涉及诉讼 → 需等诉讼结束
│
├─ 可退保性判定
│   ├─ 产品类型
│   │   ├─ 长期寿险/重疾险/年金险 → 可退保
│   │   ├─ 短期意外险 → 按条款约定退保
│   │   ├─ 投连险/万能险 → 按账户价值退保
│   │   └─ 团险 → 需单位出具证明
│   │
│   └─ 退保限制期
│       ├─ 保单生效后犹豫期内 → 全额退保
│       ├─ 保单生效后犹豫期外 → 按现金价值
│       └─ 保单生效未满1年 → 可能扣除较高费用

【Step3 现金价值计算决策点】
├─ 犹豫期退保计算
│   ├─ 应退金额 = 已缴保费 - 工本费(10元)
│   ├─ 无健康告知费用扣除
│   ├─ 无手续费扣除
│   └─ 3-5个工作日内原路退回
│
├─ 正常退保计算
│   ├─ 应退金额 = 保单现金价值(查表)
│   ├─ 现金价值 = 已缴保费 - 初始费用 - 风险保费 - 佣金成本
│   ├─ 退保时间越早,损失比例越高
│   │   第1年退保: 损失约70-90%
│   │   第2年退保: 损失约60-80%
│   │   第3年退保: 损失约50-70%
│   │   第5年后退保: 损失约30-50%
│   └─ 万能险/投连险需计算账户价值
│
├─ 特殊退保计算
│   ├─ 全残退保: 按现金价值 + 可能的全残关爱金
│   ├─ 重疾退保: 按现金价值,已理赔重疾则不可退保
│   ├─ 销售误导退保: 可能协商全额或高比例退保
│   └─ 特殊情况: 由理赔部门与保全部门联合核定

【Step4 退保材料审核决策点】
├─ 必备材料清单
│   ├─ 退保申请书(投保人签字)
│   ├─ 投保人身份证明(原件/复印件)
│   ├─ 保单原件(纸质保单需回收)
│   ├─ 银行账户信息(退款账户)
│   └─ 委托书(如代办需经公证)
│
├─ 特殊情形附加材料
│   ├─ 被保险人身份证明(如投保人被保险人不一致)
│   ├─ 关系证明(如投保人与被保险人为亲属)
│   ├─ 死亡证明+继承人证明(投保人死亡)
│   ├─ 监护证明(未成年人)
│   ├─ 诊断证明(特殊退保)
│   └─ 销售误导举证材料(录音/录像/书面)
│
├─ 材料审核要点
│   ├─ 签字一致性: 与投保时签字样本比对
│   ├─ 身份真实性: 联网核查身份证件
│   ├─ 账户有效性: 验证银行账户状态
│   └─ 委托合法性: 公证委托书真实性

【Step5 退保审批决策点】
├─ 自动审批条件
│   ├─ 犹豫期退保(金额<10万)
│   ├─ 正常退保(金额<5万)
│   ├─ 无异常标记
│   └─ 系统评分>80分
│
├─ 人工审批触发条件
│   ├─ 退保金额≥10万元
│   ├─ 犹豫期后退保且缴费<2年(疑似恶意退保)
│   ├─ 短期内频繁退保(3个月内>2次)
│   ├─ 客户投诉关联退保
│   ├─ 代理人离职后退保
│   └─ 系统识别异常交易模式
│
├─ 审批层级
│   ├─ 5万以下: 保全专员审批
│   ├─ 5-20万: 保全主管审批
│   ├─ 20-50万: 部门经理审批
│   └─ 50万以上: 分管总审批

【Step6 退款处理决策点】
├─ 退款方式
│   ├─ 原路退回: 退回原缴费账户(优先)
│   ├─ 指定账户: 投保人指定同名账户
│   └─ 特殊情况: 法院判决指定账户
│
├─ 退款时效
│   ├─ 犹豫期退保: 3-5个工作日
│   ├─ 正常退保: 7-10个工作日
│   ├─ 特殊退保: 10-15个工作日
│   └─ 大额退保(>50万): 15-20个工作日
│
├─ 退款失败处理
│   ├─ 账户异常 → 联系客户更新账户信息
│   ├─ 户名不符 → 核实身份后重新转账
│   └─ 超时未到账 → 启动资金追踪流程

【时效约束】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 约束项                    │ 规则                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 犹豫期起算                │ 以保单回执签收日期次日零时起算                │
│ 犹豫期天数                │ 长期险15个自然日,短期险3-5个自然日            │

│ 宽限期退保                │ 宽限期内退保需补缴欠缴保费及利息              │
│ 中止期退保                │ 保单中止2年内可申请退保                       │
│ 失效后退保                │ 停效超2年按失效处理,不可退保                  │
│ 材料补交时限              │ 收到补交通知后5个工作日内                     │
│ 审批时限                  │ 普通件3个工作日,复杂件7个工作日               │
│ 退款时限                  │ 审批通过后犹豫期3-5天/正常7-10天              │
│ 投诉关联退保              │ 需在投诉结案后处理                            │

【金额约束】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 约束项                    │ 规则                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 犹豫期退保损失            │ 仅扣除工本费10元,全额退还已缴保费             │
│ 正常退保损失              │ 按现金价值表执行,前期损失比例高               │
│ 最低退保金额              │ 现金价值>10元方可退保                         │
│ 欠费处理                  │ 退保金优先抵扣欠缴保费及利息                  │
│ 贷款处理                  │ 退保金优先偿还保单贷款本息                    │
│ 分红险处理                │ 未领取红利一并退还                            │
│ 万能险处理                │ 扣除退保费用后退还账户价值                    │
│ 投连险处理                │ 按赎回日单位价格计算账户价值                  │
│ 生存金处理                │ 已领取生存金从退保金中扣除                    │
│ 理赔后处理                │ 已发生理赔的保单一般不可退保                  │
└─────────────────────────────────────────────────────────────────────────────┘

【合规约束】
┌─────────────────────────────────────────────────────────────────────────────┐
│ 约束项                    │ 规则                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 投保人权益                │ 只有投保人有权申请退保                        │
│ 被保险人权益              │ 被保险人无直接退保权,但可要求投保人退保       │
│ 受益人权益                │ 受益人无退保权                                │

                              异常处理

【异常1: 保单信息不一致】
- 现象: 客户提供的身份信息与保单记录不符
- 处理: 1)核对证件是否过期或变更 2)要求提供变更证明 3)如为信息录入错误,走信息变更流程后再退保

【异常2: 退款账户异常】
- 现象: 退款时账户已注销或冻结
- 处理: 1)联系客户更新账户信息 2)重新发起退款 3)如多次失败,转人工处理

【异常3: 客户反悔】
- 现象: 退保申请提交后客户要求撤销
- 处理: 1)如未审批通过,可直接撤销 2)如已审批通过但未退款,紧急拦截 3)如已退款,告知无法撤销,可重新投保

【异常4: 代理人阻挠退保】
- 现象: 代理人威胁或诱导客户取消退保
- 处理: 1)记录投诉 2)由客服主管直接跟进 3)如涉及违规,转合规部处理

【异常5: 系统故障】
- 现象: 退保系统无法访问或数据异常
- 处理: 1)启用备用系统 2)手工登记,系统恢复后补录 3)通知客户延迟处理

【现金价值计算公式】
现金价值 = 已缴保费 - 初始费用 - 风险保费 - 佣金成本 + 利息积累

- 犹豫期截止: 2026年8月4日24时
- 8月2日申请: 在犹豫期内
- 8月5日申请: 已过犹豫期
