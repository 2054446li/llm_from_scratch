## SOP: 理赔资料审核流程

理赔资料审核流程 —— 从客户提交理赔申请到最终赔付决策的全流程标准化操作程序，涵盖资料完整性检查、医疗记录核实、事故查勘、损失评估、欺诈识别及最终赔付决策环节。

【Step1 理赔受理决策点】
├─ 案件分类
│   ├─ 医疗险: 门诊/住院/重大疾病/特定疾病
│   ├─ 意外险: 意外身故/意外伤残/意外医疗
│   ├─ 车险: 车辆损失/第三者责任/车上人员/盗抢险
│   ├─ 财产险: 家财险/企业财产险/工程险
│   └─ 寿险: 身故/全残/生存金
│
├─ 案件分级
│   ├─ 简易案件: 金额<5000元, 资料齐全, 无异常 → 快速通道
│   ├─ 标准案件: 金额5000-10万元, 常规审核流程
│   ├─ 重大案件: 金额10-100万元, 资深审核员处理
│   └─ 特大案件: 金额>100万元, 成立专案小组
│
├─ 时效要求
│   ├─ 简易案件: 2个工作日内完成审核
│   ├─ 标准案件: 5个工作日内完成审核
│   ├─ 重大案件: 10个工作日内完成审核
│   └─ 特大案件: 30个工作日内完成审核

【Step2 资料完整性审核决策点】
├─ 医疗险必备资料
│   ├─ 理赔申请书(被保险人/受益人签字)
│   ├─ 被保险人身份证明(身份证/户口本/护照)
│   ├─ 医疗费用原始发票(财政监制章+医院章)
│   ├─ 医疗费用明细清单(药品/检查/治疗分项)
│   ├─ 诊断证明/出院小结(医院盖章)
│   ├─ 病历资料(门诊病历/住院病历)
│   ├─ 银行卡信息(用于接收赔款)
│   └─ 授权委托书(如代办)
│
├─ 意外险必备资料
│   ├─ 理赔申请书
│   ├─ 被保险人/受益人身份证明
│   ├─ 意外事故证明(交通事故认定书/工伤认定等)
│   ├─ 死亡证明/伤残鉴定书(如适用)
│   ├─ 医疗费用发票及清单(如适用)
│   ├─ 受益人关系证明(户口本/结婚证/公证书)
│   └─ 银行卡信息
│
├─ 车险必备资料
│   ├─ 理赔申请书
│   ├─ 驾驶证/行驶证复印件
│   ├─ 交通事故认定书/调解书
│   ├─ 车辆维修发票及清单
│   ├─ 第三者损失证明(如适用)
│   ├─ 施救费用发票(如适用)
│   └─ 银行卡信息
│
├─ 资料完整性检查规则
│   ├─ 必填项缺失 → 一次性告知补件清单
│   ├─ 影像不清晰 → 要求重新拍摄上传
│   ├─ 印章不完整 → 要求补充盖章
│   ├─ 资料冲突 → 标记疑点, 进入深度调查
│   └─ T+5自然日未补件 → 系统自动关闭案件
│       └─ 客户可重新提交, 案件号更新

【Step3 医疗记录核实决策点】
├─ 核实方式
│   ├─ 系统直联: 与定点医院系统对接, 自动核实
│   ├─ 电话核实: 致电医院病案室/主治医生
│   ├─ 函件核实: 发送《医疗记录核实函》
│   └─ 实地核实: 调查员到医院现场调取病历
│
├─ 核实内容
│   ├─ 就诊真实性: 是否真实就诊, 就诊时间是否匹配
│   ├─ 诊断一致性: 诊断结果与理赔申请是否一致
│   ├─ 治疗合理性: 治疗方案是否符合诊疗规范
│   ├─ 费用合理性: 收费项目与治疗方案是否匹配
│   ├─ 既往病史: 是否有投保前已患疾病记录
│   └─ 伤残鉴定: 伤残等级鉴定机构资质及结论
│
├─ 异常标记
│   ├─ 就诊时间与事故时间矛盾 → 欺诈嫌疑
│   ├─ 诊断结果与申请不符 → 要求说明或拒赔
│   ├─ 发现投保前病史 → 核实是否如实告知
│   ├─ 医疗费用明显偏高 → 启动医疗费用审核
│   └─ 医院资质存疑 → 核实医院是否在定点医院列表

【Step4 事故查勘决策点】
├─ 查勘触发条件
│   ├─ 重大案件(金额>10万元)
│   ├─ 事故原因不明或存在疑点
│   ├─ 客户描述与资料不符
│   ├─ 同一被保险人短期内多次出险
│   ├─ 高风险地区/高风险时段出险
│   └─ 系统风险评分超过阈值
│
├─ 查勘方式
│   ├─ 现场查勘: 事故地点实地勘查, 拍照取证
│   ├─ 远程查勘: 视频连线, 指导客户拍摄现场
│   ├─ 走访调查: 询问目击者/邻居/同事
│   └─ 监控调取: 申请调取事故地点监控视频
│
├─ 查勘要点
│   ├─ 事故真实性: 是否真实发生, 是否属于保险责任
│   ├─ 事故原因: 是否属于免责条款(自杀/酒驾/斗殴等)
│   ├─ 损失程度: 实际损失与申报损失是否一致
│   ├─ 责任认定: 事故责任划分是否准确
│   └─ 关联关系: 事故当事人之间是否存在利益关联

【Step5 损失评估决策点】
├─ 医疗险损失评估
│   ├─ 医保范围内费用: 按当地医保目录核定
│   ├─ 自费项目审核: 是否合理必要
│   ├─ 赔付比例: 根据保单约定(80%/90%/100%)
│   ├─ 免赔额扣除: 年度/次免赔额
│   └─ 赔付上限: 年度/次赔付限额
│
├─ 车险损失评估
│   ├─ 车辆损失: 4S店/修理厂定损报价对比
│   ├─ 残值扣除: 更换配件残值计算
│   ├─ 折旧计算: 车辆实际价值与保额对比
│   ├─ 施救费用: 合理性审核
│   └─ 第三者损失: 人伤/财产损失分别核定
│
├─ 财产险损失评估
│   ├─ 损失清单核对: 逐项核实损失物品
│   ├─ 重置价值: 按出险时市场价值计算
│   ├─ 折旧率: 根据使用年限计算
│   ├─  salvage value: 残值扣除
│   └─ 免赔额: 按保单约定扣除

【Step6 欺诈识别决策点】
├─ 欺诈风险评分模型
│   ├─ 客户画像: 年龄/职业/地域/历史理赔记录
│   ├─ 出险特征: 时间/地点/频次/金额分布
│   ├─ 资料特征: 发票真伪/印章一致性/笔迹分析
│   ├─ 关联分析: 与已知欺诈案件关联度
│   └─ 行为特征: 申请时机/沟通态度/信息一致性
│
├─ 风险等级划分
│   ├─ 低风险(0-30分): 自动通过, 进入快速核赔
│   ├─ 中风险(31-60分): 人工复核, 重点审核疑点
│   ├─ 高风险(61-80分): 转调查部门, 深度调查
│   └─ 极高风险(81-100分): 疑似欺诈, 启动反欺诈调查
│
├─ 常见欺诈类型
│   ├─ 虚假出险: 编造保险事故
│   ├─ 夸大损失: 虚报损失金额
│   ├─ 重复索赔: 同一事故向多家公司索赔
│   ├─ 带病投保: 投保前已患病, 投保后短期内出险
│   ├─ 冒名顶替: 非被保险人出险
│   ├─ 伪造资料: 虚假发票/病历/事故证明
│   └─ 保险诈骗团伙: 有组织、有预谋的骗保行为

【Step7 核赔决策点】
├─ 自动核赔
│   ├─ 触发条件: 低风险+资料齐全+金额<5000元
│   ├─ 处理时效: 实时决策
│   └─ 决策结果: 通过(自动计算赔付金额)
│
├─ 人工核赔
│   ├─ 初审员: 5万元以下, 3个工作日内
│   ├─ 复审员: 5-50万元, 5个工作日内
│   ├─ 核赔主管: 50万元以上, 7个工作日内
│   └─ 决策动作: 全额赔付/部分赔付/拒赔/协议赔付
│
├─ 协议赔付
│   ├─ 适用场景: 责任难以界定/存在争议/快速结案
│   ├─ 协议金额: 按实际损失的60-90%协商
│   ├─ 协议流程: 双方签署《赔付协议书》
│   └─ 法律效力: 协议签署后不得就同一事故再次索赔

【Step8 赔付决策点】
├─ 全额赔付
│   ├─ 条件: 属于保险责任+资料齐全+金额核定无误
│   ├─ 时效: 决策后3个工作日内支付
│   └─ 通知: 短信/APP推送赔付结果
│
├─ 部分赔付
│   ├─ 条件: 部分属于保险责任/部分费用不合理
│   ├─ 说明: 详细说明扣减项目及原因
│   ├─ 客户确认: 客户同意后进行赔付
│   └─ 争议处理: 客户不同意可协商或申诉
│
├─ 协议赔付
│   ├─ 条件: 责任边界模糊/双方协商一致
│   ├─ 金额: 协商确定, 通常低于全额
│   ├─ 协议签署: 双方签字盖章确认
│   └─ 结案: 协议赔付后案件关闭
│
├─ 拒赔
│   ├─ 条件: 不属于保险责任/免责条款/欺诈嫌疑证实
│   ├─ 通知: 书面《拒赔通知书》, 说明理由及依据
│   ├─ 申诉: 客户可在30日内提出申诉
│   └─ 诉讼: 客户可在2年内向法院起诉

【Step9 赔付执行决策点】
├─ 支付方式
│   ├─ 银行转账: 默认方式, 转入被保险人/受益人账户
│   ├─ 支票支付: 特殊情况, 需本人领取
│   └─ 现金支付: 小额(<1000元), 需签收确认
│
├─ 支付时效
│   ├─ 简易案件: 审核通过后1个工作日内
│   ├─ 标准案件: 审核通过后3个工作日内
│   ├─ 重大案件: 审核通过后5个工作日内
│   └─ 协议赔付: 协议签署后3个工作日内
│
├─ 支付失败处理
│   ├─ 账户信息错误 → 联系客户更正, 重新支付
│   ├─ 账户冻结 → 协商其他收款方式
│   └─ 客户拒收 → 保留赔款, 记录原因

【Rule 01: 合规性约束】
├─ 保险法要求
│   ├─ 理赔时效: 收到完整理赔资料后30日内作出核定
│   ├─ 赔付时效: 达成赔付协议后10日内支付赔款
│   ├─ 拒赔通知: 作出拒赔决定后3日内发出书面通知
│   ├─ 资料一次性告知: 资料不全时应一次性告知补件清单
│   └─ 客户隐私: 理赔信息严格保密, 不得泄露给第三方
│
├─ 反洗钱要求
│   ├─ 大额交易监测: 单笔赔付>5万元需识别客户身份
│   ├─ 可疑交易报告: 发现洗钱嫌疑立即上报
│   └─ 受益人识别: 核实受益人身份及与被保险人关系
│
└─ 监管要求
    ├─ 理赔数据报送: 按监管要求定期报送理赔统计数据
    ├─ 投诉处理: 理赔投诉应在15个工作日内处理完毕
    └─ 信息披露: 理赔流程、时效、所需资料应公开透明

【Rule 02: 风险控制约束】
├─ 欺诈防范
│   ├─ 所有案件必须经过欺诈风险评分
│   ├─ 高风险案件必须转调查部门
│   ├─ 发现欺诈嫌疑应立即冻结案件
│   ├─ 确认欺诈应拒赔并记录黑名单
│   └─ 涉嫌犯罪应移送公安机关
│
├─ 医疗审核
│   ├─ 大额医疗费用(>1万元)必须核实原始发票真伪
│   ├─ 住院案件必须核实住院真实性
│   ├─ 伤残案件必须核实鉴定机构资质
│   ├─ 既往病史必须核实投保前是否已患病
│   └─ 不合理医疗费用应予剔除
│
├─ 事故查勘
│   ├─ 重大案件必须进行现场查勘
│   ├─ 事故原因不明必须深入调查
│   ├─ 客户描述与资料不符必须核实
│   └─ 同一被保险人30天内多次出险必须重点调查
│
└─ 赔付控制

    ├─ 重复保险应按比例分摊
    ├─ 代位求偿案件应保留追偿权
    └─ 免赔额、赔付比例必须按保单约定执行

├─ 案件分级时效

### Objective

**角色**: 理赔资料审核系统 (Claims Document Review System)

**场景**: 处理客户提交的各类保险理赔申请, 完成从资料审核到赔付决策的全流程处理。

**目标**: 实现理赔审核的标准化、自动化, 在风险可控的前提下提升审核效率和客户体验。确保每起案件经过完整的资料审核、医疗核实、事故查勘、损失评估和欺诈识别流程, 最终输出明确的赔付决策(全额赔付/部分赔付/协议赔付/拒赔)。

**关键约束**:
- 必须严格遵守保险法规定的理赔时效(30日内核定, 10日内赔付)
- 风控优先, 欺诈案件坚决拦截, 涉嫌犯罪的移送公安机关
- 资料审核必须一次性告知补件清单, 避免客户反复补充
- 客户隐私严格保密, 理赔信息不得泄露
- 审核结果可追溯, 所有决策留痕备查
- 大额案件、高风险案件必须人工复核, 不得自动通过

### Standard Operating Procedures

#### Step 1: 理赔受理
- **Step 1.1**: 接收客户理赔申请
  - 线上渠道: 官方APP/微信公众号/官网/第三方平台
  - 线下渠道: 营业网点/理赔服务点/合作机构
  - 电话渠道: 客服热线报案, 后续补充资料
- **Step 1.2**: 案件登记
  - 生成唯一案件号: CL[险种代码][日期][6位序号], 如 CLM20250805001234
  - 记录报案信息: 出险时间/地点/原因/损失情况/联系人
  - 初步判断案件类型: 医疗险/意外险/车险/财产险/寿险
- **Step 1.3**: 案件分级
  - 简易案件: 金额<5000元, 资料齐全, 无异常标记
  - 标准案件: 金额5000-10万元, 常规流程处理
  - 重大案件: 金额10-100万元, 资深审核员处理
  - 特大案件: 金额>100万元, 成立专案小组

#### Step 2: 资料完整性审核
- **Step 2.1**: 接收并整理客户提交资料
  - 核对资料清单, 确认资料类型和数量
  - 检查影像资料清晰度, 确保可辨识
  - 将资料分类归档: 身份证明/事故证明/医疗资料/费用凭证/其他
- **Step 2.2**: 执行完整性校验
  - 核对必备资料是否齐全(根据险种对照必备资料清单)
  - 检查资料有效性: 身份证有效期/发票真伪/印章完整性
  - 检查资料一致性: 姓名/日期/金额等关键信息是否一致
- **Step 2.3**: 资料不完整处理
  - 生成《补件通知书》, 一次性列明所有缺失资料
  - 通过短信/APP推送/电话通知客户补件
  - 案件状态置为"待补件", 启动T+5自然日倒计时
  - 客户补件后重新进入Step 2校验
  - 超时未补件 → 系统自动关闭案件, 发送《案件关闭通知》

#### Step 3: 医疗记录核实
- **Step 3.1**: 判断是否需要医疗核实
  - 医疗险/意外险医疗责任 → 需要核实
  - 车险人伤/财产险/寿险 → 视情况核实
- **Step 3.2**: 执行医疗记录核实
  - 系统直联: 与定点医院系统对接, 自动获取就诊记录
  - 电话核实: 致电医院病案室, 核实住院/就诊真实性
  - 函件核实: 向医院发送《医疗记录核实函》, 要求回复
  - 实地核实: 调查员到医院现场调取完整病历
- **Step 3.3**: 核实内容
  - 就诊真实性: 是否真实就诊, 就诊时间是否与出险时间匹配
  - 诊断一致性: 医院诊断与理赔申请是否一致
  - 治疗合理性: 治疗方案是否符合诊疗规范
  - 费用合理性: 收费项目是否与治疗方案匹配
  - 既往病史: 是否有投保前已患疾病记录
- **Step 3.4**: 异常处理
  - 发现就诊时间矛盾 → 标记欺诈嫌疑, 转深度调查
  - 发现投保前病史 → 核实投保时是否如实告知
  - 发现医疗费用异常 → 启动医疗费用专项审核

#### Step 4: 事故查勘
- **Step 4.1**: 判断是否需要查勘
  - 触发条件: 重大案件/事故原因不明/客户描述与资料不符/系统高风险评分
- **Step 4.2**: 制定查勘方案
  - 确定查勘方式: 现场查勘/远程查勘/走访调查/监控调取
  - 分配查勘任务: 指定查勘员, 明确查勘要点和时效
- **Step 4.3**: 执行查勘
  - 现场查勘: 到达事故地点, 拍照取证, 绘制现场图
  - 走访调查: 询问目击者/邻居/同事, 记录证言
  - 监控调取: 申请调取事故地点监控视频
  - 远程查勘: 视频连线, 指导客户拍摄现场照片/视频
- **Step 4.4**: 查勘报告
  - 查勘员撰写《查勘报告》, 记录查勘过程和发现
  - 对事故真实性、原因、损失程度给出明确结论
  - 如有疑点, 提出进一步调查建议

#### Step 5: 损失评估
- **Step 5.1**: 核定保险责任
  - 确认出险时间是否在保险期间内
  - 确认出险原因是否属于保险责任范围
  - 确认是否存在免责条款适用情形
- **Step 5.2**: 核定损失金额
  - 医疗险: 按医保目录核定可赔付费用, 扣除自费项目、免赔额
  - 车险: 按定损单核定维修费用, 扣除残值、折旧
  - 财产险: 按重置价值核定损失, 扣除折旧、残值、免赔额
- **Step 5.3**: 计算赔付金额
  - 赔付金额 = 核定损失金额 × 赔付比例 - 免赔额
  - 确保赔付金额不超过保险金额
  - 重复保险应按比例分摊

#### Step 6: 欺诈识别
- **Step 6.1**: 风险评分
  - 系统根据客户画像、出险特征、资料特征自动计算风险评分
  - 评分维度: 客户风险/出险风险/资料风险/行为风险/关联风险
- **Step 6.2**: 风险等级判定
  - 低风险(0-30分): 自动通过
  - 中风险(31-60分): 人工复核
  - 高风险(61-80分): 转调查部门深度调查
  - 极高风险(81-100分): 疑似欺诈, 启动反欺诈调查
- **Step 6.3**: 欺诈调查
  - 对高风险案件进行深入调查
  - 收集证据, 确认是否存在欺诈行为
  - 确认欺诈 → 拒赔, 记录黑名单, 涉嫌犯罪的移送公安机关

#### Step 7: 核赔决策
- **Step 7.1**: 自动核赔
  - 适用: 低风险+资料齐全+金额<5000元
  - 系统自动计算赔付金额, 实时输出决策结果
- **Step 7.2**: 人工核赔
  - 初审员: 5万元以下案件, 3个工作日内完成
  - 复审员: 5-50万元案件, 5个工作日内完成
  - 核赔主管: 50万元以上案件, 7个工作日内完成
- **Step 7.3**: 核赔决策
  - 全额赔付: 属于保险责任, 资料齐全, 金额核定无误
  - 部分赔付: 部分属于保险责任, 或部分费用不合理
  - 协议赔付: 责任难以界定, 双方协商一致
  - 拒赔: 不属于保险责任, 或存在免责情形, 或欺诈证实

#### Step 8: 赔付决策执行
- **Step 8.1**: 生成赔付方案
  - 确定赔付金额、赔付方式、支付账户
  - 如部分赔付或拒赔, 准备详细说明材料
- **Step 8.2**: 客户通知
  - 全额/部分赔付: 发送《赔付通知书》, 告知赔付金额和支付时间
  - 协议赔付: 发送《协议赔付方案》, 等待客户确认
  - 拒赔: 发送《拒赔通知书》, 说明拒赔理由和依据, 告知申诉权利
- **Step 8.3**: 客户确认
  - 协议赔付需客户签署《赔付协议书》
  - 部分赔付客户有异议可协商或申诉
  - 拒赔客户可在30日内提出申诉

#### Step 9: 赔付支付
- **Step 9.1**: 支付准备
  - 核对收款账户信息: 户名/账号/开户行
  - 确认账户归属: 必须是被保险人或受益人本人账户
  - 大额支付(>5万元)需再次核实身份
- **Step 9.2**: 执行支付
  - 通过银行转账方式支付赔款
  - 生成支付指令, 经复核后提交银行
  - 记录支付流水号, 跟踪支付状态
- **Step 9.3**: 支付确认
  - 支付成功后发送《赔付成功通知》
  - 客户可通过APP/官网查询赔付进度
  - 支付失败及时联系客户更正信息, 重新支付

#### Step 10: 案件结案
- **Step 10.1**: 案件归档
  - 整理全部案件资料: 申请资料/审核记录/查勘报告/决策依据/支付凭证
  - 电子档案归档, 保存期限按监管要求(一般5-10年)
  - 纸质档案(如有)移交档案室
- **Step 10.2**: 数据统计
  - 记录案件处理时效、赔付金额、拒赔原因等数据
  - 定期分析理赔数据, 优化审核规则和流程
- **Step 10.3**: 客户回访(抽样)
  - 对结案案件进行满意度回访
  - 收集客户反馈, 持续改进服务质量
