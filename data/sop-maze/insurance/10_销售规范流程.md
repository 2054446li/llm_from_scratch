# 保险销售规范流程SOP

## 1. SOP简介

本SOP规范保险代理人/电销专员向客户推荐保险产品的完整销售流程，涵盖客户接触与信任建立、需求分析与挖掘、产品方案设计、产品讲解与演示、异议处理与促成、投保办理与回访六大核心环节，确保销售过程合规高效，实现客户保障需求与保险公司业务目标的双赢。

## 3. Objective

### 3.1 流程目标

| 目标维度 | 具体描述 | 关键指标 |
|---------|---------|---------|
| **客户目标** | 获得符合自身需求的保障方案，充分理解产品责任与风险 | 需求匹配度、理解度评分 |
| **代理人目标** | 完成销售任务，建立长期客户关系，获得转介绍 | 成交率、件均保费、转介绍率 |
| **保险公司目标** | 合规开展业务，控制承保风险，维护品牌声誉 | 合规率、继续率、投诉率 |
| **监管目标** | 保护消费者权益，防范销售误导，维护市场秩序 | 违规率、投诉处理满意度 |

## 4. Standard Operating Procedures

### 4.1 Step 1: 客户接触与信任建立

#### 4.1.1 开场白设计

| 场景类型 | 开场白话术模板 | 适用情境 |
|---------|--------------|---------|
| **电话约访** | "您好，请问是[姓名]先生/女士吗？我是[公司名]的保险顾问[姓名]，之前您咨询过[具体渠道/活动]，今天想跟您确认一个方便的时间，为您详细介绍[产品类型]的保障方案。" | 电话销售/线上线索跟进 |
| **转介绍接触** | "[介绍人]跟我提起您，说您最近在为家庭保障做规划。我是[公司名]的[姓名]，专门帮助像您这样的[客户特征]家庭设计保障方案。" | 老客户转介绍 |
| **活动邀约** | "感谢您参加我们上周的[活动名称]，我是负责[区域]的保险顾问[姓名]。注意到您对[产品/话题]很感兴趣，想为您做个一对一的方案讲解。" | 线下活动后续 |
| **陌生拜访** | "您好，我是[公司名]的[姓名]，打扰您两分钟。我们最近在[社区/区域]开展家庭保障公益讲座，想邀请您参加，同时送您一份免费的保障缺口分析报告。" | 社区陌拜 |

│                                                         │

│                                                         │
│ 3. 服务承诺                                             │
│    "我的职责是帮您找到最适合的保障方案，                │

#### 4.1.3 关系破冰技巧

| 破冰策略 | 具体方法 | 示例话术 |
|---------|---------|---------|
| **共同点寻找** | 地域、职业、兴趣爱好、共同认识的人 | "您也是[城市]人啊，我也是！咱们老乡啊" |
| **赞美认可** | 真诚具体的赞美，避免空泛 | "看您的资料，您在[行业]做得非常成功，这种前瞻性思维在保障规划上也很重要" |
| **价值前置** | 先提供有价值的信息或服务 | "不管最后是否投保，我先帮您做一份免费的家庭保障缺口分析" |
| **好奇激发** | 提出引发思考的问题 | "您知道大部分家庭在保障配置上的三大误区是什么吗？" |

#### 4.1.4 信任建立路径

```
信任建立四阶段：

阶段1：专业信任（0-5分钟）
├── 着装得体、准时守信
├── 资料准备充分（产品彩页、计划书、公司介绍）
└── 专业知识展示（行业数据、理赔案例）

阶段2：能力信任（5-15分钟）
├── 准确理解客户需求
├── 提供有针对性的分析
└── 展示成功案例（脱敏处理）

阶段3：诚意信任（15-30分钟）
├── 坦诚告知产品优缺点
├── 不回避免责条款
└── 推荐最适合而非最贵的产品

阶段4：长期信任（持续维护）
├── 定期保单检视服务
├── 理赔协助承诺
└── 家庭保障动态调整建议
```

### 4.2 Step 2: 需求分析与挖掘

#### 4.2.1 SPIN提问法则

```
SPIN提问模型：

┌─────────────────────────────────────────────────────────────────┐
│ S - Situation Questions (背景问题)                              │
│     目的：了解客户基本情况                                      │
│     示例：                                                      │
│     • "您目前的家庭结构是怎样的？"                              │
│     • "您和太太的工作性质和收入情况方便说一下吗？"              │
│     • "目前家里有房贷或其他负债吗？"                            │
├─────────────────────────────────────────────────────────────────┤
│ P - Problem Questions (难点问题)                                │
│     目的：发现客户现有保障的问题或不足                          │
│     示例：                                                      │
│     • "如果突然失去收入来源，您目前的储蓄能支撑家庭多久？"      │
│     • "您现在的社保/医保能覆盖大病治疗费用的比例大概是多少？"   │
│     • "孩子未来的教育金，您现在有专门的储备吗？"                │
├─────────────────────────────────────────────────────────────────┤
│ I - Implication Questions (暗示问题)                            │
│     目的：放大问题的影响，让客户意识到严重性                    │
│     示例：                                                      │
│     • "如果家庭主要收入来源中断，对房贷还款和孩子教育会有什么影响？" │
│     • "一场大病平均花费30-50万，社保只能报销一部分，差额部分您打算怎么解决？" │
│     • "您有没有想过，如果没有提前规划，孩子出国留学的机会可能会受限？" │
├─────────────────────────────────────────────────────────────────┤
│ N - Need-payoff Questions (需求-效益问题)                       │
│     目的：引导客户自己说出解决方案的价值                        │
│     示例：                                                      │
│     • "如果有一份保险能在您生病时一次性给付50万，让您安心养病不用操心收入，这对您来说意味着什么？" │
│     • "如果每月存2000元就能确保孩子将来有50万教育金，您觉得这样的规划有价值吗？" │
│     • "如果能用一笔小钱锁定未来的养老品质，您愿意了解一下吗？"  │
└─────────────────────────────────────────────────────────────────┘
```

#### 4.2.3 保障缺口计算公式

```
┌─────────────────────────────────────────────────────────────────┐
│                    保障缺口计算模型                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【寿险缺口计算】                                                │
│  寿险保额需求 = 家庭负债 + 子女教育金 + 父母赡养费 + 家庭年生活费 × 10年 - 现有流动资产 │
│                                                                 │
│  示例：                                                         │
│  • 房贷余额：100万                                              │
│  • 子女教育金（至大学）：50万                                   │
│  • 父母赡养费：30万                                             │
│  • 家庭年生活费：10万 × 10年 = 100万                            │
│  • 现有流动资产：50万                                           │
│  ─────────────────────────────────                              │
│  寿险保额需求 = 100 + 50 + 30 + 100 - 50 = 230万                │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【重疾险缺口计算】                                              │
│  重疾保额需求 = 平均治疗费 + 康复费 + 收入损失补偿 - 社保报销预估 │
│                                                                 │
│  示例：                                                         │
│  • 平均治疗费：30万                                             │
│  • 康复费（2-3年）：20万                                        │
│  • 收入损失（3年）：年收入20万 × 3 = 60万                       │
│  • 社保报销预估：15万                                           │
│  ─────────────────────────────────                              │
│  重疾保额需求 = 30 + 20 + 60 - 15 = 95万（建议100万起）         │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【医疗险需求评估】                                              │
│  医疗险需求 = 期望医疗品质 - 现有医保覆盖范围                    │
│                                                                 │
│  评估维度：                                                     │
│  • 就医医院范围（公立普通/特需/国际部/私立）                    │
│  • 治疗手段限制（是否含进口药、靶向药、质子重离子）             │
│  • 年度保额需求（100万/200万/400万/更高）                       │
│  • 免赔额接受度（0免赔/1万免赔/更高）                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 4.2.4 风险评估矩阵

| 风险类型 | 评估问题 | 风险等级 | 对应产品 |
|---------|---------|---------|---------|
| **身故风险** | 家庭是否有依赖您收入生活的成员？负债情况？ | 高/中/低 | 定期寿险/终身寿险 |
| **重疾风险** | 家族病史？当前健康状况？社保覆盖程度？ | 高/中/低 | 重疾险+医疗险 |
| **意外风险** | 职业风险等级？通勤方式？经常出差？ | 高/中/低 | 意外险 |
| **医疗风险** | 对医疗品质的要求？是否有海外就医需求？ | 高/中/低 | 百万医疗/中端医疗/高端医疗 |
| **养老风险** | 期望退休年龄？社保养老金预估缺口？ | 高/中/低 | 年金险/增额终身寿 |
| **教育风险** | 子女教育规划？是否有出国留学计划？ | 高/中/低 | 教育年金/增额终身寿 |

#### 4.5.2 常见异议处理话术

| 异议类型 | 客户原话 | 处理话术 |
|---------|---------|---------|
| **价格异议** | "保费太贵了" | "我理解您的感受。我们换个角度算一下：每天[保费/365]元，也就是一杯咖啡的钱，就能换来[保额]的保障。如果不投保，万一发生风险，您需要从积蓄里拿出[保额]，相当于[年数]年的保费。您觉得哪个压力更大？" |
| **需求异议** | "我不需要保险" | "您现在身体健康、事业顺利，确实感觉不需要。但保险的本质是防范未来的不确定性。就像您开车系安全带，不是为了希望出事故，而是为了万一出事有保护。而且保险越年轻买越便宜，等需要时再买可能买不了或更贵。" |
| **信任异议** | "保险公司会不会倒闭？" | "这个您放心。保险公司受银保监会严格监管，有保证金、责任准备金、保险保障基金等多重保障。即使保险公司破产，您的保单也会由其他保险公司接管，权益不受影响。历史上还没有出现过保单无法兑付的情况。" |
| **时机异议** | "我再考虑考虑" | "当然要考虑清楚，这是对的。不过我能问一下，您主要考虑的是哪个方面吗？是产品本身、保费预算，还是其他？（等回答后）其实很多时候，考虑着考虑着就忘了，然后风险就发生了。您看这样行不行，我们先走完投保流程，您有15天的犹豫期，这期间可以无条件退保，全额退款。这样既锁定了保障，您又有充分时间考虑。" |
| **比较异议** | "别家公司更便宜" | "您说得对，市场上确实有更便宜的产品。不过买保险不能只看价格，还要看保障范围、理赔服务、公司实力。那款产品（指出具体差异）... 您觉得为了省[差价]，承担这些差异值得吗？" |
| **决策异议** | "我要和家人商量" | "当然应该和家人商量。不过我想了解一下，您家人对保险是什么态度呢？（了解后）要不这样，我给您准备一份详细的计划书，您带回去和家人一起看。明天晚上我再给您打个电话，解答家人的疑问，您看可以吗？" |

## 5. Rule约束

### 5.1 销售规则体系

```
┌─────────────────────────────────────────────────────────────────┐
│                    保险销售六大核心规则                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  R1: 适当性原则 (Suitability)                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：将适当的产品销售给适当的客户                        │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 评估客户风险承受能力                                    │   │
│  │ • 了解客户保险需求和投资目标                              │   │
│  │ • 推荐与客户情况匹配的产品                                │   │
│  │ • 不得向风险承受能力低的客户推销高风险产品                │   │
│  │                                                         │   │
│  │ 违规示例：向退休老人推荐投连险                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  R2: 如实告知原则 (Full Disclosure)                             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：客户如实告知健康状况等重要信息                      │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 逐条询问健康告知事项                                    │   │
│  │ • 不得诱导客户隐瞒或虚假告知                              │   │
│  │ • 对客户的告知内容进行核实                                │   │
│  │ • 如实记录告知内容                                        │   │
│  │                                                         │   │
│  │ 违规示例：教唆客户隐瞒既往病史                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  R3: 风险提示义务 (Risk Disclosure)                             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：充分揭示产品风险，特别是收益不确定性                │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 说明分红、万能、投连等非保证收益的不确定性              │   │
│  │ • 演示不同情景下的收益情况                                │   │
│  │ • 说明退保损失和犹豫期权利                                │   │
│  │ • 客户亲笔抄录风险提示语句                                │   │
│  │                                                         │   │
│  │ 违规示例：承诺固定收益、夸大历史收益                      │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  R4: 禁止返佣规定 (No Rebates)                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：不得以任何形式向客户返还佣金或给予额外利益          │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 不得承诺或给予保险费回扣                                │   │
│  │ • 不得赠送保险合同约定以外的利益                          │   │
│  │ • 不得以抽奖、送实物等方式诱导投保                        │   │
│  │ • 佣金是公司的，不是客户的                                │   │
│  │                                                         │   │
│  │ 违规示例：承诺返还首年佣金、送贵重礼品                    │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  R5: 双录要求 (Recording)                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：销售过程全程录音录像，保存可追溯                    │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 使用公司指定的双录设备和系统                            │   │
│  │ • 确保录音录像清晰、完整、连续                            │   │
│  │ • 包含所有法定告知内容                                    │   │
│  │ • 客户明确肯定答复                                        │   │
│  │                                                         │   │
│  │ 违规示例：双录资料剪辑、代客户回答                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  R6: 回访制度 (Callback)                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 要求：投保后必须进行回访，确认客户权益                    │   │
│  │                                                         │   │
│  │ 执行要点：                                               │   │
│  │ • 犹豫期内完成电话回访                                    │   │
│  │ • 确认客户了解产品责任和权益                              │   │
│  │ • 解答客户疑问                                            │   │
│  │ • 回访记录存档                                            │   │
│  │                                                         │   │
│  │ 违规示例：不进行回访、回访流于形式                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
