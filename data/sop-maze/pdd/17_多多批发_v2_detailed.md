# 拼多多多多批发 SOP v2_detailed

## Objective

为拼多多B端批发业务"多多批发"提供标准化操作流程指南，帮助批发商家了解入驻条件、价格体系、大宗采购流程及账期管理规则，同时协助企业客户完成认证并高效完成批量采购。本SOP涵盖商家入驻（批发资质）、批发价格体系、起批量要求、大宗采购流程、企业客户认证、账期管理、大件物流配送等核心环节。

## Standard Operating Procedures

### 一、商家入驻（批发资质）

#### 1.1 入驻条件审核

##### 1.1.1 主体资质要求

| 资质类型 | 具体要求 | 审核要点 | 有效期要求 |
|---------|---------|---------|-----------|
| **企业营业执照** | 个体工商户/企业法人 | 经营范围含批发/零售 | 剩余有效期>90天 |
| **法人身份证** | 正反面清晰照片 | 与营业执照法人一致 | 剩余有效期>90天 |
| **银行开户许可证** | 对公账户证明 | 账户名称与营业执照一致 | 长期有效 |
| **经营场所证明** | 租赁合同/产权证明 | 面积与申报仓储能力匹配 | 剩余租期>180天 |

##### 1.1.2 行业特殊资质

| 经营类目 | 特殊资质要求 | 发证机关 | 审核时效 |
|---------|-------------|---------|---------|
| **食品饮料** | 食品经营许可证 | 市场监督管理局 | 1-3个工作日 |
| **化妆品** | 化妆品生产/经营许可证 | 药监局 | 1-3个工作日 |
| **3C数码** | 3C认证证书 | 认监委 | 1-2个工作日 |
| **医疗器械** | 医疗器械经营许可证 | 药监局 | 3-5个工作日 |
| **图书音像** | 出版物经营许可证 | 新闻出版局 | 2-3个工作日 |
| **农资种子** | 种子经营许可证 | 农业农村局 | 3-5个工作日 |

##### 1.1.3 批发能力评估

| 评估维度 | 最低要求 | 优选标准 | 评估方式 |
|---------|---------|---------|---------|
| **仓储面积** | >=500㎡ | >=2000㎡ | 实地核验/视频验证 |
| **日均发货能力** | >=500单 | >=3000单 | 历史数据/系统对接 |
| **库存深度** | 主力SKU>=100件 | 主力SKU>=500件 | 系统校验 |
| **物流配送** | 覆盖>=3个区域 | 全国覆盖 | 物流合同审核 |

```
    │   ├── 日均发货能力
    │   ├── 仓储面积
    │   └── 主要销售渠道

步骤4：上传资质材料（KCP2: 材料完整性校验）
    │
    ├── 4.1 必传材料清单

    │
```

##### 1.2.2 平台资质审核（KCP3: 资质终审节点）

**审核流程：**

```
初审（系统自动）
    │
    ├── 审核内容：
    │   ├── 营业执照真实性（对接工商系统核验）
    │   ├── 身份证有效性（公安系统核验）
    │   ├── 材料完整性（必填项检查）
    │   └── 格式合规性（文件类型、大小）
    │
    ├── 时效：即时完成
    │
    └── 结果分流：
        ├── 通过 → 进入人工复审
        └── 不通过 → 退回补充材料

人工复审（审核专员）
    │
    ├── 审核内容：
    │   ├── 批发能力评估（仓储、发货能力）
    │   ├── 类目资质匹配（经营范围与申请类目）
    │   ├── 品牌授权链完整性
    │   └── 历史违规记录查询
    │
    ├── 时效：3-7个工作日
    │
    └── 结果分流：
        ├── 通过 → 进入协议签署
        ├── 需补充 → 退回补充材料
        └── 拒绝 → 告知原因，6个月后可重新申请

终审（风控部门）
    │
    ├── 审核内容：
    │   ├── 企业信用评级
    │   ├── 关联店铺风险排查
    │   └── 行业风险预警
    │
    ├── 时效：1-2个工作日
    │
    └── 结果：
        ├── 通过 → 发送入驻邀请
        └── 拒绝 → 永久限制入驻
```

**Rule层 - 资质审核拦截规则：**

```yaml
rules:
  - name: 营业执照有效性校验
    condition: 营业执照状态 != "存续" OR 剩余有效期 < 90天
    action: 拦截并提示"营业执照已过期或即将过期，请更新后重新提交"
    severity: 阻断
    
  - name: 经营范围匹配校验
    condition: 申请类目 NOT IN 营业执照.经营范围
    action: 拦截并提示"营业执照经营范围不包含申请类目，请变更经营范围或调整申请类目"
    severity: 阻断
    
  - name: 特殊资质有效期校验
    condition: 特殊资质.有效期 < 30天
    action: 拦截并提示"特殊资质即将过期，请更新后重新提交"
    severity: 阻断
    
  - name: 品牌授权链完整性校验
    condition: 品牌授权链.层级 > 3 OR 授权链存在断链
    action: 拦截并提示"品牌授权链超过3级或存在断链，请提供完整授权证明"
    severity: 阻断
    
  - name: 历史违规记录校验
    condition: 关联店铺.近12个月.严重违规次数 >= 3
    action: 拦截并提示"关联店铺存在严重违规记录，暂不符合入驻条件"
    severity: 阻断
    
  - name: 同一主体入驻限制
    condition: 同一营业执照.已入驻店铺数 >= 3
    action: 拦截并提示"同一营业执照最多可入驻3个批发店铺"
    severity: 阻断
```

#### 1.3 批发资质管理

```
资质变更触发场景：
    ├── 营业执照信息变更（名称、法人、经营范围等）
    ├── 特殊资质续期/更新
    ├── 品牌授权变更
    └── 经营场所变更

    步骤1：商家后台提交变更申请

        ├── 审核通过：即时生效
        └── 审核不通过：退回补充
```

### 二、批发价格体系

#### 2.1 价格结构定义

##### 2.1.1 价格层级体系

```
┌─────────────────────────────────────────────────────────────────┐
│                        批发价格层级架构                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   第一层级：零售价（参考价）                                     │
│   ├── 定义：单件购买的市场参考价格                              │
│   ├── 用途：展示批发优惠力度                                    │
│   └── 约束：须为真实市场零售价                                  │
│                                                                 │
│   第二层级：批发价（基础批发价）                                 │
│   ├── 定义：达到起批量后的优惠价格                              │
│   ├── 折扣范围：零售价的85%-95%                                 │
│   └── 约束：须低于或等于其他批发渠道价格                        │
│                                                                 │
│   第三层级：阶梯价（量大从优）                                   │
│   ├── 定义：根据采购量设置的多档价格                            │
│   ├── 档位设置：3-5档                                           │
│   └── 约束：每档价差>=5%，档位间起批量递增>=2倍                 │
│                                                                 │
│   第四层级：协议价（大客户专属）                                 │
│   ├── 定义：长期合作大客户专属价格                              │
│   ├── 确定方式：线下洽谈，线上锁定                              │
│   └── 约束：须低于阶梯最低价，年采购额>=100万                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

##### 2.1.2 阶梯定价规范

| 采购量级 | 建议起批量 | 折扣力度 | 适用对象 | 年采购额要求 |
|---------|-----------|---------|---------|-------------|
| **小批** | 10-50件 | 批发价（9-9.5折） | 小型零售商、个体户 | 无 |
| **中批** | 50-200件 | 中批价（8.5-9折） | 中型商超、便利店 | >=10万 |
| **大批** | 200-1000件 | 大批价（8-8.5折） | 大型连锁、经销商 | >=50万 |
| **特批** | >=1000件 | 协议价（面议，<=8折） | 战略合作客户 | >=100万 |

**Rule层 - 价格合规校验规则：**

```yaml
rules:
  - name: 批发价不得高于零售价
    condition: 批发价 > 零售价 * 0.95
    action: 拦截并提示"批发价不得高于零售价的95%，请调整价格"
    severity: 阻断
    
  - name: 阶梯价单调递减校验
    condition: 存在阶梯价[i] >= 阶梯价[i-1]
    action: 拦截并提示"阶梯价必须逐级递减，请检查价格设置"
    severity: 阻断
    
  - name: 阶梯价差校验
    condition: (阶梯价[i-1] - 阶梯价[i]) / 阶梯价[i-1] < 0.05
    action: 拦截并提示"相邻阶梯价差不得小于5%，请调整价格"
    severity: 阻断
    
  - name: 起批量递增校验
    condition: 起批量[i] < 起批量[i-1] * 2
    action: 拦截并提示"相邻阶梯起批量递增倍数不得小于2倍"
    severity: 阻断
    
  - name: 协议价权限校验
    condition: 客户.年采购额 < 100万 AND 订单.价格类型 == "协议价"
    action: 拦截并提示"该客户未达到协议价采购门槛，请使用阶梯价"
    severity: 阻断
    
  - name: 价格稳定性校验
    condition: 价格变动频率 > 7天/次 AND 变动幅度 > 10%
    action: 预警并提示"价格变动过于频繁，可能影响客户信任"
    severity: 警告
```

| 参数 | 说明 | 配置示例 |

##### 3.1.3 混批起批

| 参数 | 说明 | 配置示例 |

| **计算方式** | 累计数量/金额 | 多SKU数量累加 |

**适用场景：** 品类丰富的综合批发商

#### 3.3 起批规则配置

**Rule层 - 起批规则校验：**

```yaml
rules:
  - name: 最小起批量限制
    condition: 起批量 < 类目.最小起批量标准
    action: 拦截并提示"该商品起批量低于类目最低标准"
    severity: 阻断
    
  - name: 起批单位一致性校验
    condition: 起批单位 NOT IN 商品.规格单位
    action: 拦截并提示"起批单位与商品规格单位不一致"
    severity: 阻断
    
  - name: 混批商品范围校验
    condition: 混批商品.店铺ID != 当前店铺ID
    action: 拦截并提示"混批仅限同店铺商品"
    severity: 阻断
    
  - name: 库存满足起批校验
    condition: 可售库存 < 最小起批量
    action: 拦截并提示"库存不足，无法满足起批要求"
    severity: 阻断
    
  - name: 阶梯起批递增校验
    condition: 阶梯[i].起批量 <= 阶梯[i-1].起批量
    action: 拦截并提示"阶梯起批量必须逐级递增"
    severity: 阻断
```

```json
      "通知内容": "因中转仓临时积压，您的订单预计延误2-3天",
      "补偿方案": "发放30元无门槛优惠券",
      "跟进频率": "每24小时主动更新进展"
    },
    "升级处理": {
      "条件": "超过5天无更新",
      "措施": "启动理赔流程，优先补发"
    }
  }
}
```

**评估要点：**
- 异常检测是否及时（超过2天即应触发）
- 处理方案是否全面（物流+客户+升级）
- 补偿是否合理（考虑偏远地区特殊性）
