## Objective

品质险是拼多多平台联合保险公司（如中国人保财险）推出的正品保障服务，由保险公司承保，为消费者提供更高层级的品质保障。本SOP明确品质险的开通流程、保障范围、理赔条件、鉴定流程及赔付标准，区分品质险与平台"假一赔十"承诺的差异，确保消费者权益保护和商家合规经营。

#### 1.3 保费计算

**保费计算公式：**

```
单品保费 = 商品售价 × 保费费率
总保费 = Σ(各商品保费) 或 按销售额比例计算
```

| 计费方式 | 说明 | 适用场景 | [需内部资料确认] |
|----------|------|----------|------------------|
| 按单计费 | 每成交一单缴纳保费 | 低客单价商品 | 具体费率 |
| 按月计费 | 按月销售额比例缴纳 | 高客单价商品 | 具体费率 |
| 年费模式 | 年度固定保费 | 品牌旗舰店 | 具体金额 |

### 六、赔付标准

#### 6.1 赔付计算方式

**6.1.1 基础赔付公式**

```
赔付金额 = 商品实际损失 + 合理费用

其中：
- 商品实际损失 = min(商品实付金额, 保险金额)
- 合理费用 = 退货运费 + 鉴定费（如适用）
```

**6.1.2 不同问题的赔付标准**

| 问题类型 | 赔付方式 | 计算标准 |
|----------|----------|----------|
| 假冒品牌 | 全额赔付+退货运费 | 商品实付金额 × 100% |
| 材质不符 | 差额赔付或全额退款 | 根据实际价值差异 |
| 功能缺陷 | 维修费/更换/退款 | 实际维修费用或商品价值 |
| 外观瑕疵 | 协商赔付 | 根据瑕疵程度协商 |

#### 6.2 赔付流程

| 环节 | 处理方 | 时效 | 说明 |
|------|--------|------|------|
| 理赔申请 | 消费者 | - | 提交申请材料 |
| 平台初审 | 拼多多 | [需内部资料确认] | 材料完整性审核 |
| 保险审核 | 保险公司 | [需内部资料确认] | 核赔审核 |
| 赔付确认 | 保险公司 | - | 确定赔付金额 |
| 资金拨付 | 保险公司 | [需内部资料确认] | 赔付到账 |

#### 6.3 赔付方式

| 赔付方式 | 适用场景 | 到账时效 |
|----------|----------|----------|
| 原路退回 | 退款类赔付 | 1-3个工作日 |
| 现金赔付 | 赔偿类赔付 | [需内部资料确认] |
| 优惠券补偿 | 小额补偿 | 即时到账 |

### 七、品质险与假一赔十的区别

#### 7.1 核心差异对比

| 对比维度 | 品质险 | 假一赔十 |
|----------|--------|----------|
| **保障主体** | 保险公司承保 | 平台承诺 |
| **赔付来源** | 保险赔付 | 平台/商家赔付 |
| **赔付倍数** | 按实际损失赔付 | 商品金额 × 10 |
| **适用范围** | 品质险标识商品 | 标注"假一赔十"商品 |
| **理赔流程** | 平台+保险公司双重审核 | 平台审核 |
| **鉴定要求** | 相对灵活 | 通常需第三方鉴定 |
| **时效性** | 保险理赔周期 | 平台处理周期 |

#### 7.2 适用场景对比

| 场景 | 推荐选择 | 原因 |
|------|----------|------|
| 疑似假货 | 假一赔十 | 赔付金额更高 |
| 品质瑕疵 | 品质险 | 理赔更灵活 |
| 高价值商品 | 品质险 | 保险保障更可靠 |
| 急需处理 | 假一赔十 | 平台处理可能更快 |

#### 7.3 并行与互斥

| 情况 | 说明 | 处理方式 |
|------|------|----------|
| 同时享有 | 部分商品可能同时有两者 | 消费者可选择更有利的方式 |
| 仅品质险 | 只有品质险标识 | 按品质险流程理赔 |
| 仅假一赔十 | 只有假一赔十标识 | 按假一赔十流程申请 |
| 两者皆无 | 普通商品 | 按普通售后处理 |
