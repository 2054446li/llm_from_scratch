# 拼多多延迟发货处罚 SOP（公开信息版）

## Objective

为拼多多平台商家提供发货时效管理标准化操作流程指南，明确发货时效要求、延迟发货定义与处罚标准、缺货赔付规则、预售商品管理规范及不可抗力申诉流程，督促商家提升物流履约能力，保障消费者购物体验，促进平台生态健康发展。

## Standard Operating Procedures

### 一、发货时效要求

#### 1.1 普通商品发货时效
- **标准时效**：消费者付款后 **48小时内** 须完成发货（物流公司揽收）
- **起算时间**：以订单支付成功时间为准
- **完成标准**：在拼多多商家后台录入有效物流单号且物流公司完成揽收
- **适用范围**：平台绝大多数商品类目

#### 1.2 预售商品发货时效
- **预售时效**：消费者付款后 **15天内** 须完成发货
- **标识要求**：商品标题/详情页须明确标注"预售"字样
- **发货时间承诺**：商家须明确承诺具体发货日期
- **超时处罚**：超过承诺发货时间视为延迟发货，按延迟发货规则处罚

#### 1.3 定制商品发货时效
- **定制时效**：消费者付款后 **30天内** 须完成发货
- **适用范围**：个性化定制、手工制作、按需生产类商品
- **协商约定**：商家可与消费者协商具体发货时间，但不得超过30天上限
- **约定记录**：协商结果须在平台留存记录

#### 1.4 特殊类目时效

| 商品类型 | 发货时效 | 起算时间 | 备注 |
|---------|---------|---------|------|
| 普通商品 | 48小时 | 支付成功 | 绝大多数类目 |
| 直供商品 | 24小时 | 支付成功 | 品牌直供、平台仓发货 |
| 预售商品 | 15天 | 支付成功 | 须标注"预售" |
| 定制商品 | 30天 | 支付成功 | 可协商约定 |
| 生鲜类目 | [需内部资料确认] | 支付成功 | 可能要求24小时内 |
| 大件商品 | [需内部资料确认] | 支付成功 | 可能延长至72小时 |

#### 1.5 发货时效计算规则

```
发货时效 = 物流公司揽收时间 - 订单支付成功时间

特殊说明：
- 工作日计算：通常按自然日计算，包含周末
- 节假日顺延：法定节假日可能顺延（以平台公告为准）
- 截单时间：每日[需内部资料确认]点后的订单可能计入次日
- 大促期间：双11、618等大促可能有特殊时效要求
```

### 二、延迟发货定义

#### 2.1 延迟发货判定标准
- **核心定义**：商家未在平台规定的发货时效内完成发货（物流公司揽收）的行为
- **判定节点**：以平台系统记录的物流揽收时间为准
- **物流有效性**：物流单号须真实有效，可被物流公司追踪

#### 2.2 延迟发货情形
1. **超时未发货**：超过承诺时效仍未上传物流单号
2. **虚假发货**：上传虚假物流单号或重复使用已签收单号
3. **物流未揽收**：上传单号后超过规定时间物流未揽收 [需内部资料确认]
4. **缺货不发货**：因库存不足无法按时发货

#### 2.3 不计入延迟发货的情形
- **消费者原因**：消费者要求延迟发货且有聊天记录证明
- **不可抗力**：自然灾害、疫情、政府管制等不可抗力因素
- **系统故障**：平台系统故障导致无法发货（需平台确认）
- **协商一致**：买卖双方协商一致变更发货时间并留存记录

### 三、处罚标准

#### 3.1 延迟发货处罚

**赔付给买家**：

| 延迟时间 | 赔付标准 | 赔付上限 | 赔付下限 | 赔付对象 |
|---------|---------|---------|---------|---------|
| **延迟发货**（超过48小时） | 订单实收金额的3% | 100元 | 5元 | 消费者 |
| **严重延迟**（超过72小时） | 订单实收金额的5% | 200元 | 5元 | 消费者 |

**赔付计算示例：**
```
场景1：订单金额100元，延迟发货
赔付金额 = 100 × 3% = 3元 → 按最低5元赔付

场景2：订单金额500元，严重延迟
赔付金额 = 500 × 5% = 25元

场景3：订单金额1000元，延迟发货
赔付金额 = 1000 × 3% = 30元（未超过上限100元）
```

**平台罚款**：
- **罚款比例**：按订单金额的一定比例处以罚款 [需内部资料确认] 具体比例
- **累计处罚**：多次延迟发货可能面临更高处罚

**店铺影响**：
- **流量降权**：延迟发货率过高可能导致店铺搜索排名下降
- **活动限制**：限制参与平台营销活动资格
- **店铺扣分**：根据违规严重程度扣除店铺积分 [需内部资料确认]

#### 3.2 缺货赔付规则

**缺货定义**：
- 商家明确表示无法发货
- 超过承诺发货时间且库存为0
- 买家投诉商家缺货且核实属实

**缺货赔付标准**：

| 缺货类型 | 赔付标准 | 店铺处罚 |
|---------|---------|---------|
| **主动缺货报备** | 订单金额25%赔付 | 从轻处理 |
| **被动缺货（消费者投诉）** | 订单金额25%赔付 | 正常处罚 |
| **恶意缺货** | 订单金额25%赔付+额外处罚 | 加重处罚 |

**赔付计算示例：**
```
场景：订单金额200元，缺货无法发货
赔付金额 = 200 × 25% = 50元
最低5元，最高500元
```

#### 3.3 虚假发货处罚

**虚假发货定义**：
- 上传虚假物流单号
- 重复使用已签收的物流单号
- 物流轨迹与收货地址明显不符
- 买家未收到货但显示已签收

**虚假发货处罚** [需内部资料确认]：
- 赔付买家订单金额的25%，最低5元，最高500元
- 平台对商家处以更高额度的罚款
- 严重者可能面临店铺封禁

#### 3.4 店铺处罚措施

| 违规程度 | 延迟订单占比 | 店铺处罚 |
|---------|-------------|---------|
| **一般违规** | 延迟率<5% | 警告，要求整改 |
| **轻度违规** | 5%≤延迟率<10% | 限制参加营销活动1-7天 |
| **中度违规** | 10%≤延迟率<20% | 限制参加营销活动7-30天，降权 |
| **重度违规** | 延迟率≥20% | 限制参加营销活动30天，严重降权 |
| **特别严重** | 多次违规或恶意违规 | 店铺屏蔽，清退处理 |

#### 3.5 延迟发货率计算

```
延迟发货率 = 延迟发货订单数 / 总发货订单数 × 100%

统计周期：
- 日维度：当日延迟订单/当日总订单
- 周维度：本周延迟订单/本周总订单
- 月维度：本月延迟订单/本月总订单

考核标准：
- 平台要求延迟发货率控制在[需内部资料确认]%以内
```

#### 3.6 处罚标准汇总表

| 违规类型 | 买家赔付比例 | 赔付上限 | 赔付下限 | 平台额外处罚 |
|---------|-------------|---------|---------|-------------|
| 延迟发货（48-72小时） | 3% | 100元 | 5元 | 降权/扣分 |
| 严重延迟（>72小时） | 5% | 200元 | 5元 | 降权/扣分/限制活动 |
| 缺货 | 25% | 500元 | 5元 | 额外罚款 |
| 虚假发货 | 25% | 500元 | 5元 | 高额罚款/封店 |

### 四、预售商品规则

#### 4.1 预售商品定义
预售商品是指商家在商品未生产/未入库前先行销售，按约定时间发货的商品。

#### 4.2 预售开通条件

[需内部资料确认] 具体开通标准：
- 店铺等级要求：[需确认]
- 历史发货率要求：[需确认]
- 保证金要求：[需确认]
- 类目限制：部分类目不支持预售

#### 4.3 预售发货时间设置

| 预售类型 | 发货时间范围 | 说明 |
|---------|-------------|-----|
| **普通预售** | 支付后7-30天 | 常规预售商品 |
| **定金预售** | 尾款支付后[需确认]天内 | 先付定金，后付尾款 |
| **团购预售** | 成团后[需确认]天内 | 拼团成功后计算 |
| **定制预售** | 按定制周期约定 | 需明确告知消费者 |

#### 4.4 预售商品发布规范
- **标题规范**：须在标题中明确标注"预售"字样
- **发货时间**：须明确承诺具体发货日期
- **发货时效**：承诺发货时间不得超过15天（普通预售）
- **库存要求**：预售库存须真实可用

**页面展示要求：**
- 明确标注"预售"字样
- 清晰展示发货时间
- 说明预售原因（如定制、生产中等）
- 设置预售专属价格

**发货要求：**
- 必须在承诺时间内发货
- 延迟发货按正常规则处罚
- 建议提前备货，避免超期

#### 4.5 预售违规处罚

| 违规类型 | 处罚措施 |
|---------|---------|
| **超期未发货** | 按延迟发货规则处罚 |
| **虚假预售** | 无货预售按缺货处罚 |
| **预售信息不实** | 警告，要求整改 |
| **频繁预售违规** | 限制预售权限 |

### 五、不可抗力申诉

#### 5.1 不可抗力范围
- **自然灾害**：地震、洪水、台风、暴雪等
- **公共卫生事件**：疫情、传染病爆发等
- **政府管制**：交通管制、封控措施、政府禁令等
- **物流中断**：快递公司停运、网点关闭、物流罢工等
- **其他因素**：战争、罢工等不可预见事件

#### 5.2 申诉条件
- **时效要求**：须在不可抗力事件发生后 **7天内** 提交申诉 [需内部资料确认]
- **证明材料**：须提供官方证明文件
- **影响范围**：须证明不可抗力与延迟发货的直接因果关系

#### 5.3 申诉材料
- **政府公告**：政府部门发布的管制公告、通知
- **物流证明**：快递公司出具的停运证明
- **媒体报道**：权威媒体对事件的报道
- **其他证明**：能证明不可抗力事件的材料

#### 5.4 申诉流程
1. **登录商家后台**：进入拼多多商家后台
2. **进入申诉页面**：找到违规处罚申诉入口 [需内部资料确认] 具体路径
3. **提交申诉**：填写申诉原因并上传证明材料
4. **等待审核**：平台在3-5个工作日内审核 [需内部资料确认]
5. **结果通知**：审核结果通过站内信或短信通知

#### 5.5 申诉结果处理
- **申诉成功**：撤销处罚，恢复店铺权益
- **申诉失败**：维持原处罚决定
- **补充材料**：可能要求补充更多证明材料

#### 5.6 缺货报备流程

```
发现缺货 → 立即报备 → 平台审核 → 处理结果
    ↓
报备方式：
1. 商家后台 → 订单管理 → 缺货报备
2. 填写缺货原因和证明材料
3. 提交平台审核

审核结果：
- 通过：按报备标准处理
- 不通过：按正常缺货处罚
```

### 六、商家合规建议

#### 6.1 库存管理
- 实时同步库存数据，避免超卖
- 设置安全库存预警
- 及时下架无库存商品

#### 6.2 发货管理
- 建立发货时效监控机制
- 优先处理临近超时的订单
- 与多家物流公司合作，确保揽收时效

#### 6.3 异常处理
- 发现无法按时发货时主动联系买家
- 及时协商解决方案（延期/退款）
- 保留沟通记录作为申诉凭证
