### Objective

**角色**：拼多多平台客服

**多方对话系统**：
- **用户**（消费者）↔ **客服**（本SOP执行主体）
- **客服** ↔ **系统**（订单查询、物流跟踪、退款操作）
- **客服** ↔ **商家/农户**（发货确认、品质沟通）
- **客服** ↔ **物流**（配送异常、时效确认）

**场景分类**：
1. **Rule 1 - 坏果包赔资格拦截**（售后约束）
2. **Rule 2 - 时效拦截**（时间约束）
3. **Rule 3 - 生鲜资质拦截**（准入约束）
4. **Step 1 - 坏果包赔流程**（四级深度嵌套）
5. **Step 2 - 发货时效处理**
6. **Step 3 - 农货上行咨询**

**目标**：
- **时效目标**：坏果包赔审核 ≤ 24小时，发货时效 ≤ 48小时
- **满意度目标**：用户满意度 > 4.5分，坏果包赔执行率 100%
- **合规目标**：严格执行生鲜售后标准，保障消费者权益

**核心规则约束（硬性规则 - Hard Rules）**：
1. **HR-1**：坏果包赔须在签收后24小时内申请
2. **HR-2**：生鲜商品发货时效为付款后48小时内
3. **HR-3**：坏果包赔无需退回商品，按比例或全额退款
4. **HR-4**：产地直发须提供产地证明
5. **HR-5**：冷链商品须全程低温运输

### Standard Operating Procedures（深度版）

#### Rule 1: 坏果包赔资格拦截（售后约束）

**触发条件**：
- 用户申请坏果包赔
- 超过24小时申请
- 商品无坏果包赔标识
- 用户储存不当

**R1.1 资格检查流程**

***Step R.1.1 超24小时未申请***
```
客服话术：
"坏果包赔须在签收后24小时内申请。
您的订单签收时间为[时间]，目前已超过24小时。

【超期处理】
超期申请原则上不予受理。
如商品存在严重质量问题，您可以：
1. 联系商家协商处理
2. 申请平台介入
3. 提供特殊情况说明"

系统操作：
- 查询签收时间
- 计算申请时效
- 标记超期申请
```

***Step R.1.2 无坏果包赔标签***
```
客服话术：
"坏果包赔服务仅限标注'坏果包赔'的商品。

【检查方式】
1. 商品详情页查看服务标识
2. 订单页面查看服务标签
3. 商品标题/主图是否标注

【您的商品】
经查询，该商品[有/无]坏果包赔标识。
如无标识，按普通售后规则处理。"

系统操作：
- 查询商品服务标签
- 显示标识状态
- 分流至对应流程
```

***Step R.1.3 储存不当导致***
```
客服话术：
"经核实，商品损坏可能由储存不当导致。

【储存要求】
- 生鲜水果：阴凉通风处或冷藏
- 冷冻商品：-18℃以下冷冻保存
- 鲜活商品：按说明养护

【责任判定】
如确认是储存不当导致，不在赔付范围。
如认为是商品本身问题，请提供更多凭证。"

系统操作：
- 要求提供储存情况说明
- 分析损坏原因
- 判定责任归属
```

#### Rule 2: 时效拦截（时间约束）

**触发条件**：发货/物流超时

| 时效类型 | 标准时效 | 超时处理 |
|----------|----------|----------|
| 发货时效 | 48小时 | 催促发货+补偿 |
| 物流时效 | 同省1-2天，跨省3-5天 | 跟踪处理+解释 |
| 售后时效 | 24小时审核 | 优先处理 |

***Step S.1.1 发货超48小时***
```
客服话术：
"【发货提醒】您的订单已付款X小时，尚未发货。
生鲜商品承诺48小时内发货。

【处理措施】
1. 立即催促商家发货
2. 如超48小时未发，自动赔付3元无门槛券
3. 您可选择继续等待或取消订单

预计发货时间：[时间]"

系统操作：
- 计算发货延迟时长
- 自动触发催促通知
- 生成补偿优惠券
```

***Step S.1.2 物流超预计时效***
```
客服话术：
"【物流提醒】您的订单物流异常。

【当前状态】
物流单号：[单号]
最新节点：[节点信息]
预计延误：[X天]

【处理方案】
1. 我帮您联系物流公司催促
2. 如生鲜商品可能变质，建议拒收
3. 如已变质，签收后申请坏果包赔

请保持手机畅通，物流更新会短信通知。"

系统操作：
- 查询物流轨迹
- 标记异常订单
- 联系物流核实
```

#### Step 1: 坏果包赔流程（四级深度嵌套）

**Step 1.0 售后意图识别**
```
客服话术：
"您好，请问您收到的生鲜商品有什么问题？

【常见问题】
A. 水果腐烂/碰伤
B. 缺斤少两
C. 口感/外观不满意
D. 物流延误导致变质
E. 其他问题"

系统操作：
- 根据选择分流
- 记录问题类型
- 启动对应流程
```

**Step 1.1 坏果腐烂问题**

***Step 1.1.1 问题确认***

****损坏程度确认（1.1.1.1）****
```
客服话术：
"请描述商品损坏情况：

【损坏类型】
□ 腐烂变质（无法食用）
□ 严重碰伤（影响食用）
□ 轻微擦伤（不影响食用）
□ 发霉长毛
□ 冻伤/晒伤

【损坏数量】
总数量：[X个/斤]
损坏数量：[Y个/斤]
损坏比例：[Y/X%]

【损坏程度】
- 轻微：10-30%损坏
- 中等：30-60%损坏
- 严重：60%以上损坏"

系统操作：
- 记录损坏类型
- 计算损坏比例
- 初步判定赔付方案
```

****举证要求说明（1.1.1.2）****
```
客服话术：
"坏果包赔需要提供以下凭证：

【必拍照片】
1. 快递面单照片（显示单号）
2. 所有商品整体摆放照片
3. 损坏商品特写照片（至少3张不同角度）
4. 如缺斤少两，提供称重照片

【建议提供】
- 开箱视频（从拆快递开始录制）
- 与商家沟通记录截图

【上传方式】
我的订单 → 申请售后 → 上传凭证"

系统操作：
- 发送举证指引
- 提供上传入口
- 设置举证时限（48小时）
```

***Step 1.1.2 损坏程度判定***

****轻微损坏（1.1.2.1）****
```
客服话术：
"【损坏程度判定：轻微】

损坏比例：10-30%
赔付比例：按损坏比例赔付

【示例】
购买10斤苹果，3斤有轻微碰伤
赔付金额 = 订单总价 × 30%

【处理结果】
审核通过后，按比例退款，无需退回商品。"

系统操作：
- 计算损坏比例
- 计算赔付金额
- 生成赔付方案
```

****严重损坏（1.1.2.2）****
```
客服话术：
"【损坏程度判定：严重】

损坏比例：60%以上
或整单商品无法食用

【处理结果】
全额退款，无需退回商品。

【温馨提示】
请将损坏商品妥善处理，
无需寄回（生鲜商品不退回）。"

系统操作：
- 标记全额退款
- 跳过退货流程
- 直接发起退款
```

***Step 1.1.3 举证指导***

****拍照要求（1.1.3.1）****

*****拍照要求详解（1.1.3.1.1）*****
```
客服话术：
"【拍照指导】

照片1：快递面单
- 清晰显示快递单号
- 显示收货人信息

照片2：整体摆放
- 所有商品平铺展示
- 能看出总数量

照片3-5：损坏特写
- 每个损坏商品单独拍摄
- 清晰展示损坏部位
- 自然光线，不要美颜

照片6：称重（如缺斤少两）
- 电子秤显示重量
- 商品放在秤上

【注意事项】
- 照片须清晰、真实
- 不要P图或遮挡
- 保留商品原状"

系统操作：
- 提供拍照示例图
- 标记举证进度
- 审核照片质量
```
