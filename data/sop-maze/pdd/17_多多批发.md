# 拼多多多多批发 SOP（公开信息版）

## Objective

为拼多多B端批发业务"多多批发"提供标准化操作流程指南，帮助批发商家了解入驻条件、价格体系、大宗采购流程及账期管理规则，同时协助企业客户完成认证并高效完成批量采购。

## Standard Operating Procedures

### 一、商家入驻

#### 1.1 入驻条件

| 条件类型 | 具体要求 | 说明 |
|---------|---------|------|
| **主体资质** | 企业营业执照 | 个体工商户/企业法人 |
| **经营资质** | 相关行业许可证 | 食品经营许可、工业品生产许可等 |
| **品牌资质** | 商标注册证/授权书 | 自有品牌或品牌授权 |
| **批发资质** | 具备批发经营能力 | [需内部资料确认] 具体资质要求 |
| **资金实力** | 一定的资金实力证明 | 确保供货稳定性 |
| **仓储能力** | 具备一定仓储规模 | 满足大宗订单发货需求 |

#### 1.2 入驻流程

```
步骤1：登录拼多多商家后台
    ↓
步骤2：选择"多多批发"业务入口
    ↓
步骤3：提交入驻申请
    ├── 填写企业基本信息
    ├── 上传营业执照
    ├── 上传行业许可证
    ├── 提交品牌资质证明
    └── 填写批发经营能力说明
    ↓
步骤4：平台资质审核（3-7个工作日）
    ↓
步骤5：签署批发业务协议
    ↓
步骤6：缴纳保证金 [需内部资料确认] 具体金额
    ↓
步骤7：店铺开通，开始运营
```

#### 1.3 批发资质要求

**基础资质**：
- 营业执照（经营范围含批发/零售）
- 法人身份证
- 银行开户许可证

**行业特殊资质**：
- 食品类：食品经营许可证
- 化妆品类：化妆品生产/经营许可证
- 3C数码：3C认证证书
- 医疗器械：医疗器械经营许可证
- [需内部资料确认] 其他类目特殊要求

### 二、批发价格体系

#### 2.1 价格结构

```
┌─────────────────────────────────────────────────────────┐
│                      价格层级                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   零售价 ──────── 单件购买价格（参考价）                  │
│      │                                                  │
│      ▼                                                  │
│   批发价 ──────── 达到起批量后的优惠价格                  │
│      │                                                  │
│      ▼                                                  │
│   阶梯价 ──────── 根据采购量设置多档价格                  │
│      │                                                  │
│      ▼                                                  │
│   协议价 ──────── 长期合作大客户专属价格                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### 2.2 阶梯定价规则

| 采购量级 | 折扣力度 | 适用对象 |
|---------|---------|---------|
| **小批** | 批发价（9-9.5折） | 小型零售商、个体户 |
| **中批** | 中批价（8.5-9折） | 中型商超、便利店 |
| **大批** | 大批价（8-8.5折） | 大型连锁、经销商 |
| **特批** | 协议价（面议） | 战略合作客户 |

#### 2.3 价格设置规范

- **批发价要求**：须低于或等于其他批发渠道价格
- **价格稳定性**：活动期间价格锁定，不得随意调整
- **价格监控**：平台定期比对市场价格
- **违规处罚**：价格欺诈将被下架商品或清退 [需内部资料确认] 具体处罚标准

### 三、起批量要求

#### 3.1 起批类型

| 起批类型 | 说明 | 适用场景 |
|---------|------|---------|
| **按件起批** | 单SKU最低购买数量 | 标准商品 |
| **按金额起批** | 订单最低金额要求 | 多SKU混批 |
| **混批起批** | 多商品组合达到数量/金额 | 品类丰富度要求 |

#### 3.2 起批量设置建议

| 商品类型 | 建议起批量 | 说明 |
|---------|-----------|------|
| **快消品** | 24/48/96件 | 整箱/整件批发 |
| **日用品** | 12/24/48件 | 标准包装倍数 |
| **服装鞋帽** | 5/10/20件 | 多尺码组合 |
| **数码3C** | 5/10件 | 高单价商品 |
| **大件商品** | 1/2/3件 | 物流限制 |

#### 3.3 起批规则

- **最低起批**：单商品/订单须达到最低起批量
- **混批规则**：支持同店铺多商品混批达到起批要求
- **补货规则**：[需内部资料确认] 是否支持小批量补货

### 四、大宗采购流程

#### 4.1 采购流程图

```
企业客户认证
    ↓
浏览/搜索商品
    ↓
加入进货单
    ↓
确认订单信息
    ├── 商品清单核对
    ├── 收货地址确认
    ├── 发票信息填写
    └── 账期/支付方式选择
    ↓
提交订单
    ↓
商家确认订单
    ↓
支付货款/账期扣款
    ↓
商家发货
    ↓
物流配送
    ↓
确认收货
    ↓
评价/售后
```

#### 4.2 订单处理时效

| 环节 | 时效要求 | 说明 |
|-----|---------|------|
| **订单确认** | 24小时内 | 商家须及时处理订单 |
| **发货时效** | 48-72小时 | 大宗订单可适当延长 |
| **物流时效** | 3-7天 | 根据距离和物流方式 |
| **签收确认** | 7天内 | 超时自动确认收货 |

#### 4.3 大宗订单特殊处理

- **订单拆分**：超库存订单可协商分批发货
- **定制需求**：支持包装定制、贴牌等需求 [需内部资料确认] 具体流程
- **预约配送**：支持约定配送时间

### 五、企业客户认证

#### 5.1 认证类型

| 认证类型 | 所需材料 | 认证权益 |
|---------|---------|---------|
| **企业认证** | 营业执照 | 批发价采购、账期服务 |
| **个体工商户** | 个体户执照 | 批发价采购 |
| **事业单位** | 组织机构代码证 | 对公采购、发票服务 |
| **政府采购** | 政府采购资质 | 专属通道、合规保障 |

#### 5.2 认证流程

```
步骤1：登录多多批发客户端
    ↓
步骤2：进入"企业认证"页面
    ↓
步骤3：选择认证类型
    ↓
步骤4：上传资质材料
    ├── 营业执照
    ├── 法人身份证
    └── 其他证明材料
    ↓
步骤5：填写企业信息
    ↓
步骤6：提交审核（1-3个工作日）
    ↓
步骤7：认证通过，享受批发权益
```

#### 5.3 认证权益

- **价格权益**：享受批发价/阶梯价
- **账期服务**：符合条件的客户可申请账期
- **专属客服**：大客户专属服务通道
- **优先发货**：认证客户订单优先处理 [需内部资料确认] 具体权益

### 六、账期管理

#### 6.1 账期类型

| 账期类型 | 账期时长 | 适用条件 |
|---------|---------|---------|
| **现付** | 即时支付 | 所有客户 |
| **周结** | 7天账期 | 认证企业客户 |
| **月结** | 30天账期 | 信用良好客户 |
| **季度结** | 90天账期 | 战略合作大客户 [需内部资料确认] |

#### 6.2 账期申请条件

- **企业认证**：须完成企业实名认证
- **信用评估**：平台信用评分达标
- **交易记录**：有一定交易历史
- **保证金**：部分账期需缴纳保证金 [需内部资料确认] 具体要求

#### 6.3 账期管理流程

```
账期申请
    ↓
信用评估
    ↓
额度审批
    ↓
签署账期协议
    ↓
下单使用账期
    ↓
账期到期提醒
    ↓
还款/自动扣款
    ↓
信用更新
```

#### 6.4 账期风险管控

- **额度管理**：根据信用评估设定账期额度
- **到期提醒**：提前3/1天提醒还款
- **逾期处理**：逾期将暂停账期服务并收取滞纳金 [需内部资料确认] 具体费率
- **信用记录**：逾期影响平台信用评级

---

### 七、物流配送（大件物流）

#### 7.1 物流模式

| 物流模式 | 适用场景 | 特点 |
|---------|---------|------|
| **快递配送** | 小件批发订单 | 时效快，送货上门 |
| **零担物流** | 中批量订单 | 成本适中，网点自提 |
| **整车运输** | 大批量订单 | 成本低，时效可控 |
| **专线物流** | 固定线路大宗订单 | 定制化服务 |

#### 7.2 大件物流特殊处理

**发货要求**：
- 包装加固：确保长途运输安全
- 托盘/木架：大件须打托盘或木架
- 物流标签：清晰标注收发货信息

**配送服务**：
- 送货上楼：[需内部资料确认] 是否提供
- 安装服务：[需内部资料确认] 是否支持
- 代收货款：支持物流代收货款

#### 7.3 物流时效与费用

| 配送范围 | 时效 | 费用承担 |
|---------|------|---------|
| **同城** | 1-2天 | 协商确定 |
| **省内** | 2-3天 | 协商确定 |
| **跨省** | 3-7天 | 协商确定 |
| **偏远地区** | 5-10天 | 协商确定 |

#### 7.4 物流异常处理

- **破损理赔**：签收时验货，破损拒收
- **丢失赔偿**：按保价金额或实际价值赔偿
- **延误处理**：协商补偿方案
