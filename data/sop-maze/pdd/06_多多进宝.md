## Standard Operating Procedures

### 一、推手入驻

#### 1.1 入驻条件

| 入驻类型 | 条件要求 | 所需资料 |
|---------|---------|---------|
| **个人推手** | 年满18周岁，实名认证 | 身份证、手机号、银行卡 |
| **企业推手** | 企业资质，对公账户 | 营业执照、法人身份证、对公账户 |
| **媒体平台** | 自有流量平台/APP | 平台资质、流量证明、合作协议 |
| **社群推手** | 拥有社群资源（微信群/QQ群） | 社群规模证明、运营方案 |

#### 1.2 入驻流程

```
步骤1：访问多多进宝官网
    ↓
步骤2：点击"我要推广" / "推手入驻"
    ↓
步骤3：选择入驻类型（个人/企业）
    ↓
步骤4：填写基本信息（姓名/企业名、联系方式）
    ↓
步骤5：实名认证（上传身份证/营业执照）
    ↓
步骤6：绑定结算账户（银行卡/对公账户）
    ↓
步骤7：签署推广协议
    ↓
步骤8：等待审核（1-3个工作日）
    ↓
步骤9：审核通过，获取推广权限
```

### 二、推广链接

#### 2.1 链接生成方式

**方式一：多多进宝官网**

```
1. 登录多多进宝官网 (jinbao.pinduoduo.com)
2. 进入"选品库"浏览商品
3. 选择商品点击"立即推广"
4. 设置推广位（如微信群、朋友圈）
5. 生成推广链接/二维码/淘口令
6. 复制分享至目标渠道
```

**方式二：多多进宝APP**

```
1. 下载多多进宝APP
2. 登录推手账号
3. 搜索或浏览商品
4. 点击"推广"按钮
5. 选择分享方式（链接/图片/口令）
6. 一键分享至社交平台
```

**方式三：API接口**（适用于媒体平台）

```
1. 申请API权限
2. 获取AppKey和AppSecret
3. 调用商品查询接口
4. 生成带有tracking参数的推广链接
5. 嵌入自有平台展示
```

#### 2.2 推广链接类型

| 链接类型 | 适用场景 | 特点 |
|---------|---------|-----|
| **普通链接** | 网页/文章嵌入 | 标准URL，带tracking参数 |
| **短链接** | 短信/微信分享 | 缩短URL，便于传播 |
| **二维码** | 线下海报/朋友圈 | 扫码直达商品页 |
| **淘口令** | 微信群/QQ群 | 复制后打开APP识别 |
| **小程序卡片** | 微信生态 | 卡片形式，体验好 |

#### 2.3 链接参数说明

```
示例链接：
https://mobile.yangkeduo.com/goods.html?goods_id=123456&pid=推手ID&cpsSign=签名&duoduo_type=2

关键参数：
- goods_id: 商品ID
- pid: 推手ID（推广位标识）
- cpsSign: 推广签名（防篡改）
- duoduo_type: 推广类型标识
```

### 三、佣金结算

#### 3.1 结算规则

| 结算项目 | 规则说明 |
|---------|---------|
| **结算模式** | CPS（按成交付费），用户确认收货后结算 |
| **结算周期** | 用户确认收货后T+1或T+7结算（视商家设置） |
| **结算比例** | 商家设置的佣金比例（商品售价的百分比） |
| **最低提现** | [需内部资料确认] 通常有最低提现金额限制 |
| **提现方式** | 银行卡/支付宝/对公账户 |

#### 3.2 佣金计算示例

```
场景：推手A推广商品B，售价100元，佣金比例20%

计算过程：
- 商品售价：100元
- 佣金比例：20%
- 理论佣金：100 × 20% = 20元
- 平台服务费：[需内部资料确认] 通常抽取10%左右
- 推手实得：20 × (1 - 10%) = 18元

结算时间线：
Day 0: 用户通过推广链接下单
Day 1-3: 商家发货，物流运输
Day 4: 用户签收并确认收货
Day 5: 佣金进入推手账户（T+1结算）
Day 12: 推手申请提现
Day 13-15: 提现到账
```

#### 3.3 订单状态与佣金

| 订单状态 | 佣金状态 | 说明 |
|---------|---------|-----|
| **待付款** | 未生成 | 用户未付款，无佣金 |
| **已付款** | 待结算 | 用户已付款，等待确认收货 |
| **已发货** | 待结算 | 物流中，等待确认收货 |
| **已签收** | 待结算 | 用户签收，等待确认收货 |
| **已确认收货** | 可结算 | 佣金进入账户 |
| **已退款** | 失效 | 订单退款，佣金取消 |
| **已结算** | 已到账 | 佣金已可提现 |

#### 3.4 结算报表

推手可在后台查看：
- 实时推广数据（点击量、订单数、预估佣金）
- 历史结算记录
- 商品推广效果排行
- 渠道效果分析

### 四、招商团长

#### 4.1 招商团长定义

招商团长是多多进宝平台上的高级推广者，负责组织推手团队、对接商家资源、策划推广活动，从推广佣金中获得额外分成。

#### 4.2 团长入驻条件

[需内部资料确认] 具体入驻门槛

- 推广经验要求：通常需要有一定推广业绩
- 团队规模：需证明有稳定的推手团队
- 商家资源：需展示商家合作能力
- 保证金：可能需要缴纳保证金

#### 4.3 团长核心职责

```
┌────────────────────────────────────────────────────────┐
│                    招商团长职责                         │
├────────────────────────────────────────────────────────┤
│                                                         │
│  1. 商家招商                                           │
│     ├── 寻找优质商家合作                               │
│     ├── 谈判佣金比例和推广方案                         │
│     └── 签订合作协议                                   │
│                                                         │
│  2. 活动策划                                           │
│     ├── 设计推广活动方案                               │
│     ├── 协调商家资源（优惠券/赠品）                    │
│     └── 制定推广节奏和目标                             │
│                                                         │
│  3. 推手管理                                           │
│     ├── 招募和培训推手                                 │
│     ├── 分配推广任务                                   │
│     └── 监控推广效果                                   │
│                                                         │
│  4. 数据分析                                           │
│     ├── 跟踪活动数据                                   │
│     ├── 优化推广策略                                   │
│     └── 输出活动报告                                   │
│                                                         │
└────────────────────────────────────────────────────────┘
```

#### 4.4 团长收益模式

| 收益类型 | 说明 | 计算方式 |
|---------|-----|---------|
| **服务费分成** | 从推手佣金中抽取 | 通常为推手佣金的10%-30% |
| **商家服务费** | 商家额外支付的服务费 | 按合作协议约定 |
| **业绩奖励** | 平台对优秀团长的奖励 | 按月度/季度业绩排名 |

#### 4.5 招商活动流程

```
阶段1：招商准备
├── 确定目标品类和商家类型
├── 制定招商政策（佣金比例、活动周期）
└── 准备招商材料

阶段2：商家对接
├── 联系商家介绍多多进宝
├── 展示推广案例和数据
├── 谈判合作条件
└── 签订合作协议

阶段3：活动执行
├── 商品上架选品库
├── 组织推手推广
├── 监控数据表现
└── 及时调整策略

阶段4：结算复盘
├── 核对推广数据
├── 结算佣金费用
├── 输出活动报告
└── 维护商家关系
```
