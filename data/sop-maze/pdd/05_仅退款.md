# 拼多多仅退款 SOP

## Objective
规范拼多多平台"仅退款"售后处理流程，明确退款条件、品质退款判定标准、恶意退款识别机制及商家申诉途径，保障消费者权益的同时维护商家合法利益。

## Standard Operating Procedures

### 一、仅退款条件

#### 1.1 适用场景

| 场景类型 | 具体条件 | 处理时效 |
|---------|---------|---------|
| **未发货退款** | 订单状态为"待发货"，消费者申请退款 | 系统自动通过，即时退款 |
| **发货后未签收** | 物流显示未签收，消费者拒收或申请退款 | 物流拦截成功后退款 |
| **品质问题** | 商品存在质量问题，消费者提供凭证 | 平台审核后处理 |
| **描述不符** | 商品与描述严重不符，影响使用 | 平台介入判定 |
| **假冒品牌** | 商品涉嫌假冒品牌，经平台核实 | 平台直接处理 |

#### 1.2 退款金额规则

- **全额退款**：商品全额退还，优惠券按比例返还
- **部分退款**：协商后退还部分金额，商品由消费者保留
- **退货运费**：品质问题商家承担，非品质问题消费者承担

#### 1.3 自动退款机制

```
触发条件（满足任一）：
├── 订单金额 ≤ 设定阈值（如20元）
├── 商家超时未处理（默认48小时）
├── 商家同意退款
├── 平台判定商家责任
└── 系统识别为品质退款
```

---

### 二、品质退款

#### 2.1 品质退款定义

品质退款是指因商品存在质量问题、描述不符、假冒品牌等原因导致的退款，此类退款计入店铺品质退款率，影响店铺权重。

#### 2.2 品质退款判定标准

| 判定维度 | 具体标准 | 证据要求 |
|---------|---------|---------|
| **质量问题** | 商品破损、功能故障、变质等 | 照片/视频证明 |
| **描述不符** | 规格、材质、颜色等与描述差异明显 | 对比截图 |
| **假冒品牌** | 非正品或未经授权销售 | 品牌方鉴定/平台抽检 |
| **缺件少件** | 订单商品数量与实际收到不符 | 开箱视频/称重记录 |
| **过期临期** | 食品/化妆品超过保质期或临期未标注 | 商品日期照片 |

#### 2.3 品质退款率计算

```
品质退款率 = 品质退款订单数 / 总退款订单数 × 100%

影响指标：
- 店铺综合评分
- 搜索排名权重
- 活动报名资格
- 保证金要求
```

#### 2.4 品质退款申诉

商家可在退款完成后规定时间内（通常为7天）发起申诉：

1. **准备材料**：发货凭证、物流证明、商品质检报告等
2. **提交申诉**：商家后台 → 售后管理 → 退款申诉
3. **平台审核**：3-5个工作日内完成审核
4. **申诉结果**：成功则不计入品质退款，失败则维持原判

### 三、恶意退款识别

#### 3.1 恶意退款特征

| 特征类型 | 具体表现 |
|---------|---------|
| **高频退款** | 同一用户短期内多次申请退款 |
| **虚假凭证** | 提供伪造的商品问题照片/视频 |
| **空包退货** | 退回商品与订单不符或为空包 |
| **敲诈勒索** | 以差评/投诉威胁要求额外赔偿 |
| **职业打假** | 有组织、有预谋的批量投诉退款 |

#### 3.2 平台识别机制

- **用户画像分析**：退款频率、退款原因分布、账户关联度
- **凭证真实性校验**：图片EXIF信息、视频时间戳分析
- **行为模式识别**：异常下单时间、收货地址集中度
- **商家举报通道**：商家可标记可疑订单供平台核查

#### 3.3 商家应对措施

1. **证据保全**：发货前拍照/录像，保留物流凭证
2. **及时举报**：发现异常立即向平台举报
3. **申诉维权**：对判定结果不认可的及时申诉
4. **黑名单管理**：[需内部资料确认] 商家后台是否有用户黑名单功能

### 四、商家申诉流程

#### 4.1 申诉入口

```
商家后台路径：
拼多多商家版 APP/网页 → 售后管理 → 退款/售后订单 → 选择订单 → 申诉
```

#### 4.2 申诉材料要求

| 申诉类型 | 所需材料 |
|---------|---------|
| **未收到货申诉** | 物流签收底单、签收人信息、监控录像 |
| **商品无问题申诉** | 发货前商品照片、质检报告、物流包装照片 |
| **用户责任申诉** | 用户承认错误的聊天记录、用户操作不当证明 |
| **凭证伪造申诉** | 原始凭证、凭证真实性对比分析 |

#### 4.3 申诉处理时效

- **提交审核**：1-3个工作日
- **补充材料**：收到通知后48小时内
- **最终结果**：材料齐全后3-5个工作日

#### 4.4 申诉结果类型

- **申诉成功**：退款不计入品质退款，资金返还商家
- **申诉失败**：维持原判，计入品质退款
- **部分成功**：双方各承担部分责任
