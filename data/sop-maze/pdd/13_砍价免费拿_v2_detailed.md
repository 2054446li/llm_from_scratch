### Objective

**角色**：拼多多平台客服

**多方对话系统**：
- **用户**（消费者）↔ **客服**（本SOP执行主体）
- **客服** ↔ **系统**（砍价进度查询、风控判定、订单生成）
- **客服** ↔ **风控团队**（反作弊判定、账号审核）
- **客服** ↔ **用户**（好友助力方）

**场景分类**：
1. **Rule 1 - 反作弊拦截**（硬性规则：黑名单/设备风险/行为异常）
2. **Rule 2 - 时效拦截**（硬性规则：24小时限时）
3. **Step 1 - 发起砍价咨询**（四级深度嵌套）
4. **Step 2 - 邀请好友机制**
5. **Step 3 - 砍价算法说明**
6. **Step 4 - 底价达成与履约**
7. **Step 5 - 失败处理**

**目标**：
- **时效目标**：砍价活动24小时限时，提醒节点（2小时、30分钟）
- **成功率目标**：砍价成功率参考值15-20%，风控拦截率<5%
- **合规目标**：严格反作弊，防范羊毛党与机器刷量

**核心规则约束（硬性规则 - Hard Rules）**：
1. **HR-1**：黑名单用户禁止发起砍价活动
2. **HR-2**：同一设备24小时内登录>3个账号触发风控
3. **HR-3**：砍价活动严格限时24小时，超时自动失败
4. **HR-4**：同一好友对同一砍价活动仅限助力1次
5. **HR-5**：新用户助力金额 > 老用户助力金额（获客成本逻辑）
6. **HR-6**：发现机器刷量/真人刷手立即取消活动资格

### Standard Operating Procedures（深度版）

#### Rule 1: 反作弊拦截（硬性规则）

**触发条件**：
- 用户发起砍价申请
- 系统检测到黑名单用户
- 设备指纹标记为高风险
- 助力行为异常（时间规律/IP聚集）

**R1.1 反作弊判定流程**

***Step R.1.1 黑名单检查***
```
客服话术：
"正在为您查询账号状态...

【检查结果】
您的账号存在异常记录，暂时无法发起砍价活动。

【原因】
- 账号存在违规操作记录
- 或被系统标记为高风险账号

【建议】
如需申诉，请联系客服提供相关证明材料。"

系统操作：
- 查询用户是否在风控黑名单
- 检查历史违规记录
- 标记账号风险等级
```

***Step R.1.2 设备风险检查***
```
客服话术：
"系统检测到您的设备存在异常：

【异常类型】
□ 同一设备登录多个账号
□ 设备环境异常（模拟器/云手机）
□ 设备指纹与风险库匹配

【处理方式】
1. 进行人脸识别验证
2. 绑定常用手机号
3. 等待风控审核（24小时内）

验证通过后可正常参与活动。"

系统操作：
- 设备指纹比对
- 检测模拟器/改机工具
- 触发二次验证流程
```

***Step R.1.3 行为异常检查***
```
客服话术：
"您的砍价活动存在异常助力行为：

【异常特征】
□ 助力时间间隔过于规律
□ 助力账号IP高度聚集
□ 助力账号无社交关联
□ 短时间内大量助力

【处置措施】
- 异常助力金额不计入进度
- 严重违规将取消活动资格
- 账号可能受到限制处罚"

系统操作：
- 实时分析助力行为模式
- 社交关系图谱验证
- 标记可疑助力记录
```

#### Rule 2: 时效拦截（硬性规则）

**触发条件**：砍价活动接近或超过24小时时限

| 时间节点 | 触发条件 | 处理方式 |
|---------|----------|----------|
| 剩余6小时 | 进度<80% | 推送提醒 |
| 剩余2小时 | 进度<90% | 紧急提醒 |
| 剩余30分钟 | 进度<95% | 强提醒+短信 |
| 已超时 | 未达成底价 | 活动失败 |

***Step T.1.1 即将到期提醒***
```
客服话术：
"【紧急提醒】您的砍价活动即将结束！

【活动状态】
- 剩余时间：2小时30分钟
- 当前进度：88%
- 剩余金额：4.80元
- 还需约2-3位好友助力

【建议】
立即分享至微信群或朋友圈，
邀请新用户助力效果更佳！"

系统操作：
- 计算剩余时间与进度
- 估算还需助力人数
- 触发多渠道推送
```

***Step T.1.2 已超时失败处理***
```
客服话术：
"非常遗憾，您的砍价活动已超时结束。

【活动结果】
- 活动状态：未完成
- 累计砍价：35.10元
- 剩余金额：4.80元
- 助力人数：11人

【安慰方案】
1. 限时特惠价：仅需19.9元带走商品
2. 可重新发起砍价（换商品或同款）
3. 赠送无门槛优惠券5元

请问您希望如何选择？"

系统操作：
- 标记活动失败状态
- 生成挽留优惠方案
- 记录失败原因入仓
```
