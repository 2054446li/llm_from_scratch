## Objective

本文档旨在规范饿了么会员体系（含超级吃货卡、超级会员）的标准操作流程，确保用户能够清晰了解会员权益、便捷完成开通/续费，并合理使用各项会员特权。适用于所有饿了么会员相关服务场景。

**核心目标：**
- 提供清晰的会员权益说明与对比
- 简化会员开通与续费流程
- 规范红包/优惠券领取与使用规则
- 建立透明的积分（吃货豆）获取与兑换机制
- 完善会员等级成长体系
- 建立合理的退款与退订机制
- 提升会员用户体验与满意度

### 3. 红包/优惠券使用

#### 3.1 红包类型说明
| 红包类型 | 获取方式 | 使用规则 | 限制条件 |
|---------|---------|---------|---------|
| 会员红包 | 每月自动发放 | 无门槛，订单金额≥红包面额 | 限本人使用 |
| 超级红包 | 超级会员专属 | 可膨胀，膨胀后有门槛 | 膨胀后7天有效 |
| 活动红包 | 平台活动领取 | 按活动规则使用 | 限指定品类/商家 |
| 商家红包 | 商家发放 | 限该商家使用 | 与会员红包不可叠加 |

#### 3.2 红包使用流程
```
选择商品 ──▶ 进入结算页 ──▶ 选择可用红包 ──▶ 系统自动抵扣 ──▶ 确认支付金额 ──▶ 完成订单
```

#### 3.3 红包使用限制
| 限制类型 | 具体规则 |
|---------|---------|
| 门槛限制 | 无门槛红包：订单金额≥红包面额；膨胀红包：满足膨胀后门槛 |
| 品类限制 | 部分红包仅限外卖/果蔬/商超等指定品类 |
| 商家限制 | 部分商家不参与会员红包活动（以页面展示为准）|
| 叠加限制 | 每单限用1张会员红包，不可与商家红包叠加 |
| 地域限制 | 部分红包限指定城市/区域使用 |
| 时段限制 | 部分红包限指定时段使用（如午市/晚市）|

#### 3.4 红包过期提醒
```
到期前3天 ──▶ App Push提醒
到期前1天 ──▶ 短信提醒（高价值用户）
到期当天 ──▶ 首页弹窗提醒
```

### 6. 续费管理

#### 6.1 续费方式
| 续费方式 | 说明 | 扣费时间 | 价格 |
|---------|------|---------|------|
| 自动续费（连续包月） | 到期自动扣费续期 | 到期前1天 | 通常有优惠 |
| 自动续费（连续包季） | 每季度自动扣费 | 到期前1天 | 季卡优惠价 |
| 手动续费 | 用户主动操作续费 | 任意时间 | 标准价格 |
| 提前续费 | 在有效期内续费 | 立即生效 | 可能享受活动价 |

#### 6.2 自动续费规则
```
到期前7天 ──▶ App内消息提醒
到期前3天 ──▶ Push通知提醒
到期前1天 ──▶ 尝试扣费（余额/绑定支付渠道）
    │
    ├── 扣费成功 ──▶ 续期成功 ──▶ 发送确认通知 ──▶ 新周期权益发放
    │
    └── 扣费失败 ──▶ 重试机制（当天再试2次）──▶ 仍失败则到期失效
```

#### 6.3 提前续费处理 [需内部资料确认]
- **提前续费**：当前会员期延长，权益累计
- **权益叠加**：未使用红包/返豆权益可累计至新周期
- **价格保护**：续费按当前活动价格执行
- **类型变更**：支持升级（补差价），不支持降级续费

#### 6.4 续费优惠
| 优惠类型 | 优惠内容 | 适用条件 |
|---------|---------|---------|
| 连续包月优惠 | 月费8-9折 | 保持自动续费状态 |
| 年卡优惠 | 相当于6-7折 | 购买年卡 |
| 老用户回馈 | 额外红包/返豆 | 续费满X个月 |
| 活动期续费 | 限时特价/买赠 | 活动期间 |

#### 6.5 自动续费关闭流程
```
我的 ──▶ 超级吃货卡 ──▶ 管理自动续费 ──▶ 关闭自动续费 ──▶ 确认关闭 ──▶ 关闭成功
```

### 7. 退订规则

#### 7.1 退款条件
| 退款场景 | 退款条件 | 退款金额 |
|---------|---------|---------|
| 未使用权益 | 开通后7天内，未使用任何权益 | 全额退款 |
| 部分使用 | 已使用部分权益 | 按比例扣除后退还 |
| 服务异常 | 平台原因导致权益无法使用 | 协商退款 |
| 误购退款 | 24小时内申请 | 全额退款 |
| 自动续费退款 | 扣费后7天内申请 | 全额退款（未使用权益）|

#### 7.2 退款计算公式 [需内部资料确认]
```
可退金额 = 实付金额 - 已使用权益价值 - 已享受优惠价值

示例1（全额退款）：
实付金额：¥10
已使用红包：0张
可退金额：¥10

示例2（部分退款）：
实付金额：¥20
已使用红包：2张×¥5 = ¥10
已享受免配送费：2次×¥3 = ¥6
可退金额：¥20 - ¥10 - ¥6 = ¥4
```

#### 7.3 退款流程
```
申请退款 ──▶ 权益核查（检查已使用情况）──▶ 金额计算 ──▶ 审核确认 ──▶ 原路退回
    │                                                              │
    └── 审核不通过 ──▶ 说明原因 ──▶ 用户申诉（可选）──────────────────┘
```

#### 7.4 退款时效
| 支付方式 | 退款时效 | 到账路径 |
|---------|---------|---------|
| 余额支付 | 即时 | 饿了么余额 |
| 微信支付 | 1-3工作日 | 微信零钱/原银行卡 |
| 支付宝 | 1-3工作日 | 支付宝余额/原银行卡 |
| 银行卡 | 3-7工作日 | 原支付银行卡 |
| 花呗 | 1-3工作日 | 恢复花呗额度 |

#### 7.5 退订后权益处理
- 退订成功后，会员权益立即失效
- 未使用的红包/优惠券作废，不可恢复
- 已获取的吃货豆保留，可继续使用
- 会员等级保留，按普通用户规则计算成长值

### 合规要求

1. **价格透明**：会员价格、权益价值需明确公示，不得虚假宣传
2. **自动续费**：开通自动续费需用户明确同意，提前显著提醒扣费
3. **退款权利**：保障用户合理退款权利，简化退款流程，明确退款规则
4. **权益保障**：承诺的权益需如实兑现，不得擅自变更
5. **隐私保护**：会员消费数据不用于无关营销，保护用户隐私
6. **未成年人保护**：限制未成年人开通付费会员
7. **公平交易**：不得设置不公平、不合理的交易条件
