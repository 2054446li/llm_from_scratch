## Objective

本文档旨在规范饿了么会员体系（含超级吃货卡、超级会员）的标准操作流程，确保用户能够清晰了解会员权益、便捷完成开通/续费，并合理使用各项会员特权。适用于所有饿了么会员相关服务场景。

**核心目标：**
- 提供清晰的会员权益说明与对比
- 简化会员开通与续费流程
- 规范红包/优惠券领取与使用规则
- 建立透明的积分（吃货豆）获取与兑换机制
- 完善会员等级成长体系
- 建立合理的退款与退订机制
- 提升会员用户体验与满意度

##### 2.1.2 红包使用规则
| 规则项 | 说明 |

##### 2.2.1 膨胀规则
```
普通红包 ──▶ 选择膨胀 ──▶ 满足条件 ──▶ 金额提升
  ¥5    ──▶  点击膨胀  ──▶ 满20可用 ──▶  ¥6-¥12

##### 2.2.2 膨胀档位
| 膨胀前 | 膨胀后 | 使用门槛 | 适用场景 |

| 续费方式 | 说明 | 扣费时间 | 价格 |

#### 5.2 自动续费规则
##### 5.2.1 续费流程
```
到期前提醒 ──▶ 到期前1天扣费 ──▶ 扣费成功 ──▶ 续期成功
    │              │              │
    ▼              ▼              ▼
消息推送      余额/绑卡扣费    发送确认通知

| 失败次数 | 处理动作 |

### 6. 退款规则

#### 6.1 退款条件
| 退款场景 | 退款条件 | 退款金额 |
|---------|---------|---------|
| 未使用权益 | 开通后7天内，未使用任何权益 | 全额退款 |
| 部分使用 | 已使用部分权益 | 按比例扣除后退还 |
| 服务异常 | 平台原因导致权益无法使用 | 协商退款 |
| 误购退款 | 24小时内申请 | 全额退款 |
| 自动续费退款 | 扣费后7天内申请 | 全额退款（未使用权益）|

#### 6.2 退款计算公式
```
可退金额 = 实付金额 - 已使用权益价值 - 已享受优惠价值

示例1（全额退款）：
实付金额：¥10
已使用红包：0张
可退金额：¥10

示例2（部分退款）：
实付金额：¥20
已使用红包：2张×¥5 = ¥10
已享受免配送费：2次×¥3 = ¥6
可退金额：¥20 - ¥10 - ¥6 = ¥4
```

#### 6.3 退款流程
```
申请退款 ──▶ 权益核查（检查已使用情况）──▶ 金额计算 ──▶ 审核确认 ──▶ 原路退回
    │                                                              │
    └── 审核不通过 ──▶ 说明原因 ──▶ 用户申诉（可选）──────────────────┘
```

#### 6.4 退款时效
| 支付方式 | 退款时效 | 到账路径 |
|---------|---------|---------|
| 余额支付 | 即时 | 饿了么余额 |
| 微信支付 | 1-3工作日 | 微信零钱/原银行卡 |
| 支付宝 | 1-3工作日 | 支付宝余额/原银行卡 |
| 银行卡 | 3-7工作日 | 原支付银行卡 |
| 花呗 | 1-3工作日 | 恢复花呗额度 |

#### 6.5 退订后权益处理
- 退订成功后，会员权益立即失效
- 未使用的红包/优惠券作废，不可恢复
- 已获取的吃货豆保留，可继续使用
- 会员等级保留，按普通用户规则计算成长值
