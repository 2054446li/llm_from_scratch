## 3. Objective（业务目标）

| 目标维度 | 具体目标 | 衡量指标 |
|---------|---------|---------|
| 拉新获客 | 吸引新用户首次下单 | 新客转化率 ≥ 25% |
| 提升客单价 | 通过满减/满折刺激凑单 | 客单价提升 ≥ 15% |
| 增加复购 | 老用户召回与留存 | 7日复购率 ≥ 35% |
| 清库存 | 针对滞销商品的促销 | 滞销品动销率 ≥ 40% |
| 品牌曝光 | 提升店铺在平台流量位 | 店铺曝光量提升 ≥ 30% |
| 竞争防御 | 应对竞品营销活动 | 市场份额保持率 ≥ 90% |

## 4. Standard Operating Procedures

### 4.1 优惠券类型

#### 4.1.1 平台券 vs 商家券

| 维度 | 平台券 | 商家券 |
|-----|-------|-------|
| 出资方 | 平台承担 | 商家承担 |
| 适用范围 | 全平台可用 | 仅限本店 |
| 流量权重 | 高（优先展示） | 中（需配合推广） |
| 成本 | 商家0成本 | 商家全额承担 |
| 适用场景 | 新店开业、大促 | 日常运营、老客维护 |

#### 4.1.2 券类型详解

- **满减券**：满X元减Y元，最常用类型
- **折扣券**：满X元打Y折，适合高毛利商品
- **无门槛券**：任意金额可用，拉新效果好
- **兑换券**：指定商品兑换，用于爆品推广
- **运费券**：减免配送费，提升转化率

### 4.2 领券流程

```
用户触达 → 领券入口 → 券领取 → 券到账 → 用券提醒
    │          │          │         │          │
    ▼          ▼          ▼         ▼          ▼
首页Banner   店铺页     一键领取   卡包查看   到期提醒
Push推送    商品详情   分享领券   短信通知   智能推荐
短信营销    订单完成页  任务领券   App消息    精准推送
```

**关键步骤说明**：

1. **券创建**：在商家后台设置券面额、门槛、有效期、库存
2. **券投放**：选择投放渠道（首页、店铺、商品详情等）
3. **用户领取**：支持直接领取、分享领券、任务领券
4. **券使用**：下单时自动/手动选择可用券
5. **券核销**：订单完成后系统自动核销

### 4.3 用券规则

#### 4.3.1 基础规则

| 规则项 | 配置选项 | 建议设置 |
|-------|---------|---------|
| 使用门槛 | 满X元可用 | 建议为客单价1.2-1.5倍 |
| 优惠面额 | 固定金额/折扣 | 毛利允许范围内最大化 |
| 有效期 | 领取后X天/固定日期 | 3-7天最佳 |
| 每人限领 | 1张/多张 | 新客1张，老客可多张 |
| 叠加规则 | 可叠加/不可叠加 | 注意与满减活动互斥 |

#### 4.3.2 叠加规则矩阵

| 券类型 | 满减活动 | 第二件半价 | 新客立减 | 运费减免 |
|-------|---------|-----------|---------|---------|
| 平台券 | 不可叠加 | 可叠加 | 不可叠加 | 可叠加 |
| 商家满减券 | 不可叠加 | 可叠加 | 不可叠加 | 可叠加 |
| 商家折扣券 | 不可叠加 | 不可叠加 | 不可叠加 | 可叠加 |
| 无门槛券 | 可叠加 | 可叠加 | 可叠加 | 可叠加 |

### 4.4 满减活动

#### 4.4.1 满减类型

- **阶梯满减**：满30减5、满50减10、满80减20
- **每满减**：每满30减5，可叠加
- **满额赠**：满X元赠指定商品
- **满额免邮**：满X元免配送费

#### 4.4.2 满减配置流程

1. **确定档位**：根据客单价分布设置2-3个档位
2. **计算成本**：确保满减后仍有合理毛利
3. **设置时间**：建议与用餐高峰期匹配
4. **选择商品**：可设置全店或部分商品参与
5. **监控数据**：实时关注转化率和ROI

#### 4.4.3 满减档位设计公式

```
建议档位1 = 平均客单价 × 0.8
建议档位2 = 平均客单价 × 1.2  
建议档位3 = 平均客单价 × 1.8

优惠力度 = (档位金额 - 目标实付) / 档位金额
建议优惠力度控制在 15%-25%
```

### 4.5 新用户专享

#### 4.5.1 新客定义

- 从未在饿了么平台下单的用户
- 或超过180天未下单的回流用户

#### 4.5.2 新客营销策略

| 策略 | 具体动作 | 预期效果 |
|-----|---------|---------|
| 首单立减 | 新客首单减X元 | 降低首单门槛 |
| 新客专享价 | 指定商品新客特价 | 爆品引流 |
| 新客礼包 | 多张券组合发放 | 提升复购 |
| 免配送费 | 新客首单免运费 | 提升转化率 |

#### 4.5.3 新客转化漏斗

```
曝光 → 点击 → 领券 → 加购 → 下单 → 支付
 │      │      │      │      │      │
 │      │      │      │      │      └─ 支付成功率 ≥ 95%
 │      │      │      │      └─ 下单转化率 ≥ 30%
 │      │      │      └─ 加购率 ≥ 40%
 │      │      └─ 领券率 ≥ 60%
 │      └─ 点击率 ≥ 5%
 └─ 曝光量（流量位决定）
```

### 4.7 商家自营销

#### 4.7.1 店铺券配置

**入口**：商家中心 → 营销 → 优惠券 → 创建店铺券

| 配置项 | 说明 | 注意事项 |
|-------|-----|---------|
| 券名称 | 用户可见 | 简洁明了，如"满30减5" |
| 券面额 | 优惠金额 | 参考竞品，有竞争力 |
| 使用门槛 | 最低消费金额 | 建议略高于客单价 |
| 发放总量 | 券的总库存 | 根据预算设置 |
| 每人限领 | 单用户领取上限 | 新客1张，老客3-5张 |
| 有效期 | 领取后X天有效 | 3-7天最佳 |
| 使用时段 | 可用时间段 | 可与高峰期错开 |

#### 4.7.2 商品券配置

- **单品券**：针对特定商品的优惠券
- **品类券**：针对某类商品的优惠券（如饮品券）
- **套餐券**：固定组合商品的优惠

#### 4.7.3 精准营销

**人群定向**：
- 新客：未下单用户
- 老客：历史下单用户
- 流失客：30天未下单
- 高价值客：客单价TOP20%

**场景定向**：
- 雨天营销：雨天自动推送
- 时段营销：早餐/午餐/晚餐/夜宵
- 位置营销：写字楼/住宅区/学校

## 5. Rule层（系统约束）

### 5.1 平台规则约束

| 规则类别 | 约束内容 | 违规处罚 |
|---------|---------|---------|
| 券面额限制 | 单张券面额 ≤ 100元 | 超额无法创建 |
| 折扣限制 | 折扣券最低5折 | 低于5折无法提交 |
| 发放频率 | 同用户每天最多领5张 | 超限自动拦截 |
| 活动时长 | 单次活动最长30天 | 超期自动结束 |
| 预算控制 | 需预充值或授信 | 余额不足活动暂停 |

### 5.2 商家资质要求

| 资质项 | 要求 | 说明 |
|-------|-----|-----|
| 店铺评分 | ≥ 4.5分 | 低于此分限制参与部分活动 |
| 营业时长 | ≥ 30天 | 新店保护期后开放 |
| 违规记录 | 近30天无严重违规 | 有违规限制营销活动 |
| 保证金 | 足额缴纳 | 不足时无法创建活动 |

### 5.3 财务规则

| 项目 | 规则 | 结算周期 |
|-----|-----|---------|
| 券成本 | 商家承担部分实时扣除 | T+0 |

| 退款处理 | 券不退回，按比例退实付 | 随订单退款 |
| 发票开具 | 按实付金额开票 | 用户申请后 |

## 8. Evaluation（评估维度）

### 8.1 核心指标

| 指标名称 | 计算公式 | 健康阈值 | 说明 |
|---------|---------|---------|-----|
| 领券率 | 领券人数 / 曝光人数 | ≥ 15% | 衡量券吸引力 |
| 用券率 | 用券订单数 / 领券数量 | ≥ 25% | 衡量券转化效果 |
| 券ROI | 用券GMV / 券成本 | ≥ 5 | 衡量投入产出比 |
| 拉新成本 | 券成本 / 新客数 | ≤ 20元 | 衡量获客效率 |
| 客单价提升 | (用券客单价 - 日常客单价) / 日常客单价 | ≥ 10% | 衡量凑单效果 |
| 复购率 | 7天内再次下单用户数 / 用券用户数 | ≥ 30% | 衡量长期效果 |

### 8.2 分级评估标准

**A级（优秀）**：
- ROI ≥ 8
- 用券率 ≥ 35%
- 领券率 ≥ 20%
- 建议：扩大预算，复制模式

**B级（良好）**：
- ROI 5-8
- 用券率 25-35%
- 领券率 10-20%
- 建议：微调优化，继续观察

**C级（待优化）**：
- ROI 3-5
- 用券率 15-25%
- 领券率 5-10%
- 建议：分析原因，调整策略

**D级（不合格）**：
- ROI < 3
- 用券率 < 15%
- 领券率 < 5%
- 建议：立即下线，复盘改进
