## Objective

1. **时效目标**: 订单30分钟送达率 ≥ 90%，平均配送时长 ≤ 40分钟
2. **体验目标**: 用户下单转化率 ≥ 20%，复购率 ≥ 50%
3. **服务目标**: 客服响应时效 ≤ 3分钟，售后问题2小时内处理完成
4. **质量目标**: 客诉率 ≤ 2%，商品完好率 ≥ 97%，拣货准确率 ≥ 99%
5. **平台目标**: 打造"全能超市"即时零售心智，实现"30分钟万物到家"

### 二、下单支付

#### 2.1 确认订单流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     下单支付流程图                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │ 确认商品 │ -> │ 填写地址 │ -> │ 选择优惠 │ -> │ 完成支付 │  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│                                                                 │
│  KCP: 地址准确性、支付安全、订单信息核对                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 进入购物车，选择商品 | 勾选需要购买的商品 | 失效商品无法选中 |
| 2 | 点击「去结算」 | 进入订单确认页 | 库存不足商品提示 |
| 3 | 确认/修改收货地址 | 精确到门牌号 | **KCP**: 地址完整性校验 |
| 4 | 选择配送时间 | 立即送达或预约时间 | 预约时间需提前30分钟 |
| 5 | 填写备注信息 | 如无接触配送、放门口等 | 备注字数限制50字 |
| 6 | 选择优惠券/红包 | 系统自动推荐最优组合 | 不可叠加使用 |
| 7 | 确认订单金额 | 核对商品金额、配送费、优惠 | 金额异常提示 |
| 8 | 选择支付方式 | 支付宝、微信支付、花呗等 | **KCP**: 支付安全校验 |
| 9 | 完成支付 | 支付成功生成订单 | 支付超时15分钟自动取消 |

#### 3.2 拣货作业流程

| 步骤 | 操作内容 | 注意事项 | Rule层约束 |
|------|----------|----------|------------|
| 1 | 接收订单 | 系统推送+语音提醒 | 需在5分钟内接单 |
| 2 | 打印拣货单 | 按商品分类/货架位置排序 | 支持PDA扫码拣货 |
| 3 | 商品拣选 | 按单拣货，扫码确认 | **KCP**: 拣货准确率 ≥ 99% |
| 4 | 缺货处理 | 标记缺货，联系用户 | 缺货商品自动退款 |
| 5 | 商品打包 | 分类打包，易碎品特殊处理 | 生鲜/冷冻品单独包装 |
| 6 | 等待骑手 | 放置取货区，通知骑手 | 需在承诺时间内完成 |

#### 3.3 拣货异常处理

| 异常情况 | 处理流程 | Rule层约束 |
|----------|----------|------------|
| 商品缺货 | 标记缺货，联系用户协商换货/退款 | 缺货商品自动退款 |
| 商品临期 | 优先拣选新鲜批次，临期品标记 | 保质期需剩余1/3以上 |
| 拣货错误 | 复核发现错误，重新拣货 | 出库前二次校验 |
| 打包破损 | 更换包装，确保完好 | 易碎品需特殊防护 |

#### 4.2 配送状态节点

```
订单状态节点及用户通知：

1. 订单已提交
   └── 推送：「您的订单已提交，等待商家接单」

2. 商家已接单
   └── 推送：「商家已接单，正在为您备货」

3. 骑手已接单
   └── 推送：「骑手XXX已接单，正赶往商家」

4. 骑手已到店
   └── 推送：「骑手已到达商家，等待取货」

5. 骑手已取货
   └── 推送：「骑手已取货，预计XX分钟后送达」

6. 配送中
   └── 推送：「商品配送中，请保持电话畅通」
   └── 实时位置更新（每30秒）

7. 即将送达
   └── 推送：「骑手即将到达，请准备收货」

8. 已送达
   └── 推送：「订单已送达，请及时确认收货」
```

#### 4.3 配送跟踪功能

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| 实时地图 | 显示骑手当前位置和配送路线 | 配送中状态 |
| 预计送达时间 | 基于算法动态计算 | 实时更新 |
| 配送进度通知 | APP推送、短信通知关键节点 | 状态变更时 |
| 联系骑手 | 虚拟号拨打电话 | 需要沟通时 |
| 联系商家 | 虚拟号拨打电话或在线聊天 | 商品咨询时 |

#### 4.4 配送异常处理

| 异常情况 | 处理流程 | Rule层约束 |
|----------|----------|------------|
| 配送延迟 | 系统自动计算新预计时间，超时发放补偿 | 超时15分钟自动触发补偿 |
| 骑手位置异常 | 系统监控，异常停留自动预警 | 停留超15分钟触发预警 |
| 联系不上骑手 | 用户可联系平台客服协助 | 客服5分钟内响应 |
| 配送路线偏离 | 系统监控，自动提醒骑手 | 偏离超800米触发提醒 |
| 骑手取消配送 | 系统自动重新派单 | 15分钟内重新分配 |

|----------|----------|----------|------------|
| 仅退款 | 未收到货、商品问题 | 照片/视频 | 签收前或质量问题 |
| 退货退款 | 商品问题需退回 | 照片+退回商品 | 部分商品不支持 |
| 补发商品 | 漏发/错发商品 | 照片 | 商家责任 |
| 换货 | 商品规格错误 | 照片+退回商品 | 需商家支持 |
| 部分退款 | 部分商品问题 | 照片 | 按比例退款 |

#### 6.2 售后申请流程

```
用户进入订单详情
    │
    ▼
点击「申请售后」
    │
    ▼
选择售后类型
    │
    ▼
填写售后原因
    │
    ▼
上传凭证照片
    │
    ▼
提交申请
    │
    ▼
┌─────────────────────────────────────────┐
│ Rule: 售后时效拦截                      │
│ - 普通商品：签收后7天内可申请           │
│ - 生鲜商品：签收后24小时内可申请        │

└─────────────────────────────────────────┘
    │
    ▼

    │
    ▼

```

#### 6.3 售后处理时效

| 处理环节 | 时效要求 | Rule层约束 |
|----------|----------|------------|
| 用户提交申请 | 即时 | 系统即时接收 |
| 商家响应 | ≤ 2小时 | 超时系统自动介入 |
| 平台审核 | ≤ 24小时 | 复杂问题可延长 |
| 退款到账 | 审核通过后即时或1-3工作日 | 极速退款用户即时到账 |


## Rule层

| 规则类别 | 规则名称 | 规则内容 | 触发时机 |
|----------|----------|----------|----------|
| 订单时效 | 支付超时取消 | 15分钟未支付自动取消订单 | 下单后 |
| 订单时效 | 商家接单时限 | 商家需在5分钟内接单，超时自动取消 | 支付成功后 |
| 订单时效 | 自动确认收货 | 送达后24小时自动确认收货 | 送达后 |
| 配送范围 | 配送范围拦截 | 超出商家配送范围无法下单 | 下单时 |
| 配送补偿 | 超时自动补偿 | 超时15分钟自动发放补偿红包 | 配送超时 |
| 售后时效 | 普通商品售后 | 签收后7天内可申请售后 | 售后申请时 |
| 售后时效 | 生鲜商品售后 | 签收后24小时内可申请售后 | 售后申请时 |
| 售后凭证 | 凭证要求拦截 | 必须提供照片凭证 | 售后申请时 |
| 库存管理 | 库存锁定规则 | 下单后锁定库存15分钟 | 下单时 |
| 库存管理 | 库存释放规则 | 支付超时或取消订单释放库存 | 订单取消时 |
| 商品质量 | 临期商品拦截 | 保质期剩余不足1/3禁止出库 | 拣货时 |
| 退款 | 极速退款条件 | 信用良好用户审核通过后即时退款 | 退款时 |
