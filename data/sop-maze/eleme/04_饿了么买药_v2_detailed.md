## Objective

本文档旨在规范饿了么买药即时送药服务的标准操作流程，确保用户能够安全、便捷地购买药品，同时保障处方审核的合规性和用户隐私安全。适用于饿了么买药平台的所有药品购买场景，包括 OTC 非处方药和处方药。

**核心目标：**
- 提供便捷的药品搜索与比价服务
- 确保处方药购买的合规性与安全性
- 实现快速、准时的药品配送
- 保护用户购药隐私
- 提供专业的用药咨询与售后服务
- 支持医保在线支付，减轻用户用药负担

## Standard Operating Procedures

### 1. 药品浏览搜索

#### 1.1 搜索入口
##### 1.1.1 入口类型
| 入口类型 | 说明 | 操作路径 |
|---------|------|---------|
| 首页搜索 | 直接输入药品名称/症状 | 饿了么App首页搜索框 |
| 分类浏览 | 按疾病/科室/药品类型筛选 | 买药频道 > 分类 |
| 扫码找药 | 扫描药品条形码 | 搜索框 > 扫码图标 |
| 附近药店 | 基于LBS的周边药店 | 买药首页 > 附近药店 |
| 智能推荐 | 基于症状的智能推荐 | 买药首页 > 症状入口 |

##### 1.1.2 搜索流程
```
用户输入 → 智能联想 → 结果展示 → 筛选排序 → 商品详情
```

##### 1.1.3 筛选维度
- **药品类型**：处方药 / 非处方药 / 医疗器械 / 保健品 / 中药饮片
- **价格区间**：自定义价格范围
- **配送时效**：30分钟达 / 1小时达 / 当日达
- **药店距离**：1km内 / 3km内 / 全城
- **品牌筛选**：指定药品品牌
- **规格剂型**：片剂/胶囊/颗粒/口服液/外用等
- **医保标识**：支持医保支付的药品

#### 1.2 智能联想与推荐
##### 1.2.1 联想规则
| 输入类型 | 联想内容 | 优先级 |
|---------|---------|--------|
| 药品名 | 完整药品名、通用名、品牌名 | P0 |
| 症状 | 对应症状药品、科室推荐 | P1 |
| 拼音 | 药品拼音首字母匹配 | P2 |
| 历史 | 历史搜索记录 | P3 |

##### 1.2.2 推荐算法
- 基于症状的药品关联推荐
- 基于购买历史的个性化推荐
- 基于地理位置的附近药店推荐
- 基于季节/流行病的热点推荐

#### 1.3 商品信息展示
##### 1.3.1 列表页信息
| 信息项 | 展示内容 | 备注 |
|-------|---------|------|
| 药品名称 | 商品名+通用名 | 双行展示 |
| 价格信息 | 现价+原价+折扣 | 突出优惠 |
| 配送信息 | 预计时效+距离 | 实时计算 |
| 药店信息 | 店名+评分+资质 | 认证标识 |
| 标签信息 | 处方药/OTC/医保 | 醒目展示 |

##### 1.3.2 详情页信息
- 药品名称、通用名、商品名
- 批准文号（国药准字）
- 生产厂家、生产日期、有效期
- 规格、用法用量
- 价格、促销信息
- 库存状态
- 药店资质信息
- 医保支付标识

### 2. 处方管理

#### 2.1 处方药购买流程
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择处方药  │────▶│  提交处方   │────▶│  处方审核   │────▶│  审核通过   │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                    │
                              ┌─────────────────────────────────────┘
                              ▼
                       ┌─────────────┐
                       │  进入下单   │
                       └─────────────┘
```

#### 2.2 处方来源类型
| 处方类型 | 说明 | 有效期 | 审核时效 |
|---------|------|--------|---------|
| 平台在线问诊 | 饿了么互联网医院医生开具 | 3天 | 即时 |
| 上传实体处方 | 用户拍照上传医院处方 | 原处方有效期内 | 5-15分钟 |
| 历史处方复用 | 平台内历史有效处方 | 原处方剩余有效期 | 即时 |
| 复诊续方 | 基于历史购药记录的续方 | 新开具起3天 | 即时 |

#### 2.3 处方审核标准
##### 2.3.1 审核维度
| 审核项 | 审核内容 | 通过标准 |
|-------|---------|---------|
| 合法性审核 | 处方来源、医师资质 | 来源合法、资质有效 |
| 规范性审核 | 处方要素完整性 | 信息齐全、签章完整 |
| 合理性审核 | 用药与诊断匹配度 | 诊断明确、剂量合理 |
| 有效期审核 | 处方是否在有效期内 | 未过期 |

##### 2.3.2 审核结果
| 结果 | 说明 | 处理方式 |
|-----|------|---------|
| 通过 | 处方合规有效 | 允许购买 |
| 待补充 | 信息不完整 | 通知用户补充 |
| 不通过 | 不合规或过期 | 拒绝购买并说明原因 |

#### 2.4 实名认证要求
##### 2.4.1 认证流程
```
用户选择处方药 → 触发实名认证 → 身份信息填写 → 人脸识别 → 认证通过
```

##### 2.4.2 认证规则
- 购买处方药需完成实名认证
- 处方信息与购买人信息需一致
- 部分特殊药品需额外身份验证
- 未成年人购药需监护人确认

### 4. 配送追踪

#### 4.1 配送方式
| 配送类型 | 时效承诺 | 适用场景 | 费用 |
|---------|---------|---------|------|
| 即时配送 | 平均30分钟 | 急需用药 | 根据距离计算 |
| 预约配送 | 指定时间段 | 计划用药 | 根据距离计算 |
| 快递配送 | 1-3天 | 非急需/囤货 | 满额免邮 |

#### 4.2 配送包装规范
| 包装类型 | 适用药品 | 包装要求 |
|---------|---------|---------|
| 隐私包装 | 全部药品 | 外包装不显示药品信息 |
| 温控包装 | 冷链药品 | 保温箱+冰袋，2-8℃ |
| 防震包装 | 易碎药品 | 增加缓冲材料 |
| 密封包装 | 全部药品 | 确保包装完整无损 |

#### 4.3 配送跟踪
- 实时查看骑手位置
- 配送状态推送通知
- 预计送达时间动态更新
- 异常配送自动预警

#### 4.4 配送异常处理
| 异常类型 | 处理方式 |
|---------|---------|
| 骑手超时 | 自动触发催单，超时赔付 |
| 联系不上 | 短信/电话通知，放置指定位置 |
| 地址错误 | 联系用户确认，协商处理 |
| 药品破损 | 拍照取证，启动售后流程 |

### 5. 收货验收

#### 5.1 验收流程
```
核对订单 ──▶ 检查包装 ──▶ 验货签收 ──▶ 确认收货
```

#### 5.2 验收要点
| 验收项目 | 检查内容 |
|---------|---------|
| 订单核对 | 药品名称、规格、数量是否与订单一致 |
| 包装检查 | 外包装是否完好，隐私包装是否有效 |
| 冷链检查 | 冷链药品保温包装是否完好，温度指示是否正常 |
| 有效期检查 | 药品有效期是否充足 |
| 外观检查 | 药品外观是否有破损、变质 |

#### 5.3 签收规范
- 当面验收，确认无误后签收
- 冷链药品需当场检查温控状态
- 发现问题可拒收并申请售后
- 签收后保留购药凭证

### 7. 售后服务

#### 7.1 售后政策
| 售后类型 | 适用条件 | 处理方式 | 时效要求 |
|---------|---------|---------|---------|
| 质量问题 | 药品破损/变质/过期 | 全额退款/换货 | 签收后7天内 |
| 错发漏发 | 商品与订单不符 | 补发/退款 | 签收后24小时内反馈 |
| 订单取消 | 配送前取消 | 全额退款 | 骑手取货前 |
| 拒收退货 | 配送中拒收 | 协商处理 | 配送时 |
| 退款申请 | 已签收退货 | 审核后退款 | 签收后7天内 |

#### 7.2 售后流程
```
用户申请 ──▶ 原因核实 ──▶ 凭证审核 ──▶ 处理方案 ──▶ 退款/补发 ──▶ 完结
```

#### 7.3 特殊药品售后限制
- 处方药：一经售出，非质量问题不退换
- 冷链药品：签收后非质量问题不退换
- 拆封药品：非质量问题不退换

#### 7.4 投诉与评价
- 订单评价：对药品、配送、服务进行评分
- 投诉渠道：客服热线、在线投诉、监管部门
- 投诉处理：48小时内响应，7个工作日内处理完毕

## Rule 层（拦截与约束）

## 多方对话示例

### 对话1：处方药购买全流程

```
【用户】我要买阿莫西林

【系统】为您找到【阿莫西林胶囊】，该药品为处方药，需要凭处方购买。
      您可以选择：
      1. 在线问诊开方（5分钟，¥5问诊费）
      2. 上传现有处方
```
