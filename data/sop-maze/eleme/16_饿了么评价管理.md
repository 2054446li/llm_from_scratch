## 3. Objective

### 3.1 业务目标

| 目标维度 | 具体目标 | 衡量指标 |
|----------|----------|----------|
| 用户体验 | 提供便捷的评价入口和流畅的评价体验 | 评价完成率 >= 85% |
| 商家服务 | 帮助商家获取真实用户反馈，提升服务质量 | 商家回复率 >= 70% |
| 平台治理 | 维护评价生态，打击虚假/恶意评价 | 违规评价处理率 100% |
| 数据质量 | 确保评价内容真实、有效、可追溯 | 有效评价占比 >= 90% |

### 3.2 核心价值

1. **用户价值**：为消费决策提供参考，保障用户权益
2. **商家价值**：获取真实反馈，优化产品和服务
3. **平台价值**：构建信任体系，提升平台公信力

## 4. Standard Operating Procedures

### 4.1 评价入口与触发

#### 4.1.1 入口类型

| 入口类型 | 触发条件 | 展示位置 |
|----------|----------|----------|
| 订单完成入口 | 订单状态变更为"已完成" | 订单详情页顶部浮层 |
| 消息推送入口 | 订单完成后30分钟 | App推送/短信 |
| 我的评价入口 | 用户主动查看 | 我的-我的评价 |
| 商家页入口 | 用户浏览商家时 | 商家详情页评价标签 |

#### 4.1.2 入口展示规则

```
IF 订单状态 = "已完成" AND 未评价 THEN
    展示评价入口浮层
    延迟30分钟后发送推送提醒
ELSE IF 订单已评价 THEN
    展示"已评价"标识
    提供"追评"入口(7天内)
END IF
```

#### 4.1.3 入口优先级

1. **P0 - 订单页入口**：订单完成后立即展示，最核心入口
2. **P1 - 推送入口**：30分钟后触发，提高评价率
3. **P2 - 我的评价入口**：用户主动行为，长期有效
4. **P3 - 商家页入口**：浏览场景下的评价查看

### 4.2 评价内容填写

#### 4.2.1 评分维度

| 评分项 | 分值范围 | 权重 | 说明 |
|--------|----------|------|------|
| 总体评分 | 1-5星 | 40% | 综合满意度 |
| 口味评分 | 1-5星 | 25% | 餐品口味 |
| 包装评分 | 1-5星 | 20% | 包装质量 |
| 配送评分 | 1-5星 | 15% | 配送服务 |

#### 4.2.2 评价内容结构

```
评价填写表单
├── 星级评分区 (必填)
│   ├── 总体评分
│   ├── 口味评分
│   ├── 包装评分
│   └── 配送评分
├── 标签选择区 (选填)
│   ├── 好评标签: 味道好/分量足/包装精美/配送快
│   └── 差评标签: 味道差/分量少/包装破损/配送慢
├── 文字评价区 (选填)
│   ├── 最少5字，最多500字
│   └── 敏感词过滤
├── 图片上传区 (选填)
│   ├── 最多9张
│   ├── 单张<10MB
│   └── 支持JPG/PNG格式
└── 匿名选项 (默认匿名)
```

#### 4.2.3 填写校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|----------|
| 总体评分 | 必须选择 | "请先进行总体评分" |
| 文字长度 | 5-500字 | "评价内容需5-500字" |
| 图片数量 | 0-9张 | "最多上传9张图片" |

```
│- 用户端延迟5分钟 │

```

#### 4.3.2 展示规则

| 场景 | 展示规则 | 延迟时间 |
|------|----------|----------|
| 正常评价 | 全部用户可见 | 5分钟延迟 |
| 带图评价 | 优先展示 | 审核通过后 |
| 差评(1-2星) | 商家回复后展示 | 商家回复后 |
| 违规评价 | 隐藏/删除 | 立即处理 |

#### 4.3.3 排序算法

```
评价排序得分 = 时间衰减分 * 0.3 + 质量分 * 0.4 + 互动分 * 0.3

其中:
- 时间衰减分: 24小时内100分，每过一天衰减10%
- 质量分: 带图+20分，有文字+10分，字数>50+10分
- 互动分: 商家回复+15分，点赞数*0.5分
```

### 4.4 评价修改与删除

#### 4.4.1 修改规则

| 操作 | 时间限制 | 次数限制 | 影响 |
|------|----------|----------|------|
| 修改评价 | 发布后7天内 | 1次 | 原评价保留历史记录 |
| 追加评价 | 发布后30天内 | 1次 | 追加内容独立展示 |
| 删除评价 | 发布后7天内 | 不限 | 评价进入回收站30天 |

## 5. Rule层

### 5.1 系统约束

| 约束类别 | 约束项 | 规则说明 | 违规处理 |
|----------|--------|----------|----------|
| **内容安全** | 敏感词过滤 | 禁止政治/色情/暴力词汇 | 拦截并提示 |
| | 隐私保护 | 禁止泄露手机号/地址 | 自动打码/拦截 |
| | 广告管控 | 禁止第三方平台信息 | 删除+警告 |
| **频次控制** | 评价频次 | 单订单仅1次评价 | 系统限制 |
| | 修改频次 | 7天内可修改1次 | 系统限制 |
| | 回复频次 | 单评价商家回复1次 | 系统限制 |
| **时间约束** | 评价有效期 | 订单完成后30天内 | 超期关闭入口 |
| | 修改有效期 | 发布后7天内 | 超期禁止修改 |
| | 申诉有效期 | 评价发布后15天内 | 超期不予受理 |
| **数据约束** | 图片格式 | JPG/PNG/GIF | 格式错误提示 |
| | 图片大小 | 单张<10MB | 超限提示压缩 |
| | 字数限制 | 5-500字 | 边界提示 |
| **反作弊** | 刷单检测 | 同一设备/IP异常 | 评价无效化 |
| | 诱导评价 | 禁止利益诱导好评 | 删除+处罚 |
| | 恶意竞争 | 禁止竞品恶意差评 | 删除+封号 |

### 5.2 状态流转

| 评价状态 | 状态说明 | 可执行操作 |
|----------|----------|------------|
| 待评价 | 订单完成未评价 | 填写评价 |
| 已评价 | 评价已提交 | 修改/删除/追评 |
| 审核中 | 提交后审核 | 等待审核结果 |
| 已展示 | 审核通过展示 | 商家回复 |
| 已隐藏 | 违规被隐藏 | 申诉 |
| 已删除 | 用户/系统删除 | 30天内可恢复 |
