## Objective

本SOP旨在规范饿了么跑腿（同城急送）服务的运营流程，确保：

1. **响应速度**：用户下单后快速匹配蜂鸟骑手，缩短等待时间
2. **服务品质**：保障物品安全、准时送达，提升用户体验
3. **服务多样**：支持帮我买、帮我送、帮我取等多种服务场景
4. **风险管控**：完善物品损坏/丢失处理、安全保障及异常应对机制
5. **运力保障**：依托蜂鸟众包+蜂鸟专送双运力体系，确保配送稳定

## Standard Operating Procedures

### 1. 下单发件

#### 1.1 服务类型

| 服务类型 | 说明 | 典型场景 |
|----------|------|----------|
| 帮我买 | 骑手代用户购买商品 | 代购餐饮、超市商品、药品、鲜花等 |
| 帮我送 | 骑手将物品从A地送至B地 | 文件传递、礼品配送、商务急件、餐饮配送 |
| 帮我取 | 骑手代为取回物品 | 取快递、取钥匙、取证件、取外卖 |

#### 1.2 下单流程

```
选择服务类型 ──▶ 填写取/送地址 ──▶ 描述物品/需求 ──▶ 选择配送时效 ──▶ 确认支付
```

#### 1.3 订单信息填写规范

| 字段 | 必填性 | 说明 |
|------|--------|------|
| 取货地址 | 必填 | 精确到门牌号，含联系人及电话 |
| 送货地址 | 必填 | 精确到门牌号，含联系人及电话 |
| 物品信息 | 必填 | 类型、数量、预估重量/体积 |
| 物品价值 | 建议填写 | 用于保价和理赔参考 |
| 备注说明 | 选填 | 特殊要求、取货码、外观要求、放置要求等 |
| 期望时效 | 必填 | 普通/特快/专人直送 [需内部资料确认] |

#### 1.4 费用构成 [需内部资料确认]

| 费用项目 | 说明 |
|----------|------|
| 基础配送费 | 根据距离、重量、时段计算 |
| 重量附加费 | 超重部分按阶梯计费 |
| 时段加价 | 高峰期、恶劣天气加价 |
| 特快服务费 | 优先配送、专人直送 |
| 保价费 | 按声明价值比例收取 |

### 2. 骑手接单

#### 2.1 接单模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 系统派单 | 算法根据骑手位置、负载、评分自动分配 | 标准订单 |
| 骑手抢单 | 骑手主动选择订单 | 蜂鸟众包模式 |
| 蜂鸟专送 | 平台指定专职骑手 | 高价值/特殊订单 |

#### 2.2 接单时效要求 [需内部资料确认]

| 服务类型 | 接单响应时限 | 到店/取货时限 |
|----------|--------------|---------------|
| 普通帮我买 | 5分钟内 | 接单后30分钟内 |
| 普通帮我送 | 5分钟内 | 接单后20分钟内 |
| 特快服务 | 3分钟内 | 接单后15分钟内 |
| 专人直送 | 即时响应 | 立即取货 |

#### 2.3 骑手资质要求 [需内部资料确认]

- 实名认证
- 健康证明（餐饮配送）
- 无犯罪记录
- 蜂鸟培训考核合格
- 装备要求（保温箱、头盔、工服等）

### 3. 取件配送

#### 3.1 取货流程

```
到达取货点 ──▶ 联系发货人 ──▶ 核验物品 ──▶ 拍照留证 ──▶ 确认取货
```

#### 3.2 物品核验标准

| 检查项 | 操作要求 |
|--------|----------|
| 外观检查 | 包装完好、无破损、无渗漏 |
| 数量核对 | 与订单描述一致 |
| 禁限品检查 | 拒绝承接违禁品 [需内部资料确认] |
| 特殊要求确认 | 温度要求、易碎标识、向上放置等 |

#### 3.3 配送途中规范

| 环节 | 要求 |
|------|------|
| 路线规划 | 按系统推荐路线，特殊情况可调整 |
| 时效监控 | 实时更新配送进度，关键节点上报 |
| 异常上报 | 交通堵塞、车辆故障等及时上报 |
| 物品保管 | 妥善放置，防止损坏、丢失、污染 |

#### 3.4 送达流程

```
到达送货点 ──▶ 联系收货人 ──▶ 核验身份 ──▶ 交付物品 ──▶ 确认签收 ──▶ 拍照完成
```

### 4. 送达确认

#### 4.1 签收方式

| 签收方式 | 适用场景 | 操作要求 |
|----------|----------|----------|
| 本人签收 | 收货人在场 | 核对身份，确认无误后交付 |
| 代收签收 | 收货人委托他人代收 | 与收货人电话确认，记录代收人信息 |
| 放置签收 | 收货人要求放置指定地点 | 按指定位置放置，拍照留证 |
| 智能柜签收 | 放入快递柜/外卖柜 | 放入后告知取件码，拍照留证 |

#### 4.2 送达确认流程

```
联系收货人 ──▶ 确认收货方式 ──▶ 完成交付 ──▶ 拍照/扫码确认 ──▶ 订单完成
```

#### 4.3 送达后服务

| 环节 | 内容 |
|------|------|
| 评价邀请 | 邀请用户对骑手服务进行评价 |
| 小费打赏 | 用户可对优质骑手进行打赏 [需内部资料确认] |
| 售后入口 | 提供物品问题反馈入口 |

### 5. 异常处理

#### 5.1 订单取消

| 取消时机 | 处理规则 |
|----------|----------|
| 骑手未接单前 | 用户可免费取消 |
| 骑手已接单未取货 | 可能产生取消费 [需内部资料确认] |
| 骑手已取货 | 原则上不可取消，特殊情况协商处理 |

#### 5.2 物品损坏/丢失处理

| 场景 | 责任判定 | 处理原则 |
|------|----------|----------|
| 取货时已损坏 | 发货方责任 | 拍照留证，联系发货人确认 |
| 配送途中损坏 | 骑手/平台责任 | 按保价或实际价值赔偿 |
| 配送途中丢失 | 骑手/平台责任 | 全额赔偿 |
| 收货后发现问题 | 需举证区分责任 | 根据证据判定 |

#### 5.3 配送超时处理

| 超时类型 | 判定标准 | 处理措施 |
|----------|----------|----------|
| 接单超时 | 超过接单响应时限 | 系统自动重新派单 |
| 取货超时 | 超过到店/取货时限 | 提醒骑手，必要时改派 |
| 送达超时 | 超过承诺送达时间 | 超时赔付/优惠券补偿 [需内部资料确认] |

#### 5.4 联系不上处理

| 场景 | 处理流程 |
|------|----------|
| 联系不上发货人 | 等待10分钟，上报异常，联系客服介入 |
| 联系不上收货人 | 等待10分钟，尝试备用联系方式，上报异常 |
| 地址错误/不详 | 联系用户确认，必要时取消或改派 |

#### 5.5 理赔流程

```
用户申请理赔 ──▶ 提交证据（照片、视频、价值证明）──▶ 平台审核 ──▶ 责任判定 ──▶ 赔付/拒赔
```

#### 5.6 赔付标准 [需内部资料确认]

| 情况 | 赔付标准 |
|------|----------|
| 已保价物品 | 按保价金额赔付，最高不超过声明价值 |
| 未保价物品 | 按实际损失赔付，有上限 [需内部资料确认] |
| 部分损坏 | 按损坏比例赔付或协商修复费用 |
| 完全丢失 | 全额赔付（受保价/赔付上限限制） |

#### 5.7 免责情形 [需内部资料确认]

- 不可抗力（自然灾害、政府行为等）
- 物品本身质量问题
- 用户提供的地址/联系方式错误
- 用户指定的特殊配送方式导致

## Rule层（系统约束）

| 约束类别 | 约束项 | 规则说明 |
|----------|--------|----------|
| **订单约束** | 最小配送距离 | 一般不低于1公里 [需内部资料确认] |
| | 最大配送距离 | 一般限制在10-15公里内 [需内部资料确认] |
| | 最大重量限制 | 单件不超过20-30公斤 [需内部资料确认] |
| | 禁运品清单 | 违禁品、危险品、易碎贵重品等 [需内部资料确认] |
| **时效约束** | 普通订单时效 | 3公里内约45-60分钟 [需内部资料确认] |
| | 特快订单时效 | 3公里内约30-45分钟 [需内部资料确认] |
| | 专人直送时效 | 取货后直接送达，无中转 |
| **费用约束** | 起步价 | 基础配送费起步价 [需内部资料确认] |
| | 距离加价 | 按距离阶梯加价 |
| | 重量加价 | 按重量阶梯加价 |
| | 时段加价 | 高峰期、夜间、恶劣天气加价 |
| **骑手约束** | 接单率要求 | 骑手需保持一定接单率 [需内部资料确认] |
| | 准时率要求 | 骑手需保持一定准时率 [需内部资料确认] |
| | 投诉率上限 | 投诉率超过阈值将限制接单 [需内部资料确认] |
| **安全约束** | 实名认证 | 骑手必须完成实名认证 |
| | 装备检查 | 配送前检查装备完整性 |
| | 保险覆盖 | 骑手配送意外险覆盖 [需内部资料确认] |
