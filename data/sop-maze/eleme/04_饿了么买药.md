## Objective

本文档旨在规范饿了么买药即时送药服务的标准操作流程，确保用户能够安全、便捷地购买药品，同时保障处方审核的合规性和用户隐私安全。适用于饿了么买药平台的所有药品购买场景，包括 OTC 非处方药和处方药。

**核心目标：**
- 提供便捷的药品搜索与比价服务
- 确保处方药购买的合规性与安全性
- 实现快速、准时的药品配送
- 保护用户购药隐私
- 提供专业的用药咨询与售后服务
- 支持医保在线支付，减轻用户用药负担

## Standard Operating Procedures

### 1. 药品浏览搜索

#### 1.1 搜索入口
| 入口类型 | 说明 | 操作路径 |
|---------|------|---------|
| 首页搜索 | 直接输入药品名称/症状 | 饿了么App首页搜索框 |
| 分类浏览 | 按疾病/科室/药品类型筛选 | 买药频道 > 分类 |
| 扫码找药 | 扫描药品条形码 | 搜索框 > 扫码图标 |
| 附近药店 | 基于LBS的周边药店 | 买药首页 > 附近药店 |
| 智能推荐 | 基于症状的智能推荐 | 买药首页 > 症状入口 |

#### 1.2 搜索流程
```
用户输入 → 智能联想 → 结果展示 → 筛选排序 → 商品详情
```

#### 1.3 筛选维度
- **药品类型**：处方药 / 非处方药 / 医疗器械 / 保健品 / 中药饮片
- **价格区间**：自定义价格范围
- **配送时效**：30分钟达 / 1小时达 / 当日达
- **药店距离**：1km内 / 3km内 / 全城
- **品牌筛选**：指定药品品牌
- **规格剂型**：片剂/胶囊/颗粒/口服液/外用等
- **医保标识**：支持医保支付的药品

#### 1.4 商品信息展示 [需内部资料确认]
- 药品名称、通用名、商品名
- 批准文号（国药准字）
- 生产厂家、生产日期、有效期
- 规格、用法用量
- 价格、促销信息
- 库存状态
- 药店资质信息
- 医保支付标识

### 2. 处方管理

#### 2.1 处方药购买流程
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择处方药  │────▶│  提交处方   │────▶│  处方审核   │────▶│  审核通过   │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                    │
                              ┌─────────────────────────────────────┘
                              ▼
                       ┌─────────────┐
                       │  进入下单   │
                       └─────────────┘
```

#### 2.2 处方来源类型
| 处方类型 | 说明 | 有效期 |
|---------|------|--------|
| 平台在线问诊 | 饿了么互联网医院医生开具 | 3天 |
| 上传实体处方 | 用户拍照上传医院处方 | 原处方有效期内 |
| 历史处方复用 | 平台内历史有效处方 | 原处方剩余有效期 |
| 复诊续方 | 基于历史购药记录的续方 | 新开具起3天 |

#### 2.3 处方审核标准 [需内部资料确认]
- **合法性审核**：处方来源是否合法、医师资质是否有效
- **规范性审核**：处方要素是否齐全（患者信息、药品、用量、医师签章）
- **合理性审核**：用药与诊断是否匹配、剂量是否合理
- **有效期审核**：处方是否在有效期内

#### 2.4 实名认证要求
- 购买处方药需完成实名认证
- 处方信息与购买人信息需一致
- 部分特殊药品需额外身份验证

### 3. 下单支付

#### 3.1 下单流程
```
确认药品 ──▶ 选择数量 ──▶ 填写收货地址 ──▶ 选择配送时间 ──▶ 选择支付方式 ──▶ 支付订单
```

#### 3.2 支付方式
| 支付类型 | 说明 | 适用场景 |
|---------|------|---------|
| 在线支付 | 支付宝/微信支付 | 通用场景 |
| 医保支付 | 医保个人账户支付 | 医保定点药店 |
| 组合支付 | 医保+自费组合 | 医保余额不足时 |
| 红包优惠 | 平台红包/商家优惠券 | 满减活动 |

#### 3.3 医保支付流程
```
选择医保支付 ──▶ 医保电子凭证授权 ──▶ 医保账户扣款 ──▶ 自费部分支付 ──▶ 支付完成
```

#### 3.4 订单确认信息 [需内部资料确认]
- 药品清单及数量
- 收货地址及联系方式
- 配送方式及预计送达时间
- 支付金额明细（药品金额、配送费、优惠金额）
- 医保支付金额（如适用）

### 4. 配送追踪

#### 4.1 配送方式
| 配送类型 | 时效承诺 | 适用场景 | 费用 |
|---------|---------|---------|------|
| 即时配送 | 平均30分钟 | 急需用药 | 根据距离计算 |
| 预约配送 | 指定时间段 | 计划用药 | 根据距离计算 |
| 快递配送 | 1-3天 | 非急需/囤货 | 满额免邮 |

#### 4.2 配送包装规范 [需内部资料确认]
- **隐私包装**：外包装不显示药品信息
- **温控包装**：冷链药品使用保温箱+冰袋
- **防震包装**：易碎药品增加缓冲材料
- **密封包装**：确保药品包装完整无损

#### 4.3 配送跟踪
- 实时查看骑手位置
- 配送状态推送通知
- 预计送达时间动态更新
- 异常配送自动预警

#### 4.4 配送异常处理
| 异常类型 | 处理方式 |
|---------|---------|
| 骑手超时 | 自动触发催单，超时赔付 |
| 联系不上 | 短信/电话通知，放置指定位置 |
| 地址错误 | 联系用户确认，协商处理 |
| 药品破损 | 拍照取证，启动售后流程 |

---

### 5. 收货验收

#### 5.1 验收流程
```
核对订单 ──▶ 检查包装 ──▶ 验货签收 ──▶ 确认收货
```

#### 5.2 验收要点
| 验收项目 | 检查内容 |
|---------|---------|
| 订单核对 | 药品名称、规格、数量是否与订单一致 |
| 包装检查 | 外包装是否完好，隐私包装是否有效 |
| 冷链检查 | 冷链药品保温包装是否完好，温度指示是否正常 |
| 有效期检查 | 药品有效期是否充足 |
| 外观检查 | 药品外观是否有破损、变质 |

#### 5.3 签收规范
- 当面验收，确认无误后签收
- 冷链药品需当场检查温控状态
- 发现问题可拒收并申请售后
- 签收后保留购药凭证

#### 6.3 咨询记录管理 [需内部资料确认]

### 7. 售后服务

#### 7.1 售后政策
| 售后类型 | 适用条件 | 处理方式 | 时效要求 |
|---------|---------|---------|---------|
| 质量问题 | 药品破损/变质/过期 | 全额退款/换货 | 签收后7天内 |
| 错发漏发 | 商品与订单不符 | 补发/退款 | 签收后24小时内反馈 |
| 订单取消 | 配送前取消 | 全额退款 | 骑手取货前 |
| 拒收退货 | 配送中拒收 | 协商处理 | 配送时 |
| 退款申请 | 已签收退货 | 审核后退款 | 签收后7天内 |

#### 7.2 售后流程
```
用户申请 ──▶ 原因核实 ──▶ 凭证审核 ──▶ 处理方案 ──▶ 退款/补发 ──▶ 完结
```

#### 7.3 特殊药品售后限制
- 处方药：一经售出，非质量问题不退换
- 冷链药品：签收后非质量问题不退换
- 拆封药品：非质量问题不退换

#### 7.4 投诉与评价
- 订单评价：对药品、配送、服务进行评分
- 投诉渠道：客服热线、在线投诉、监管部门
- 投诉处理：48小时内响应，7个工作日内处理完毕

## Rule层

| 规则类别 | 规则名称 | 规则说明 | 约束类型 |
|---------|---------|---------|---------|
| 合规规则 | 处方药销售 | 处方药必须凭处方购买，严格执行"先方后药" | 强制 |
| 合规规则 | 实名认证 | 购买处方药需完成实名认证 | 强制 |
| 合规规则 | 处方有效期 | 处方必须在有效期内使用 | 强制 |
| 合规规则 | 药师资质 | 提供用药咨询的药师需持有执业药师资格证 | 强制 |
| 合规规则 | 广告合规 | 药品广告需符合《广告法》和《药品管理法》 | 强制 |
| 隐私规则 | 数据加密 | 用户健康数据全链路加密传输 | 强制 |
| 隐私规则 | 隐私包装 | 外包装不显示药品名称和病症信息 | 强制 |
| 隐私规则 | 访问控制 | 最小权限原则，操作留痕 | 强制 |
| 业务规则 | 配送时效 | 即时配送承诺平均30分钟送达 | 承诺 |
| 业务规则 | 售后时效 | 质量问题签收后7天内可申请售后 | 承诺 |
| 业务规则 | 医保支付 | 仅医保定点药店支持医保支付 | 限制 |
| 业务规则 | 冷链管理 | 冷链药品全程2-8℃温控配送 | 强制 |
| 业务规则 | 库存校验 | 下单时校验库存，避免超卖 | 系统 |
| 业务规则 | 限购规则 | 部分药品设置购买数量上限 | 限制 |
