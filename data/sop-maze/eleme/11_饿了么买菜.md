## 业务概述

饿了么买菜是阿里巴巴本地生活集团旗下饿了么APP内的即时零售生鲜频道，依托饿了么配送网络，提供生鲜果蔬、肉禽蛋奶、粮油副食等商品的即时配送服务，主打「最快30分钟达」。

### 核心参与方

```
+-----------+      选购下单      +-----------+      履约配送      +-----------+
|  消费者   | -----------------> | 饿了么平台 | -----------------> |  前置仓/   |
+-----------+                    +-----------+                    |  合作商超  |
     ^                               |                            +-----------+
     |      收货/售后                |                                  |
     |                               |      库存管理                     | 分拣打包
     +-----------------------  运营系统  <-------------------------  商品出库
```

## Objective

1. **时效目标**：订单30分钟内送达率 ≥ 90% `[需内部资料确认：具体时效标准]`
2. **品质目标**：生鲜商品新鲜度达标，客诉率 ≤ 1.5%
3. **库存目标**：缺货率 ≤ 5%，缺货及时通知用户
4. **体验目标**：售后问题30分钟内响应处理
5. **覆盖目标**：核心城市主城区全覆盖，配送半径3-5公里

## Standard Operating Procedures

### 一、商品浏览选购

#### 1.1 用户端操作流程

| 步骤 | 操作内容 | 注意事项 |
|------|----------|----------|
| 1 | 打开饿了么APP，进入「买菜」频道 | 自动定位，显示附近商家 |
| 2 | 浏览商品分类或搜索商品 | 生鲜商品库存实时变化 |
| 3 | 选择商品规格、数量，加入购物车 | 注意商品重量/个数规格 |
| 4 | 进入购物车，确认商品清单 | 查看小计金额、优惠抵扣 |
| 5 | 选择配送时间段 | 可选「立即配送」或预约时段 |
| 6 | 确认收货地址 | 确认是否在商家配送范围内 |
| 7 | 选择支付方式，完成支付 | 支持支付宝、微信等多种方式 |

### 三、配送履约

#### 3.1 订单分配与拣货

```
用户下单成功
      ↓
系统根据配送地址分配最近前置仓/商家
      ↓
订单进入拣货队列（按配送时段排序）
      ↓
分配拣货员 `[需内部资料确认：分配逻辑]`
      ↓
按最优路径拣货 → 扫码核对 → 生鲜称重 → 完成拣货
```

#### 3.2 拣货流程

| 步骤 | 操作内容 | 系统支持 |
|------|----------|----------|
| 1 | 拣货员接收订单任务 | PDA/APP推送 |
| 2 | 按最优路径拣货 | 系统规划拣货路线 |
| 3 | 扫码核对商品 | 扫描商品条码确认 |
| 4 | 生鲜称重 | 实际称重，系统计算差价 |
| 5 | 缺货处理 | 标记缺货，系统触发通知 |
| 6 | 完成拣货，提交复核 | 打包台接收 |

#### 3.3 打包复核

```
拣货完成
      ↓
复核员核对商品（品种、数量、质量）
      ↓
┌─────────────────────────────────────────┐
│  核对无误 → 按规范打包                  │
│  发现问题 → 退回重新拣货                │
│  商品瑕疵 → 更换商品                    │
└─────────────────────────────────────────┘
      ↓
粘贴订单标签，放置配送区
      ↓
等待骑手取货
```

#### 3.4 打包规范 `[需内部资料确认：具体规范标准]`

| 商品类型 | 打包要求 |
|----------|----------|
| 冷冻食品 | 保温袋+冰袋，单独包装 |
| 生鲜水产 | 防水袋+冰袋，防止渗漏 |
| 易碎商品 | 气泡膜包裹，标识易碎 |
| 重物商品 | 底部放置，轻物在上 |
| 化学品 | 单独密封，与食品隔离 |

#### 3.5 骑手配送

| 步骤 | 操作内容 |
|------|----------|
| 1 | 骑手接收配送任务 |
| 2 | 到达前置仓/商家，扫码取货 |
| 3 | 核对订单号、商品数量 |
| 4 | 检查商品包装完整性 |
| 5 | 装车，按系统规划路线配送 |

#### 3.6 配送时效管理 `[需内部资料确认：具体时效标准]`

```
时效控制节点：
├── 下单至商家接单：≤ 5分钟
├── 拣货完成时间：≤ 15分钟
├── 骑手取货时间：≤ 5分钟
├── 配送途中时间：≤ 20分钟（3公里内）
└── 总时效目标：≤ 30-45分钟
```

#### 3.7 配送异常处理

| 异常情况 | 处理流程 |
|----------|----------|
| 联系不上用户 | 多次联系 → 上报异常 → 等待/按备注放置 |
| 地址错误 | 联系用户确认 → 协商处理/退回商家 |
| 商品破损 | 拍照留证 → 联系客服 → 协商处理 |
| 用户拒收 | 了解原因 → 上报平台 → 商品退回 |

### 四、收货验收

#### 4.1 收货流程

```
骑手送达
      ↓
用户验收商品
      ↓
┌─────────────────────────────────────────┐
│  验收无误 → 确认收货 → 订单完成        │
│  发现问题 → 拍照留证 → 申请售后        │
│  拒收商品 → 说明原因 → 退回处理        │
└─────────────────────────────────────────┘
```

#### 4.2 验收要点

| 验收项目 | 检查内容 |
|----------|----------|
| 商品完整性 | 包装是否破损、商品是否齐全 |
| 生鲜品质 | 是否新鲜、有无异味、色泽是否正常 |
| 重量核对 | 实际重量与订单是否一致 |
| 保质期 | 生产日期、保质期是否符合要求 |
| 温度控制 | 冷冻/冷藏商品是否保持低温 |

#### 4.3 签收方式

| 签收方式 | 适用场景 |
|----------|----------|
| 当面签收 | 用户在家，可当面验收 |
| 无接触配送 | 用户要求放门口/前台/快递柜 |
| 代收 | 物业/邻居代收，需提前确认 |

### 五、售后服务

#### 5.1 售后场景

| 场景 | 描述 | 举证要求 |
|------|------|----------|
| 商品变质 | 生鲜不新鲜、有异味 | 照片/视频 |
| 商品损坏 | 挤压破损、包装破裂 | 照片 |
| 重量不足 | 实际重量低于标注 | 称重照片 |
| 商品错发 | 收到非订单商品 | 照片 |
| 品质不符 | 与描述/图片不符 | 照片 |
| 缺货未通知 | 订单商品未配送且无通知 | 订单截图 |

#### 5.2 售后流程

```
用户申请售后
      ↓
选择售后原因 → 上传凭证 → 提交申请
      ↓
系统/客服审核
      ↓
┌─────────────────────────────────────────┐
│  审核通过 → 退款/补发/补偿              │
│  需补充凭证 → 通知用户补充              │
│  审核不通过 → 说明原因                  │
└─────────────────────────────────────────┘
```

#### 5.3 售后政策 `[需内部资料确认：具体售后标准]`

| 商品类型 | 售后时效 | 退款方式 |
|----------|----------|----------|
| 生鲜商品 | 签收后24小时内 | 按比例/全额退款 |
| 普通商品 | 签收后7天内 | 退货退款/仅退款 |
| 质量问题 | 优先退款，无需退货 | 极速退款 |

#### 5.4 缺货处理流程

```

系统标记缺货商品
      ↓
自动推送通知给用户（APP推送/短信）

┌─────────────────────────────────────────┐
│  方案1：用户选择替换商品（等价/补差价） │
│  方案2：缺货商品退款，其余商品继续配送  │
│  方案3：整单取消，全额退款              │
│  用户未响应 → 按默认方案处理 `[需内部资料确认：默认规则]` │
└─────────────────────────────────────────┘
```

1. **时效保障**：30分钟送达率达标，超时主动补偿 `[需内部资料确认：具体标准]`
2. **品质保障**：生鲜商品严格质检，问题商品快速售后
3. **缺货及时通知**：发现缺货立即通知用户，提供替代方案
4. **售后快速响应**：质量问题极速退款，减少用户等待
5. **数据驱动**：基于用户反馈持续优化商品品质和履约效率
6. **用户体验**：全流程信息透明，关键节点主动推送通知
