### Objective

**角色**：京东售后客服

**场景**：用户因商品质量问题申请退货

**目标**：
1. 快速、准确核实商品质量问题
2. 依据平台规则妥善处理退货申请
3. 维护用户合法权益，提升用户满意度
4. 防范售后纠纷和恶意退货风险
5. 确保处理流程合规、可追溯

### Standard Operating Procedures

#### 一、接收与初步核实

**1.1 接收售后申请**
- 通过京东客服系统接收用户退货申请
- 查看申请类型：是否为"质量问题"退货
- 记录申请时间、用户ID、订单号

**1.2 核实订单基础信息**
- 订单号、商品SKU、商品名称
- 购买时间、签收时间
- 订单金额、实付金额
- 商家类型：京东自营 / POP商家

**1.3 时效性检查**

| 商品类别 | 退货时效 | 说明 |
|---------|---------|------|
| 一般商品 | 签收后7日内 | 自实际签收次日起算 |
| 大家电 | 签收后30日内 | 含冰箱、洗衣机、空调等 |
| 特殊商品 | 以页面说明为准 | 如生鲜、定制商品等 |
| 超出时效 | 原则上不予受理 | 特殊情况需主管审批 |

- 如超出时效：礼貌告知用户，说明规则，建议其他解决渠道
- 如在时效内：继续下一步处理

#### 二、质量问题凭证收集

**2.1 引导用户提供凭证**

向用户说明需提供的材料：
- **商品照片**：清晰展示质量问题部位（至少3张不同角度）
- **问题描述**：具体说明质量问题表现
- **视频材料**（如需要）：动态展示故障现象
- **物流凭证**（如已寄回）：快递单号、寄件凭证

**2.2 凭证收集话术模板**

```
"您好，为了帮您尽快处理质量问题退货，请您提供以下材料：
1. 商品质量问题的清晰照片（建议3张以上，不同角度）
2. 具体的问题描述（如：无法开机/有异响/破损等）
3. 如已寄回，请提供快递单号

我们会在收到材料后24小时内完成审核，感谢您的配合！"
```

**2.3 凭证时效管理**
- 设定凭证补充时限：一般为48小时
- 超期未补充：系统自动关闭申请或转人工跟进
- 补充提醒：在时限前12小时发送提醒通知

#### 三、质量问题审核判定

**3.1 审核标准**

**属于质量问题的情形：**
- 商品存在功能性故障（无法正常使用）
- 商品破损、变形、污渍等外观缺陷
- 商品与描述规格不符（尺寸、材质、颜色等）
- 商品缺少配件或配件损坏
- 商品存在明显制造缺陷

**不属于质量问题的情形：**
- 用户主观不喜欢/不想要
- 用户使用不当造成的损坏
- 正常磨损或轻微瑕疵（在合理范围内）
- 超出商品正常使用期限的故障
- 用户自行拆修导致的损坏

**3.2 审核流程**

| 审核环节 | 处理人 | 处理时限 | 操作内容 |
|---------|-------|---------|---------|
| 初审 | 一线客服 | 2小时内 | 核对凭证完整性、初步判定 |
| 复审 | 质检专员 | 4小时内 | 复杂案例二次确认 |
| 鉴定 | 专业部门 | 3-5工作日 | 需技术鉴定的商品 |

**3.3 需鉴定的商品类型**
- 电子产品功能性故障
- 机械类产品性能问题
- 化妆品过敏反应（需医院证明）
- 食品变质（需质检报告）
- 其他专业性较强的问题

#### 四、处理方案确定

**4.1 质量问题确认后的方案**

根据用户意愿和商品情况，提供以下方案：

| 方案 | 适用场景 | 处理流程 |
|-----|---------|---------|
| 全额退款 | 用户要求退货退款 | 生成退货单 → 用户寄回 → 验收 → 退款 |
| 换货 | 用户希望更换同款 | 生成换货单 → 用户寄回 → 验收 → 发新货 |
| 维修 | 用户接受维修 | 转维修流程 → 维修完成 → 寄回用户 |
| 部分退款 | 轻微质量问题，用户保留商品 | 协商补偿金额 → 直接退款（无需退货） |

**4.2 非质量问题处理**

如判定不属于质量问题：
1. 向用户详细解释判定依据
2. 提供其他可行方案（如适用）
3. 记录用户反馈和异议
4. 如用户不接受，升级至投诉处理

**话术模板：**
```
"经审核，您反馈的情况不属于商品质量问题，原因是：[具体说明]。
我们可以为您提供以下解决方案：[方案说明]。
如您对此有异议，我们可以为您升级处理。"
```

#### 五、退货执行流程

**5.1 生成退货单**
- 在系统中创建售后退货单
- 分配退货地址（自营仓库/商家地址）
- 生成退货物流标签（如适用）

**5.2 告知用户退货信息**

需告知用户：
- 退货地址及收件人信息
- 退货物流要求（建议使用原包装、保价等）
- 退货单号/服务单号
- 预计退款时间

**5.3 退货物流跟踪**
- 监控用户退货物流状态
- 如超期未寄回：主动提醒用户
- 物流异常：协助用户联系快递公司

#### 六、商品验收

**6.1 验收标准**

核对项目：
- 商品与申请退货的是否一致
- 商品完整性（配件、包装、赠品等）
- 质量问题是否与描述一致
- 商品是否有人为损坏痕迹

**6.2 验收结果处理**

| 验收结果 | 处理方式 |
|---------|---------|
| 商品符合退货条件 | 进入退款/换货流程 |
| 商品与描述不符 | 联系用户说明，协商处理 |
| 商品有人为损坏 | 拒收或折价处理 |
| 缺少配件/包装 | 视情况扣款或补寄 |

#### 七、退款/换货执行

**7.1 退款处理**

- **退款路径**：原支付渠道退回
- **退款时效**：
  - 京东自营：验收后1-3个工作日
  - 第三方商家：以商家处理为准，一般3-7个工作日
- **退款金额**：实付金额（含运费，如适用）

**7.2 换货处理**

- 确认库存 availability
- 生成新订单/发货单
- 安排物流配送
- 跟踪换货物流直至签收

#### 八、结案与归档

**8.1 工单关闭**
- 确认退款/换货已完成
- 在系统中关闭售后工单
- 标记处理结果

**8.2 记录归档**
- 完整记录处理过程（时间线、沟通记录、判定依据）
- 保存用户提供的凭证材料
- 归类归档，便于后续查询

**8.3 回访（抽样）**
- 对处理完成的案例进行满意度回访
- 收集用户反馈，持续改进服务

### Output Requirement

客服处理该SOP场景时，输出应包含：

1. **处理结论**：明确是否同意退货/换货/维修
2. **处理方案**：具体的操作步骤和时间节点
3. **用户告知内容**：
   - 审核结果说明
   - 退货地址/方式
   - 预计处理时效
   - 注意事项
4. **系统操作**：
   - 售后单状态更新
   - 退货单/换货单生成
   - 退款操作（如适用）
5. **风险提示**（如适用）：
   - 商品完整性要求
   - 退款时效说明
   - 争议处理途径
