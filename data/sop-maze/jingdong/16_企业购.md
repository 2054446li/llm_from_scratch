## 详细流程说明

### 一、企业账号注册与认证

#### 1.1 账号注册

| 步骤 | 操作内容 | 注意事项 |
|------|----------|----------|
| 1 | 访问京东企业购官网 (b.jd.com) | 确保使用企业网络环境 |
| 2 | 点击"免费注册" | 选择"企业用户"类型 |
| 3 | 填写手机号并验证 | 建议使用企业管理员手机号 |
| 4 | 设置登录密码 | 密码需符合安全强度要求 |
| 5 | 完成基础注册 | 记录账号信息 |

#### 1.2 企业认证

| 步骤 | 操作内容 | 所需材料 |
|------|----------|----------|
| 1 | 进入"企业认证"页面 | 登录后点击认证入口 |
| 2 | 填写企业基本信息 | 企业名称、统一社会信用代码 |
| 3 | 上传营业执照 | 彩色扫描件或高清照片 |
| 4 | 填写法人信息 | 法人姓名、身份证号 |
| 5 | 上传法人身份证 | 正反面照片 |
| 6 | 填写联系人信息 | 采购负责人信息 |
| 7 | 提交审核 | 确认信息无误后提交 |

#### 1.3 认证审核

| 审核阶段 | 处理时间 | 审核内容 |
|----------|----------|----------|
| 初审 | 1个工作日 | 资料完整性检查 |
| 复审 | 1-2个工作日 | 企业资质真实性核验 |
| 终审 | 1个工作日 | 开通采购权限 |

**审核结果通知：**
- 审核通过：短信+邮件通知，开通全部采购权限
- 审核驳回：告知驳回原因，需补充材料重新提交

### 二、采购流程

#### 2.1 商品选购

| 功能 | 说明 | 适用场景 |
|------|------|----------|
| 企业专享价 | 认证企业专属优惠价格 | 日常采购 |
| 批量采购 | 支持大批量商品询价 | 集中采购 |
| 协议商品 | 签订框架协议后的专属商品池 | 长期合作 |
| 定制服务 | 特殊规格/包装定制需求 | 个性化需求 |

#### 2.2 询价流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择商品    │────▶│  填写询价单  │────▶│  等待报价   │────▶│  确认价格   │
│ (批量选择)  │     │ (数量/要求)  │     │ (1-2工作日) │     │ (接受/拒绝) │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

**询价单必填信息：**
- 商品SKU/名称
- 采购数量
- 期望交货时间
- 特殊要求（发票、包装等）

#### 2.3 购物车与订单

| 操作 | 功能说明 | 备注 |
|------|----------|------|
| 加入购物车 | 暂存待购商品 | 支持批量导入 |
| 选择收货地址 | 添加企业收货地址 | 可设置多个地址 |
| 选择发票类型 | 普票/专票选择 | 影响后续开票 |
| 提交订单 | 生成待审批订单 | 触发审批流程 |

### 三、审批流程

#### 3.1 审批流配置

企业管理员可在后台配置审批规则：

| 审批维度 | 设置选项 | 示例 |
|----------|----------|------|
| 按金额 | 设置不同金额阈值 | 5000元以下免审，5000-20000元需部门经理审批，20000元以上需总监审批 |
| 按品类 | 特定品类强制审批 | 办公设备、IT设备需IT部门审批 |
| 按部门 | 不同部门不同规则 | 行政部门、财务部门独立审批流 |

#### 3.2 审批操作

| 审批人角色 | 审批权限 | 操作选项 |
|------------|----------|----------|
| 部门经理 | 本部门采购审批 | 通过/驳回/转交 |
| 财务审核 | 财务合规性审核 | 通过/驳回/要求补充说明 |
| 总监/副总 | 大额采购审批 | 通过/驳回 |
| 采购负责人 | 最终确认 | 通过/驳回/修改后通过 |

**审批时效：**
- 普通审批：24小时内响应
- 紧急审批：2小时内响应（需标记紧急）

### 五、发票处理

#### 5.1 发票类型

| 发票类型 | 税率 | 适用场景 | 抵扣说明 |
|----------|------|----------|----------|
| 增值税专用发票 | 13%/9%/6% | 一般纳税人企业 | 可抵扣进项税额 |
| 增值税普通发票 | 13%/9%/6% | 小规模纳税人/个人 | 不可抵扣 |
| 电子发票 | 同上 | 所有企业 | 与纸质发票同等效力 |

#### 5.2 专票申请流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  完善开票   │────▶│  提交专票   │────▶│  资质审核   │────▶│  发票开具   │
│  资质信息   │     │  申请       │     │  (税务信息) │     │  (3-5工作日)│
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

**专票申请所需资料：**
- 企业名称（与营业执照一致）
- 纳税人识别号
- 注册地址
- 注册电话
- 开户银行
- 银行账号
- 一般纳税人资格证明

#### 5.3 发票管理

| 功能 | 说明 | 操作路径 |
|------|------|----------|
| 发票申请 | 订单完成后申请开票 | 我的订单-申请开票 |
| 发票查询 | 查询历史开票记录 | 发票管理-开票记录 |
| 发票红冲 | 退货/换货时红冲发票 | 联系客服处理 |
| 发票重开 | 信息错误时重新开具 | 提交重开申请 |

## 异常处理

### 常见异常及解决方案

| 异常场景 | 可能原因 | 解决方案 |
|----------|----------|----------|
| 认证审核失败 | 资料不清晰/信息不一致 | 重新拍摄清晰照片，核对信息一致性 |
| 支付失败 | 账户余额不足/限额 | 联系银行调整限额或更换支付方式 |
| 发票开具失败 | 资质信息有误 | 核对税号、开户行信息准确性 |
| 审批流卡住 | 审批人未处理 | 联系审批人或管理员转交审批 |
| 商品无法购买 | 超出配送范围/库存不足 | 更换收货地址或联系客服调货 |
