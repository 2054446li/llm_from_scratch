## 4. Objective

**角色**：京东服务+ 客服专员

**场景**：用户咨询、预约、执行、售后全流程服务

**目标**：
1. 规范服务+全流程服务标准
2. 确保服务质量一致性
3. 提升用户体验
4. 明确各环节责任与操作规范

**关键指标**：
- 准时上门率 ≥ 95%
- 工单完成时效：24小时内完成率 ≥ 90%
- 投诉响应时效：2小时内响应率 100%
- 一次修复率 ≥ 85%
- 返修率 ≤ 5%
- 用户满意度 ≥ 4.8分（5分制）

## 5. Standard Operating Procedures

### 5.1 服务预约流程

#### 5.1.1 用户下单

| 步骤 | 操作内容 | 标准/要求 |
|------|----------|-----------|
| 5.1.1.1 | 进入京东服务+ 入口 | 京东APP首页/搜索"服务+"/扫描服务码 |
| 5.1.1.2 | 选择服务类型 | 安装/维修/清洗/检测四选一 |
| 5.1.1.3 | 选择设备品类 | 空调、电视、冰箱、洗衣机、烟机、热水器等 |
| 5.1.1.4 | 填写设备信息 | 品牌、型号、购买时间、故障现象（维修） |
| 5.1.1.5 | 选择服务时间 | 预约时间段（通常2小时为一个时段） |
| 5.1.1.6 | 填写服务地址 | 详细地址、联系人、联系电话 |
| 5.1.1.7 | 确认服务费用 | 查看预估费用明细 |
| 5.1.1.8 | 提交订单支付 | 支付定金或全款 |

#### 5.1.2 系统派单

| 步骤 | 操作内容 | 标准/要求 |
|------|----------|-----------|
| 5.1.2.1 | 订单进入派单池 | 系统根据LBS匹配附近工程师 |
| 5.1.2.2 | 智能派单 | 考虑工程师技能、当前工单量、距离、评分 |
| 5.1.2.3 | 工程师接单 | 工程师APP端确认接单（15分钟内） |
| 5.1.2.4 | 派单成功通知 | 短信/APP推送通知用户 |
| 5.1.2.5 | 工程师联系用户 | 确认上门时间、了解基本情况 |

### 5.2 服务类型详解

#### 5.2.1 安装服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **准备阶段** | 1. 确认安装环境 | 检查电源、空间、承重、通风条件 |
| | 2. 确认安装位置 | 与用户沟通确认最佳安装位置 |
| | 3. 检查配件完整性 | 核对产品配件、辅材准备 |
| **施工阶段** | 4. 安全防护 | 佩戴安全装备、铺设防护垫 |
| | 5. 定位打孔 | 精准测量、防尘打孔 |
| | 6. 设备安装 | 按规范安装、水平校准 |
| | 7. 管路连接 | 密封处理、检漏测试 |
| | 8. 电路连接 | 接地保护、绝缘检测 |
| **调试阶段** | 9. 通电测试 | 功能测试、运行检测 |
| | 10. 效果验证 | 制冷/制热效果、噪音检测 |
| | 11. 用户指导 | 操作讲解、注意事项说明 |
| **收尾阶段** | 12. 现场清理 | 清理施工垃圾、擦拭设备 |
| | 13. 填写工单 | 记录安装信息、用户签字 |

#### 5.2.2 维修服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **诊断阶段** | 1. 故障询问 | 详细了解故障现象、发生时间、使用环境 |
| | 2. 外观检查 | 检查设备外观、电源连接、使用环境 |
| | 3. 通电检测 | 安全检测、故障代码读取 |
| | 4. 拆机检测 | 内部部件检查、电路检测 |
| | 5. 故障定位 | 确定故障原因、损坏部件 |
| **报价阶段** | 6. 维修方案 | 提供维修/更换建议 |
| | 7. 费用报价 | 明确人工费+配件费，用户确认 |
| **维修阶段** | 8. 配件更换 | 使用正品配件、规范更换 |
| | 9. 电路修复 | 焊接、绝缘处理 |
| | 10. 系统调试 | 参数设置、功能恢复 |
| **验证阶段** | 11. 功能测试 | 全面功能验证 |
| | 12. 稳定性测试 | 运行观察、确保故障排除 |

#### 5.2.3 清洗服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **准备阶段** | 1. 环境检查 | 检查设备状态、周边环境 |
| | 2. 防护措施 | 铺设防护垫、准备接水设备 |
| | 3. 断电处理 | 安全断电、验电确认 |
| **拆洗阶段** | 4. 部件拆卸 | 按规范拆卸可清洗部件 |
| | 5. 深度清洗 | 使用专业清洗剂、高温蒸汽 |
| | 6. 杀菌消毒 | 消毒液处理、高温杀菌 |
| **装复阶段** | 7. 部件安装 | 正确复位、紧固检查 |
| | 8. 电路恢复 | 接线检查、绝缘确认 |
| **验收阶段** | 9. 通电测试 | 功能正常、无异响 |
| | 10. 清洁对比 | 前后效果展示 |

#### 5.2.4 检测服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **检测阶段** | 1. 基础检测 | 外观、电源、基本功能 |
| | 2. 性能检测 | 制冷/制热效率、能耗检测 |
| | 3. 安全检测 | 漏电、接地、绝缘检测 |
| | 4. 深度检测 | 压力检测、电路检测 |
| **报告阶段** | 5. 数据分析 | 检测数据分析 |
| | 6. 问题诊断 | 潜在问题识别 |
| | 7. 建议方案 | 维修/保养建议 |
| | 8. 出具报告 | 电子检测报告 |

### 5.3 收费标准说明

#### 5.3.1 收费构成

| 收费项目 | 说明 | 计费方式 |
|----------|------|----------|
| **上门费** | 工程师上门的交通成本 | 按区域：市区30-50元，郊区50-80元 |
| **检测费** | 故障诊断、检测服务 | 30-100元（部分可抵扣维修费） |
| **安装费** | 设备安装人工费 | 按品类：挂机100-200元，柜机150-300元，中央空调300-800元 |
| **维修费** | 故障维修人工费 | 按难度：小修80-150元，中修150-300元，大修300-600元 |
| **配件费** | 更换配件费用 | 按配件类型，明码标价 |
| **高空费** | 2楼以上外机作业 | 2-5层50-100元，6层以上100-150元 |
| **打孔费** | 穿墙孔施工 | 普通墙30-50元/个，混凝土80-150元/个 |

#### 5.3.2 收费原则

1. **透明定价**：服务前明确告知所有费用
2. **明码标价**：执行平台公示价格标准
3. **用户确认**：额外费用需用户确认后方可施工
4. **开具凭证**：提供正规发票/收据

### 5.4 改约/取消流程

#### 5.4.1 用户改约

| 时间节点 | 处理方式 | 费用影响 |
|----------|----------|----------|
| 提前24小时以上 | 免费改期，重新预约 | 无费用 |
| 提前4-24小时 | 免费改期一次 | 无费用 |
| 提前2-4小时 | 可改期，可能产生调度费 | 可能收取30元调度费 |
| 提前2小时内 | 视为临时改约 | 收取50元空跑费 |
| 工程师上门后 | 无法改期 | 按已完成上门计费 |

#### 5.4.2 用户取消

| 时间节点 | 处理方式 | 退款规则 |
|----------|----------|----------|
| 工程师接单前 | 直接取消 | 全额退款 |
| 接单后4小时前 | 取消订单 | 全额退款 |
| 接单后4小时内 | 取消订单 | 扣除30元调度费 |
| 工程师上门后 | 取消订单 | 扣除上门费+检测费 |

#### 5.4.3 工程师改约

| 场景 | 处理标准 |
|------|----------|
| 工程师无法按时上门 | 提前2小时通知用户，协商改期 |
| 配件缺货需改期 | 说明原因，优先调货，必要时改期 |
| 恶劣天气/交通 | 及时沟通，免费改期 |
| 用户原因无法入户 | 等待15分钟后可标记用户原因离开 |

### 5.5 服务执行与验收

#### 5.5.1 上门服务规范

| 项目 | 标准要求 |
|------|----------|
| **准时率** | 按预约时间±30分钟内到达 |
| **形象规范** | 统一工装、佩戴工牌、鞋套入户 |
| **沟通规范** | 礼貌用语、耐心解答、不打扰用户 |
| **施工规范** | 按标准流程操作、使用专业工具 |
| **安全规范** | 佩戴安全装备、确保施工安全 |

#### 5.5.2 服务验收标准

| 服务类型 | 验收项目 | 合格标准 |
|----------|----------|----------|
| **安装** | 安装牢固度 | 水平稳固、无晃动 |
| | 功能测试 | 各项功能正常运行 |
| | 效果验证 | 制冷/制热效果达标 |
| | 安全检查 | 接地良好、无漏电 |
| | 外观检查 | 无损伤、整洁美观 |
| **维修** | 故障排除 | 原故障现象消失 |
| | 功能恢复 | 全部功能正常 |
| | 稳定性测试 | 连续运行无异常 |
| | 安全检查 | 无安全隐患 |
| **清洗** | 清洁度 | 无明显污渍、异味 |
| | 功能检查 | 运行正常、无异响 |
| | 杀菌效果 | 消毒处理完成 |

#### 5.5.3 验收流程

1. **功能演示**：工程师现场演示设备功能
2. **效果确认**：用户确认服务效果满意
3. **签字确认**：电子工单用户签字确认
4. **支付尾款**：如有尾款，现场支付
5. **评价邀请**：邀请用户对服务进行评价

### 5.6 服务质保与返修

#### 5.6.1 质保期限

| 服务类型 | 质保期限 | 质保范围 |
|----------|----------|----------|
| **安装服务** | 90天-1年 | 安装质量问题、配件松动、漏水漏电 |
| **维修服务** | 30-90天 | 同一故障复发、维修部位故障 |
| **清洗服务** | 7-30天 | 清洗导致的故障、异味问题 |
| **配件更换** | 90天-1年 | 配件本身质量问题 |

#### 5.6.2 返修流程

| 步骤 | 操作内容 | 时效要求 |
|------|----------|----------|
| 5.6.2.1 | 用户申请返修 | 质保期内通过APP/电话申请 |
| 5.6.2.2 | 客服核实 | 24小时内核实订单和故障 |
| 5.6.2.3 | 派单处理 | 优先派原工程师或高级技师 |
| 5.6.2.4 | 上门检测 | 确认是否属于质保范围 |
| 5.6.2.5 | 免费返修 | 质保范围内免费维修 |
| 5.6.2.6 | 完工确认 | 用户确认故障排除 |
| 5.6.2.7 | 质保延期 | 返修后重新计算质保期 |

#### 5.6.3 非质保情形

- 用户自行拆修导致的故障
- 不可抗力（雷击、水灾等）导致的损坏
- 用户使用不当造成的故障
- 超过质保期限的故障

#### 5.7.2 投诉处理流程

```
用户投诉 → 客服受理 → 问题核实 → 责任判定 → 处理方案 → 用户确认 → 执行处理 → 回访闭环
   │           │          │          │          │          │          │          │
  发起       2小时内    24小时内    明确责任    提出方案   用户同意   执行赔付   7天内回访
```

#### 5.7.3 争议处理原则

| 争议类型 | 处理方式 |
|----------|----------|
| **费用争议** | 核实收费标准，多收费用双倍退还 |
| **质量争议** | 第三方检测，责任方承担费用 |
| **损坏争议** | 现场取证，协商赔偿方案 |
| **服务态度** | 核实后按规范处罚，向用户致歉 |

#### 5.7.4 赔付标准

| 情形 | 赔付标准 |
|------|----------|
| 爽约（未提前通知未上门） | 退还费用+50元赔付 |
| 迟到30分钟以上 | 减免20%服务费 |
| 服务态度差（核实） | 退还费用+道歉 |
| 施工损坏用户物品 | 照价赔偿或修复 |
| 维修后故障未排除 | 免费返修+50元赔付 |

- 是否提供工程师信息
- 是否主动承诺赔付
- 是否升级跟进

### 10.4 服务禁语

工程师在服务过程中禁止使用以下语言：
- "不知道"、"不归我管"、"找别人"
- "这是产品质量问题，找厂家"
- "这个修不了/没法弄"
- "你买的时候怎么不看清楚"
- "必须加钱才能做"
