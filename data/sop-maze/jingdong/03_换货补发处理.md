### 1. 基本信息

| 项目 | 内容 |
|------|------|
| SOP编号 | JD-AF-03 |
| SOP名称 | 换货/补发处理流程 |
| 适用场景 | 用户申请换货或补发商品 |
| 负责岗位 | 售后客服专员 |
| 版本号 | V1.0 |
| 生效日期 | 2024-01-01 |

---

### 2. 流程步骤详解

#### 步骤1：接收售后申请

| 属性 | 内容 |
|------|------|
| 步骤编号 | S01 |
| 步骤名称 | 接收并识别售后类型 |
| 操作说明 | 1. 登录京东客服后台<br>2. 查看待处理售后工单<br>3. 识别用户申请类型（换货/补发）<br>4. 查看订单详情和申请原因 |
| 输入信息 | 用户售后申请单、订单信息 |
| 输出信息 | 分类后的售后工单 |
| 系统操作 | 京东商家后台 → 售后管理 → 售后单列表 |
| 注意事项 | 优先处理时效即将超期的工单 |

---

#### 步骤2：审核申请条件

| 属性 | 内容 |
|------|------|
| 步骤编号 | S02 |
| 步骤名称 | 审核售后申请条件 |
| 操作说明 | **换货审核：**<br>1. 确认是否在换货时效内（自营：7天；POP：按商家承诺）<br>2. 确认商品是否支持换货（非定制、非生鲜、非虚拟）<br>3. 核实换货原因（质量问题/规格不符/不喜欢等）<br><br>**补发审核：**<br>1. 核实漏发/破损/少件情况<br>2. 确认用户提供凭证（照片/视频）<br>3. 确认订单状态已签收 |
| 输入信息 | 用户申请信息、订单详情、凭证图片 |
| 输出信息 | 审核结果（通过/拒绝） |
| 决策点 | 是否符合换货/补发条件？ |
| 注意事项 | 质量问题需用户提供有效凭证；7天无理由换货需商品完好 |

---

#### 步骤3：库存检查

| 属性 | 内容 |
|------|------|
| 步骤编号 | S03 |
| 步骤名称 | 检查目标商品库存 |
| 操作说明 | 1. 查询用户所需规格商品的库存状态<br>2. 确认可售库存数量<br>3. 预估发货时间 |
| 输入信息 | 商品SKU、规格信息 |
| 输出信息 | 库存状态（有货/无货/预售） |
| 系统操作 | 商家后台 → 库存管理 → 库存查询 |
| 决策点 | 是否有足够库存？ |
| 注意事项 | 如库存不足，需与用户协商替代方案（退款/换其他规格/等待补货） |

---

#### 步骤4：用户意愿确认

| 属性 | 内容 |
|------|------|
| 步骤编号 | S04 |
| 步骤名称 | 确认用户处理意愿 |
| 操作说明 | **换货确认：**<br>1. 告知用户换货流程及时效<br>2. 确认换货商品规格、颜色、尺码<br>3. 说明用户需先退回原商品（如适用）<br>4. 获取用户明确同意<br><br>**补发确认：**<br>1. 告知用户补发商品信息<br>2. 确认收货地址<br>3. 说明补发时效<br>4. 获取用户明确同意 |
| 输入信息 | 库存查询结果、商品信息 |
| 输出信息 | 用户确认结果（同意/拒绝） |
| 沟通话术 | "您好，您申请的换货商品目前有库存，预计X天内发出。请您确认是否继续办理换货？" |
| 注意事项 | 必须通过在线聊天或电话获得用户明确回复，保留沟通记录 |

---

#### 步骤5：创建换货/补发单

| 属性 | 内容 |
|------|------|
| 步骤编号 | S05 |
| 步骤名称 | 生成售后处理单据 |
| 操作说明 | **换货单创建：**<br>1. 在系统中创建换货单<br>2. 填写新商品SKU信息<br>3. 关联原订单<br>4. 生成退货地址（如需用户退货）<br><br>**补发单创建：**<br>1. 创建补发订单<br>2. 填写补发商品信息<br>3. 确认收货地址<br>4. 标记为"补发"类型 |
| 输入信息 | 用户确认信息、商品SKU、地址信息 |
| 输出信息 | 换货单号/补发单号 |
| 系统操作 | 商家后台 → 售后管理 → 创建换货/补发单 |
| 注意事项 | 确保新订单与原订单正确关联，便于后续追踪 |

---

#### 步骤6：通知仓库处理

| 属性 | 内容 |
|------|------|
| 步骤编号 | S06 |
| 步骤名称 | 通知仓库发货 |
| 操作说明 | 1. 将换货/补发单推送至仓库系统<br>2. 标注优先级（如加急）<br>3. 跟进仓库处理进度 |
| 输入信息 | 换货单/补发单 |
| 输出信息 | 仓库接单确认 |
| 系统操作 | WMS系统 → 出库管理 → 售后出库 |
| 注意事项 | 换货需等仓库收到退货后才发货；补发可直接发货 |

---

#### 步骤7：物流跟踪

| 属性 | 内容 |
|------|------|
| 步骤编号 | S07 |
| 步骤名称 | 跟踪物流状态 |
| 操作说明 | 1. 获取物流单号后及时告知用户<br>2. 定期跟踪物流进度<br>3. 发现异常及时联系物流处理 |
| 输入信息 | 物流单号、快递公司 |
| 输出信息 | 物流状态更新 |
| 系统操作 | 物流跟踪系统/快递公司官网 |
| 注意事项 | 物流异常需在24小时内处理并告知用户 |

---

#### 步骤8：确认收货与完结

| 属性 | 内容 |
|------|------|
| 步骤编号 | S08 |
| 步骤名称 | 确认收货并完结工单 |
| 操作说明 | 1. 跟踪到用户签收后，主动联系确认<br>2. 询问商品是否完好、是否满意<br>3. 在系统中标记工单完结<br>4. 邀请用户评价服务 |
| 输入信息 | 签收状态 |
| 输出信息 | 完结工单、满意度评价 |
| 注意事项 | 如用户反馈新商品仍有问题，需重新开启售后流程 |

### 3. 决策矩阵

| 决策点 | 条件 | 是（Y） | 否（N） |
|--------|------|---------|---------|
| D01 | 是否符合换货/补发条件？ | 进入库存检查 | 拒绝申请，说明原因 |
| D02 | 是否有足够库存？ | 进入用户确认 | 协商替代方案 |
| D03 | 用户是否确认处理？ | 创建处理单据 | 关闭工单或转其他方案 |
| D04 | 换货是否需用户退货？ | 等待退货入库 | 直接发货 |
| D05 | 质检是否通过？ | 发出新商品 | 协商其他处理方案 |

---

### 4. 异常处理

| 异常场景 | 处理方案 | 负责岗位 |
|----------|----------|----------|
| 库存不足 | 1. 推荐替代规格<br>2. 建议退款处理<br>3. 登记缺货，承诺到货后优先补发 | 售后客服 |
| 用户不确认 | 1. 详细解释流程<br>2. 强调售后保障<br>3. 如仍拒绝，记录原因后关闭 | 售后客服 |
| 退货物流异常 | 1. 联系物流公司查询<br>2. 如丢失，启动理赔流程<br>3. 先行补发或退款 | 售后客服/物流专员 |
| 换货后仍不满意 | 1. 了解具体问题<br>2. 可再次换货或转为退货退款<br>3. 特殊情况升级主管处理 | 售后客服/主管 |
| 超时效申请 | 1. 核实特殊情况<br>2. 酌情特殊处理或拒绝<br>3. 超15天原则上引导维修 | 售后客服/主管 |
