## 4. 目的

本 SOP 旨在规范京东服务+ 的全流程服务标准，确保服务质量一致性，提升用户体验，明确各环节责任与操作规范，建立标准化的服务交付体系。

---

## 5. 适用范围

本 SOP 适用于京东服务+ 平台所有服务类型，包括：
- 家电安装服务（空调、电视、烟机、热水器等）
- 家电维修服务（各类家用电器故障维修）
- 家电清洗服务（空调、烟机、洗衣机、冰箱等深度清洗）
- 家电检测服务（故障检测、性能评估）
- 家居安装/维修服务（灯具、卫浴、锁具、窗帘等）
- 企业服务（办公设备安装维修、设备巡检等）

---

## 6. 职责分工

| 角色 | 职责 |
|------|------|
| **用户/客户** | 准确描述服务需求、提供真实设备信息、配合服务时间、按时支付费用、服务验收与评价 |
| **平台运营** | 订单管理、工程师调度、服务质量监控、投诉处理、数据运营分析 |
| **服务工程师** | 准时上门服务、专业规范操作、现场安全施工、费用透明报价、服务质量保障 |
| **客服中心** | 售前咨询、订单跟踪、投诉受理、争议协调、售后回访 |
| **质控部门** | 服务标准制定、工程师培训认证、服务质量抽检、差评整改跟踪 |

## 7. 流程步骤

### 7.1 服务预约流程

#### 7.1.1 用户下单

| 步骤 | 操作内容 | 标准/要求 |
|------|----------|-----------|
| 7.1.1.1 | 进入京东服务+ 入口 | 京东APP首页/搜索"服务+"/扫描服务码 |
| 7.1.1.2 | 选择服务类型 | 安装/维修/清洗/检测四选一 |
| 7.1.1.3 | 选择设备品类 | 空调、电视、冰箱、洗衣机、烟机、热水器等 |
| 7.1.1.4 | 填写设备信息 | 品牌、型号、购买时间、故障现象（维修） |
| 7.1.1.5 | 选择服务时间 | 预约时间段（通常2小时为一个时段） |
| 7.1.1.6 | 填写服务地址 | 详细地址、联系人、联系电话 |
| 7.1.1.7 | 确认服务费用 | 查看预估费用明细 |
| 7.1.1.8 | 提交订单支付 | 支付定金或全款 |

#### 7.1.2 系统派单

| 步骤 | 操作内容 | 标准/要求 |
|------|----------|-----------|
| 7.1.2.1 | 订单进入派单池 | 系统根据LBS匹配附近工程师 |
| 7.1.2.2 | 智能派单 | 考虑工程师技能、当前工单量、距离、评分 |
| 7.1.2.3 | 工程师接单 | 工程师APP端确认接单（15分钟内） |
| 7.1.2.4 | 派单成功通知 | 短信/APP推送通知用户 |
| 7.1.2.5 | 工程师联系用户 | 确认上门时间、了解基本情况 |

### 7.2 服务类型详解

#### 7.2.1 安装服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **准备阶段** | 1. 确认安装环境 | 检查电源、空间、承重、通风条件 |
| | 2. 确认安装位置 | 与用户沟通确认最佳安装位置 |
| | 3. 检查配件完整性 | 核对产品配件、辅材准备 |
| **施工阶段** | 4. 安全防护 | 佩戴安全装备、铺设防护垫 |
| | 5. 定位打孔 | 精准测量、防尘打孔 |
| | 6. 设备安装 | 按规范安装、水平校准 |
| | 7. 管路连接 | 密封处理、检漏测试 |
| | 8. 电路连接 | 接地保护、绝缘检测 |
| **调试阶段** | 9. 通电测试 | 功能测试、运行检测 |
| | 10. 效果验证 | 制冷/制热效果、噪音检测 |
| | 11. 用户指导 | 操作讲解、注意事项说明 |
| **收尾阶段** | 12. 现场清理 | 清理施工垃圾、擦拭设备 |
| | 13. 填写工单 | 记录安装信息、用户签字 |

#### 7.2.2 维修服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **诊断阶段** | 1. 故障询问 | 详细了解故障现象、发生时间、使用环境 |
| | 2. 外观检查 | 检查设备外观、电源连接、使用环境 |
| | 3. 通电检测 | 安全检测、故障代码读取 |
| | 4. 拆机检测 | 内部部件检查、电路检测 |
| | 5. 故障定位 | 确定故障原因、损坏部件 |
| **报价阶段** | 6. 维修方案 | 提供维修/更换建议 |
| | 7. 费用报价 | 明确人工费+配件费，用户确认 |
| **维修阶段** | 8. 配件更换 | 使用正品配件、规范更换 |
| | 9. 电路修复 | 焊接、绝缘处理 |
| | 10. 系统调试 | 参数设置、功能恢复 |
| **验证阶段** | 11. 功能测试 | 全面功能验证 |
| | 12. 稳定性测试 | 运行观察、确保故障排除 |

#### 7.2.3 清洗服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **准备阶段** | 1. 环境检查 | 检查设备状态、周边环境 |
| | 2. 防护措施 | 铺设防护垫、准备接水设备 |
| | 3. 断电处理 | 安全断电、验电确认 |
| **拆洗阶段** | 4. 部件拆卸 | 按规范拆卸可清洗部件 |
| | 5. 深度清洗 | 使用专业清洗剂、高温蒸汽 |
| | 6. 杀菌消毒 | 消毒液处理、高温杀菌 |
| **装复阶段** | 7. 部件安装 | 正确复位、紧固检查 |
| | 8. 电路恢复 | 接线检查、绝缘确认 |
| **验收阶段** | 9. 通电测试 | 功能正常、无异响 |
| | 10. 清洁对比 | 前后效果展示 |

#### 7.2.4 检测服务流程

| 阶段 | 操作步骤 | 技术标准 |
|------|----------|----------|
| **检测阶段** | 1. 基础检测 | 外观、电源、基本功能 |
| | 2. 性能检测 | 制冷/制热效率、能耗检测 |
| | 3. 安全检测 | 漏电、接地、绝缘检测 |
| | 4. 深度检测 | 压力检测、电路检测 |
| **报告阶段** | 5. 数据分析 | 检测数据分析 |
| | 6. 问题诊断 | 潜在问题识别 |
| | 7. 建议方案 | 维修/保养建议 |
| | 8. 出具报告 | 电子检测报告 |

### 7.3 收费标准说明

#### 7.3.1 收费构成

| 收费项目 | 说明 | 计费方式 |
|----------|------|----------|
| **上门费** | 工程师上门的交通成本 | 按区域：市区30-50元，郊区50-80元 |
| **检测费** | 故障诊断、检测服务 | 30-100元（部分可抵扣维修费） |
| **安装费** | 设备安装人工费 | 按品类：挂机100-200元，柜机150-300元，中央空调300-800元 |
| **维修费** | 故障维修人工费 | 按难度：小修80-150元，中修150-300元，大修300-600元 |
| **配件费** | 更换配件费用 | 按配件类型，明码标价 |
| **高空费** | 2楼以上外机作业 | 2-5层50-100元，6层以上100-150元 |
| **打孔费** | 穿墙孔施工 | 普通墙30-50元/个，混凝土80-150元/个 |

#### 7.3.2 收费原则

1. **透明定价**：服务前明确告知所有费用
2. **明码标价**：执行平台公示价格标准
3. **用户确认**：额外费用需用户确认后方可施工
4. **开具凭证**：提供正规发票/收据

## 9. 附录

### 9.1 服务禁语

工程师在服务过程中禁止使用以下语言：
- "不知道"、"不归我管"、"找别人"
- "这是产品质量问题，找厂家"
- "这个修不了/没法弄"
- "你买的时候怎么不看清楚"
- "必须加钱才能做"

### 9.2 常用话术

| 场景 | 标准话术 |
|------|----------|
| 上门时 | "您好，我是京东服务+工程师XXX，工号XXX，很高兴为您服务" |
| 检测前 | "现在为您检测设备，请稍等，大约需要X分钟" |
| 报价时 | "经过检测，故障原因是XXX，维修费用XXX元，配件费XXX元，合计XXX元，您看可以吗" |
| 完工时 | "服务已完成，这是您的质保凭证，质保期X天，有任何问题随时联系我们" |

### 9.3 应急处理

| 突发情况 | 处理措施 |
|----------|----------|
| 用户不在家 | 联系用户等待15分钟，标记后离开 |
| 现场无法维修 | 说明原因，带回维修或预约下次 |
| 用户不满意 | 耐心沟通，升级主管处理 |
| 安全事故 | 立即停止作业，救助伤员，上报平台 |
