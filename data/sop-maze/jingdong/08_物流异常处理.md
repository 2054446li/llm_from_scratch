### 二、异常类型定义与判定标准

#### 2.1 丢件（Lost Package）

| 判定维度 | 标准 |
|----------|------|
| 物流停滞 | 物流信息超过72小时无更新 |
| 末端丢失 | 显示"已签收"但客户未收到，且核实非客户原因 |
| 中转丢失 | 物流轨迹中断，经核实包裹无法找到 |
| 确认流程 | 客服发起核实 → 物流方48小时内反馈 → 确认丢件 |

#### 2.2 破损（Damaged Package）

| 判定维度 | 标准 |
|----------|------|
| 外包装破损 | 包装箱/袋明显损坏、变形、浸水 |
| 商品破损 | 商品外观或功能受损，影响正常使用 |
| 隐性破损 | 签收时外观完好，开箱后发现内部损坏 |
| 举证要求 | 需提供签收时照片/视频，或24小时内反馈记录 |

#### 2.3 延误（Delivery Delay）

| 判定维度 | 标准 |
|----------|------|
| 211限时达 | 当日上午11:00前下单，当日未送达 |
| 次日达 | 下单后第二个自然日24:00前未送达 |
| 定时达 | 未在客户指定时间段内送达 |
| 普通配送 | 超过页面承诺时效未送达 |
| 免责情形 | 天气灾害、交通管制、客户原因等不可抗力 |

---

### 三、责任判定矩阵

#### 3.1 丢件责任判定

| 场景 | 责任方 | 判定依据 |
|------|--------|----------|
| 京东物流配送 | 京东物流 | 使用京东物流单号，物流轨迹在京东系统 |
| 第三方快递配送 | 第三方物流 | 使用三通一达等外部物流单号 |
| 商家自配送 | 商家 | 商家使用自有物流或线下配送 |
| 客户填错地址 | 客户 | 地址信息经客户确认后仍错误 |

#### 3.2 破损责任判定

| 场景 | 责任方 | 判定依据 |
|------|--------|----------|
| 运输途中挤压/碰撞 | 物流方 | 外包装有明显挤压、撞击痕迹 |
| 派送环节操作不当 | 物流方 | 配送员暴力投递、未按规范操作 |
| 商品包装不合格 | 商家 | 包装不符合商品防护标准 |
| 客户签收后自行损坏 | 客户 | 签收24小时后反馈，无签收时异常证明 |
| 易碎品无警示标识 | 商家 | 易碎商品未标注"易碎""向上"等标识 |

#### 3.3 延误责任判定

| 场景 | 责任方 | 判定依据 |
|------|--------|----------|
| 物流分拣/运输延误 | 物流方 | 物流轨迹显示在某节点长时间滞留 |
| 末端配送延误 | 物流方 | 到达站点后24小时内未派送 |
| 客户原因无法联系 | 客户 | 配送员3次以上联系不上客户 |
| 地址不详/错误 | 客户 | 地址信息不完整或错误导致延误 |
| 不可抗力 | 免责 | 天气、灾害、政府管制等 |

### 五、补偿标准矩阵

#### 5.1 丢件补偿

| 商品价值 | 补偿方案 | 审批权限 |
|----------|----------|----------|
| < 500元 | 全额退款 或 补发 + 1000京豆 | 客服专员 |
| 500-2000元 | 全额退款 或 补发 + 2000京豆 | 客服主管 |
| > 2000元 | 全额退款 或 补发 + 定制补偿方案 | 部门经理 |
| 生鲜/易腐品 | 全额退款 + 50元无门槛券 | 客服主管 |

#### 5.2 破损补偿

| 破损程度 | 补偿方案 | 备注 |
|----------|----------|------|
| 轻微破损 | 商品金额5-15%等值京豆 | 可修复、不影响使用 |
| 中度破损 | 商品金额20-30%等值京豆 或 换货 | 部分功能受影响 |
| 严重破损 | 全额退款 或 补发 | 无法使用 |
| 生鲜破损 | 全额退款 + 补发/补偿券 | 按变质比例赔付 |

#### 5.3 延误补偿

| 延误时长 | 补偿标准 | 适用场景 |
|----------|----------|----------|
| 1天 | 1000京豆 | 211限时达/次日达 |
| 2天 | 2000京豆 | 普通配送延误 |
| 3天及以上 | 5000京豆 或 免单 | 需主管审批 |
| 特殊节日 | 双倍补偿 | 618/双11等高峰期 |

### 六、话术模板

#### 6.1 丢件场景

**确认丢件时：**
> "非常抱歉给您带来不好的体验。经核实，您的包裹在运输途中不幸丢失，这确实是我们的责任。我们现在为您安排补发，预计XX时间发出，同时补偿您1000京豆作为歉意，您看可以吗？"

**客户要求退款时：**
> "理解您的想法，我们立即为您办理全额退款，款项将在3-7个工作日内原路退回。同时为您申请1000京豆补偿，希望下次能给您更好的服务体验。"

#### 6.2 破损场景

**客户已签收发现破损：**
> "非常抱歉商品出现破损。请您提供一下外包装和商品破损的照片，我们核实后会立即为您处理。如果确认是物流原因，我们可以为您办理退换货，运费由我们承担，同时给予适当补偿。"

**轻微破损协商：**
> "看到照片了，这个破损确实影响了美观。考虑到不影响实际使用，我们可以为您提供XX元京豆补偿，您看这样可以吗？如果您不满意，我们也可以安排换货。"

#### 6.3 延误场景

**一般延误安抚：**
> "非常抱歉您的包裹未能按时送达。经查询，目前包裹在XX站点，预计XX时间送达。我们已催促物流优先派送，并为您申请1000京豆补偿，请您再耐心等待一下。"

**211限时达未达：**

### 七、系统操作指引

#### 7.1 创建物流异常工单

1. 进入【订单详情】→【售后服务】→【物流异常】
2. 选择异常类型：丢件/破损/延误
3. 填写异常描述，上传客户提供的证据
4. 选择处理方案：补发/退款/补偿
5. 提交审批（如需）

#### 7.2 补偿发放

1. 进入【客户关怀】→【补偿管理】
2. 选择补偿类型：京豆/优惠券/余额
3. 填写补偿金额和原因
4. 关联订单号
5. 提交审批（超出权限需主管审批）

#### 7.3 物流核实

1. 进入【物流系统】→【异常工单】
2. 创建核实工单，填写物流单号
3. 选择优先级：普通/加急（丢件/高价值选加急）
4. 跟进物流反馈，48小时内确认结果

### 八、注意事项与风险提示

| 风险点 | 应对措施 |
|--------|----------|
| 客户情绪失控 | 立即升级主管，避免冲突；优先安抚，再处理问题 |
| 高价值商品丢件（>5000元） | 必须升级部门经理，启动专项调查 |
| 客户要求额外赔偿（超标准） | 记录诉求，提交主管审批，不轻易承诺 |
| 第三方物流推诿责任 | 京东先行赔付客户，内部再与物流方追偿 |
| 客户威胁投诉/曝光 | 立即升级，由主管或经理介入处理 |
| 批量异常（同一批次多客户反馈） | 立即上报，启动应急预案，统一处理口径 |
