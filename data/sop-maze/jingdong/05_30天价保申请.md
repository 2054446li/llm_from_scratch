## 三、SOP-Maze 格式详细内容

### 3.1 基本信息

| 项目 | 内容 |
|------|------|
| SOP名称 | 京东30天价保申请流程 |
| 适用对象 | 京东自营商品订单用户 |
| 价保期限 | 7天/30天（根据商品类别） |
| 责任部门 | 售后服务部/客服中心 |
| 版本号 | V1.0 |
| 生效日期 | 2024年1月1日 |

### 3.2 价保期限规则

| 商品类别 | 价保期限 | 说明 |
|----------|----------|------|
| 家用电器 | 30天 | 冰箱、洗衣机、空调、电视等 |
| 手机数码 | 7天 | 手机、平板、相机等 |
| 电脑办公 | 7天 | 笔记本、台式机、配件等 |
| 日用百货 | 7天 | 食品、个护、家居等 |
| 图书音像 | 7天 | 图书、音像制品等 |
| 生鲜冷链 | 不支持 | 易腐商品不参与价保 |
| 虚拟商品 | 不支持 | 充值卡、软件等 |
| 秒杀/特价商品 | 不支持 | 明确标注不参与价保的商品 |

### 3.3 比价规则

#### 3.3.1 比价基准
- **订单实付价格**: 用户实际支付金额（扣除优惠券、京豆、红包等）
- **当前售价**: 商品当前页面显示的销售价格
- **差价计算**: 差价 = 订单实付价格 - 当前售价

#### 3.3.2 比价范围
- 仅限同一商品（SKU相同）
- 仅限同一销售主体（京东自营/同一第三方商家）
- 仅限正常销售状态商品（非下架、非缺货）

#### 3.3.3 不计入比价的情况
- 限时秒杀价格
- 优惠券抵扣金额（部分情况）
- 满减活动（未满足条件时）
- 套装/组合优惠价格
- 企业采购价格
- 批发价格

### 3.4 差价计算规则

```
差价计算公式:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

基础差价 = 订单实付价 - 当前商品售价

实际退款额 = 基础差价 - 不可价保部分

其中不可价保部分包括:
• 已使用的部分优惠券金额
• 特殊活动补贴
• 赠品价值（如买赠活动）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 计算示例

**示例1: 基础价保**
- 订单实付价: ¥2999
- 当前售价: ¥2799
- 优惠券: 无
- **可退差价**: ¥2999 - ¥2799 = **¥200**

**示例2: 含优惠券订单**
- 订单实付价: ¥2899（原价2999，使用100元券）
- 当前售价: ¥2799
- 当前可用优惠券: 50元
- **可退差价**: ¥2899 - (¥2799 - ¥50) = **¥150**

### 3.5 退款流程

#### 3.5.1 退款方式

| 退款方式 | 到账时间 | 适用场景 |
|----------|----------|----------|
| 原路退回 | 1-7个工作日 | 原支付方式为微信/支付宝/银行卡 |
| 京东余额 | 实时到账 | 用户选择退至余额 |
| 京豆 | 实时到账 | 按1元=100京豆比例兑换 |
| 京东E卡 | 1-3个工作日 | 特殊活动订单 |

#### 3.5.2 退款处理时效

| 处理环节 | 时效要求 | 责任方 |
|----------|----------|--------|
| 系统自动审核 | 即时 | 系统 |
| 人工复核 | 24小时内 | 客服人员 |
| 退款到账 | 1-7个工作日 | 财务/支付渠道 |
| 异常处理 | 48小时内 | 客服主管 |

### 3.6 不支持价保的情况

#### 3.6.1 订单类型限制
- 第三方商家订单（遵循商家自身政策）
- 团购订单
- 企业采购订单
- 拍卖订单
- 二手商品订单

#### 3.6.2 商品类型限制
- 生鲜、冷冻、易腐商品
- 虚拟商品（充值卡、软件授权等）
- 黄金、珠宝等贵金属
- 汽车、房产等大件商品
- 明确标注"不支持价保"的促销商品

#### 3.6.3 时间限制
- 超出价保期限（7天/30天）
- 订单已完成退货
- 订单已取消

#### 3.6.4 价格类型限制
- 秒杀价格
- 闪购价格
- 限量抢购价格
- 员工内购价格
- 批发价格

### 3.7 价保失败原因及处理

| 失败原因 | 系统提示 | 客服处理话术 |
|----------|----------|--------------|
| 超出价保期 | "该订单已超过价保期限" | "您的订单已超过7天/30天价保期，无法申请价保。建议关注后续促销活动。" |
| 无差价 | "当前价格未低于订单价格" | "经系统比对，该商品当前售价未低于您的购买价格，暂无价保差价。" |
| 商品下架 | "该商品已下架，无法比价" | "该商品已下架，无法自动比价。如您发现同款商品更低价格，可联系人工客服核实。" |
| 不支持价保 | "该商品不支持价格保护" | "您购买的商品属于不支持价保的类别（生鲜/虚拟商品等），无法申请价保。" |
| 第三方商家 | "第三方商家订单，请直接联系商家" | "您的订单为第三方商家销售，价保政策由商家制定，建议您直接联系商家客服。" |
| 系统异常 | "系统繁忙，请稍后重试" | "系统暂时无法处理您的申请，请稍后重试或联系人工客服协助处理。" |

### 3.8 客服处理流程

#### 3.8.1 一线客服处理权限

| 场景 | 处理方式 | 权限范围 |
|------|----------|----------|
| 系统价保成功 | 告知用户到账时间和方式 | 标准流程 |
| 系统价保失败-有差价 | 人工核实后手动发起价保 | ≤500元 |
| 系统价保失败-无差价 | 解释原因，结束服务 | 标准话术 |
| 用户不认可结果 | 安抚并升级至二线 | 转交处理 |

#### 3.8.2 二线客服/主管处理权限

| 场景 | 处理方式 | 权限范围 |
|------|----------|----------|
| 大额差价争议 | 人工核算并审批 | >500元 |
| 系统异常订单 | 特殊通道处理 | 无限制 |
| 投诉升级 | 安抚并给出解决方案 | 无限制 |
| 特殊活动订单 | 按活动规则处理 | 按活动规定 |

### 3.9 常见问题FAQ

**Q1: 价保退款退到哪里？**
A: 默认原路退回至您的支付账户（微信/支付宝/银行卡），也可选择退至京东余额。

**Q2: 价保申请后多久到账？**
A: 系统审核通过后，原路退回1-7个工作日，京东余额实时到账。

**Q3: 使用了优惠券的订单可以价保吗？**
A: 可以，但差价计算会考虑当前可使用的优惠券情况。

**Q4: 第三方商家的商品支持价保吗？**
A: 第三方商家订单遵循商家自身价保政策，建议直接联系商家客服。

**Q5: 价保期内商品下架了怎么办？**
A: 商品下架后无法自动比价，如您发现同款商品更低价格，可联系人工客服核实处理。

**Q6: 秒杀价格可以价保吗？**
A: 秒杀、闪购等限时特价不参与价保比价。

**Q7: 价保可以多次申请吗？**
A: 同一订单在价保期内可以多次申请，但累计退款金额不超过订单实付价。

**Q8: 已申请退货的订单还能价保吗？**
A: 已申请退货或已退货完成的订单不支持价保。
