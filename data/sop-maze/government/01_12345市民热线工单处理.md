# 12345市民热线工单处理SOP

## 1. SOP简介

本SOP规范12345热线话务员接听市民来电后的完整处理流程，涵盖诉求受理、分类派单、跟踪督办、回访结案四个核心环节，确保市民诉求得到及时、准确、满意的处理。

## 4. Standard Operating Procedures

### 4.1 开场白与身份确认话术

#### 4.1.1 标准开场白

```
【标准话术】
"您好，这里是XX市12345市民服务热线，工号XXXX为您服务，请问有什么可以帮您？"

【节假日开场白】
"您好，XX市12345市民服务热线祝您节日快乐，工号XXXX为您服务，请问有什么可以帮您？"

【高峰时段简化版】
"您好，12345热线，工号XXXX，请讲。"
```

#### 4.1.2 身份确认话术

| 场景 | 话术模板 |
|------|----------|
| **来电人身份确认** | "请问您贵姓？方便留下全名吗？" |
| **联系方式确认** | "请问您的联系电话是？是否有备用联系方式？" |
| **地址确认** | "请问事发地址/您的居住地址是？属于哪个区/街道？" |
| **匿名诉求** | "好的，我们尊重您的意愿，会为您保密。请问具体诉求是？" |
| **代理诉求** | "请问您是被代理人的什么人？是否有授权委托书？" |

#### 4.1.3 结束语

```
【标准结束语】
"感谢您的来电，我们会尽快处理您的诉求，请保持电话畅通。祝您生活愉快，再见！"

【投诉类结束语】
"您反映的问题我们已经记录，将在X个工作日内给您答复，请您留意接听。感谢您的监督，再见！"

【求助类结束语】
"您的情况我们已了解，会立即转交相关部门处理。如涉及紧急情况，请同时拨打110/120/119。再见！"
```

### 4.3 紧急程度判断标准

| 级别 | 判定标准 | 响应要求 | 办理时限 |
|------|----------|----------|----------|
| **特急** | ① 危及生命财产安全<br>② 重大自然灾害<br>③ 群体性事件<br>④ 重大公共卫生事件 | 即时报告值班长<br>10分钟内报领导<br>启动应急预案 | 2小时内响应<br>24小时内办结 |
| **紧急** | ① 影响正常生活秩序<br>② 安全隐患明显<br>③ 涉及多人利益<br>④ 可能引发舆情 | 优先派单<br>电话通知责任单位<br>纳入重点监控 | 4小时内响应<br>3个工作日内办结 |
| **一般** | ① 常规咨询投诉<br>② 个人一般诉求<br>③ 非时效性敏感 | 正常派单流程<br>系统流转 | 1个工作日内响应<br>按类型时限办结 |

## 5. Rule约束

### 5.1 核心制度规则

| 编号 | 规则名称 | 规则内容 |
|------|----------|----------|
| R01 | **首接负责制** | 首个接听的话务员对工单全流程负责，不得推诿。需跟踪至工单办结或明确移交。 |
| R02 | **限时办理制** | 所有工单必须在规定时限内办结，超期系统自动预警并纳入考核。 |
| R03 | **一次性告知制** | 对材料不全的诉求，需一次性告知所需全部材料，避免群众多次往返。 |
| R04 | **限时办结制** | 简单事项当场办结，复杂事项按类型限时办结，特急事项2小时内响应。 |
| R05 | **AB岗工作制** | 每个岗位设置A岗（主责）和B岗（备岗），确保工作连续性。 |
| R06 | **保密工作制** | 严格保护来电人隐私，未经同意不得泄露姓名、电话、地址等信息。 |
| R07 | **回避制度** | 话务员与诉求事项有利害关系的，应主动申请回避。 |
| R08 | **督办机制** | 超期未办工单自动升级督办，由督查部门介入协调。 |
| R09 | **考核通报制** | 定期通报各单位工单办理情况，纳入年度绩效考核。 |
| R10 | **责任追究制** | 对推诿扯皮、弄虚作假、泄露信息等行为严肃追责。 |

### 5.2 操作规范规则

| 编号 | 规则名称 | 规则内容 |
|------|----------|----------|
| R11 | **三声接听** | 电话铃响三声内必须接听，高峰期最长不超过五声。 |
| R12 | **全程录音** | 所有通话必须全程录音，录音保存不少于3年。 |
| R13 | **准确记录** | 诉求内容记录须准确完整，包含时间、地点、人物、事件、诉求五要素。 |
| R14 | **分类准确** | 诉求分类须准确，派单部门须正确，避免因分类错误导致流转不畅。 |
| R15 | **敏感报告** | 涉及群体性事件、重大安全隐患、敏感舆情的，须即时报告值班长。 |
| R16 | **无效甄别** | 对恶意骚扰、无理纠缠、重复无效诉求进行标记，按程序处理。 |

| R19 | **不满意重办** | 满意度评价不满意（≤5分）的工单，须发回责任单位重办。 |
| R20 | **归档规范** | 办结工单须在3个工作日内完成归档，确保资料完整可查。 |
