## 4. Standard Operating Procedures

### 4.1 缴存基数与比例

#### 4.1.1 缴存基数核定

| 项目 | 规定内容 | 计算公式 |
|-----|---------|---------|
| **基数上限** | 不超过当地职工月平均工资的3倍 | 上限 = 上年度社平工资 × 3 |
| **基数下限** | 不低于当地最低工资标准 | 下限 = 当地最低工资标准 |
| **新职工基数** | 以当月工资为缴存基数 | 基数 = 首月工资 |
| **调整周期** | 每年7月调整一次 | 年度基数核定 |

#### 4.1.2 缴存比例

| 类型 | 单位比例 | 个人比例 | 合计比例 |
|-----|---------|---------|---------|
| **常规比例** | 5%-12% | 5%-12% | 10%-24% |
| **困难企业** | 可申请降低至5%以下 | 不低于5% | 协商确定 |
| **机关事业单位** | 12% | 12% | 24% |

**月缴存额计算公式：**
```
月缴存额 = 缴存基数 × (单位比例 + 个人比例)

示例：某职工缴存基数8000元，单位比例12%，个人比例12%
月缴存额 = 8000 × (12% + 12%) = 8000 × 24% = 1920元
其中：单位缴存960元，个人缴存960元
```

### 4.2 提取条件与额度计算

#### 4.2.1 提取类型与条件

| 提取类型 | 提取条件 | 提取额度 | 提取频次 |
|---------|---------|---------|---------|
| **购房提取** | 购买自住住房 | 账户余额或购房款（取低） | 一次性 |
| **租房提取** | 无房且租房居住 | 每月最高1500-3000元 | 每季度/每年 |
| **还贷提取** | 偿还住房贷款 | 当年还款额或账户余额 | 每年一次 |
| **退休提取** | 达到退休年龄 | 账户全部余额 | 一次性 |
| **大病提取** | 本人/配偶/直系亲属患重大疾病 | 医疗费用自付部分 | 一次性 |
| **失业提取** | 失业满2年且未重新就业 | 账户全部余额 | 一次性 |

#### 4.2.2 提取额度计算示例

```
【购房提取计算】
账户余额：150,000元
购房总价：800,000元
首付比例：30%（240,000元）
可提取额度 = min(账户余额, 购房款) = min(150,000, 800,000) = 150,000元

【租房提取计算】
当地租房提取上限：2,000元/月
申请提取时长：12个月
可提取额度 = 2,000 × 12 = 24,000元（不超过账户余额）

【还贷提取计算】
当年已还贷款本息：60,000元
账户余额：80,000元
可提取额度 = min(当年还款额, 账户余额) = min(60,000, 80,000) = 60,000元
```

### 4.3 贷款额度计算公式

#### 4.3.1 贷款额度核定方法

贷款额度取以下三种计算方法的**最小值**：

**方法一：账户余额倍数法**
```
贷款额度 = 账户余额 × 倍数

其中：
- 首套房倍数：15-20倍（各地不同）
- 二套房倍数：10-15倍
- 示例：账户余额50,000元，倍数20倍
  贷款额度 = 50,000 × 20 = 1,000,000元
```

**方法二：还款能力法**
```
贷款额度 = (月缴存额 × 贷款年限 × 12 × 还贷能力系数) / 月还款额系数

或简化为：
月还款额 ≤ 月收入 × 还贷能力比例（通常50%-60%）

示例：
月收入：10,000元
还贷能力比例：50%
可承受月还款额：5,000元
按等额本息、利率3.1%、期限30年计算：
最高贷款额度 ≈ 1,170,000元
```

**方法三：房价成数法**
```
贷款额度 = 房屋总价 × 贷款成数

其中：
- 首套房最高成数：70%-80%
- 二套房最高成数：60%-70%
- 示例：房屋总价1,500,000元，首套房成数70%
  贷款额度 = 1,500,000 × 70% = 1,050,000元
```

#### 4.3.2 最终额度确定

```
【综合计算示例】
账户余额：50,000元
月收入：10,000元
房屋总价：1,500,000元（首套房）

方法一：50,000 × 20 = 1,000,000元
方法二：约1,170,000元（按还款能力）
方法三：1,500,000 × 70% = 1,050,000元

最终可贷额度 = min(1,000,000, 1,170,000, 1,050,000) = 1,000,000元
同时需满足：不超过当地最高贷款限额（如120万元）
```

### 4.4 贷款利率与还款方式

#### 4.4.1 贷款利率（2024年标准）

| 贷款类型 | 贷款期限 | 首套房利率 | 二套房利率 |
|---------|---------|-----------|-----------|
| **公积金贷款** | 5年以下（含） | 2.35% | 2.775% |
| **公积金贷款** | 5年以上 | 2.85% | 3.325% |

#### 4.4.2 还款方式对比

| 对比项 | 等额本息 | 等额本金 |
|-------|---------|---------|
| **月还款额** | 每月相同 | 逐月递减 |
| **前期压力** | 较小 | 较大 |
| **总利息** | 较多 | 较少 |
| **适合人群** | 收入稳定者 | 前期还款能力强者 |

**计算公式：**

```
【等额本息】
月还款额 = 贷款本金 × [月利率 × (1+月利率)^还款月数] / [(1+月利率)^还款月数 - 1]

示例：贷款100万元，期限30年，利率2.85%
月利率 = 2.85% / 12 = 0.2375%
还款月数 = 360
月还款额 = 1,000,000 × [0.002375 × (1.002375)^360] / [(1.002375)^360 - 1] ≈ 4,134元

【等额本金】
月还款额 = (贷款本金 / 还款月数) + (本金 - 已还本金累计) × 月利率

首月还款 = (1,000,000 / 360) + 1,000,000 × 0.002375 ≈ 5,153元
末月还款 = (1,000,000 / 360) + (1,000,000/360) × 0.002375 ≈ 2,784元
```

```
市民周女士：组合贷款的利率怎么算？

公积金专员：组合贷款中：
- 公积金部分：利率2.85%（5年以上）
- 商业贷款部分：利率按LPR执行，目前首套约3.85%-4.2%

两部分贷款分别计息，月供合并计算。

市民周女士：还款方式可以不一样吗？

公积金专员：可以。公积金部分和商贷部分可以分别选择还款方式。比如公积金选等额本金，商贷选等额本息，或者都选一样的。

市民周女士：那办理流程复杂吗？需要跑两个银行？

公积金专员：不复杂，您只需到公积金受托银行（如建行、工行等）一次性提交材料，银行会同时办理公积金和商贷两部分。审批也是同步进行的。

市民周女士：放款呢？也是一起放吗？

公积金专员：是的，两部分贷款审批通过后，会同时放款到监管账户。您只需按月还一个合并后的月供即可。

市民周女士：明白了，那我现在需要准备什么？

公积金专员：组合贷款材料包括：
1. 夫妻双方身份证、户口本、婚姻证明
2. 收入证明、银行流水（覆盖两部分贷款的还款能力）
3. 购房合同、首付款发票
4. 征信报告
5. 首付款转账凭证

您可以先到银行进行预审批，确认贷款额度后再正式申请。

市民周女士：好的，谢谢！
```

### 7.8 退休提取业务对话

```
【场景：市民马先生办理退休提取】

市民马先生：你好，我刚退休，想把公积金全部取出来，怎么办理？

公积金专员：马先生您好！恭喜退休！退休提取可以全额提取账户余额。请问您已经办理完退休手续了吗？

市民马先生：办完了，退休证也拿到了。

公积金专员：好的。退休提取需要以下材料：
1. 身份证原件
2. 退休证或退休审批表
3. 本人名下的银行卡
4. 填写《住房公积金提取申请表》

请问您的公积金账户目前是什么状态？

市民马先生：应该是正常缴存状态，单位缴到我退休那个月。

公积金专员：好的，单位会为您办理账户封存。您可以在封存后办理提取，也可以现在直接办理，我们会同步处理。

市民马先生：我账户里大概有多少钱能提取？

公积金专员：您可以全额提取账户内的全部余额，包括：
- 个人缴存部分
- 单位缴存部分
- 历年结息

具体金额您可以通过APP查询，或到柜台查询。

市民马先生：提取后账户还有吗？

公积金专员：提取后账户会保留，但余额为零。如果您以后重新就业继续缴存，可以重新使用原账户。

市民马先生：好的，那我今天就去办。多久能到账？

公积金专员：退休提取是即时办结业务，材料齐全的话，现场审核通过后，资金一般当天或次日到账。

市民马先生：太好了，谢谢！

公积金专员：不客气！祝您退休生活愉快！
```

## 附录：常用计算公式汇总

### A.1 缴存计算
```
月缴存额 = 缴存基数 × (单位比例 + 个人比例)
年度结息 = 账户余额 × 年利率（目前1.5%）
```

### A.2 提取计算
```
购房提取额度 = min(账户余额, 购房实际支出)
租房提取额度 = min(月提取上限 × 月数, 账户余额)
还贷提取额度 = min(当年还款额, 账户余额)
```

### A.3 贷款计算
```
贷款额度 = min(余额×倍数, 还款能力额度, 房价×成数, 当地上限)

等额本息月还款 = 本金 × [月利率×(1+月利率)^n] / [(1+月利率)^n - 1]

等额本金月还款 = 本金/n + (本金 - 已还本金) × 月利率
```

### A.4 逾期计算
```
逾期罚息 = 逾期本金 × 日罚息率(0.05%) × 逾期天数
```
