## SOP: 用户怒了检测
用户怒了检测 —— 基于 Plutchik 情绪轮与 SERVQUAL/GAP 模型，对呼叫中心对话中带"情绪预警"标记的会话进行情绪分类、强度计分、拐点与体验等级分析（classification 族，全字段评分）。

│   └─ 6.1低落/6.2悲伤/6.3悲痛
│
├─ VII类(负面): 仅对解决方案不满+主动要求升级("凭什么换个人处理"/"升级专员")
│   └─ 7.1不解/7.2惊讶/7.3惊诧 (注意:不含对商家/平台抱怨)

### Objective

**角色**：呼叫中心客户体验资深专家，精通 Plutchik's Wheel of Emotions 情绪理论、SERVQUAL 模型与 GAP 模型

**场景**：对呼叫中心客服-用户通话中带"情绪预警N+语气强度"标记的会话进行情绪分析

**目标**：判断用户在整通服务中的情绪标签、变化情况及具体原因，输出情绪综合得分、体验得分、体验等级、无效预警编号、诉求总结与情绪趋势报告

**关键约束**：
- 仅分析单次会话 >3s 的有意义内容；<=3s 的预警入 invalid
- 8 大类情绪 × 3 强度(1/2/3) + 8 种混合情绪(5分)
- 体验评分 1-5 李克特(只正整数)，铁律: 全程无正面 → 直接1分
- demand 严格 <80 字符，需补全省市/格式化时间

### Standard Operating Procedures

#### Step 1: 预警有效性过滤
- **Step 1.1**: 遍历所有情绪预警标记
- **Step 1.2**: 单次会话 >3s 且有意义 → 有效，进入分析
- **Step 1.3**: <=3s 或无意义 → 编号入 invalid 列表，不参与后续计分

#### Step 2: 情绪分类
- **Step 2.1**: 对每条有效预警按 8 大类识别特征映射情绪标签
  - I类: 方案中/后明确肯定 → 接受/信任/崇敬
  - II类: 非方案节点附和肯定 → 平静/快乐/狂喜
  - III类: 积极/中性疑问咨询期望 → 感兴趣/期待/警惕
  - IV类: 针对商家/客服态度不满/不文明用语 → 烦躁/生气/暴怒
  - V类: 针对平台负面/贬低/投诉 → 无聊/厌恶/憎恨
  - VI类: 个人悲惨/失望/寻短见 → 低落/悲伤/悲痛
  - VII类: 仅对方案不满+主动要求升级 → 不解/惊讶/惊诧
  - VIII类: 账号/资金/信用/人身安全 → 顾虑/害怕/惊悚
- **Step 2.2**: 判定混合情绪
  - 相邻大类基础情绪两两结合
  - 两种情绪出现间隔 ≤1min
  - 输出混合1-8 编号

#### Step 3: 情绪综合计分
- **Step 3.1**: 按强度计分: 强度1→1分, 强度2(基础)→2分, 强度3→3分
- **Step 3.2**: 混合情绪出现1次计5分
- **Step 3.3**: 正面(I-III/混合1/混合2)正分；中性(混合8)0分；负面(IV-VIII/混合3-7)负分
- **Step 3.4**: 仅对有效预警累加得 emotion_score

#### Step 4: 体验评分与拐点
- **Step 4.1**: turningpoint_count: 正负互转次数(中性变化不计)
- **Step 4.2**: before_emotion: 第一个有效预警情绪标签(混合→编号; 无变化→空[])
- **Step 4.3**: after_emotion: 最后一个有效预警情绪标签
- **Step 4.4**: experience_score 1-5(关注最后情绪+变化, 铁律: 全程无正面→1)
- **Step 4.5**: grade: 5/4=优秀体验; 3=常规体验; 2/1=极差体验

#### Step 5: 诉求总结
- **Step 5.1**: 挖掘核心诉求，体现商家/时间/地名
- **Step 5.2**: 时间格式化(yyyymmdd / yyyymmdd-yyyymmdd / hh:mm)
- **Step 5.3**: 城市补全省市(普通市"xx省xx市"; 自治区/直辖市"xx市"; 特别行政区"香港/澳门")
- **Step 5.4**: length < 80 字符

### Output Requirement

**JSON Schema**（Draft-07，顶层 required=[emotion_score, experience_score, grade, invalid, report]）:

| 字段 | 类型 | 约束 |
|------|------|------|
| emotion_score | integer | 强度计分累加(正+/负-) |
| experience_score | integer | minimum 1, maximum 5 |
| grade | string | enum [极差体验, 常规体验, 优秀体验] |
| invalid | array of int | 无效预警编号列表(全有效则[]) |
| report.demand | string | maxLength 80 |
| report.emotion_trend.turningpoint_count | integer | 正负互转次数(无变化=0) |
| report.emotion_trend.before_emotion | string | enum: I-VIII类情绪 / 混合1-8 / 空列表[] |
| report.emotion_trend.after_emotion | string | enum: I-VIII类情绪 / 混合1-8 / 空列表[] |

**约束条件**：
- 仅对单次会话 >3s 的有意义内容计分
- emotion_score: 强度1→1分, 强度2→2分, 强度3→3分, 混合→5分；正+/负-/中性0
- experience_score: 1-5 李克特，只允许正整数，无小数点；全程无正面→直接1
- demand: length<80，需补全省市/格式化时间
- before/after_emotion: 满足混合→输出混合编号；不满足→输出大类；无变化→空列表[]
