## 合成优先级建议

按 longcat 4 机制的占比与可程序化度排序：

1. **② 状态机纪律崩（32%）+ ④ 格式落地崩（10%）** —— 最高杠杆，solver-first 可反推、改了即满分。合成 spec 应覆盖 #15/#17/#21 的深嵌套结构 + #22/#6/#3 的硬规则。
2. **③ over-reasoning 净回归（29%）** —— solver-first（合并/无效/拦截可代码化）+ 正向教收手（自我推翻/决策回避需人工核验）。覆盖 #3/#16/#22/#18。
3. **① 没读懂语义（29%）** —— 真能力缺失，forward&verify + 对抗样本，需人工核验 gold。覆盖 #8/#6/#17/#21/#22 的语义陷阱。

## 与 SOP-Maze 论文 3 大错误类型的对应

- **① 没读懂语义** = 论文 Conversational Fragility（强语境/不流利/微妙意图）
- **② 状态机纪律崩** = 论文 Route Blindness（LRS 早锁不恢复 + HRS 跳中间步/前置当已满足）
- **③ over-reasoning 净回归** = 论文 Route Blindness（rule-step互斥/拦截优先级）+ Conversational Fragility（自我推翻/决策回避）+ 部分 Calculation（中位数漏算）
- **④ 格式落地崩** = 论文不分析（只盯 0.2）的补充，含 Calculation 的 0.0 部分
